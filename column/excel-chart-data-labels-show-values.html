Excelのグラフに実際の数値をラベルで表示するには

要点

データ ラベルは、グラフのデータ要素に数値などを添えて、系列や個々の点を読み取りやすくするものです。系列かグラフを選び、グラフの右上の［グラフ要素の追加］から［データ ラベル］を選ぶと付けられます。既定では、データ ラベルはワークシートの値とリンクしており、ワークシートの値を変えるとラベルも自動で更新されます。 ただし、グラフの上でラベルの文字を書き換えると、ワークシートのデータとのリンクは切れます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

会議でグラフを見せるたびに「この月はいくら」と聞き返される。棒や点の横に実際の数値を出すデータ ラベルを、どこに付けて何を出し、手で書き換えないために何を決めるかを整理しました。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．「いくらだったのか」と聞かれないグラフにする

確認日：2026年11月17日。

対象は Windows 版の Excel です。Mac 版は操作の一部が違います。

縦棒グラフや折れ線グラフは、増えたか減ったかを見るには向いていますが、目盛から正確な金額を読み取るのは難しいものです。ヘルプでも、データ ラベルがあると、系列や個々の点についての詳しい情報が表示され、グラフが理解しやすくなると説明されています。 会議の場で数字を聞き返されるたびに元の表を開く手間を減らすには、読み手が知りたい数字をラベルで出しておくのが近道です。

2．全部の点に付けるか、1つの点だけに付けるか

ラベルは、1つの系列、全部の系列（グラフ全体）、1つのデータ ポイントのいずれにも付けられます。 12か月分の棒すべてに金額を出すと、グラフが数字で埋まって、かえって読みにくくなることがあります。

使い分けの目安は、報告で何を伝えたいかです。毎月の金額をそのまま読ませたいなら系列全体に、今月の金額だけを目立たせたいなら最新の月の1点だけに付けます。系列が2つ以上あるグラフで全部に付けると、ラベルどうしが重なりやすいので、伝えたい系列だけに絞ります。

3．データ ラベルを付ける

系列かグラフを選びます。1つのデータ ポイントだけに付けるときは、系列を選んだ後、その点を選びます。 続けて、グラフの右上の［グラフ要素の追加］から［データ ラベル］を選びます。

表示する場所を変えるときは、［データ ラベル］の横の矢印から選びます。吹き出しの図形の中に出したいときは［データ吹き出し］を選びます。 選べる位置の種類は、グラフの種類によって変わります。

1つのラベルだけ位置を動かしたいときは、そのラベルをドラッグします。系列のラベルをまとめて選ぶときは1回、1つのラベルだけを選ぶときは2回クリックします。 棒の上の端に数字が重なって読めないときは、棒の内側か外側に移すと読みやすくなります。

4．ラベルに何を出すかを決める

ラベルの中身は、系列かラベルを右クリックして［データ ラベルの書式設定］を選び、［ラベルのオプション］を選んで、ラベルに含める項目を選びます。 値のほかに系列名などを足すと、1つのラベルに書かれる文字が増えるので、何を出すかは読み手に必要なものだけにします。

表の別の列にある値をラベルにしたいときは、［ラベル オプション］で［セルの値］のチェック ボックスをオンにします。［データ ラベル範囲］ダイアログ ボックスが出たら、ラベルとして出したい範囲をワークシートで選び、［OK］を選びます。 たとえば、棒は金額のまま、ラベルには前の年との比べを書いた列を出す、といった使い方ができます。この場合は、ラベルに使う列を誰が更新するのかも決めておきます。

5．手で書き換えたラベルは、表の数字と切れる

ラベルの文字は、ラベルを選んでもう一度選ぶと、そのラベルだけが選ばれ、文字を置き換えられます。 ただし、グラフでデータ ラベルの中身を書き換えると、ワークシートのデータにはリンクされなくなります。

報告の直前に、ラベルの数字だけを手で直すと、次の月に表を更新してもそのラベルは変わらず、古い数字が残ります。数字が違っていたら、ラベルではなく元の表を直します。手で書き換えてしまったラベルを表の値に戻すには、［データ ラベルの書式設定］の［ラベル オプション］で［ラベル テキストのリセット］のチェック ボックスをオンにします。 1つの点のラベルだけを表のセルにつなぎ直すときは、ラベルを選んで数式バーに等号（=）を入れ、表示したい値の入ったセルを選んで Enter キーを押す方法も案内されています。

「この月は特別な入金があった」のような補足を書き添えたいときは、ラベルの文字を書き換えるのではなく、テキスト ボックスを使えます。 ラベルは表の数字、補足はテキスト ボックス、と分けておけば、表を更新してもラベルの数字は正しく追いかけます。

ラベルが多すぎて乱雑に見えるときは、ラベルを選んで Delete キーを押すと、一部または全部を消せます。 まとめて消すときは、［デザイン］タブの［グラフ レイアウト］で［グラフ要素の追加］から［データ ラベル］の［なし］を選びます。

6．報告に貼る前の見直し（架空の例）

見る所架空の記入例誰が見るか
ラベルを付けた範囲売上の系列の最新の月だけグラフを作った担当者
ラベルの中身値のみ（系列名は凡例で分かる）グラフを作った担当者
表との一致ラベルの数字と元の表の数字別の担当者
手で書き換えたラベル無し（あれば元の表で直す）資料をまとめる人

作った担当者は、どの系列のどの点にラベルを付けたかと、ラベルに何を出したかを自分で確かめます。別の担当者は、ラベルの数字を2か所か3か所、元の表と読み合わせます。資料をまとめる人は、手で書き換えたラベルが残っていないかだけを見ます。役割を分けておくと、月が替わったときに古い数字が残る失敗を防げます。

毎月の報告のグラフをどんな形で並べるかは、棚卸しレポートの見本のつくりも参考になります。
