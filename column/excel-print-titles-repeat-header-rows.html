Excelの長い一覧を印刷するとき各ページに見出しを付ける方法

要点

Excel の長い一覧で各ページに項目名を付けるには、［印刷タイトル］で見出しの行を繰り返す設定を使います。どの行を繰り返すかを決めてから指定し、後続の紙面にも項目名と明細が対応して載っているかを確かめる流れです。

公開：2026年11月8日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、小さな会社の事務担当者に向け、Windowsデスクトップ版Excelで、印刷する各ページに見出し行を繰り返す設定と結果の確認をまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 操作する版と、繰り返したい項目名を確かめます
  2. 見出し行の範囲を指定します
  3. 配付用の一覧では、項目名の並びを目印にします
  4. 設定を選べないときは、編集状態と選択範囲を見ます
  5. 後続の紙面でも、項目名と明細を照合します
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．操作する版と、繰り返したい項目名を確かめます

確認日：2026年11月6日

ここでは Windows のデスクトップ版の操作を扱い、対象は Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 です。Mac 向けには、公式ヘルプに Excel for Microsoft 365 for Mac の説明もあります。画面の違いを混ぜず、使っている版の説明に合わせます。

Excel for the web では、現在、印刷時に列見出しを繰り返せないため、この設定はデスクトップアプリで行います。

準備では、途中の紙面だけを受け取った人が、何の欄かを読める状態を考えます。表の名前や説明が上にある場合も、明細を読むための項目名がどこに並ぶかを先に見つけると、繰り返す対象を決めやすくなります。

2．見出し行の範囲を指定します

対象のワークシートで［ページ レイアウト］タブを開き、［ページ設定］の［印刷タイトル］を選びます。

先頭の行が見出しの場合

先頭の見出し行だけを繰り返す場合、［一番上の繰り返し行］に「$1:$1」と入力します。先頭から2行が見出しなら「$1:$2」と指定できます。見出しに何が含まれるかを見てから、必要な範囲を選ぶ考え方です。

左側にも目印が必要な場合

紙面の左側で繰り返したいラベルがある場合は、［左で繰り返す列］に、その列の参照を入力します。上に項目名を付けたいのか、左に照合の目印を残したいのかを分けて考えると、入力する欄を取り違えにくくなります。

ここで大切なのは、明細と見出しの役割を区別することです。記入するたびに変わる内容まで繰り返す対象に含めると、後続の紙面を読む際に紛らわしくなります。欄の名前として共通に読みたい部分を選びます。

3．配付用の一覧では、項目名の並びを目印にします

ここからは当社の整理です。

次の表は、繰り返す範囲を決めるために、一覧の上部を役割ごとに分ける見方です。

一覧の区切り見る内容繰り返す範囲の考え方
帳票名や説明対象一覧の名前と補足途中の紙面にも必要かを個別に確認する
項目名の行各列に何を書くかを示す名前明細を読むための共通の見出しとして選ぶ
明細記録ごとに変わる内容見出しの範囲に含めない

繰り返す対象は、明細の意味を示す項目名の行です。個々の明細は、その下で読む内容として扱います。見出しと明細の境目を先に整理しておくと、繰り返す範囲をほかの担当者へ説明するときにも役立ちます。

引き継ぎでは、「上にある部分」とだけ伝えるより、「明細の意味を示す項目名の行」と書く方が、選ぶ対象が伝わります。帳票の名前や注意書きを含めるかどうかは、途中の紙面を読む相手に必要かという観点で決めるとよいです。

4．設定を選べないときは、編集状態と選択範囲を見ます

コマンドが淡色になっている

［タイトルの印刷］が淡色になる条件は、セル編集中、同じシートのグラフを選択中、またはプリンターがインストールされていない場合です。行の指定をやり直す前に、現在の状態に当てはまるものがないかを見ます。

行や列の指定欄を使えない

複数のワークシートを選択している間は、繰り返す行と列の指定欄を使えません。選択していないシートをクリックすると複数選択を解除でき、表示中のシートをすべて選んでいる場合は、シート見出しを右クリックして［作業グループ解除］を選びます。

行番号や列記号が印刷された

［シート オプション］の［見出し］で［印刷］をオンにする操作は、シートの行見出し・列見出しを印刷する設定です。この行見出し・列見出しは、シートの境界にある「1、2、3」や「A、B、C」などを指します。配付する相手が読みたい項目名が出ているか、結果で見分けます。

5．後続の紙面でも、項目名と明細を照合します

［ファイル］から［印刷］を選ぶと、プレビューと印刷オプションを表示できます。後続のページは、プレビュー下部の［次のページ］［前のページ］の矢印、またはページ番号の入力で表示します。

見比べる中心は、項目名の並びと、その下の明細の対応です。最初の紙面だけで確認を終えず、途中や最後の紙面でも、欄の意味を読めるかに目を向けます。見出しの一部が欠けていないか、明細を見出しに含めていないかも点検するとよいです。

内容と設定が整ったら、［印刷］ボタンを選んで印刷します。紙を渡す前にも、途中の紙面だけで内容を読めるかを確かめると、設定した範囲と読み手の必要が合っているかを判断できます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□配付する一覧の項目名がどこにあるかを確かめたか
□繰り返す範囲に、不要な明細を含めていないかを確認したか
□操作対象のシートだけを選んでいるかを確認したか
□後続の紙面にも必要な項目名が載っているかを確認したか
□行番号や列記号だけを見出しと思い違いしていないかを確認したか
□途中と最後の紙面で、項目名と明細の対応を確かめたか

出典（確認日：2026年11月6日）

  • ワークシートやブックを印刷する：対象の版と印刷を実行する操作
  • 全ページの先頭の列見出しとともに行を印刷する：各ページへの見出しの繰り返し、Web 版の制約、Mac 向け説明、コマンドが淡色になる条件

  • 印刷前にワークシート ページをプレビューする：印刷プレビューの表示と後続ページの確認
