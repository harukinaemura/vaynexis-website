Excelのブックから提出する一枚だけを別ファイルにするには

要点

提出するシートのタブから［移動またはコピー］を開き、移動先を新しいブックにして［コピーを作成する］を選ぶと、元シートを残して別ファイルにできます。保存後は、参照先と提出不要の情報を確かめ、送付対象を決めます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Excelのブックから提出する1枚のシートだけを別のファイルにして渡したい小さな会社の担当者が、元のシートを残すコピーの手順と、リンク・非表示の情報を提出前に確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 元シートを残して新しいブックへコピーする
  2. ブラウザーで開いている場合は手順を分ける
  3. 表が開けても参照先の点検は残る
  4. 不要情報はコピー側で検査する
  5. 提出用と社内用を分けて受け渡す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．元シートを残して新しいブックへコピーする

確認日：2026年11月11日。

以下はデスクトップ版の手順です。Microsoft の「ワークシートを保存する」の適用先は Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 で、Mac 版は一覧にありません。作業前に、提出する表の見出しと対象のシート名を照らし合わせます。似た名前の下書きや社内用の集計表があるときは、送付対象を先に決めておくと取り違えを見つけやすくなります。

対象のシート名のタブを右クリックし、［移動またはコピー］を選びます。［移動先ブック名］のドロップダウン メニューで、「(新しいブック)」を選びます。移動先は、表をどこへ渡すかを決める欄です。元のファイルと提出用ファイルを分ける目的に合っているかを、確定前に見直します。

元シートを残す場合は、［OK］を押す前に［コピーを作成する］にチェックを入れます。コピーを選ばない元の手順では、シートは元のブックから移動します。この選択を、操作途中の確認点にします。

［OK］を押すと、対象のシートが新しいブックで開きます。新しいブックで［ファイル］から［保存］を選びます。保存先とファイル名には、送付対象を見分けられる言葉を使います。元のブックにも対象の表が残っていることを確認し、提出用として保存したファイルを開き直して中身を見ます。

2．ブラウザーで開いている場合は手順を分ける

Excel for the web では、デスクトップ版のようにタブの右クリックから別ブックへシートを移動またはコピーするオプションは使えません。Web 版では、シート内のすべてのデータをコピーし、別ブックの空白のシートに貼り付ける方法が案内されています。手順は、ワークシート内のすべてのデータを選択して Ctrl + C キーでコピーし、貼り付け先のブックでステータス バーの［+］から新しい空白のワークシートを追加して、その最初のセルを選択して Ctrl + V キーを押す流れです。

この方法で他のブックに貼り付けると、セルの条件付き書式が失われます。画面上の色分けを提出内容の判断に使っているときは、貼り付け後にその意味が伝わるかも確認します。元の画面と見比べ、内容だけでなく見え方も点検します。

3．表が開けても参照先の点検は残る

Microsoft の「ブックのリンクを管理する」は、ブック内のすべてのブックのリンクを自動的に検索する方法はなく、数式、定義された名前、オブジェクト（テキスト ボックスや図形など）、グラフ タイトル、グラフ データ系列を個別に確認する必要があるとしています。提出用の表に計算結果やグラフがある場合は、目に見える結果と、その結果のもとになっている情報を分けて確認します。

定義された名前の参照先は、［数式］タブの［名前の管理］を開き、［参照先］列で確認できます。提出先でも更新して使う表なのか、提出時の内容を確認する表なのかは、受け取る側と合わせておきます。判断がつかない参照先は、表を管理している担当者に確認します。

［リンクの解除］では、リンク元の値を使う数式が現在の値へ変わります。リンク解除は元に戻せないため、必要に応じて変更前のファイルを保存します。リンクを見つけた後は、提出目的に照らして残すかどうかを判断します。警告が出ることだけを理由に、内容を確認せず解除する進め方は避けます。

4．不要情報はコピー側で検査する

Excel のドキュメント検査は、ブック内の非表示データや個人情報の確認と削除に役立ちます。同じページは、ドキュメント検査で削除されたデータは復元できるとは限らないため、元のブックのコピーで使うことを強く勧めています。操作は、元ブックのコピーで［ファイル］タブの［情報］を開き、［問題のチェック］から［ドキュメントの検査］へ進みます。送付用に保存したファイルを対象にし、必要な情報まで除いてしまわないよう、検査結果の内容を見てから削除を判断します。

ドキュメント検査で非表示の行・列・シートを削除すると、計算や数式の結果が変わることがあり、中身が分からない場合は再表示して内容を確認します。また、ドキュメント検査は、他のオブジェクトに覆われているオブジェクトを検出しません。検査後も、相手へ渡す内容として過不足がないかを目で確かめる工程を残します。

5．提出用と社内用を分けて受け渡す

ここからは当社の整理です。

元ブックの内容提出先へ渡すか作業後の確認
提出用の明細表渡す保存した提出用ファイルで内容を照合
社内用の検討表渡さない元ブックに残して業務で使う
下書きのメモ渡さない提出用ファイルへ含めない

この例では、提出する表を選ぶ段階と、送るファイルを選ぶ段階を別に点検します。作成した表が正しくても、最後に元ブックを添付すると、渡す範囲が変わってしまいます。添付を決めたファイルを開き、表題と内容を照合します。

引き継ぎでは、元のファイルの場所、提出用の保存先、確認した人、参照先について残した判断を共有します。次回の担当者が提出用を原本として編集し続けないよう、どちらを日常の作業に使うかも明らかにしておきます。差し替えが必要になったときは、確認済みの提出用ファイルを基準にして、送る対象を選び直します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□提出対象の表題とシート名を照合したか
□元ブックに対象の表が残っていることを確認したか
□提出用のファイルを保存し、開き直して内容を確認したか
□計算結果と参照先を確認し、残す情報を判断したか
□不要な情報を除いた後も、内容と見え方を照合したか
□添付するファイルが確認済みの提出用であるかを確かめたか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月11日）

  • ワークシートを保存する：対象の版、提出用シートの別ブック化、元シートを残す設定、保存
  • ワークシートまたはワークシートのデータを移動またはコピーする：Web 版の別ブックへのコピーの方法と手順、条件付き書式の制約
