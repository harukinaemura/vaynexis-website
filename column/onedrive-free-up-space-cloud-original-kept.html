OneDriveの「空き領域を増やす」を選ぶと、クラウドの原本も消える？

要点

消えません。ヘルプのよくある質問には、ファイルをオンラインのみに変更しても OneDrive からは削除されない、と書かれています。 ［空き領域を増やす］を選んだファイルはパソコンの容量を使わなくなり、OneDrive のモバイル アプリや Web サイトでは引き続き表示できます。 気をつけたいのは、よく似た場面で「削除」を選んでしまうことです。オンラインのみのファイルをパソコンから削除すると、すべてのデバイスの OneDrive からも消えます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

容量不足の表示が出て［空き領域を増やす］を押したいのに、会社の資料まで消えないか心配で手が止まる。パソコンの写しとクラウドの本体の関係、削除や移動との違い、操作の後に気をつけることを確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

総務のノートパソコンの場面は架空のもので、クラウドの容量が変わらないという点には当社の読みを含みます。

1．パソコンから外れるのは「写し」だけ

確認日：2026年11月17日。

対象は、Windows のパソコンで使う OneDrive 同期アプリのファイル オンデマンドです。

「容量が不足しています」という表示が出て、OneDrive フォルダーの大きな資料を何とかしたい。けれど、［空き領域を増やす］を押したら会社の大事な資料まで消えてしまうのでは、と手が止まる。こうした迷いには、ファイル オンデマンドの仕組みを知っておくと答えが出ます。

OneDrive のファイルには、クラウドにある本体と、パソコンにダウンロードされた写しがあります。一度開いたファイルはデバイスにダウンロードされ、インターネットにつながっていなくても開けるローカルのファイルになります。 ［空き領域を増やす］は、このパソコン側の写しを外して、ファイルをオンラインのみの状態に戻す操作です。 オンライン専用のファイルはパソコンの容量を使いません。

2．取り違えやすい3つの操作

パソコンの容量を空けたいときに選びがちな操作を並べると、残る場所がまったく違います。

操作パソコンクラウドの OneDriveほかのパソコン
［空き領域を増やす］写しが外れ、容量を使わない残る残る
エクスプローラーで削除（オンラインのみのファイル）消える消える消える
OneDrive フォルダーの外へ移動移した先に残る消える消える

削除については、同期されたファイルを扱うヘルプでも、同期されたオンラインのみのファイルをデバイスから削除すると、すべてのデバイスとクラウドから削除されると説明されています。 外への移動については、OneDrive フォルダーの外にファイルを移すと、ファイルは新しいフォルダーにダウンロードされ、OneDrive から削除されます。 容量を空けたいだけなら、選ぶのは［空き領域を増やす］です。

万一、削除を選んでしまった場合でも、すぐに諦める必要はありません。ヘルプでは、削除したファイルとフォルダーは、個人用 OneDrive（Microsoft アカウントでサインインしている場合）なら 30 日以内、職場または学校の OneDrive や Microsoft 365 の SharePoint（職場または学校のアカウントでサインインしている場合）なら 93 日以内であれば復元できるとされています。

3．操作のしかた

エクスプローラーで、容量を空けたいファイルやフォルダーを右クリックし、［空き領域を増やす］を選びます。 操作の後は、ファイルの横の印が青い雲に変わります。青い雲は、ファイルがオンラインでのみ利用可能であることを示す印です。

［このデバイス上で常に保持する］にしていたフォルダーで容量を空けたい場合も、同じ右クリックのメニューから［空き領域を増やす］を選びます。同期の停止のヘルプでは、誤って常に保持にした場合、OneDrive をいったん閉じて起動し直し、［空き領域を増やす］にする手順が案内されています。

4．空き領域を増やした後に気をつけること

オンラインのみに戻したファイルは、パソコンがインターネットにつながっていないと開けません。 出張や現場で使う予定の資料は、容量を空ける対象から外しておきます。

パソコンの中で資料を探すときにも違いが出ます。デスクトップ サーチでは、オンラインのみのファイルを名前で探せますが、ファイルの中の内容では探せません。 「本文に取引先名が入った資料」を検索で見つけていた人は、空けた後にその探し方が使えなくなります。

5．自分で選ばなくても雲のマークになる場合

［空き領域を増やす］を押した覚えがないのに、ファイルが青い雲になっていることがあります。ヘルプには、ストレージ センサーが有効な場合、開いたことのあるファイルは、ユーザーが指定した期間が過ぎるとオンラインのみのファイルになる、と書かれています。 また、クラウドからの新しいファイルは、既定ではオンライン専用で、ディスク領域を占有しないと説明されています。 どちらも、手で［空き領域を増やす］を選んだときと同じく、パソコンの写しが無いだけで、OneDrive の本体はそのまま残っている状態です。雲のマークを見ても、資料が消えたと慌てる必要はありません。

6．クラウドの容量は別に考える

［空き領域を増やす］で空くのは、パソコンの容量です。ファイルは OneDrive に残るので、クラウドの OneDrive の容量の使い方は変わらないと考えられます。クラウドの容量を空けたいなら、要らないファイルを OneDrive から削除し、さらに OneDrive のごみ箱からも削除する別の作業になります。ヘルプにも、OneDrive と OneDrive のごみ箱からファイルを削除すると、OneDrive アカウントのストレージの利用状況に反映されるまでに少し時間がかかる場合がある、と書かれています。

7．架空の例：容量不足の表示が出たノートパソコン

総務の担当者のノートパソコンで、容量不足の表示が出た場面です（架空の例）。

確かめたこと架空の記入例
容量を使っていたものOneDrive の「社内行事の写真」フォルダー（緑の印で、パソコンに写しがあった）
選んだ操作フォルダーを右クリックして［空き領域を増やす］
選ばなかった操作エクスプローラーでの削除、デスクトップへの移動
操作の後の確認印が青い雲になったこと、Web の OneDrive で写真が残っていること

パソコンごとにどれだけ容量があり、どの資料を手元に置いているかが分かっていれば、容量不足の表示が出ても慌てずに済みます。パソコンと置いている資料を一覧にしておく方法は、事務の道具と作業の棚卸しでも触れています。
