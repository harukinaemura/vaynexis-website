返品された商品を在庫へ戻すとき、Shopify で補充先のロケーションをどう指定するか

要点

Shopify では、返品アイテムを受け取って確認した後に返品を処理します。 返品の処理の画面で、返品アイテムを補充するには［補充先］を選択し、補充するロケーションを選択します。 補充した返品はキャンセルできず、補充されたアイテムを返品から削除することもできないため、どこへ戻すかを決めてから選びます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

倉庫と店舗の両方で在庫を持っていると、戻ってきた商品をどちらの在庫に戻したのか分からなくなりがち。Shopify の返品の処理で補充先を選ぶ場所と、補充した後に取り消せなくなる操作を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．ロケーションごとに在庫が分かれている

確認日：2026年11月17日。

Shopify のロケーションは、商品を販売、注文をフルフィルメント、または在庫を保管する物理的な場所のことで、ロケーションを使うと各物理的なロケーションで別々に在庫を追跡できます。 倉庫と店舗の2か所を登録している会社なら、返品を倉庫に戻すか店舗に戻すかで、どちらの在庫数が増えるかが変わります。

実際の商品がどこにあるかと、画面で選ぶ補充先が食い違うと、画面の上では倉庫にあるはずの商品が店舗の棚にある、ということが起きます。補充先を選ぶ人は、商品が今どの場所にあり、どこで売ることにしたのかを、検品をした人から聞いてから操作します。

2．返品を処理する画面の手順

管理画面での手順は次のとおりです。

  1. 管理画面から［注文管理］に移動し、返品を処理する注文をクリックする。
  2. ［返品の処理中］セクションで、［返品を処理する］をクリックする。
  3. ［受け取る返品アイテム］セクションで、処理する返品アイテムを選択する。
  4. 返品アイテムを補充する場合は、［補充先］を選択し、補充するロケーションを選択する。
  5. 送料の返金や、返金の発行・決済の徴収を、注文への調整に応じて行う。

返品は、処理の準備が整った返品アイテムに応じて、部分的に処理することも、すべて同時に処理することもできます。 1つの返品に複数の商品があり、一部だけ検品が済んだ場合は、済んだ商品だけを選んで処理できます。

スマートフォンの Shopify アプリでも、［受け取る返品アイテム］で選び、［補充先］でロケーションを選ぶ同じ流れが案内されています。

3．交換を含む返品では、同じ画面で交換品も動く

交換を含む返品では、同じ処理の画面の［リリースする交換アイテム］セクションで、リリースする交換アイテムを選択します。 返品と交換の作成のページには、交換アイテムの在庫は、返品を処理するまで確保されないと書かれています。 戻ってきた商品を補充先へ戻すのも、お客様へ送る交換品の在庫が確保されるのも、この返品の処理のときです。戻ってきた商品と交換品を別の場所で扱っている会社では、補充先と、交換品を出す場所の両方を処理の前に確かめておきます。

4．処理する人の権限を決めておく

返品を作成するには、ストアオーナーであるか、「返品」の許可を持っている必要があり、返品を返金するには、返金方法に応じて「元の決済方法への返金」または「ストアクレジットへの返金」の許可が必要とされています。 補充先を選ぶ処理と返金を同じ人が行うのか、返金だけは責任者が行うのかによって、スタッフに与える許可が変わります。誰が補充先を選び、誰が返金を確定させるかを、許可の設定と合わせて決めておきます。

5．補充した後は戻せない操作がある

補充は、後から取り消しにくい操作と結び付いています。ヘルプでは、返品をキャンセルできるのは、返品が返金されていない、返品が補充されていない、などの状況のみとされています。 また、すでに返金されたり、補充されたりしたアイテムを返品から削除することはできません。

このため、お客様から「やはり返品を取り下げたい」と連絡が来そうな段階や、届いた箱の中身がまだ確かめられていない段階では、補充しないでおきます。検品が終わり、売り物に戻すと決まってから［補充先］を選ぶ、という順番を社内の決まりにしておきます。

すべてのアイテムが処理され、すべての返品アイテムが補充されると、返品は自動的に閉じられます。 補充しないアイテムがある返品は、処理の後に閉じているかを確かめ、開いたままなら未完了のタスクをすべて終えてから閉じます。

6．売り物に戻さない商品のとき

［補充先］は「オプション」とされているので、売り物に戻さない商品は補充先を選ばずに処理できます。 一方で、Shopify には、ロケーションに仕入れられていても販売できない「利用不可」という在庫状態があり、破損、品質管理、安全在庫などの理由で保留されているユニットの数を指すと説明されています。 在庫数量の調整では、在庫を破損、品質管理、安全在庫などの利用不可のステータスに移動することができます。 在庫数量の調整のページでは、在庫の更新はすべて調整履歴に記録され、完全な監査証跡が作成されると説明されています。 傷んだ商品を倉庫に置いておく場合に、補充しないで済ませるのか、利用不可として数えるのかは、在庫の担当者と先に決めておきます。

7．社内で残す受け渡しの記録（架空の例）

倉庫で検品した人と、Shopify で処理する人が別なら、補充先の決定を紙か共有の表で受け渡します。

注文番号商品検品の結果補充先（決めた人）Shopify で処理した人・日
架空 #1001シャツ M傷なし倉庫（在庫の責任者）受注の担当・10月5日
架空 #1002マグカップ欠けあり補充しない（在庫の責任者）受注の担当・10月5日

検品から画面の処理までの受け渡しが、担当者の記憶や口頭に頼っている場合は、事務の業務改善の進め方で流れを書き出してみると、抜けやすい所が見えます。
