Chromeの「音声」でサイトから勝手に音が出るのを止めるには

要点

鳴っている音をすぐ止めたいときは、Chrome の右上のメディア コントロールから一時停止できます。 同じサイトで何度も鳴るなら、ウェブアドレスの左側のサイト情報から［サイトの設定］を開き、そのサイトだけ許可の設定を変えます。 すべてのサイトの既定を変えるときは、［設定］の［プライバシーとセキュリティ］、［サイトの設定］から、［コンテンツ］の［その他のコンテンツの設定］にある［音声］を選びます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

事務所で調べものをしていたら、開いたページの動画がいきなり音を出した。そんなときに、パソコン版 Chrome で鳴っている音をその場で止める方法と、特定のサイトだけ、またはすべてのサイトの既定で［音声］を変える手順を、Google の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 止め方は3段階ある
  2. 今鳴っている音を止める
  3. 決まったサイトだけ鳴らさない
  4. すべてのサイトの既定を変える
  5. 会議の最中に鳴ったときの順番（架空の例）
  6. 小さな困りごとを、まとめて見直す
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．止め方は3段階ある

確認日：2026年11月16日。

対象は、パソコンで使う Google Chrome です。マイク（声を拾う側）の設定と、Windows 全体の音量の設定は扱いません。

静かな事務所で急に音が鳴ると、まずは止めることで頭がいっぱいになります。ただ、止め方には段階があります。今鳴っている音だけを止めるのか、そのサイトでは今後も鳴らさないのか、どのサイトでも既定では鳴らさないのか。どこまで止めるかで、触る場所が変わります。いきなり既定を変えると、あとで音が要る場面で困ることがあるので、狭い範囲から試すのが基本です。

止めたい範囲触る場所向いている場面
今鳴っている音だけメディア コントロールたまたま開いたページで一度だけ鳴った
決まったサイトだけサイト情報の［サイトの設定］毎日見るニュースのサイトで毎回鳴る
すべてのサイトの既定［設定］の［音声］共用のパソコンで、音を出す用事がほとんどない

2．今鳴っている音を止める

どのタブから鳴っているか分からないときに便利なのが、メディア コントロールです。ヘルプでは、音声を操作するには右上のメディア コントロールを選び、一時停止したり、次の曲や動画にスキップしたりできると説明されています。 選ぶと、再生しているタブに戻れます。

気を付けたいのは、別のタブに移っても、元のタブではメディアが引き続き再生されることです。 見えないタブで鳴り続けている、という状態はこれで起きます。タブをたくさん開いているときほど、メディア コントロールから探すほうが早く済みます。

いくつものタブをまとめて黙らせたいときは、タブを複数選んでから右クリックする一括操作もあります。ヘルプでは、Ctrl キーを押しながらタブを選び、ハイライトされたタブのどれかを右クリックして操作を選ぶ流れで、その操作の一つにミュートまたはミュートを解除が挙がっています。

3．決まったサイトだけ鳴らさない

毎日見るサイトで毎回鳴るなら、そのサイトの設定を変えます。ヘルプの「サイトの権限設定を変更する」には、権限の一つとして［音声］があり、音楽や動画などのメディアの音声を再生するサイトもあると説明されています。

  1. 鳴るサイトを開きます。
  2. ウェブアドレスの左側で、サイト情報を表示するアイコンを選びます。
  3. ［サイトの設定］を選びます。
  4. ［音声］の許可の設定を変更します。

このやり方で決めた設定は、デフォルトの設定の代わりに、そのサイトにだけ使われます。 研修の動画のように音が要るサイトには影響しないので、まずはこちらから試すのが無難です。変更は自動的に保存されます。

あとでそのサイトの音が必要になったら、同じ画面で設定を戻します。［権限をリセット］ボタンを使える場合は、そのボタンを選んで、変更した設定をリセットすることもできます。 誰がいつ変えたかが分からないと、しばらくして「このサイトだけ動画の音が出ない」と別の人が困ることになります。共用のパソコンで変えたときは、変えた人と日付を一言残しておくと、戻すときに迷いません。

4．すべてのサイトの既定を変える

共用のパソコンで、音を出す用事がほとんどない場合は、既定そのものを変える手もあります。

  1. パソコンで Chrome を開きます。
  2. 右上のその他アイコンから［設定］を選びます。
  3. ［プライバシーとセキュリティ］、［サイトの設定］の順に選びます。
  4. ［コンテンツ］で、［その他のコンテンツの設定］、［音声］の順に選びます。
  5. デフォルト設定として使うオプションを選びます。

既定で鳴らさない形にすると、Web 会議の録画や研修の動画など、音が要るサイトまで静かになるおそれがあります。その場合は、上の「決まったサイトだけ」の手順で、音が要るサイトだけを鳴らす形に戻します。どのサイトを例外にしたかは、あとで誰かが見ても分かるように控えておきます。

5．会議の最中に鳴ったときの順番（架空の例）

Web 会議の最中に別のタブの動画が鳴ると、相手にも音が届いてしまうことがあります。慌てて会議の画面を閉じないよう、手順を決めておくと落ち着いて対応できます。

順番架空の場面での動き
1右上のメディア コントロールから、鳴っている動画を一時停止する
2会議が終わってから、鳴ったサイトを開き直す
3サイト情報の［サイトの設定］で、そのサイトの［音声］を変える
4例外にしたサイトの名前を、共用のパソコンのメモに書く

6．小さな困りごとを、まとめて見直す

「急に音が出る」「通知がうるさい」といったパソコンの小さな困りごとは、一つひとつは数分でも、何人もが毎日出会うと時間になります。社内の作業と一緒に書き出してみると、どこから手を付けるかを決めやすくなります。書き出すときの型として、業務棚卸しチェックシート（エクセル・CSV）を用意しています。
