Wordで新しい文書の行間をそろえる｜標準テンプレートの設定

要点

Windows版Wordの［ホーム］の［行間隔と段落間隔］から［行間オプション］を開き、［行間］で間隔を選びます。今後、標準テンプレートから作る文書にも適用する場合は［既定に設定］を選び、標準テンプレートに基づいて［すべてのドキュメント］を選びます。標準テンプレート（Normal.dotm）への変更は、今後作成される文書に適用されます。新規文書を作って確認します。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、Wordで新しく作る文書の行間をそろえたい小さな会社の担当者が、既定に設定する手順と標準テンプレート・Web版の違いを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 本文の行間と段落の余白を見分ける
  2. 行間を決め、既定に設定する
  3. 同じ作り方で新しい文書を開く
  4. Web版や既存の書類と違う場合を切り分ける
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．本文の行間と段落の余白を見分ける

確認日：2026年11月10日。

Microsoftの案内では、Wordの既定の行間は1.15で、既定では段落の後ろに空白行があり、見出しの上部には余白があります。行間は［間隔］の［行間］ボックスで選び、段落と段落の間隔は［前］と［後］の設定で調整します。この案内の適用先は、Word for Microsoft 365、Word 2024、Word 2021と、それぞれのMac版で、手順はWindows・Mac・Webの欄に分かれています。

ここからは当社の整理です。

同じ段落で折り返した行の間隔を変えたいのか、段落の境目にある空きを変えたいのかを決めます。社内文書に体裁の指定があれば、その資料と開いた設定を照らします。

2．行間を決め、既定に設定する

MicrosoftのWindows向け案内では、［ホーム］の［行間隔と段落間隔］から［行間オプション］を選び、［間隔］の［行間］ボックスでオプションを選びます。段落間の間隔を変えるときは［前］と［後］を調整し、［既定に設定］を選んで、標準テンプレートに基づいて［すべてのドキュメント］を選び、［OK］を選びます。Mac版の欄では、入口の名前が［行と段落間隔］と書かれています。

標準テンプレートの案内では、Wordを起動するたびに標準テンプレート（Normal.dotm）が開き、文書の基本的な外観を決める既定のスタイルとカスタマイズが含まれます。Normal.dotm に対する変更はすべて、今後作成される文書に適用されます。

現在作業している一つの資料の体裁だけを変えたい場合は、以後の文書全体に適用する操作と混ぜないよう、変更する範囲を確認します。すでにある文書の行間は、それぞれの文書を開いて確かめます。

インデントと行間隔の案内（Windowsの欄）では、選んだ段落だけを変えるときは、調整する1つ以上の段落を選び、［ホーム］タブの［段落］グループから開く画面で［インデントと間隔］タブを選び、設定を選んで［OK］を選びます。

3．同じ作り方で新しい文書を開く

新規文書を開き、本文の段落で行間と段落前後を確認します。社内のひな形を選んで作る文書では、標準テンプレートの設定だけで判断せず、そのひな形から開いたときの表示を見ます。

Microsoftの案内では、Normal.dotm の名前が変わったり、壊れたり、移動したりした場合は、次にWordを起動したときに元の既定の設定を使った新しい Normal.dotm が自動で作られ、それまでのカスタマイズは含まれません。Normal.dotm は C:\Users\（ユーザー名）\AppData\Roaming\Microsoft\Templates にあり、［ファイル］タブの［開く］から開いて、フォント、余白、間隔などを変えて保存することもできます。この案内の適用先は、Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016です。

既定にした行間が新しい文書で元に戻っているときは、Normal.dotm を移したり名前を変えたりしていないかを確かめます。

4．Web版や既存の書類と違う場合を切り分ける

Microsoftの案内では、Web版のWordでも行間は変更できますが、次に新しい文書を作るときは1.15の行間に戻ります。Web版で段落の前後の空きを変えるときは、［レイアウト］タブの［段落］グループで［前］または［後］のボックスに数値を入れます。

使うアプリ、文書の作り方、段落に適用されているスタイルを控えます。既存文書の体裁も直したい場合は、対象の版を分けて変更します。
