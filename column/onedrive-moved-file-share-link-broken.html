OneDriveで移動後の共有リンクが開けない｜所有者と新しいリンクを確認

要点

OneDriveでファイルやフォルダーを移動して共有リンクが開けなくなった場合は、所有者に移動先と共有の状態を確認します。移したファイルの共有が必要なら、移動先で相手と権限を確かめて新しいリンクを作り、受け取った人が開けるか確認します。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、OneDriveで資料を移した後に共有リンクが開けなくなった小さな会社の担当者が、開けない理由の切り分け、移動先での共有のやり直し、新しいリンクの種類と権限を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 開けないリンクが指す資料を特定する
  2. 新しい場所で同じ版のファイルを開く
  3. 共有する人と権限を決めてリンクを作る
  4. 案内を更新して受け取る側で確認する
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．開けないリンクが指す資料を特定する

確認日：2026年11月10日。

Microsoftは、OneDrive内でファイルやフォルダーを移動すると共有リンクが機能しなくなると説明しています。共有の停止も、受け取ったリンクが開かなくなる理由として案内されています。

同じページでは、リンクに有効期限を設定した場合も、設定した日付を過ぎるとリンクは機能しなくなり、アクセスが必要な人のために新しいリンクを作る必要があるとされています。有効期限の設定は Microsoft 365 サブスクライバーのみが使えると注記されています。

ここからは当社の整理です。

開けないリンクを使った連絡と、資料の名称、移動を行った担当を確かめます。ファイルを移したのか、共有を止めたのか、リンクの期限が切れたのかが不明なときは、画面に出た内容とリンクを受け取った日を所有者へ伝えます。

2．新しい場所で同じ版のファイルを開く

所有者は新しい保存先を開き、ファイル名、更新日、内容を照合します。同じ名前の作業用の版があれば、相手に渡す方を確認します。フォルダーの中の一部だけを共有する場合は、対象外の資料が同じリンクで見えないかも見ます。

Microsoftの案内では、受信者が自分の OneDrive に追加できるのは共有フォルダーだけで、個々のファイルは追加できません。特定のファイルだけを見せたい場合は、ファイルを別のフォルダーに置いてから、そのフォルダーを共有するよう書かれています。また、自分または共有しているユーザーがファイルを共有フォルダーに移した場合は、新しいファイルが含まれるように、もう一度共有する必要があるとされています。

3．共有する人と権限を決めてリンクを作る

Microsoftの案内は、移動後に共有リンクが機能しなくなった場合に新しいリンクを作るよう説明しています。手順は、対象のファイルかフォルダーを選んでページ上部の［共有］を選び、設定の歯車アイコンでリンクの設定を開く流れです。職場または学校の OneDrive では、ここでリンクのアクセス許可を変えられ、アクセスできる人を［すべてのユーザー］、組織内のユーザー、［既存のアクセス権を持つユーザー］、［特定のユーザー］から選びます。設定を終えたら［適用］を選びます。

選択肢のうち［既存のアクセス権を持つユーザー］は、既にアクセス権を持っている人が使うリンクで、アクセス許可は変わりません。［特定のユーザー］は指定した人にだけアクセス権を与え、招待が転送されても、アクセス権を既に持つ人しかリンクを使えません。［その他の設定］の［編集を許可する］は既定でオンで、フォルダーを編集できる人は、フォルダー内のすべてのものをコピー、移動、編集、名前変更、削除できると説明されています。

以前の共有先をそのまま使う前に、いま閲覧や編集が必要な人を確認します。移動先のフォルダーで相手がまだアクセス権を持っていない場合、［既存のアクセス権を持つユーザー］のリンクはアクセス許可を変えないため、それだけでは相手が開けません。相手を指定して共有するかを所有者が決めます。閲覧だけでよい相手には、［編集を許可する］をオフにしてから送ります。新しいリンクが開かないときは、相手が開いたアカウントと、共有した相手の指定を照らします。

4．案内を更新して受け取る側で確認する

送る前に新しいリンクと資料の版を組にして控えます。旧リンクが手順書や連絡に残っている場合は、更新する場所と担当を決めます。受け取った人が開けたかを確認し、閲覧だけで足りる資料に編集できる権限が付いていないかも点検します。

Microsoftの案内では、ファイルの所有者は共有のアクセス許可を停止または変更できます。対象を1つだけ選んで右上の［情報］から［詳細］ウィンドウを開き、［アクセス権あり］の下の［アクセスの管理］を選びます。共有リンクを削除するときは、リンクの横の［X］を選びます。共有オプションが灰色表示の場合は、組織の管理者がオプションを制限している可能性があり、職場または学校のアカウントの技術的な問い合わせは、組織の IT ヘルプデスク、サービス デスク、または管理者にするよう書かれています。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□開けないリンクが指す資料を確認したか
□所有者に移動先と共有の状態を聞いたか（移動・共有の停止・リンクの有効期限）
□移動先の資料の版を確認したか
□新しい共有先と権限を確認したか（リンクの種類と［編集を許可する］）
□共有フォルダーへ移したファイルは、もう一度共有したか
□［アクセスの管理］で、不要になったリンクや相手が残っていないか
□旧リンクの差し替えと受信側の確認を行ったか
