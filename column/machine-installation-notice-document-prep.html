機械の設置届を出す前に仕様書・配置図と工事予定をそろえる順番

要点

対象と届出要否の確認を終えたら、必要書類と担当者を一覧にし、仕様書の機種・寸法、配置図の設置位置、工事予定の開始時点を突き合わせます。書類が届いたかに加え、同じ計画の資料がそろったかを見ることが準備の中心です。技術面の確認と事務の回収作業を分け、食い違いは作成者に戻してから提出用の一式をまとめます。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、機械の設置届を準備したい小さな会社の担当者が、確認済みの必要書類と仕様書・図面・工事予定の対応を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. チェックリストの表題より先に対象範囲を見る
  2. 期限は納品予定からではなく工事開始から考える
  3. 書面の項目と図面の役割を分けて依頼する
  4. 回収する人・確かめる人・そろえる時点を決める

  7. 自社の事務の手順まで形にしたいとき

1．チェックリストの表題より先に対象範囲を見る

確認日：2026年11月13日。

青森労働局が公開する「機械等設置届チェックリスト」は、足場・架設通路・型わく支保工の設置届を対象に作られたものです。

機械全般に使える一覧として広げず、該当する設備の資料かを見て使い分けます。この記事は、安全担当等による対象・届出要否の確認を終えた後の書類準備を扱います。事務担当がカタログの名称だけで適用を決めたり、構造の安全性を判断したりする手順にはしません。

労働安全衛生規則第86条では、別表第七に掲げる機械等の設置・移転・主要構造部分の変更について、様式第二十号の届書に、機械等の種類に応じた同表中欄の事項を記載した書面と下欄の図面等を添え、所轄労働基準監督署長に提出しなければなりません。

準備の起点は、手元にある仕様書の束ではなく、確認を受けた必要書類の一覧です。資料名が似ていても、必要な情報が別のページに分散していることがあります。ファイル名だけで提出用と判断せず、どの記載に対応する資料かを担当者と結び付けておくとよいです。

厚生労働省の機械の設置等に関する案内では、届出を提出する窓口への問い合わせを求め、機械の種類によって問い合わせ先が異なるとしています。

2．期限は納品予定からではなく工事開始から考える

労働安全衛生法第88条第1項の対象となる機械等を設置・移転し、又は主要構造部分を変更しようとする事業者は、その計画を当該工事の開始の日の30日前までに労働基準監督署長に届け出なければなりません。

同項には、法定の措置を講じているものとして所定の手続で労働基準監督署長が認定した事業者については、この限りでないという例外があります。

工程の連絡を受けるときは、納品、搬入、据付、試運転などの日付に、それぞれ何の予定かを添えます。社内の一覧に「開始」とだけ書くと、依頼する相手によって違う日を返すおそれがあるためです。どの作業を起点として扱うかは、責任者が窓口・専門家に確認し、事務側は確認された予定と提出期限を記録します。

提出の締切と、仕様書・図面の回収予定は分けて管理します。図面を受け取った直後に送付する段取りでは、寸法や位置の不一致を作成者へ戻す時間を予定に入れられません。回収、照合、修正、承認、提出の順を工程に載せ、日程が変わったときにどの担当へ連絡するかまで決めておきます。

3．書面の項目と図面の役割を分けて依頼する

添付資料は、労働安全衛生規則別表第七の中欄に掲げる事項を記載した書面と、下欄に掲げる図面等に分かれ、機械等の種類に応じて準備します。配置図を機械全般に共通する添付書類として固定せず、該当する行の図面等と必要書類の一覧を対応させます。

依頼するときは「設置届の資料一式」とだけ伝えず、必要な記載を誰が持っているかに分けます。メーカーから受け取る機器の仕様と、施工側が作る現場の図面では、更新する担当も確定する時期も異なります。必要書類の一覧に、資料の提供者と内容を確認する人を併記すると、単に添付を待つ状態から抜け出しやすくなります。

仕様書では、選んだ機種、型式、寸法、能力などが今回の計画と対応しているかを担当者に確認してもらいます。複数機種を掲載するカタログを受け取った場合は、採用する部分を明らかにしてもらうとよいです。図面側も、機器の呼び方が仕様書と違うままでは照合しにくいため、対応する名称を作成者に示してもらいます。

配置図の照合では、設置位置と機器の向き、周囲の設備との関係、寸法の記載に目を向けます。ただし、これらの確認作業を終えたことと、技術上の適合が確認されたことは分けて記録します。事務担当が図面を描き直して帳尻を合わせるのではなく、相違点を作成者へ返し、修正版を受け取る流れにします。

4．回収する人・確かめる人・そろえる時点を決める

ここからは当社の整理です。

以下は説明のための架空の準備例で、実在の会社の話ではありません。担当の呼び方や役割分担は、自社の体制に合わせて置き換えます。

資料の一覧には、到着済みかどうかと、内容確認を終えたかどうかを分けて記録します。届いた資料に不足がある状態を、完了として扱わないためです。「確認中」のまま止まった資料には、誰から何の回答を待っているかを残します。

仕様書と配置図で寸法が違う場合は、どちらを正しいと事務側で選ばず、相違箇所をそのまま担当へ伝えます。連絡には対象の資料名とページ、図面上の位置、比較した記載を添えると、作成者が回答しやすくなります。返答を受けたら、回答の内容と修正版が一致しているかも見ます。

差し替えは、変更されたファイルだけを保存して終えず、関連資料への影響を確認する機会にします。設置位置の変更なら図面の対応、機種の変更なら仕様との対応、工事予定の変更なら社内の提出予定との対応を担当者へ戻します。提出用として確定した資料は、作業中の資料と保存場所を分けておくとよいです。

5．迷う内容を分けてから窓口へ引き継ぐ

技術的な安全性、適用の可否、例外の扱いは、安全担当等を通じて窓口・専門家に確認します。社内で問い合わせをまとめる際は、対象設備、決まっている仕様、設置場所、工程、質問事項をそろえます。「この資料でよいか」だけでなく、何の記載が不足していると考えているかを示すとよいです。

窓口への確認と社内の資料回収は、待ち先を分けて管理します。回答待ちの質問が残っている資料と、記載の照合まで終わった資料を区別すると、提出用にまとめる範囲が見えます。送付後に問い合わせを受けた場合に備え、送った資料の組合せと、内容を確認した人も残しておきます。

事務の手間を洗い出すなら、事務作業の棚卸しとして、資料依頼・照合・差し替えのうち、どこで待ちや転記が生じているかを整理します。内容を判断する仕事と、決まった内容を集める仕事を分けるところから始めるとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること

□仕様書の機種・名称・寸法と図面の記載を突き合わせたか

□提出期限と社内の回収・照合・承認の予定を分けたか
□変更箇所と未回答の質問を整理し、提出用の資料を確定したか
□送付した資料の組合せと確認・送付の記録を残したか
