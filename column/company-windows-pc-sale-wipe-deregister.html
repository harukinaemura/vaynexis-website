社用Windowsパソコンを売却する前に｜業務データの退避・消去・端末登録を確認する

要点

社用のWindowsパソコンを社外に渡す前に、資産番号と管理方式を確認し、必要なデータを移して別の端末で開けることを確かめます。消去は自社の基準に沿って行い、端末のアカウントや管理サービスの登録解除を確認します。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、社用のWindowsパソコンを売却・譲渡したい小さな会社の担当者が、業務データの退避、リセットの消去の選び方、Microsoft アカウントと端末管理の登録解除を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 資産番号から対象の端末と管理方式を確認する
  2. 残す業務データを退避して開けることを確認する
  3. 消去方法を社内の基準に合わせて決める
  4. 端末の登録とアカウントの関連を確認する
  5. 引渡し前の作業と確認者を記録する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．資産番号から対象の端末と管理方式を確認する

確認日：2026年11月10日。

MicrosoftはWindows PCの譲渡等に先立ち、バックアップ、リセット、Microsoftアカウントからのデバイス削除を案内しています。組織でWindows Autopilotに登録している場合は、端末が組織を離れる際の管理者向け手順があります。

ここからは当社の整理です。

対象の資産番号、端末の製造番号、現在の利用者を台帳で確認します。複数台を同時に扱う場合は、消去する機器を取り違えないよう現物のラベルも照らします。自社所有か借りている機器か、組織の端末管理があるかも先に確かめます。

2．残す業務データを退避して開けることを確認する

Microsoftの譲渡前の案内（適用先 Microsoft account・Windows 11・Windows 10）では、リサイクル、売却、譲渡の予定がある場合に、デバイスからすべての個人情報を削除していることを確認するよう書かれています。手順は、Windows バックアップで保存する情報をバックアップしてから、設定アプリの［システム > 回復］で［回復の設定］を開く順です（Windows 10 はページの表記で［Update & Security］>［Recovery］）。

Microsoftの「PC を初期状態に戻す」の案内では、リセットすると Windows が再インストールされ、選んだオプションによってはアプリ、設定、個人用ファイルが削除される場合があります。リセットに先立ち、重要なファイルをバックアップするよう案内しています。暗号化されている機器ではBitLockerの回復キーが必要になる場合も案内しています。

引き続き使う資料は、会社の保管先に移して、引き継ぐ担当が別の機器で開けることを確かめます。端末内のフォルダだけでなく、個人用の作業場所に保管していた業務ファイルや、別の保存先に同期されているものがないかを調べます。引継ぎが未確認なら、消去を進める前に確認を終えます。

3．消去方法を社内の基準に合わせて決める

Microsoftの「PC を初期状態に戻す」の案内（適用先 Windows 11・Windows 10）では、［ファイルを保持する］は個人用ファイルを残したまま Windows を再インストールし、［すべて削除する］（［リセット］とも呼ばれる）は Windows を再インストールして、すべての個人用ファイル、アプリ、設定を削除します。［すべて削除する］は、PC を譲渡または売却する場合に最適とされています。

さらに［データの消去］を有効にすると、ファイルが削除され、ドライブが消去されます。案内では、PC の寄付、リサイクル、販売を予定している場合にこのオプションを使うよう書かれ、時間がかかる可能性がある一方で、削除したファイルを他のユーザーが回復しにくくなると説明されています。ただし注記では、このデータ消去機能はコンシューマーを対象としており、政府や業界のデータ消去基準を満たしていないとされています。

リセットの途中では、画面が長時間（場合によっては15分以上）黒くなり、デバイスが自動的に再起動しようとする場合があります。その間に手動で再起動するとリセットが失敗する可能性があると案内されています。

端末に保存していた情報の種類と自社の規程から、使う消去方法を情報管理の担当に確認します。証明が必要な場合は、作業の方法と確認する記録を先に決めます。リセットが終わった画面だけで、必要な基準を満たしたと判断しないようにします。

4．端末の登録とアカウントの関連を確認する

Microsoftの譲渡前の案内では、デバイスのバックアップとリセットの後に、そのデバイスを Microsoft アカウントから削除します。Microsoft アカウントのデバイスのページにサインインして対象のデバイスを見つけ、［詳細を表示する］で情報を確かめてから［その他のアクション］の［削除］を選び、［このデバイスを削除する準備ができました］チェック ボックスをオンにして［削除］を選びます。続けて、Microsoft Store のデバイス制限に影響しないよう、［リンク解除］も行うよう書かれています。

Microsoft Learn の「Windows Autopilot 登録の概要」（適用対象 Windows 11・Windows 10・Windows Holographic）では、デバイスが修理やライフサイクルの終了などで組織を完全に離れるたびに、Windows Autopilot から登録解除する必要があるとされています。管理者の手順は、Microsoft Intune 管理センターでデバイスのシリアル番号を控えてから Intune から削除し、その後、同じシリアル番号で Windows Autopilot のデバイスの一覧から削除する順です。登録解除には時間がかかる場合があり、デバイスが一覧に無くなるまで数分ごとに［更新］を選びます。Intune ではなく Microsoft 365 管理センターを使っている場合は、［Devices>Autopilot］でデバイスを選び［デバイスの削除］を選ぶ方法も示されています。

同じページでは、手順をスキップしたりレコードを順不同で削除したりすると、孤立したレコードが残ったり、デバイスが回復不能になったりする可能性があると注意されています。Microsoft Entra に参加しているデバイスでは、Intune で登録解除した後の追加の手順は不要で、Microsoft Entra ID から手動で削除すると予期しない問題が起こる可能性があるため避けるよう書かれています。

端末を初期化する担当と、管理サービス側の登録を確認する担当を分けます。組織の管理対象なら、該当する管理サービスと対象機器を管理者に伝え、登録解除の完了を確認してから引き渡します。管理者に伝えるときは、資産番号に加えて端末のシリアル番号を添えると、管理画面の一覧と照らし合わせられます。

5．引渡し前の作業と確認者を記録する

引渡しの記録には、資産番号、必要なデータを確認した担当、消去の方法と日付、登録を確認した担当を残します。付属品や記憶媒体が別にある場合は、端末と一緒に渡すものと回収するものを確かめます。

複数台の作業を終えたときは、完了した資産番号を台帳と照合します。消去、登録解除、引渡しのそれぞれの完了を記録し、どこで確認が止まっているか分かるようにします。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□台帳の資産番号と端末の現物を照合したか
□引き継ぐ担当が保存した業務ファイルを開けるか
□自社の基準に合う消去方法を確認したか（［すべて削除する］と［データの消去］の設定を含む）
□リセットの途中で手動で再起動していないか
□Microsoftアカウントと組織の管理登録を分けて確認したか
□Microsoft アカウントからの削除と［リンク解除］を済ませたか
□管理者が Intune、Windows Autopilot の順に登録を解除し、一覧から消えたことを確かめたか
□必要な消去記録と引渡しの控えを残したか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
