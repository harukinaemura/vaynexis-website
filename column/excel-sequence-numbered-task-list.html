Excelの作業一覧に指定した件数の連番をまとめて表示するには

要点

ExcelのSEQUENCE関数では、指定した行数・列数に合わせて連続する数値を生成できます。作業一覧では、必要な件数と番号の並ぶ向きを先に決め、結果を置く空きを確保してから入力するとよいです。件数を変えた後は、番号の始まりと終わり、作業名との対応を確かめます。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、作業一覧の番号を指定した件数だけまとめて用意したい小さな会社の担当者が、SEQUENCE 関数の件数・開始番号・増分の指定と、番号が広がる範囲の確かめ方をまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 使える版と、番号が広がる場所をそろえる
  2. 件数・開始番号・増分を、式の中で区別する
  3. 縦方向の短い例で、入力から確定までを見る
  4. 件数を直すときは、式のある先頭へ戻る

1．使える版と、番号が広がる場所をそろえる

確認日：2026年11月10日。

Microsoft のヘルプでは、SEQUENCE 関数の適用先として、Excel for Microsoft 365、Excel 2024、Excel 2021（それぞれ Mac 版を含む）と、iPad・iPhone・Android の Excel を挙げています。Excel 2019 以前の版はこの一覧にないので、使う前に手元の版を確かめます。引き継ぎでは、利用する版を操作メモに添えておくと、同じ前提で読み進められます。

数式の結果が隣接するセルへ広がる動作を、スピルと呼びます。見出し、番号、作業名の置き場を分け、番号を広げたい方向に別のメモが入り込んでいないかを先に見ます。特に、一覧の下に集計や注記を置いている表では、番号欄の途中だけを見て空きがあると判断せず、予定する末尾まで見渡すことが大切です。

スピルする配列数式は、Excelのテーブル内に置けないため、テーブル外の通常のセルに配置する必要があります。作業一覧のどこに番号欄を確保するかは、入力前に決めておきます。

2．件数・開始番号・増分を、式の中で区別する

基本の構文は、=SEQUENCE(行,[列],[開始],[目盛り])です。角括弧を含む表記は構文の説明として読み、入力する式には具体的な指定値を当てはめます。

「行」は返す行の数で、縦に並ぶ作業一覧では生成したい件数に対応します。「列」は返す列の数です。「開始」は数列の最初の数値です。「目盛り」は、後続の値の増分量です。同じヘルプの使用例では、=SEQUENCE(5,1,1001,1000) を使って、例の GL コード番号の連続した一覧を作っています。5 行・1 列で、1001 から始めて 1000 ずつ増やす指定です。式を見直すときは、件数を変えたいのか、番号の始まりを変えたいのかを区別すると、直す欄を絞れます。最終番号だけを思い浮かべて行数の欄を埋めると、開始位置と件数の意味が混ざってしまいます。

省略した任意の引数の既定値は1なので、縦の連番なら行数だけを指定する形も使えます。反対に、行を省略する場合は、少なくとも 1 つの他の引数を指定する必要があります。ただし、引き継ぎ相手が式を読み解く場面では、省略した欄が何を表すかも操作メモに残しておくとよいです。欄の順序を説明しておけば、別の開始番号に変える際にも同じ見方を使えます。

3．縦方向の短い例で、入力から確定までを見る

公式の縦方向の例にある=SEQUENCE(5)は、下に余地のある空白セルへ入力する形です。この形を、作業名を横に置く一覧の番号欄へ当てはめます。

=SEQUENCE(5)

数式をEnterキーで確定すると、出力範囲の大きさが動的に調整され、各セルに結果が入ります。入力欄に表示された式を見直してから確定し、表に戻って番号と作業名の並びを照合する流れです。

番号欄の表示例作業名
1共有資料の準備
2連絡事項の確認
3配布先の確認
4資料の配布
5保管場所の記録

番号が表示された時点で終えず、作業の漏れや、番号の隣が空欄になっている箇所も見ます。

横に並べる場合の公式例は=SEQUENCE(1,5)で、1行×5列の配列を作ります。縦の作業一覧と横の見出しでは、空ける方向が変わります。期待した向きと違う表示になったときは、行と列の指定を読み直す順にするとよいです。

4．件数を直すときは、式のある先頭へ戻る

スピル領域で編集できるのは最初のセルだけです。下の番号を直接修正しようとして操作を重ねる前に、数式を入れた位置へ戻ります。番号の列が長い表では、式の入力位置も引き継ぎメモに記しておくと、変更先が分かりやすくなります。

左上の数式を変更してEnterキーを押すと、残りのスピル領域も自動的に更新されます。変更後は、以前の末尾だけを見ず、広がった範囲全体に目を通します。件数を減らした場合も、作業名の側に確認対象が残っていないかを照合する流れです。

出力範囲内のセルを選択すると、範囲を囲む境界線が表示されます。番号の途中だけを見て件数を推測するより、境界の末尾と作業一覧の末尾を対応させて確認すると、見ている範囲をそろえられます。

件数を別のブックのセルから読み込む形にしている場合は、ブックを閉じたときの動きにも注意します。SEQUENCE 関数のヘルプでは、ブック間の動的配列のサポートは双方のブックが開いているときに限られ、リンク元ブックを閉じると、リンクされた動的配列数式が更新されたときに #REF! エラーが返されるとしています。

5．展開できないときは、置き場所から切り分ける

展開先が空でない場合は、#SPILL!エラーの原因になります。式を書き直す前に、番号を置く予定の範囲に既存の入力がないかを見ます。業務上必要な入力を見つけたときは、内容と退避先を確認してから移す順にするとよいです。

Microsoft のヘルプでは、エラー チェック アラートを選び、［障害物セルの選択］を選ぶと、展開を妨げているセルへすぐに移動できると案内しています。どこが障害なのかを特定してから直せば、周辺の入力をまとめて消す操作を避けられます。

スピルする配列数式は結合されたセルへ展開できず、結合の解除か、結合セルと交差しない場所への数式の移動が対処方法です。表の見た目を保つ必要があるかを考えて、対処する場所を決めます。周辺を空けても直らないときは、前に述べた配置の制約も見直し、原因を分けて扱うことが大切です。
