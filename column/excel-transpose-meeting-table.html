Excelで会議用の集計表の縦横を入れ替えて貼る手順と確認点

要点

会議用の集計表の縦横を入れ替えて貼るには、元の範囲をコピーし、行と列を入れ替える貼り付け操作を使います。見出しも含めて向きを変え、貼り付け先に残したい内容がないか、貼り付け後の値と参照先が合うかを確認する流れです。

公開：2026年11月6日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、会議用の集計表の縦横を入れ替えて貼りたい小さな会社の事務担当者が、版ごとの操作と、貼り付け先の上書き・数式の参照先を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 貼り付ける場所と使う版を先に確かめる
  2. Windows 版では見出しごとコピーして貼る
  3. Web 版では［ホーム］から向きを指定する
  4. 会議用の表は見出しと値の組を照合する
  5. 使えない表と数式の変化を見落とさない
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．貼り付ける場所と使う版を先に確かめる

公式ヘルプの適用先は Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 で、手順は Windows と Web に分かれています。使っている版に合う手順を選び、会議でどちらの方向に見出しを並べたいかを先に決めておくとよいです。ここでは、すでに集計された表の向きを変えて別の場所へ貼る操作を扱います。集計項目や帳票全体の設計を変える話は含めません。

貼り付け先には、縦横を入れ替えた表が収まるスペースを用意します。貼り付けた新しい表は、そこにあるデータと書式設定を完全に上書きします。開始位置だけでなく、表が広がる先まで見ておきます。会議用の注記や別の集計が近くにある場合は、それらと重ならない場所を選ぶ考え方です。

2．Windows 版では見出しごとコピーして貼る

元の範囲を選ぶ

Windows 版では、行や列の見出しを含めて範囲を選び、Ctrl キーを押しながら C キーを押してコピーします。この操作ではコピーが必要で、切り取りコマンドや Ctrl+X キーでは機能しません。値が並ぶ部分だけでなく、その値の意味が分かる見出しまで選べているかを確認するところが出発点です。

貼り付け先でメニューを開く

Windows 版では、［ホーム］を選び、クリップボードアイコン（貼り付け）のメニューから［入れ替え］を選びます。入れ替えの公式ヘルプでは、入れ替えた表を貼り付ける場所の左上のセルを右クリックし、［貼り付けオプション］から［入れ替え (T)］を選ぶ手順も示されています。向きを変えた表ができたら、先頭の見出しだけで完了とせず、末尾の見出しと合計欄まで見ます。元の表を残したまま照合してから、会議に使う範囲を決めるとよいです。

3．Web 版では［ホーム］から向きを指定する

Web 版では、セル範囲をコピーし、入れ替えたデータを貼る空のセルを選びます。［ホーム］タブの［貼り付け］アイコンを選び、［行と列の入れ替え］を選択します。貼り付けのオプションの公式ヘルプでは、Excel for the web の［貼り付け］メニューの項目を［行列を入れ替えて貼り付ける］と書いています。使っている画面に対応した流れで進め、選んだ貼り付け方で向きが変わったかを確認するところまでを作業に含めます。

引き継ぎでは、どの版で行った操作かに加えて、コピー元の表と貼り付ける場所を残すとよいです。担当者が変わっても、何をどこへ置く作業なのかが分かる状態を目指します。向きが変わったことと、会議で見たい項目がそろったことは、分けて確かめます。

4．会議用の表は見出しと値の組を照合する

ここからは当社の整理です。

架空の例として、部門別の経費集計で、会議では費目ごとに部門を横に見比べたい場面を考えます。値そのものを入れ直すのではなく、どの見出しが上端へ移り、どの見出しが左端へ移るかを整理した例です。

確かめる場所入れ替え前入れ替え後に照合する内容
上端の見出し交通費・消耗品費営業・総務
左端の見出し営業・総務交通費・消耗品費
見出しが交わる値営業の交通費交通費の行と営業の列が交わる値
合計欄元の表で合計とした範囲同じ対象を合計しているか

見た目だけでなく、「誰の、何の値か」をたどって照合します。合計欄も、端に並んでいるから合っていると考えず、集計した対象が同じかを見ます。元の表と貼り付け後の表を見比べ、見出しと値の組が保たれているかを確かめる進め方です。

会議の資料として渡す段階では、集計対象や単位など、読む人に必要な説明が表のそばにあるかも確認します。向きが整ったことだけを受け渡しの基準にせず、値の意味を読み取れるかまで見るとよいです。

5．使えない表と数式の変化を見落とさない

通常の範囲かどうかを確かめる

データが Excel テーブル内にある場合は入れ替え機能を使えず、公式ヘルプでは先にテーブルを範囲に変換する方法か、TRANSPOSE 関数を使う方法を示しています。項目が見つからないときは、コピーした表の種類も確認することになります。別の方法へ進む前に、元の表を今後どのように使うかを整理しておくとよいです。

計算結果と参照先を確かめる

入れ替えの公式ヘルプでは、データに数式が含まれている場合は Excel が新しい配置に合わせて自動的に更新するとし、数式で絶対参照が使われているかを確かめ、使われていなければ入れ替える前に参照の種類を切り替えられると案内しています。貼り付けのオプションの公式ヘルプでも、数式を貼り付けた後は、新しい場所でセル参照がすべて正しいことを確認する必要があるとしています。相対セル参照を含む数式をコピーすると、数式内の参照が変わります。数式のある表では、表示された合計が近いかどうかだけでなく、意図した元の値を参照しているかを確認することが大切です。

セル参照を絶対参照にするには、列と行の前にドル記号（$）を付けます。固定したい参照先と、配置に応じて動かしたい参照先を整理してから扱います。数式をまとめて変更するより、計算の意味を確かめ、必要な箇所を判断する進め方です。見出し、値、計算の参照先まで確認した状態で受け渡すとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□コピーする範囲に、行と列の見出しを含めたか
□貼り付け先で表が広がる場所に、残したい内容がないかを確認したか
□使っている版に対応する手順を選択したか
□入れ替え前後で、見出しと値の組を照合したか
□合計欄が同じ対象を集計しているかを確認したか
□数式の参照先が意図どおりかを確認したか
□会議で読む人に必要な対象や単位の説明を確認したか
