Outlookで誤って振り分けるルールの条件を直すには

要点

新しい Outlook for Windows では、ページの上部の［設定］から［メール>ルール］を開き、直したいルールの［その他のアクション］（⋯）から［ルールの編集］を選んで条件を変え、［保存］で確定します。 ルールは一覧の中の順序に基づいて受信メッセージに適用されるため、条件だけでなく、順序と［仕分けルールの処理を中止する］の設定も合わせて見ます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

経理に届いた請求書が営業のフォルダーに入っていた、取引先の案内まで同じ場所に移ってしまう。新しい Outlook で作ったルールの条件・順序・処理の中止を、どの画面で直すかを順に確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

振り分けの見本の表は架空の場面で、確認表とルールの並べ方の目安も当社の整理であり、Microsoft が示す手順そのものではありません。

  1. 先に、使っている Outlook を見分ける
  2. 誤って振り分ける理由の当たりを付ける
  3. ルールを開いて条件を直す
  4. 順序と処理の中止を合わせて見る
  5. 直した後に、すでに届いたメールを片付ける
  6. 直している間だけ止めておく
  7. 直し方の見本（架空の例）
  8. 確認表
  9. 自社の事務の手順まで形にしたいとき

1．先に、使っている Outlook を見分ける

確認日：2026年11月17日。

対象は、Windows のパソコンで使う新しい Outlook for Windows です。

Microsoft のヘルプでは、ルールの手順が「新しい Outlook」「クラシック Outlook」「Outlook on the web」「Outlook.com」のタブに分かれていて、開く画面も操作の名前も違います。見分け方として、画面の上部に［ファイル］が表示される場合は従来の Outlook、表示されない場合は新しい Outlook または Web 上のバージョンだと説明されています。 クラシック Outlook では［ファイル］から［ルール & アラートの管理］を開く別の手順になるため、このページの手順はそのままでは当てはまりません。

もう1つ、つないでいるメール アカウントの種類も確かめます。新しい Outlook では、Gmail、Yahoo、iCloud などのサードパーティ アカウントを管理するためのルールはサポートされていないと書かれています。 会社のメールを他社のメール サービスで受けていて、それを新しい Outlook に追加して読んでいる場合は、振り分けの設定はそのメール サービスの側で見直すことになります。

2．誤って振り分ける理由の当たりを付ける

ルールを開く前に、どのメールが、どのフォルダーへ行ってしまったのかを2〜3通分メモしておくと、直す場所を絞れます。新しい Outlook のヘルプから読み取れる、振り分けがずれる主な理由は次の3つです。

1つ目は、条件が広すぎることです。すべてのルールには、少なくとも名前、条件、アクションの3つが必要で、条件の例外も含めることができます。 例えば件名の言葉だけを条件にしていると、同じ言葉を使った別の取引先の案内まで同じフォルダーへ入ります。差出人の条件を足す、例外を加える、といった方法で対象を狭めます。

2つ目は、ルール同士の重なりです。1通のメールが2つのルールの条件に当てはまると、思っていない側のルールが先に働くことがあります。ヘルプでは、1つのメッセージに複数のルールが当てはまる場面の例を挙げ、最初のルールに［仕分けルールの処理を中止する］のオプションを使えると説明しています。 こうすると、それ以降のルールがメッセージに当てはまる場合でも無視されます。

3つ目は、クラシック Outlook から移ってきたルールです。従来の Outlook で作成された一部のルールは、クライアント側のルールであるため、新しい Outlook で処理できません。 この場合、ルールには「このルールは編集または表示できません」というアラートが表示され、そのまま直すことはできません。 ヘルプは、新しい Outlook でもう一度ルールを作成するよう案内しています。

3．ルールを開いて条件を直す

順番操作
1ページの上部で［設定］を選ぶ
2［メール>ルール］を選ぶ
3編集するルールで［その他のアクション］（⋯）から［ルールの編集］を選ぶ
4条件、アクション、例外を直す
5［保存］を押して、編集したルールを保存する

条件や例外を足すときは、［条件の追加］、［アクションの追加］、［例外の追加］を選ぶと、それぞれ複数を追加できます。 直すついでに、ルールの名前を「誰からのメールを、どこへ移すか」が分かる名前に変えておくと、後から一覧を見た人が迷いません。移動先のフォルダーが合っているかも、同じ画面で確かめます。

4．順序と処理の中止を合わせて見る

条件を直しても振り分けがずれるときは、ルールの順序を見直します。［メール>ルール］でルールを選び、上方向キーまたは下方向キーを使って、受信メッセージにルールが適用される順序を変えられます。 範囲の狭いルール（特定の取引先だけを移すものなど）を上に、広いルールを下に置き、上のルールで処理を止めるようにすると、意図しない二重の処理を避けやすくなります。

処理の中止は、ルールを編集する画面で、［その他のルールの処理を停止する］チェック ボックスをオンにして［保存］を選びます。 ヘルプの中では、同じ設定が［仕分けルールの処理を中止する］とも書かれているため、画面ではどちらかの名前で表示されると考えて探します。

5．直した後に、すでに届いたメールを片付ける

既定では、受信トレイ ルールは、ルールを作成した後で受信メッセージに対して実行されます。 条件を直しても、それまでに違うフォルダーへ移ったメールはそのまま残ります。既存のメッセージにも当てたいときは、［メール>ルール］で、実行したいルールの横にある［Run rule now］（今すぐルールを実行）を選びます。 いきなり全部を動かすより、まず誤って移ったメールが何通あるかを数えてから実行し、実行後に数が合うかを見ると安心です。

6．直している間だけ止めておく

条件を考え直す時間が必要なら、ルールを消さずに止めておけます。ヘルプでも、一時的に止めたいが削除したくない場合は、ルールを無効にするよう勧めています。 操作は、ルール名の横にあるトグルを使って、無効または有効を切り替えるだけです。 止めている間は該当するメールが受信トレイに残るので、担当者には「今週は手で仕分ける」と一言伝えておきます。

7．直し方の見本（架空の例）

場面（架空の例）起きていたこと直したこと
経理の請求書フォルダー件名の言葉だけを条件にしていて、営業の案内まで入った差出人の条件を足し、案内の件名を例外にした
問い合わせの通知別の広いルールが先に働き、担当のフォルダーに入らなかった狭いルールを上に移し、処理の中止をオンにした
前のパソコンから移したルール「このルールは編集または表示できません」と出た新しい Outlook で同じ条件のルールを作り直した

メールの振り分けは、担当者ごとに作ったルールが少しずつ増え、誰も全体を把握していない状態になりがちです。部署で受けるメールの流れを見直すときは、業務改善の進め方の考え方も参考になります。
