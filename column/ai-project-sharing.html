ChatGPT・Claudeのプロジェクト｜社内資料は誰に見えるか

要点

社内資料の共有では、招待した相手だけでなく、公開範囲と各メンバーの権限を確認することが大切です。資料を読む担当と内容を変更する担当を分け、利用終了時のアクセス解除まで決めておくとよいです。共有する場所と、そこで誰が何をできるかを組にして管理します。

公開：2026年11月2日／情報の確認日：2026年11月2日（出典はこの記事の最後）

この記事は、社内の資料をAIにまとめて参照させたい小さな会社の管理者・総務の担当者が、ChatGPTとClaudeの「プロジェクト」で、誰に何が見えるかを公式の説明で確かめるための整理です。

公式ページ・公式ヘルプなどの一次資料を2026年11月2日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 資料をまとめる場所と、見せる相手を分けて考える
  2. 読む担当と変更する担当を分ける
  3. 組織への公開と、会話の公開を混同しない
  4. アーカイブとアクセス解除を別々に確認する
  5. 資料を入れる前に、共有単位を決める

1．資料をまとめる場所と、見せる相手を分けて考える

製品の機能・設定に関する以下の記述の確認日：2026-11-02。

ChatGPT のプロジェクトには、ファイルをアップロードし、専用の指示を設定できます。

Claude のプロジェクトは、それぞれにチャット履歴と知識ベースを持つ作業の場です。

資料を置く場所を決める際には、利用する人の範囲も併せて考えます。共有相手を決めてから、その相手に必要な操作を割り当てる順に整理すると、見せる範囲と編集する範囲を混同しにくくなります。

比較する点公式資料で確認できる共有範囲
ChatGPT の共有対象所有者は「Only those invited」と「Anyone with a link」から共有範囲を選べます。
Claude の共有対象非公開では自分と招待したメンバーだけが利用できます。 Public は、組織の全員が閲覧・利用する公開範囲です。

2．読む担当と変更する担当を分ける

ChatGPT では、Share から共有の画面を開きます。 chat アクセスでは、プロジェクト内のチャット、ファイル、指示を閲覧し、利用できます。 edit アクセスでは、指示の更新、ファイルの追加・削除、他の人の招待が可能です。 所有者は、メンバーを個別に削除できます。

資料を参照して質問する仕事と、参照資料を差し替える仕事は分けて考えるとよいです。編集担当を決める際には、文書の内容に詳しいかだけでなく、資料の追加や共有先の変更を誰が承認するかも整理します。

個人の名前を確かめた後は、グループ経由の参加や共有リンクの扱いも管理者と照合します。招待一覧を残すだけでなく、どの経路で参加できる設定にしたかを書き添えておくと、担当交代時の確認に使えます。ここでいう確認の進め方は、当社の運用上の整理です。

3．組織への公開と、会話の公開を混同しない

Claude のプロジェクト共同利用は、Team と Enterprise のプランを対象としています。 Can view はプロジェクト内で会話できますが編集はできず、Can edit はプロジェクトの指示や知識を変更できます。 プロジェクト内のチャットは、初期状態では共有されません。

資料を同じ場所に置くことと、会話まで引き継ぐことは別の確認項目です。引き継ぎたい情報が資料にあるのか、担当者との会話にだけあるのかを整理し、必要な相手に届く方法を選ぶとよいです。

なお、Claude の公式資料には、新しいプロジェクトのベータ版を段階的に提供する旨の注記があります。 案内を読みながら設定を確認するときは、利用中の画面と説明の対象が合っているかも照合します。画面の違いを見つけた場合は、似た名前の項目を推測で選ぶより、管理者に対象の版を確認する進め方が適切です。

4．アーカイブとアクセス解除を別々に確認する

Claude は、プロジェクトをアーカイブしても共有権限やメンバーは解除されません。 非公開プロジェクトのメンバーを外す操作には、共有メニューの「Remove access」があります。

担当変更や退職への対応では、一覧から見えなくなったことと、利用する権限を外したことを分けて記録します。対象者が関わった共有先を洗い出し、解除を担当する人と、完了を確かめる人を決めておくとよいです。

終了した仕事の資料を保管する判断と、元の担当者に閲覧を続けてもらう判断も別に扱います。保管のために残す資料については、引き続き閲覧する人と、内容の管理を引き受ける人を明らかにしておきます。

5．資料を入れる前に、共有単位を決める

この節は当社の整理です。参照する目的と、共有する相手の仕事が対応しているかを確認します。社内の資料だからという理由だけで、部署や担当の異なる資料をまとめることは避けたいところです。

個人情報や取引先名を含む資料は、社内の入力ルールと資料の管理担当者に照らし、入れてよい範囲を先に確かめます。共有の設定が選べることと、その資料の入力が認められていることは、それぞれ確認する事項です。

入れてよい資料が決まった後は、更新する人と、差し替えの判断をする人も定めます。古い資料を残す場合には、その理由と使用する範囲を管理担当者が把握できる状態にします。共有先が同じでも、目的や管理責任が異なる資料は、分けて扱う方針も考えられます。

6．実際の設定は管理者と照合する

この節は当社の整理です。公式の説明を読む作業と、自社の設定を調べる作業を続けて行うとよいです。確認の際には、使用中の契約、対象の共有先、現在の参加者、各人に認める操作を並べます。

画面に目的の項目がない場合は、表示されている内容と、実現したい共有範囲を管理者に伝えます。担当者ごとに説明が食い違うときは、その場で共有を広げず、資料の管理担当者を交えて判断をそろえる進め方が適切です。

最初の確認が済んだ後も、参加者の変更や資料の追加を、設定を見直すきっかけにします。作成した人だけが分かる管理にせず、担当交代時にも共有の範囲を説明できる状態を目指します。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□資料の入力が社内ルールで認められているか確認したか
□個人情報や取引先名を含む範囲を管理担当者と照合したか
□招待先だけでなく、グループやリンクを通じた参加経路も確認したか
□読む担当と、資料・指示を変更する担当を分けて設定したか
□資料の共有と会話の共有を区別して確認したか
□担当交代や退職に伴うアクセス解除の担当を決めたか
□利用中の画面と公式資料の説明が対応するか管理者と照合したか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
