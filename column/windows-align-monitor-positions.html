Windowsのディスプレイで左右のモニター配置を直すには

要点

左右のモニター配置は、ディスプレイ設定で位置を変えたい対象を選び、机上の並びに合わせてドラッグした後、動かしたい対象がすべて希望する位置に並んだところで［適用］を選ぶと変更できます。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、左右のモニター配置を直したい小さな会社の担当者が、Windows の画面番号と机上の位置、適用後の行き来を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 画面の番号と机上の位置を照合する
  2. 対応する枠を動かして配置を適用する
  3. 適用後はポインターの行き来を確かめる
  4. 共有の席では位置と用途を分けて記録する
  5. 引き継ぎは変更した内容と確認結果を残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．画面の番号と机上の位置を照合する

確認日：2026年11月15日

ここで扱うのは、Microsoftの案内にある、Windows 11で外部ディスプレイを接続した後の手順です。画面の表記は Windows の版や更新状況によって異なることがあります。

［設定］の［システム］、［ディスプレイ］から［識別］を選ぶと、それぞれの画面に割り当てられた番号が表示されます。机を正面から見た状態で、左にある実物の画面と、そこに出た番号を対応させます。右側も同じように見比べると、動かす対象を言葉にできます。

Microsoft の案内では、Windows が複数のディスプレイを検出すると配置のオプションが表示され、それぞれに番号が付けられます。番号を表示して実物との対応を見る［識別］と、設定に現れていない画面を探す［検出］は、使う場面が異なります。画面はそろっているのに左右だけが合わない場合は、まず［識別］で対象を対応させます。

左右で別の内容を表示する使い方かを確かめる

Microsoft の表示方法の案内では、［複製］はすべてのディスプレイに同じ内容を表示し、［拡張］では複数の画面にデスクトップを広げ、画面間で項目を移動できます。左右で資料と入力先を分けたい場合は、番号や位置を調整する前に、同じ内容を映している状態か、画面をまたいで使う状態かを見ます。表示方法を変える必要があるかと、左右の位置だけを直す必要があるかを分けると、変更する範囲を決めやすくなります。

2．対応する枠を動かして配置を適用する

Microsoft の案内では、ディスプレイ設定で対象を選んで目的の場所へドラッグし、移動したいすべての画面を希望する配置にしたら［適用］を選びます。画面上の見た目だけで判断せず、先ほど照合した番号を手がかりに、左の実物に対応する枠を左へ、右の実物に対応する枠を右へ並べる考え方です。

接続した画面が設定に見当たらないとき

別のディスプレイを接続しても設定に表示されない場合は、［スタート］、［設定］、［システム］、［ディスプレイ］から［複数のディスプレイ］を開き、［検出］を選びます。この段階では、表示されていない対象を推測して動かすより、対象がそろっているかの確認を先に置きます。

3．適用後はポインターの行き来を確かめる

Microsoftは、新しい配置をテストする方法として、異なるディスプレイの間でマウスポインターを移動し、期待どおりに動くかを確認する手順を示しています。設定画面の並びを眺めるだけで終わらず、普段の席に座った向きで行き来を確かめることが、完了を判断する材料になります。

確認するときは、左から右へ進む向きと、右から左へ戻る向きを分けて見ます。引き継ぐ相手が別にいる席では、その人にも実際に動かしてもらい、どこからどこへ移りたいのかを共有するとよいです。「直った」という感想だけでなく、意図した移動と実際の動きが一致したかを残します。

期待した動きにならないときの記録には、出発した側、進めた向き、移動先として期待した側を書きます。原因をその場で断定するより、同じ動きを別の人が確認できる形にしておくほうが、次の確認につなげやすくなります。

4．共有の席では位置と用途を分けて記録する

ここからは当社の整理です。

共有の席に残すメモは、「机上のどちらにあるか」と「何を表示して使うか」を分けると読みやすくなります。用途だけで「資料を見る画面」と呼ぶと、使う人が変わった際に、どちらの実物を指すのかが曖昧になります。位置は机を正面から見た左右でそろえ、用途はその横に添える形です。

机を正面から見た位置主な用途の例引き継ぐときの記録
左参照資料を見る画面に表示された番号を書き留める
右入力する資料を見る左側との行き来を確認したかを記す

実際に使う人が逆の置き方を望む場合は、その希望も一緒に書きます。番号そのものを使い道の名前にせず、実物の位置と結び付けておくことが、このメモの目的です。

記録には、調整前に困っていた動きと、調整後に確かめた動きを分けて残すとよいです。席の写真を添えるなら、左右の基準が読み取れる向きにそろえます。画面の中の資料や個人情報が写り込まないよう、記録に必要な範囲を選ぶことも考えておきます。

5．引き継ぎは変更した内容と確認結果を残す

引き継ぎ用の文章は、操作の名前を並べるだけでなく、どの実物を対象にし、何を確かめて終えたかまで書くと伝わりやすくなります。席を共用する担当者向けには、変更した内容と、まだ困っている動きを分けて記録します。確認できていないことを「問題なし」に含めない形です。

相談を受ける側へ渡すメモにも、観察した動きと、自分で考えた原因を分けて書きます。「右へ進めたときに意図した側へ移れない」は観察の記録ですが、「機器が故障している」は原因の判断です。まず前者を共有すれば、次の担当者が何を再確認するかを決めやすくなります。

事務の手間を洗い出すなら、画面の並びの調整と、その後に行う資料の転記や確認を分けて書き出すとよいです。後者のどこを人が確かめ、どこを任せるか考える入口として、事務でのAI活用の進め方を検討できます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□机を正面から見た左右の基準をそろえたか
□実物の画面と表示された番号を照合したか
□動かす対象と希望する位置を整理したか
□配置の変更を反映する操作まで終えたか
□左右の行き来が意図に合うか確かめたか
□引き継ぐ相手にも変更後の動きを確認してもらったか
□未解決の動きがあれば観察した内容を残したか
