Copilot ChatのWork IQで社内資料の参照を止めるには

要点

Microsoft 365の作業データを回答の根拠に使わせないときは、Work IQをオフにし、自分で添付する資料も別に確認します。切り替えた状態と渡す内容を確かめ、回答の根拠を見てから仕事に使う、という順にするとよいです。

公開：2026年11月16日／情報の確認日：2026年11月16日（出典はこの記事の最後）

社内資料を使わずにCopilot Chatで下書きを作るには、Work IQの切り替えに加え、自分で添付・入力する情報も確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月16日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象アカウントと利用条件を先に確かめる
  2. 画面上部の切り替えで参照範囲を変える
  3. 添付した資料と個人用設定は分けて考える
  4. 送信前と回答後の確認を担当者に割り当てる
  5. 一般的な下書きと社内の決まりを答える依頼を分ける
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象アカウントと利用条件を先に確かめる

確認日：2026年11月16日

この記事で扱うのは、Webブラウザーで職場または学校アカウントにサインインして使うCopilot Chatです。業務向けのCopilot Chatを使うには、Microsoft 365アカウントでサインインし、対象となるビジネスまたはエンタープライズのサブスクリプションが必要です。Work IQは、Microsoft Copilotアドオンライセンスを持つユーザーが利用できます。

利用者への案内では、契約していることと、自分が使うアカウントに必要なものが割り当てられていることを分けて確認する流れにします。操作する人が契約内容を把握していなければ、社内の管理担当者に割り当ての状況を尋ねるところから始めるとよいです。

職場・学校アカウントでは、自分のアカウントに関連付けられたCopilotのラベルから、取得しているライセンスを確かめられます。契約名を推測して操作案内を渡すより、使っている画面と割り当てをそろえてから確認する方が、案内の行き違いを減らせます。

2．画面上部の切り替えで参照範囲を変える

Microsoftの開始ガイドでは、Chat画面上部の［自動モデル ピッカー］の横にWork IQのコントロールがあると案内しています。社内資料を参照させないときは、Work IQボタンをオフにします。Microsoft Copilotアドオンライセンスがある場合、Work IQは既定で有効です。

送信前は、質問文の書き方だけでなく、参照の切り替えが意図した状態かも確認します。「社内情報を使わない」という依頼の言葉と、画面で選ぶ状態を分けて記録しておくと、後で回答の内容を見直すときに判断の経緯を追いやすくなります。確認記録には、実際に見えた表示を残し、案内書の呼び方だけで状態を記入しないようにします。

Microsoftは新しいホーム画面を順次提供しており、アプリの表示がヘルプの説明と異なる場合があると案内しています。該当する操作箇所が見当たらないときは、その場で別の設定を代わりに変更せず、画面の表示とアカウントの種類を管理担当者と照合する進め方にします。

3．添付した資料と個人用設定は分けて考える

Copilotは、応答に含めるよう渡されたコンテンツを回答の作成に使います。Work IQをオフにしても、個人用設定はオフになりません。MicrosoftのFAQでは、オフにした後も仕事のプロフィール、保存された設定、文書のスタイル、チャットで直接渡した仕事関連情報などを使用する場合があると説明しています。切り替えだけを見て「会社に関する内容を何も渡していない」と扱わず、入力欄に貼り付けた文章や添付した資料を、送信前の別の確認項目にします。

一般的な説明を作りたい段階では、その質問を成立させるのに社内資料が必要なのかを先に考えるとよいです。必要がなければ資料を加えずに進め、資料に基づく判断が必要になったところで、扱う内容と確認する人を決め直します。文章の整え方を相談する段階と、社内の事実を答えさせる段階を分けるためです。

Work IQは、作業の必要に応じてオンとオフを切り替えられます。運用上は、社内の根拠が必要になったら、依頼の目的を確認してから切り替える流れにします。一般的な下書きのまま承認資料に進めるのではなく、どの文に社内の裏付けが要るのかを担当者が見分けることが大切です。

4．送信前と回答後の確認を担当者に割り当てる

回答後は、Copilot Chatの応答下部にある［ソース］ボタンから参照元の一覧を確認できます。見たかった根拠と回答で使われた根拠が合っているかを照合し、文章が自然に読めることだけで確認を終えないようにします。

以下の役割分担は当社の整理です。操作する人と回答を仕事に使う人が異なる場合も、どこまで確認を終えたかを引き継げる形にしておくとよいです。

誰がいつ確かめること
操作する担当者入力を始める前一般的な下書きか、社内資料に基づく回答か
操作する担当者送信する直前切り替えの状態と、入力・添付で渡す内容が目的に合っているか
回答を使う担当者回答を受け取った後参照元が目的に合い、社内の事実として扱える内容か
管理担当者画面が案内と合わないとき対象アカウント、割り当て、実際の表示
作業の責任者社内判断に使う前根拠の不足を誰が補い、どの範囲まで確認したか

参照元を見た結果、意図しない資料が含まれていれば、その回答の利用をいったん保留し、渡した内容と依頼の目的を見直します。反対に社内の根拠が必要なのに一般的な説明しかなければ、担当者が資料で確認する部分を明示します。設定を変えた記録と、回答を採用してよいという判断は別々に残すとよいです。

5．一般的な下書きと社内の決まりを答える依頼を分ける

たとえば、備品を貸し出す際の案内文を整えたい場面を考えます。「一般的に案内に含める項目を整理したい」のか、「自社で定めた貸出条件を正しく伝えたい」のかで、必要な根拠は変わります。先に案内の構成を作り、社内の条件を当てはめる段階を担当者の確認として分ける進め方が考えられます。

下書きに担当部署、返却方法、紛失時の扱いなどが出てきても、それだけで自社の決まりと一致したことにはしません。社内で決まっている項目は根拠の資料と照合し、決まっていない項目は空欄や確認待ちとして残します。整った文章の中に仮の条件が混ざったまま配布されることを避けるためです。

確認の基準は、社内の内容を使う必要があるか、使った根拠を担当者が確かめられるかです。参照範囲を選ぶ作業を、社内判断そのものの代わりにはしない運用にします。作業に使う情報と人が判断する範囲を整理する際は、AIを業務に取り入れる進め方も合わせて考えるとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□一般的な下書きが必要なのか、社内資料に基づく回答が必要なのかを整理したか
□使用する職場・学校アカウントと必要な割り当てを確認したか
□送信前に参照の切り替えが意図した状態か確認したか
□入力欄に貼り付けた文章と添付資料を別に点検したか
□回答の参照元を開き、使いたい根拠と一致するか確認したか
□社内の決まりに当たる部分を、担当者が資料と照合したか
□画面が案内と異なる場合の確認先と、利用を保留する場面を決めたか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月16日）

  • Microsoft Copilot Chatを探索する：切り替え位置、対象となるアカウントと画面の提供状況
  • Copilot Chat のしくみ (Microsoft Copilot ライセンスの有無)：対象となる契約とサインインの条件
  • Copilot は、プロンプトに応答するためにどのような情報を使用しますか?：アドオンの条件、既定の状態とオン・オフの用途
  • 所有している Copilot ライセンスの種類：職場・学校アカウントのライセンスの確かめ方
  • Microsoft Copilot で特定のファイルなどを参照する：オフへの切り替えと、添付・入力で渡す内容を別に見る理由
  • Microsoft Copilot Chat についてよく寄せられる質問：オフ時の添付ファイルと個人用設定の扱い
  • Microsoft Copilot Chatの回答のソースを制御および確認する：回答後に使用したソースを確認する操作
