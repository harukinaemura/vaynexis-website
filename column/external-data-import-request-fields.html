外部データ持込申請書には何を書く？提供元と検査確認の欄

要点

外部データ持込申請書には、申請者、提供元、対象データと利用目的、持込方法、取込先、許可の記録、検査の確認、取込担当をつなげて書ける欄を設けます。社内書式の項目案として、申請時の予定と検査後・取込後の記録を分け、どのファイルについて誰が何を確認したかを追える形にする考え方です。

公開：2026年11月8日／情報の確認日：2026年11月7日（出典はこの記事の最後）

小さな会社の事務担当者が、外部データの提供元と許可、検査、実際の取込先をつなげて記録する手順です。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 公的な規程に見る許可と使用前検査の関係
  2. 提供元から取込担当までをつなぐ記入欄
  3. 検査の予定と完了を同じ欄にしない
  4. 受領物の照合と差し替え後の記録を決める
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．公的な規程に見る許可と使用前検査の関係

確認日：2026年11月7日

南和広域医療企業団の「外部記憶媒体の取扱いに関する規程」には、外部データ持込申請書（様式第6号）が置かれています。

企業団の規程第10条は、持ち出しを許可された媒体や外部機関・個人が持つ媒体で、企業団の設置したコンピュータ以外で作った電子データを持ち込む場合を扱っています。法令・例規に基づく事務で外部機関から提供されたデータの持込みは、この申請の規定から除かれます。

同規程では、セキュリティ管理者は申請内容を精査し、必要不可欠と判断した場合に限り、情報セキュリティ担当者に許可を与えることができます。許可を受けた場合、同規程は情報セキュリティ担当者が電子データの使用前にコンピュータウイルスチェックを行うよう定めています。

企業団の様式第6号では、管理番号、媒体の種類、データの内容・形式、申請理由などを記入し、申請者が記入する部分と持込みの可否を記録する部分を分けています。

ここからは当社の整理です。

社内用の申請書を考える際にも、利用を認めた記録と、検査を終えた記録をそれぞれ残せる構成が考えられます。承認の印だけで処理を終えると、検査が済んだ対象を後から確かめにくくなります。申請書を受け付ける人だけでなく、検査する人と取り込む人が読める欄にすることが出発点です。

2．提供元から取込担当までをつなぐ記入欄

社内書式を作る際の項目案をまとめます。欄を増やすだけでなく、同じデータを指しているか照合できる書き方にするのが狙いです。提供元は送り主の呼び名だけで済ませず、問い合わせる相手が分かる粒度にするとよいです。

項目案何を書くか書き間違えやすい点
申請者・利用部門利用部門と連絡先申請を取りまとめる人と、実際に使う部門の混同
提供元・受領経路提供元の名称、窓口、受領経路持参した人の名前だけを書き、データの提供元を残さないこと
対象データファイル名、形式、版や更新日、内容の概要フォルダー名だけを書き、中の対象ファイルが特定できないこと
利用目的必要な業務と利用範囲「業務用」だけで、何のために使うかが伝わらないこと
持込方法受領した媒体と識別の手掛かり媒体の種類だけを記入し、現物との対応を残さないこと
取込先取込先の端末・保存先と利用者の範囲受け渡し用の一時保管先と、利用する保存先の混同
許可の記録許可者、判断した日時、認めた対象と範囲申請した内容と、認められた内容の混同
検査の確認対象、担当者、実施日時、結果と記録の保管先実施予定だけを書いて、完了したように読めること
取込担当・取込記録担当者、実施日時、実際の取込先、処理した対象検査担当者の名前だけで、取込担当も兼ねたと扱うこと
保管・処理の記録受領物と申請書の保管先、返却・削除等を担当する人申請書だけを保存し、対象データや媒体の所在を追えないこと

提出時点で書ける情報は申請者が記入し、検査や取込みをした人が後から結果を追記する構成にします。記入者の違いが分かるよう、欄ごとに担当する役割を添える方法もあります。

対象データの欄は、内容の概要とファイルを見分ける情報を分けると読みやすくなります。「取引先から受領した資料」という説明だけでは、申請したファイルと検査したファイルを比べにくいためです。申請書に書き切れない対象は、対象一覧を添付して申請書と対応付ける形が考えられます。

3．検査の予定と完了を同じ欄にしない

検査確認欄には、担当する予定の人を書く場所と、実施した人が結果を残す場所を設けます。「確認済み」という印だけにせず、何を対象にしたか、いつ実施したか、結果の記録はどこにあるかまで対応付ける案です。検査結果の詳しい内容を申請書に転記する代わりに、確認できる保存先を記す方法もあります。

提供元の確認と、社内での検査も分けて記録するとよいです。送り主から受けた説明は「提供元の申告」として残し、自社で実施した確認の欄へそのまま移さないようにします。誰の説明なのかが分かれば、照会先を探し直す手間を抑えられます。

予定、実施済み、担当者への照会中といった状態を、社内で決めた言葉で記録します。空欄の意味を読む人の推測に任せず、未着手なのか、確認を待っているのかが分かる形です。検査に関する判断を事務担当だけで埋めず、技術的な確認は情報管理の担当者につなぎます。

取り込む人は、対象データ欄と検査記録を見比べられるようにします。検査したファイルが後から差し替わっていないか、許可された範囲と同じかを確認するためです。申請者、検査担当、取込担当を同じ人が兼ねる運用でも、それぞれの処理を記入する場所は分けておくと経過をたどりやすくなります。

4．受領物の照合と差し替え後の記録を決める

書式と併せて、提供元への問い合わせ、対象の照合、保管、差し替えを誰が担当するかを決めます。申請者は受領したデータの名前と申請内容を比べ、内容や提供元がはっきりしない部分を問い合わせます。検査担当と取込担当へ渡す段階で、同じ対象一覧を共有する流れが考えられます。

保管先は、申請書だけでなく、対象一覧、許可の記録、検査結果、取込記録が対応して見つかるように整理します。関連する記録の置き場所を申請書からたどれるようにすれば、別の担当者が引き継ぐ場面でも確認しやすくなります。閲覧する人の範囲も、データの扱いを決める担当者と相談しておきます。

ファイルの差し替えがあったときは、以前の申請内容を上書きするだけで済ませず、差し替えた対象と理由、確認した担当者を残します。以前の検査記録がどのファイルについてのものか分かるようにし、更新後の扱いを担当者へ照会する流れです。検査や許可を改めて扱う範囲は、社内の管理担当者が決めます。

書式の見直しでは、空欄が続く項目や問い合わせが多い項目を拾います。提供元の窓口が分からないのか、対象ファイルを特定できないのか、取込後の記録が残らないのかによって、直す欄は異なります。項目を足す前に、欄名と記入者の役割が伝わっているかを見返すとよいです。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□提供元の名称と、照会できる窓口を記録したか
□対象ファイルを見分ける情報と、利用目的・範囲を整理したか
□持ち込む媒体と、実際の取込先を対応付けたか
□許可の記録と、検査の予定・実施結果を分けて記録したか
□検査した対象と取り込んだ対象を、担当者が照合できる形にしたか
□申請書と関連記録の保管先、差し替え時の連絡先を整理したか
