Excelの全シートから管理番号を完全一致で検索する手順と確認

要点

全シートから管理番号を探すには、検索オプションの［範囲内］で［ブック］を選びます。番号全体が同じセルを探す設定は［セルの内容全体を一致させる］です。探す場所と一致の条件をそろえたうえで、結果の一覧から対象を確認するとよいです。

公開：2026年11月5日／情報の確認日：2026年11月5日（出典はこの記事の最後）

この記事は、管理番号がどのシートにあるか分からない小さな会社の事務担当者が、Excelの検索でブック全体・セルの内容全体の一致・検索先を設定し、結果を確かめて引き継ぐ流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月5日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 対象の版を確認し、検索画面を開く
  2. 探す場所と、番号全体の一致を設定する
  3. 検索先と、英字の大小の扱いをそろえる
  4. 短い見本で、番号と周辺の文字を見比べる
  5. 結果の一覧から対象を開き、条件を確かめ直す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象の版を確認し、検索画面を開く

確認日：2026年11月5日。

公式ヘルプの適用先は、Excel for Microsoft 365、Excel for Microsoft 365 for Mac、Excel 2024、Excel 2024 for Mac、Excel 2021、Excel 2021 for Mac、Excel 2019、Excel 2016 です。

ここで扱うのは、公式ヘルプの Windows タブの手順です。同じヘルプには macOS と Web のタブもあります。

検索画面は Ctrl+F で開き、［オプション］で詳細な設定を表示します。［検索する文字列］に探す管理番号を入力します。

作業の前に、探したい帳簿や一覧のファイル名を見ておくとよいです。同じ名前の控えがある業務では、検索を始めるファイルを取り違えないことも確認に含めます。引き継ぎ用のメモにも、対象のファイルと探す番号を分けて残します。

2．探す場所と、番号全体の一致を設定する

［範囲内］では、ワークシート内を探す［シート］と、ブック全体を探す［ブック］を選べます。今回は開いているファイルの各シートを探すため、［ブック］を選びます。

［セルの内容全体を一致させる］をオンにすると、入力した文字だけを含むセルを検索します。

探す場所を広げる設定と、内容の一致を絞る設定は、役割が異なります。検索する文字を入れた後に、両方の設定を見てから実行する流れにすると、条件の確認漏れを整理しやすくなります。

引き継ぎでは、番号を検索したことだけを書くよりも、［範囲内］の選択と一致の条件を別々に記録するとよいです。担当者が自分の画面と照らし合わせるときも、どの設定を確認するのかが伝わります。

3．検索先と、英字の大小の扱いをそろえる

［検索先］には［数式］［値］［メモ］［コメント］の選択肢があります。管理番号の値を対象にするときは、［検索先］で［値］を選びます。検索する対象が管理番号の値なのか、数式の記述や付随するメモなのかを先に整理します。番号を探す作業と、番号について書かれた説明を探す作業では、目的を分けておくとよいです。

英字の大小も区別して探す場合は、［大文字と小文字を区別する］をオンにします。番号全体の一致と、英字の大小の区別は、別々の設定として確認します。

検索条件には、疑問符（?）、アスタリスク（*）、チルダ（~）などのワイルドカード文字を使えます。疑問符・アスタリスク・チルダそのものを探すときは、その文字の前にチルダ（~）を付けます。番号にこれらの記号が含まれる業務では、通常の番号と同じ入力でよいと判断せず、検索条件を記録してから照合します。

結果が想定と違うときは、番号の元の記載を見直したうえで、検索先や英字の扱いが目的に合っているかを確かめます。見つけるために条件を緩めた状態と、番号全体の一致を確認する状態を、引き継ぎのメモでも分けておくとよいです。

4．短い見本で、番号と周辺の文字を見比べる

ここからは当社の整理です。

確認用のコピーに、探す番号そのものと、前後に別の文字が付いた内容を置く構成を考えます。下の表は検索結果の記録ではなく、見本に含める内容と、見比べたい点を示したものです。

置くシートセルに入れる内容見比べたい点
受付仮番号ア探す番号そのもの
控え仮番号ア枝後ろに別の文字がある内容
メモ確認対象は仮番号ア説明の途中に番号がある内容

この見本では、探す文字列を仮番号アとする想定です。実際の結果を見ながら、番号だけのセルと、番号を含む説明のセルを区別できたかを確認します。

本番の情報を広くコピーする前に、短い見本で検索の目的を共有するとよいです。確認後に残すメモも、表全体の写しではなく、対象のファイル、探した文字、設定の内容、確認した場所を中心にまとめます。

5．結果の一覧から対象を開き、条件を確かめ直す

公式ヘルプでは、［すべて検索］を選ぶと条件に合う出現箇所がすべて一覧表示され、一覧の項目を選ぶとそのセルが選択されると案内されています。

結果を開いた後は、番号の欄と周辺の見出しを見比べ、今回確認したい情報かを判断します。同じ番号について別の控えがある業務では、担当者が使う資料を決めておくと、見つかった場所だけを根拠に処理を進めることを避けやすくなります。

見つからないときの確認順は、探す文字の転記、対象のファイル、［範囲内］の選択、一致の条件、検索先とすると整理しやすくなります。原因をまとめて推測するより、入力した内容と選んだ設定を順に照合する進め方です。

設定を変えて検索し直した後は、最後に使った条件をメモへ戻します。見つからなかったという結果だけでなく、どの条件で確認したかを残すことが、別の担当者へ渡す際の手がかりになります。
