訪問看護指示書の発行を依頼するとき、何の情報をそろえる？

要点

訪問看護指示書の発行を依頼する事業所は、医療機関の案内を開き、対象者、希望する指示期間、種別、予定する支援の情報をそろえます。依頼先と事業所の連絡担当を確かめ、受領したら対象者や期間を依頼記録と照合します。国の基準では、医療保険でも介護保険でも、指定訪問看護事業者は提供の開始に際し、主治の医師による指示を文書で受けるとされています。この記事は旭川医療センターの参考様式を使います。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、訪問看護指示書の発行を医療機関に依頼する事業所の事務担当者が、旭川医療センターの参考様式の欄と国の基準での指示の受け方、受け取った指示書の照合と保存を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月9日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 発行を依頼する医療機関の案内を読む
  2. 対象者と依頼する期間・種別を照合する
  3. 支援予定の情報と連絡先をそろえる
  4. 依頼した記録と受領した指示書を照合する
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．発行を依頼する医療機関の案内を読む

確認日：2026年11月9日。

旭川医療センターは、訪問看護指示書の発行依頼の書式を指定せず、必要事項が分かるように訪問看護ステーション向けの参考様式を公開しています。記載が足りない場合は交付できないことがあると案内しています。参考様式はそのまま使ってもよいとされ、訪問リハビリテーション事業所用には別の依頼書が用意されています。

国の基準では、医療保険の指定訪問看護の事業の人員及び運営に関する基準第16条第2項と、介護保険の指定居宅サービス等の事業の人員、設備及び運営に関する基準第69条第2項が、いずれも指定訪問看護事業者は指定訪問看護の提供の開始に際し、主治の医師による指示を文書で受けなければならないとしています。どちらの基準も、主治の医師に訪問看護計画書と訪問看護報告書を提出し、主治の医師との密接な連携を図るよう定めています。

医療保険の基準第16条第3項は、利用者の病状と心身の状態について、定期に主治の医師に指定訪問看護の提供の継続の要否を相談するよう定めています。介護保険の基準第69条第4項は、事業所が指定訪問看護を担当する医療機関である場合は、文書による指示と計画書・報告書の提出を、診療録その他の診療に関する記録への記載をもって代えることができるとしています。

ここからは当社の整理です。

事業所で依頼の準備を始めるときは、今回の医療機関の案内を開き、必要な情報と提出方法を確認します。使う様式と、依頼の内容を確認する事業所内の担当を先に決めます。依頼先が別の医療機関であれば、その医療機関の案内で、依頼の書式の指定と送り先を改めて確かめます。

2．対象者と依頼する期間・種別を照合する

旭川医療センターの参考様式には、診療科・主治医名、患者氏名、生年月日、指示期間、指示書種別を記入する箇所があります。

同じ参考様式の指示書種別には、訪問看護指示書（一般）（医療保険で介入か介護保険で介入かを選ぶ）、在宅患者訪問点滴指示書、特別訪問看護指示書（一般）が並んでいます。旭川医療センターの案内は、交付する指示書として訪問看護指示書（一般・特別・点滴指示）と訪問リハビリテーション指示書を挙げています。

事業所内の記録と依頼書を照合し、対象者と依頼先を確認します。期間を更新する依頼では、手元の指示書の期間と、今回依頼する期間を分けて控えます。種別や期間が決まっていない場合は、事務担当が推測で選ばず、確認する人と確認事項を控えます。医療保険と介護保険のどちらで介入するかの欄も、事業所内で確かめた担当と日付を控えてから記入します。

3．支援予定の情報と連絡先をそろえる

同じ参考様式には、提供を予定している支援内容と、事業所の連絡先や担当者名の欄があります。介護保険でリハビリを行う場合は、理学療法士・作業療法士・言語聴覚士が行う訪問看護について、1日あたりの分数、週の回数、実施内容を書く欄があります。連絡先の欄は、郵便番号、住所、電話、FAX、担当者名に分かれています。

支援予定の情報は担当者が確認した内容を用い、問い合わせを受ける担当と連絡先を記します。送る前に依頼先、添付する資料の範囲、送付方法を確認し、対象者を取り違えていないか見直します。

4．依頼した記録と受領した指示書を照合する

依頼の記録には、依頼日、確認した担当、提出した版、依頼した種別と期間を控えます。受領したら対象者、発行元、指示書の種別と期間を確認し、受領日と引き継いだ担当を記録します。

依頼時の内容と受領した書面に差があるときは、事務側で書面を書き換えず、差がある項目を整理して発行元と事業所の担当に確認します。

医療保険の基準第30条第2項は、訪問看護記録書、訪問看護指示書、訪問看護計画書、訪問看護報告書などの記録を整備し、その完結の日から2年間保存しなければならないとし、記録は正確かつ最新の内容を保つよう整備するとしています。介護保険の基準第73条の2第2項も、主治の医師による指示の文書を、完結の日から2年間保存する記録に挙げています。

受領した指示書は、依頼の記録と同じ利用者・同じ指示期間で対応がつくように保管し、指示期間の終わりが近い利用者を月ごとに一覧にして、次の依頼を出す時期を事業所内で決めておきます。保存の年限は、事業所を所管する自治体が定める基準でも確かめます。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□医療機関の現行の案内と依頼に使う様式を確認したか
□対象者、依頼先、種別、期間を確認したか
□支援予定の情報と問い合わせ先をそろえたか
□提出用の版と、受領した指示書を対応させたか
□依頼と受領で差があった箇所を担当に引き継いだか
□医療保険・介護保険のどちらで介入するかを確かめてから種別を記入したか
□受領した指示書を指示期間ごとに保管し、次の依頼の時期を一覧にしたか
