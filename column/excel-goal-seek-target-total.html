Excelで合計が指定額になる入力値を逆算するには？

要点

Windows版のExcel for Microsoft 365では、［データ］の［What-If 分析］から［ゴール シーク］を開きます。［セルの設定］に合計の数式が入ったセルの参照、［目標値］に求める金額、［変化させるセル］に数式が参照する入力セルを指定します。指定できる入力セルは1つです。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、Excelの合計を指定額に合わせる入力値を求めたい小さな会社の担当者が、ゴール シークの3つの欄と、計算後の端数や前提を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月9日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 数式セルと、変更を許す入力を分ける
  2. ゴール シークの3つの欄に入れる情報
  3. 計算後に、金額と前提を別々に見直す
  4. 目標に合わなければ、参照先と入力の条件を点検する
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．数式セルと、変更を許す入力を分ける

確認日：2026年11月9日。

この記事はWindowsデスクトップ版のExcel for Microsoft 365を対象にします。ゴール シークは、数式で得たい結果が決まっていて、そのために必要な入力値が分からないときに使う機能です。Microsoftの案内では、変える入力セルは結果の数式から参照されている必要があります。

Microsoftの操作例では、得たい結果は数式の結果として求めるため、分かっていても値としてセルに入力せず、先に数式を入れたセルを用意します。ゴール シークは数式から始める必要があると説明されています。また例では、変化させるセル（例では金利の欄）がまだ空のため0%と見なされた結果が先に表示され、この時点の値は無視して構わないとされています。

ここからは当社の整理です。

合計のセルを選び、数式バーに計算式が入っているか確かめます。帳票に表示される金額が入力値を変えると動くかを、作業用のコピーで確認しておくと、集計対象外のセルを選ぶ取り違えを防げます。共有中の原本でいきなり試算すると、ほかの担当者が途中の値を使うことがあるため、作業用の版を分けます。

変えてよい入力は、担当者から調整を任されている欄だけにします。合計に含まれる確定額や変更できない数量は、計算の前提として控えます。目標が税抜額か税込額か、円単位か千円単位かも、合計の数式と同じ基準にそろえます。目標値だけを別の単位で入力すると、合計が意図した金額と合いません。

2．ゴール シークの3つの欄に入れる情報

MicrosoftのWindows向け案内では、［データ］タブの［予測］グループで［What-If 分析］を選び、［ゴール シーク］を開きます。［セルの設定］には数式を含むセルの参照、［目標値］には数式で得たい値、［変化させるセル］には調整するセルの参照を入れ、［OK］を選びます。

同じページの適用先には、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 と、Excel for Microsoft 365 for Mac などのMac版が挙がっています。Mac版（macOS）の欄では［予測］グループの記載がなく、［データ］タブで［What-If 分析］、［ゴール シーク］の順に選びます。3つの欄に入れる内容と［OK］で実行する流れは、Windowsの欄と同じです。

画面の欄入れる情報入れる前に見る箇所
セルの設定合計の数式があるセル参照範囲と合計の単位
目標値合計として求める数値金額の根拠、税や丸めの扱い
変化させるセル調整を許された1つの入力セル結果の数式から参照されること、変更前の値

離れた場所にセルがあるときは、セル番地に加えてシート名と欄名も控えます。合計が複数ある表では、帳票で使う合計と、確認用の小計を区別します。あとで追えるように、どのファイルの版で計算したかを入力の控えに添えます。

3．計算後に、金額と前提を別々に見直す

ゴール シークで結果が出たら、変化した入力の値と、合計の表示をそれぞれ確認します。画面に表示された合計が指定額に見える場合でも、金額が丸められて表示されていることがあります。セルの表示と、計算に使われる値を確認し、帳票で採用する端数処理と一致するかを見ます。Microsoftの操作例でも、ゴール シークで値が入ったセルは、最後に［ホーム］タブで表示形式（例ではパーセンテージ）と小数点以下の表示桁数を設定しています。表示の桁を整えた後も、採用する値は帳票の端数処理の決まりに合わせて別に決めます。

求めた値に小数が含まれるときは、その入力欄に小数を採用できるか担当者に確かめます。端数を調整する場合は、調整後の値を入れたときの合計を再計算し、目標額との差を控えます。計算で得た値と、実際に採用する値が異なるときは、差が生じた理由も分けて残します。

残す情報担当者に渡すときの照合先
目標額とその単位依頼を受けた文書や金額の管理表
数式セルと入力セル作業用ファイルのシート名と欄名
入力の変更前と計算結果作業用の版と計算後の控え
採用値とそのときの合計丸め方や数量の制限を確認した記録

4．目標に合わなければ、参照先と入力の条件を点検する

目標に近い結果が得られないときは、入力セルを一度変えて合計が動くか、合計の数式が別の集計範囲を指していないかを作業用のコピーで見直します。合計が動いても希望した額に合わない場合は、変化させる数値の取り得る範囲や、途中の数式にある条件と丸めを担当者に確認します。

Microsoftの案内では、ゴール シークで扱える変数入力値は1つです。複数の入力値を変える必要がある場合は、ソルバー アドインを使うよう案内されています。複数の入力も動かす必要がある場合は、先に動かしてよい欄と固定する欄を決めます。元の条件のままで目標に合わなかったときは、条件の変更を依頼元へ相談し、結果だけを使って金額を確定しないようにします。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□結果のセルに、値ではなく合計の数式が入っていることを確かめたか
□使っている版（WindowsかMacか）の欄で、ゴール シークを開く場所を確かめたか
□合計の数式が、変えてよい1つの入力セルを参照することを確かめたか
□目標値の根拠と、合計に使う単位・税・丸めの条件をそろえたか
□作業用のファイルと入力の変更前の値を控えたか
□求めた入力値と、表示される合計をそれぞれ確認したか
□採用する値を入れ直したときの合計と、目標額との差を確かめたか
□目標に合わない場合に見直す数式・前提と相談先を残したか
