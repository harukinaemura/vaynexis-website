Excelを開くたび外部リンクの更新確認が出るときの確認手順

要点

参照元と、そのデータを今も更新する必要があるかを確かめます。リンクの解除は参照元を使う数式を現在の値に変える操作なので、不要と判断できるまで解除を見送る方針で整理します。

公開：2026年11月5日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelのブックを開くたびにリンクの更新を尋ねられる小さな会社の担当者が、参照元と使われている箇所を調べ、更新・保留・解除を分けて確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 更新を選ぶ前に、参照元の用途を確かめる
  2. 一覧と使用箇所を照らして、必要な参照を見分ける
  3. 更新と解除を分け、解除前のコピーを残す
  4. 事務の引き継ぎでは、判断と確認先を並べる
  5. 確認が残るときは、数式以外と設定の影響も調べる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．更新を選ぶ前に、参照元の用途を確かめる

Microsoft サポートの「ブックのリンクを管理する」の適用先は、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 です。ページには Windows と Web の手順の切り替えがあり、この記事の画面の名前は Windows の手順の記載によります。

ここで扱うのは、Excel の数式から別のブックのセルを参照するリンクです。更新しない場合は、以前の情報が使われます。表示された金額や集計結果を業務で使う前に、その表がいつの情報を必要としているかを整理します。

外部コンテンツの有効化は、信頼できる発行元からのものだと確認できる場合に限る扱いです。受け取った表の用途が分からないときは、先に作成者や管理担当者へ確認する流れがよいです。確認する内容は、表を作った目的、参照元の保管場所、今後も更新して使う予定の有無です。

2．一覧と使用箇所を照らして、必要な参照を見分ける

［ブックのリンク］ウィンドウは、［データ］＞［クエリと接続］＞［ブック リンク］を選択して開きます。一覧から対象のブックを選び、［次を検索］で使われている箇所をたどります。参照元の名前だけを見るより、どの欄の値に使われているかを併せて調べると、担当者に尋ねる内容が具体的になります。

たとえば、提出用の表なのか、日々更新する管理用の表なのかを確認します。用途が不明なまま、ファイル名が古そうだという理由だけで不要と判断することは避けたいところです。必要性を尋ねるときは、参照元の名前と、使われているシートや欄を一緒に伝えるとよいです。

Microsoft サポートの案内では、従来の［リンクの編集］コマンドは［ブックのリンク］コマンドに置き換えられ、従来のコマンドはリボンのカスタム グループに追加して使うこともできる、とされています。手順書の呼び方が手元の画面と異なるときは、同じ操作かを確かめてから進めます。

必要かどうかが決まらない参照は、そのまま保留にします。見つけた参照を順に消す進め方では、残すべき情報まで失わないかという確認が抜けてしまいます。

3．更新と解除を分け、解除前のコピーを残す

必要と確認できた参照は、一覧で対象のブックを選び、［最新の情報に更新］から更新できます。更新後は、参照元の該当箇所と、利用する表の値を見比べます。変わるはずの欄だけでなく、変わってほしくない欄も確認の対象にするとよいです。

Microsoft サポートの案内では、ブックのリンクの解除は元に戻すことができないため、必要に応じてバックアップとしてリンク先ブックのバージョンを保存するとされています。この記事では、解除を検討する前にコピーを保存する進め方にします。コピーの置き場所も作業記録に残し、見た目が同じ表を取り違えないよう、確認用と通常利用するものを区別します。

そのうえで、今後も参照元に合わせて値を変える必要があるかを担当者と確かめます。今回使う値が合っていることと、今後の更新が不要なことは、分けて考えると判断しやすくなります。担当者の返答がない参照は、解除せず確認待ちにしておきます。

作業後は保存した表を開き直し、確認対象にした欄の値を見直すとよいです。引き継ぎ相手にも、その値を見て判断できる状態で渡します。未解決の参照については、照会先と返答待ちの内容を残し、途中の状態を完成版として配らないよう整理します。

4．事務の引き継ぎでは、判断と確認先を並べる

ここからは当社の整理です。

引き継ぎには、調べた結果と、まだ決まっていないことが分かる短い表を残す方法があります。確認した人の名前だけで終わらず、何を根拠に必要・不要と判断したかも書き添えます。

参照元の用途整理した状態次に確かめること
継続して使う集計の元表必要管理担当者に保管場所と更新担当を確認
過去の配布資料の元表不要か確認中作成者に今後の更新予定を確認
用途が分からない表不明引き継ぎ元に使用目的と確認先を照会

確認が済んだ参照と、照会中の参照を混ぜずに残すのが狙いです。返答を受けた後に、判断の内容と確認先を追記します。画面の表示が消えたことだけを引き継ぐと、残した理由や、解除した理由が後から分かりにくくなります。

5．確認が残るときは、数式以外と設定の影響も調べる

Excel では、接続できていない参照元からは更新できません。参照元を開けないことだけで、不要な参照とは判断せず、管理担当者に現在の保管場所を尋ねます。

Microsoft サポートの案内では、ブック内のすべてのブックのリンクを自動的に検索する方法はなく、数式、定義された名前、オブジェクト（テキスト ボックスや図形など）、グラフ タイトル、グラフ データ系列を個別に確認する必要があるとされています。画面上の表だけを見て、参照がなくなったと判断するのは控えたいところです。

Microsoft Learn のトラブルシューティングの記事では、選択したオプションに関係なく、ブックに無効なリンクまたは破損したリンクが含まれている場合でも、メッセージが表示されるとされています。確認が続く場合は、表示された文面、参照元の名前、調べ終えた範囲をそろえて、作成者や管理担当者に渡します。

ブックを開いたときの扱いは、［ブックのリンク］ウィンドウの右上隅にある［更新設定］で、［更新を要求する］［常に更新］［更新しない］のいずれかを選べます。このオプションはブックのすべてのユーザーに影響し、リンクを更新せず、メッセージを表示しないことを選んだ場合は、ブックのユーザーはデータが最新ではないことを認識できない、とされています。通知を消すことを作業の完了条件にせず、必要な値が確認できたか、未判断の参照が残っていないかを見届けます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□表の用途と、今後も値を更新する必要があるかを確認したか
□参照元の名前と、使われている箇所を控えたか
□参照元を信頼できるか、管理担当者に確認したか
□必要・不要・不明の判断と、確認先を記録したか
□解除を検討する前に、元の状態のコピーを保存したか
□作業後の値を参照元と見比べ、未判断の参照を引き継いだか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月4日）

  • ブックのリンクを管理する：適用先、ウィンドウの開き方、使用箇所の検索、更新、更新設定とその影響、解除、従来の操作名、数式以外の確認箇所
  • Excel でのブックのリンクの管理とストレージの説明：別のブックのセルを数式で参照するリンクの説明。
  • Excel でリンクされたブックの更新に関するスタートアップ メッセージを制御する方法：更新しない場合の情報、無効・破損したリンクがあるときのメッセージ
  • Office ドキュメントで外部コンテンツをブロックまたはブロック解除する：信頼できる発行元かを確認してから有効にする条件。
