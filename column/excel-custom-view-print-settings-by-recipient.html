Excelで提出先別の余白や印刷設定を保存して切り替えるには

要点

提出先ごとの余白や印刷設定は、ユーザー設定ビューに保存して切り替えられます。提出先と対象の表が分かる名前で登録し、呼び出した後に紙に出る形を確かめる流れにします。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、提出先によって余白や用紙の向きが変わるExcelの表を毎回設定し直さずに使い分けたい小さな会社の担当者が、ユーザー設定ビューへの保存と呼び出し、印刷前の表示での照合までをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 保存できる設定と利用条件を先に確認する
  2. 提出先の形に整えてから名前を付ける
  3. 登録した名前を選び、対象のシートまで確認する
  4. 呼び出した結果を印刷前の表示で照合する
  5. 引き継ぎには提出先と設定の違いを残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．保存できる設定と利用条件を先に確認する

確認日：2026年11月13日

ユーザー設定ビューのヘルプの適用先は、Excel for Microsoft 365・2024・2021・2019・2016 です。この記事で詳しい設定まで扱う対象は、Excel for Microsoft 365、Excel 2024、Excel 2021です。［ページ設定］ダイアログのヘルプの適用先がこの3つだからです。ユーザー設定ビューとページ設定のヘルプの適用先に Mac 版・Web 版は挙がっておらず、この手順の対象に含めません。余白のヘルプにも、Excel for the web ではページ余白の設定はサポートされていない、とあります。使う人の環境を引き継ぎメモに残し、別の環境でも同じ入口があると見込んで進めないことが大切です。

ブック内のワークシートにExcelの表が含まれている場合、ユーザー設定ビューはブックのどこでも使用できません。ヘルプの日本語版は「Excel の表」と書いており、どの範囲までを指すかは確かめていません。対象の表だけを見て判断せず、ほかのシートにあるものも確認対象にします。使えないからといって元の表をすぐ作り替えず、どこで使っているかを担当者と整理するとよいです。

シートビューについて、ヘルプは、他の人に邪魔されることなくワークシートにカスタマイズされたビューを作成できる方法と説明しています。シートビューは、SharePoint または OneDrive の場所に格納されているドキュメントでのみ使用できる、ともあります。この記事では、提出する紙の形を名前で呼び分けることに絞ります。

2．提出先の形に整えてから名前を付ける

保存の前に、提出先から受け取った指定を読み、変える項目と共通のまま使う項目を分けます。余白だけ違うのか、縦横の向きも違うのかを曖昧にすると、登録名が正しくても中身の取り違えが残ります。

余白と紙の配置を整える

対象のワークシートを選び、［ページ レイアウト］タブの［ページ設定］にある［余白］を開きます。定義済みの余白は［標準］［広い］［狭い］から選べ、個別の寸法は［ユーザー設定の余白］の［上］［下］［左］［右］で入力します。

ページのレイアウトや印刷の詳しい設定には、［ページ設定］ダイアログを使います。［ページ］タブでは、主な項目として向き、印刷時の拡大・縮小、用紙サイズを設定できます。

ヘッダーとフッターの余白は、上と下の余白より小さく、プリンターの最小余白以上にする必要があります。紙の端から本文までの空きと、見出しなどを置く位置を混同せず、本文と重なっていないかを見るとよいです。

今の状態を登録する

保存したい表示・印刷設定に整えた後、［表示］の［ブック ビュー］から［カスタム ビュー］、［追加］へ進みます。［名前］ボックスにビューの名前を入力したら、［ビューに含む］で、含める設定のチェック ボックスをオンにします。ヘルプの日本語版は、機能を「ユーザー設定ビュー」、手順の画面名を［カスタム ビュー］と書いており、表記が揺れています。お使いの画面での表記は確かめていません。登録する名前は、提出先と対象の表を見分けられるものにします。登録前の状態を整える工程と、名前を付ける工程を続けて行うと、途中の形を登録する取り違えを避けやすくなります。次の提出先についても、指定に合わせて整えてから別の名前を付ける流れにします。

ワークシートで定義した余白は、ブックの保存時にそのシートと共に保存されます。登録作業の区切りではブックも保存し、次の担当者へ渡すファイルをそろえるとよいです。

3．登録した名前を選び、対象のシートまで確認する

呼び出すときは、［ビュー］で目的の名前を選んで［表示］を選択します。

ユーザー設定ビューを適用できるのは、ユーザー設定ビューを作成したときにアクティブだったワークシートのみ、とされています。別のワークシートで作成したビューを選ぶと、そのワークシートが自動で表示されます。呼び出した後は、余白の見た目だけでなく、対象の表に切り替わったかも確かめます。名前が似ているものを選び続けると、提出先は合っていても別の表を見ている可能性を見落としがちです。

公式ヘルプでは、ビューを識別しやすくするため、名前にアクティブなワークシートの名前を含める方法を挙げています。部署内でも、提出先だけで区別するか、表の名前も加えるかをそろえておくとよいです。

4．呼び出した結果を印刷前の表示で照合する

印刷前のプレビューのヘルプは「新しいバージョン」と「Web」の欄に分かれており、ここで挙げるのは「新しいバージョン」の欄の説明です。対象を選んで［ファイル］、［印刷］の順に開くと、プレビューと印刷オプションを表示できます。次のページや前のページを見るには、印刷プレビューの下部にある矢印を使うか、ページ番号を入力します。先頭の見出しだけで終わらず、末尾の注記や合計欄まで含めて照合する流れにします。

余白を見分けにくい場合は、印刷プレビューの右下にある［余白の表示］ボタンで境界を表示できます。提出先の指定と比べるときは、見た目の広さだけで済ませず、登録前に決めた項目と突き合わせるとよいです。

シートに色が含まれていても、カラー プリンターを使用していない限り、プレビューは白黒で表示されます。色が変わったように見えるときは、元の表を直し始める前に出力先も確認します。文字が小さすぎないか、紙に必要な情報が欠けていないかは、設定名が合っていることとは別に見る項目です。

5．引き継ぎには提出先と設定の違いを残す

ここからは当社の整理です。

名前の一覧だけを渡すと、どの指定を基にしたものかが後から分かりにくくなります。引き継ぎでは、提出先、対象の表、違いを設けた理由を短くまとめます。例では寸法を仮置きせず、提出先の指定と社内の用途を区別しています。

呼び分ける名前の例用途保存前に決める違い
提出用_月次表外部へ渡す紙相手から指定された余白と向き
社内確認用_月次表書き込みながら確認する紙記入欄の空きと読みやすさ

同じ表でも、提出用と確認用では残したい空きが違います。余白を広げたい理由が「先方の指定」なのか「社内で書き込むため」なのかをメモに残すと、後任者が見た目だけで直す場面を減らせます。変更の連絡を受けた際も、どの用途の形を見直すかをたどれます。

引き継ぎの確認では、渡す側が普段の操作を見せるだけでなく、受け取る側が名前を選び、提出先の指定と照合するところまで進めます。違いが出たら、その場で直した内容と残す課題を分け、古い指定が手元に残っていないかも点検するとよいです。

この作業を AI で減らすなら、提出先の指定を読み取る作業と、仕上がりを人が確認する作業を分けて洗い出します。事務作業への AI 活用を考える際も、判断を任せる範囲と、提出前に人が照合する項目を先に整理するとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□提出先の指定と、対象にする表を照合したか
□利用条件を調べ、ほかのシートも確認したか
□保存前に、余白・向き・用紙の指定を整えたか
□名前から、提出先と対象の表を見分けられるようにしたか
□呼び出した後に、意図した表が表示されたか
□印刷前の表示で、先頭から末尾まで欠けや重なりを確認したか
□引き継ぎ相手が同じ形を呼び出せるか確かめたか
