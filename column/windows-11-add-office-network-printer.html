Windows 11で社内プリンターを追加する｜候補と出力先の照合

要点

Windows 11でネットワーク上のプリンターを追加するときは、プリンターとPCの接続先を確認し、［設定］の［Bluetooth & デバイス］から［プリンター & スキャナー］を開きます。既に登録されていないことを確かめ、［デバイスの追加］で目的の機器を選びます。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、Windows 11に社内のネットワーク プリンターを追加したい小さな会社の担当者が、同じネットワークかどうか、登録済みの一覧と追加の候補、ドライバーと実際の出力先を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 使う機器と接続先を確認する
  2. 登録済みの一覧と新しい候補を分けて見る
  3. 候補にないときは管理担当と照合する
  4. 登録した機器と実際の出力先を照らす
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．使う機器と接続先を確認する

確認日：2026年11月10日。

この記事で扱うのは、Microsoftの案内「Windows でプリンターを追加またはインストールする」のうち Windows 11 の欄です（同じページに Windows 10 の欄もあります）。ネットワーク プリンターやワイヤレス プリンターを入れる前の確認として、案内はプリンターの電源が入っていることと、PC と同じネットワークにつながっていることを挙げています。ワイヤレスの機器なら同じワイヤレス ネットワークにいるかを見ます。機器をネットワークにつなぐ方法そのものは、プリンターのマニュアルか製造元の Web サイトで調べるよう書かれています。

ここからは当社の整理です。

設置場所、機器の名前、社内で呼んでいる名称を管理担当に確認します。来客用の接続先がある場合は、使用するプリンターに届く接続かを確かめます。

2．登録済みの一覧と新しい候補を分けて見る

Microsoftの案内にある Windows 11 の手順は、次の順です。まず［スタート］＞［設定］＞［Bluetooth & デバイス］＞［プリンター & スキャナー］と進み、インストール済みの一覧に同じ機器が載っていないかを見ます。載っていなければ［プリンター & スキャナーの追加］の［デバイスの追加］を押し、近くの機器の一覧ができあがるのを待ちます（数分かかることがあります）。一覧に目的の機器が出たら、その横の［デバイスの追加］ボタンを押します。

候補に同じシリーズが並ぶときは、本体の型式だけで決めず、設置場所と社内管理の名前を照合します。候補が出るまで時間がかかる場合は、二重に操作せず表示を待ちます。

3．候補にないときは管理担当と照合する

Microsoftは、自動で見つからない場合に手動追加の選択肢を案内しています。Windows 11 の欄では、［プリンターが必要］の横にある［手動で新しいデバイスを追加］を選び、開いた［プリンターの追加］ウィンドウの指示に従います。手動で試してもインストールされない場合は、プリンター接続と印刷の問題を解決する記事の手順を使うよう書かれています。

同じページの注記では、一部の ARM PC（例として Copilot+ PC）で、プリンターの製造元から提供されたインストーラーを使うとプリンターを追加できない場合があるとされています。その場合は製造元のインストーラーではなくこの記事の指示に従い、製造元のガイダンスが異なる場合は製造元のガイダンスに従うよう書かれています。ARM PC かどうかは、［設定］＞［システム］＞［バージョン情報］の［デバイスの仕様］にある［システムの種類］で確かめます。

職場で指定された接続方法がある場合は、それを管理担当から受け取ります。似た名前の機器を試しに登録したり、他の人が使う設定を変更したりする前に、必要な機器を特定します。

Microsoftの案内では、追加済みの機器は同じ［プリンター & スキャナー］の一覧でその機器を選び、［削除］を押すと外せます。違う機器を追加してしまった場合は、一覧に残したままにせず、管理担当に伝えたうえで外します。

4．登録した機器と実際の出力先を照らす

追加が済んだら、Windows Update でドライバーが新しくなっているかも見ます。Microsoftの案内によると、追加の直後は機器の横に［ドライバーの検索］ボタンが出ることがあります。その間も印刷はできるはずですが、ドライバー一式がそろうまでは機能が落ちている可能性があり、ドライバーの入手先は Windows Update が最適とされています。

追加後は印刷画面から今回追加した機器を選び、社内で認められた方法で出力先を確認します。両面や用紙の選択など、業務で使う機能が印刷画面に出ているかも見ます。登録が完了したという画面と、目的の場所で出力を受け取れたことを分けて記録します。担当には、使用した接続先と登録名を伝えます。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□使う機器の設置場所と登録名を確認したか
□PCと機器のネットワークを照合したか
□登録済み一覧にないか確認したか
□ARM PC で、製造元のインストーラーではなく Windows の手順を使ったか
□候補がない場合の連絡先を確かめたか
□登録した機器と出力先を照合したか
□インストール後に Windows Update でドライバーを確かめ、［ドライバーの検索］が出ていないか見たか
□誤って追加した機器を一覧に残していないか
