Googleフォームの担当者を共同編集に加える手順と権限の確認

要点

担当者を共同編集に加えるには、フォームで共有アイコンを開き、編集者のアクセス権を共有します。追加前に、任せる作業と扱う情報の範囲を相手とそろえます。追加後は本人が作業できるかを確かめ、担当交代時には回答の保存先も確認対象に含めるとよいです。

公開：2026年11月4日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Googleフォームの作業を担当者に任せたい小さな会社の事務担当者が、共同編集者の追加と回答用シートの権限、担当交代時の解除を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 回答の依頼と、共同編集の依頼を分ける
  2. 共有画面で相手と「編集者」を選ぶ
  3. 回答用シートも、別の確認対象にする
  4. 依頼する作業と、確認の終わり方をそろえる

1．回答の依頼と、共同編集の依頼を分ける

製品の機能・操作の確認日：2026-11-04。以下の操作は、確認日に読んだ公式ヘルプに基づきます。

招待した共同編集者は、回答や回答の保存場所を含め、フォームのどの部分でも編集できます。

ここからは当社の整理です。

質問文の修正だけを依頼する場合も、相手に任せる範囲と、扱ってもらう情報を先にすり合わせるとよいです。「文面を見てもらう」という曖昧な依頼では、確認だけなのか、変更まで頼むのかが伝わりません。

「回答者に送信するリンクをコピー」は、回答を記入する相手へ渡すリンクを取得する操作です。担当者への連絡には、何の作業を依頼するのかを添えます。リンクを送ったという連絡と、共同作業を始められる状態になったという確認を分けておくと、引き継ぎ途中の行き違いを探せます。

2．共有画面で相手と「編集者」を選ぶ

  1. 対象を開く：Googleフォームで対象を開き、共有アイコンをクリックします。
  2. 相手を指定する：ユーザー名またはグループ名を入力します。
  3. 役割を選ぶ：下矢印をクリックし、「編集者」を選びます。
  4. 追加を確定する：内容を見直して「送信」をクリックします。

入力時は、表示された候補と依頼先が一致しているかを見直します。似た名前が並んだときも、急いで確定せず、相手と照合してから進めるとよいです。追加する相手は、所属だけで広げず、任せる作業を基準に整理します。

追加したあとは、依頼先の本人が対象を開き、合意した作業を行えるかを確かめます。「連絡した」「開けた」「作業できた」を別の状態として残す考え方です。確認のために変更を試す場合も、何を触ってよいかを事前にそろえておくと、意図しない変更を避ける手立てになります。

画面で操作の入口を見つけられないときは、表示されている項目と公式ヘルプを照らし合わせます。以前の操作メモだけで進めず、現在の画面を確認できる担当者へ相談する進め方が考えられます。

3．回答用シートも、別の確認対象にする

回答をスプレッドシートに保存すると、フォームとは別のファイルが作成されます。新しい回答用スプレッドシートを作成すると、フォームの共同編集者は自動的にそのシートへアクセスできるようになります。その後にフォームの権限を変えても、自動的には同期されません。アクセス権を変更・削除するときは、フォームとリンク済みシートを個別に更新します。

引き継ぎの記録には、作業対象と回答の保存先を別々に残すとよいです。「担当者を追加済み」とだけ書くより、どの対象で誰の利用を確認したかが伝わります。必要な情報に届くかという確認と、不要になった相手を外したかという確認も、同じ欄にまとめず区別します。

担当交代では、後任が作業できることと、前任者の利用を終えることを分けて扱います。交代日だけを伝えて終えるより、後任の確認が済んだ箇所、前任者を外す箇所、判断が残る箇所を明記するほうが、途中の状態を共有しやすくなります。

4．依頼する作業と、確認の終わり方をそろえる

社内の受付担当を交代する場面なら、相手の役割だけでなく、何を確かめたら引き継ぎを終えられるかを短く残します。

任せる作業依頼する相手引き継ぎで確かめること
質問文の修正新しい受付担当変更する文面と、相談が必要な文面を合意したか
受付内容の確認集計担当見る対象と、取り扱う情報の範囲を合意したか
担当交代後の整理管理担当前任者を外す対象と、変更後に確認する人を決めたか

表に書くのは、依頼の範囲と確認の担当です。表を作っただけで引き継ぎ完了とはせず、本人からの確認結果も添えます。開けたかどうかだけでは、依頼した作業を終えられるかまでは分かりません。

確認結果には、できたことと、止まっていることを短く残すとよいです。たとえば、対象は開けたものの、変更してよい内容の合意が済んでいないなら、その合意を残件として扱います。操作の問題と、業務上の判断待ちを分けると、次に誰へ相談するかが明確になります。

5．開けない場合と、担当を外す場合の確かめ方

フォームが開けない原因には、権限がない場合や、アクセス権のない別のアカウントでログインしている場合があります。相手から開けないと連絡があったときは、招待先と利用中のアカウントを照合するところから確認を進めるとよいです。送った宛先が合っているかだけでなく、相手がどの対象を開こうとしているかも確認します。

仕事用・学校用のアカウントでは、組織が外部とのファイル共有を制限している場合があります。原因が分からないまま共有範囲を広げず、管理担当へ現在の制限を確認する進め方が考えられます。相談時は、対象、招待先、開けなかったときの表示をまとめると、確認すべき場所をそろえやすくなります。

回答用シートの共有を停止する際は、共有画面で対象者の名前の横にある下矢印をクリックし、「アクセス権を削除」を選択して「保存」をクリックします。変更後は、作業前に決めた対象と照合して結果を記録します。外す相手の確認に加え、引き続き作業する相手にも支障がないかを確かめて区切るとよいです。

公開・共有の前に、この表で確かめます。

確認確かめること
□回答を頼む相手と、共同作業を頼む担当者を分けたか
□追加する相手と、任せる作業の範囲を合意したか
□確定する前に、選択した相手と役割を確認したか
□依頼先の本人が対象を開き、作業できるか確認したか
□回答の保存先も、別の確認対象に含めたか
□担当交代で外す対象と、変更後の確認結果を記録したか
