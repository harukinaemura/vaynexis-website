PowerPointの配布資料、読み上げる順番を直す手順と確認

要点

PowerPoint では、［読み上げ順序］ウィンドウに、スクリーン リーダーが読み取る順序でオブジェクトが並びます。この一覧を、聞いて理解できる順番に並べ替えます。飾りは装飾として読み上げ順序から外し、部品の多い図はグループ化して1つの単位にする方法もあります。配る前には、音声で聞いて説明のつながりと抜けを確かめ、画面上でも重なりを見直します。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、PowerPoint の配布資料をスクリーン リーダーで聞いたときの順番を直したい小さな会社の担当者が、［読み上げ順序］ウィンドウでの並べ替えと、装飾・グループ化・代替テキスト、音声での確認を進める流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象の版を確認し、直したいスライドの一覧を開く
  2. 一覧の番号を見て、読む対象だけを並べ替える
  3. 先に聞きたい内容を短い表にして考える
  4. 順序を変えた後は、重なりと読み飛ばしを見分ける
  5. 最後に音声で聞き、意図した説明と照らし合わせる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象の版を確認し、直したいスライドの一覧を開く

確認日：2026年11月11日。

Microsoft サポートの「[読み上げ順序] ウィンドウを使ってスライドを読みやすくする」の適用先は PowerPoint for Microsoft 365、PowerPoint 2024、PowerPoint 2021 で、Mac は挙げられていません。以下は、この対象を前提にしたWindowsでの操作と確認の流れです。引き継ぎ時には、作業する端末の版もそろえておくと、同じ説明をたどりやすくなります。

プレゼンテーションを開き、［レビュー］から［アクセシビリティ チェック］を選びます。［警告］で［読み上げ順序の確認］を選び、一覧を開きます。対象のスライド番号の横のドロップダウンから［オブジェクトの順序の確認］を選ぶと、［読み上げ順序］ウィンドウが開きます。

同じヘルプは、スライド上のオブジェクトの読み上げ順序が、オブジェクトを空間的に並べる一般的な方法の 1 つと一致しない場合に、アクセシビリティ チェックがここにスライドを表示するとしています。一覧に出るのはこの条件に当たるスライドなので、出ないスライドの順番が意図どおりかは、最後の音声の確認で見ます。

最初に、先に聞く必要がある見出しと、後から補足する説明を分けます。画面を指しながら話せば伝わる関係も、音声では前後のつながりが手掛かりです。見た位置だけを基準にせず、内容の意味に沿って読み進められるかを考えます。

2．一覧の番号を見て、読む対象だけを並べ替える

一覧の各オブジェクトの横の数字は、読み上げる順序の位置を表します。番号を追いながら、「何の説明か」「何が変わるか」「何をするか」がつながる並びかを見ます。途中の注記だけを先に聞いても、何に対する注意なのか分からない並びは見直しの対象です。

一覧から 1 つ以上の項目を選び（複数は Ctrl＋クリック）、上か下へドラッグするか、上矢印の［上へ移動］または下矢印の［下へ移動］で位置を変えます。直す際は、説明の前後関係が崩れている箇所から動かし、移動後の一覧を先頭から読み直します。見出しと説明の間に別の話題が挟まっていないかも見ます。

項目の横のチェックボックスをオフにすると、そのオブジェクトは装飾として読み上げ順序から外れます。装飾にした項目は一覧で位置を変える必要がなく、横の番号が消えます。

同じヘルプは、装飾的なオブジェクトは視覚的な興味をひくものの情報的ではないとし、様式的な罫線を例に挙げています。読む内容と見栄えのための飾りを区別する際は、なくても同じ意味が伝わるかを考えます。注意の意味を持つ表示や、説明を理解する手掛かりまで除いてしまわないよう、見た目の単純さだけで判断しません。

部品の多い図は、グループ化でまとめる方法もあります。同じヘルプは、多数のオブジェクトで構成される複雑な図がある場合はオブジェクトを論理単位にグループ化し、スクリーン リーダーのユーザーはグループ化された単位を読み取れるとしています。一方で、オブジェクトにアニメーション効果がある場合、グループ化した後はアニメーションは保持されないと注意しています。説明会でアニメーションを使う資料では、グループ化の前にどちらを優先するかを決めます。

3．先に聞きたい内容を短い表にして考える

ここからは当社の整理です。

事務の案内資料なら、聞き手が内容を理解して行動できる順を先に書き出すと、移動先を考えやすくなります。例えば、備品の受取場所の案内では、窓口の注意事項から始めるより、何の案内かを示してから場所と手順を伝える流れを考えます。

内容の役割並びを考える際の観点
表題何についての案内かを先に伝える
受取場所の説明どこへ向かう話かを理解できる位置に置く
受付で伝える内容場所の説明を聞いた後に必要な行動を示す
補足の注意関係する説明の後で意味がつながる位置に置く
意味を持たない飾り読む内容に含める必要があるかを見分ける

表の行をそのまま資料に増やすのではなく、前の説明を知らなければ理解できない言葉が先に出ていないかを見ます。

担当者に渡すメモにも、「順番を直した」だけでなく、「補足は関係する説明の後に置く」といった意図を残します。文章の追加や差し替えがあっても、なぜその並びにしたのかを考え直せます。

4．順序を変えた後は、重なりと読み飛ばしを見分ける

［読み上げ順序］ウィンドウのヘルプの注は、オブジェクトの順序を変更すると、オブジェクトが重なっている場合のスライドの表示に影響する場合があるとしています。変更後に意図した外観でなくなった場合は、Ctrl＋Zキーで元に戻します。

移動の直後には、文字が隠れた箇所や、説明と背景の関係が変わった箇所を見ます。順番だけを見て作業を終えず、変更した部分の外観もその場で確かめると、どの移動で変化したかを追いやすくなります。

同じヘルプは、番号のないオブジェクトは装飾用とマークされているため、スキップされるとしています。音声で必要な説明が抜けたときは、順番をさらに動かす前に、読む対象に含めたつもりの内容を一覧で見直します。「後で読まれる」のか「読まれない扱いなのか」を分けて考えることが切り分けの手掛かりです。

同じヘルプは、代替テキストとは、スライド上のビジュアル アイテムの意味や文脈を伝える説明的なテキストで、スクリーン リーダーが読み上げるとしています。テキストを含むテキスト ボックスおよび図形には代替テキストを追加する必要はないものの、他のすべてのオブジェクトには代替テキストが必要とし、［読み上げ順序］ウィンドウでは代替テキストが必要な項目の横に警告サインが表示されるとしています。読む位置は合っていても説明が伝わらないときは、並びの問題と、内容の説明の問題を分けて見直します。順序の変更だけで解決したと判断せず、聞こえた言葉が周囲の説明につながっているかを見ます。

5．最後に音声で聞き、意図した説明と照らし合わせる

Microsoft サポートのアクセシビリティの案内では、ナレーターを起動するには、Ctrl キーと Windows ロゴ キーを押しながら Enter キーを押すとしています。同じ案内では、F6キーで青い四角形のフォーカスをスライドのコンテンツ領域へ移し、Tabキーで要素を移動して、必要に応じて順序を修正するとしています。

ナレーターの付録 B は、日本語 106 キーボードでは、挿入キーと非変換キーが既定のナレーター キーとしています。「PowerPoint でスクリーン リーダーを使ってプレゼンテーションを作成する」では、標準表示でナレーターに要素の内容を読み取らせるには SR キー（ナレーター キー）を押しながら R キーを押し、連続読み上げを停止するには Ctrl キーを押すとしています。音声の確認では、見出しの後に対応する説明が続くか、補足だけが先に出ないか、必要な内容が抜けていないかを聞き取ります。画面を見て補わず、聞こえた内容だけで関係が分かるかを意識します。

「スクリーン リーダーを使って PowerPoint でプレゼンテーションを表示する」では、Windows のスライド ショーは Shift＋F5 キーで現在のスライドから開始できるとしています。作成のヘルプでは、スライド上のオブジェクトを読む場合は、ナレーターのスキャンモードをオンに切り替えるとしています。スライド ショー ビューでは、下方向キーを押してオブジェクト間を移動します。

聞いて分かりにくかった場所は、どの説明の前後でつながりが切れたかを記録します。引き継ぎでは、修正した箇所と、音声で確認した箇所を区別して残します。資料を配る前の確認は、一覧の並び、聞こえた内容、変更後の外観を照らし合わせて終えます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□何の案内かを、補足より先に理解できる並びにしたか
□見出しの後に、それに対応する説明が続くようにしたか
□後から補う注意を、意味の通じる位置に置いたか
□読む必要のある内容を、飾りと取り違えて除いていないか確認したか
□グループ化した図で、アニメーションの扱いを決めたか
□代替テキストが必要な項目の警告サインが残っていないか確認したか
□並べ替えた箇所で、文字や図の重なりが変わっていないか確認したか
□音声で聞き、必要な説明の抜けと前後関係を確認したか
□変更の意図と、音声で確かめた箇所を引き継ぎ用に残したか
