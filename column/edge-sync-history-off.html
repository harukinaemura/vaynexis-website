Edgeの「同期」で履歴だけ別のPCへ渡さないには

要点

Edge の同期では、同期する機能とデータの種類ごとに、オンとオフを切り替えられます。［その他のオプション］から［設定］、［プロファイル］、［同期］と進み、一覧の右側にあるトグルで切り替えます。 管理者向けの Microsoft の文書でも、同期できるデータとして「履歴」が挙げられ、ユーザーはサポートされている各データ型の同期をオンまたはオフにできると書かれています。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

同じ Microsoft アカウントで、事務所のパソコンと持ち出し用のノートパソコンの両方の Edge にサインインしていると、閲覧の履歴もほかのパソコンに渡ります。お気に入りやパスワードの同期は続けたまま、履歴の同期だけを止めるときの手順と注意を、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．サインインすると何が渡るか

確認日：2026年11月16日。

対象は、Windows のパソコンで使う Microsoft Edge で、同じアカウントで複数のパソコンにサインインしている場合です。履歴の削除の手順は扱いません（理由は後で書きます）。

Microsoft のヘルプによると、サインインすると、Edge はそのアカウントで使うデバイスの間で、お気に入り、パスワード、履歴、拡張機能、設定、開いているタブ、オートフィル フォームのエントリ（名前、住所、電話番号など）、支払い情報、その他のデータの種類を同期します。

お気に入りやパスワードは、どのパソコンでも同じものが使えると便利です。一方で履歴は、別のパソコンで何を見たかがそのまま並ぶので、場面によっては困ります。たとえば、来客の前で画面を映すノートパソコンや、ほかの人と一緒に使うパソコンに、事務所で調べた取引先の情報や、個人的に見たページの履歴まで出てくるのは避けたいところです。

2．履歴の同期だけを止める

  1. Edge で［その他のオプション］を選びます。
  2. ［設定］、［プロファイル］、［同期］の順に選びます。
  3. 同期に使える機能とデータの種類の一覧が出たら、履歴の項目の右側にあるトグルを選んでオフにします。

ほかの項目のトグルはそのままにしておけば、お気に入りやパスワードの同期は続きます。止めたいのが「どのページを見たか」だけなら、ここまでで足ります。切り替えた後は、日を改めて、もう一方のパソコンで新しく開いたページが履歴に出てこないかを見ておくと安心です。

履歴の項目の近くには、開いているタブの項目もあります。管理者向けの文書でも、タブを開く（開いているタブ）と履歴は別のデータ型として並んでいます。 「ほかのパソコンで今開いているページが見えるのも困る」という場合は、こちらも合わせて見直します。ただ、ヘルプには、お気に入りの同期を選ぶと、以前に残しておいたすべてのタブも同期されるという注意もあります。 タブの見え方まで気にするなら、どの項目がどのデータに関わるかを、一覧の名前を読みながら一つずつ確かめます。

3．履歴を「消して」解決しようとしない

履歴の同期を止める前に、渡ってしまった履歴を消したくなるかもしれません。ただ、ヘルプには、サインイン中にデータを削除して同期すると、同期されたすべてのデバイスから削除されるという警告があります。 事務所のパソコンで「ノートパソコンに出る履歴を消したい」と思って消すと、事務所のパソコンの履歴まで消えるおそれがある、ということです。

ここで扱うのは、これから先の履歴を渡さないための切り替えだけです。すでに渡った履歴をどうするかは、消える範囲を理解したうえで、別に判断します。

4．全部の同期を止めたいときは別の操作

履歴に限らず、そのパソコンでは何も同期したくない、という場合もあります。ヘルプには、データの同期を停止する場合は、［設定など］、［設定］、［プロファイル］、［サインアウト］の順に進んで、Edge からサインアウトする必要があると書かれています。 履歴だけを止めるトグルとは別の操作なので、目的に合わせて選びます。

5．会社が管理しているパソコンの場合

職場のアカウントで Edge にサインインしている場合、同期の設定を会社の管理者が決めていることがあります。管理者向けの文書には、データ同期を無効にする SyncDisabled や、同期から除外するデータ タイプの一覧を構成する SyncTypesListDisabled などのグループ ポリシーが挙がっています。 トグルが思うように切り替えられないときは、自分で何度も試すより、社内でパソコンを管理している人に相談します。相談するときは、どのパソコンで、どの項目の同期を止めたいのかを具体的に伝えると、話が早く進みます。

6．パソコンごとの使い分けを決めておく（架空の例）

同じアカウントで何台も使う職場では、どのパソコンで何を同期するかを決めておくと、あとで迷いません。
