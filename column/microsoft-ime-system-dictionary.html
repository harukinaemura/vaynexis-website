Microsoft IMEの「システム辞書」はどこで切り替える？

要点

Microsoft のヘルプには、システム辞書のオン・オフは、Microsoft IME 設定の［ラーニングと辞書］にあるシステム辞書で切り替えられると書かれています。 Microsoft IME 設定は、タスク バーのシステム トレイ領域にある IME オプション アイコンを右クリックし、［設定］を選ぶと開けます。 自分で言葉を登録するユーザー辞書や、予測入力の候補に使う辞書の設定は、別の項目です。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Microsoft IME の設定には「辞書」と名の付く項目がいくつもあり、システム辞書のオン・オフを探しているうちに、ユーザー辞書や予測入力の画面に迷い込みがちです。Windows 11 で Microsoft IME 設定を開き、［ラーニングと辞書］のシステム辞書にたどり着くまでの道順と、似た項目との違いを、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  3. ［ラーニングと辞書］でシステム辞書を切り替える
  4. ユーザー辞書との違い

1．「辞書」と名の付く項目は3か所ある

確認日：2026年11月16日。

対象は、Windows 11 の Microsoft IME（日本語）です。ユーザー辞書への言葉の登録のしかたと、予測入力の入力履歴の設定は扱いません。

「IME の辞書をオフにして」と頼まれても、設定の画面を開くと、似た名前の項目がいくつも見つかります。ヘルプの記述を並べると、辞書に関わる項目は次の3か所に分かれています。

置き場所項目ヘルプにある内容（要約）
ラーニングと辞書システム辞書システム辞書のオン・オフを切り替える
ラーニングと辞書ユーザー辞書ツール新しい単語を手動で IME 辞書に追加する
全般 → 予測入力システム辞書を使用します予測入力で提案される候補のカスタマイズの一つ

今回探しているのは、表の1行目です。2行目は自分で言葉を足すための道具で、3行目は予測入力の候補の出し方に関わる項目です。名前が似ているので、何をしたいのかを先に決めてから画面を開くと迷いません。たとえば、社内で「変換で社名が出ない」と言われたらユーザー辞書、「入力の途中に昔の言葉が候補に出る」なら予測入力、「システム辞書を切り替えて」と項目の名前で頼まれたときだけ［ラーニングと辞書］、というように読み替えます。頼まれた言葉と画面の項目が合っているかを、操作の前に一度確かめるのが近道です。

2．Microsoft IME 設定を開く

ヘルプには、Microsoft IME 設定を開く方法が2つ載っています。

  • タスク バーから：タスク バーのシステム トレイ領域にある IME オプション アイコン（「あ」や「A」の表示）を右クリックし、［設定］を選びます。
  • 設定アプリから：［スタート］から［設定］、［時刻 & 言語］、［言語 & 地域］へ進みます。［言語］で日本語の横にある省略記号を選んで［言語オプション］を開き、［キーボード］で［Microsoft IME］の横にある省略記号から［キーボード オプション］を選びます。

ふだんはタスク バーからのほうが早く着きます。タスク バーにアイコンが見当たらないときは、設定アプリからの道を使います。

3．［ラーニングと辞書］でシステム辞書を切り替える

Microsoft IME 設定を開いたら、［ラーニングと辞書］を選びます。システム辞書のオン・オフは、ここにあるシステム辞書で切り替えます。

同じ［ラーニングと辞書］には、ほかにも大事な項目があります。一つは［この PC で入力した内容に基づいて入力精度を向上させる］で、入力した内容から入力の精度を上げる機能のオン・オフを切り替えます。 もう一つは、ユーザー辞書ツールを開く入口です。 システム辞書を探して開いた画面で、隣の項目まで触ってしまわないよう、一つずつ名前を読んでから操作します。

4．ユーザー辞書との違い

ユーザー辞書は、自分で新しい単語を IME の辞書に足すためのものです。ヘルプでは、［ラーニングと辞書］でユーザー辞書ツールを開く方法と、タスク バーの IME オプション アイコンを右クリックして［Wordの追加］を選ぶ方法の2つが挙がっています。

取引先の社名や、社内でしか使わない製品名が一度で変換されないときに使うのは、こちらです。システム辞書のオン・オフを変えたときに、自分で登録した言葉が増えたり減ったりするかは、ヘルプに記述がありません。変換の様子が変わったら、ユーザー辞書の側も見て切り分けます。

5．予測入力の「システム辞書を使用します」との違い

もう一つ紛らわしいのが、予測入力の設定です。ヘルプには、提案された候補は［Microsoft IME 設定］の［全般］、［予測入力］でカスタマイズでき、その項目として、入力履歴を使用する、システム辞書を使用する、提案サービスを使用する、が並んでいます。

こちらは、入力の途中に出る予測候補の出し方に関わる項目です。「予測候補に出てくる言葉を減らしたい」のか、「システム辞書そのものを切り替えたい」のかで、触る画面が変わります。前者なら［全般］の［予測入力］、後者なら［ラーニングと辞書］です。

6．切り替える前と後にしておくこと

システム辞書の切り替えは、毎日の変換に関わります。共用のパソコンや、複数の人が同じ設定で使うパソコンでは、黙って変えると「急に変換が変わった」と戸惑う人が出ます。

すること（架空の例）中身
変える前にどの画面のどの項目を、なぜ変えるかを書き留める
変えた直後にふだんよく打つ言葉をいくつか入力して、変換を確かめる
戻すときのために元のオン・オフの状態を書き残す

パソコンの設定の変更は、だれがいつ変えたかが残りにくい作業です。社内の作業を一度洗い出すときは、業務棚卸しチェックシート（エクセル・CSV）を使うと、こうした細かな作業も1行ずつ書き出せます。
