Wordのハイフネーションを段落ごとに解除し、英単語の分割を止めるには

要点

選択した本文の英単語の分割を止めるには、対象の段落を選び、［段落］の設定で［ハイフネーションしない］を選びます。まず直したい本文の範囲を決め、変更後は英単語のつながりと前後の行の収まりを見比べます。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、Wordで英単語の分割を止めたい小さな会社の担当者が、対象の段落とハイフネーションを解除した後の行の収まりを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象の版と、設定する本文を決める
  2. 段落を選んで、分割しない設定にする
  3. 変更前後は、単語と行の収まりを分けて見る
  4. 直り方が意図と違うときの確認順
  5. 引き継ぎには、対象と仕上がりを残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象の版と、設定する本文を決める

確認日：2026年11月15日。

この記事で扱う操作は、Microsoft の日本語ヘルプが Windows 版向けに示している手順で、適用先は Word for Microsoft 365、Word 2024、Word 2021 です。同ヘルプは、Mac 版と Web 版では手順とオプションが異なる場合があるとしています。

Microsoft の「ハイフネーションを調整する」でも、選んだテキストをハイフネーションの対象外にする操作が案内されています。文書を開いたら、変更したい箇所と、そのまま残したい箇所を先に見分けます。全文をまとめて直すかどうかは別に考え、今回は英単語の分割を止めたい本文に対象を絞ります。

2．段落を選んで、分割しない設定にする

操作は次の順です。

  • 分割を止めたい本文を含む段落を選択し、必要な範囲に応じて複数の段落を選びます。
  • Microsoftの案内に沿って、［ホーム］タブの［段落］ダイアログボックス起動ツールを選びます。
  • ［改ページと改行］タブを開きます。
  • ［書式設定］の［ハイフネーションしない］を選びます。
  • ［OK］を選んで設定を確定します。

手順を追うときは、目立つ英単語だけに気を取られず、直したい本文のまとまりを確認するとよいです。長い説明の途中だけを見ていると、前後にも同じような分割があるのかを見落としがちです。設定前に対象の先頭と末尾を見ておくと、あとで見比べる範囲がはっきりします。

3．変更前後は、単語と行の収まりを分けて見る

ここからは当社の整理です。

仕上がりの確認は、英単語が途中で分かれていないかを見ることから始めます。その後で、行末の空き、前後の行の読みやすさ、本文と見出しの位置関係を見ます。単語がつながったことと、文書の見た目が整ったことを、同じ確認で済ませないのがポイントです。

特に、行末の空きだけを見て文字を足したり、英単語そのものを書き換えたりすると、内容の確認と見た目の調整が混ざってしまいます。綴りや文章の意味は元の記載と照合し、表示を整えるためだけに内容を変えない方針にするとよいです。読みやすいかどうかは、行の右端だけでなく、文を続けて読んで判断します。

確認する場面対象の決め方仕上がりの見方
英文の案内文が行末で分かれる分割を止めたい本文の段落を対象にする元の綴りと、行末から次の行へのつながりを見比べる
説明の段落が続いている変更したいまとまりの先頭と末尾を決める対象内を通して読み、見落とした分割がないか見る
日本語の本文に英語の用語が混ざる英語を含む本文のうち、直す範囲を決める英語のつながりと周囲の文章の読みやすさを見る

表は確認箇所を整理するための例です。特定の語がどの位置で折り返されるかを示す見本ではありません。変更した場所に加えて、変更対象のすぐ外側も見比べ、直す必要のなかった本文まで選んでいなかったかを確かめます。

4．直り方が意図と違うときの確認順

仕上がりが意図と違ったときは、すぐに別の設定へ進まず、最初に選んだ本文と、いま見ている本文が同じかを照合します。似た説明が続く文書では、変更箇所を取り違えることも考えられます。見出しや段落の書き出しを目印にしておくと、確認する場所を共有しやすくなります。

次に、操作の途中で別の項目を選んでいないか、確定するところまで進めたかを振り返ります。見た目が変わらなかったことだけを理由に、文書全体の設定をまとめて変更するのは避けたいところです。どの本文に、何を設定したかを確かめてから、残っている症状を分けて考えます。

行末に記号が残っている場面でも、見た目だけで不要と判断せず、元の表記を見ます。必要な記号を削除することと、行の途中で語を分けないようにすることは、目的が異なります。残っている箇所の位置と表示を記録しておけば、内容を確認する担当者にも状況を伝えやすくなります。

5．引き継ぎには、対象と仕上がりを残す

引き継ぎでは「英語を直した」だけで済ませず、どの本文を対象にしたのか、何を見て完了と判断したのかを残します。たとえば、該当する見出し、対象の段落の書き出し、分割が気になっていた語を記録する形です。文書の場所を示す情報と、仕上がりを判断する情報を組み合わせると、引き継いだ人も同じ箇所を確認できます。

本文の追記や差し替えがあったときには、修正した箇所の周辺を読み直し、途中で分かれている語がないかを見ます。見た目の好みを引き継ぐだけでなく、「英単語の綴りを変えずに、対象の本文を読みやすくする」という目的まで伝えておくとよいです。確認が済んだ箇所と、判断が残っている箇所も分けておきます。

事務の手間を洗い出すなら、文書を直す操作と、仕上がりを確かめる作業を分けて整理するところから考えられます。AI を業務に取り入れる進め方を考える際も、対象箇所を伝える情報と、人が最後に確かめる点を先にまとめておくとよいです。
