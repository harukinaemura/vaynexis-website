Windowsでプリンターがオフラインと出たときに確かめる順番

要点

Windows 11ではMicrosoftの案内に沿って、自動診断から始めます。解決しなければ、本体の電源と接続、目的の出力先、印刷待ちの文書を順に見ます。表示の変化だけで終えず、必要な文書が目的の場所から出たかまで確認する進め方です。途中で操作を引き継ぐときは、試した操作と、その直後の状態を分けて残します。

公開：2026年11月8日／情報の確認日：2026年11月7日（出典はこの記事の最後）

この記事は、Windows 11でプリンターがオフラインと表示された小さな会社の事務担当者が、接続、出力先、印刷待ち、紙の出力を順に確かめる流れを整理したものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象の版をそろえ、自動診断から始める
  2. 電源を入れ直し、接続方法に合う箇所を見る
  3. 印刷待ちの文書と、選んでいる出力先を確かめる
  4. 事務の引き継ぎには、操作と見えた状態を残す
  5. 紙が出たかを見て、解決しない状態を引き継ぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象の版をそろえ、自動診断から始める

確認日：2026年11月7日

この記事の画面操作は Windows 11 を対象とし、公式ヘルプが最初に案内する自動プリンター トラブルシューティング ツールから確認を始めます。自動診断で解決しない場合は、公式ヘルプの一般的なトラブルシューティングへ進みます。

ここからは当社の整理です。

手元の画面と説明が食い違ったら、使っている版と表示されている項目を照らし合わせます。引き継ぎにも、困った表示だけでなく、どの画面まで進めたかを添えるとよいです。

2．電源を入れ直し、接続方法に合う箇所を見る

Microsoftの案内では、プリンターの電源を切ってプラグを抜き、30秒待ってからプラグを差し込み、電源を入れ直します。職場で共同利用しているものは、ほかの人が使っていないかを先に確認してから扱います。

USB 接続では、ケーブルがプリンターからパソコンへ正しくつながっているかを確認します。Wi-Fi 接続では、プリンターとパソコンが同じネットワークに接続されているかを確かめます。

接続方法が分からないときは、管理している担当者に確かめてから進めるとよいです。つながり方を確かめる段階で、接続先の設定まで一緒に変えると、元の状態と比べにくくなります。電源を入れ直した後と、ケーブルを確認した後の状態を分けて見ることで、引き継ぐ際にも操作の順番を説明できます。

3．印刷待ちの文書と、選んでいる出力先を確かめる

MicrosoftのWindows 11向けヘルプに沿って、［スタート］から［設定］を開き、［Bluetooth & デバイス］の［プリンター & スキャナー］を選びます。対象のプリンターを選び、［印刷キューを開く］へ進みます。同じ場所で使うものでも、名前を思い込みで選ばず、今回出力したい相手かを見直します。

印刷キューでは保留中の印刷ジョブを確認でき、一覧が空なら印刷待ちのジョブはありません。待っている文書の有無と、紙が出たかどうかは分けて扱います。表示が空になっただけで、必要な文書が出力されたと判断せず、手元の紙も照らし合わせる進め方です。

Microsoftの公式ヘルプでは、保留中のジョブがあるとき、印刷キューの省略記号から［すべてキャンセル］を選ぶ手順があります。共同利用では、保留中の文書と送信した人を確認し、すべて取り消してよいと確認した場合に操作します。

通常使うプリンターも手動で変更する場合は、Microsoftの案内に沿って、［Windows に既定のプリンターを管理させる］をオフにします。続いて対象を選び、プリンター名の横の［既定に設定］を選択します。出力先をそろえる操作の後も、印刷結果は別に確かめます。

4．事務の引き継ぎには、操作と見えた状態を残す

次の表は、別の担当者に確認を引き継ぐときの記録欄です。

確かめた箇所記録する状態引き継ぐ内容
本体の電源入れ直した後の表示表示された言葉と、いつ見たか
接続接続方法、確かめた箇所と結果担当者が続けて確認する箇所
印刷待ちの文書出力先、保留の有無、取消の有無文書の担当者と再印刷の要否

「直らなかった」だけでは、次の人がどこから始めるか迷います。試したことと見えたことを対応させ、判断していない部分も残すと、同じ確認をやり直す範囲を絞れます。

原因を推測して書くより、画面に出た言葉を残す方が、相手が状態を照合しやすくなります。まだ見ていない箇所を、問題がなかった箇所として扱わないことも大切です。

5．紙が出たかを見て、解決しない状態を引き継ぐ

テストページを印刷すると、プリンターが正しく動作しているかを確認できます。その結果に加えて、業務で必要な文書が目的の場所から出ているかも見ます。予定した内容の紙を受け取れているかを確かめ、途中で取り消した文書があれば担当者と扱いをそろえます。

公式ヘルプには、パソコンの再起動によって、プリンターとの通信に必要なサービスや構成要素をリフレッシュできる場合があるという説明もあります。再起動へ進む前には、作業中の文書を保存します。

解決しないまま引き継ぐときは、表示された言葉、つながり方、試した操作、出力できたかをまとめます。接続を確認した段階と、紙の出力を確認した段階を分けて引き継ぎます。復旧したと伝える際にも、何をもって確認を終えたかが分かる記録を残します。

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月7日）

  • Windows でのオフライン プリンターの問題のトラブルシューティング：自動診断からの進め方、電源の入れ直し、同じネットワークへの接続、保留中のジョブの取り消し、パソコンの再起動
  • Windows でのプリンター接続と印刷の問題を修正する：USB ケーブルの接続確認と、テストページによる動作確認
  • Windows でプリンターの印刷キューを表示する：設定画面から印刷キューを開く手順と、印刷待ちのジョブの有無
  • Windows で通常使うプリンターを設定する：通常使うプリンターを手動で設定する際の自動管理の条件と、既定に設定する操作
