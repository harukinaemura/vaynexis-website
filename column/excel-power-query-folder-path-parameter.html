Excelの取込ファイルの場所をパラメーターで切り替えるには

要点

取込元の場所を値として持つパラメーターを作り、データソースの引数に使う構成にします。最初に値と取込設定の対応を作り、その後は切替先の場所を変更して、読み込まれた内容まで確かめる流れです。

公開：2026年11月4日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelの取込元フォルダーの場所が変わる小さな会社の担当者が、Power Query のパラメーターで参照先を切り替える流れと、切り替えた後の確かめ方を Microsoft のヘルプで確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 切替先に置くファイルの形を先に確かめる
  2. 場所を保存する設定を作る
  3. 取込元の設定に作った値を結び付ける
  4. 場所を書き換えた後は表まで更新する
  5. 架空の切替例で引き継ぐ内容を決める
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．切替先に置くファイルの形を先に確かめる

ここでは、フォルダーからの取込設定があるブックを対象に、Windows版のデスクトップ画面で参照先を切り替える操作を扱います。参照したクエリ管理のヘルプには Windows の手順があり、適用先は Excel for Microsoft 365、Excel 2024、Excel 2021 です。パラメーター クエリの作成を説明するヘルプの適用先は、Excel for Microsoft 365 と Excel for Microsoft 365 for Mac です。認証情報やスクリプトを保存する話は扱いません。

フォルダー内のファイルを結合する場合は、配下のサブフォルダーも含め、形式と構造をそろえることが公式資料の確認事項です。

作業前には、現在の参照先と変更後の参照先を手元に控えておくとよいです。変更前の状態に戻せるよう、元のブックのコピーを使って設定を確かめる進め方にします。作業中のブックと日常業務で使うブックの名前を控え、試した内容をどちらに反映したかも区別しておきます。取込元の移動と、書類の列や項目の変更は分けて扱います。

2．場所を保存する設定を作る

Excelの［データ］から［データの取得］へ進み、Power Query エディターを起動します。エディターの［ホーム］にある［パラメーターの管理］から［新しいパラメーター］を選んで作成を始めます。

［名前］は他のパラメーターと区別するために使い、［説明］には値を指定する人が用途を理解できる情報を入れられます。

［型］は値のデータ型を指定する項目で、［現在の値］が実際に格納されている値です。場所を入れる設定として、名前は「取込元フォルダー」、説明は「取込対象を置く場所」とするなど、担当者が用途を読み取れる表記にします。

場所を文字列として扱うため、［型］には［テキスト］を選びます。候補は［任意の値］にして、［現在の値］へ今の取込元のフォルダーパスを入力します。入力するのは、ファイルを置いている場所の表記です。引き継ぐ人にも同じ場所を指していると伝わるよう、画面の値と作業メモを見比べます。

入力を終えたら［OK］でパラメーターを作成します。

3．取込元の設定に作った値を結び付ける

取込クエリの［ソース］を選び、ステップの設定アイコンから、そのステップの設定ページへ進めます。［ファイル パス］のオプションが［パラメーター］に設定されていることを確かめ、作成したパラメーターをドロップダウン リストから選びます。

設定を作る作業と、取込元に結び付ける作業を分けて記録しておくと、引き継ぐ人が変更箇所をたどれます。「場所を控えた」「設定を作った」「取込元との対応を確かめた」という区切りで、作業の記録を残すとよいです。値を置く設定の名前と、取込結果を作る設定の名前を並べて控えると、変更時に選ぶ対象も伝えやすくなります。

4．場所を書き換えた後は表まで更新する

作成後のパラメーターは［パラメーターの管理］に戻って変更できるため、切替時は［現在の値］に入れた場所を見直します。

値を変えた後は、エディターの［ホーム］から、エディターを閉じてワークシートへ読み込む操作を選びます。このコマンドの名前は、日本語のヘルプではページによって「[読み込み & 閉じる]」「[閉じる] & [読み込み]」と表記が分かれているため、手元の画面の表示で確かめます。ブック内のすべてのデータの更新には、［データ］タブの［すべて更新］を使います。

候補を一覧にした場合も、［既定値］と［現在の値］は別の値なので、変更対象を取り違えないようにします。

変更後は、表の対象期間や見出しを手元の取込元と照合します。表示された内容が想定と違うときは、変更した場所と、そこに置いたファイルを見比べるところから確認します。

5．架空の切替例で引き継ぐ内容を決める

ここからは当社の整理です。

資料の置き場を整理し、取込元を移す場面を考えます。変更前後で書類の形はそろえ、場所の変更を確かめる例です。

確認すること変更前変更後
取込元の場所C:\取込\旧置場C:\取込\新置場
書類の見出し管理番号・受付日・区分管理番号・受付日・区分
結果の照合に使うもの変更前の保存済みの表新しい置き場の原票
引き継ぐ記録元の参照先変更先と照合した内容

担当者には、変更先だけでなく、どの原票と表を照合したかを渡します。変更したという記録と、結果を見て業務に使えると判断した記録を分けておくと、確認が止まっている箇所を追いやすくなります。表が表示されたことだけを完了の印にせず、対象期間、抜けている書類、重ねて読み込んだ書類を確認したかまで記録に含めます。引き継ぎメモには、変更理由、戻すときの参照先、照合に使った原票の保管場所を短く残すとよいです。

Microsoft Learn のフォルダーの説明では、フォルダー取込ではサブフォルダー内のファイル情報も表示されるとされているため、意図していない書類が配下にないかも確認します。

公開・共有の前に、この表で確かめます。
