Excelの名簿の漢字に保存されたふりがなを別列へ出すには

要点

PHONETIC 関数は、文字列からふりがなを取り出す関数で、書式は PHONETIC(参照) です。 取り出せるのは、セルに保存されているふりがなだけです。Excel がふりがなを自動で付けるのは日本語版の Excel に入力された新しいデータだけで、ほかのプログラムで作ったファイルを開いた場合は自動では作られません。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

名簿の漢字の氏名から読みの列を作ったら、一部の行だけ読みが出ない。関数が返すのは入力のときに保存された読みだけ、という前提で、確かめる行の分け方を整理しました。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 漢字の氏名の右に、読みの列を足す
  2. 読みが出てこないセルは、どこから来たか
  3. 入力したときの読みが、そのまま残る
  4. 架空の名簿で試す
  5. 誰が、いつ読みを確かめるか
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．漢字の氏名の右に、読みの列を足す

確認日：2026年11月17日。

対象は Windows 版の Excel（Microsoft 365・2024・2021 など）です。関数を使うには、地域設定が日本語・中国語・韓国語のいずれかである必要があります。 名簿を開く人が複数いるときは、事務所のパソコンだけでなく、在宅で使う端末でも同じ設定かを先に確かめておくと、人によって関数が使えない、という食い違いを防げます。

氏名が B 列の2行目から入っている名簿なら、C2 に =PHONETIC(B2) と入れ、下の行へコピーします。参照に複数のセルを指定すると左上のセルのふりがなが返り、離れた複数のセルを指定するとエラー値 #N/A が返ります。 1つの式で見るのは1人分のセル、と決めておくと迷いません。

式を入れるときは、元の氏名の列には手を入れず、読みの列を右に新しく足します。ヘルプの Web 版の節には、色や太字のような小さな変更ならふりがなは消えないが、それ以外の文字の変更ではふりがなが削除される場合がある、と書かれています。 氏名の表記を直す作業と、読みを取り出す作業は、日を分けて行うと、どちらで読みが変わったかを追いやすくなります。

2．読みが出てこないセルは、どこから来たか

名簿は、担当者が手で打った行と、勤怠や販売の仕組みから書き出したデータを貼った行が混ざりがちです。関数を入れたら、まず読みの列を上から眺め、ほかの行と様子の違う行に印を付けます。

ヘルプの Web 版の節には、セルにふりがなの情報が無い場合は［表示/非表示］のコマンドが使えなくなる、と書かれています。 印を付けた行がどこから来たデータかを確かめ、外から取り込んだ行は、読みを別に集める対象として分けておきます。同じ Web 版の節には、ふりがなを編集するには Windows 版の Excel を使う必要があるとも書かれています。

3．入力したときの読みが、そのまま残る

ふりがなには、日本語を入力するときに使った読みの文字列が使われます。 珍しい名字を、別の読みで変換して出した場合は、その変換に使った読みが残ります。関数は保存された読みをそのまま返すだけなので、本人の正しい読みかどうかまでは分かりません。

ふりがなが正しく入っていない場合は、必要な修正をするよう案内されています。また、並べ替えでは、日本語のデータは既定でふりがなの順に並びます。 正しいふりがなが付いていれば、国語辞書と同じ順に並ぶとも説明されています。 裏を返すと、読みの誤りは、名簿を五十音順に並べたときの位置にも響きます。

4．架空の名簿で試す

行氏名（架空）どう入ったか読みの列で起きること
2山田 花子担当者が入力入力に使った読みが出る
3東海林 一郎「ひがし」「うみ」「はやし」で変換して入力本人の読みと違う読みが出る
4佐藤 次郎別の仕組みの書き出しを貼り付けふりがなの情報が無い行として扱う

2行目は、担当者が普段どおりに入力した行で、入力に使った読みがそのまま出ます。3行目は、変換で漢字を出すために、本人の読みとは違う読みで入力した行です。関数は入力のときの読みを返すので、結果の文字そのものには誤りが見えません。4行目は、ほかの仕組みから書き出したデータを貼った行で、ふりがなは自動では作られません。

3行目のように、関数の結果が正しく見えても、本人の読みと合っているとは限りません。読みの列は、使う前に人の目で確かめる前提で作ります。

ふりがなの種類は、全角カタカナ・半角カタカナ・ひらがなの3種類から選べます。 名簿の使い道に合わせて、どれで出すかを社内で決めておきます。担当者ごとに種類が違うと、同じ名簿の中にひらがなとカタカナの読みが混ざり、見比べるときの手間が増えます。

5．誰が、いつ読みを確かめるか

いつ誰が何と照らすか
名簿に人を足したとき入力した担当者本人に書いてもらった読み
読みの列を使う前名簿の管理者印を付けた行（外からの行・読みの怪しい行）
年に1回名簿の管理者退職・社名変更などで変わった行

人を足すときは、入力した担当者が、本人に書いてもらった読みと読みの列を照らします。読みの列をほかの用途に使う前には、名簿の管理者が、印を付けた行だけをまとめて見直します。年に1回は、退職や社名の変更で変わった行を拾い、読みも一緒に見直します。確かめる人と時期を分けておくと、入力した人が自分の誤りに気づけなかった行も拾えます。

名簿をクラウドに置き、ブラウザーの Excel で開く担当者がいる場合は、直す人を決めておく意味が大きくなります。Web 版の Excel でふりがなを編集しようとすると、メッセージが表示されると書かれています。 読みを直すのは、Windows 版の Excel を使う管理者にまとめておくと、直したのに反映されていない、という行き違いを防げます。

読みの列を、ほかの表や送付の宛名づくりに渡すときは、関数の列のまま渡すのか、確かめが済んだ時点の文字として貼って渡すのかも決めておきます。確かめが済んだ時点の文字として渡すと、渡した先でも、いつ誰が確かめた読みかを名簿の記録と照らせます。

名簿の列ごとに、誰がいつ直すかを書き出しておくと、業務棚卸表のテンプレートで事務の作業を洗い出すときにも使えます。
