Copilotノートブックの「手順」で手順書の書式をそろえるには

要点

Microsoft Copilot アプリでノートブックを開き、右上の［その他のオプション（...）］から［手順］を選ぶと、Copilot への具体的な指示を入力して［保存］できます。 指示では、応答の書式、焦点を当てるトピック、使うトーンを頼めるので、手順書の下書きの形をそろえる指示を書いておけます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

社内のあちこちから集めた作業メモを、同じ形の手順書の下書きにそろえたい。Microsoft Copilot アプリのノートブックには、Copilot に毎回従ってほしい指示を保存する［手順］があります。開き方と書き方、使える人の条件、指示が効く範囲、共有したときの注意、ワークスペースへの切り替えによる画面の違いを、Microsoft の日本語サポートに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 使える人と画面の前提
  2. ［手順］に書式の指示を入れる
  3. 書式の指示に何を書くか
  4. 指示が効く範囲と、ノートブックの材料
  5. 共有したノートブックでは、指示も共同のもの
  6. 画面の名前が違うとき
  7. 確認表

1．使える人と画面の前提

確認日：2026年11月17日。

対象は、Microsoft Copilot アプリのノートブックで、［手順］の中で出力の書式を指定する操作です。手順書の改訂の承認や配り方の決まりは扱いません。

Copilot ノートブックは、Microsoft Copilot および Copilot Chat のライセンスを持つユーザーが利用できます。ノートブックを作るには、アカウントに SharePoint または OneDrive のライセンス（サービス プラン）が必要です。 Microsoft 365 Personal、Family、Premium、Pro のサブスクライバーも利用できるとされています。 会社で使うなら、まず自分のアカウントにどのライセンスが付いているかを、社内でライセンスを管理している人に確かめておきます。

ノートブックは、Microsoft Copilot アプリ（m365.cloud.microsoft）の左側のナビゲーションで［ノートブック］を選んで開きます。表示されないときは、左側のナビゲーション ウィンドウの上部にあるアプリ起動ツールを開いて［ノートブック］を選びます。 説明している機能の一部は段階的にロールアウトされていて、まだ使えない場合があるとも書かれています。

2．［手順］に書式の指示を入れる

  1. Microsoft Copilot アプリでノートブックを開きます。
  2. 右上隅にある［その他のオプション（...）］ボタンを選び、［手順］を選びます。
  3. ダイアログで、Copilot への具体的な指示を入力します。
  4. ［保存］を選びます。

OneNote でノートブックを開いている場合は、左上隅のノートブック名の横にある矢印を選び、［Copilot の指示］を選びます。 同じノートブックでも、開いているアプリで項目の名前が違う点に注意します。

指示はいつでも編集できます。 最初から完璧な文面を目指さず、何本か下書きを作らせてみて、形が崩れる所を見つけたら指示を足していく、という進め方が向いています。

3．書式の指示に何を書くか

サポートのページには、指示の例として、常にスペイン語と箇条書きで返信する、ブランド カラーを考慮する、クライアントの名前を小文字で書く、数字を単語で書き出す、といった文が載っています。 言語、書き方の決まり、表記の好みのように、毎回同じ形にしたいことを書く欄だと分かります。

手順書の下書きをそろえるなら、たとえば次のように書きます（架空の例）。

  • 手順は番号付きの箇条書きで、1行に1つの操作だけを書く
  • 画面のボタンやメニューの名前は［ ］で囲む
  • 各手順の最後に「確認すること」を1行で添える
  • 冒頭に「この手順を使う場面」と「必要なもの」を書く
  • です・ます調で書き、専門用語には短い説明を付ける

書式の指示は、内容の正しさを保証するものではありません。回答は言語データのパターンと確率に基づいて作られるため正確とは限らず、判断や行動の前に自分で事実を確かめるよう書かれています。 形がそろった下書きほど正しく見えやすいので、画面の名前や順番は、実際に作業している人に読んでもらってから手順書にします。

4．指示が効く範囲と、ノートブックの材料

ノートブックでは、Word の文書や PowerPoint、Excel、Copilot ページなどの参照を追加し、Copilot はその集めた内容だけを使って回答を作ります。 ワークフローの説明にも、トーンやフォーマットなどの指示を設定して Copilot の動作をカスタマイズできると書かれています。 つまり、［手順］で決めた形は、そのノートブックの中でのやり取りに向けたものです。手順書の種類ごとに書式を変えたいなら、ノートブックを分けるのが自然です。

材料の量にも上限があります。Copilot はノートブック内の最大 300 ファイルを使って回答を作ります。 Copilot Chat のユーザーは、ノートブックに追加できる参照が最大 50 個です。 また、ノートブックの中では、チャートやグラフ、画像を直接作れません。 図入りの手順書を考えているなら、図は別に用意する前提で、文章の形だけを［手順］でそろえます。

ノートブックや Copilot ページの削除は、今のところ永久的で元に戻せないとされています。 書式の指示の文面は、ノートブックの中だけに置かず、社内の文書にも控えておくと、作り直すときに困りません。

5．共有したノートブックでは、指示も共同のもの

ノートブックを共有すると、ほかのユーザーが参加して指示を確認し、リアルタイムで一緒に編集できます。 今のところ、読み取り専用のメンバーは含められず、招待したユーザーは全員がノートブックの編集アクセス権を持ちます。 誰かが善意で指示を書き換えると、ほかの人の下書きの形も変わります。共有する前に、［手順］の文面を誰が直すかだけは決めておきます。

共有すると、受け取った人はノートブックにつながっているファイルにも招待されます。各ファイルを共有する権限が必要で、権限がない場合は受け取った人が個別にアクセスを求めることになります。 書式をそろえる目的で共有したつもりが、材料のファイルまで見えるようになる点は、先に知っておきます。

6．画面の名前が違うとき

Microsoft のサポートには、Copilot ノートブックは Copilot ワークスペースになったという案内もあります。既存のノートブックは自動的にワークスペースになり、ノートブックでできた操作は引き続きワークスペースで使えるとされています。 ワークスペースは 2026 年 10 月後半から段階的にロールアウトを始め、組織のスケジュールによって時期が異なる場合があります。 左側に［ノートブック］が見当たらない、名前が違う、というときは、この切り替えの途中かもしれません。社内の手順書には、確かめた日付と、そのとき見えた画面の名前を残しておきます。

各部署から集めた作業メモを、どの順番で手順書にしていくかという全体の進め方は、AIで業務マニュアルを作る方法にまとめています。
