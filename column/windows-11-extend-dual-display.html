Windows 11の「拡張」で二画面に別の資料を出すには

要点

二つの画面に別々のものを出したいときは、Windows キー＋P を押して表示のしかたの一覧を出し、［拡張］を選びます。 ヘルプでは、［拡張］は複数の画面すべてにデスクトップを表示し、2 つの画面の間で項目を移動できる表示、［複製］はすべてのディスプレイに同じものを表示する表示と説明されています。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

ノートパソコンに外付けのモニターをつないだのに、両方の画面に同じものが映っていて、片方に資料、片方に入力の画面を出せないときの切り替え方です。Windows キー＋P で選べる4つの表示のしかた（PC 画面のみ・複製・拡張・セカンド スクリーンのみ）の違い、モニターが出てこないときや拡張にしても映らないときの確かめ方、ノートパソコンを外すときの動きを、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．同じものが映るのは「複製」になっているから

確認日：2026年11月17日。

対象は Windows 11 のパソコンです。画面の左右の並び（どちらを右に置くか）の調整は扱いません。

見積書を見ながら会計ソフトに入力する、会議の資料を見ながらメモを取る、といった事務では、二つの画面に別のものを出せると作業がはかどります。ところが、モニターをつないだだけでは、両方に同じ画面が映ることがあります。これは表示のしかたが［複製］になっている状態で、［拡張］に切り替えると、二つの画面を一つの広い机のように使えます。

2．Windows キー＋P で選ぶ4つの表示

ヘルプには、ディスプレイの表示を変更するには Windows キー＋P を押すとあり、選べるものとして次の4つが挙がっています。

選択肢ヘルプの説明事務での場面（架空の例）
PC 画面のみ1 つのディスプレイのみに表示する外のモニターを使わずに作業する
複製すべてのディスプレイに同じものを表示する会議室のモニターに、手元と同じ画面を映す
拡張複数の画面すべてにデスクトップを表示する片方に資料、片方に入力の画面を出す
セカンド スクリーンのみすべての項目をセカンド ディスプレイに表示する大きなモニターだけで作業する

［拡張］を選んだら、資料のウィンドウをマウスで画面の端まで動かし、もう一方の画面へ移るかを確かめます。ヘルプにも、ディスプレイを拡張した場合は、2 つの画面の間で項目を移動できると書かれています。 来客に画面を見せる打ち合わせのときだけ［複製］に戻す、というように、場面ごとに切り替えて使えます。

3．つないだら確かめる3つのこと

ヘルプは、外部ディスプレイの設定を変える前の準備として、ケーブルが PC またはドックに正しく接続されていることと、Windows 更新プログラムの確認を挙げています。 そのうえで、次の順に見ます。

  • どちらが何番か：［設定］の［システム］、［ディスプレイ］で［識別］を選ぶと、ディスプレイの画面に割り当てられている番号が表示されます。 手順書に「2番の画面に資料を出す」と書くときは、先にこの番号を確かめておきます。
  • 一覧に出てこないとき：別のディスプレイを接続しても［設定］に表示されない場合は、［スタート］、［設定］、［システム］、［ディスプレイ］、［複数のディスプレイ］と進んで［検出］を選びます。
  • ワイヤレスでつなぐとき：会議室のテレビなどにワイヤレス ディスプレイ アダプターでつなぐ場合は、Windows キー＋K で［キャスト］を開き、アダプターを選びます。

4．［拡張］にしても映らないとき

外部モニターのトラブルシューティングのページでは、まず Windows ロゴ キー＋P を押して［拡張］が選ばれていることを確かめるよう案内しています。 選ばれているのに期待どおりに表示されない場合の基本は、PC からすべてのアクセサリを外すこと、ケーブルがしっかりつながっているかを確かめること、ケーブルを交換してみることです。ドック、ドングル、アダプターなどがつながっていると、競合が生じることがあると書かれています。

気をつけたいのが分配器です。ヘルプによると、ディスプレイ スプリッターでは2つの独立した信号が作られるのではなく同じ信号が複製されるため、スプリッターで複数の外部モニターに拡張することはできません。 「一本のケーブルを分けて二台に映したのに、同じものしか出ない」という場合は、設定ではなく機器の側の理由です。それまで使えていた二画面が急に映らなくなったときは、Windows ロゴ キー＋Ctrl＋Shift＋B でグラフィック ドライバーをリセットし、だめなら再起動する方法が載っています。

5．ノートパソコンを外して会議に出るとき

二画面で作業していたノートパソコンを外して会議室へ持って行くと、外部モニターに出していたウィンドウがどうなるかが気になります。ヘルプによると、ドッキングを解除すると外部モニターのウィンドウが最小化され、再ドッキングすると Windows によって以前の位置に戻ります。 この動きは、［ディスプレイ］の［複数のディスプレイ］にある［モニターの接続に基づいてウィンドウの場所を記憶する］と［モニターが切断されているときにウィンドウを最小化する］のチェック ボックスで調整できます。

二画面の使い方は、人によって慣れの差が大きいところです。どの作業でどちらの画面に何を出すかを決めておくと、引き継ぎのときにも説明しやすくなります。事務の道具の使い方を並べて見直すときは、業務棚卸しチェックシート（エクセル・CSV）の考え方も参考になります。
