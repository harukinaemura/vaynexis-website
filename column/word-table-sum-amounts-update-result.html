Wordの報告書の表で金額を合計し、修正後の結果を更新する手順

要点

Wordの表では［計算式］で合計し、元の金額を直した後は、合計欄を選んで F9 キーを押して結果を更新します。式が足す方向と、今回合計したい明細が一致しているかを見て、入力値・対象範囲・更新後の結果を分けて確かめるとよいです。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、Wordの報告書の表で金額を合計し、元の金額を直した後に結果を更新したい小さな会社の担当者が、式を入れる場所と足す方向、空欄の扱い、更新して照合する流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 合計欄を決めてから、足す方向を指定する
  2. 小さな明細で、入力欄と照合用の合計を分ける
  3. 空欄は、未入力なのか金額がないのかを見直す
  4. 元の金額を直したら、更新する範囲を選ぶ
  5. 結果が変わらないときは、式の内容と引き継ぎ方を確かめる
  6. 引き継ぎでは、入力から照合までの順序を残す
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．合計欄を決めてから、足す方向を指定する

確認日：2026-11-13

ここでは Windows 版の Word for Microsoft 365・Word 2024・Word 2021 を対象に、合計の挿入と更新を説明します。Web 版は既存の数式を保持しますが、数式を追加する方法はまだ提供されていません。

作業前には、明細として入力する欄と、合計を表示する欄を区別します。金額欄の途中に参考値や小計を置いている表なら、何を足したいのかを先に整理するとよいです。見た目が整っていても、明細と参考値の境界が読み取りにくいままでは、式の内容を照合する基準が曖昧になります。

まず結果を表示するセルを選び、内容が入っていれば削除します。続いて［テーブル レイアウト］タブから［数式］を選びます。同じページには、このあたりのコマンドの名前が［計算式］と書かれている箇所もあり、お使いの画面での表記は確かめていません。合計欄の上側に並ぶ金額を足す式は「=SUM(ABOVE)」、左側に並ぶ数値を足す式は「=SUM(LEFT)」です。［計算式］ボックスで式を指定した後は、［OK］を選択します。

列の一番下に合計欄を置く場合と、行の右端に置く場合では、数値が並ぶ方向が違います。以前の報告書を流用する際も、合計欄だけを見ず、明細がどちら側にあるかを見比べる流れです。操作名を覚えるだけでなく、結果を置く場所と足す対象を対応させます。

2．小さな明細で、入力欄と照合用の合計を分ける

ここからは当社の整理です。

報告書の印刷費用を整理する例として、次の表を考えます。合計欄の値は、入力後に結果を照合するための目安として示したものです。

項目金額（円）
資料の印刷1,200
用紙800
合計（照合用）2,000

この配置では、項目名と金額を分け、合計の対象にする明細を上側へまとめています。実際の報告書に置き換えるときは、参考として載せた別の費用や、別期間の金額を同じ対象に混ぜないようにします。何を含めた合計かが説明できることを、結果確認の出発点にするとよいです。

合計欄だけを正しい値に書き直して終えると、元の明細に入力の誤りが残っていないかを見落とします。金額が合わない場合は、入力元の明細と照らし合わせ、項目の抜けや重複、合計に含める範囲の判断から順に見直します。結果の値を合わせる作業と、元の内容を確かめる作業は分けて進めます。

3．空欄は、未入力なのか金額がないのかを見直す

Word の表の計算式のヘルプでは、上側や左側などの場所を指定して合計する場合、エラーを避けるため、計算対象となるすべての空のセルに 0 を入力しておくとしています。

空欄を埋める前には、その項目の金額が確定しているかを確認します。金額がないことを確認済みの欄と、担当者への確認が済んでいない欄を、同じ意味で扱わないためです。未確定のまま計算を進める場合も、報告書を確定させる前の確認事項として残します。

空欄の意味が分からないときは、計算上の扱いを先に決めず、入力元に戻るとよいです。見直す際は、空欄の位置だけでなく、明細の途中に説明用の行が入っていないかも確認します。報告内容の区切りと、合計に含める範囲を対応させておくと、別の担当者にも判断を引き継ぎやすくなります。

4．元の金額を直したら、更新する範囲を選ぶ

Word の表の計算式のヘルプでは、数式の結果は、数式を挿入したときと、その数式を含む文書を開いたときに計算されるとしています。同じページには、Word の表の数式はフィールド コードの一種であるとも書かれています。編集中の確認では、元の金額を修正する作業に加え、結果を更新して見比べる工程を設けます。

同じページでは、同じ表の計算結果をまとめて更新するには、表全体を選択して F9 キーを押すとしています。フィールドを更新するヘルプでは、個別のフィールドは、右クリックして［フィールド更新］を選ぶ方法でも更新できるとしています。Mac 版で元の数値を変えた後は、合計を選択し、fn + F9 キーを押す手順が案内されています。

修正した箇所の横に表示されている合計だけを見て済ませず、どの合計がその明細に対応しているかを確認するとよいです。修正前の控えと見比べる場合も、入力欄と結果欄を対にして追います。更新を行ったことと、対象の明細が正しいことは別々の確認事項です。

フィールドを更新するヘルプでは、文書全体を更新する手順は Ctrl + A、続いて F9 とされています。同じページは、表については個別に選んで F9 を押す必要がある場合もあるとしています。

文書をまとめて処理した後でも、提出する表の結果を元の明細と照合する工程は残します。見出しや本文の修正が終わった時点で計算結果も確定したとみなさず、金額の確認を終えてから報告書全体を確定させる順序にします。

5．結果が変わらないときは、式の内容と引き継ぎ方を確かめる

式を調べたいとき、Word のキーボード ショートカットのヘルプでは、Windows 版で Shift + F9 により、選択したフィールドのコードと結果の表示を切り替えられるとしています。Windows 版には、Ctrl + F11 でフィールドをロックし、Ctrl + Shift + F11 でロックを解除する操作もあります。

更新しても想定と違う結果なら、合計に含めるつもりだった明細を、式が実際に対象としているか照合します。入力値が正しいか、対象の指定が正しいか、結果の確認を済ませたかを、順に切り分けるとよいです。表示された金額だけを上書きする前に、どの段階に違いがあるのかを確かめます。

6．引き継ぎでは、入力から照合までの順序を残す

引き継ぎ用には、金額を入力する場所、合計の対象、修正後に更新する場所、結果を照合する資料を残します。報告書の表を後から組み替えた場合は、元の手順をそのまま使えるかも確認対象です。担当者の記憶に頼らず、表を見ながら同じ順序で確かめられる内容にします。

事務の手間を洗い出すなら、入力・集計・照合のどこに作業があるかを整理し、AIを事務に取り入れる進め方を考える出発点にするとよいです。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□入力する明細と合計を表示する欄を区別したか
□合計に含める項目と、参考値や小計の扱いを確認したか
□式が対象とする方向と明細の配置を照合したか
□空欄が未確定を意味するのか、金額がないことを意味するのか確認したか
□元の金額の修正後に、対象の合計を更新して結果を照合したか
□使用する版に合う操作と、引き継ぎで残す確認先を整理したか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
