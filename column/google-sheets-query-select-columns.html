GoogleスプレッドシートのQUERYで必要な列だけを別表に出すには？

要点

元の表で使う列と、出力する順番を先に確認します。QUERYの第1引数に元の表の範囲、第2引数にselectと列の記号、第3引数に元の範囲の先頭にある見出しの行数を指定します。別表に出た列の順番と値を元の表で照合します。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、Googleスプレッドシートの元の表から必要な列だけを別表に並べたい小さな会社の担当者が、QUERYの列の指定と見出しの行数、値が欠けたときの型を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月9日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 元の表と出力する列を控える
  2. selectで列を並べる順を指定する
  3. 見出しの行数と出力先を確認する
  4. 別表の見出しを付け直すとき
  5. 抜けた値は元の列のデータ型を調べる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．元の表と出力する列を控える

確認日：2026年11月9日。

Googleの日本語ヘルプは、QUERYの引数としてデータの範囲、実行するクエリ、任意の見出しを挙げています。同じヘルプでは、データの各列に指定できるのは、ブール値、数値（日付/時刻など）、文字列の値のみとされています。

ここからは当社の整理です。

必要な項目の見出しと、その項目が入っている列の記号を元の表で対応させます。出力したい順で記号を並べてから、必要な列をすべて含むように元の範囲を決めます。この記事では、元の表の列の記号（A、B…）で列を指定する書き方を扱います。

2．selectで列を並べる順を指定する

Googleのクエリ言語の仕様では、selectは返す列とその順序を指定します。列を指定するときは、表の見出しの文字列とは区別し、列の識別子を使います。日本語ヘルプは、クエリの値を二重引用符で囲むか、その内容が入ったセルの参照にするよう説明しています。同じヘルプの例では、QUERY は「Col」表記と「A, B」表記のどちらも受け付け、SELECT 句と WHERE 句を使うと、指定した条件に一致する行を返せるとされています。

日本語のヘルプは、クエリ言語の詳しい説明として英語の開発者向け資料を案内しています。その仕様では、Google スプレッドシートの列の識別子は1〜2文字の列の文字（A, B, C, ...）で、識別子は大文字と小文字を区別します。select を省いた場合や select * とした場合は、すべての列が元の順序で返ります。列の記号は、シートの列の上に出ている大文字のまま書きます。必要な列だけを出したいのに元の表の全列が出たときは、select の後ろに列の記号が入っているかを見直します。

元の表と重ならない出力先の先頭セルで、QUERYの第1引数に元の表の範囲を入れます。第2引数の二重引用符の中にselectと半角の空白を書き、列の記号を出力順にカンマで区切って並べます。列の見出しと記号を控えた一覧を見て、選び違いがないかを確かめます。

3．見出しの行数と出力先を確認する

日本語ヘルプでは、第3引数で入力範囲の先頭にある見出し行の数を指定します。指定を省いた場合や値を-1にした場合は、データから見出しを推測するとしています。また、見出し行の数を指定すると、複数の見出し行がある範囲の入力値を、1行の見出しの入力値に変換できると説明されています。

元の表に見出しがあれば、選んだ入力範囲の中に何行含めたかを数えて指定します。出力先では、その順番で必要な列が出ているか、元の明細の先頭行が抜けていないかを確かめます。元の表に列を追加したときは、設定した範囲と列の記号が意図した項目を指しているか確認します。見出しが2行に分かれている表では、2行とも範囲に含めて見出し行の数を2とし、出力の見出しが1行にまとまったかを見ます。

4．別表の見出しを付け直すとき

クエリ言語の仕様では、label 句で1つ以上の列にラベルを付けられますが、クエリの中でラベルの値を列の識別子の代わりに使うことはできません。また、句は select、where、group by、pivot、order by、limit、offset、label などの決まった順序で書くとされています。別表の見出しを元の表と違う名前にしたい場合は、select と where の後ろに label 句を置きます。式の中でクエリを二重引用符で囲んでいる場合は、付ける名前を単一引用符で囲みます。label で付けた名前は、select や where の列の指定には使わず、列の記号で指定します。

5．抜けた値は元の列のデータ型を調べる

Googleは、同じ列に異なる種類のデータが混ざる場合、多数の種類が列のデータ型となり、少数の種類の値はNULLとして扱うと説明しています。

元の表に値があるのに出力で空白に見えるときは、参照先の列とセルを確認し、数値と文字列などが混在していないかを調べます。元の入力を直す場合は、担当と項目の扱いを確認し、修正した行が別表にどう出るかを見直します。たとえば列の大部分が数値で、一部の行に「なし」などの文字を入れている場合は、文字の値が NULL として扱われ、出力では空白に見えます。数値の列に文字を混ぜていないか、日付の列に文字で入れた日付がないかを先に見ます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□元の表の項目と列の記号を対応させたか
□selectで必要な列を出したい順に指定したか
□列の記号を大文字で書いたか
□入力範囲の先頭に含めた見出し行数を指定したか
□出力した表の列と明細を元の表と見比べたか
□見出しを付け直す場合、label 句を後ろに置き、列の指定には記号を使ったか
□値が欠けた場合は元の範囲と列のデータ型を調べたか
