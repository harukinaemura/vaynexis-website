スプレッドシートの「値のみ貼り付け」で数式を外すには

要点

計算の結果だけを別の場所へ写したいときは、普通の貼り付けではなく、［編集］の［特殊貼り付け］から［値のみ貼り付け］を選びます。Google のヘルプでは、値のみ貼り付けは元のセル範囲のテキストのみを貼り付けると説明されています。 キーボードなら、Windows は Ctrl＋Shift＋V、Mac は ⌘＋Shift＋V です。 ただし、特殊貼り付けは同一のスプレッドシート内でのみ使えます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

集計表の計算結果を、月ごとの控えや報告用のシートへ写すとき、数式ごと貼り付けると元の表を直したときに数字が動いてしまいます。Google スプレッドシートの［特殊貼り付け］から［値のみ貼り付け］を選び、計算の結果だけを写す手順と、キーボードでの操作、使える範囲の注意を、Google の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．数式ごと写すと、控えの数字が後から動く

確認日：2026年11月17日。

対象は、パソコンのブラウザで使う Google スプレッドシートです。

売上や経費の集計表では、合計や比率のセルに数式が入っています。そのセルをそのまま別のシートへ貼り付けると、数式も一緒に写ります。元の表を後から直したときに、締めたはずの月の控えまで数字が変わると、報告した数字と手元の数字が合わなくなります。

控えとして残したいのが「その時点の計算結果」なら、数式は写さず、結果の文字と数字だけを貼り付けます。計算に使う元のセルは、そのまま残しておきます。翌月も同じ集計表を使い続けるためです。

2．メニューから写す手順

ヘルプの手順は次のとおりです。

  1. パソコンの Google スプレッドシートで、スプレッドシートを開きます。
  2. 貼り付けるデータをコピーし、貼り付け先のセルにカーソルを移動します。
  3. ［編集］の［特殊貼り付け］をクリックします。
  4. 表示される項目のうち、［値のみ貼り付け］を選びます。

貼り付けた後、写した先のセルを選び、数式バーに数式ではなく数字が出ているかを確かめます。合計の列など、数式が入っていたはずの列を一つ選んで見るだけでも、取り違えに気づけます。

3．普通に貼り付けた後で切り替える

いつもの癖で普通に貼り付けてしまっても、同じスプレッドシートの中なら、貼り付けた後に切り替える道があります。ヘルプでは、同一のスプレッドシート内にコンテンツを貼り付けると、デフォルトではコンテンツの元の書式がそのまま使用され、変えるときは貼り付けアイコンをクリックすると説明されています。 そこで選べるのは［値のみ貼り付け］と［書式のみ貼り付け］で、［値のみ貼り付け］は元のセル範囲に含まれているテキストのみを貼り付けます。

4．キーボードで写すときの決まり

ヘルプのキーボード ショートカットの一覧では、［値のみ貼り付け］は Windows で Ctrl＋Shift＋V、Mac で ⌘＋Shift＋V です。ふだんの貼り付け（Ctrl＋V）に Shift を足した形なので、覚えやすい組み合わせです。 ショートカットの一覧は、スプレッドシートの中で Ctrl＋/（Mac は ⌘＋/）を押すと表示できます。 ただし、言語やキーボードの形式によっては、一部のショートカットを使用できない場合があるとも書かれています。 キーで写せないときは、上の［編集］メニューからの手順に戻ります。

コピーの操作そのものにも注意があります。セキュリティ上の理由で、ほとんどのブラウザでは、ブラウザのメニューを使用してパソコンのクリップボードにアクセスする操作は許可されていません。Chrome 以外のブラウザでは、コピーと貼り付けにキーボード ショートカットを使います。 右クリックでコピーできないときは、Ctrl＋C でコピーしてから値のみ貼り付けに進みます。

5．名前の似た項目と取り違えない

［特殊貼り付け］の中には、名前の似た項目が並びます。ヘルプの説明を並べると、計算の結果を写すのは［値のみ貼り付け］だと分かります。

  • 数式のみ貼り付け：コピーしたセル範囲に含まれる数式のみを貼り付け、数式の計算結果は貼り付けません。名前は近いのに、今回の目的とは逆の働きです。
  • 書式のみ貼り付け：セルの書式のみをコピーし、セルにすでに入力されているテキストや数式はそのまま変わりません。
  • 枠線を除くすべてを貼り付け：セルの枠線を除くすべてを貼り付けます。
  • 列幅のみ貼り付け：選択した列の幅を、コピー元のセルの列幅と一致させます。
  • 転置して貼り付け：コピーしたセルを回転させて貼り付けます。1 つの列内の複数のセルが、1 つの行内の複数のセルとして貼り付けられます。

このほか、データの入力規則のみ、条件付き書式のみを貼り付ける項目もあります。

6．見た目もそろえたいときは

［値のみ貼り付け］はテキストのみを写すので、元の表の色などの見た目は控えに付いてきません。見た目も合わせたいときは、同じ範囲をもう一度コピーし、写した先で［書式のみ貼り付け］を選ぶ方法が考えられます。［書式のみ貼り付け］は、セルにすでに入力されているテキストや数式を変えないとヘルプに書かれているので、先に写した値はそのまま残ります。

7．別のファイルへは、この方法で写せない

ヘルプには、あるスプレッドシートでセルをコピーし、別のタブで開いたスプレッドシートで特殊貼り付けを使うことはできないと書かれています。 月ごとの控えを別のファイルに作っている場合は、この手順はそのまま使えません。控えを同じファイルの別シートに置くか、別の方法を確かめてから作業します。別のファイルへ結果だけを写す方法は、このページからは読み取れませんでした。

8．写した後に残すメモ（架空の例）

控えを作ったら、いつ・どの範囲を・どの方法で写したかを短く残しておくと、数字が合わないときに元をたどれます。

残す内容架空の記入例

表の作り方や写し方は、担当者ごとにばらばらになりがちです。月末の控え作りのように毎月くり返す作業を書き出してみるなら、業務棚卸しチェックシートとAI業務改善のやり方が使えます。
