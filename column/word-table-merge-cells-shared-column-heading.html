Wordの表で複数の列にまたがる共通見出しを作る手順と確認

要点

Word の表で複数の列にまたがる共通見出しは、見出しを置く行で隣り合うセルを選び、［セルの結合］で1つのセルにして作ります。Microsoft サポートは、同じ行または列内の 2 つ以上のテーブル セルを 1 つのセルに結合できるとしています。先に見出しを置く範囲を決め、操作後は上の見出しと下の項目名の対応を見ます。結合したセルはスクリーン リーダーが表の中の位置を見失う原因にもなるので、配る相手の読み方も確かめます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Word の表で複数の列をまとめる見出しを作りたい小さな会社の担当者が、セルの結合の手順と、結合した後の見出しの対応や読み上げへの影響を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 使っている版と見出しを置く場所を確認する
  2. 選択後にリボンか右クリックから操作する
  3. 共通見出しと項目名を短い表で考える
  4. 操作が表示されないときは選んだ範囲を見る
  5. 仕上がりは見出しの対応と読み方から確かめる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．使っている版と見出しを置く場所を確認する

確認日：2026年11月11日。

Microsoft サポートの「Word で表のセルを結合または分割する」の注は、この内容はデスクトップ版の Word for Windows および Mac（Microsoft 365 サブスクリプションの Word を含む）に適用されるとしています。同じ注は、一部の機能は Web 用 Word アプリまたはモバイル アプリでは使用できない場合があるとしています。手順は Windows と Mac で分けて書かれているので、自分の Word がどちらかを先に確かめます。

作業前の整理として、表のどこに大きな分類を置き、その下にどの項目名を並べるかを書き出します。上の見出しだけを読んでも大まかな分類が伝わり、下の項目名まで読むと各欄に何を書くか分かる構成を目指します。分類名が隣の欄の内容まで含んでいないかを考えると、まとめる範囲を決めやすくなります。

既存の文書を直すときは、作業前の内容を見返せるようにしておきます。選ぶ予定の場所にすでに文字があるか、残す項目名がどこにあるかも把握します。

2．選択後にリボンか右クリックから操作する

共通する準備

操作の最初に、結合するセルを選びます。選択前の作業上の整理として、共通見出しを置く段と、項目名が並ぶ段を見分けておきます。予定した範囲の左端と右端を確認し、明細の記入欄まで選んでいないかを見ます。

リボンから進める方法

Microsoft サポートの Windows 向けの手順では、リボンから［表のレイアウト］＞［セルの結合］を選択します。Mac 向けの手順では、［表のデザイン］タブの横にある［レイアウト］タブで［セルの結合］を選択します。選択した範囲と操作後の形を見比べます。共通見出しを置く場所がまとまり、その下で各項目を区別できるかが確認の中心です。

右クリックから進める方法

同じ Windows 向けの手順には、選択したセルを右クリックして［セルの結合］を選択する方法もあります。右クリックの方法は、このヘルプでは Windows 向けの手順にだけ書かれています。引き継ぎ用に手順を残す際は、自分が使った経路を書き、対象の表と見出しの位置を併記します。

3．共通見出しと項目名を短い表で考える

ここからは当社の整理です。

社内の問い合わせ先をまとめる表を考えます。次の表は、上段をまとめる前の配置です。「空欄」は説明上の表示で、実際の記入内容には含めません。

社内窓口空欄受付方法空欄
部門担当業務連絡手段受付場所
総務備品の相談社内メッセージ事務室
管理設備の相談口頭管理室

目指す形は、「部門」と「担当業務」の上に「社内窓口」がまたがり、「連絡手段」と「受付場所」の上に「受付方法」がまたがる配置です。上段のまとまりごとに対象を定めて作業します。下段の項目名は、それぞれの欄の意味を説明する役割があります。

共通見出しの言葉は、その下に並ぶ項目をまとめて説明できるものを選びます。名前を短くすることに気を取られると、分類の意味が曖昧になる場合があります。表を初めて読む人が、見出しから必要な欄へたどれるかを基準に考えます。

また、項目名を残す場所まで一緒にまとめると、完成させたい配置から外れます。操作の対象を決めるときには、横のまとまりと上下の役割を続けて確認します。共通見出しの範囲を説明できても、下の項目名の意味が分からない状態なら、見出しの言葉や配置を見直す余地があります。

4．操作が表示されないときは選んだ範囲を見る

Microsoft サポートの注では、［セルを結合］が表示されない場合は、隣接する複数のセルを選択したことを確認するとしています。手順の中では［セルの結合］と書かれている同じ操作です。

当社の確認の順番としては、操作したい場所、実際に選んでいる場所、画面に出ている選択肢を順に見ます。見出しの文字がある位置を指していることと、まとめる範囲を選べていることを確かめます。

範囲を選び直す前には、完成させたい見出しの幅をもう一度確認します。操作が見つかったことだけを区切りにせず、隣の分類や下の項目名にまで対象が広がっていないかも見ます。

引き継ぐときに「できない」とだけ残すと、相手は同じ状態を探すところから始めることになります。対象の表、選んだ場所、表示されなかった選択肢を記録しておくと、どの段階を確認するか共有しやすくなります。

5．仕上がりは見出しの対応と読み方から確かめる

見た目の仕上がりは、共通見出しから下の項目を順にたどって確かめます。見出しの左右の端が意図した範囲に合っているか、項目名や記入内容が抜けていないか、別の分類に属する欄を含めていないかを読み直します。

罫線の無い表では、結合した範囲の端が見えにくくなります。Microsoft サポートは、表に罫線がない場合は枠線をオンにすることができるとし、Windows 向けの手順では、表内の任意の場所を選択してから、表レイアウトの［表］グループで［枠線の表示］を選択するとしています。Mac 向けの手順では、表内の任意の場所を選択し、［レイアウト］タブで［枠線の表示］を選択します。

Microsoft サポートのアクセシビリティの案内では、スクリーン リーダーは、表のセルを数えて表内の位置を把握するとしています。表の中に別の表が入っている場合や、セルが結合・分割されている場合、スクリーン リーダーは位置を見失い、その先の表の有用な情報を提供できなくなります。同じページは、表に空白のセルがあると、スクリーン リーダーを使用しているユーザーは表にそれ以上何もないと誤解する可能性があるとしています。そのうえで、テーブルを使用する必要がある場合は、データにのみ単純なテーブル構造を使用し、列ヘッダー情報を指定するとし、分割セル、結合セル、入れ子になったテーブルが含まれていないことを確かめるには、アクセシビリティ チェックを使用するとしています。

当社の仕上げの確認では、受け取る相手がどのように文書を読むかも確かめます。画面上での見やすさと、読み上げを使った内容の把握を、確認項目に含めます。読み上げで読む人に渡す表では、共通見出しを結合せず、下の項目名に分類の名前を含める形にするかも相手と相談します。確認を担当する人には、まとめた見出しの範囲と、その下に残した項目名が分かる状態で渡します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□共通見出しに含める項目を決めたか
□使っている版と公式ヘルプの適用先を照合したか
□予定した見出しの範囲を選んだか
□下の項目名や明細欄をまとめる対象に含めていないか確認したか
□共通見出しの左右の端と下の項目の対応を確認したか
□作業前後で項目名や記入内容に抜けがないか確認したか
□罫線の無い表で、枠線を表示して結合した範囲を見たか
□受け取る相手の読み方（読み上げを使うか）と引き継ぐ手順を確認したか
