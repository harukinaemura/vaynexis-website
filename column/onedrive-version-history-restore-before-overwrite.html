OneDriveのバージョン履歴で、上書きする前の内容に戻すには

要点

上書き前の内容に戻したいファイルを右クリックして［バージョン履歴］を選び、戻したい版の横の省略記号（...）から［復元］を選びます。 この操作は OneDrive の Web サイトでも、同期アプリを入れたパソコンのエクスプローラーでもでき、一度に戻せるのは1ファイルだけです。 戻した版が現在の版になり、それまでの現在の版は一覧の以前の版として残ります。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

保存した後で、取引先に渡す資料が先月の内容に置き換わっていると気づいた。OneDrive の［バージョン履歴］で戻す版の選び方と、戻した後に前の内容がどこに残るか、欲しい版が並ばない理由を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

単価表の場面と記入例は架空の設定で、確認表は Microsoft のヘルプをもとに当社が組んだ点検の順番です。

  1. 消えたのではなく、中身が書き換わったとき
  2. OneDrive の Web サイトから戻す
  3. パソコンのエクスプローラーから戻す
  4. 戻す前に中身を確かめたいとき
  5. 欲しい版が見当たらないときに考えること
  6. 架空の例：単価表の PDF を古い版で上書きした
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．消えたのではなく、中身が書き換わったとき

確認日：2026年11月17日。

対象は、OneDrive の Web サイト（onedrive.com）と、Windows のパソコンに入れた OneDrive 同期アプリのエクスプローラーです。個人用の Microsoft アカウントと、職場または学校のアカウントの両方を扱います。

ファイルそのものが無くなったならごみ箱を探しますが、ファイルはあるのに中身が古い、あるいは別の資料の内容になってしまった、という場合はごみ箱には出てきません。こちらで使うのがバージョン履歴です。ヘルプでは、バージョン履歴を使うと、OneDrive または SharePoint に保存されている古いバージョンのファイルを確認および復元できると説明されています。

Word や Excel だけの機能ではない点も覚えておくと役立ちます。バージョン履歴は、Microsoft 365 ファイル、PDF、CAD ファイル、写真、ビデオなど、すべてのファイルの種類で機能します。 取引先に渡す PDF の価格表を、古い PDF で上書きしてしまった、という場面でも使えます。

2．OneDrive の Web サイトから戻す

ブラウザーで戻す場合の順番です。

順番操作（OneDrive の Web サイト）
1個人用の Microsoft アカウント、または職場や学校のアカウントで onedrive.com にサインインする
2戻すファイルを1つ選び、右クリックして［バージョン履歴］を選ぶ
3［バージョン履歴］ウィンドウで、戻したい版の横の省略記号（...）を選び、［復元］を選ぶ

複数のファイルをまとめて選んでも、版は戻せません。一度に復元できるファイルは1つだけと書かれています。 見積書と添付の明細など、いくつかのファイルを同じ日に上書きしてしまったときは、1つずつ順に戻します。

3．パソコンのエクスプローラーから戻す

パソコンに OneDrive 同期アプリが入っていれば、ブラウザーを開かなくても戻せます。エクスプローラーで戻したいファイルを右クリックし、［バージョン履歴］を選びます。 続けて、目的の版の横にある省略記号（...）を選び、［復元］を選びます。

Web サイトでもエクスプローラーでも、戻した版が現在の版になり、それまでの現在の版は一覧の以前の版に移ります。 つまり、戻す版を選び間違えても、直前の内容が消えるわけではありません。もう一度［バージョン履歴］を開けば、戻す前の版を選び直せます。

4．戻す前に中身を確かめたいとき

上書き前の版が複数あると、どれに戻すか迷います。職場や学校の OneDrive にも当てはまる SharePoint のバージョン管理のヘルプでは、現在のバージョンを上書きすることなく、以前のバージョンを表示できると説明されています。 また、バージョン履歴では、アイテムやファイルが変更されたタイミングと変更者を確認できます。 共有している資料なら、「誰が、いつ保存した版か」を手がかりに、上書きの前の版を見分けます。

一覧には番号の付いた版が並びます。新しいバージョンを作成するたびに、バージョン番号は自動的に加算されます。 中身を書き換えていないのに版が増えていることもあります。ブラウザーや OneDrive 同期クライアントでファイルの名前を変えると、新しいバージョンが作成されるためです。 名前を整えただけの版と、中身を書き換えた版が並んでいる場合は、日時を見て、上書きした時刻より前の版を開いて確かめます。

5．欲しい版が見当たらないときに考えること

［バージョン履歴］を開いても、思っていた版が並んでいないことがあります。考えられる理由を、ヘルプの記載から並べます。

考えられることヘルプの記載
保存のたびに版ができるわけではないOffice ドキュメントの編集と保存では、すべての編集と保存で新しいバージョンが作成されるわけではない（自動保存が有効な場合に一般的）
日数がたっているOneDrive のヘルプの注に「ファイルのバージョン履歴は 30 日間保持されます」とある
職場の設定職場または学校のアカウントでは、管理者がドキュメントのバージョン管理をオフにしている可能性がある
版の数の上限版の数に制限があるかどうかは組織によって異なり、制限に達すると最初のバージョンから削除される

一つ目の「保存のたびに版ができるわけではない」は、見落としやすい点です。ヘルプでは、編集内容を頻繁に保存する場合は、個々の編集ではなく、新しいバージョンごとに特定の時点がキャプチャされると説明されています。 自動保存のまま長く作業していると、「10時の状態」「11時の状態」のように細かく残っているとは限りません。大きく書き換える前の内容を確実に残したいときは、別名でコピーを作ってから作業する、という社内の決まりを足しておくと安心です。

日数と版の数は、ヘルプのページごとに別の書き方になっています。OneDrive のページの注は日数（30 日間）で、SharePoint のページには、Microsoft 365 では新しいライブラリやリストを作るとバージョン管理が既定で有効になり、ドキュメントの最後の 500 バージョンが自動的に保存されると書かれています。 どちらが自分の OneDrive に当てはまるかは、アカウントの種類と管理者の設定で変わります。上書きに気づいたら日を置かずに戻す、会社のアカウントで古い版が見当たらなければ社内の管理者に確かめる、という順で進めます。

6．架空の例：単価表の PDF を古い版で上書きした

営業事務の担当者が、取引先に渡す単価表の PDF を、先月の PDF で上書きしてしまった場面です（架空の例）。

確かめたこと架空の記入例
上書きに気づいた日上書きした翌日
開いた場所エクスプローラーの OneDrive フォルダーで、単価表の PDF を右クリック
戻した版上書きの直前に、担当者本人が保存した版
戻した後の確認PDF を開き、今月の単価が載っていることと、ページ数を見た

戻した後は、同じことが起きないように、上書きしやすい場面（同じ名前のファイルを別の場所から持ってくるときなど）を手順書に書いておくと、ほかの担当者にも伝わります。社内の手順書のまとめ方は、業務マニュアルの作り方で紹介しています。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□困っているのが「消えた」ではなく「中身が書き換わった」ことか
□戻すファイルを1つだけ選んで［バージョン履歴］を開いたか
□版の日時と保存した人を見て、上書きの直前の版を選んだか
□［復元］の後、ファイルを開いて中身を確かめたか
□複数のファイルを上書きした場合、1つずつ戻したか
□欲しい版が無い場合、会社のアカウントなら管理者に確かめたか
