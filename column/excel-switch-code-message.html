ExcelのSWITCH関数で区分コード別の案内文を表示するには

要点

Excelで区分コード別の案内文を表示するには、SWITCH関数で入力値とコードを比較し、最初に一致したコードに対応する文面を返します。未登録コードの表示も先に決め、入力欄と案内文の欄を分けて管理するとよいです。

公開：2026年11月14日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、区分コード別の案内文を表示したい小さな会社の担当者が、SWITCH関数の入力順と既定値、コピー後の対応を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 固定コードの対応を決め、使う版を確かめる
  2. コードと案内文を交互に並べて入力する
  3. 下へコピーした後は、入力セルとの対応を見る
  4. 未一致の表示と入力時のエラーを切り分ける
  5. 文面の変更と引き継ぎで残すこと
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．固定コードの対応を決め、使う版を確かめる

確認日：2026-11-13。

Microsoftの公式ヘルプに掲載された適用先は、Excel for Microsoft 365、Excel for Microsoft 365 for Mac、Excel 2024、Excel 2024 for Mac、Excel 2021、Excel 2021 for Mac、Excel 2019です。以下の入力手順は、このうちWindows版を対象にします。

最初に決めるのは、どのコードにどの案内文を対応させるかです。表示する文面が担当者ごとに異なるまま数式を作ると、計算結果の正誤と、案内内容の妥当性が混ざってしまいます。コードの意味、表示したい文面、対応するコードがないときの文面を、入力前に書き出すとよいです。

比較する値には、数値、日付、テキストなどを指定できます。ここでは少数の固定コードと定型文の対応に絞ります。案内文を決める担当者と、数式を直す担当者も分けておくと、文面の変更を計算の修正だけで済ませずに確認できます。

2．コードと案内文を交互に並べて入力する

SWITCH関数は、比較する値の後ろに、照合するコードと返す結果を組にして並べる構文です。一致しないときに返す既定値は、数式の最後の引数に置きます。コードだけを先に全部並べるのではなく、対応する案内文と隣り合わせで読むと、組み合わせを点検しやすくなります。

数式に直接書く文字列は、二重引用符で囲みます。資料手配の区分を題材に、入力コードと表示文面を次のように決めたとします。

入力コード区分の意味表示する案内文
D資料送付資料を送付します
S日程調整日程を調整します
X（登録外の例）対応する区分なしコードを確認

入力コードのセルをA2、案内文のセルをB2とした場合の数式例です。

「=SWITCH(A2,"D","資料を送付します","S","日程を調整します","コードを確認")」

数式例は、先頭に入力セルを置き、コードと案内文の組、その後に未一致時の文面を並べたものです。表の文面は説明用の対応であり、社内で用いる案内内容は担当者が決めます。

数式を入力した後は、WindowsではEnterキーで確定します。まず登録済みのコードを入れ、対応表の文面と照合します。登録のないコードも試す順番に含めると、通常の案内と確認が必要な表示を区別できます。

3．下へコピーした後は、入力セルとの対応を見る

数式を含むセルと入力先の隣接セルを選び、［ホーム］の［フィル］から［下］を選ぶと、下方向へ入力できます。下方向へのコピーでは、絶対参照や複合参照を含めない限り、相対参照が行ごとに調整されます。表示された案内文だけでなく、同じ行の入力欄を指しているかも点検するとよいです。

例のA2を固定しない相対参照で下へコピーする場合は、参照する行も移る仕組みです。コピー先が元の入力欄を見続けていないか、途中の行だけ異なる式になっていないかを見比べます。コードと文面の組を読む作業と、入力セルの位置を見る作業を分けると、どこを直すべきか整理できます。

コピー前に確認した対応表は、コピー後の照合にも使います。各コードが現れる行を選び、コードの意味と表示文面を対で読み合わせるとよいです。同じ文面が連続している部分だけを見るより、切り替わる位置を含めて確認するほうが、対応の取り違えを見つける助けになります。

4．未一致の表示と入力時のエラーを切り分ける

未登録コードと重複コード

一致する値がなく、既定値も指定していない場合、SWITCH関数は#N/Aエラーを返します。既定値を指定した場合は、一致するコードが見つからないときにその値を返します。運用では、未一致時の表示を通常の案内と混同しない文面にしておくとよいです。案内欄を見た人が入力内容を見直せるよう、確認する担当者も決めておきます。

同じコードを重ねて指定した場合も、返るのは最初に一致した値に対応する結果です。同じ区分なのに文面が違って見えるときは、対応の重複も点検対象に含めます。文面を追記するだけで済ませず、元の対応を置き換えるのか、別の区分を設けるのかを先に整理するとよいです。

数式を受け付けないとき

引数を区切る記号はOSのロケールとExcelの設定によって異なる場合があります。入力を受け付けない状態では、案内文の内容を直す前に、記号や引用符の入力を確認するとよいです。別の環境から受け取った数式も、文面の誤りと入力形式の違いを切り分けて見ます。

5．文面の変更と引き継ぎで残すこと

ここからは当社の整理です。

引き継ぎでは、コードの一覧だけでなく、各案内文をどの場面で使うかも残します。文字列が正しく表示されても、案内する内容が現在の運用に合っているとは限りません。文面を変更できる担当者と、変更後に読み合わせる担当者を決めておくとよいです。

未登録コードが見つかったときは、入力の誤りなのか、新たな区分が必要なのかを担当者が判断します。確認用の表示を、業務上の承認や却下の判断として扱わないことも、引き継ぎに含めます。数式へ組み込むのは、すでに決まっている対応です。新しい案内内容を決める作業とは分けて管理します。

引き継ぎ用のメモには、入力する欄、案内を表示する欄、文面の決定者、未登録コードが出たときの確認先、変更後に照合する項目を残します。修正の際は、変更した文面に対応する区分に加え、従来の区分と未登録の入力も照合対象にするとよいです。確認を終えた式をどの範囲へ反映するかまで決めると、担当者間で作業の区切りを共有できます。

事務の手間を洗い出すなら、コードを整える作業、文面を決める作業、結果を照合する作業を分けて、AIを使う前の業務整理につなげるとよいです。
