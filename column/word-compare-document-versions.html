変更履歴がないWord文書の二つの版を比べるには？

要点

Windows版Word for Microsoft 365では、［校閲］の［比較］で修正前と修正後のファイルを指定します。表示先を新しい文書にすると、元の二つの版に手を加えず差分を確認できます。比較の対象と表示先を確かめ、結果は比較用の文書として分けて扱います。

公開：2026年11月9日／情報の確認日：2026年11月7日（出典はこの記事の最後）

変更履歴が残っていないWindows版Wordの二つの版を比較し、元の文書と変更された文書を照合する手順です。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 1．元にする文書と変更後の文書を決める
  2. 2．［校閲］の［比較］で二つの版を指定する
  3. 3．変更の表示先を新しい文書にする
  4. 4．差分を元の二つの版へ戻って確かめる
  5. 5．比較結果の文書で、変更の種類と表示を確かめる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．1．元にする文書と変更後の文書を決める

情報の確認日：2026年11月7日

この記事で使うのは、Windows版Word for Microsoft 365の二つの文書を比較する操作です。Microsoftは、複数の校閲者からの変更を比較する場合はこの操作を選ばず、複数の作成者の変更を1つの文書に結合する別の操作を選ぶよう案内しています。

受け取ったファイルの名前が似ているときは、更新日時だけで順序を決めず、送付時の連絡や保存先から修正の前後を確かめます。どちらを基準にするか分からなければ、差分を出す前に文書の担当者へ確認します。比較するときは、両方のファイルをWordで開きます。

変更履歴が画面に見えない場合、表示設定も確かめます。Microsoftの変更履歴の案内では、［変更履歴なし］は変更履歴やコメントを隠して表示する設定です。比較時に既存の変更履歴を知らせるメッセージが表示された場合、Microsoftの案内では［はい］を選ぶと、変更を確定して比較します。先へ進む前に、その履歴を誰がどの状態で扱うかを確認します。

2．2．［校閲］の［比較］で二つの版を指定する

  1. ［校閲］タブの［比較］グループにある［比較］を開き、［ドキュメントの 2 つのバージョンを比較する（法的ブラックライン）］を選びます。
  2. ［元の文書］に修正前のファイルを指定します。変更後の欄で、修正後のファイルを選びます。
  3. 比較する項目を確認します。Microsoftの案内では、テキストの変更や書式設定、コメントなどを選べます。変更を表示する単位も、文字か単語から選びます。

基準となるファイルと変更後のファイルを逆に選ぶと、どの版を起点として結果を読むかが変わります。比較の目的に関係する項目を決め、結果を受け取る人にも分かるようにします。

3．3．変更の表示先を新しい文書にする

表示先は新しい文書にします。Microsoftの案内では新しい文書が既定ですが、元の文書や変更後の文書へ表示する選択肢もあり、その場合は選んだ文書が変更されます。二つの元ファイルを保つために、［OK］を選ぶ前に表示先を読み直します。

比較が終わると、差分を変更履歴の形で表示する別の文書が開きます。

これを保存する場合は、比較用と分かる名前を付け、もとの二つのファイルと区別します。確認先には、比較したファイルの組み合わせと、どの項目を比較したかを伝えます。

4．4．差分を元の二つの版へ戻って確かめる

ここからは当社の整理です。まず確認したい変更箇所を選び、修正前と修正後の該当箇所をそれぞれ開きます。結果の記号だけで決めず、差分の前後も読み、金額、日付、注記など意味が変わる箇所を担当者に示します。

確認すること比較結果と見比べるもの確認先へ伝える内容
どちらを基準にしたか修正前・修正後のファイルと送付時の連絡比較に使った二つの版
何を比較に含めたか比較する項目と文字・単語の表示単位今回の比較に含めた範囲
どの箇所の判断が要るか差分表示と両方の版の前後の文該当の見出し・段落と確認する理由

比較結果は、差分を確認する資料として渡します。文書を確定する担当が別にいる場合は、比較用ファイルに加え、採用を確認してほしい箇所を添えます。

5．5．比較結果の文書で、変更の種類と表示を確かめる

Microsoftの比較の案内では、比較した版に変更履歴があった場合、結果の新しい文書は、元の文書の変更履歴が受け入れられ、変更された文書の変更が変更履歴として表示されたものになります。

Microsoftの変更履歴の案内のWindowsの欄では、変更履歴の記録がオンの場合、削除された箇所は取り消し線、追加された箇所は下線で示され、別のユーザーによる変更内容は異なる色で示されます。比較結果も変更履歴の形で表示されるので、この印を目安に、削除と追加を分けて読みます。

同じ欄では、表示の種類として［シンプルな変更履歴］［すべての変更履歴］［変更履歴なし］［オリジナル］を挙げています。［すべての変更履歴］では、変更履歴が校閲者ごとに異なる色で表示されます。［オリジナル］では元の文書が表示されますが、承諾、拒否、または削除されていない変更履歴やコメントは文書内に残ると注意しています。

また、同じ欄では、［校閲］タブの［変更履歴とコメント］グループで［変更履歴とコメントの表示］を選び、挿入と削除、書式設定といった編集の種類を選んで表示できます。変更履歴を吹き出しに表示する場合は、印刷レイアウト表示または Web レイアウト表示で表示する必要があります。一部の種類を非表示にしても、自分または校閲者が文書を開くたびに変更履歴とコメントは自動的に表示されます。

比較結果を確認先へ渡すときは、表示を切り替えた画面だけで変更が無いと判断しません。文字の変更だけを見たのか、書式の変更も見たのかを、比較の条件と一緒に伝えます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□修正前と修正後のファイルを送付時の連絡や保存先から確かめたか。
□画面に見えない変更履歴や、比較時のメッセージの有無を確認したか。
□［元の文書］と変更後の欄に意図した版を指定したか。
□比較対象と文字・単語の表示単位を確認したか。
□表示先を新しい文書にしてから［OK］を選んだか。
□比較結果の表示の種類（すべての変更履歴・書式設定など）を確かめ、何を見たかを伝えたか。
□確認が要る箇所を二つの版と照合し、比較条件とともに伝えたか。
