Excelで月が横に並ぶ表を月と金額の縦長データにするには

要点

Power Query では、列を「属性」と「値」の組に変えられ、横に並んでいた列が行になります。 月の列が毎月増える表なら、営業所などの動かさない列だけを選んで［他の列のピボット解除］を使うと、更新で増えた新しい月の列もピボット解除されます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

4月・5月・6月と月を横に書き足していく売上表を、グラフや集計に回したい。Power Query の［ピボット解除］で、来月の列が増えても組み替え直さずに済む選び方を整理しました。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．月が横に並ぶ表の、何が使いにくいのか

確認日：2026年11月17日。

対象は Windows 版の Excel（Microsoft 365・2024・2021）です。

毎月の売上を、営業所を縦、月を横にして書き足していく表は、人が目で追うには分かりやすい形です。一方で、月ごとの推移をグラフにしたり、別の集計表に渡したりするときには、月の列が増えるたびに範囲を直す手間が出ます。

公式ヘルプでは、データのピボットを解除して、似た値がすべて1つの列に入るようにでき、これはグラフやレポートを作るときなどに必要だと説明されています。 横に並んだ月を「月」の列に、それぞれの金額を「金額」の列に集めた縦長の形にしておけば、月が増えても行が増えるだけで済みます。

行と列をそのまま入れ替える操作とは違い、営業所の列は残したまま、月の列だけを縦に並べ直す点がこの操作の要です。

2．表を Power Query エディターに読み込む

元の表を Excel のテーブルにしておき、テーブルの中にカーソルを置いて、［データ］の［データの取得 & 変換］から［テーブル/範囲から］を選びます。 Power Query エディターが開き、プレビューの画面にデータが出ます。

ヘルプには、Power Query に読み込んで変換しても新しいワークシートができ、元のワークシートは変わらないと書かれています。 毎月の入力は今までどおり横長の表で続け、集計やグラフには縦長の結果を使う、という分け方ができます。

すでに読み込んだクエリを開き直すときは、結果のデータのセルを選んで［クエリ］の［編集］を選びます。

3．3つのピボット解除は、来月の列で差が出る

ピボット解除には、［列のピボット解除］［他の列のピボット解除］［選択した列のみをピボット解除する］の3つがあり、列を右クリックするか、リボンの［変換］タブから選べます。 作った直後の結果は、どれを選んでも同じ形になります。違いが出るのは、元の表に新しい月の列を足してからクエリを更新したときです。

選ぶもの最初に選ぶ列新しい月の列を足して更新したとき
列のピボット解除月の列新しい列もピボット解除される
他の列のピボット解除営業所など動かさない列新しい列もピボット解除される
選択した列のみをピボット解除する月の列選んだ列だけで、新しい列はそのまま残る

公式の説明では、［他の列のピボット解除］は、更新で新しい日付の列が加わる場合に理想的なやり方とされています。 反対に［選択した列のみをピボット解除する］では、最初に選んだ列にだけピボット解除が適用されるため、後から足した列は変わりません。 月の列が毎月増える表では、動かさない列を選ぶ［他の列のピボット解除］にしておくと、選び直しの手間がありません。

4．営業所の列を選んで、残りを縦にする

エディターで営業所の列を選び、［変換］の［他の列のピボット解除］を選びます。 営業所と担当者のように動かさない列が2つ以上あるときは、Ctrl キーを押しながらクリックして一緒に選びます。

結果は、営業所の列に、「属性」と「値」の2列が足された形になります。Power Query は、属性と値の組を作るときに常に2つの列を使い、属性にはピボット解除した列見出しの名前、値にはその見出しの下にあった値が入ります。 月の見出しが「属性」に、金額が「値」に入る、ということです。

5．Excel に戻して、中身を確かめる

変換したデータは、［ホーム］の［閉じる & 読み込み］で Excel に戻します。既定では新しいワークシートに読み込まれ、ヘルプでは、元のワークシートと区別しやすいように新しいワークシートの名前を変えることが勧められています。

読み込んだ後は、次の3点を確かめます。1つ目は行の数で、営業所の数と月の数を掛けた数になっているかを見ます。2つ目は、月の見出しが入る「属性」の列の型です。Learn の例では、日付の見出しだった列が、ピボット解除の後はテキストのデータ型の属性の列になっています。 Power Query はデータ型を解釈し、後で調整できると説明されているので、月として並べ替えたいときは型を見直します。 3つ目は、元の表の空欄の月が結果でどう扱われているかで、空欄だった所を金額0と読み違えないよう、元の表と数か所を突き合わせます。

6．毎月の回し方（架空の例）

時期誰がすること
月初入力の担当者元の横長の表の右端に、新しい月の列を足して金額を入れる
入力の後集計の担当者［クエリと接続］のクエリで［最新の情報に更新］を選び、行の数が営業所の数だけ増えたかを見る
報告の前確認者縦長の結果から、新しい月の合計を出し、元の表の列の合計と照らす

［最新の情報に更新］は、［クエリと接続］ウィンドウの［クエリ］タブで使えるコマンドとして案内されています。 入力の担当者は横長の表だけを触り、縦長の結果のシートには手を入れない、と決めておくと、どちらが元のデータかで迷いません。集計の担当者は、更新の後に行の数と新しい月の合計の2つだけを見れば、取り込み漏れに気づけます。
