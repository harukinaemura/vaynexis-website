Microsoft Formsの分岐の追加で不要な質問を飛ばすには

要点

Microsoft Forms では、分岐を始めたい質問で［その他のオプション］ボタンから［分岐の追加］を選び、質問に対する考えられる回答ごとに分岐先の質問を選びます。 分岐できるのは今の質問より後の質問かフォームの終わりだけで、前の質問には分岐できません。 設定したら、デザイン ウィンドウの上の［プレビュー］で、分岐がどう働くかを確かめます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

社内アンケートで「いいえ」と答えた人にまで関係のない質問が続き、空欄だらけの回答が集まってしまう。Microsoft Forms で回答ごとに進む先を決める操作と、前の質問へは戻せない制約、プレビューでの確かめ方を見ていきます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

分岐の流れ図にある聞き取りの質問は架空の例です。流れを紙に書いてから設定する進め方や確認表は当社がすすめる目安で、Microsoft の手順として書かれたものではありません。

1．Google フォームとは別の道具の話

確認日：2026年11月17日。

対象は Microsoft Forms です。ヘルプでもアンケート、クイズ、投票を作る道具として紹介されている Microsoft の道具で、Google の道具である Google フォームとは、画面も操作の名前も違います。Google フォームで回答によって質問を分ける方法（セクションを使った分岐）は、公開済みの別の記事で扱っています。会社で使っているのがどちらの道具か、フォームの編集画面の上の表示やアドレスで先に確かめてから読み進めてください。

Microsoft のヘルプでは、分岐するアンケートやテストでは、質問は回答者に関係がある場合にのみ表示され、該当しない場合は別の質問のまとまりに送られたり、すっかりスキップされたりする、と説明しています。 たとえば社内の研修の申し込みで「車で来るか」を聞き、「いいえ」の人には駐車場の質問を出さない、といった使い方です。答える側は自分に関係のある質問だけを読めばよくなり、集める側も空欄だらけの回答を見なくて済みます。

2．分岐は、質問を全部作り終えてから入れる

ヘルプは、分岐を始める前に、テストまたはフォームの質問をすべて作成しておくことを勧めています。 分岐は「この回答なら、どの質問へ進むか」を質問ごとに決めるものなので、途中で質問を足したり順番を入れ替えたりすると、決めた行き先がずれやすくなります。紙に質問の流れを書き出して、どの答えのときにどこへ進むかを決めてから、画面で設定すると手戻りが減ります。

3．分岐の追加の手順

順番操作
1分岐するフォームを開く
2分岐を始める質問を選び、［その他のオプション］ボタンから［分岐の追加］を選ぶ
3［分岐オプション］ページで、質問の横の［ドロップダウン リスト］を選ぶ
4回答ごとに分岐先の質問を選ぶ（最後にする場合はフォームの［末尾］）
5ほかの質問にも分岐が要るなら、手順を繰り返す

手順3と4は、分岐ロジックのヘルプでは、［分岐オプション］ページで分岐する質問の横にある［ドロップダウン リスト］を選び、分岐先の質問を選ぶ、と書かれています。 ある答えの人にはそこでフォームを終えてもらいたい場合は、分岐先としてフォームの［末尾］を選びます。 必要な数の質問に分岐を作るには、同じ手順を繰り返します。

4．前の質問へは戻せない

いちばん気をつけたいのが、分岐の向きです。ヘルプでは、7 つの質問があるフォームで質問 4 に分岐を付けるなら、行き先にできるのは質問 5、6、7 かフォームの終わりだけだ、と例を挙げています。

さらに、前の質問へ分岐させようとすると、回答の途中の流れが途切れ、後ろの質問を飛ばして［送信］ボタンのあるフォームの最後へ直接移ってしまう、とも書かれています。 「答え直してもらうために前の質問へ戻す」という作り方はできないので、確かめたいことは後ろの質問として置き直します。答えの組み合わせで聞く内容が大きく変わる場合は、無理に1つのフォームにまとめず、フォームを分けることも考えます。

5．長いフォームは、セクションに分けてから分岐する

質問が多いフォームでは、質問を複数のページまたはセクションに整理できます。 セクションを足すには、［＋新規追加］を選び、フォームの一番下までスクロールして［新しい質問の追加］を選び、［セクション］を選びます。 フォームにセクションを追加した場合は、セクションに分岐を追加することもできます。

セクションの分岐は、セクションの右上の［その他のオプション］ボタンの［詳細設定］から選ぶメニューの1つとして案内されています。 なお、フォームにセクションを含めると、質問のシャッフル機能は無効になります。 質問の順番を回答者ごとに入れ替えたいフォームでは、セクションを使うかどうかを先に決めておきます。

6．プレビューで、すべての道をたどる

設定が終わったら、デザイン ウィンドウの上にある［プレビュー］を選び、コンピューターやモバイル デバイスで分岐がどう働くかを確かめます。 確かめるときは、「はい」と答えた場合、「いいえ」と答えた場合のように、分岐の数だけ道をたどります。1つの道だけを試して公開すると、もう一方の道で質問がまるごと飛ばされていた、という見落としが起きやすいからです。

作り直したいときは、［分岐オプション］ページの［その他のオプション］（…）アイコンを選び、［リセット］を選ぶと、分岐をまとめて消せます。 一部だけ直したいときにリセットすると、すべての分岐を決め直すことになるので、紙の流れ図と見比べながら使います。

7．分岐の流れ図（架空の例）

社内の事務作業を洗い出す聞き取りのフォームを作る場面です。

質問（架空の例）回答分岐先
質問1：毎月決まって行う事務作業がありますかはい質問2（作業の名前）
質問1：毎月決まって行う事務作業がありますかいいえ質問4（困っていること）
質問2：作業の名前（記述）質問3（かかる時間）
質問3：1回にかかる時間（選択）質問4
質問4：困っていること（記述）フォームの［末尾］

聞き取りのフォームに分岐を入れておくと、毎月の作業が無い人は質問2と3を飛ばして早く答え終えられます。事務の作業を洗い出して、どこから手を付けるかを考えるときは、事務の道具と作業の棚卸しの考え方も使えます。
