Excelの報告グラフの下に元の数値表を付ける手順と確認点

要点

Excelの報告グラフに元の数値表を添えるには、グラフの作成に使う数値を格子状に表示する「グラフのデータ テーブル」を使います。表示後は、数値だけでなく期間と項目名も元の集計表と対応させ、図と表を続けて読めるか確かめます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Excelの報告用グラフの下に元の数値も並べて見せたい小さな会社の担当者が、グラフのデータ テーブルの表示の手順（デスクトップ版・Web 版）と、元の集計表との照合を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 表示するのは、グラフの元になった数値です
  2. デスクトップ版では、グラフ右上のプラス記号から表示します
  3. Web版では、右側の作業ウィンドウから切り替えます
  4. 短い集計表で、期間と分類を対応させます
  5. 値が違うときと、文字が読みにくいときを分けて点検します
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．表示するのは、グラフの元になった数値です

確認日：2026-11-11（日本時間）

Microsoft の「グラフの凡例やデータ テーブルの表示/非表示を切り替える」の適用先には、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 が含まれます（同じページに Word・Outlook・PowerPoint の各版も並んでいます）。この記事のデスクトップ版の手順は、同ページの「新しいバージョン」の欄の手順です。まず、すでに報告用の図があり、その下に数値を並べて見せたい場面を出発点にします。集計方法の変更や、新しい図の作成には進みません。

グラフのデータ テーブルは、一部のグラフに追加でき、通常は横軸に付いて目盛ラベルに代わる形で表示されます。表示前後を比べる際は、下に表が現れたかに加え、項目の名前をどこで読む構成になったかを見ます。図の下に文字が増えただけで完成とせず、どの項目の値なのかを追えることを仕上がりの基準にします。

同じ用語集では、異なる値を数式に代入した結果を並べる「データ テーブル」と、数値を表示する「グラフのデータ テーブル」が別に定義されています。今回の目的は、すでにある集計結果を読み手に示すことです。設定を探す前に、試算をしたいのか、報告に数値を添えたいのかを分けておくと、操作の入口を取り違えにくくなります。

2．デスクトップ版では、グラフ右上のプラス記号から表示します

対象のグラフを選び、その右上にあるプラス記号を選択します。報告書に図が並んでいる場合は、数値を添えたい図が対象になっているか、見出しや期間を見てから進めます。近くの別の図を選んでいると、表示できても目的の資料とは違う仕上がりになります。

続いて［データ テーブル］にポインターを合わせ、横の矢印を開いて表示オプションを選びます。

添えた表を非表示に戻すときは、［データ テーブル］のチェックを外します。

3．Web版では、右側の作業ウィンドウから切り替えます

Microsoft の「グラフを作成する」は Windows・macOS・Web の欄に分かれており、その Web の欄では、グラフをダブルクリックして、画面右側の［グラフ］作業ウィンドウを開きます。

［書式設定］の［データ テーブル］で、オンとオフを切り替えます。

さらに［データ テーブル］を展開すると、罫線、凡例、表のフォントを変更できます。値を見分けにくい場合は、装飾を増やす前に文字の読みやすさを見直します。読み手が値の所属を追えるか、隣の値と混同しないかを基準に整えます。

4．短い集計表で、期間と分類を対応させます

ここからは当社の整理です。

社内説明会の申込件数を窓口別にまとめた、次の集計結果を考えます。図の大小から全体の動きをつかみ、下の表で個別の値を読む資料にしたい場面です。ここでは、下表を元にした図がすでにあるものとして扱います。

受付月社内窓口（件）申込フォーム（件）
春の受付月1826
夏の受付月2331
秋の受付月2029

照合は、元の集計表の項目名を読み、表示された表で同じ項目を探し、続いて分類名と値を見る順で行います。表の形が元と違っていても、見出しをたどって対応できるかが確認点です。行や列の位置だけを頼りに、端から値を比べないようにします。

件数なのか金額なのか、対象期間はどこまでかも、読む前提としてそろえます。単位の説明が離れた場所にしかないと、数値を読めても意味を取り違えるおそれがあります。表題や近くの説明を含め、資料を初めて見る人にも前提が伝わる構成かを見直します。

説明用の表を別に手入力する前に、表示された値と元の集計結果を見比べます。違いがあれば、先に対象期間や分類の対応を点検します。報告に都合のよい値へ合わせるのではなく、どの値を示す資料なのかを明らかにするための照合です。

5．値が違うときと、文字が読みにくいときを分けて点検します

数値の違いは、見出しの対応から確認します

数値が合わない場合は、元の集計表と表示した表が同じ対象を指しているかを先に見ます。期間が違う、分類名が似ている、合計と内訳を見間違えている、といった違いを順に点検する流れです。表の見栄えを直す作業に入る前に、内容の食い違いがあるのかを判断します。

表に数値が現れたことは、集計内容の確認を終えたこととは別です。読み手が問うのは、その値が何を数えたものかであり、作成者だけが分かる略称が残っていないかも確認します。見出しを読んでも対象が特定できない場合は、報告資料としての説明を補う余地があります。

読みにくさは、受け手が使う大きさで確認します

内容が合っているのに読みにくい場合は、見出しの長さ、隣接する値の見分けやすさ、図と表の間の視線の移動を見ます。作成中の拡大した画面だけでなく、受け手が読むときに近い大きさで確認すると、詰まり具合を判断しやすくなります。紙で配る予定なら、出力した状態で項目名と値を追えるかを見る流れです。

引き継ぎ時は、元の集計表の場所と対象期間を伝え、見た目を変えた箇所も短く残します。後任が数値を見直す際に、どこを照合すればよいかが分かることが目的です。完成の判断は表が付いたかだけで終えず、図で傾向を読み、表で値を確かめる流れが途切れないかまで含めます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□数値を添える対象の図と、元の集計表を対応させたか
□使用する環境に合う手順を選んだか
□表示された項目名と分類名を、元の集計表と照合したか
□表示した値が、同じ対象期間の値に対応するか確認したか
□数量の単位や対象範囲が読み手に伝わるか確認したか
□配布時に近い大きさで、見出しと値を続けて読めるか確認したか
□引き継ぐ相手に、元の集計表の場所と確認した範囲を伝えたか
