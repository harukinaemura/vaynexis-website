Wordの文字カウントで選択した文章だけの文字数を見るには

要点

数えたい文章を選ぶと、Word のステータス バーに、選んだ部分と文書全体の数が並んで表示されます。 文字数・段落数・行数まで見たいときは、ステータス バーの文字カウントをクリックします。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

申請書の「400字以内」の欄など、文書の一部だけの字数を確かめたいときに、Word で選んだ部分の数をステータス バーで読む方法を確かめます。文字数・段落数・行数を開く文字カウント、Mac 版と Web 用 Word での入口の違い、文書全体の数を本文に入れるフィールドも分けて扱います。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

欄ごとの字数の表と確認表は、架空の申請書を想定して当社がまとめたもので、Microsoft のヘルプが示す手順そのものではありません。

1．「全体の数」を見て安心してしまう

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Word（Microsoft 365 などのデスクトップ版）です。ヘルプの適用先は、Word for Microsoft 365、Word 2024、Word 2021 と、それぞれの Mac 版です。 Mac 版とブラウザーで開く Web 版は数え方の入口が違うので、後の節で分けます。

補助金の申請書や応募書類では、「事業の概要（400字以内）」のように、欄ごとに字数が決まっていることがあります。一つの文書に複数の欄を書いていると、画面の下に出ているのは文書全体の数なので、欄ごとの字数は分かりません。欄の文章だけを選んで数える、という一手間で、提出前の書き直しを減らせます。

ヘルプでは、Word は入力しながら文書の単語数を数え、ページ数・段落数・行数・文字数も数えている、と説明されています。

2．選んだ部分だけを数える手順

順番操作
1数えたい欄の文章を、ドラッグして選ぶ
2画面の下のステータス バーを見る（選んだ部分と、文書全体の数が並ぶ）
3文字数・段落数・行数を見たいときは、ステータス バーの文字カウントをクリックする

3．詳しい数と、テキスト ボックス・脚注の扱い

同じ Microsoft のヘルプに「文字カウント」というページがあり、Microsoft 365 の Word（Windows のデスクトップ版）のタブに、もう少し詳しい書き方があります。「文字カウント」のページの適用先は、Word for Microsoft 365、Word for Microsoft 365 for Mac、Word for the web です。

  • 表示の場所：Word は、ウィンドウの左下隅にあるステータス バーに数を自動で表示します。
  • 一部だけを数える：数えたい部分を選ぶと、ステータス バーに選んだ部分の合計が出ます。
  • 詳しい画面：ページ、段落、文字数などの詳細を見たいときや、テキスト ボックスや脚注を合計に含めたいときは、［レビュー］タブで［Wordカウント］を選ぶ、と書かれています。

ヘルプの表記は、タブによってそろっていません。同じページの Mac のタブでは、［校閲］の［文字カウント］に移動して数を確かめる書き方です。 社内の手順書に書くときは、自分の Word のリボンにどちらの名前で出ているかを確かめてから書きます。

申請書の様式によっては、欄がテキスト ボックスで作られていたり、注記が脚注になっていたりすることがあります。テキスト ボックスや脚注を合計に含めるかどうかは詳しい画面で決める、というのがヘルプの書き方なので、様式の作りが分からないときは、選んで数えた数と詳しい画面の数を見比べてから書き留めます。

4．数える前にそろえておくこと

  • 見出しや「（400字以内）」などの注記まで選ばない：欄の本文だけを選びます。
  • 選び直したら数も変わる：数を書き留めるのは、文章を直し終えてからにします。
  • 提出先の数え方を確かめる：句読点や空白を字数に入れるかどうかは、提出先の決まりによります。Word の数と提出先の数え方が合っているかは、募集要項で確かめます。

5．Mac 版と Web 用 Word では入口が違う

同じヘルプでも、Mac のタブと Web のタブでは書かれている操作が変わります。Windows 版の手順をそのまま伝えると迷う人が出るので、分けて押さえます。

  • Mac 版：ステータス バーの単語数をクリックすると［Word カウント］ボックスが開き、文字数、行、段落などを見られます。 テキストを選んでいないときは、文書のすべてのテキストと文字が数えられ、統計としてボックスに出ます。 一部だけを数えたいときは、その文章を選んでから［ツール］メニューの［文字カウント］をクリックします。
  • Web 用 Word：デスクトップの Word と同じように、入力しながら単語を数えています。 画面の下に数が出ていないときは、［編集］ビューになっているかを確かめます。 ［編集］ビューにするには、［ドキュメントの編集］をクリックし、続けて Web の Word で［編集］をクリックします。 画面の下の文字カウントは、クリックするたびに表示と非表示が切り替わります。

たとえば、共有フォルダーの申請書の下書きを、総務の人は Windows の Word、営業の人は出先でブラウザーから開いて直す、という場面を考えます（架空の例）。ブラウザーで開いた人が閲覧の画面のままだと、下に数が出ないまま「字数は見当たらない」となりがちです。誰がどの画面で数えるのかを先に決め、Web で開く人には［編集］ビューに切り替えてから数えるよう一言添えておくと、確認の行き違いが減ります。

6．文書全体の数を本文の中に表示しておく方法

欄ごとの字数とは別に、文書全体の数を本文の中に書いておきたいときは、フィールドを使う方法が別のヘルプに載っています。Word では、文書に文字数を挿入し、必要に応じてその情報を何度でも更新できます。 手順は、数を表示したい位置を選び、［クイック パーツ］からフィールドの挿入を開いて、［フィールドの名前］の一覧で［NumWords］を選び、［OK］を選ぶ流れです。 文章を直したあとは、フィールドを追加した位置を右クリックして［フィールド更新］を選びます。 印刷のたびに新しい数にしたいなら、［ファイル］→［オプション］→［表示］の［印刷オプション］で［印刷前にフィールドを更新する］を選びます。 このページの適用先は、Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016 です。 ここで入るのは文書全体の数で、選んだ欄だけの数ではありません。欄ごとの字数は、ここまでの節のとおり選んで数えます。

7．欄ごとに字数を残しておく（架空の例）

欄決まった字数選んで数えた結果直したこと
事業の概要400字以内412字前置きの一文を削った
取り組みの内容800字以内765字そのまま
期待する変化300字以内298字そのまま

表の「選んで数えた結果」には、ステータス バーに出た数をそのまま書きます。提出先の数え方に合わせて数え直したときは、その数え方も横に書いておくと、あとで別の人が見直すときに迷いません。

字数を数えて直す作業は、締め切り前にまとめてやると時間がかかります。書類作りの流れの中で、どこで数えるかを決めておくと楽になります。申請書のように字数の決まった書類が多いなら、どの書類のどの欄をいつ数えるかを、事務の道具と作業の棚卸しの要領で一覧にしておく方法もあります。

8．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□数えたい欄の本文だけを選んだか（見出しや注記を含めていないか）
□ステータス バーの、選んだ部分の数を読んだか（文書全体の数と取り違えていないか）
□文字数・段落数・行数が要るときは、文字カウントをクリックしたか
□テキスト ボックスや脚注のある様式では、詳しい画面で合計に含めるかを確かめたか
□提出先の数え方（句読点や空白の扱い）を募集要項で確かめたか
□直し終えたあとに数え直したか
□Mac 版の人には［ツール］メニューの［文字カウント］を、Web で開く人には［編集］ビューを案内したか
□本文に入れた数のフィールドは、直したあとに［フィールド更新］をしたか
