Excelの数字への質問と返答をセルのコメントに残すには

要点

数字について質問と返答を残すには、返信欄のあるスレッド形式コメントを使い、対象セルでやり取りを続ける形にすると、質問とその回答を会話の流れとしてまとめて読み返せます。

公開：2026年11月4日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelの表の数字について質問と返答をセルに残したい小さな会社の担当者が、コメントの投稿・返信・解決と、メモとの違いを Microsoft のヘルプで確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 返信を残したいときは、メモとの違いを見る
  2. 対象セルから質問を投稿し、同じ場所へ返信する
  3. 質問には、答えてほしい内訳を短く添える
  4. やり取りを終えたら解決し、後から読み返す
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．返信を残したいときは、メモとの違いを見る

メモには返信欄がなく、コメントには返信欄があるため、数字について質問と回答を残すときはコメントを使います。スレッド形式のコメントとメモの違いを説明する Microsoft のヘルプは、Excel for Microsoft 365 ではコメントの動作方法が変更され、コメントがスレッド化されたと説明しています。以下の操作は、Microsoft のヘルプ「Excel でコメントとメモを追加する」の Windows の手順に沿って整理します。このヘルプの適用先は、Excel for Microsoft 365、Excel for Microsoft 365 for Mac、Excel 2024、Excel 2024 for Mac、Excel 2021、Excel 2021 for Mac、Excel for iPad、Excel for iPhone、Excel for Android タブレット、Excel for Android スマートフォンです。

ここでは、表の数字について質問を付け、その場所へ回答を返す操作を扱います。数字の正しさを判定する方法や、社内での確認責任・承認の判断は対象にしません。まず対象の行や列を見て、何について尋ねたいのかを整理しておくとよいです。「数字が気になる」という状態から、内訳や含まれる範囲など、相手に答えてほしい点を言葉にしていきます。

2．対象セルから質問を投稿し、同じ場所へ返信する

質問を付ける

質問を付けたいセルを右クリックし、［新しいコメント］を選びます。コメント欄に質問の文章を入力します。コメントでは、宛先にしたい相手を @mention で指定でき、指定するとコメントの通知がメールで送信されると案内されています。書いた質問は、［投稿］ボタンで送ります。投稿したコメントは、対象セルの上にカーソルを置くと表示されます。

相手が返答する

返答する側は、質問のあるセルを右クリックして［コメントに返信する］を選び、返信を残します。編集できるのは自分が作成したコメントだけなので、質問の文面は直さず、返信で答える形になります。

操作をたどるときは、文章を入力する前に、尋ねたい数字のある行・列と選択中の位置を照らし合わせます。質問を置く場所と、質問の中で指している対象をそろえるための確認です。返答を読む際も、どの数字に対する答えかを見直すとよいです。

3．質問には、答えてほしい内訳を短く添える

ここからは当社の整理です。

「この金額でよいですか」だけでは、相手が何を調べればよいか迷う場合があります。質問には、気になっている内訳や、含まれているか知りたい費目を添えるとよいです。回答側も、結論だけでなく、どの資料を見たかを短く残す形にします。

対象質問の文面返答の文面
備品の金額欄この金額には送料も含まれていますか。見積書の内訳を確認しました。送料を含む金額です。

この例では、金額そのものの変更より先に、「送料を含むか」という問いを明らかにしています。質問と返答の言葉を対応させると、後から読む人も何について答えたのかを追いやすくなります。

質問が広すぎると感じたときは、相手に尋ねる前に、知りたい点を短い文章へ整えます。違和感の理由がまだ分からない段階では、誤りだと断定せず、何が分からないかを書く形でも構いません。

返答を受けた後に別の疑問が出た場合も、前の答えと新しく尋ねたい点を文章の中で分けるとよいです。前の返答のどこまでが分かり、何が残ったのかを明らかにするためです。読み返すときは、質問の表現と答えの対象がずれていないかを見るようにします。

4．やり取りを終えたら解決し、後から読み返す

解決済みにする

Microsoft のヘルプの手順では、やり取りが終わったら、対象セルの上にカーソルを置き、［その他...］を選んでスレッドを解決します。

同じヘルプによると、解決済みのコメントは引き続き表示できますが、追加の書き込みにはスレッドを再度開く操作が必要です。コメントの解決と再度開く操作は、ブックへの書き込みアクセス権を持つユーザーが行えます。

追加できないときと、見返すとき

Microsoft のヘルプでは、すべてのコメントを一度に表示するには［校閲］タブの［コメントの表示］をクリックし、すべてのコメントとその返信が含まれる［コメント］ウィンドウが右側に表示されると案内されています。やり取りをまとめて見返すときに使えます。

返答を続けたい場面では、入力できる場所を探すだけでなく、やり取りが終わった状態になっていないかも見ます。表示が見つからないときは、質問を書いた位置と、今選んでいる位置を照らし合わせるとよいです。

最後は、相手の返答が質問への答えになっているかを読み直します。求めた内訳が分かったのか、それとも追加で尋ねることが残っているのかを整理してから、やり取りを閉じる流れです。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□質問を付けた位置が、尋ねたい数字のある行・列と合っているかを確認したか
□相手に答えてほしい内訳や範囲を、質問の文章に書いたか
□入力した質問が、投稿後に読めることを確認したか
□質問とその回答が同じ場所で読めるかを確認したか
□返答が質問の内容に対応しているかを読み直したか
□やり取りを終えた後も、質問と返答を読み返せるかを確認したか
