Excelの受付表で未入力の必須欄が何件残るか数えるには

要点

必須欄だけを集計範囲にして、COUNTBLANK 関数で空欄の個数を数えます。受付済みの行に対象を絞り、任意欄や将来の受付用の空行を外すのが当社の整理です。結果は入力漏れのある受付の件数とは区別して扱います。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Excelの受付表で必須欄の入力漏れが何件残っているかを数えたい小さな会社の担当者が、COUNTBLANK 関数で数える範囲の決め方と、0 や空文字列の扱いを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 空欄を数える機能と、使う版を確かめる
  2. 受付済みの行と、必須の列を先に決める
  3. 小さな受付表で式と結果を対応させる
  4. 数値のゼロと、数式による空欄を分けて読む
  5. 合わない結果は、範囲と式の形から確認する

1．空欄を数える機能と、使う版を確かめる

確認日：2026年11月11日。

Microsoft の「COUNTBLANK 関数」のページの適用先は、Excel for Microsoft 365、Excel for Microsoft 365 for Mac、Excel 2024、Excel 2024 for Mac、Excel 2021、Excel 2021 for Mac、Excel 2019、Excel 2016 です。Web 版とモバイル版はこの一覧に無いため、この記事では扱いません。

数える対象を指定する「範囲」は必須の引数で、空白セルの個数を調べるセル範囲を入れます。受付表の全体と、入力を求める欄を分けて考えるのが当社の整理です。見出しや管理用の欄までまとめて選ぶ前に、何を入力待ちとして扱うかを決めます。

基本の書き方は「=COUNTBLANK(範囲)」です。かっこの中を、手元の表で数えたい場所に置き換える形です。

2．受付済みの行と、必須の列を先に決める

ここからは当社の整理です。

対象は、受付があったことを識別できる行に限定します。表の下に用意した記入用の行は、今回の入力漏れの確認から外す扱いです。担当者が見る範囲と集計範囲をそろえておくと、結果を照合するときに前提がずれにくくなります。

次に、受付後に埋める必要がある欄と、記入が任意の欄を分けます。依頼内容や担当の記入を必須にするかは業務側の判断です。自由記入の備考まで対象に加えず、引き継ぎ時に不足を確認する欄を明記します。

受付の種類によって記入の要否が違う欄は、全件共通の必須欄とは区別します。対象外の受付に残る空欄を、入力待ちとして担当者へ戻さないためです。今回の集計には、対象の受付で共通して埋める欄を選ぶ方針にします。

集計結果の横には、受付日の期間と対象の欄名を短く書き添えます。翌日の担当者も、どの範囲を数えた値かを確かめられます。

3．小さな受付表で式と結果を対応させる

Microsoft の「Excel の数式の概要」は、組み込み関数を含む数式の入力を、空のセルを選択し、等号を入力してから関数を入力し、左かっこを入力し、セルの範囲を選択してから閉じかっこを入力する順で案内しています。COUNTBLANK の場合は、集計結果を置く空のセルを選び、「=COUNTBLANK(」の後に必須欄の範囲を選んで右かっこを入力します。結果を表示するには Enter キーを押します。

関数名を入力すると一致する関数や引数のヒントが表示されるので、COUNTBLANK のつづりと、かっこの中の範囲を確認できます。

説明用の表では、依頼内容と担当を必須欄とし、受付識別は集計に含めない扱いです。表の空欄には何も入力していない状態を置いています。

行A列：受付識別B列：依頼内容（必須）C列：担当（必須）
2甲変更
3乙
4丙相談確認済

この例で「=COUNTBLANK(B2:C4)」と入力した場合、表の空欄を数えた計算上の結果は 3 です。

欄ごとに見る例では、「=COUNTBLANK(B2:B4)」の結果は 1、「=COUNTBLANK(C2:C4)」の結果は 2 となります。全体の不足を知る値と、どの欄の確認が残っているかを知る値を分けておく考え方です。受付識別と不足している欄を照合して、確認先を探します。

ここで数えているのは空白セルの個数なので、同じ受付に未入力欄が重なっていても、受付をまとめた件数にはなりません。引き継ぎの報告でも、未対応の受付の数と記入待ちの欄の数を混ぜず、報告する値の意味をそろえます。

4．数値のゼロと、数式による空欄を分けて読む

COUNTBLANK 関数の解説では、空白文字列（""）を返す数式が入力されているセルも計算の対象となり、数値として 0 を含むセルは計算の対象となりません。入力待ちの意味を確認する際には、見た目だけでなく、その欄へ何を入れる決まりなのかも照合するのが当社の整理です。

たとえば、件数を入力する欄で「該当なし」と「まだ確認していない」を区別したい場面があります。担当者が入力すべき内容を確認し、仮の値を入れて空欄だけをなくす運用にしない方が、確認待ちの状態を残せます。空欄を埋めることと、記入内容を確かめることは別の作業として扱います。

なお、COUNTA 関数では空の文字列（""）やエラー値を含むセルも計算の対象となるため、こちらの結果をそのまま正しく入力済みの欄の数として扱うのは避けます。

対象セルに入力されている数式は、そのセルを選ぶと数式バーで確認できます。空欄の理由を確かめるときは、手入力を待っている欄なのか、計算の結果を表示する欄なのかを分けておくと、問い合わせる相手や直す場所を考えやすくなります。

5．合わない結果は、範囲と式の形から確認する

結果の照合は、当社の整理として、受付済みの範囲、必須欄の選び方、入力内容の順で進めます。新しく受け付けた行を対象へ加えたか、表の途中の任意欄まで数えていないかを見てから、セルの内容を確かめる流れです。

Microsoft の「Excel で壊れた数式のエラーを回避する方法」は、循環参照は数式が配置されているセルを参照するときに発生するとしています。集計結果は数える範囲の外に置きます。入力欄の途中に結果の欄を作らず、集計の場所が分かる配置にすると、担当者が表を見直す際にも区別しやすくなります。

数式が計算されないときは、先頭が等号になっているか、左かっこと右かっこが対応しているかを確認します。

最後に、結果と実際の不足箇所を照合します。残っている欄の担当者が分からないときは、入力の役割分担を決め直します。空欄がなくなった後も、受付に必要な内容がそろっているかは、欄の意味に沿って人が確認します。
