PowerPointの説明資料を動画にする｜音声とスライドの時間を確認

要点

Windowsデスクトップ版のPowerPointでは、元の資料を保存して、［記録］タブの［ビデオにエクスポート］（または［ファイル］からの［ビデオの作成］）へ進みます。記録したナレーションとタイミングを使うかを選び、MPEG-4ビデオとして保存します。配布前に完成動画を再生し、音声と切り替わりを確認します。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、PowerPointの説明資料を配布用の動画にしたい小さな会社の担当者が、記録したナレーションとタイミングの扱い、品質とファイルの種類、動画に含まれないものを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 書き出す原稿と収録を照らす
  2. ナレーションとスライドの時間を選ぶ
  3. 画質と保存先を選び動画を書き出す
  4. 完成した動画を開いて確認する
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．書き出す原稿と収録を照らす

確認日：2026年11月10日。

Microsoftの案内「プレゼンテーションをビデオに変換する」の適用先は、PowerPoint for Microsoft 365、PowerPoint 2024、2021、2019、2016 です。案内の手順は、スライドを作り、タイミングとナレーション、レーザー ポインターの動きを記録したら、ビデオ ファイルを作る準備ができるという流れです。最初に［ファイル］メニューの［保存］で、最近の作業がすべてPowerPoint プレゼンテーション形式（.pptx）で保存されていることを確かめます。

動画を作る画面へは、［ファイル］から［ビデオの作成］を選ぶ経路（ページの表記は「ファイル > Export > ビデオの作成」）と、リボンの［記録］タブで［ビデオにエクスポート］を選ぶ経路が示されています。同じページでは、開くと編集モードではなくスライド ショーが全画面で表示される PowerPoint スライド ショー（.ppsx）として保存する方法も、別の手順として案内されています。この記事は、ビデオ ファイルにして渡す場合を扱います。

ここからは当社の整理です。

公開してよい版かを確認し、収録した説明と表示される文言を照らします。配布用に資料の一部を差し替えた場合は、その箇所を説明する音声も新しい内容に合うかを確認します。

2．ナレーションとスライドの時間を選ぶ

Microsoftの案内では、［ビデオの作成］の見出しの下の2番目のドロップダウン ボックスに、プレゼンテーションにナレーションとタイミングが含まれているかどうかが示され、必要に応じて切り替えられます。

既定値は、タイミング設定を行ったナレーションを記録している場合は［記録されたタイミングとナレーションを使用する］、記録していない場合は［記録されたタイミングとナレーションを使用しない］です。使用しない場合、各スライドの既定の所要時間は5秒で、［各スライドの所要時間 (秒)］ボックスの右の矢印で長くしたり短くしたりできます。

説明に合わせてスライドを切り替える場合は、音声を使う設定と、収録時のスライドの順が合うかを見ます。音声を使わない場合は、既定の5秒のままで表や注記を読み切れるかを確かめ、足りなければ所要時間を延ばしてから書き出します。

3．画質と保存先を選び動画を書き出す

Microsoftの案内では、［ビデオの作成］の見出しの最初のドロップダウン ボックスでビデオの品質を選びます。品質は完成したビデオの解像度に関係し、品質が高いほどファイルのサイズが大きくなります。どれが合うかは試して決められるとされています。案内に載っている選択肢は次のとおりです。

品質の選択肢解像度とファイル サイズ案内にある表示手段
Ultra HD (4K)3840 x 2160、最大のファイル サイズ大型モニター
フル HD (1080 p)1920 x 1080、大きいファイル サイズコンピューター画面および HD 画面
HD (720p)1280 x 720、中程度のファイル サイズインターネットおよび DVD
標準 (480p)852 x 480、最小のファイル サイズポータブル デバイス

案内の注記では、Ultra HD (4K) は Windows 10 以降を使っている場合にのみ選べ、PowerPoint 2016 ではボリューム ライセンス エディションで使えません。

案内では、［ビデオの作成］を選んだ後に、ファイル名と保存するフォルダーを指定し、［ファイルの種類］ボックスで［MPEG-4 ビデオ］か［Windows Media ビデオ］を選びます。.mp4 と .wmv のどちらも広くサポートされ、コンピューターに PowerPoint がインストールされていなくても再生できると説明されています。作成の進み具合は画面の下のステータス バーに表示され、ビデオの長さとプレゼンテーションの複雑さによっては数時間かかる場合があります。作成中も PowerPoint は使えます。

配布する経路で扱える容量と、視聴者が読む必要のある文字を確認します。元資料と完成動画を別の名前で管理し、前の配布版を誤って送らないようにします。

4．完成した動画を開いて確認する

Microsoftの案内では、作ったビデオを再生するには、指定したフォルダーの場所に移動し、ファイルをダブルクリックします。

同じページには、PowerPointで作ったビデオに含まれないものとして、PowerPoint の前のバージョンで挿入されたメディア、QuickTime メディア（サード パーティの QuickTime コード ffdShow を入れて互換性のために最適化した場合を除く）、マクロ、OLE/ActiveX コントロールが挙がっています。例として、PowerPoint 2007 で挿入したメディアはリンクされてプレゼンテーションで再生されますが、ビデオとしてエクスポートするとリンクされたメディアは削除されます。［ファイル］タブの［情報］で［変換］を選んで新しいファイル形式にするか、メディア オブジェクトを右クリックしてアップグレードすると、ファイルが埋め込まれ、正しくエクスポートされると案内されています。一方、プレゼンテーションに埋め込みのビデオが含まれている場合は、操作しなくても正しく再生されるとされています。

完成動画で冒頭と最後の音声、切り替わり、画像の文字、使う予定のメディアを確認します。以前のバージョンのPowerPointで動画や音声を挿入した資料を流用した場合は、そのメディアが完成動画で再生されるかを先に見ます。修正する場合は編集元に戻り、書き出し後に同じ箇所をもう一度再生してから渡します。

映像内の文字を読みながら手順を追う資料では、途中で一時停止せずに読めるか、停止しても文字がつぶれないかを分けて見ます。元資料と動画のどちらで見た内容かを記録すると、書き出しの設定を直すべきか、元資料の文字を大きくすべきか判断しやすくなります。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□原稿と収録の版を確かめたか
□記録したタイミングとナレーションを使うか、使わない場合の所要時間（既定は5秒）を決めたか
□品質の解像度とファイル サイズが、配布する経路に合うか
□保存先とファイルの種類（MPEG-4 ビデオか Windows Media ビデオ）を選んだか
□前のバージョンで挿入したメディア、マクロ、OLE/ActiveX コントロールなど、ビデオに含まれないものに頼っていないか
□配布する動画で音と切り替わりを再生したか
□保存したファイル形式が配布先で使えるか確認したか
□古い配布版と新しい配布版が区別できるか
