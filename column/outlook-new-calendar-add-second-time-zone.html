新しいOutlookの予定表に日本と海外の時刻を並べるには？

要点

新しいOutlook for Windowsでは、設定で予定表の表示を開き、［タイム ゾーンの追加］を選びます。海外拠点の都市を検索し、［予定表に表示］をオンにして保存します。日本と海外の表示を並べ、会議の開始・終了と、両方の地域での日付を確かめます。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、新しいOutlookの予定表に日本と海外拠点の時刻を並べたい小さな会社の担当者が、タイム ゾーンの追加と表示、会議の日付の読み方、クラシック Outlook や Web 版との違いを確かめる流れをまとめたものです。

1．追加前に、基準の時間と相手拠点の都市を決める

確認日：2026年11月9日。

Microsoftの公式案内は、使っている Outlook のバージョンに応じて［新しい Outlook］［クラシック Outlook］［Web］のタブに手順を分けています。適用先には、新しい Outlook for Windows、Outlook for Microsoft 365、Outlook 2024、Outlook 2016、Outlook.com などが挙がっています。［新しい Outlook］タブの手順が機能しない場合は、まだ新しい Outlook for Windows を使っていない可能性があるため、従来の Outlook のタブの手順に従うよう案内されています。ここでは新しいOutlook for Windowsの追加手順を中心に扱い、クラシック Outlook と Web 版の違いは後の節にまとめます。

ここからは当社の整理です。

普段使っている予定表が日本時間を基準にしているかを確かめ、並べたい海外拠点の都市を相手の担当者に確認します。拠点の国名だけでは都市を決めにくい場合があります。予定の相手が実際に参加する場所を確かめ、複数の拠点を表示するときは、予定表で見分けられる名前を決めておきます。

2．海外拠点のタイムゾーンを追加する

Microsoftの新しいOutlook向け案内では、［設定］を開き、予定表の表示に関する設定で［タイム ゾーンの追加］を選びます。［その他のタイム ゾーン］で都市を検索し、必要ならラベルを付けて［予定表に表示］をオンにし、［保存］を選びます。

同じタブでは、予定表の基準のタイム ゾーンは、同じ表示の設定にある［予定表をタイム ゾーンで表示する］のドロップダウンで選び、［ラベル］に名前を付けて［保存］します。予定表に2つ以上のタイム ゾーンが表示されている場合は、［その他のタイム ゾーン］で［下へ移動］または［上へ移動］を選んで位置を入れ替えられ、不要になった追加のタイム ゾーンは［削除］を選んで［保存］します。

予定表へ戻ったときは、日本時間と追加した拠点の表示が両方あるかを見ます。Microsoftの案内では、2つ目のタイム ゾーンは、予定表を日ビューまたは週ビューで表示した場合にのみ表示されます。月の表示のままでは時刻が並ばないため、時刻を見比べるときは日または週の表示に切り替えます。

3．会議の日時を、両方の地域の日付で読む

Microsoftによると、Outlookの予定は協定世界時で保存され、タイムゾーンが異なる参加者の予定表では各自の現地時刻で表示されます。同じ案内では、2つのタイム ゾーンが表示されている場合は、会議開催者のタイム ゾーンが基準ポイントとして使われます。会議を開催し、他のタイム ゾーンの招待者の空き時間情報を表示すると、その情報は調整されてタイム ゾーンで正しく表示されるとされています。

確認するときは同じ予定を開き、開始と終了の両方について、日本と海外で何月何日になるかを見ます。開始と終了が違う日付にまたがるときは、連絡文にも日付をそれぞれ添えます。

繰り返す会議は、最初の開催日だけで判断せず、実際に案内する回の日時を見ます。表示される日付や時刻に疑問があるときは、予定を変更する前に、その予定が基準とするタイムゾーンと、相手側が見ている日時を確認します。

4．クラシック Outlook と Web 版で使う場合

Microsoftの案内では、クラシック Outlook（ページ内では従来の Outlook とも表記）では、［ファイル］の［オプション］を選び、［Calendar］タブの［タイム ゾーン］で［2 つ目のタイム ゾーンを表示］を選び、必要に応じて［3 つ目のタイム ゾーンを表示］を選んで、タイム ゾーンごとにラベルを付けます。位置は［タイム ゾーンの入れ替え］で入れ替え、追加のタイム ゾーンは、他のタイム ゾーンを表示するチェック ボックスをオフにして消します。最新バージョンの Outlook for Microsoft 365 では予定表に最大3つのタイム ゾーンを表示できますが、Outlook 2019 LTSC や Outlook 2016 など、従来の Outlook のほかのバージョンで表示できるのは2つだけです。

Outlook on the web と Outlook.com では、新しい Outlook と同じように［設定］から予定表の表示の設定を開き、［タイム ゾーンの追加］を選んで都市を検索し、必要ならラベルを付けて［予定表に表示］をオンにし、［保存］を選びます。

新しい Outlook とクラシック Outlook では設定の場所が違うため、両方を切り替えて使う人や外出先で Web 版を開く人は、使う版ごとに追加したタイム ゾーンが表示されているかを確かめます。社内で手順を共有するときは、どの版の手順かを書き添えます。

5．連絡文に、相手が照合できる日時を残す

会議の候補を連絡する際は、日付・開始時刻・終了時刻と、どの都市の時刻かを一緒に記します。相手から別の日付が返ってきたら、どのタイムゾーンを見ているかを確かめ、同じ予定を指しているかを確認します。

社内の予定表に表示したラベルは、見分けるために使います。相手へ伝える文では、部署の略称だけで意味が通じるかを確かめ、必要なら都市名を添えます。担当が交代するときは、予定の確認に使う地域と相手の連絡先を引継ぎに残します。
