Wordの表で長い備考が切れるとき、行の高さを直す手順と確認

要点

備考の末尾が隠れるときは、行の高さを、内容に応じて広がる設定へ変更するのが入口です。Microsoftは、高さが固定された行では、内容を追加してもセルが広がらないと説明しています。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、Wordの表で長い備考を末尾まで読めるようにしたい小さな会社の担当者が、行の高さの設定と修正後の配置を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象の版と、欠けている場所をそろえる
  2. 表の選択から、高さの設定へ進む
  3. 高さの数値を増やす操作と区別する
  4. 備考の末尾を残して、仕上がりを読む
  5. 引き継ぎには、直した場所と確認した文章を残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象の版と、欠けている場所をそろえる

確認日：2026年11月13日。

Microsoft公式ヘルプの適用先は、Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016です。この記事ではWindows版での行の高さの見直しに絞り、Mac版・Web版や、高さ以外が原因の文字欠けは扱いません。

最初に、どの備考のどこまでが見えているかを、入力した文章と照らします。末尾の注意書きだけが見えないのか、文章の途中から欠けているのかを押さえると、直した後の比較に使えます。短い備考だけで仕上がりを判断せず、長い文章が入る欄を確認の対象にします。

先に決めたいのは、修正する範囲と、残す文章です。配布済みの文書や共通のひな形を扱う場合は、手元で確かめるための控えを使うとよいです。表示を整える途中で備考を削ってしまうと、必要な内容を残せたかという確認が別に必要になります。

2．表の選択から、高さの設定へ進む

操作名は日本語の公式ヘルプの表記です。ただし、ヘルプにある［少なくとも］などの表記が利用中の画面でどの表示名になるかは未確認です。同じ役割の欄を特定できない場合は、別の設定を変えず、使用版と表示名を残して確認を止めます。

まず、変更の対象となる表を選択します。Microsoftの案内では、テーブル移動ハンドルを選んで表全体を選択します。

続いて右クリックから［テーブルのプロパティ］を開き、［行］タブに進みます。

［サイズ］の［高さの指定］を選び、行の高さを指定する欄を確認します。

［行の高さ］の矢印から［少なくとも］を選び、［OK］で確定します。

この順番では、先に対象を選び、その後で高さの扱いを変えます。選んだ場所を見失ったまま進めず、直したい備考を含む範囲になっているかを確かめるとよいです。別の表もある文書では、操作前後で同じ備考を読み比べます。

Microsoftの案内では、確定後に、選択した表を右クリックして［行を均等に分散］を選びます。

当社の確認手順では、表全体を対象にする前に控えを残し、高さをそろえたときに備考以外の行の配置もどう変わるかを比べます。見た目をそろえる操作まで終えた後も、備考の末尾と周囲の配置を読み直します。文字が見えることと、文書全体が読みやすいことを、分けて確かめるためです。

3．高さの数値を増やす操作と区別する

高さの数値を直接変える方法では、対象行のセルを選択し、［テーブル レイアウト］の［セル サイズ］にある［テーブル行の高さ］で高さを指定します。

Microsoftのサイズ変更の案内では、行の高さは手動で変更するまでは内容の大きさに合わせて自動調整されます。

今回は、長い備考を追加するたびに見切れを直す手間に着目しています。現在の文章を収める高さにするだけでよいのか、後から文章を足す使い方も考えるのかを先に整理すると、修正後に何を確かめるかが明確になります。高さを変えた直後の見た目だけで終えず、追記を含む使い方で確認するのが当社の考え方です。

なお、［自動調整］ボタンで内容に合わせて変える対象は、公式ヘルプでは表または列とされています。

同じ「調整」という言葉だけを手掛かりに操作を選ばず、縦方向の余地を直したいのか、横方向の広さを変えたいのかを区別します。今回の確認を終えるまでは、文字の大きさや文章量を同時に変えず、高さの変更による違いを見比べるとよいです。

4．備考の末尾を残して、仕上がりを読む

ここからは当社の整理です。

項目残したい備考修正後に見るところ
会議資料の準備配布前に差し替えを確認し、旧版は配布しない。末尾の「旧版は配布しない。」まで読めるか
備品の返却使用後は保管場所に戻す。破損がある場合は担当者に伝える。注意書きが途中で隠れず、項目との対応も分かるか

表のように、見せたいのは末尾まで含めた意味です。途中まで読める状態では、注意書きの結論が伝わらないおそれがあります。欠けていた部分が現れたかだけでなく、修正前に残した文章と読み合わせ、言葉を落としていないかも確かめます。

続けて、隣の欄の内容と、その下に続く項目を見ます。長い備考に対応する項目名が追えるか、空いた部分が大きすぎて別の項目の備考に見えないかを確認します。文章を読む人が、横と縦のどちらにも無理なく目を動かせるかが目安です。

最後に、追記が必要になる場面を想定して、控えで長めの文章も確かめます。今の文章が収まったという確認に加え、更新後も末尾を読めるかを見るためです。別の箇所が欠けた場合は、直ったと扱わず、どの位置にどの文章が残っているかを記録します。

5．引き継ぎには、直した場所と確認した文章を残す

引き継ぎのメモには、対象の文書、備考のある項目、修正前に隠れていた部分、修正後に読めた末尾を残します。「表示を直した」だけでは、次に編集する人がどこを見ればよいか分かりにくいためです。操作名を覚えているかより、何を残せたかが伝わる記録にします。

共通のひな形に反映する場合も、今回の文書だけで判断せず、普段入る文章の長さや、注意書きの置き方を含めて確認します。高さをそろえる見た目を優先するのか、長い備考を読み切れることを優先するのかは、文書を使う人とそろえておくとよいです。

この作業をAIで減らすなら、事務でのAI活用を考える前に、備考を追記する場面と、人が末尾を読み合わせる場面を整理するとよいです。繰り返す確認と、内容の意味を判断する確認を書き分けることが、作業の見直しの入口になります。
