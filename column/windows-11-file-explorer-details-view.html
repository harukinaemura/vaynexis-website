Windows 11のエクスプローラーで資料を詳細表示にする手順

要点

Windows 11のエクスプローラーで対象フォルダーを開き、［表示］から［詳細］を選ぶと、ファイルが詳細表示に切り替わります。まず保存先の一覧で探す資料の候補を絞り、内容の確認が必要なものを開く流れにするとよいです。操作後は、見ている場所と一覧の見え方を確かめます。

公開：2026年11月8日／情報の確認日：2026年11月7日（出典はこの記事の最後）

Windows 11で資料を探す事務担当者が、詳細表示に切り替えて一覧で候補を絞ります。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 保存先を開き、表示メニューで切り替える
  2. キーで切り替える方法と、長い名前への対処
  3. 一覧で探す目印と、中身を確認する仕事を分ける
  4. 詳細ウィンドウを開く操作との違いを確かめる
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．保存先を開き、表示メニューで切り替える

確認日：2026年11月7日

この記事では、Microsoftのエクスプローラーの案内のうちWindows 11の手順を扱います。

最初に、一覧で見たい資料が保存されているフォルダーを開きます。引き継ぎの連絡や自分の控えと照らし合わせ、対象の保存先にいるかを確かめるところから始めるとよいです。似た名前のフォルダーがある場合も、今回の仕事で使う場所を先に決めておきます。

エクスプローラー上部の［表示］を選び、表示方法の候補から［詳細］を選択します。資料の中身を順番に開く前に、一覧の見え方を整える操作です。

切り替えた後は、探したい資料の名前を一覧で追えるかを見ます。目当ての資料が見つからない段階で、表示の設定を次々と変えるよりも、開いている保存先が合っているかを確かめるとよいです。表示を選ぶ操作と、資料のある場所を選ぶ操作を分けて進めます。

2．キーで切り替える方法と、長い名前への対処

エクスプローラーでは、CtrlキーとShiftキーを押しながら数字キーの6を押す方法でも、詳細表示へ切り替えられます。メニューを使う方法と、キーを使う方法のどちらで進めたかを覚えておくと、引き継ぎの説明をそろえやすくなります。

文字が途中までしか読めないときは、表示の切り替えができたかと、名前を読み取れるかを別々に確認します。途中までの名前が似ている資料については、読めない部分を想像して選ばず、名前全体を確かめてから候補にするとよいです。

テンキーを使える場合は、Ctrlキーとテンキーの正符号（＋）を押すと、テキストに合わせてすべての列のサイズを変更できます。この操作を引き継ぐときは、使うキーの場所も併せて伝えます。

キー操作に慣れていない担当者へは、最初に説明したメニューでの進め方を渡すとよいです。引き継ぎ用の手順には、普段使う方法を中心に書き、別の方法を併記する場合も操作を混ぜずに分けておきます。

3．一覧で探す目印と、中身を確認する仕事を分ける

ここからは当社の整理です。

一覧を見る目的を「必要な資料の候補を探す」と決めておくと、どこで中身の確認へ移るかが明確になります。名前が目的に合っているかを見た後、承認済みか、修正が反映されているかなど、仕事に必要な内容を確認する流れです。

確認する段階一覧で見る情報その後に確かめること
探す資料の候補を絞るファイル名と更新時期目的に合う候補の場所と名前
長い名前を見分ける列幅を調整した後のファイル名全体似た名前のファイルや別の版との違い
使う資料を確定する一覧で確認した候補の場所と名前開いた資料に修正が反映されているか、使用してよい版か

ファイル名や更新時期は、資料を探すときの目印です。名前に「確認済み」「最終」と書かれていても、それだけを根拠に送付対象を決めず、担当者の連絡や資料の内容と照らし合わせるとよいです。

一覧の確認を終えた時点では「候補を見つけた」と記録し、内容まで確認した資料とは区別します。引き継ぎでも、見つかったことと、使ってよいことを同じ意味で伝えないようにします。本文の情報を書き出して管理表を作る作業まで広げず、ここでは保存資料を探す段階を整えます。

4．詳細ウィンドウを開く操作との違いを確かめる

Windows 11の公式ヘルプでは、ファイルやフォルダーを表示する中央の領域を「コンテンツ ウィンドウ」と呼んでいます。一方、詳細ウィンドウは、選択した項目に関する追加情報を表示する領域です。

Microsoftの案内では、詳細ビューの中央の一覧は、ファイル名や更新時期などの項目で並べ替えられます。選んだ資料の情報だけが別の領域に表示されたときは、一覧そのものが見やすくなったかを見直すとよいです。似た名称の操作をしたことだけで、切り替えが済んだと判断しないようにします。

操作の終わりには、対象の保存先、探していた資料の名前、一覧で読み取れる範囲を確かめます。別の担当者に渡すメモにも、押した場所だけでなく、どのフォルダーで何が見える状態にしたかを残すとよいです。

引き継ぎを受ける人は、そのメモと手元の一覧を照合します。見え方が違う場合は、まず対象の保存先と使った操作を確かめ、同じ資料を見ている状態にそろえます。資料を探せた後は、その仕事に必要な内容の確認へ進みます。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□今回の資料が保存されているフォルダーを開いたことを確認したか
□資料の一覧が目的の見え方に切り替わったことを確認したか
□名前が途中で切れている資料は、名前全体まで確認したか
□探した資料と、内容まで確認した資料を区別したか
□名前の「最終」などの言葉に加え、使ってよい資料か内容も確認したか
□引き継ぎのメモに、保存先と操作後の状態を記録したか
