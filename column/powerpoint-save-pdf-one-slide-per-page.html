PowerPointの提出資料を一頁一スライドのPDFで保存するには

要点

Windows版では［ファイル］の［エクスポート］から、提出用のPDFを作成できます。出力する範囲と内容を整えたうえで保存し、完成した資料が、先頭から末尾まで各ページにスライドを単独で表示しているかを確かめます。

公開：2026年11月14日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、提出資料を一頁一スライドのPDFにしたい小さな会社の担当者が、PowerPointの出力条件と保存後の内容を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 提出する内容と利用する版をそろえる
  2. Windowsでは範囲と発行対象を整えてから書き出す
  3. MacとWebはそれぞれの保存経路を使う
  4. 完成した資料は枚数・配置・細部の順に見る
  5. 引き継ぎには出力条件と確認結果を残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．提出する内容と利用する版をそろえる

確認日：2026年11月13日。

Microsoftの保存手順の適用先は、WindowsのPowerPoint for Microsoft 365・2024・2021・2019・2016と、MacのPowerPoint for Microsoft 365・2024・2021です。日本語の公式ヘルプに沿って整理しており、実画面での操作確認は行っていません。手元で使う版に合わせて、後の節の操作を選びます。

プレゼンテーションをPDFで保存すると、書式設定とレイアウトが固定されます。提出前には、送りたい内容、資料の並び、読み取れる文字の大きさを元の資料で整えておくとよいです。表紙だけを眺めて終えず、細かい表や注記を含む箇所にも目を向けます。

ただし、PDFとして共有しただけでは、受信者の編集を防ぐ手段として十分ではありません。提出用の完成版と、社内で修正を続ける元の資料は、用途を分けて管理します。

2．Windowsでは範囲と発行対象を整えてから書き出す

保存先とファイルの種類を決める

［ファイル］から［エクスポート］を開きます。続いて、［PDF/XPS の作成］を選びます。 ［PDF または XPS 形式で発行］で保存先を選び、必要に応じて［ファイル名］を入力します。 ファイルの種類は、PDF（*.pdf）が選ばれていることを確かめます。

保存先には、提出用として扱う場所を選ぶとよいです。名前も、何の資料か、修正途中なのか提出する版なのかが区別できる付け方にします。書き出した後に探し直すことを避けるため、作業を始めた段階で送り先と保管場所をそろえておきます。

出す範囲と、ページに載せる内容を分けて確認する

［オプション］では、プレゼンテーションをPDFとして表示する方法を設定できます。 特定の範囲を保存する場合は、［スライド］の［開始］と［終了］に番号を入れます。 ［現在のスライド］は、表示中のスライドだけを保存する指定です。

［発行対象］には、スライドを保存する以外に、コメント、配布資料、アウトライン表示のみを保存する選択肢があるため、提出用はスライド自体を保存する設定にします。範囲は「どこからどこまで」、発行対象は「何を載せるか」という別の確認として扱うと、見直す場所を絞れます。

追加で含められる主なものには非表示のスライドやコメントがあり、出力時のオプションで選べます。補足用の内容まで提出対象にするのかを、書き出す前に決めておくとよいです。

読みやすさと容量を見て発行する

印刷品質を高くしたい場合は［標準 (オンライン発行および印刷)］、印刷品質よりファイルサイズを小さくすることを優先する場合は［最小サイズ (オンライン公開)］を選びます。容量だけで判断せず、小さな文字や薄い線が読めるかを、完成した資料で確かめます。

［発行後にファイルを開く］をオンにすると、保存したファイルを開く設定にできます。 設定を終えたら［OK］で戻り、［発行］を選びます。

3．MacとWebはそれぞれの保存経路を使う

Macでは保存とエクスポートを区別する

Mac版で保存する場合は、［ファイル］の［名前を付けて保存］で保存先を決め、［ファイル形式］を［PDF］にします。別の方法として、［ファイル］の［エクスポート］から［ファイル形式］の［PDF］を選ぶ経路もあります。保存かエクスポートかを先に選んでから、その経路の画面をたどります。

主な違いとして、Mac版のPDF書き出しでは、ノートの保存、配布資料としての保存、非表示のスライドを含める指定、ファイルサイズを小さくする指定が使えず、印刷品質は設定できます。設定項目を探し続ける前に、使っている版と、どの内容を提出したいのかを照らし合わせます。

Webではダウンロードした資料を確認する

Web版は、［ファイル］、［エクスポート］、［PDF としてダウンロード］の順に進んで変換します。書き出した資料を開いた後は、元の編集画面へ戻る前に、送る内容がそろっているかを見ます。画面で使った経路も引き継ぎに残しておくと、別の担当者が見直す際の手がかりになります。

4．完成した資料は枚数・配置・細部の順に見る

ここからは当社の整理です。

保存できたことと、提出する内容がそろったことは分けて考えます。最初は、元の資料の先頭と末尾が含まれているか、途中の内容が抜けていないかを確認します。ページを続けて送り、同じ内容の重複や順番の入れ替わりも見ます。

次に、各ページにスライドが単独で載っているかを見ます。表紙だけが意図した形でも、途中に別の形式のページが混ざっていないかは、最後まで見て判断する必要があります。発表者だけが使う補足や書き込みが、提出する内容に紛れていないかにも目を向けます。

確認する場所架空の提出資料での見方
冒頭と末尾社内説明資料の表紙と締めの案内がそろっているか
途中の並び見出しが元の順番で続き、抜けや重複がないか
ページの配置各ページにスライドが単独で表示されているか
細かな箇所表の注記と図の凡例が読み取れるか

最後は、文字の欠け、図の端、記号、細い罫線を見ます。全体を小さく表示した状態と、細部を読める大きさにした状態の両方で確認するとよいです。違和感があれば、提出用の名前で保存できているかだけで済ませず、元の内容と出力時の指定を分けて見直します。

5．引き継ぎには出力条件と確認結果を残す

引き継ぐときは、保存する場所、名前の付け方、提出する範囲、補足内容を含める方針、仕上がりを確認する担当者を記録します。「いつもの設定」とだけ残すと、受け取った人がどの状態を再現すればよいか判断しにくくなります。操作の経路と、完成後に見る箇所を分けて書いておくとよいです。

提出直前に修正が入った場合は、修正箇所を見た後に、全体の並びと末尾まで見直します。送付時も、保管場所にある提出用の資料と、実際に添付する資料が同じものかを照らし合わせます。確認結果は「保存済み」だけにせず、範囲、配置、読みやすさをそれぞれ確認したと分かる形で残します。

事務の手間を洗い出すなら、資料を整える作業、書き出す作業、人が仕上がりを確かめる作業に分けて記録します。その整理は、事務の作業へのAI活用を考える際の出発点にもなります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□提出する元の資料と、先頭から末尾までの内容を確認したか
□利用する版に合う操作経路で書き出したか
□発表者だけが使う補足を提出対象に含めるか確認したか
□各ページにスライドが単独で表示されているか確認したか
□途中の内容の抜け、重複、並び違いを確認したか
□細かな文字、図の端、罫線を読めるか確認したか
□保存した提出用の資料と、送付する資料が同じものか確認したか
