OneDriveで権限を変えず、すでに見られる人にリンクを渡すには？

要点

職場または学校のアカウントでOneDriveのWebサイトを開き、対象ファイルのリンク設定を［既存のアクセス権を持つユーザー］にします。設定を適用してからリンクをコピーして渡すと、すでにアクセス権を持つ相手が、アクセス許可を変えないまま資料を開くためのリンクになります。 送る前に、相手が普段使うアカウントで対象ファイルにアクセスできるかを確かめます。

公開：2026年11月9日／情報の確認日：2026年11月7日（出典はこの記事の最後）

この記事では、職場や学校のOneDriveで、すでにアクセス権を持つ相手に資料のリンクを渡す手順を整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. リンクを受け取る人の既存アクセスを確かめる
  2. 設定を適用してからリンクをコピーする
  3. 相手が普段のアカウントで開けたかを確認する
  4. 開けないときは、止まった場面を所有者に伝える
  5. ほかのリンクの種類と、送った後に開けなくなる条件
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．リンクを受け取る人の既存アクセスを確かめる

確認日：2026-11-07。

Microsoftの日本語ヘルプでは、［既存のアクセス権を持つユーザー］向けのリンクは、対象のファイルやフォルダーをすでに開ける人が使うもので、アクセス許可は変わらないと説明しています。 すでに相手にある閲覧や編集の権限で開くときの設定です。この記事では職場または学校のアカウントを使い、OneDriveのWebサイトにあるファイルを案内する場面を扱います。

ここからは当社の整理です。

先に資料名と保存場所を確かめ、相手が開こうとするファイルを特定します。似たファイル名の資料がある場合は、日付や版も照合します。送信先のメールアドレスと、相手がOneDriveにサインインするアカウントは分けて確認します。相手のアクセス状況が分からないときは、リンクを作る前に対象のファイルとアカウントを所有者に伝えます。

2．設定を適用してからリンクをコピーする

Microsoftが案内するWebサイトの手順では、ファイルを選んで共有メニューを開き、リンクの設定を歯車から変更します。

  1. OneDriveのWebサイトに職場または学校のアカウントでサインインし、案内したいファイルを選びます。
  2. ページ上部の［共有］を選び、［リンクのコピー］を選択します。リンクの設定を変えるため、設定の歯車アイコンを選択します。
  3. ［既存のアクセス権を持つユーザー］を選び、［適用］を押します。
  4. ［適用］の後に［コピー］し、その時点のリンクを送るメッセージに貼り付けます。

手順2で［リンクのコピー］を選んだ時点でコピーされるのは設定を変える前のリンクなので、送るメッセージには手順4でコピーしたリンクを貼ります。送信前には、相手に案内するファイルと、設定を適用してからコピーしたリンクが対応しているかを見ます。複数の資料を扱っているときは、送るメッセージにファイル名を添えると、受け手も開いた資料を照合できます。

3．相手が普段のアカウントで開けたかを確認する

送った後は、受け手に普段の職場または学校のアカウントで開き、依頼したファイル名や版が表示されるか確かめてもらいます。送付済みと閲覧確認済みを別々に控えておくと、担当が交代してもどこまで済んだかが分かります。

確認する場面照合すること記録に残すこと
対象を決める相手に案内したいファイルとWebサイトで選んだファイルファイル名と保存場所、版
相手を確かめる連絡先と、相手が普段使うサインイン先確認した相手とアカウントの種類
コピーするリンク設定に選んだ項目と、適用後にコピーしたリンク設定の種類と送付先
受け手が開く開いた資料と依頼した資料が同じか到達の確認結果、未確認の点

4．開けないときは、止まった場面を所有者に伝える

受け手から開けないと連絡が来たら、対象のファイル、相手のアカウント、画面の表示をそろえます。別のファイルを送っていた場合は対象を選び直し、サインイン先が違っていた場合は既存の権限があるアカウントを確かめます。相手の既存アクセスを確認できない場合は、どの資料を誰が使うかを所有者へ伝えます。

共有の項目が灰色で選べない場合について、Microsoftは組織の管理者が選択肢を制限している可能性を案内しています。 選べなかった項目の名前と、既存の権限で開ける相手にリンクを渡したいことを伝えると、確認先が状況を切り分けやすくなります。新しい権限が必要と分かった場合は、その判断と手続きを所有者に引き継ぎます。

5．ほかのリンクの種類と、送った後に開けなくなる条件

Microsoftのヘルプでは、リンクの設定のうち［すべてのユーザー］は、このリンクを受信するすべてのユーザーにアクセス権を付与し、組織外のユーザーも含まれる場合があると説明されています。組織内のユーザー向けのリンクは、リンクを持つ組織内のすべてのユーザーがファイルにアクセスできるようになるもので、［特定のユーザー］は、指定したユーザーにのみアクセス権を付与すると説明されています。

同じヘルプでは、Windows 10、Windows 11、Mac 用の OneDrive デスクトップ アプリでファイルを右クリックし、［OneDrive リンクの共有］を選ぶと共有リンクがクリップボードにコピーされますが、既定では、リンクは編集アクセス許可に設定されていると説明されています。

同じヘルプでは、職場または学校の OneDrive のアカウントの場合、複数のアイテムを同時に共有する機能は使用できないとされています。

同じヘルプでは、OneDrive 内でファイルまたはフォルダーを移動すると、リンクが機能しなくなるとされています。作成したリンクが機能しなくなった場合は新しいリンクを作成し、受け取ったリンクが機能しなくなった場合は、所有者がファイルを移動したか、フォルダーの共有を停止している可能性があると案内されています。

権限を増やさずに渡したいときは、［既存のアクセス権を持つユーザー］以外の種類を選んでいないかを、［適用］の前に見直します。パソコンのOneDriveのファイルを右クリックしてコピーしたリンクは、そのまま送らず、Webサイトでリンクの設定を確かめてからコピーし直します。職場または学校のアカウントでは資料を1件ずつ選ぶため、複数の資料を案内するときはファイルごとにリンクを作り、メッセージでファイル名とリンクを対応させます。送った後に資料の保存場所を変えた場合は、受け手が開けなくなっていないかを確かめ、必要なら新しいリンクを作って送り直します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□職場または学校のアカウントで対象ファイルを選んだか
□相手が対象ファイルにアクセスできるアカウントを確かめたか
□［既存のアクセス権を持つユーザー］を選び、適用後にリンクをコピーしたか
□相手が開いた資料名や版を、案内した資料と照合したか
□開けなかった場合は、対象・アカウント・表示をそろえて確認先へ伝えたか
□パソコンの右クリック（［OneDrive リンクの共有］）で作ったリンクをそのまま送っていないか
□送った後に資料を移動していないか、移動したならリンクを作り直したか
