Wordで戻った修正履歴を一件ずつ確定する手順と確認の分け方

要点

戻ってきた修正履歴は、内容を読んで［承諾］または［元に戻す］を選び、次の変更へ進みながら個別に確定します。採否を決める前に、どの表現を残すかを人が判断します。判断待ちの箇所と処理を終えた箇所を区別すると、途中で担当が替わる場合にも続きを確認しやすくなります。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、修正履歴つきで戻ってきたWord文書を扱う小さな会社の担当者が、提案を一件ずつ採用するか元に戻すかを確かめ、判断待ちの箇所と残った履歴を引き継ぐ流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 返却された文書で、対象の版と変更の見え方をそろえる
  2. 先頭から順に読み、採否を決めて次の箇所へ進む
  3. 気になる修正だけを直接選んで処理する
  4. 処理後は残った履歴と、読み通した文章を確かめる
  5. 採用・差し戻し・判断待ちを、引き継ぎで区別する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．返却された文書で、対象の版と変更の見え方をそろえる

確認日：2026年11月13日

この記事は、公式ヘルプの適用先のうち Windows 版の Word for Microsoft 365 を対象にします。適用先には Word 2024・Word 2021・Word 2019・Word 2016 や Mac 版も挙がっていますが、版ごとの画面の違いはこの記事では確かめていません。画面名は日本語の公式ヘルプに合わせています。日本語版のヘルプには、タブの名前が［レビュー］と書かれている箇所と、［校閲］と書かれている箇所があり、お使いの画面でどちらの表記かは確かめていません。別の端末で作業する担当者へ渡すときは、使う版も引き継ぎ情報に添えるとよいです。

［すべての変更履歴］では、変更履歴が表示され、校閲者ごとに異なる色のテキストと行が表示されます。修正後の文章だけでなく、何が変わったかを読んでから判断する進め方です。

［マークアップなし］は変更を一時的に隠す表示であり、履歴を削除するには変更を受け入れるか拒否する必要があります。見た目が整ったことと、内容を確定したことは分けて確かめます。

2．先頭から順に読み、採否を決めて次の箇所へ進む

作業は文書の先頭をクリックするところから始めます。途中に表示されている箇所から始めると、どこまで読んだのかを別に管理する必要があります。返却後の確認を通して行う場合は、読み始める位置をそろえるとよいです。

Windows 欄の手順では、［レビュー］タブから［追跡］へ進みます。そこで［承諾］または［元に戻す］を選ぶと、次の変更へ移動します。押す前には対象の文章を読み、残す表現について判断します。処理後も直前の修正を見ているつもりで同じ判断を繰り返さず、対象箇所を見直します。

決められない箇所は、移動と確定を分ける

採否を決めずに別の変更を確認する場合は、［次へ］または［前へ］を選べます。確認先からの回答を待つ箇所については、どの見出しのどの表現なのかと、誰に何を尋ねるかを控えます。「後で確認」とだけ残すより、再開時に必要な情報が伝わります。

採用しないと決めた箇所と、まだ決めていない箇所を同じ扱いにしないことも大切です。判断待ちの理由が分かれば、次の担当者は文章を読み直す前に、どの回答が必要なのかを確認できます。

3．気になる修正だけを直接選んで処理する

文書内の変更履歴を右クリックして、対象の候補を確認する方法もあります。ヘルプには、右クリックの方法ではバナー メニューとドロップダウン メニューのオプションが表示されると書かれています。ここではドロップダウン メニューを扱い、挿入なら［挿入を承諾］か［挿入を元に戻す］、削除なら［削除を承諾］か［削除を元に戻す］を選びます。返答を受け取った箇所へ戻る際など、処理したい位置を特定してから使う方法です。

対象の語だけを見ず、前後の文章を合わせて読みます。削られる表現に確認先や例外の説明が含まれていないか、追加される語によって読み手や対応する範囲が変わらないかを検討するとよいです。表記を整える修正と、内容を変える修正は、同じ見た目でも判断に必要な情報が異なります。

ここで決めるのは、修正者の意図を想像して全体を直すことではなく、対象としている提案をどう扱うかです。関連する別の文章にも手直しが必要だと分かった場合は、その必要性を別に残すと、今回の採否と追加の修正依頼を区別できます。

4．処理後は残った履歴と、読み通した文章を確かめる

［校閲］タブで［校閲ウィンドウ］を選ぶと、残った変更を一覧で確認する入口になります。その上部の概要には、文書内に残っている変更履歴とコメントの正確な数が表示されます。未処理の箇所があるときは、判断待ちの控えと照合し、説明のつかない残りがないかを見ます。

ヘルプには、コメントは変更の記録機能の一部ではなくなったとの注意書きがあります。そのため、修正の採否とコメントの確認は分けて見ます。やり取りに未回答の質問が残っていないかも、文書を渡す前に確かめるとよいです。

内容を決め終えた文章は、修正箇所の周囲を含めて読み通します。主語と述語がつながるか、見出しの説明と本文が一致するか、同じ対象を別の呼び方で残していないかが確認の観点です。採否を終えたという操作上の状態と、読み手に伝わる文章になったかという確認は、別々に記録できます。

途中で区切る場合は、文書全体の確認が終わったように伝えず、判断待ちの場所と理由を添えて渡します。相手が続きを始められる状態まで情報をそろえることが、引き継ぎの区切りになります。

5．採用・差し戻し・判断待ちを、引き継ぎで区別する

ここからは当社の整理です。

社内案内文への修正を扱う場面なら、表記を直す提案と、誰が対応するかを変える提案を分けて考えられます。操作をする人が内容の決定権も持っているとは限らないため、採否を決める人と文書へ反映する人の役割をそろえておくとよいです。

戻ってきた提案人が確認すること引き継ぎに残す内容
誤字を正しい表記に直す意図した語になっているか採用する表記と確認の終了
問い合わせ先の部署を変える対応する部署と合意しているか判断待ちの箇所と回答を求める相手
注意書きを削る読み手に必要な説明が残るか差し戻す理由と残したい表現

表は判断を整理するためのものであり、採否を自動的に決める規則ではありません。依頼者が何を伝えたい文章なのかを確認し、その目的に照らして修正を扱います。意見が分かれる表現は、担当者が独自に折衷案へ置き換える前に、確認する相手へ論点を返す進め方が考えられます。

判断の控えには、対象の見出し、該当する短い表現、判断の状態、確認先を残します。文書全体を再説明する必要はなく、相手が対象を探せて、何を回答すればよいかが分かる情報に絞ります。処理を終えた箇所についても、後から説明が必要な内容の変更であれば、決定理由を残すかを担当者間で決めておくとよいです。

事務の手間を洗い出すなら、AIを使う作業範囲の考え方に沿って、判断前の情報整理と、人が採否を決める工程を分けて検討できます。
