Wordのダーク モードで黒くなった用紙を白く表示するには

要点

Windows 版 Word では、リボンの［表示］タブで［モードの切り替え］を選ぶと、ダーク モードのままページの背景を明るい色と暗い色で切り替えられます。 いつも白い用紙で表示したいなら、［ファイル］→［オプション］→［全般］の［Office テーマ］で［ドキュメント ページの色を変更しない］をオンにします。 どちらにしても、印刷はライト モードのページの色で行われます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Word を開いたらメニューも用紙も真っ黒で、作った書類が印刷でどう見えるのか判断しにくい。ダーク モードは残したまま用紙だけを白に戻す2つの設定と、Excel まで黒くなったときに見る場所、Mac 版・Web 版での呼び名の違いを確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

表示をそろえる表と確認表は、架空の事務所を想定して当社がまとめたもので、Microsoft のヘルプが示す手順そのものではありません。

  2. その場で切り替える：［モードの切り替え］
  3. いつも白い用紙にする：［ドキュメント ページの色を変更しない］

1．用紙が黒いのは表示だけ

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Word（Microsoft 365 などのデスクトップ版）です。ヘルプの適用先には、Word for Microsoft 365、Word 2024、Word 2021 と、Mac 向けの Word for Microsoft 365 for Mac が並んでいます。 Mac 版と Web 版の違いは、後の節で分けて書きます。

Word のダーク モードは、メニューと文書の背景の両方を暗い配色にします。 目の疲れを減らすのには役立ちますが、ヘルプにも、ページの背景が暗いと、印刷したときの見え方や共同作業者が開いたときの見え方が伝わらない、と書かれています。 見積書や案内文の色づかいを確かめたいときは、用紙を白に戻して見るほうが確実です。

ヘルプによると、Windows 版 Word のダーク モードは、Office テーマを［黒］にしたときに使われます。 メニューは黒いままでよく、用紙だけを白くしたい、というのが今回の目的です。

この［黒］は、［ファイル］→［オプション］→［全般］にある［Office テーマ］のドロップダウンで選ぶ設定です。 しかも Word だけの設定ではなく、すべての Office アプリで黒のテーマが有効になります。 Excel や PowerPoint の画面まで暗くなっているなら、きっかけはこのテーマだと見当がつきます。用紙の色を戻す前に、どこで切り替わったのかをここで確かめておくと、別のパソコンで同じことが起きたときにも説明しやすくなります。

2．その場で切り替える：［モードの切り替え］

順番操作
1リボンの［表示］タブを開く
2［モードの切り替え］を選ぶ（用紙が明るい色になる。もう一度選ぶと暗い色に戻る）

Word は、このボタンの状態を次からのダーク モードでも覚えています。

3．いつも白い用紙にする：［ドキュメント ページの色を変更しない］

順番操作
1［ファイル］→［オプション］→［全般］を開き、「Microsoft Office のコピーをカスタマイズ」の欄へ進む
2［Office テーマ］の色の選択の近くにある［ドキュメント ページの色を変更しない］をオンにする
3［OK］を選ぶ

4．印刷と共同作業者への影響

  • 印刷：ダーク モードの設定に関係なく、ライト モードのページの色で印刷されます。
  • 共同作業者：ダーク モードの設定はほかの人には影響せず、Word は一人ひとりの表示設定に従います。
  • 別のパソコンや Web 版：ダーク モードの設定は Web、Windows、Mac の間で引き継がれません。

印刷すると背景の色が出ない、という別の困りごとは、ページの色の印刷の設定の話で、ダーク モードとは関係しません。

5．ダーク モードで気をつけたい貼り付け

ほかのアプリから文章をコピーしてダーク モードの Word に貼ると、白い背景に黒い文字で表示されることがあります。ヘルプでは、Ctrl+Shift+V を押すか、［貼り付けオプション］で［テキストのみ貼り付け］を選ぶよう案内しています。 書類の中で一部だけ白く見える行があるときは、まずこれを疑います。

6．暗い用紙のままだと見誤りやすいもの

ヘルプの「既知の問題」には、貼り付けのほかにも、ダーク モードで見え方がそろわない場面が挙がっています。

  • 画面の一部：一部のサイド ペインとダイアログ ボックスは、ダーク モードに対応していない場合があります。
  • ペンで描くとき：描いている間は、ペンを離すまでインクの色がダーク モードの色に変わりません。
  • 文書の中の部品：グラフ、テキスト ボックス、数式などの一部の部品は、ダーク モードの配色に合わせて表示されない場合があります。

グラフを貼った月次の報告書や、テキスト ボックスで囲みを作った案内文は、暗い用紙の上では色の組み合わせが仕上がりと違って見えることがあります。ヘルプも、印刷や共有の前に見え方を確かめるときは、ボタンでページの背景を明るい色に変えるよう書いています。 送る前の最後の確認だけは、白い用紙で行うと決めておくと迷いません。

7．Mac 版・Web 版では設定の名前が変わる

ダーク モードの設定は、Windows・Mac・Web のそれぞれで別に持つもので、ヘルプにもプラットフォームごとにオンにする必要があると書かれています。 同じ人が会社の Windows と自宅の Mac、出先のブラウザーを使い分けていると、場所ごとに用紙の色が違って見えるのはこのためです。

  • Mac 版（ヘルプの Mac のタブ）：Word のダーク モードを使うには、macOS 側でダーク モードを有効にします。 用紙を明るく保つ設定は、［Word >設定］>［一般］>［パーソナライズ］にある［ダーク モードのページの色は白］です。
  • Web 用 Word（ヘルプの Web のタブ）：OS かブラウザーのテーマがダーク モードなら、自動的にダーク モードになります。 用紙の色は、リボンの［表示］タブの［背景を切り替える］か、ステータス バーの右下にある［明るい背景に切り替える］のトグルで変えます。 選んだ状態はブラウザーごとに記憶され、記憶されないときはブラウザーの Cookie の設定を確かめるよう案内されています。

8．社内で表示をそろえるなら（架空の例）

そろえること架空の記入例
書類の色を確かめるとき［モードの切り替え］で用紙を白にしてから見る
印刷前の確認印刷プレビューで色を見る
貼り付けの決まり外から持ってきた文は［テキストのみ貼り付け］

画面の見え方の好みは人それぞれですが、書類の確認の手順はそろえておくと、見落としが減ります。書類作りの手順を洗い出して見直すときは、事務の道具と作業の棚卸しの考え方も使えます。
