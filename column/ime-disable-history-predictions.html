Microsoft IMEの予測入力に入力履歴を出さないには

要点

Microsoft IME の予測入力に入力履歴を使わないようにするには、履歴を使用する設定を無効にします。変更後は、設定の状態と、入力中に何が表示されるかを分けて確認します。候補が見えるという理由だけで失敗とせず、過去の入力内容を使わせたくないという目的に沿って、変更した項目を見直すことが大切です。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、予測入力に過去の入力履歴を出さないようにしたい小さな会社の担当者が、Microsoft IME の設定と変更後の表示を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 過去の入力を候補に使う部分を見分ける
  2. 設定を開き、履歴を使用する項目を無効にする
  3. 候補が残ったときに広げすぎない
  4. 業務の内容を使わずに表示を確かめる
  5. 引き継ぎは変更内容と確認結果を対にする
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．過去の入力を候補に使う部分を見分ける

確認日：2026年11月15日。

Microsoft の日本語ヘルプの適用先は Windows 11 と Windows 10 で、この記事では Windows 11 の操作を対象にします。画面の表記は Windows の版や更新状況によって異なることがあります。予測候補ウィンドウは、入力を先取りした候補を表示する場所です。

作業を始める前に、「入力の途中で以前の言葉が出る」のか、「文字を確定した後の内容が違う」のかを書き分けます。今回確認するのは、過去に入力した内容を、途中の候補として使わせたくない場面です。文書そのものの誤字や、入力したい言葉の表記を直す作業とは、困っている現象を分けておくとよいです。

最初の記録には、見えた言葉の全文を残す必要はありません。「以前に入力した宛名らしい候補が出る」のように、内容の種類と、表示されたタイミングを書けば、変更後にどこを見るかが明確になります。

2．設定を開き、履歴を使用する項目を無効にする

タスクバーから設定を開く

タスクバーのシステムトレイにある IME オプションのアイコンを右クリックし、［設定］を選びます。入力中の画面から進む場合は、まずこの入口を使います。別の場所を探し回る前に、開いた画面の名前を確かめておくと、引き継ぎの説明もそろえやすくなります。

候補の設定へ進む

候補を調整する場所は、［Microsoft IME 設定］から［全般］へ進んだ先の［予測入力］です。ここで、入力履歴を使用する項目を無効にするのが、履歴由来の予測候補を使わないための変更です。

変更前の状態を記録してから、目的の項目だけを変えます。近くにある項目をまとめて変更すると、後から表示の違いを確認しても、どの変更によるものかを切り分けにくくなります。記録には、変更した項目の画面上の名前と、変更前後の状態を対にして残す形が適しています。

操作の途中で説明と違う画面に進んだときは、その場の見た目だけで似た項目を選ばず、開いている画面の名前と入口を照合します。引き継いだ説明を修正する際にも、通った経路を途中からつなぎ合わせず、出発した場所から書き直すとよいです。

3．候補が残ったときに広げすぎない

同じ候補の設定には、システム辞書を使う項目もあります。このため、変更後の確認を「何も表示されないこと」だけにすると、目的より広い範囲を変えることになります。今回の目的は、過去の入力内容を候補に使わせないことです。ほかの表示まで消したいのかは、別に整理します。

公式ヘルプでは、日付など一部の候補は削除できないことも案内されています。消したい言葉が残ったときも、表示されているものをすべて同じ種類と考えず、何を入力した時点で見えたかに戻って確認することが大切です。

また、候補に使うかどうかを変えた記録と、保存された情報を消去した記録は分けて扱います。今回の設定変更の記録に、そのまま「保存情報をすべて消去済み」と書き足すのは避けます。消去が目的であれば、対象となる情報と操作の範囲を確かめてから別の作業として進める形です。

期待した結果と違ったときは、さらに項目を変える前に、変更した箇所を再確認します。見えた候補の全文ではなく、読みを入れた段階なのか、候補を選ぼうとした段階なのかという状況を残すと、相談する相手にも現象を伝えやすくなります。

4．業務の内容を使わずに表示を確かめる

ここからは当社の整理です。

試し入力には、取引先の宛名、個人の連絡先、未公開の案件名を使わず、業務と関係のない短い言葉を用意します。確認のために見せたくない言葉を再入力すると、その内容を周囲に見せる場面を増やしてしまいます。画面を共有する前に、表示内容を自分の手元で確かめる流れにします。

確認する場面用意するもの・見るところ記録の書き方
変更前の状態を残す開いている画面と、対象項目の現在の状態項目の名前と状態だけを記録
入力途中の表示を見る業務に関係のない「はな」などの短い読み表示の有無と、表示されたタイミングを記録
期待と違う表示がある変更した項目と、確認時に使った読み追加変更をする前の状況を記録

試す前に「どの表示を避けたいか」を短く決めておくと、確認の途中で目的が変わりにくくなります。入力中に何かが見えたというだけで終わらせず、当初困っていた表示との関係を見ます。判断がつかなかった部分は、確認できた部分に混ぜず、状況を残して相談する形が適しています。

画面の画像を残す場合も、作業中のメールや周辺の文書が一緒に写っていないかを見ます。設定の状態を伝えるための画像に、業務の内容まで含める必要はありません。

5．引き継ぎは変更内容と確認結果を対にする

引き継ぎの記録では、「困っていた表示」「設定を開いた入口」「変更した項目」「変更前後の状態」「試し入力で見たこと」をひと続きに残します。「対処済み」だけでは、次の担当者がどこまで確認したか分かりません。表示を見たことと、保存情報の扱いまで確認したことを、同じ意味で使わないようにします。

作業日と確認した人も併せて残しておくと、後から別の担当者が見直すときの起点になります。複数の端末を扱う職場では、どの端末で確認した記録かを区別し、未確認の端末まで対応済みに含めない形がよいです。

記録を渡す前には、説明だけを読んで設定の場所までたどれるかを確かめます。候補に現れた業務の言葉を記録の見出しに使わず、変更した内容が分かる名前にすると、後から探すときにも内容を広げずに済みます。

同じ文面を繰り返し入力する事務の手間を洗い出すなら、候補の見直しに加え、どこで転記や書き直しが起きているかを整理します。その先の検討には、事務作業への AI 活用を考えるという視点もあります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□避けたい表示と、その表示が出るタイミングを区別したか
□設定を開いた入口と画面の名前を確認したか
□変更した項目の名前と変更前後の状態を記録したか
□候補が残ったことだけで結果を判断しないようにしたか
□業務と関係のない言葉で試し入力したか
□保存情報を消去したという記録と混同しないようにしたか
□引き継ぎの記録や画像に業務の内容が含まれないか確認したか
