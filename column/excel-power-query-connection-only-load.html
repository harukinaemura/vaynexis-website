Excelの取込用クエリをシートへ展開せず接続だけ残すには

要点

Windows版Excelでは、取込用クエリの読み込み先を指定する画面で［接続の作成のみ］を選びます。Windows版で作成済みなら対象の読み込み先を開き直します。Web版の読み込み先は、ブラウザー版の節に沿って確認します。途中の取込と人が見る完成表を区別し、変更対象と残したい表を先に控えると、引き継ぐ人にも意図が伝わります。

公開：2026年11月8日／情報の確認日：2026年11月7日（出典はこの記事の最後）

小さな会社の事務担当者が、Excelの中間取込を接続だけ残し、シートに載せる完成表を分けて管理する手順です。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 表を表示する場所と、取込の処理を分けて考える
  2. 新しく取り込むときは、読み込み先を指定する
  3. 作成済みなら対象の［読み込み先］を開き直す
  4. ブラウザーでは専用の読み込みメニューを使う
  5. 中間取込と完成表の役割を短い表に残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．表を表示する場所と、取込の処理を分けて考える

確認日：2026年11月7日。

デスクトップの手順はWindows版のExcel for Microsoft 365を対象とします。作成・読み込みの公式ヘルプの適用先には、Excel 2024、Excel 2021、Excel 2019、Excel 2016も掲載されています。以下では作成済みの対象を扱う方法と、作成途中で指定する方法を分け、ブラウザーでの操作は別の節にまとめます。

クエリを作ると接続情報も作られ、クエリはデータの整形、接続情報は取込元の情報の維持と更新設定に沿った更新を担います。取込途中の状態を毎回配布する必要があるか、完成した一覧だけを見せたいかを先に決めます。

作業前には変更対象の名前と、人が確認する完成表の名前を控えておくとよいです。見えている表だけを頼りに片付けるのではなく、どの取込を残し、どの結果を表示したいのかを整理してから設定に進みます。

2．新しく取り込むときは、読み込み先を指定する

取込を始める入口の例として、［データ］→［データの取得］→［ファイルから］→［テキスト/CSV から］があります。対象のファイルと内容を確認し、必要な加工を終えた段階で、結果の置き方を決めます。

Power Query エディターでは、［ホーム］で読み込みのメニューを開き、［読み込み先］を選ぶとインポートのダイアログを開けます。［データのインポート］では［接続の作成のみ］を選び、［OK］で確定します。

［このデータをデータ モデルに追加する］は、データモデルへ読み込むための選択項目です。シートにもデータ モデルにも読み込まないときは、［接続の作成のみ］を選び、データ モデルへの追加が選択されていないことを確認します。

取込途中のものを整理する作業では、表示する表を増やしたいのか、取込の定義を残したいのかを、確定する直前にも見直します。完成表の置き方まで同じ扱いにせず、それぞれの用途に合わせて指定する進め方です。

3．作成済みなら対象の［読み込み先］を開き直す

Excelで［データ］から［クエリ & 接続］を開き、［クエリ］タブで対象を探します。対象を右クリックして［読み込み先］を選ぶと、［データのインポート］が開きます。そこで前節の接続を残す選択に進みます。

名前の似た対象が並んでいるときは、控えておいた変更対象と照合します。完成表を作っているものと、取込途中に使うものを区別できてから変更するとよいです。現在見えている表をほかの集計や配布に使っている場合は、その利用先も先に控えます。変更前のブックを控え、参照先の動作を変更後に確かめます。

初めてクエリを作る際に［読み込み先］が無効になる場合、公式ヘルプでは一度読み込んだ後、一覧で対象を右クリックして［読み込み先］を選ぶ方法を案内しています。

設定後の内容を見直す入口は、対象を右クリックしたときの［編集］です。表が見当たらないという理由だけで取込を作り直さず、対象を選べるか、元の内容をたどれるかを確認します。

4．ブラウザーでは専用の読み込みメニューを使う

Excel for the webでは、クエリの表示と更新はすべてのMicrosoft 365サブスクライバーが利用でき、追加機能はBusinessプランまたはEnterpriseプランのE3以上が対象です。この節はブラウザー版の操作を扱います。

編集後は、MicrosoftのWeb版ヘルプの読み込み先を指定するメニューで、シートへ読み込むか、接続のみのクエリを作るかを選べます。作成したクエリは、クエリと接続のウィンドウで確認できます。

MicrosoftのWeb版向けのクエリ管理の説明では、データ モデルへ読み込まれたクエリにも「接続のみ」と表示されます。その表示だけを、どこにもデータを読み込んでいないという意味には受け取らず、設定した保存先と合わせて見るとよいです。

5．中間取込と完成表の役割を短い表に残す

ここからは当社の整理です。

元の内容、途中の加工、人が確認する結果を分けて、引き継ぐ情報を表にまとめます。

対象担当する役割引き継ぐ内容
取込元取込元データを保管する元データの保管場所
中間取込確認用の結果を作る前の加工を受け持つ接続だけ残すクエリの名前と読み込み先の指定
完成表担当者が内容を照合する表の置き場と照合する項目

残したい処理と、人に見せる結果を対応させておくことが目的です。変更後は途中の表の有無だけで終えず、完成表に必要な見出しや対象がそろっているかを見ます。取込元と表示結果の内容を照合し、設定の変更とデータの正しさを別々に確かめます。

引き継ぎには、変更した対象、残したい結果、照合した内容を短く記録するとよいです。確認が済んだ範囲と利用先の確認を待つ範囲も分けておくと、次の担当者が続きを進められます。
