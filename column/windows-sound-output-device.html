Windowsのサウンドで音が出る出力デバイスを替えるには

要点

音を出す先を替えるには、サウンドの［出力］で使う機器を選びますが、この選択は既定の出力先の設定にもなるため、選ぶ前に音を届けたい相手と場所を決め、変更後は目的の機器から聞こえるところまで確かめるとよいです。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、音を出す機器を替えたい小さな会社の担当者が、Windowsの出力デバイスの選択と変更後の再生を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 設定画面では［出力］から使う機器を選ぶ
  2. タスクバーから開くときは音量と出力先を区別する
  3. 選んだのに聞こえないときの確認を分ける
  4. 事務で使うときは誰に聞かせるかを先に決める
  5. 引き継ぎには選んだ名前と聞こえた結果を残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．設定画面では［出力］から使う機器を選ぶ

確認日：2026-11-15

Microsoft の日本語ヘルプをもとに、Windows 11 の［サウンド］で出力先を選ぶ手順を扱います。画面の表示は更新によって変わることがあります。

対象にするのは、接続済みの機器を一覧から選ぶ作業です。新しい機器の追加や修復に進む前に、何から音を出したいのかを言葉にしておくと、選択時に迷いにくくなります。

開く場所と選ぶ場所

［スタート］→［設定］→［システム］→［サウンド］の順に開き、［出力］で目的のオーディオデバイスを選びます。

Microsoft の案内では、［出力］で再生に使うデバイスを選ぶと、そのデバイスが既定値にも設定されます。

操作前には、現在選ばれている名前と、変更したい機器を手元のメモに残しておくとよいです。表示名だけでは現物との対応が分からないときは、分かったつもりで選択を進めず、機器の表示や管理担当者の案内と照らし合わせます。引き継ぎに使う説明でも、「上にある項目」のような位置だけの案内を避け、使う機器を識別できる書き方にすると、後から確認しやすくなります。

2．タスクバーから開くときは音量と出力先を区別する

タスクバーから進む場合は［スピーカー］アイコンを選び、音量スライダーの右側の矢印から、接続されているオーディオデバイスの一覧を開きます。

その矢印にカーソルを合わせた際の表示は、公式ヘルプでは「サウンド 出力の選択」です。

音の大きさを調整したところで作業を終えず、どの機器を選んだかまで確かめます。引き継ぎの説明を作るときは、「音を大きくする操作」と「聞こえる先を替える操作」を別の行にすると、目的が伝わりやすいです。先ほどの設定画面から進む方法と、こちらから一覧を開く方法は、入口を分けて書きます。途中から別の方法の説明を混ぜると、読み手が現在開いている場所を追いにくくなるためです。

選択後は、スピーカーやヘッドフォンなど、使うオーディオデバイスで実際に再生されているかを確認します。

3．選んだのに聞こえないときの確認を分ける

Microsoft は、スピーカーを内蔵しない外付けモニターが既定の出力デバイスに選ばれている場合、音が出ないと説明しています。

画面に名前があるという理由だけで、その機器を音の確認先にしないことが大切です。手元で聞きたいのか、同席者に聞かせたいのかに立ち戻り、選んだ機器と目的を照らし合わせます。確認用の音には、周囲に聞こえても支障のない短い内容を使うとよいです。聞こえた場所まで言葉にすると、「選択は済んだが再生結果は見ていない」という状態を避けられます。

出力先を選んだ後も無音なら、音量がミュートになっていないか、音量スライダーが上がっているかを確認するのが公式の手順です。

また、一部のスピーカーやアプリには、それぞれ独自の音量調整があります。

ヘッドホンが接続されているとスピーカーが動作しない場合もあると、Microsoft は注意を促しています。

出力先を選んだ結果と、音量を確かめた結果は分けて記録します。変更した項目をまとめて「直した」と書くより、何を選び、どこまで聞こえたかを残すほうが、次の担当者が状況を追いやすくなります。

Microsoft は、スピーカーやヘッドホンが［サウンド］設定の［出力］に表示されない状態を、出力デバイスが見つからない・検出されない問題の症状として挙げています。

目的の機器が見当たらない段階では、選択を終えた扱いにせず、表示されていないという事実を管理担当者へ渡します。ここで扱う切り替えの手順は、一覧にある機器を選ぶところまでです。

4．事務で使うときは誰に聞かせるかを先に決める

ここからは当社の整理です。

仕事中の使い分けは、機器名を覚える前に、音を聞く人と場所を整理すると考えやすくなります。自分だけで確認する場面と、同席者にも聞いてもらう場面では、選択後に確かめたいことが違います。

使う場面の架空例音を届けたい範囲選択後に確かめること
席で説明動画を見る自分の手元自分が聞く機器から再生されたか
打ち合わせで短い音声を共有するその場の同席者同席者が聞く機器から再生されたか
共有を終えて個人作業へ戻る自分の手元次の作業に合う聞こえ方になったか

この表は選択する機器を固定するものではありません。職場にある機器と利用場所に合わせて、確認の言葉を置き換えます。特に共同で使う場所では、操作をした人の聞こえ方だけで終わらせず、音を届けたい相手にも聞こえたかを確かめるとよいです。終了後の状態も決めておけば、次に使う人へ説明する内容がはっきりします。

5．引き継ぎには選んだ名前と聞こえた結果を残す

引き継ぎのメモには、利用場所、使いたかった機器、選んだ表示名、再生の結果を残すとよいです。「音が出ない」だけでは、機器を選べなかったのか、選べた後に聞こえなかったのかが伝わりません。聞こえた場合も、自分の手元なのか同席者の側なのかを添えると、意図した結果かを確かめやすくなります。

うまくいかなかった場合は、試した内容と未実施の内容を分けます。名前を選ぶところまでは進めたのか、再生を試せたのか、確認を途中で止めたのかを残す形です。原因が分からないまま故障と書いたり、確認していない機器まで使用可能としたりせず、見えたことと聞こえたことを記録します。

メモの最後には、共有して聞く状態で終えたのか、個人で聞く状態へ戻したのかを添えると、次の担当者が利用を始める前の確認に使えます。

この作業に伴う事務の手間を洗い出すなら、機器を選ぶ操作と、手順書や引き継ぎメモを整える作業を分け、AIの活用を考える際の整理につなげるとよいです。まず人が確かめる箇所を明らかにし、文章の整理をどこまで任せるかを検討します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□音を聞く人と、音を届けたい場所を決めたか
□使いたい機器と、一覧に表示された名前を照合したか
□操作前に選ばれていた名前を控えたか
□音の大きさの調整だけで終わらず、目的の機器を選んだか
□選択後に、意図した場所から音が聞こえるか確かめたか
□終了時の状態と、未解決の点を引き継ぎに残したか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月15日）

  • Windows でスピーカーまたはヘッドホンからサウンドが再生されない場合のオーディオの問題を修正する：適用先、設定画面からの選択、ミュートと音量の確認
  • Windows のサウンドまたはオーディオの問題を修正する：既定の出力先、タスクバーからの一覧表示、再生確認、外付けモニターと独自の音量調整
  • Windows でオーディオ出力デバイスが見つからない、または検出されない問題を修正する：出力先が表示されない状態と、表示済みの機器を選ぶ作業との区別
