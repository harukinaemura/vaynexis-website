持ち出す社用PCのドライブは暗号化済み？貸出前に確かめる手順

要点

持ち出し前は、社用パソコンの Windows のエディションに合った画面で、暗号化の状態を確認します。Windows Pro・Enterprise・Education の［BitLocker の管理］の画面では、ドライブ文字の横に各ボリュームの状態が表示されるため、仕事の保存先となるドライブが「オン」かを見ます。 Windows Home を実行しているデバイスなどでも使えるデバイスの暗号化は、設定アプリの［デバイスの暗号化］の画面で見ます。

公開：2026年11月5日／情報の確認日：2026年11月5日（出典はこの記事の最後）

この記事は、社用パソコンを社外へ持ち出す前に、保存先のドライブが暗号化されているかを確かめたい小さな会社の事務担当者が、Windows のエディションに合った画面の見方と、記録・引き継ぎの流れを確かめる手順をまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月5日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 最初に、確認に使う画面と権限をそろえる
  2. 設定で全体を見て、必要ならドライブ別に確かめる
  3. 「オン」以外の表示と、項目がない場合を分ける
  4. 管理担当者が詳しく確かめるときの補助
  5. 貸出記録には、見た状態と確認待ちを残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．最初に、確認に使う画面と権限をそろえる

公式資料の確認日：2026年11月4日。

デバイスの暗号化と BitLocker ドライブ暗号化の公式ヘルプの適用先は、Windows 11 と Windows 10 です。パソコンの貸出準備では、利用者が見られる画面と、管理担当者が確認する画面を先に決めておくと、引き継ぎが進めやすくなります。

デバイスの暗号化は Windows Home を含む対応端末でも利用でき、手動で特定のドライブを暗号化する BitLocker ドライブ暗号化とは利用できるエディションが異なります。組織で管理する端末の BitLocker ドライブ暗号化は、通常は IT 部門が管理します。

確認する人と設定を変更する人を分け、貸出担当者だけで変更まで進めない運用にするとよいです。持ち出しの可否を決める社内の担当者も、記録の渡し先としてそろえます。

2．設定で全体を見て、必要ならドライブ別に確かめる

デバイスの暗号化を開く

デバイスの暗号化を有効にする公式手順では、管理者アカウントで Windows にサインインし、設定アプリの［プライバシー セキュリティ］>［デバイスの暗号化］を開いて、トグル ボタンでオンにします。 貸出前の確認では、この画面の表示を見るところまでにとどめます。Microsoft の IT 管理者向けの資料（BitLocker の概要）では、設定画面には、暗号化が完了するまでデバイスの暗号化が有効になっていることが表示されないとされています。操作を始めたことと、確認が済んだことは、記録の欄を分けると混同しにくくなります。

個々の保存先を見る

Windows Pro・Enterprise・Education では、管理者アカウントでサインインしたうえで、スタートで「BitLocker」を検索し、［BitLocker の管理］を開く方法もあります。 BitLocker は Windows Home エディションでは利用できず、［BitLocker の管理］が一覧にない場合は、正しい Windows エディションがないことを意味するとされています。この画面には接続されているドライブが一覧表示され、追加の保存用ドライブは［固定データ ドライブ］の下に並びます。

同じ IT 管理者向けの資料では、デバイスの暗号化で暗号化されるのは OS ドライブと固定ドライブのみで、外部・USB ドライブは暗号化されないとされています。

パソコンの名称だけで確認済みにせず、業務ファイルの保存先と画面のドライブを照らし合わせて記録するとよいです。確認した保存先と、まだ見ていない保存先を区別して残します。

3．「オン」以外の表示と、項目がない場合を分ける

BitLocker 操作ガイド（IT 管理者向けの資料）の［コントロール パネル］の欄では、［BitLocker の管理］の画面に出る状態として、「オフ」は BitLocker がボリュームに対して有効になっていない状態、「Suspended」は BitLocker が中断され、ボリュームがアクティブに保護されていない状態とされています。「アクティブ化を待機中」は、完全に保護するにはさらなるアクションが必要な状態とされています。表示を読み替えて確認済みにせず、そのまま管理担当者へ伝える運用にするとよいです。

［デバイスの暗号化］が表示されない場合は、端末で利用できないか、標準ユーザーアカウントでサインインしている可能性があります。項目が見えない結果は、暗号化の状態を確認できた結果とは分けて扱います。

管理担当者は、デバイスの暗号化が使えない理由を［システム情報］で調べられます。公式ヘルプの手順では、［スタート］から「System Information」と入力し、結果のリストにある［システム情報］を右クリックして［管理者として実行］を選び、［システムの概要 - 項目］のリストで［自動デバイス暗号化サポート］または［デバイス暗号化サポート］の値を探します。こちらは利用できる要件を調べる欄として扱い、現在の保護状態の確認と混ぜないようにします。

4．管理担当者が詳しく確かめるときの補助

管理担当者がドライブの状態を詳しく調べる方法として、次のコマンドは C ドライブの状態を表示します。

manage-bde -status C:

状態表示の項目には、暗号化の割合を示す Percentage encrypted と、保護状態を示す Protection status が含まれます。BitLocker の概要の資料では、デバイスの暗号化について、デバイスがローカル アカウントのみを使用している場合、データは暗号化されていても保護されないとされています。暗号化済みという情報だけで貸出準備を終えず、保護の状態も管理担当者と照合する流れにします。

コマンドの結果を読む担当者まで決めておけば、事務担当者が表示の意味を推測して判断する場面を減らせます。結果と次に行う対応は、別々に記録すると引き継ぎやすくなります。

5．貸出記録には、見た状態と確認待ちを残す

ここからは当社の整理です。

貸出用の記録には、端末名、確認した保存先、画面の表示、確認者、次の対応をそろえます。記録するのは判断の根拠になった表示です。設定済みといった広い書き方だけでは、何を確認したのかを後から追いにくくなります。

対象記録する内容の例次の対応
貸出用の社用端末利用予定の端末名と確認者貸出対象と照合する
業務ファイルの保存先確認したドライブと、見た表示管理担当者が内容を確認する
状態を読めなかった保存先開いた画面と、確認できなかった箇所確認待ちとして引き継ぐ
貸出の判断判断した担当者と確認した日時社内の持ち出しルールに沿って扱う

確認待ちが残る端末は、貸出可否を判断する担当者へ引き継ぐとよいです。利用者に渡す前に、誰が何を確かめるかまで決めると、記録だけを残して対応が止まることを防ぎやすくなります。

公開・共有の前に、この表で確かめます。

出典（確認日：2026年11月5日）

  • Windows でのデバイスの暗号化：適用先、利用できるエディション、設定画面、項目がない場合、使えない理由の調べ方
  • BitLocker ドライブ暗号化：管理主体、対象エディション（Home では使えない）、管理画面の開き方、ドライブ一覧
  • BitLocker の概要（Microsoft Learn・IT 管理者向け）：設定画面の完了表示、デバイスの暗号化の対象ドライブ、ローカル アカウントのみの場合の注意
