Excelで循環参照の警告が出たとき、原因のセルを探すには

要点

原因のセルは、［数式］→［エラー チェック］→［循環参照］の一覧から探します。表示されたセルの数式を直し、ステータスバーの循環参照の表示が消えるまで確認を繰り返すのが基本です。

公開：2026年11月11日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、Excelで循環参照の警告が出て集計の値が信用できなくなった小さな会社の事務担当者が、［エラー チェック］の［循環参照］と参照元のトレースで原因のセルを探し、修正後も表示が残るときの理由を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 警告を閉じる前に、原因と対象の版を整理する
  2. 一覧のセルを選び、数式が自分に戻っていないか見る
  3. 集計する範囲に、集計欄自身を含めていないか
  4. 式の中に自分の番地がなくても、参照元を追う
  5. 修正後も残る表示と、再び出ない警告を区別する
  6. 引き継ぐときは、直した理由と残る疑問を分ける
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．警告を閉じる前に、原因と対象の版を整理する

確認日：2026年11月10日

公式ヘルプの適用先は、Excel for Microsoft 365、Excel 2024、Excel 2021のWindows版とMac版、およびExcel 2019、Excel 2016です。ヘルプでは、Windows と Mac のデスクトップ版は、どちらも［数式］＞［エラー チェック］＞［循環参照］を使うとされています。以下ではWindowsのデスクトップ版で原因を探し、数式を見直す手順を扱います。参照元をたどるトレースのヘルプは、適用先が Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 で、Mac 用の版は挙がっていません。

循環参照は、数式が直接、またはほかのセルを経由して自分自身を参照するときに発生します。警告を閉じたあとでも、セルにはゼロや最後に計算された値が表示されることがあるため、値の見た目だけでは修正できたか判断できません。

原因を調べるときは、値が不自然に見える欄だけに注目せず、その値を求める式のつながりを確認するとよいです。入力する欄と結果を表示する欄の役割を分けて見ると、どこに戻りの参照があるかを整理しやすくなります。

2．一覧のセルを選び、数式が自分に戻っていないか見る

［数式］タブから［エラー チェック］の［循環参照］を開くと、確認するセルの一覧へ進めます。一覧のセル番地を選び、数式が自分自身を指さない形へ修正します。

先に見るのは、数式を置いている場所と、その式が材料として読みに行く場所の関係です。式の記号をやみくもに変えるよりも、どの入力欄から何を集計したいのかを言葉にすると、残す参照と外す参照を判断しやすくなります。

コマンドが見当たらない場合は、Excel の検索ボックスで Error Checking または Circular References を検索する方法が案内されています。コマンドが無効になっている場合は、ワークシート内のセルを選択してから操作し直します。Web版やモバイルアプリでは数式監査のコマンドが制限される場合があるため、原因の特定と修正はデスクトップアプリで行う案内になっています。

3．集計する範囲に、集計欄自身を含めていないか

たとえばD3に「=D1+D2+D3」が入っていると、結果を置くD3が計算の材料にもなり、計算を完了できません。合計の関数でも同じで、F3 に「=SUM(A3:F3)」が入っていると、F3 が計算中の範囲に含まれます。

架空の事務用集計欄に当てはめると、確認する場所は次のように分けられます。

欄の役割場所・式確認する点
集計の材料を置く欄D1、D2合計に含めたい入力欄か
集計結果を置く欄D3入力欄と結果欄を分けているか
見直す式=D1+D2+D3結果欄自身への参照を含んでいないか

修正方法には、数式を別のセルへ移す方法と、循環参照が起きないように数式の書き方を変える方法があります。

どちらにするかは、表をどう使うかで考えます。結果欄の位置を維持したいなら集計する範囲を見直し、入力欄の並びを維持したいなら結果欄の置き場所を検討するとよいです。警告を消すために材料となる入力値まで削ると、求めたい集計から離れてしまうため、残すべき入力欄を先に整理します。

4．式の中に自分の番地がなくても、参照元を追う

問題が複数のセルにまたがる場合は、参照関係をたどって原因を探します。

選んだセルへ直接データを渡しているセルを見るには、［数式］タブの［数式監査］で［参照元のトレース］を選びます。さらに手前の参照元を調べるときは、［参照元のトレース］をもう一度選びます。青い矢印はエラーのないセル、赤い矢印はエラーの原因となっているセルを示します。

トレースの前の準備として、［ファイル］＞［オプション］＞［詳細設定］の［このブックの表示オプション］で、［オブジェクトの場合、表示］が［すべて］になっているかを確かめる手順が挙がっています。

目の前の式に同じ番地が見当たらない場合も、途中で使われている式を読み、出発した場所に戻るつながりがないか確かめるとよいです。表示された場所を入口にして、どこで計算の流れが輪になるかを確認していきます。ヘルプには、A1 に「=B1+1」、B1 に「=A1+1」が入っていて、各セルが互いに依存する例が挙がっています。

参照元が別のワークシートやブックにある場合は、黒い矢印をダブルクリックして［ジャンプ］を開き、［移動先］の一覧から目的のセルをダブルクリックします。別ブックの参照セルを調べるには、そのブックを開いておく必要があります。

数式の変更や行・列の挿入と削除、セルの削除と移動を行うとトレース矢印は消えるため、変更後は表示し直します。

5．修正後も残る表示と、再び出ない警告を区別する

ステータスバーには、循環参照とセル番地が表示されることがあります。別のワークシートに原因があると、番地のない循環参照の表示だけになる場合があります。

修正しても警告が続く場合の主な確認対象には、別のワークシートに残った循環参照があります。別の開いているブックに循環参照が残っている場合もあります。数式のつながりに間接的な自己参照が残っていないかも確認します。ヘルプの理由の一覧には、反復計算が有効になっていて、循環参照が意図的に許可されている場合も挙がっています。

一方、警告メッセージは、そのセッションで初めて循環参照が作られたときに表示され、それ以降の循環参照では同じ警告ダイアログが出ない場合があります。修正の区切りは警告の再表示の有無だけで判断せず、ステータスバーに循環参照が表示されなくなるまで確認します。

反復計算で循環参照を許可する仕組みは、再計算を意図した特定の財務モデルやエンジニアリングモデル向けで、ほとんどのワークシートでは反復計算をオフのままにする案内です。

6．引き継ぐときは、直した理由と残る疑問を分ける

ここからは当社の整理です。

引き継ぎには、警告が出たときの状態、修正前後の式、求めたい集計の意味、確認できた範囲を残すとよいです。「警告が消えた」という結果だけでは、入力欄を減らしたのか、結果欄を移したのかが次の担当者に伝わりません。

式を読んでも、なぜその欄を参照するのか分からないときは、計算方法を決めた担当者に確認します。確認済みの範囲と、まだ意味を判断できていない範囲を分けて記録すると、途中の状態でも次に調べる場所が明確になります。

最後は、修正後の結果が表の目的に合っているかを、元の入力内容と照らして確かめます。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□警告の出た場所と、実際に調べた場所を記録したか
□数式を置く欄と、その材料になる入力欄の役割を整理したか
□集計の対象に、結果を置く欄自身を含めていないか確認したか
□途中の参照を追い、出発した場所へ戻るつながりを確認したか
□修正前後の式と、変更した理由を残したか
□修正後の結果を、元の入力内容と照合したか
