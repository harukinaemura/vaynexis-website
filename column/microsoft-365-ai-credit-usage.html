Microsoft 365の「AI クレジット」使用量はどこで見る？

要点

Microsoft 365の「AI クレジット」と制限の状態は、Microsoft アカウントの「サービス & サブスクリプション」で確認します。見る順番は、契約に使ったアカウント、対象の契約、表示された状態です。

公開：2026年11月16日／情報の確認日：2026年11月16日（出典はこの記事の最後）

個人向け Microsoft 365 の AI クレジット使用量は、契約に使った Microsoft アカウントの「サービス & サブスクリプション」で確認し、所有者と共有相手の違いや機能ごとの制限を分けて読み取ります。

公式ページ・公式ヘルプなどの一次資料を2026年11月16日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 購入時のアカウントから確認する
  2. 契約の所有者と共有相手を分ける
  3. 使用量と機能ごとの上限を読み分ける
  4. 確認を引き継ぐための記録を作る
  5. 表示が見つからないときは購入先も確認する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．購入時のアカウントから確認する

確認日：2026年11月16日

Microsoft の契約管理ヘルプでは、購入に使った Microsoft アカウントで account.microsoft.com/services にサインインする手順が案内されています。すでにブラウザーで画面を開いている場合も、表示されている名前だけで進めず、契約時の控えと照らし合わせるとよいです。

契約管理ヘルプの適用先は、家庭向け Microsoft 365、Microsoft 365 Family、Microsoft 365 Personal です。この記事は個人向け契約を対象にしており、法人向け契約の使用量を調べる手順は扱いません。

確認の進め方としては、契約名が分かる控えを用意し、開いているアカウント、対象の契約、表示された状態の順に記録します。契約を見つける前の段階と、契約は見つかったが使用量の表示が分からない段階では、次に調べることが異なります。「表示がない」という言葉だけでまとめず、どこまで確認できたかを残すことが大切です。

2．契約の所有者と共有相手を分ける

Microsoft の日本語FAQでは、Microsoft 365 Personal、Family、Premium、Pro プランに AI クレジットが含まれると案内されています。Microsoft 365 Family・Premium に含まれる Word、Excel、PowerPoint、Outlook、Designer の AI 機能は、サブスクリプション所有者だけが使用でき、他のユーザーと共有することはできません。

担当者が利用状況を取りまとめる際は、「契約の所有者」と「確認作業をする人」を分けておくとよいです。共有を受けている人の画面を見ただけで、契約全体の状態を確かめたことにはしない、という確認の進め方です。確認できた人と画面の対象が食い違っていると、別の対象について話していることに気づきにくくなります。

手元の記録には、契約名と確認した人の役割を残します。操作した人の名前だけでは、所有者として確認したのか、共有相手として見たのかを後から区別できません。契約内容を調べる前に、誰の契約について回答が必要なのかを明確にすると、確認を引き継ぐ際にも話がつながります。

3．使用量と機能ごとの上限を読み分ける

Microsoft の説明では、機能制限は一定期間に特定の機能を使える合計回数、AI クレジットは Microsoft 365 や Windows アプリで使う月単位の使用量割り当てです。画面の見方としては、表示された値だけでなく、見出しと対象の機能を組み合わせて読むとよいです。

たとえば、利用できないという状態を記録する場合も、どの機能についての表示なのか、利用枠そのものを示す欄なのかを区別します。表示された内容を自分の言葉で短くしすぎると、元の画面にあった区別が消えてしまいます。まず欄の名前と表示文を控え、それから社内向けの説明を添える順番にすると、読み違いを確かめやすくなります。

AI クレジットの使用量制限に近づいた場合や上限に達した場合は、製品内で通知を受け取ると Microsoft は案内しています。通知を記録するときは、受け取った時点と、その後に確認した画面の時点を分けます。以前の通知だけを見て今の状態を説明するのではなく、確認した日時を付けた記録として扱う方法です。

Microsoft の案内では、制限は機能、エントリ ポイント、システム条件によって異なる場合があり、新しい AI モデルの提供に伴って変わることもあります。同じ契約でも、ある機能の表示から別の機能の利用枠まで推測せず、問い合わせる機能と画面を対応させて記録します。

4．確認を引き継ぐための記録を作る

当社では、所有者に代わって答えを推測せずに済むよう、確認できる人と確認する内容を先に決める進め方を提案します。記録の目的は、使える枠を見積もることよりも、どの契約のどの表示を、いつ確かめたかを説明できるようにすることです。

誰がいつ何を確かめて残すか
契約を把握する人確認を始める前対象の契約名、所有者、購入先
所有者本人対象の契約を開いたとき開いているアカウントと契約の一致
画面を見る人状態を確認したとき確認日時、欄の名前、表示された内容
利用状況をまとめる人社内へ伝える前画面で分かったことと、分からないことの区別

記録の文面は、読んだ人が同じ対象を確認できるかという観点で整えます。「使えなかった」だけでは、契約を見つけられなかったのか、目的の作業で止まったのかが分かりません。契約の確認、表示の確認、実際に困った操作を分けて書くと、次に調べる箇所を絞れます。

5．表示が見つからないときは購入先も確認する

Microsoft 365 の契約管理先は、購入場所によって異なります。アプリストアや小売業者を通じて購入した場合、課金とサブスクリプションの設定は、その購入先で直接管理する必要があります。使用量を確認する話と、支払いや契約設定を変更する話を分けて考えることが大切です。

短い例として、共有を受けた人から「使用量が分からない」と連絡が来た場面を考えます。担当者は、すぐに利用枠が不足したと判断するのではなく、対象の契約、確認した人の立場、開いた画面、表示文の順に聞き取ります。所有者本人の確認がまだなら、その確認を残件として記録する進め方です。

また、「契約が見つからない」「契約は見つかったが状態を読み取れない」「支払いの設定を変更したい」は、別々の相談として整理します。購入先を調べる作業が必要なのはどの問題なのかを明確にし、画面にない表示を想像して補わないようにします。

利用枠の確認と、外部に依頼する作業の検討は、検討事項を分けて残すとよいです。後者を整理する際は、支援にかかる費用の考え方も確認の手がかりになります。

公開・共有の前に、この表で確かめます。

確認確かめること
□対象の契約名と所有者を確認したか
□購入時の控えと、開いているアカウントを照合したか
□所有者と共有を受ける人の立場を分けて記録したか
□表示された欄の名前と、その対象を確認したか
□通知を受け取った時点と、画面を確認した時点を区別したか
□使用量を調べる用件と、課金や契約設定を変える用件を分けたか
□確認できた内容と、追加の確認が必要な内容を分けて記録したか
