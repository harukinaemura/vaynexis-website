Chromeの「前回開いていたページを開く」でタブを戻すには

要点

Chrome で終了前のタブを次の起動時に戻すには、設定の［起動時］で［前回開いていたページを開く］を選びます。ページが開いたことと、仕事を続けられる状態かどうかは、分けて確かめるとよいです。

公開：2026年11月16日／情報の確認日：2026年11月16日（出典はこの記事の最後）

仕事の続きを始めるたびに前のタブを探し直しているなら、Chromeの起動時の設定を確認し、ページの復元と再ログインの確認を分けて進めます。

公式ページ・公式ヘルプなどの一次資料を2026年11月16日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 起動時の画面で復元を指定する
  2. ページの表示とログイン状態を分けて確かめる
  3. 終了後に記録を残さない使い方を混ぜない
  4. 職場の管理表示があるときの確認先
  5. 閉じる前後の比較を引き継ぎに残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．起動時の画面で復元を指定する

確認日：2026-11-16

仕事の続きを始めるたびに、昨日使っていた画面を探し直しているなら、起動時に何を表示するかを見直す余地があります。Google の案内では、起動ページはデバイスで最初に Chrome を起動したときに表示されるページです。ホームページと起動ページには、それぞれ別のページを設定できます。目的を「起動後に前の仕事へ戻る」と言葉にしてから設定を開くと、変更する場所を取り違えにくくなります。

ここでは Windows 版 Chrome の操作を扱います。Chrome を開き、右上のその他アイコンから［設定］を選びます。続いて左側の［起動時］から［前回開いていたページを開く］を選びます。選択後は、目的の項目が選ばれていることを見ておきます。設定画面を開けたことだけで作業を終えず、選んだ内容まで確かめるのが確認の区切りです。

毎回決まったページを開くための［特定のページまたはページセットを開く］も、別の選択肢として用意されています。「前の続きを再開したい」のか「決まった入口から始めたい」のかを、担当者間でそろえておくとよいです。引き継ぎでは、設定名に加えて変更の目的も残します。

2．ページの表示とログイン状態を分けて確かめる

Google は、Cookie とデータが保存されていれば、以前にログインしたウェブサイトが再表示されると案内しています。確認するときは、戻したかったページがあるかを見た後に、ログイン画面が出ていないかを見ます。当社では、この順序で切り分けると、表示先の問題なのか、その先の利用状態の問題なのかを伝えやすいと考えます。

［すべてのウィンドウを閉じるときに、サイトによりデバイスに保存されたデータを削除する］を選ぶと、次のアクセス時に利用者の情報が記憶されている可能性は低くなります。この設定を確認する経路は、［設定］の［プライバシーとセキュリティ］、［サイトの設定］、［その他のコンテンツの設定］、［デバイス上のサイトデータ］です。

ここでは、ログインを残すために保存の方針を変えることを、確認作業の目的にしないほうがよいです。共用の端末か、本人だけが使う端末かによって、職場で守るべき運用も考え合わせます。変更する前に、現在の状態と職場の扱いをそろえておくと、便利さだけを理由に別の設定まで動かすことを避けられます。

3．終了後に記録を残さない使い方を混ぜない

シークレット ウィンドウは、すべて閉じるとシークレット モードのセッションが終了します。ゲストモードも、終了すると閲覧履歴、Cookie、サイトデータが削除されます。

この違いを踏まえ、再開の確認には普段の仕事で使う画面を選ぶとよいです。記録を残さない使い方と、続きを残したい使い方を同じ確認に混ぜると、結果の読み方が曖昧になります。引き継ぎメモでも「閉じる前にどんな使い方をしていたか」を残し、単に「戻らなかった」とだけ書かない形にします。利用していた状態をそろえることが、設定を変える前の手がかりになります。

4．職場の管理表示があるときの確認先

Chrome のその他メニューの下部に［組織によって管理されています］と表示される場合、そのブラウザは管理対象です。選べない項目があるときは、すぐに設定の初期化や管理の解除へ進めず、画面の表示と変更したい内容を社内の管理担当者に伝えるとよいです。

相談のメモには、やりたいこと、開いた設定の場所、選べなかった項目、出ていた表示を分けて残します。「以前はできた」という説明だけより、いま見えている状態を伝えるほうが照合しやすくなります。他の担当者が使っている端末と表示が違う場合も、同じ操作を繰り返す前に、それぞれの管理状況をそろえて確認する流れが考えられます。

5．閉じる前後の比較を引き継ぎに残す

当社では、設定の確認と仕事の再開確認を分けて記録する方法を考えます。開き直す前に、作業中の内容を保存し、閉じてもよい状態に整えておくとよいです。表示先を戻す確認に、未保存の作業を巻き込まないためです。

確認する場面メモに残すこと
終了する前続きに使いたいページの名前と、作業を保存したこと
再び起動した後目的のページが表示されたか、別の入口が表示されたか
仕事を再開するときログインを求められたか、必要な資料を開けたか
引き継ぐとき選んだ設定と、表示が想定と違った箇所

確認では、閉じる前に見ていたページ名と、起動後に表示されたページ名を照らし合わせます。戻ったページがあっても、必要な資料にたどり着けたかは別に見ておくとよいです。見当たらないものがあれば、その名前と画面の状態を記録し、関係のない設定をまとめて変えることは控えます。変更した点を追えるようにしておくと、引き継いだ相手も次に調べる場所を選びやすくなります。

引き継ぎの対象も、設定を共有したいのか、作業の続きそのものを渡したいのかで分けて考えます。後者では、読むべき資料や残っている確認事項を、担当者自身の言葉で記しておくことが大切です。画面がそろったことを、業務の判断や確認まで終わったこととして扱わないようにします。

事務の手間を洗い出すなら、画面を探す手間と、開いた後に読む・転記する手間を分けたうえで、AI を使う作業の整理につなげると考えやすくなります。

確認確かめること
