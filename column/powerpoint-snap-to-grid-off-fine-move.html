PowerPointのグリッド線で図形が細かく動かせないときは

要点

図形が飛ぶように動くときは、まず［グリッドとガイド］ダイアログ ボックスの［描画オブジェクトをグリッド線に合わせる］がオンになっていて、近くのグリッドの交点に吸い寄せられていないかを見ます。オフにするには、［表示］タブの［表示］グループのダイアログ ボックス起動ツールから、このチェック ボックスをオフにします。 一時的に外したいだけなら、ドラッグ中に Alt キーを押したままにします。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

図形や矢印をほんの少しずらしたいのに、ドラッグするとカクッと飛んで思った位置に置けない。グリッド線の表示と位置合わせの違い、位置合わせの外し方、Ctrl キーと方向キーで少しずつ動かす方法を Windows 版のヘルプで確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．「線を消したのに直らない」の理由

確認日：2026年11月17日。

対象は、Windows のパソコンで使う PowerPoint（Microsoft 365 などのデスクトップ版）です。

図形が飛ぶので、画面のグリッド線を消してみたら、それでも飛ぶ、ということがあります。グリッド線を画面に出すかどうかと、図形をグリッドに合わせるかどうかは、別の設定です。

設定何が変わるか場所
［グリッド線］のチェック ボックス画面にグリッド線を表示するかどうか［表示］タブ
［描画オブジェクトをグリッド線に合わせる］図形を最も近いグリッドの交点に置くかどうか［グリッドとガイド］ダイアログ ボックスの［位置合わせ］

細かく動かせないときに見直すのは、2つ目の位置合わせのほうです。

ヘルプによると、既定のグリッド線は縦横1インチ四方のグリッドで、グリッドの大きさそのものは変えられません。 また、［グリッドとガイド］ダイアログ ボックスの［グリッド設定］にも［画面にグリッドを表示］というボックスがありますが、これも画面に出すかどうかの設定です。 表示の欄をいくら外しても、図形の動きは変わりません。

2．位置合わせをオフにする手順

順番操作
1リボンの［表示］を選び、［表示］グループのダイアログ ボックス起動ツールを選ぶ
2［グリッドとガイド］ダイアログ ボックスが開く
3［描画オブジェクトをグリッド線に合わせる］のチェック ボックスをオフにする

ほかのプレゼンテーションでも同じ設定にしたいときは、同じダイアログ ボックスで［既定に設定］を選びます。

3．いつもは合わせて、ときどき外す

表や図をきれいにそろえるには、位置合わせが役に立つ場面も多くあります。いつもはオンのままにして、少しだけずらしたい図形のときだけ、Alt キーを押しながらドラッグする、という使い分けもできます。

グリッドの間隔を変えて、合わせる細かさを調整する方法もあります。ヘルプには、グリッドのサイズは変えられないが、［間隔］のオプションで点と点の間を変えられ、配置の精度を調整できる、と書かれています。

4．キーボードで少しずつ動かす

マウスで狙った位置に置きにくいときは、キーボードで動かす方法もあります。図形やテキスト ボックスを移動するヘルプには、少しずつ移動するには Ctrl キーを押しながら方向キーを押す、と書かれています。 動く距離は1ピクセルで、1画面ピクセルが表す長さはズームの割合によって変わるため、400% で表示していれば動く距離は相対的に小さく、25% なら大きくなります。 細かく合わせたいときは、画面を拡大してから Ctrl キーと方向キーで動かすと調整しやすくなります。

横や縦にまっすぐずらしたいだけなら、Shift キーを押しながらドラッグすると、水平方向か垂直方向にだけ動かせます。 反対に、大きく離れた位置へ移したいときは、ドラッグより切り取りと貼り付けのほうが簡単な場合もある、と案内されています。

並べた図形どうしの間隔を保ったまま位置だけを変えたいなら、Ctrl キーを押しながら境界線をクリックして複数を選び、まとめて動かします。 1つずつ動かして間隔が崩れ、そろえ直すという手戻りを防げます。

Mac 版のヘルプでは、オブジェクトの配置を細かく調整するには Command キーを押しながらドラッグする、と別の操作が書かれています。 Mac で作業する人がいる場合は、この違いも共有しておきます。

5．グリッドを外しても吸い寄せられるとき

グリッドの位置合わせを外したのに、スライドの真ん中あたりで図形が止まる場合は、描画ガイドかもしれません。ヘルプでは、描画ガイドがオンだと、近くでドラッグしたときに図形がガイドの線にスナップされると説明されています。 描画ガイドの表示は、［グリッドの設定］の下の［ガイドを表示］で切り替えます。 描画ガイドは、スライドの中央で交差する、縦と横1本ずつの点線の組です。 真ん中あたりで止まりやすいのは、このためです。

ほかの図形の近くで止まる場合は、スマート ガイドも考えられます。ヘルプでは、スマート ガイドは、あるオブジェクトをほかのオブジェクトに対して位置合わせしたり間隔を合わせたりするのに役立つ、と説明されています。 並んだ図形の端をそろえたいときには便利なので、外す前に、止まる位置が図形の端や中央とそろう所かどうかを見ます。

位置合わせの設定は、線の描き方にも関わります。ヘルプには、グリッドにスナップする設定がオンのときは、フリーフォームの図形を描くときに直線で描ける、と書かれています。 手で描いた線が角ばってしまうときも、同じ設定を見直します。
