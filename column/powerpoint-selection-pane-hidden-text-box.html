PowerPointで奥に重なった文字枠を選ぶ｜選択ウィンドウの使い方

要点

Windows版PowerPointでは、［ホーム］の［配置］から［選択ウィンドウ］を開くと、スライド上の文字枠や図形を一覧から選べます。前にある図形を動かす前に、一覧で対象を見つけて選択します。表示の切替や重なり順の変更が必要かは別に判断します。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、PowerPointで図形の下に隠れた文字枠を直したい小さな会社の担当者が、選択ウィンドウの開き方と、一覧での選択・表示の切り替え・重なり順の違いを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 目的のスライドと文字枠を特定する
  2. 一覧の項目を選んで枠を確かめる
  3. 前面の図形を隠す場合は戻し方を控える
  4. 配布用の表示に戻して点検する
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．目的のスライドと文字枠を特定する

確認日：2026年11月10日。

Microsoftの案内では、選択ウィンドウを使ってスライドのオブジェクトを選択できます。

この案内の適用先は、PowerPoint for Microsoft 365、PowerPoint 2024・2021・2019・2016 と、PowerPoint for Microsoft 365 for Mac・PowerPoint 2024 for Mac・PowerPoint 2021 for Mac です。ページは［新しい Windows バージョン］［新しい Mac バージョン］［Web］の欄に分かれ、選択ウィンドウの開き方が欄ごとに違います。この記事は Windows 版の欄を中心にし、違う所は欄の名前を付けて書き分けます。

Windows 版の欄では、まずオブジェクトをクリックして選びます。この操作で選択されない場合は、［ホーム］タブの［編集］で［選択］をクリックし、次の3つから選びます。スライド上のすべてのオブジェクトとプレースホルダーを選ぶ［すべて選択］、非表示・積み重ね・テキストの背後にあるオブジェクトをクリックしてドラッグで選ぶ［オブジェクトの選択］、複数選択や表示・非表示、順序の変更を行う［選択ウィンドウ］です。案内の図では、太陽と三角形の図形の下に埋め込まれた楕円を、［選択］ウィンドウなら簡単に選べる例が示されています。

ここからは当社の整理です。

スライドの見出しを確認し、変更する文字、文字枠の位置、どの図形に隠れているかを控えます。同じレイアウトが繰り返される資料では、いま直すスライドと、別のスライドに共通する変更を分けます。

2．一覧の項目を選んで枠を確かめる

MicrosoftのWindows向け案内では、［ホーム］の［配置］から［選択ウィンドウ］を開けます。オブジェクトを選んだ後は、通常どおりPowerPointのコマンドと機能をそのオブジェクトに適用できるとされています。

Microsoftの案内のMac 版の欄では、オブジェクトを選んだときにリボンに表示される［書式］タブで［選択ウィンドウ］を選びます（または［配置］＞［選択ウィンドウ］）。Web 版の欄では、［クラシック］リボンでも［Single-Line］リボンでも［ホーム］＞［配置］＞［選択ウィンドウ］の順で開き、［配置］ボタンが表示されない場合は右端の［その他］ボタン（...）を選び、［その他の描画オプション］で［配置］＞［選択ウィンドウ］を選びます。Web 版の欄では、ウィンドウ内の項目をダブルクリックすると名前を変えられるとも説明されています。

一覧で項目を選び、スライド上で選ばれた枠を見ます。一覧から選べば、前面の図形をドラッグしてずらさずに奥の文字枠を選べます。似た名前が並ぶときは、枠の位置と表示したい文字を合わせて確認します。項目名やスライドの位置を控えると、後で同じ枠を探しやすくなります。

3．前面の図形を隠す場合は戻し方を控える

Microsoftは、選択ウィンドウからオブジェクトの表示・非表示や順序変更を行えると案内しています。

Microsoftの案内のWeb 版の欄では、ウィンドウ内の項目はレイヤー順に一覧表示され、最上位の項目が最上位のレイヤーにあると説明されています。項目を上下にドラッグすると順序が変わり、Mac 版の欄の例では、一覧の下部にあったコネクタを一番上に移すと、2つの楕円の図形の前に表示されます。項目の右にある目の記号は、スライドでの表示と非表示に使います。Mac 版の欄では、非表示にしたオブジェクトはスライドに表示されず、非表示のアイコンをクリックすると再び表示されると説明されています。

一時的に表示を切り替える場合は、何を隠したかを記録してから操作します。選択だけで修正できるときは重なり順を変えません。一覧の項目をドラッグすると、それだけでスライド上の前後の重なりが変わるためです。別の図形が背景や余白を作っていることがあるため、表示を戻した状態で読めるかも確かめます。

4．配布用の表示に戻して点検する

編集後、非表示にしたものを目の記号で表示に戻し、スライド全体を開きます。変更した文字が切れていないか、背面や前面の図形の位置が動いていないかを確認します。配布する版と修正した箇所が対応するよう、ファイル名とページを記録します。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□修正するスライドを特定したか
□使っている版（Windows・Mac・Web）の開き方で選択ウィンドウを開いたか
□クリックで選べないときに、［オブジェクトの選択］か選択ウィンドウを使ったか
□一覧で文字枠を選んで位置を照合したか
□一覧の項目をドラッグして、意図せず重なり順を変えていないか
□選択と重なり順の変更を分けたか
□一時的に隠した図形の状態を戻したか
□配布用の表示で変更箇所を見たか
