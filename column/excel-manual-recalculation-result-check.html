Excelで入力値を変えても結果が変わらないとき、何を確かめる？

要点

入力を変えてもExcelの結果が動かないときは、まず結果のセルに数式があり、変えた入力のセルが参照先になっているか確かめます。式がある場合は、Windows版Excelの［数式］にある［計算オプション］を見て、手動なら再計算前後を比べます。自動へ戻す判断をする場合は、開いているほかのブックにも影響するので、変更前の設定と、作業後に戻す設定を確認します。

公開：2026年11月9日／情報の確認日：2026年11月7日（出典はこの記事の最後）

この記事は、Windows版Excelの入力を変えても結果が動かないときに、数式と参照、計算オプションの順に確かめる手順を整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 入力したセルと結果の数式を確かめる
  2. 手動計算かどうかを設定で確認する
  3. 再計算して前後の結果を比べる
  4. 他のブックへの影響と変更を引き継ぐ
  5. 計算方法の選択肢と、再計算のキーごとの範囲
  6. Web版で計算方法を変えたときの影響
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．入力したセルと結果の数式を確かめる

確認日：2026-11-07

対象はWindowsデスクトップ版のExcel for Microsoft 365です。Microsoftの日本語ヘルプでは、Excelは既定で変更されたセルに依存する数式を自動で再計算する一方、手動計算の設定も選べると説明しています。数式が計算されない場合の案内でも、自動計算が有効になっているかを確認するよう示し、手動計算が有効になっていると数式が計算されないと説明しています。

ここからは当社の整理です。

結果のセルを選び、数式バーで、数式が入っているか値が入っているかを確かめます。値だけのセルを再計算しても、元の数式に戻す操作にはなりません。数式がある場合も、変更したセルが参照先に含まれているか、別のシートの似た欄を見ていないかを確認します。参照の対応を確かめる前に数式を上書きすると、止まった原因を切り分けにくくなります。

2．手動計算かどうかを設定で確認する

［数式］タブの［計算オプション］を開き、選択中の項目を確認します。自動計算を使う運用に戻す場合は、公式ヘルプが案内する［自動］を選ぶ方法があります。同じヘルプは、デスクトップ版ではこれらの計算設定を変えると開いているすべてのブックに影響すると注意しています。

手動になっている理由が不明なら、変更する前に設定を控え、ブックを管理する人に確認します。変更する場合は、同時に開いているブックで計算の途中の作業がないかも確かめます。

3．再計算して前後の結果を比べる

公式ヘルプでは、［数式］タブの［今すぐ計算］を選ぶと、開いているすべてのワークシートを、データテーブルを含めて再計算する手順を案内しています。再計算の前に、照合したい入力値と結果、見ているシート名を控えます。再計算後は、同じ入力と同じ数式に対して結果がどう変わったかを比べます。

見る所残す項目次の作業
数式バー結果セル、数式の有無、変えた入力セル値だけなら、元の式があったか管理者へ確認する
参照先数式が参照するシート・セルと、入力した位置参照が異なる場合は、設定の変更より先に式の意図を確認する
計算オプション変更前の項目、ほかに開いているブック手動が意図した設定か確認し、必要なら再計算する
計算結果比較した入力と再計算の前後、残る差意図した入力に対応した結果か確かめる
作業後変更した計算設定、保存前の確認、引継ぎ先元に戻す設定か、今後も使う設定かを管理者とそろえる

4．他のブックへの影響と変更を引き継ぐ

まず、変わらない結果を一つ選び、結果セルと、直前に変えた入力セルを記録します。再計算後も結果が変わらない場合は、計算設定だけに原因を絞らず、数式が実際に参照するセルと、どの結果を期待したかを管理者に渡します。別ブックや外部データから値を更新する作業は、この計算設定とは分けて確認します。

5．計算方法の選択肢と、再計算のキーごとの範囲

Microsoftの再計算のヘルプのWindowsの欄では、［ファイル］タブ→［オプション］→［数式］の［計算オプション］セクションにある［ブックの計算］で計算方法を選べます。［自動］は、値、数式、または名前を変更するたびにすべての依存数式を再計算する既定の設定です。データ テーブルを除くすべての従属数式を再計算する選択肢もあり、Windowsの欄の日本語訳では［部分分画］、Webの欄では［データ テーブルを除く自動］と書かれています。［手動］では、F9 キーを押すなど手動で再計算するときにだけ数式が更新されます。同じ欄では、［手動］を選ぶと［保存する前にブックを再計算する］チェック ボックスが自動的に選択されると注記しています。

入力を変えても結果が変わらない所がデータ テーブルの中なら、［自動］ではなくデータ テーブルを除く設定になっていないかも確かめます。

同じヘルプでは、キーボードでの再計算の範囲を次のように分けています。

  • F9：作業中のブックの中で、最後に計算されたとき以降に変更された数式と、その数式を参照する数式を再計算します。ブックに自動再計算が設定されている場合は、F9 キーを押す必要はありません。
  • Shift + F9：作業中のワークシートの中で、最後に計算されたとき以降に変更された数式と、その数式を参照する数式を再計算します。
  • Ctrl + Alt + F9：開いているすべてのブックの数式を、最後に再計算されたとき以降に変更されたかどうかを問わず再計算します。
  • Ctrl + Shift + Alt + F9：依存する数式を確認し、開いているすべてのブックのすべての数式を再計算します。

また、［数式］タブの［計算］グループの［シートの計算］は、作業中のワークシートと、そのワークシートにリンクされているグラフおよびグラフ シートを再計算するボタンとして案内されています。どのキーやボタンで再計算したかで対象が変わるため、前後を比べるときは使った操作も控えます。

6．Web版で計算方法を変えたときの影響

Microsoftの再計算のヘルプのWebの欄では、Excel for the web でブックの計算オプションを変更すると、現在のブックにのみ影響し、ブラウザーで開いている他のブックには影響しないとしています。同じ欄では、［数式］タブの［計算オプション］に［自動］［データ テーブルを除く自動］［手動］があり、ブック（データ テーブルを含む）を手動で再計算するには［ブックの計算］を選ぶと案内しています。デスクトップ版では開いているすべてのブックに影響するため、作業後に設定を戻すときは、どちらの版で変えたかも記録に残します。
