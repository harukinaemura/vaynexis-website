クラシックOutlookの「添付ファイルとして転送」でメールを渡すには

要点

クラシック Outlook では、メッセージの一覧からメールを選び、メイン リボンで［その他の対応アクション］>［添付ファイルとして転送］を選ぶと、そのメールを添付した新しいメッセージが作れます。 複数のメールをまとめて渡したいときは、Ctrl キーを押しながらメールを選んでから［転送］を選ぶと、ほかのメッセージを添付ファイルとして含めた新しいメッセージになります。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

後任に取引先とのやり取りを渡したいが、本文に引用した転送では元のメールの形が崩れてしまう。クラシック Outlook でメールそのものを添付して送る操作と、何通もまとめる方法、送る前に中身を確かめる点を順に見ていきます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

使い分けの見本の表は架空の場面です。転送の選び方や確認表は当社がまとめた考え方で、Microsoft のヘルプに書かれた手順ではありません。

1．本文に引用する転送と、メールごと渡す転送

確認日：2026年11月17日。

対象は、Windows のパソコンで使うクラシック Outlook（Outlook for Microsoft 365 などの、［ファイル］タブがある Outlook）です。根拠にしたヘルプは「従来の Outlook でメール メッセージに返信または転送する」という題で、新しい Outlook や Web 版の手順は含まれていません。

ふだんの［転送］は、宛先や CC に入っていない人にメッセージを送るときに使う操作です。 ［転送］では新しい受信者を入れられ、元のメッセージに付いていた添付ファイルは、転送するときに自動的に含まれます。 本文は新しいメッセージの下に引用される形になるため、受け取った人は、自分あての文と元のメールを1つの画面で読めます。

一方、［添付ファイルとして転送］は、受け取ったメールを1つの添付ファイルにして送る操作です。受け取った人は、添付を開いて元のメールを1通のメールとして見ることになります。引用の形にすると、転送する人が本文に手を入れられてしまう、元のメールの差出人や日時が引用の見出しにまぎれて分かりにくい、という心配があるときに、元の形のまま渡せるのがこの操作の使いどころです。

どちらがよいかは、受け取る人が何をするかで決めます。内容を読んで返事をするだけなら、ふだんの転送のほうが読みやすいでしょう。受け取った人が、そのメールを自分の受信トレイの1通として保管したり、記録として残したりするなら、添付ファイルとして渡すほうが向いています。

2．1通を添付ファイルとして転送する

順番操作
1メッセージの一覧からメールを選ぶ
2メイン リボンで［その他の対応アクション］>［添付ファイルとして転送］を選ぶ
3宛先、CC、BCC に渡す相手を入れる
4本文に、何のために渡すのかを書く
5［送信］を選ぶ

ヘルプには、返信や転送のボタンは画面の解像度と Outlook のバージョンによって、いくつかの異なる場所にあると書かれています。 画面の幅によってリボンの見え方が変わることもあるため、見つからないときは Outlook の画面を広げてから探します。

3．複数のメールを1通にまとめて渡す

前任者から後任へ、取引先との一連のやり取りを渡すときなど、メールを何通もまとめて送りたい場面があります。ヘルプでは、最初のメッセージを選び、Ctrl キーを押しながら追加のメッセージを選ぶ、と案内しています。 すべて選んだらメイン リボンで［転送］を選ぶと、選んだメッセージを添付ファイルとして含めた新しいメッセージが作られます。

まとめて送るときは、選び忘れと選びすぎの両方に気をつけます。同じ件名のメールが並んでいても、途中で別の担当者が加わった返信や、社内だけで話したメールが混じっていることがあります。渡す前に、添付された件名と日付を本文に箇条書きで書いておくと、受け取った人も抜けがないかを確かめやすくなります。

4．書きかけのメールに、後からメールを足す

新しいメッセージを書いている途中で、関係するメールを添付したくなったときは、別の方法があります。クラシック Outlook では、新しいメッセージで［ファイルの添付］>［アイテムの添付］を選びます。 いずれかのメール フォルダーから1つ以上のメール メッセージを選び、添付するアイテムを選んでから［挿入］を選びます。 一覧から転送を始めるか、作成中のメールに足すかの違いで、どちらもメールを添付して渡す点は同じです。

5．返信では添付が付かないことも覚えておく

メールを渡す方法を考えるときに混同しやすいのが、返信です。ヘルプでは、［返信］と［全員に返信］では添付ファイルは含まれないと説明されています。 添付ファイル付きのメッセージをほかの人に送る必要がある場合は、［転送］を使うよう案内されています。 資料ごと別の人に渡したいのに返信の画面から宛先を足すと、資料が付かないまま届くので、渡すときは転送か、添付ファイルとして転送のどちらかを選びます。

転送の画面が閲覧ウィンドウの中に開いて狭いときは、［ポップアウト］ボタンで新しいウィンドウに開けます。 毎回新しいウィンドウで開きたい場合は、［ファイル］>［オプション］の［メール］で［返信と転送を新しいウィンドウに開く］チェック ボックスをオンにします。 渡す相手への説明を本文にしっかり書くときは、広い画面のほうが書きやすくなります。

6．送る前に見ること

添付ファイルとして転送したメールの中には、元のメールに付いていた資料や、途中のやり取りがそのまま入っています。受け取った人は添付を開けば中身をすべて読めるので、ふだんの転送以上に「その相手に見せてよい中身か」を確かめます。特に、社外の人に渡す場合は、社内の担当者どうしのやり取りや、ほかの取引先の情報が混じっていないかを開いて見ておきます。

また、ファイルの種類によっては送受信がブロックされることがあります。 元のメールに付いていた添付がどのように扱われるかは、受け取った相手の環境にもよります。大事な資料なら、届いたかどうかを相手に一言確かめます。

7．使い分けの見本（架空の例）

場面（架空の例）選んだ方法理由
取引先の問い合わせを営業担当に回すふだんの［転送］返事を書くのは営業担当で、本文を読めれば足りる
退職する担当者が、後任に1件分のやり取りを渡す複数を選んで［転送］何通もの経緯を、元の形のまま1通で渡せる
社内の情報担当に、気になるメールを見てもらう［添付ファイルとして転送］転送する人が本文に手を入れずに渡せる

メールの渡し方は、人によってやり方が違うと、後から探す人が困ります。どの場面でどの渡し方をするかを短い手順にまとめておくときは、マニュアル・手順書づくりの考え方も参考になります。
