消費税の申告後に誤りが見つかったら？相談前にそろえる資料と記録

要点

当初提出した申告書の控え、提出日が分かる記録、誤りに気付いた根拠資料をそろえます。対象期間と該当箇所を対応させ、確認できた事実と疑問を分けて相談先へ渡すのが準備の中心です。手続きの選択や税額の訂正は専門家に確認します。

公開：2026年11月4日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、消費税の申告後に誤りが見つかった小さな会社の経理担当者が、提出済みの控えと根拠資料をそろえ、専門家や税務署に相談する準備を整理するためのものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。制度や規約の内容は出典の公式ページで確かめ、個別の判断は専門家に確認してください。

  1. 提出した日と、誤りに気付いた日を分けて残す
  2. 公式資料で確認するのは、期限と根拠書類
  3. 当初の控えと、誤りを示す資料を対にする
  4. 発見から相談後まで、担当と引き継ぐものを決める
  5. 書類を見てもらう相談は、持参資料も確認する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．提出した日と、誤りに気付いた日を分けて残す

確認日：2026年11月4日（日本時間）

国税庁「申告と納税」は、税額を多く申告していたときの手続きを「更正の請求」、少なく申告していたときの手続きを「修正申告」と案内しています。また、「申告が間違っていた場合」では、確定申告期限内に誤りに気付いた場合は、改めて申告書等を作成して期限までに提出する扱いが示されています。これらは、相談前に手続きの違いを把握するための資料です。自社でどの扱いになるかは専門家に確認します。

資料整理では、提出した日と発見した日を別の欄に残すとよいです。社内で確認した日や、作成担当者へ渡した日を、提出した日と混同しないようにします。控えの表題だけで提出済みと考えず、提出を担当した人にも照合する進め方です。

相談の入口では、「何の書類を出したか」「いつ出したか」「どの箇所に疑問があるか」を説明できる状態を目指します。誤りが確定した箇所と、まだ調べている箇所も分けておくと、相談相手に見てほしい範囲が伝わります。

2．公式資料で確認するのは、期限と根拠書類

法人用の「消費税及び地方消費税の更正の請求手続」は、提出時期を法定申告期限から5年以内とし、後発的理由などによる請求は、それらの事実が発生した日の翌日から2か月以内と案内しています。期限の起算点や自社への適用は専門家に確認します。

同じ法人用の案内では、更正の請求の理由となった事実を証明する書類の添付が求められています。個人事業者用の案内でも、請求の理由となった事実を証明する書類の提出が求められています。この点を、口頭で誤りを説明するだけでなく、根拠となる資料を探す理由として押さえます。

「申告と納税」では、修正申告によって納付すべき新たな税額は、修正申告書を提出する日までに延滞税と併せて納付するよう案内されています。提出を予定する日と支払いの準備を相談し、納付額や附帯する税の扱いは専門家に確認します。

期限の説明を読んだ段階で、担当者だけで締切や税額を確定することは避けます。相談時には対象期間と提出の記録を示し、確認された期限、確認先、根拠にした資料を社内の予定に残すとよいです。

3．当初の控えと、誤りを示す資料を対にする

相談用に集める資料は、当初の状態を示すものと、疑問の根拠を示すものに分けます。当初の控えには、提出した書類と一緒に、その作成に使った集計表や計算の資料を添えます。後から計算し直した資料には、相談前の検討用であることが分かる名前を付けると、提出済みの版との取り違えを防ぎやすくなります。

誤りの根拠として探す候補は、関係する帳簿の記録、請求書、領収書、取引の内容を確かめられるやり取りなどです。ここで挙げるものは社内で探す候補であり、提出が必要な書類の指定ではありません。どの資料が必要かは相談先へ確かめます。

資料には、相談で取り上げる箇所の目印を付けます。帳簿のどの記録を見て疑問が生じ、当初の集計表のどこに対応するのか、参照先を残す方法です。関連がまだ分からない箇所は、推測で結び付けず、調べている状態であることを記録します。

見つかった内容は、「書類に記載されている事実」「当初の処理との相違」「専門家に聞きたいこと」に分けるとよいです。原因についての推測を事実と混ぜず、元資料の記載をたどれる形にします。金額を記す際も、提出した書類の額と、見直し中の額が区別できる欄に置きます。

元のファイルや控えを直接書き換える前に、当初の状態が分かるものを取り分けます。相談用の写しに目印を付け、保存場所と更新した人を記録する進め方です。資料が見つからないときは、所在を知りそうな担当者と、確認中の内容を残します。

4．発見から相談後まで、担当と引き継ぐものを決める

役割を分けておくと、資料を集める作業と内容を判断する作業の境目が分かります。下表は社内で分担を決める際の整理案です。兼任する場合も、確認した内容を記録して引き継ぎます。

段階担当する役割用意・記録するもの引き継ぐ相手
誤りの発見時発見した人発見日、疑問の箇所、根拠資料の所在経理の担当者
相談の連絡前経理の担当者当初の控え、提出の記録、該当箇所の対応相談の窓口となる人
相談日の調整時相談の窓口となる人確認したいこと、案内された持参資料、不足資料資料を準備する人
相談後回答を受けた人回答日、回答者、内容、追加の依頼事項作業を進める担当者
対応後完了を確かめる人実施した内容、その根拠、残った作業社内の確認者

資料の収集に時間がかかる部分は、その状況も相談相手へ伝えます。そろっていない資料を隠して説明を完成させるより、現時点で示せる事実と不足を分ける方が、追加で探すものを相談しやすくなります。

相談を終えたら、聞いた内容をそのまま作業済みとして扱わず、これから行うことと実施済みのことを分けます。追加資料を渡した相手や、回答を待っている事項も残します。引き継いだ人が、どこから続きを始めればよいか分かる形にするためです。

5．書類を見てもらう相談は、持参資料も確認する

法人用の更正の請求手続では、提出先は納税地を所轄する税務署とされています。提出先を確認する根拠として、この手続案内を参照します。

国税庁「国税に関するご相談について」では、具体的な書類や事実関係の確認が必要な場合など、電話相談センター等で解決が困難な相談は、所轄の税務署で面接相談を受け付けています。面接相談は、持参書類の案内や相談時間の確保のため、電話で事前に相談日時等を予約する方式です。この案内は、書類を見てもらう相談の準備に使います。

相談の連絡では、提出済みの内容に誤りが見つかったことと、手元にある資料を簡潔に伝えます。持参するものに加え、不足する資料を後から渡せるか、どの箇所を整理しておくかも確かめるとよいです。適用する手続きや税額の訂正、追加で負担する税の判断は、根拠資料を示して専門家に確認します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□当初提出した書類の控えと、作成途中の資料を区別したか
□提出日と発見日を、それぞれの根拠とともに記録したか
□対象期間と、誤りが疑われる箇所を特定したか
□当初の記載と相違する資料の該当箇所・保存先を示したか
□確認できた事実、推測、専門家に聞くことを分けたか
□相談先に必要資料と期限を確認し、不足資料の担当を決めたか
□相談の回答、対応済みの内容、残った作業を記録したか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
