Excelの長い一覧で見出し行と管理番号列を同時に固定する方法

要点

見出し行と管理番号列を同時に残すには、選択セルの上の行と左側の列を残す［ウィンドウ枠の固定］を使い、残したい範囲に合わせて選択位置を決め、縦横に動かして表示を確かめます。

公開：2026年11月4日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelの長い一覧を縦横にスクロールしながら照合する小さな会社の事務担当者が、見出し行と管理番号の列を同時に固定する手順と確かめ方を整理するためのものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 残す行の下と列の右が交わるセルから始めます
  2. 管理番号を左端に置いた一覧で位置を考えます
  3. 範囲が違ったら解除し、選択位置を見直します
  4. 縦と横に動かし、明細との対応を確かめます
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．残す行の下と列の右が交わるセルから始めます

確認日：2026年11月4日。

公式ヘルプの適用先は、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 です。

操作に入る前に、縦に移動しても読みたい項目名と、横に移動しても照合に使いたい列を決めておきます。残す範囲の下端と右端を目で追っておくと、選択位置を整理しやすくなります。

  1. 残したい行のすぐ下と、残したい列のすぐ右が交わるセルを選択します。
  2. ［表示］→［ウィンドウ枠の固定］→［ウィンドウ枠の固定］の順に選びます。

選ぶ場所を「見出しのセル」「管理番号が入ったセル」とだけ覚えるより、残したい範囲との位置関係で捉えるとよいです。引き継ぎ用の説明も、残す行と列を先に示してから操作を書く形にします。

2．管理番号を左端に置いた一覧で位置を考えます

備品を確認する一覧を例に、項目名が並ぶ行を先頭、管理番号を左端に置く想定です。次の表では、管理番号、品名、確認状態の配置を示しています。

管理番号品名確認状態
仮番号ア保管箱確認済み
仮番号イ書類ケース確認待ち

この一覧で残したいのは、上にある項目名と、左にある管理番号です。下の明細を読むときの手がかりは項目名、右の項目と照合するときの手がかりは管理番号、と分けて考えます。

表を広げる前に、読みたい明細と照合の目印を整理しておくとよいです。ここで示した備品名や確認状態は、配置を説明するためのものです。

3．範囲が違ったら解除し、選択位置を見直します

この配置例に公式の選択ルールを当てはめると、選ぶのは「品名」の直下にある明細セルです。

見出しの上に表題がある配置では、選択セルより上にある表題の行も固定対象になります。

固定範囲をやり直す際は、［表示］→［ウィンドウ枠の固定］→［ウィンドウ枠の固定解除］の順に選んで解除します。

やり直しの前には、想定していた見出しや目印と、実際に画面に残っている範囲を見比べます。余分な部分まで残したのか、必要な部分が抜けたのかを分けてから、選択位置を決め直すとよいです。

編集を制限する操作とは目的を分けます

［シートの保護］は、ロックされたセルの変更を防ぐための機能です。

画面で見出しを読み続けることと、入力できる場所を制限することは、作業の目的を分けて整理します。この記事では、長い一覧を画面で読むための表示の調整を扱います。

4．縦と横に動かし、明細との対応を確かめます

完了の判断は、メニューを選べたかだけでなく、読むときに必要な手がかりが残っているかで行います。まず下の明細へ移動し、項目名を読めるかを確かめます。次に右へ移動し、管理番号と見ている明細の対応をたどります。

途中で視線を外しても、どの項目と明細を照合しているかを読み直せるかが確認の中心です。先頭付近を眺めるだけで終えず、普段読み進める位置まで動かして確かめるとよいです。

引き継ぎには、残す項目名、目印にする列、選択位置の考え方、やり直す操作を短く記します。「見やすくした」とだけ書くより、受け取った人が同じ意図で確認できる説明になります。

公開・共有の前に、この表で確かめます。
