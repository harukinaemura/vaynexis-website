ExcelのPower Queryを複製して元の処理を残し試し直すには

要点

元の処理を残して試し直すには、対象のクエリを［複製］してからコピー側を編集します。試験用には用途が分かる名前を付け、変更前後の行や列を見比べます。元の処理とのつながりも先に区別し、採用するまで業務用の処理を残す進め方です。

公開：2026年11月6日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、Excelの取込後の加工方法を変えて比べたい小さな会社の事務担当者が、元のクエリを残したまま複製で試し直す流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 複製と参照は、変更の伝わり方で使い分ける
  2. 対象を開いて、試験用のコピーに名前を付ける
  3. 処理途中の結果を見て、変える場所を絞る
  4. 比較の目的は、小さな表にして残す
  5. 更新後の表まで比べて、採用する処理を決める
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．複製と参照は、変更の伝わり方で使い分ける

確認日：2026年11月6日。

ここで扱うのはWindows版の操作で、Microsoft サポートの「クエリの管理 (Power Query)」のページの適用先はExcel for Microsoft 365・Excel 2024・Excel 2021です。

［複製］で作ったクエリには、元のクエリに後から加えた変更は影響しません。［参照］は元のクエリの手順を使う新しいクエリを作り、元の変更も参照先へ伝わります。

比較の基準にする処理と、変更を試す処理を先に分けておくと、結果の違いを説明しやすくなります。元の状態との比較を目的にする場面では、コピーを作ってから変更する流れにします。共通の加工結果から別の用途へ処理を続けたい場面とは、作業の目的を分けて考えるとよいです。

2．対象を開いて、試験用のコピーに名前を付ける

まず、業務で使っている表と、その表を作る処理の対応を確かめます。似た名前が並んでいる場合は、担当者の引き継ぎ記録とも照合し、変更したい対象を取り違えないようにします。

［データ］から［クエリ & 接続］を開き、［クエリ］タブで対象を右クリックして［編集］を選びます。エディターの［クエリ］ウィンドウで元のクエリを右クリックし、［複製］を選びます。

作成されたコピーは、右クリックメニューの［名前の変更］で名前を変えられます。名前は比較用・試験用だけで終えず、どこを変える予定かが伝わるものにします。元の名前も作業記録に残しておくと、比較の相手が分からなくなるのを防げます。

編集を始める前に、選んでいる対象の名前を見直します。コピーを作った後も元の対象を選んだまま作業していないか、変更予定の内容と一緒に確かめる区切りを置きます。

3．処理途中の結果を見て、変える場所を絞る

［適用されたステップ］で任意のステップを選ぶと、その段階の結果が表示されます。最終結果だけを見るのではなく、変更予定の箇所の前後を見比べる使い方です。必要な列が残っているか、除外したい行と残したい行の扱いが合っているかを確かめます。

ステップを右クリックして開くメニューでは、［設定の編集］から個別の設定を変更できますが、変更できる設定のないステップもあります。不要になったステップは、右クリックメニューの削除操作で取り除けます。

先に、試したい変更と、その結果としてどうなればよいかを言葉にしておきます。例えば、確認用の表から不要な項目を除きたいのか、表示する対象を絞りたいのかでは、比較する箇所が異なります。狙いを決めてから変更し、その都度結果を見れば、どの操作で差が出たかをたどれます。

途中の結果が意図に合っていても、最後まで同じ見方で確認します。後に続く加工に必要な項目まで取り除いていないか、変更した部分と、その後の結果を対応させて見るとよいです。

4．比較の目的は、小さな表にして残す

ここからは当社の整理です。

会議で確認する一覧から、配布用には不要な担当メモを外したい場面を考えます。試す前の整理例は次のとおりです。

残しておく対象試す内容比較するところ
業務で使っている一覧加工前後の比較基準として残す見出しと対象行を控える
配布項目を見直すための試験用担当メモを外した見え方を試す配布に必要な項目が残っているかを見る
採用を判断するための記録変更理由と確認結果を残す元の状態との違いを説明できるかを見る

表の役割は、正しい結果を先に決め付けることではなく、何を比べるつもりだったかを残すことです。表示をすっきりさせる変更でも、確認に必要な項目を外していないかは別に見ます。

業務用として採用するかどうかは、使う担当者と結果を照合してから決めます。試験中のものと配布に使うものの区別も共有し、名前だけを頼りに採用済みと判断しない進め方にします。

5．更新後の表まで比べて、採用する処理を決める

Microsoft サポートの「Excel の Power Query について」では、クエリを更新すると各ステップが自動的に実行されると説明されています。処理を残すことと、比較に使った時点の値を控えておくことは、作業記録で分けて扱います。違う時点で結果を見た場合は、加工方法の差か、比較対象の変化かを判断するため、対象期間や元にした表も照合します。

同じく公式ヘルプでは、［クエリ & 接続］の［クエリ］タブでクエリを右クリックし、［読み込み先］を選ぶと［データのインポート］ダイアログ ボックスが表示されると案内されています。比較用の表を読み込むときは、この操作で試験用のクエリを選びます。読み込む場所は比較用と業務用を区別できるように決め、試験中の結果を配布用と取り違えない運用にします。

照合では、必要な見出し、残す対象、除く対象、行の抜けや重複を見ます。合計が合っただけで終えず、変更の影響を受ける行や項目をたどり、意図した違いだけになっているかを確かめます。

引き継ぎには、元の対象、試した対象、変更箇所、照合に使った表、採用を判断した理由を残すとよいです。確認を待つ箇所は完了した範囲と分け、別の担当者が続きを進められる状態にします。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□元の処理と試験用の対象を区別したか
□元の変更を引き継ぐ必要があるか、比較の目的に照らして整理したか
□編集を始める前に、選んだ対象の名前を確認したか
□変える箇所と期待する結果を記録したか
□変更箇所の前後と、最後の結果を照合したか
□比較用の表と業務用の表の置き場を区別したか
□採用した範囲と確認を待つ範囲を分けて記録したか
