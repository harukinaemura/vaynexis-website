Wordの文書中の表記を一件ずつ検索・置換するには？

要点

［ホーム］タブの［編集］から置換を開き、［検索する文字列］に直したい語句、［置換後の文字列］に新しい語句を入れます。 一件ずつ確かめるときは［すべて置換］を使わず、次の候補へ進みながら、直してよい所でだけ［置換］を選びます。 置き換えを間違えた所は、Ctrl+Z で元に戻せます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

社名や用語を新しい表記にそろえたいのに、［すべて置換］を押すと、残すべき古い名前や引用まで変わってしまいそうで手が止まる。一件ずつ前後を読んで直す置換の進め方と、似た語句を巻き込まない検索オプション、間違えたときの戻し方を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

直す前に決めておく表や確認表、探す範囲の絞り方といった進め方は、架空の文書を想定して当社が整理したもので、Microsoft のヘルプにある手順ではありません。

1．まとめて置き換えると困る表記

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Word（Microsoft 365・Word 2024 など）です。ヘルプの適用先には、Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016 が並んでいます。 ブラウザーで開く Web 版の違いは、後の節で分けて書きます。

社名が変わったので「旧社名」を「新社名」にそろえたい、という場面でも、文書の中には「旧社名から変更しました」のように、古い名前のまま残すべき文が混じっていることがあります。引用した契約書の名前、過去の日付の記録、他社の名前の一部に同じ文字が入っている場合も同じです。どの表記にそろえるかを先に決めてから、一件ずつ見て直すと、直しすぎを防げます。

2．一件ずつ置き換える手順

順番操作
1［ホーム］タブの［編集］から置換を開く
2［検索する文字列］に、直したい語句を入れる
3［置換後の文字列］に、新しい語句を入れる
4次の候補へ進み、文書の中で前後の文を読む
5直してよい所なら［置換］、残す所なら置換せずに次の候補へ進む

ヘルプでは、すべて変える場合は［すべて置換］、そうでない場合は更新したい語句が見つかるまで次へ進み、見つかったら［置換］を選ぶ、と2つの使い方が並べて書かれています。

この Windows のタブは、ほかのオプションを「テキストを置換する」のページに任せています。 そのページ「テキストの置換」では、更新したい箇所に着くまで［次を検索］を選ぶ、と書かれています。 同じページは［すべて置換］を、一件ごとに止まらずにすべての箇所を更新する操作として説明しています。 ヘルプの Mac のタブには、［すべて置換］ではなく［置換］を選ぶよう勧めるヒントがあり、置換する前に各項目を確認できるから、と理由が添えられています。

3．英字の大文字・小文字を区別したいとき

英字の略称など、大文字か小文字かで意味が変わる語句は、置換の画面の［More］から［Match case］を選ぶと区別して探せます。 このメニューには、ほかにもいくつかの探し方があります。

4．似た語句を巻き込まないための検索オプション

「テキストの置換」のヘルプには、探し方を絞るオプションが並んでいます。表記をそろえる作業で関わりそうなものを挙げます。

  • 探す範囲：文書全体にするか、カーソルの位置から上か下かを指定します。 後半の新しい章だけを直したいときは、直し始める所にカーソルを置いてから探すと、前半の章に触れずに済みます。
  • 大文字と小文字の一致：特定の大文字と小文字に一致する単語だけを探して置換します。 前の節の［Match case］と同じ働きと読めますが、画面の名前は手元で確かめます。
  • 単語全体のみを検索する：部分一致を避けるための設定です。 ヘルプの例は英単語で、ある単語を置き換えても、別の単語の一部までは変わらないようにする使い方です。
  • 句読点文字を無視する：ハイフネーションの違いを無視します。
  • 空白文字を無視する：文字と文字の間の間隔を無視します。 社名の途中に空白がある所とない所が混じる文書で候補になりますが、全角の空白に効くかは試しの文書で確かめます。
  • ワイルドカードを使用する：部分一致を取得する設定です。 当てはまる範囲が広がるので、一件ずつ直す作業では、まず使わずに始めるほうが直しすぎを防ぎやすくなります。

英語だけを対象に、発音の似た単語や、動詞のすべての時制を探して置き換える設定もあります。

5．太字や蛍光ペンの付いた所だけを探す

「蛍光ペンを付けた所が直すべき所」という決め方をしている場合、ヘルプの Mac のタブには、［検索と置換］ダイアログ ボックスの下の矢印を開き、［書式］メニューから書式を選んで探す方法が書かれています。 Windows 版で同じ画面かは、手元で確かめます。

「テキストの置換」のヘルプにも、［書式］ボタンで、フォントの種類や色、段落の書式設定（左・右・中央）、強調表示された単語などを探して置換できる、と書かれています。 書式を指定して探したあとは、［書式設定なし］で書式の選択をオフにします。 蛍光ペンの所を直し終えたら、ここで書式の条件を外してから次の語句に移ります。

タブやセクション区切りの入れ方をそろえたいときは、［特別］ボタンで、Em ダッシュ、タブ、セクション区切りなどの要素を探して置き換えられます。

6．Web 版の Word で直すとき

ブラウザーで開く Web 版の Word でも、基本的なテキストを見つけて置き換えることができます。 大文字と小文字の区別や、単語全体の検索も使えます。 ほかのオプションを使うには、デスクトップ版の Word で文書を開くよう案内されています。 書式で探す方法などが Web 版で見当たらないときは、デスクトップ版で開き直します。

7．置き換えを間違えたときに戻す

一件ずつ進めていても、残すはずの所で［置換］を選んでしまうことはあります。Windows 版では、Ctrl+Z を押すか、クイック アクセス ツール バーの［元に戻す］を選ぶと操作を元に戻せます。 複数の手順を戻すときは、Ctrl+Z を繰り返し押します。 ［元に戻す］の横の矢印を選ぶと、戻す操作を一覧から選んで、まとめて戻すこともできます。 戻しすぎたときは、Ctrl+Y か F4 でやり直せます。

既定では、最近行った 100 回の取り消し可能な操作が保存され、その範囲なら保存した後でも元に戻して、もう一度保存できます。 ただし、［ファイル］タブでのコマンドの選択やファイルの保存など、元に戻せない操作もあり、そのときは［元に戻す］が［元に戻せません］に変わります。 それでも戻せない変更は、以前のバージョンのファイルを復元できることがあります。 長い規程を直し始める前に、元のファイルを別の名前で残しておくと、直した後に見比べる相手にもなります。

8．直す前に決めておく表（架空の例）

今の表記そろえる表記残す場合
申込み書申込書様式の正式名に「申込み書」とある所
旧社名新社名社名変更のお知らせ、過去の契約の名前
お客様／お客さまお客様引用した他社の文章

表記をそろえる作業は、手順書が増えるほど手間がかかります。手順書の用語を最初からそろえて作るやり方は、AIで業務マニュアル・手順書を作る方法でも整理しています。

9．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□そろえる表記と、残す場合を先に決めたか
□［検索する文字列］と［置換後の文字列］を入れ間違えていないか
□［すべて置換］ではなく、一件ずつ前後の文を読んで［置換］を選んだか
□直す範囲に合わせて、探す範囲を文書全体・カーソルの上・下から選んだか
□英字の略称は［Match case］で大文字・小文字を区別したか
□英単語の一部まで変わらないよう、［単語全体のみを検索する］を考えたか
□書式で探したあと、［書式設定なし］で書式の選択を外したか
□間違えた置換は Ctrl+Z で戻せること、戻せない操作もあることを知っているか
□直し終えたら、もう一度［検索する文字列］で探して取り残しを見たか
