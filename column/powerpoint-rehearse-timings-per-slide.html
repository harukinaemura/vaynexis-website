PowerPointで社内説明会のスライド別の所要時間を測るには

要点

PowerPointの［リハーサルのタイミング］を開始し、説明にかかる時間を測ります。終了後はスライド一覧表示で各スライドの時間を確認できます。長かった理由を見分け、本番の進行方法まで確かめるとよいです。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、社内説明会の練習でスライドごとの所要時間を測りたい小さな会社の担当者が、PowerPoint のリハーサルのタイミングの使い方と結果の見方、本番前に手動の進行へ戻す設定を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 計測を始める前に、説明の範囲をそろえる
  2. 説明しながら、現在の時間と全体の時間を読む
  3. 終了時に結果を保持し、各スライドを見比べる
  4. 長かった理由を、引き継ぎのメモに残す
  5. 本番前に、手動で進める設定へ戻す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．計測を始める前に、説明の範囲をそろえる

確認日：2026年11月10日

Microsoft のヘルプ（自動プレゼンテーションを作成する）の適用先は、PowerPoint for Microsoft 365・2024・2021・2019・2016 と、Microsoft 365・2024・2021 の Mac 版です。この記事の操作は、そのヘルプの Windows のタブの手順に沿って説明します。

練習前には、説明会で使う資料と、当日説明する内容をそろえます。資料を探す時間や、説明担当者どうしの相談が混ざると、内容そのものに必要な時間を読み取りにくくなります。途中で別の資料を見せる予定があるなら、その操作を含めて測るかも先に決めておくとよいです。

［リハーサルのタイミング］を選ぶとタイマーがすぐに始まるため、話し始める準備ができてから実行します。

2．説明しながら、現在の時間と全体の時間を読む

開始して、説明が終わったところで進める

［スライド ショー］から［リハーサルのタイミング］を選んで計測を始めます。次のスライドへは、［次へ］、マウスのクリック、右方向キーで移動できます。

練習では、画面を眺めて終えるよりも、当日伝える内容を実際に声に出して進めるとよいです。図を指して説明する箇所や、参加者に資料を見てもらう間も、当日の進め方に合わせます。

現在のスライドの時間は一時停止アイコンの右側に、そのさらに右側にはプレゼンテーション全体の時間が表示されます。

中断と説明のやり直しを区別する

時間の記録を一時的に止めるには、［一時停止］を選びます。再開のボタンは、自動プレゼンテーションのヘルプの Windows のタブでは［一時停止］をもう一度選ぶと書かれ、リハーサルのヘルプでは［記録の再開］を選ぶと書かれています。ヘルプによって書き方が違うので、画面に出ている名前で選びます。現在のスライドの時間を測り直すには、［繰り返し］を選びます。

外からの呼び出しで中断した場面と、説明内容を直して話し直した場面は、メモでも分けます。後から長かった箇所を探すときに、内容を短くする対象なのか、測り直す対象なのかを判断する手がかりになります。

途中で練習を終了する場合は、Escキーで記録を停止し、プレゼンテーションを終了することもできます。

3．終了時に結果を保持し、各スライドを見比べる

最後のスライドのタイミングを設定すると、全体の所要時間を示すメッセージボックスが表示されます。計測結果を保持するときは、終了時に［はい］を選びます。記録した切り替えのタイミングを破棄するときは、［いいえ］を選びます。

［表示］から［スライド 並べ替えツール］を選ぶと、各スライドの右下に割り当てられた時間が表示されます。

結果を見る際は、話した内容と各スライドの見出しを対応させます。長い箇所でも、説明会の中心となる内容なら必要な時間かもしれません。逆に、短い箇所でも、読み手が理解する前に進めていなかったかを振り返る余地があります。合計を縮めることだけを目的にせず、残す説明と整理する説明を分けるとよいです。

測った長さと進行予定を分けて記録する

リハーサル中には、［リハーサル］ツール バーの［スライド表示時間］ボックスに時間の長さを入力して、そのスライドを表示する時間を指定することもできます。メモには、実際に説明して測った時間か、予定として指定した長さかを分けて残すとよいです。練習後に長さを調整したなら、その理由も合わせて記録します。

4．長かった理由を、引き継ぎのメモに残す

ここからは当社の整理です。

担当者へ渡すときは、時間とともに「何が起きたか」を残します。長かった理由が資料の探し直しなら、説明を削る前に準備を整えて再計測できます。用語の補足が必要だったなら、その補足を残すか、資料の表現を直すかを検討する流れです。

説明の箇所練習で気づいたこと次に確かめること
変更点の説明同じ内容を言い直した重複を整理して通して説明する
手順の案内別の資料を探して中断した資料を開いた状態で測り直す
質問を受ける場面参加者の反応を待つ必要がある待つ時間を進行予定に含める

計測時に質問を受けなかったなら、説明会全体の予定には質疑の余裕を別に考えておきます。担当者交代の挨拶や、配布資料をそろえる時間も同じ扱いです。練習に含めた作業と含めなかった作業が分かると、計測結果を開催時間へ当てはめやすくなります。

資料を修正した後は、古い結果と混同しないよう、どの資料を使って測ったかをメモに残します。説明の順番や担当が変わったときは、影響する範囲を通して確かめるとよいです。説明担当者が交代する箇所では、誰が次の資料を開き、どこから説明を再開するかもそろえます。担当部分だけを個別に測った場合は、交代を含めて通したときの流れも確認するとよいです。

5．本番前に、手動で進める設定へ戻す

Microsoft のリハーサルのヘルプでは、プレゼンテーションを行う前に、記録したスライドのタイミングをオフにするよう案内しています。同じヘルプによると、スライドが自動的に進まないようにするには、［スライド ショー］タブで［スライド ショーのセットアップ］を選び、［表示のセットアップ］ダイアログ ボックスの［スライドの事前設定］で［手動］を選びます。タイミングをもう一度使うときは、［タイミングの使用］（ある場合）に戻すとしています。

参加者の質問に答えたり、説明の途中で資料を指したりする進行では、当日の発表者が切り替えのタイミングを決められる状態に整えます。計測結果の確認までで準備を終えず、本番で使う資料を開いて、話し終わる前に画面が進まないかを確認するとよいです。

引き継ぎの際も、練習に使った資料と本番で開く資料を取り違えていないか、実際の開始から切り替えまでを発表者と確かめます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□当日説明する内容と資料をそろえて計測したか
□現在のスライドの時間と、全体の時間を区別して読んだか
□中断した箇所と、説明をやり直した箇所をメモに残したか
□終了時に計測結果を保持する操作を選んだか
□長かった箇所を見出しと照合し、見直す理由を整理したか
□質疑や担当者交代など、練習に含めなかった時間を考慮したか
□本番で使う資料が、発表者の操作で進む状態かを確かめたか
