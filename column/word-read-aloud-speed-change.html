Wordの音声読み上げで読む速さを変えるには

要点

［校閲］タブで［読み上げる］を選び、読み上げのコントロールの右上の歯車アイコンを開いて、読み上げ速度スライダーで速さを変えます。 読み上げ中なら、Alt キーと矢印キーでも速さを上げ下げできます。 Web 版の Word では、イマーシブ リーダーの［音声設定］にある［音声の速度］で変えます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

作った見積書や案内文を Word に読み上げさせて耳で確かめたいのに、速すぎて数字を聞き逃したり、遅くて長い文書がなかなか終わらなかったりする。歯車アイコンの速さのスライダーとキーボードでの上げ下げ、Web 版やスマートフォンでの設定の名前を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

文書の種類ごとの速さの表と確認表は、架空の事務所を想定して当社が置いた目安で、Microsoft のヘルプが勧める速さや手順ではありません。

1．耳で聞く読み合わせに使う

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Word です。ヘルプによると、音声読み上げは Office 2019、Office 2021、Microsoft 365 で使えます。 Word は、端末のテキスト読み上げ（TTS）の機能を使い、書かれた文字を話し言葉として再生します。

ヘルプは、文書を聞く理由として、校正やマルチタスクなどを挙げています。 見積書の金額や案内文の日付は、目で追うだけだと読み飛ばしやすいものです。耳で聞くと、「てにをは」の抜けや、同じ言葉の繰り返しに気づく手がかりになります。ただし、速すぎると聞き逃し、遅すぎると長い文書で時間がかかります。文書の種類に合わせて速さを決めます。

2．似た名前の機能と取り違えない

ヘルプには、Word 文書を聞くための道具が複数あると書かれています。 速さのスライダーを探す前に、どの機能で聞いているのかを確かめます。

  • 音声読み上げ：文書の全部または一部を読み上げます。 オーディオブックのように、カーソルの位置から文書全体を読み上げます。 歯車アイコンの読み上げ速度スライダーは、この機能の設定にあります。
  • ［読み上げ］（ヘルプの中では Speak とも書かれます）：選んだ文字だけを読み上げる機能で、Windows でのみ使えます。 Word、Outlook、PowerPoint、OneNote に組み込まれています。
  • ナレーター：ダイアログ ボックスやボタンなどの画面の表示と文字を読み上げる、Windows のスクリーン リーダー アプリです。

リボンの［校閲］タブにある［読み上げる］は音声読み上げを始めるボタンで、クイック アクセス ツール バーに置く［読み上げ］とは別の機能です。 名前が一字違いなので、社内で手順を伝えるときは「［校閲］タブの［読み上げる］」と場所まで書くと迷いません。

［読み上げ］をクイック アクセス ツール バーに出すには、［クイック アクセス ツール バーのカスタマイズ］を選び、［その他のコマンド］を開いて、［コマンドの選択］の一覧で［すべてのコマンド］を選び、［読み上げ］を選んで［追加］を選び、［OK］を選びます。 追加した後は、単語や文のまとまりを選んでから［読み上げ］のアイコンを選ぶと読み上げます。 ただし、ここで開いた2つのヘルプには、［読み上げ］の速さを変える場所は書かれていません。

3．速さを変える手順

順番操作
1［校閲］タブで［読み上げる］を選ぶ
2読み上げのコントロールの右上で、歯車アイコンを選ぶ
3読み上げ速度スライダーで速さを変える
4声を変えたいときは［音声の選択］で選ぶ

再生は［再生］、止めるのは［一時停止］、段落を移るのは［前へ］と［次へ］、終えるときは［停止］(x) です。

4．キーボードで速さを変える

ヘルプには、Windows のキーボード ショートカットとして次が挙がっています。

キー動き
Ctrl + Alt + Space音声読み上げを始める
Ctrl + Space再生と一時停止
Ctrl + ←今の段落の頭へ戻る
Ctrl + ← + ← + ←前の段落の頭へ戻る
Ctrl + →次の段落の頭へ進む
Alt + ←読み上げ速度を下げる
Alt + →読み上げ速度を上げる

読み合わせの途中で、数字の多い段落だけゆっくり聞きたいときに便利です。金額を聞き逃したときは、Ctrl + ← で今の段落の頭に戻り、Alt + ← で速さを下げてから聞き直せます。

Mac 版のヘルプにもキーボード ショートカットの一覧があり、開始は Ctrl + Option + Space、再生と一時停止は Option + Space、段落の移動は Option + ↑ と Option + ↓ です。 Mac の一覧には速さを上げ下げするキーは挙がっていないため、Mac 版では後の「Mac・Web・スマートフォンで速さを変える場所」の節の歯車アイコンから変えます。

5．一部だけを聞きたいとき

聞きたい文章を選んでから［校閲］タブで音声読み上げを始めると、選んだ部分を聞けます。 文書の全部を聞き直さなくても、直した段落だけを確かめられます。

6．Mac・Web・スマートフォンで速さを変える場所

速さの設定は、使う端末によって入口や名前が少しずつ違います。ヘルプの各タブに書かれている場所は次のとおりです。

  • Mac 版（ヘルプの macOS のタブ）：コントロールの歯車アイコンで設定を開き、読み上げ速度スライダーで音声の速度を変えます。
  • Word for the web（ヘルプの Web のタブ）：案内されているのは、イマーシブ リーダーで聞く方法です。 ［表示］タブで［ドキュメント ビュー］に移動して［イマーシブ リーダー］を選び、下部の［再生］ボタンで始めます。 速さは、下部の歯車アイコンで［音声設定］を開き、［音声の速度］のスライドで変えます。 声は［女性］か［男性］を選べますが、一部の言語は1つの声でしか使えません。
  • iPad 版：音声読み上げのコントロールで歯車アイコンをタップし、スライダーで読み上げ速度を増減します。
  • iPhone 版：［音声読み上げ］のコントロールで歯車アイコンをタップし、［オーディオ設定］の読み上げ速度スライダーで増減します。
  • Android スマートフォン版：［オーディオ設定］の［話し速さ］スライダーで増減します。

外出先でスマートフォンから聞き直すときは、パソコンと同じ名前のスライダーとは限らない点に気をつけます。

7．読み上げが使えない・声が違うとき

  • 音声読み上げが使えないときは、Microsoft 365 のアカウントにサインインしているかを確かめ、Word を起動し直すか、サインインし直すよう案内されています。
  • 自然な声（ニューラル音声）が選べないときは、インターネットに安定してつながっているかと、サインインしているかを確かめます。
  • 読み上げには、文書に設定された校正言語が使われます。 日本語の文書が英語風に読まれるときは、校正言語を疑います。
  • 声の種類：ヘルプによると、音声合成（TTS）は、プラットフォームに応じて、端末に組み込まれたソフトか、Microsoft のサービスを通じたソフトを使い、TTS サービスの間で使える声は異なります。

8．聞いた内容は保存されるか

見積書や人事の書類を聞くときに、内容がどこかに残るのかが気になる人もいるでしょう。ヘルプのプライバシーの節によると、音声読み上げでは内容や音声のデータは保存されず、Microsoft は音声の結果を出すためだけに内容を使います。 内容を分析する機能の詳しい扱いは、「Office の接続エクスペリエンス」のページに分けて案内されています。

9．文書の種類ごとの速さを決めておく（架空の例）

文書速さの目安聞くときの注意
見積書・請求書ゆっくり金額と日付で一時停止して目でも見る
社内の案内文ふつう言い回しの繰り返しに気をつける
長い手順書少し速め直した段落だけ選んで聞き直す

読み合わせの手順を決めておくと、担当が替わっても確認の質がそろいます。どの書類を誰が耳で読み合わせるかを決めるなら、事務の道具と作業の棚卸しで確認の作業を書き出すところから始められます。
