Chromeの「リーディング モード」で本文だけ読みやすくするには

要点

読みにくいページは、ページを右クリックして［リーディング モードで開く］を選ぶと、読みやすい全画面表示のリーディング ビューで開きます。 文字の大きさや色のテーマ、行や文字の間隔を変えても、その設定はリーディング モードで読むテキストにだけ適用されます。 動画やフォーラムのウェブサイトなど、対応していないサイトや形式もあります。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

広告や囲みの多いページで、制度の案内や手順の説明を落ち着いて読みたいときに使える Chrome のリーディング モードの使い方です。右クリック・メニュー・アドレスバー・キーボードからの開き方、文字の大きさや行の高さ・色のテーマの変え方、読み上げ、うまく開かないページの見分け方を、Google の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 元のページはそのまま、読む側の見え方だけを変える
  2. 開き方は4つ
  3. 文字・行の高さ・色を、自分の目に合わせる
  4. 耳で確かめる：読み上げ
  5. うまく開かないページ
  6. 読みやすさの工夫を、社内で分け合う
  7. 確認表

1．元のページはそのまま、読む側の見え方だけを変える

確認日：2026年11月17日。

対象は、パソコンで使う Chrome です。

役所の制度の案内や、取引先から届いたリンク先の説明文を読むとき、まわりの画像やメニューに目を取られて、肝心の本文が頭に入りにくいことがあります。ヘルプによると、リーディング モードでは、テキストに集中しやすくすること、画面上の気が散る要因を減らすこと、別の書体とフォントサイズやカラーテーマを選ぶことができます。 パソコンでは、テキストの読み上げを聞くことや、行や文字の間隔の調整もできます。

大事なのは、ここで変えた設定が Chrome の他のコンテンツには適用されないことです。 サイトの作りを変えるわけでも、ほかのページの文字が大きくなるわけでもなく、自分の画面での読み方を変える機能として使います。

2．開き方は4つ

いちばん手早いのは、読みたいページの上で右クリックし、［リーディング モードで開く］を選ぶ方法です。 ほかにも、ヘルプには次の開き方が載っています。

  • メニューから：右上のその他アイコンから［その他のツール］、［リーディング モード］の順に選びます。
  • アドレスバーから：アドレスバーで読み上げモードのアイコンを選びます。
  • キーボードから：Windows では Alt+Shift+R です。

元のページを見ながら横に本文だけを出したいときは、リーディング モードの設定から［表示］、［サイドパネル］を選びます。ブラウザにはこの設定が保存されます。 パネルが狭いときは、パネルの枠線を左にスライドすると広げられます。 よく使う人は、右上の設定から［リーディング モードを固定］を選んでおくと、ツールバーから開けるようになります。

なお、操作した覚えがないのにリーディング モードが開く場合について、ヘルプは、音声操作など、同じキーボード ショートカットを使う他のアプリが開いていないかを確かめるよう案内しています。

3．文字・行の高さ・色を、自分の目に合わせる

文字の大きさは、右上のフォントサイズ アイコンから［縮小］・［拡大］を選び、元に戻すときは［リセット］を選びます。 そのほかの項目は、右上の設定から選びます。ヘルプに挙がっているのは、［色のテーマ］、［フォント］、［行の高さ］、［文字間隔］と、リンクや画像の表示の切り替えです。

困りごと（架空の例）変える項目
文字が小さくて目が疲れるフォントサイズ アイコン（拡大）
行が詰まっていて、どこを読んでいたか分からなくなる行の高さ
白い背景がまぶしい色のテーマ
本文の途中のリンクや画像に気を取られるリンク・画像をオフ

リンクはデフォルトでは表示されています。 申請の手順のように、本文の中のリンクから様式を開く必要があるページでは、リンクはオンのままにしておきます。

4．耳で確かめる：読み上げ

リーディング モードを使うと、ウェブサイト上のテキストを音声で聴くこともできます。右上の再生を選ぶと始まり、一時停止や、前の文・次の文への移動、音声の速度の調整ができます。 使う声は右上の設定の［音声の選択］で、読んでいる箇所の示し方は［音声ハイライト］で選べます。 声は、現在の言語の Google の自然な音声が自動的にダウンロードされ、ダウンロードできない場合は現在の言語のシステム音声が使われます。 事務所のパソコンで声が思ったものと違うときは、この仕組みを思い出して［音声の選択］を見直します。長い要領を、手元の書類と見比べながら耳で追いたいときに向いています。

5．うまく開かないページ

ヘルプには、この機能は一部のウェブサイトでは利用できないとあります。 また、画像ギャラリー、操作可能な地図、フォーム、クイズ、お支払いページ、ログイン画面のようなページでは、想定どおりに動作しないことがあると書かれています。 事務でいえば、申請の入力画面や支払いの画面は元のページのまま操作し、リーディング モードは説明を読む場面に使う、と分けておくと迷いません。

本文が見つからないと表示されたときは、元のページで読みたい部分を選んでからリーディング モードで開く方法があります。 それでも開けないときは、Chrome が最新のバージョンかを確かめます。

6．読みやすさの工夫を、社内で分け合う

社内で「読みにくい」という声が多いページがあるなら、どのページで、どの読み方が助かったかを書き留めておくと、ほかの人にも勧めやすくなります。事務の道具の使い方と、それで減った手間を一覧にして見直すときは、業務棚卸しチェックシート（エクセル・CSV）の考え方も参考になります。
