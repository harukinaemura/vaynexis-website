クラシックOutlookのオートコンプリートから古い宛先候補を消すには

要点

古い宛先候補は、候補一覧で対象を選んで削除する方法があります。この記事の主手順は、従来のOutlook for WindowsでExchangeオンプレミスまたはPOP/IMAPを使い、候補がオートコンプリート一覧から提供される場合を対象にします。削除の操作だけで送信準備を終えず、送りたい相手と入力したアドレスを照合することが大切です。候補を消す作業と、相手の連絡先そのものを整理する作業は、目的を分けて考えます。

公開：2026年11月15日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、古い宛先候補を整理したい小さな会社の担当者が、ExchangeオンプレミスまたはPOP/IMAPで使うWindows版クラシックOutlookの削除手順とアドレスの再入力を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. まず使っている版とアカウントを確かめる
  2. 古い候補を表示し、削除する対象を選ぶ
  3. 完全なメールアドレスを入れ直す
  4. 消した候補が戻る場合と、連絡先の違い
  5. 送信前の照合と引き継ぎを揃える
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．まず使っている版とアカウントを確かめる

確認日：2026年11月15日。

Microsoft の入力候補の管理案内の適用先は、Outlook for Microsoft 365、Outlook 2024・2021・2019・2016、新しい Outlook for Windows です。以下では、従来のOutlook for Windowsの対象アカウントに絞り、配信エラー対処の公式案内に沿って宛先候補の削除と正しいアドレスの入れ直しを説明します。メールが届かない原因をすべて調べる手順や、候補全体を消去する方法は扱いません。

Microsoft の入力候補の管理案内では、新しい Outlook とクラシック Outlook を、使用しているバージョンに応じて読み分けます。画面名が見つからないときは、似た項目を続けて押す前に、読んでいる説明と利用中の画面が合っているかを確かめるとよいです。

従来の Outlook for Windows では、Exchange Online の候補は Microsoft Search Service、Exchange オンプレミスまたは POP/IMAP の候補はオートコンプリート一覧から提供されます。使っている画面が同じでも、候補の出所まで同じとは考えず、契約や設定を管理している担当者に利用環境を確かめておくと、後の切り分けにつながります。

2．古い候補を表示し、削除する対象を選ぶ

宛先欄に入った相手と候補一覧を区別する

作業を始める前に、送り先としてすでに選んだ相手と、入力途中に表示される候補を分けて見ます。送信しようとしている文面に入った相手を取り除く段階と、入力途中に出る古い候補を取り除く段階を区別すると、どこまで作業したかが分かります。「欄から消えた」という確認だけで終えないことがポイントです。

入力途中の一覧から対象を削除する

［宛先］欄に受信者のアドレスを入力し、オートコンプリートの候補一覧に対象を表示させます。次に下方向キーで削除する受信者を選び、［削除］を選択します。一覧の上のほうにあるからという理由で選ばず、変更対象の文字列を見てから操作します。似た名前が並ぶ場面では、表示名だけを手掛かりにすると、残したい相手を選んでしまうおそれがあります。

削除する前に、相手から受け取った変更の案内などと対象を照合しておくとよいです。先に正しい送り先を手元で確かめておけば、候補を消した後で入力内容に迷ったときにも戻る場所ができます。

3．完全なメールアドレスを入れ直す

候補を削除した後は、［宛先］欄に受信者の完全なメールアドレスを入力し、つづりを確かめます。相手の名前が見えたことだけを確認の終点にせず、入力した文字列全体を、現在の連絡先が分かる資料と見比べます。

確認の順番は、送りたい相手が合っているか、使う窓口が合っているか、文字列が合っているかです。担当者個人に送る文面なのに部署の共通窓口を選んでいないか、以前の案内を見ていないかも整理します。読めない文字や、変更の案内どうしで食い違う箇所があるときは、推測で補って送信へ進めず、相手側の担当者に確かめるとよいです。

宛先を入れ直す作業中は、本文や添付物の準備と照合を混ぜないほうが確認箇所を追いやすくなります。古い情報を見つけた経緯と、送り先として採用した情報を分けておくと、引き継いだ人も判断の理由をたどれます。

4．消した候補が戻る場合と、連絡先の違い

Microsoftの既知の問題の案内（最終更新日2026年6月17日）では、Exchange Onlineを使う従来のOutlook for Windowsで候補の「X」を押して消えたように見えても、後で候補が戻る場合があると説明しています。その場で表示が変わったことだけを根拠に、次回も出ないと判断せず、再表示した状況を管理担当者へ伝えるとよいです。

保存された個人用連絡先はその連絡先を削除しない限り、組織の連絡先は組織の管理者が削除しない限り、連絡先検索候補に引き続き表示されます。今回の目的が古い入力候補を整理することなら、連絡先を削除する作業へ進む前に、対象と管理者を確かめます。

Microsoft Learnの英語本文では、オートコンプリート一覧から名前を削除した相手に新たなメールを送ると、その情報が一覧に復元されると説明しています。これは前述の検索サービスによる再表示とは分けて考える点です。古い情報を使っていないかと、削除後にどの相手へ送ったかを分けて振り返ると、同じ操作を繰り返すだけの状態を避けやすくなります。

5．送信前の照合と引き継ぎを揃える

ここからは当社の整理です。

例では、取引先から案内された送り先の変更を、事務担当者が確認する場面を考えます。

状況確かめる対象引き継ぎに残す内容
過去の送り先が入力途中に現れた変更案内と古い文字列の対応整理した対象と、正しい情報の確認先
名前は同じで文字列が違う担当者向けか共通窓口向けか今回の用件に使う送り先
整理した後で再び現れた再表示した場面と利用環境その場で見えたこと、管理担当者へ伝えること

引き継ぎには「削除済み」という結果だけを書くより、どの場面で何を確かめたかを残すほうが役立ちます。たとえば、入力途中の表示を整理したのか、送信予定の文面から相手を取り除いたのかを分けます。担当者が交代した後も、送り先が正しいかを確かめる資料の保管場所が分かるようにしておくとよいです。

確認の記録には、相手から受け取った変更案内を根拠にしたのか、社内の管理担当者に確かめたのかを残します。表示が消えた事実と、送り先が正しいと判断した理由は別の情報です。後から見た人が両方をたどれる形にすると、表示の変化だけで判断することを防ぐ助けになります。

事務の手間を洗い出すなら、送り先の変更案内を受けてから照合し、引き継ぐまでの流れも対象にして、AIの活用を考える前の作業整理につなげるとよいです。相手への送信を決める場面と、確認に必要な情報を整理する場面を分けて考えます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□消したい対象が、入力途中の候補か、送信予定の文面に入った相手かを区別したか
□利用している版とアカウントの種類を確かめたか
□整理する対象の文字列を、変更の案内と照合したか
□入れ直した送り先を最後まで読み、現在の案内と一致するかを確かめたか
□再表示したときに、その場面を管理担当者へ伝えられる形にしたか
□保存された連絡先の整理とは作業を分けたか
□引き継ぐ人が正しい情報の確認先をたどれるようにしたか

出典（確認日：2026年11月15日）

  • Outlook の宛先、CC、BCC フィールドの入力候補表示を管理する：適用先と版の読み分け、保存された個人用・組織の連絡先の扱い
  • オートコンプリートで、個々の推奨受信者を削除する "X" キーが期待どおりに機能しない場合があります：アカウント別の候補の提供元、削除後に再表示される条件
  • outlook.com、microsoft.com、または service.microsoft.com の郵便局長からの配信メッセージの失敗：古い候補を表示して削除する手順、完全なアドレスの再入力
