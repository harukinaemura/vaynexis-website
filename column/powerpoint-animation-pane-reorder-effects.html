PowerPointのアニメーション ウィンドウで表示順を変えるには

要点

Windows 版では、［アニメーション］タブの［アニメーション ウィンドウ］で効果の並びを確かめ、順番を変えたい効果のアニメーション マーカーを選んで［順番を早くする］か［順番を遅くする］を選びます。 PowerPoint for the web では、ウィンドウの一覧で効果を選んだまま上下にドラッグして並べ替えます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

説明の順に図を出したいのに、後から付けた動きが先に出てしまう。アニメーション ウィンドウで順番を入れ替える操作を Windows・Web・Mac の版ごとに確かめ、開始のタイミングや要らない効果の消し方も合わせて見ます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

並べ替えたあとに見ることの表は、提案資料を作る場面を想定した架空の例で、Microsoft のヘルプに載っている手順ではありません。

  1. 説明の順と図の出る順がずれる
  2. Windows 版：ウィンドウで確かめ、ボタンで動かす
  3. Web 版：一覧の上でドラッグする
  4. Mac 版：ウィンドウの上の方向キー
  5. 順番だけでは直らないとき：開始のタイミング
  6. 要らない効果を先に消す（Windows 版）
  7. 配布用や練習のときは動きを止める
  8. 並べ替えたあとに見ること（架空の例）
  9. 確認表
  10. 自社の事務の手順まで形にしたいとき

1．説明の順と図の出る順がずれる

確認日：2026年11月17日。

対象は、Windows のパソコンで使う PowerPoint（デスクトップ版）を中心に、Web 版と Mac 版の違いも添えます。

提案の資料で「課題、対策、費用」の順に図を出したいのに、後から付けた効果が先に出てしまう、ということがあります。効果を消して付け直さなくても、順番だけを入れ替えれば直せます。Mac 版のヘルプの説明では、スライド上のオブジェクトの横に付く番号が、アニメーション効果の再生順序を示すとされています。 まずウィンドウの一覧で（Mac 版ではこの番号でも）、いまの順番をつかみます。

2．Windows 版：ウィンドウで確かめ、ボタンで動かす

順番操作
1［アニメーション］タブで［アニメーション ウィンドウ］を選ぶ
2スライドで、順番を変えたいオブジェクトを選ぶ（そのオブジェクトの効果がウィンドウで強調表示される）
3アニメーション マーカーを選ぶ
4前に出したいときは［順番を早くする］、後に回したいときは［順番を遅くする］を選ぶ

ヘルプの説明では、［順番を早くする］は表示される順序を前に、［順番を遅くする］は動作する順序を後に移します。

3．Web 版：一覧の上でドラッグする

PowerPoint for the web のヘルプでは、［アニメーション］タブで［アニメーション ウィンドウ］を選ぶと、アニメーション効果が順番に一覧表示されると書かれています。 動かしたい効果を選び、選んだまま上下にドラッグします。 ドラッグ中は赤い細い水平線が置ける場所を示し、間違えたときは Ctrl+Z キーで戻せます。

4．Mac 版：ウィンドウの上の方向キー

Mac 版のヘルプでは、［アニメーション］ウィンドウで効果を選び、ウィンドウの上部の方向キーで順序を変える、と案内されています。 ウィンドウが見えないときは、標準表示になっているかを確かめてから［アニメーション ウィンドウ］を選びます。

5．順番だけでは直らないとき：開始のタイミング

Windows 版のヘルプでは、アニメーションの始まり方として［クリック時］［直前の動作と同時］［直前の動作の後］の3つが挙げられています。 並べ替えても思った順に見えないときは、効果の開始が［直前の動作と同時］になっていないかを見ます。この設定は、前の順番のアニメーションと同時に再生するものなので、順番を後ろに回しても、ひとつ前の効果と重なって出ます。

説明に合わせて1つずつ出したいなら、スライドをクリックすると始まる［クリック時］が合います。 話しながら自動で続けて出したいなら、前のアニメーションが動作した後すぐに始まる［直前の動作の後］を選びます。 同じ所には［継続時間］と［遅延］もあり、それぞれ効果を長くしたり短くしたりする、効果が実行される前に時間を追加する、と説明されています。 図が出るのが速すぎて話が追いつかないときは、順番ではなくこちらを直します。

6．要らない効果を先に消す（Windows 版）

試しに付けた効果が残っていると一覧が長くなり、並べ替えの手間が増えます。Windows 版のヘルプでは、アニメーション ウィンドウで削除する効果を選び、下矢印を選んで［削除］を選ぶ、と案内されています。 複数の効果を消すときは、ウィンドウで Ctrl キーを押しながら効果を選び、Delete キーを押します。 あるオブジェクトの効果をすべて外すなら、そのオブジェクトを選んで、［アニメーション］タブの効果のギャラリーで［なし］を選びます。

一緒に動かしたい図が複数あるなら、先にグループ化する方法もあります。Ctrl キーを押しながらオブジェクトを選び、［図形の書式設定］の［グループ］でまとめてから、アニメーションを付けます。 図を1つずつ動かすより、並べ替える対象が減ります。

7．配布用や練習のときは動きを止める

画面で読んでもらう資料として配るときなど、動きが要らない場面もあります。ヘルプには、1回の操作でプレゼンテーション全体からすべてのアニメーションを削除することはできないが、すべてのアニメーションを無効にすることはできる、と書かれています。 Windows 版では、［スライド ショー］タブで［スライド ショーの設定］を選び、［オプション］で［アニメーションを表示しない］を選びます。 削除ではなく無効にする操作なので、付けた効果を消すわけではありません。本番の前に設定を戻し、通して動きを確かめておきます。

8．並べ替えたあとに見ること（架空の例）

見ること架空の記入例
説明の順課題 → 対策 → 費用の順に出るか

同時に出す効果は、Mac 版のヘルプでは番号付きのスタックで表されると説明されています。 片方だけを動かしてしまうと、同時に出るはずの図がずれることがあるので、並べ替えのあとに通して見ます。
