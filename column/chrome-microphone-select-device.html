Chromeの「マイク」で会議に使う入力機器を変えるには

要点

Chrome では、サイトで使うデフォルトのマイクを選べます。［設定］から［プライバシーとセキュリティ］、［サイトの設定］と進み、［権限］で［マイク］を選んだら、下矢印から使うマイクを選びます。 パソコン全体の側では、Windows 11 の［サウンド］の［入力］で、話す・録音するために使う機器を選びます。 職場の Chrome では、カメラとマイクの設定を変えられるのがネットワーク管理者だけのこともあります。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

ヘッドセットをつないだのに、相手には内蔵マイクの声が届いている。そんなときに、パソコン版 Chrome の［サイトの設定］の［マイク］で既定のマイクを選ぶ手順と、Windows 11 の［サウンド］の［入力］で録音に使う機器を確かめる手順を、Google と Microsoft の公式ヘルプに沿って整理します。

1．マイクを選ぶ場所は一つではない

確認日：2026年11月16日。

対象は、Windows 11 のパソコンで、Chrome から Web 会議に入る場面です。会議サービスの画面の中にある音声の設定と、Windows のスピーカー（音を出す側）の設定は扱いません。

ノートパソコンには、たいてい内蔵のマイクがあります。そこへ USB のヘッドセットや Web カメラをつなぐと、マイクが2つ、3つと増えます。会議の相手から「声が遠い」「周りの電話の音まで入っている」と言われたら、思っていたのとは別のマイクが使われているのかもしれません。

声を拾うマイクを選ぶ場所は、少なくとも2か所あります。一つは Chrome の［サイトの設定］、もう一つは Windows の［サウンド］の設定です。どちらか一方だけを見て「選んであるはず」と思い込むと、原因にたどり着くまで時間がかかります。まず Chrome の中の選び方を見て、次に Windows の側へ進みます。

2．Chrome で既定のマイクを選ぶ

Chrome のヘルプには、サイトで使用するデフォルトのマイクを選択できると書かれています。

  1. パソコンで Chrome を開きます。
  2. 右上のその他アイコンから［設定］を選びます。
  3. ［プライバシーとセキュリティ］、［サイトの設定］の順に選びます。
  4. ［権限］で［マイク］を選びます。
  5. 下矢印を選び、使うマイクを選びます。

一覧に並ぶ名前は、機器の製品名や「既定」などの表示になっていることが多く、どれがヘッドセットか迷うことがあります。いったんヘッドセットのケーブルを抜き、一覧から消えた名前を見ると見分けやすくなります。

3．Windows の［サウンド］の［入力］で、録音に使う機器を確かめる

Chrome で選んでも声が届かないときは、Windows の側も見ます。Microsoft のヘルプでは、マイクまたはヘッドセットが、システムの既定の録音デバイスになっていることを確かめるよう案内されています。

  1. ［スタート］から［設定］、［システム］、［サウンド］の順に選びます。
  2. ［入力］で、［話す/録音するためのデバイスを選択する］に移動し、使うデバイスを選びます。
  3. 声の拾い方を試すには、デバイスの右側にある［>］を選び、プロパティのページの［マイク テスト］で［テストの開始］を選んでマイクに向かって話します。

会議の前にこのテストを一度しておくと、当日「聞こえますか」のやり取りで数分を使わずに済みます。

4．声が届かないときに見る順番

マイクを選び直しても声が届かないときは、次の順で見ていきます。Google と Microsoft のヘルプにある手順を、手元で確かめやすい順に並べました。

順番見る所ヘルプにある内容
1ヘッドセットのミュートヘッドセットにミュート ボタンがある場合、アクティブでないことを確かめる
2会議の画面のミュートウェブサイトやビデオ会議サービスでミュートになっていないか
3Chrome のサイトの権限マイクを使うサイトに、マイクへのアクセスを許可しているか
4Windows の既定の録音デバイス正しいマイクが選ばれ、録音レベルが適切か
5入り直す・再起動ビデオ通話を終了して再参加し、Chrome とパソコンを再起動する

1と2は、機器や画面を見るだけで済みます。コードの途中に付いているミュートスイッチは、机の下で何かに当たって入ってしまうこともあります。3は、会議のサイトでマイクを［許可しない］にしていると起きます。4は、ヘッドセットを替えた後に見落としやすい所です。

さらに、Windows 11 の更新の後にマイクが検出されないときは、［プライバシーとセキュリティ］の［マイク］で［マイクへのアクセス］がオンになっているかを確かめるよう、Microsoft のヘルプに書かれています。 デスクトップ アプリには、［デスクトップ アプリからマイクにアクセスできるようにする］という別の項目があります。

最後まで試してもだめなら、Chrome のヘルプでは、マイクの製造元に問い合わせて、追加のトラブルシューティングや互換性について相談するよう案内されています。

5．職場の Chrome で選べないとき

ヒントとして、職場や学校で Chrome を使っている場合、カメラとマイクの設定を変更できるのはネットワーク管理者のみと書かれています。 下矢印が押せない、選んでも元に戻る、というときは、社内でパソコンを管理している人に、使いたいヘッドセットの名前を伝えて相談します。

共用の会議室のパソコンなら、使い終わった人がマイクを選び直したままにしていることもあります。会議室に「このパソコンで使うマイク」を貼っておくと、次の人が迷いません。

6．機器の記録を残しておく（架空の例）

ヘッドセットの貸し出しや入れ替えがある職場では、どのパソコンでどのマイクを使うかを一覧にしておくと、毎回の確かめが短くなります。

残す内容架空の記入例

使うマイクUSB ヘッドセット（総務の貸し出し品）

パソコンや会議の機器に関わる細かな作業は、表に出にくい時間です。社内の作業を一度洗い出してみるときは、業務棚卸しチェックシート（エクセル・CSV）を使うと、こうした作業も1行ずつ書き出せます。
