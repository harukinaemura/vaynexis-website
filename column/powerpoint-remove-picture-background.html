PowerPointで写真の背景を削除する手順と残す部分の確認

要点

写真の背景は、自動で削除した後、残す領域と削除する領域を線で示して調整できます。仕上がりは、背景の消え残りと被写体の欠けを分けて見るとよいです。説明に必要な形や表示を残せたかを、元の写真と照合します。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、説明資料に載せるPowerPointの写真から背景を取り除きたい小さな会社の担当者が、使える環境、残す領域と消す領域の調整、仕上がりの確かめ方を確認する流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 編集を始める前に環境と対象をそろえる
  2. 写真を選び、背景を削除する画面を開く
  3. 色の付いた領域を見て、残す部分と消す部分を調整する
  4. 操作できない画像と、薄くする操作を区別する
  5. 変更の採用を決め、再利用する写真を分けて保存する
  6. 説明に必要な部分を基準に、仕上がりを引き継ぐ
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．編集を始める前に環境と対象をそろえる

確認日：2026年11月13日。

このヘルプは Excel・Word・Outlook・PowerPoint などに共通のページで、適用先には PowerPoint for Microsoft 365・PowerPoint 2024・PowerPoint 2021 とそれぞれの Mac 版などが並んでいます。ここではそのうち PowerPoint 2024 と PowerPoint 2024 for Mac を対象に、デスクトップ版の操作を扱います。PowerPoint for the web には画像の背景を削除する機能がなく、デスクトップアプリを使う案内になっています。

対象は、説明資料に載せる写真です。作業前には元の写真を別に保管し、どこを相手に見せたいのかを言葉にしておきます。輪郭だけ伝わればよいのか、表面の表示や周囲との位置関係も必要なのかで、採用する仕上がりは変わります。背景を広く消すこと自体を目標にせず、説明に必要な情報を決めてから編集に進むとよいです。

2．写真を選び、背景を削除する画面を開く

出典のページでは、操作の手順が Windows の欄と macOS の欄に分かれています。以下はその欄ごとに書きます。

Windows の操作

Windows では写真を選び、［図の書式設定］→［背景の削除］、または［書式設定］→［背景の削除］を選びます。

Mac の操作

Mac では写真を選び、［図の形式］タブの［背景を削除］を選びます。ボタンの名前は、Windows の欄では［背景の削除］、macOS の欄では［背景を削除］と書かれています。お使いの画面での表記は確かめていません。

写真そのものを編集したいのか、資料の地の色を変えたいのかは、作業前に分けて考えます。ここで扱うのは写真の中の背景です。画面の名前だけを頼りに進めず、編集したい写真が対象になっているかを見ることが大切です。

背景を削除する項目が見つからないときは写真を選択しているか確認し、必要に応じてダブルクリックして［図の形式］タブを開きます。

3．色の付いた領域を見て、残す部分と消す部分を調整する

自動処理後は、削除対象の背景がマゼンタで示され、前景は元の色で残ります。

まず、残したい物の外周を追います。角、持ち手、細い脚、突出した部品など、欠けると形の意味が変わる場所が確認の中心です。次に、物の内側にある穴や隙間を見て、背景が取り残されていないかを調べます。外側の輪郭だけで合否を決めない進め方がよいです。

残したい部分は［保持する領域をマーク］で保持する領域を示し、不要な部分は［削除する領域をマーク］で削除する領域を示して調整します。

修正した後も、直した場所とその周辺を見比べます。大きく表示した状態では輪郭を点検し、資料に載せる大きさでは形や文字を読み取れるかを確かめます。細部が残っていても、説明に必要な表示を読めなければ、そのまま配布する判断は避けたいところです。

4．操作できない画像と、薄くする操作を区別する

主な対象外の形式として、SVG、AI、WMF、DRW などのベクター画像では［背景の削除］が灰色表示になり、背景を削除できません。

写真を選んでいるのに操作できない場合は、受け取った画像の種類を確かめます。元の写真を持っている担当者に確認するなど、素材を見直す段階に戻るとよいです。見た目が似ているだけで、同じ編集ができるとは判断しません。

［透明度］は図の不透明度を下げたり上げたりする設定です。このページは「新しいバージョン」「macOS」「Web」の欄に分かれており、ここで挙げたのは「新しいバージョン」の欄の説明です。ほかの欄の手順は確かめていません。背景だけを取り除きたいときは、被写体まで薄くなっていないかにも目を向けます。

5．変更の採用を決め、再利用する写真を分けて保存する

調整を終えたら［変更を保持する］を選び、変更を採用しないときは［すべての変更を破棄する］を選びます。処理後の写真を別のファイルに保存するには、写真を右クリックして［画像として保存］を選びます。

元の写真と編集後の写真は名前を分け、どちらを資料に使うか分かるようにします。再利用するときは保存した画像を開き、残すはずの箇所が欠けていないかを改めて確認するとよいです。編集画面で見た印象だけで受け渡しを終えず、実際に渡す画像と資料の組合せで判断します。

6．説明に必要な部分を基準に、仕上がりを引き継ぐ

ここからは当社の整理です。

事務で使う写真は、見栄えだけでなく説明の目的から残す範囲を決めます。たとえば、説明資料で写真の使い道を整理するなら、次のような見方があります。

写真の用途残したい部分仕上がりで見る箇所
備品の形を説明する本体の外周と持ち手持ち手の内側に背景が残っていないか
操作箇所を案内する操作部とその表示表示や小さな突起が欠けていないか
設置位置を伝える対象物と位置の手掛かり周囲を消しすぎて位置関係が不明になっていないか

きれいに切り抜けても、置き場所や対象の向きを伝えられなくなった写真は、説明の目的に合いません。周囲が必要な写真では、背景を残したまま使う判断もあります。また、この手順は説明用の見た目を整えるものとして扱い、個人情報を復元不能に消す手順には使いません。

引き継ぎには、元画像の保管先、編集後の保存先、残す範囲の意図、確認を終えていない箇所を短く残します。担当者が変わっても、消す範囲を好みだけで広げず、同じ目的で仕上がりを判断するためです。写真を差し替えたときには、以前の確認結果を流用せず、欠けと消え残りを見直すとよいです。

この作業を AI で減らすなら、素材の選定、背景の調整、仕上がりの判断のうち、手間のかかる工程を整理します。AI の活用を考える入口とあわせて、任せる工程と人が確認する工程を分けて考えるとよいです。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□元の写真を残し、編集後の保存先と区別したか
□使っている環境と画像の種類を確認したか
□残したい物の輪郭や細い部分が欠けていないか確認したか
□穴や隙間に不要な背景が残っていないか確認したか
□資料に載せる大きさで形や表示を読み取れるか確認したか
□説明に必要な位置関係まで消していないか確認したか
□渡す画像と引き継ぎのメモを照合したか
