Excelで担当と完了状況を指定して平均作業時間を出すには

要点

担当と完了状況を指定した平均作業時間は、複数の条件に一致する値の算術平均を返すAVERAGEIFS関数で求めます。作業時間の列と条件の列を分け、同じ時間の意味と単位で記録しておくことが出発点です。結果だけでなく、対象になった明細まで照合します。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、担当別に完了した作業の平均時間をExcelで出したい小さな会社の担当者が、平均する範囲と条件の組み合わせ、時間の単位、該当する記録がないときの確認までをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 数式の前に、平均する時間の意味を決める
  2. 平均範囲を先に置き、担当と状況を組み合わせる
  3. 分単位の数値と、時刻の差を混ぜない
  4. 値が合わないときは、範囲と対象行からたどる
  5. 集計条件と照合の順番を引き継ぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．数式の前に、平均する時間の意味を決める

確認日：2026年11月13日。

公式ヘルプの適用先には、Excel for Microsoft 365と同Mac版、Excel 2024と同Mac版、Excel 2021と同Mac版、Excel 2019、Excel 2016、Excel Web Appが含まれます。ここでは、表の配置と数式を中心に説明します。

表の準備については、当社では次のように整理します。担当、状況、作業時間を別々の列に記録し、明細ごとに同じ区切りで時間を測ります。着手から終了までの経過時間なのか、待ち時間を除いた手を動かした時間なのかを先に決めると、数値の意味がそろいます。途中で測り方を変えた記録は、そのまま混ぜず、区別して扱うとよいです。

「完了」の意味も共有しておきます。担当者の作業終了を指すのか、確認者の承認まで済んだ状態を指すのかによって、対象にしたい明細が変わります。引き継ぐ人が同じ表を見て対象を選べるよう、状況の呼び名と判定の区切りをそろえてから集計に進みます。

2．平均範囲を先に置き、担当と状況を組み合わせる

AVERAGEIFS関数では、平均する範囲を先頭に置き、その後に条件範囲と条件の組を並べます。平均したい数値の列と、対象を選ぶための列を分けて読むと、式の役割を追いやすくなります。

行A列：担当B列：状況C列：作業時間（分）
2担当い完了16
3担当ろ完了32
4担当い完了24
5担当い対応中50
6担当い完了20
7担当い差戻し12

この表の配置では、C2:C7を平均範囲、A2:A7と「担当い」を担当の条件、B2:B7と「完了」を状況の条件として、次の式を使います。

=AVERAGEIFS(C2:C7,A2:A7,"担当い",B2:B7,"完了")

平均に使われるのは指定した条件をすべて満たす行の値なので、この表では「担当い」であり、かつ「完了」である明細を選びます。対象になる明細を先に目で追い、その後で式の参照先と見比べる流れです。

表の対象値から計算すると、16・24・20の合計を対象の3件で割り、平均は20分になります。この結果は説明用の表から求めた計算例です。元の表とは離れた空きセルを集計結果の置き場にし、明細の時間欄へ式を混ぜない形にします。

3．分単位の数値と、時刻の差を混ぜない

平均する前に、作業時間の列全体を同じ単位にそろえます。分単位で記録する運用と、開始・終了の時刻を記録する運用では、集計前の準備が異なります。引き継ぎ時には、列名に単位を添えるだけでなく、どの元情報から時間を得ているかも共有するとよいです。

開始・終了を時刻で記録した場合、公式の例では、開始がA2、終了がB2のときに「=(B2-A2)*1440」で差を合計分数に直しています。分として入力した値を使う列と、時刻から求めた値を使う列は、変換の有無を確かめてからまとめます。表示されている見た目だけで、保存された値の意味まで同じだと判断しないことが大切です。

ヘルプの「Windows」「Web」の項目では、文字列の数値に警告が出た場合、変換するセルを選んで左上隅のエラー インジケーターを選び、メニューから［数値に変換］を選ぶと案内しています。Mac版の操作は、この記事では扱いません。この方法は、警告が表示された場合の操作です。

別の方法として、VALUE関数で文字列の数値を返すこともできます。変換前の記録を残したいときは、確認用の列で値を見比べてから、平均する列を決めるとよいです。警告からの変換と、別の列で行う変換を混同せず、元の記録へ戻れる形で扱います。

4．値が合わないときは、範囲と対象行からたどる

各条件範囲は、平均範囲と同じサイズと形状である必要があります。さらに、この表のように同じ行の情報を組み合わせる場合は、範囲の開始位置と終了位置もそろえます。列の長さだけを見て終わらせず、担当、状況、時間が同じ明細を指しているかまで追います。

明細を追記した後は、時間の列だけでなく条件側の列も末尾まで確認します。式を引き継ぐ際には、先頭の明細と末尾の明細を実際に指し示せる状態にしておくと、途中までの行だけを対象にしたまま集計する見落としを探せます。見出しや途中の集計行が明細へ入り込んでいないかも、同じ順番で見ます。

すべての条件を満たすセルがない場合は、エラーが返されます。該当する担当の明細があるか、状況の呼び名がそろっているか、記録した範囲を読み違えていないかをたどります。

平均範囲が空またはテキスト値の場合も、エラーになるとされています。対象行が見つかっても、時間が未記入のままなら、その理由と記録の担当を確認します。エラーを見えなくする前に、対象の不在と記録の不足を分けて扱うことが、結果の読み違いを防ぐための確認になります。

5．集計条件と照合の順番を引き継ぐ

ここからは当社の整理です。

最終確認では、式を見ながら対象行を選び、該当する時間だけを別に足して平均と照合します。合わないときは、先に選んだ行を比べ、その後で時間の記録を調べる順にすると、対象の選び違いと入力内容の違いを切り分けられます。結果の表示だけを見て修正するより、どの明細が含まれるべきかを説明できる状態が大切です。

引き継ぎには、対象の担当、完了と扱う状態、時間の単位、待ち時間を含めるか、明細を追記したときに見直す範囲を残します。未記入の時間を後で補う運用なら、補記後に集計を見直す役割も決めておくとよいです。数式を渡すだけでなく、どんな記録を平均したのかが分かる短い説明を添えます。

担当間で結果を比べる場面では、作業の難しさや担当する内容がそろっているかも検討します。平均時間だけを見て仕事の速さを評価せず、対象に含めた仕事と測り方を併せて読む扱いにします。

この作業をAIで減らすなら、時間の記録、条件の確認、結果の照合を分け、事務でAIを活用する進め方を考える出発点にできます。対象に含める仕事と、平均する時間の意味は、人が確認する項目として残します。
