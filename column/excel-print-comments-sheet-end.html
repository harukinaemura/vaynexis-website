Excelの確認コメントを表の末尾にまとめて印刷するには

要点

確認コメントを末尾にまとめるには、対象のワークシートの［ページ設定］を開き、［シート］タブの［コメント］で［シートの末尾］を選びます。 Microsoft 365版では、末尾にスレッド形式のコメントとメモの両方を印刷できます。

公開：2026年11月14日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、Excelの確認コメントを紙で渡したい小さな会社の担当者が、Microsoft 365のWindows版とMac版の印刷設定、表と注釈の対応を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 注釈の種類と対象の版を確認する
  2. Windowsでは末尾の設定を選ぶ
  3. Macの入口と、表示位置で出す場合を分ける
  4. 紙の表と注釈の対応を確かめる
  5. 引き継ぎには出力目的と確認結果を残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．注釈の種類と対象の版を確認する

確認日：2026年11月13日

Microsoftの印刷ヘルプの適用先は、Excel for Microsoft 365、同Mac版、Excel 2024、同Mac版、Excel 2021、同Mac版です。 ここでは、Microsoft 365版で末尾へまとめる操作を案内します。

Excel for Microsoft 365のコメントには［返信］ボックスがあり、返答を含む会話を表示できます。 メモには［返信］ボックスがなく、以前のバージョンではコメントと呼ばれていた注釈です。

引き継ぎでは、注釈を何と呼んでいるかだけでなく、会話を渡したいのか、補足の書き込みを渡したいのかをそろえておくとよいです。紙を受け取る人が探す内容を先に決めると、出力後の照合にもつながります。

2．Windowsでは末尾の設定を選ぶ

まず、印刷したいスレッド形式のコメントとメモを含むワークシートを選択します。 次に［ページ レイアウト］タブの［ページ設定］グループで右側のポップアップを開き、［ページ設定］ダイアログへ進みます。

［シート］タブを選んでから、［コメント］ボックスを［シートの末尾］に切り替えます。 ［印刷］または［印刷プレビュー］を選ぶと、コメントとメモの出力をプレビューできます。

操作を引き継ぐ際は、どの表を対象にしたのかと、末尾へまとめた仕上がりを対にして残すとよいです。設定画面を開いたことだけで終えず、受け渡す内容が紙のどこにあるかまで照合する流れにします。

Microsoft 365版では、シート上に表示された位置のままスレッド形式のコメントを印刷することはできません。 また、末尾にメモだけを印刷することはできず、末尾へ出す場合はスレッド形式のコメントとメモの両方が対象になります。

3．Macの入口と、表示位置で出す場合を分ける

Microsoft 365のMac版では、対象のワークシートを選び、［ファイル］メニューから［ページ設定］を開きます。 続いて［シート］タブの［コメント］ボックスで［シートの末尾］を選びます。 設定後は［印刷］を選択します。

Mac版でも、スレッド形式のコメントをシート上の表示位置で印刷することはできず、表示どおりに印刷できるのはメモです。 末尾へメモだけを出すこともできず、末尾にはスレッド形式のコメントとメモの両方を印刷できます。

WindowsのMicrosoft 365版では、メモをシートに表示されている形で印刷する方法もあります。 個別表示にはセルの右クリックから［ノートの表示/非表示］を使い、一括表示には［校閲］タブから［ノート］、［すべてのノートを表示］へ進みます。 対象のメモを表示してから［ページ設定］を開き、［シート］タブの［コメント］で［シートに表示形式 (レガシー)］を選びます。

末尾にまとめたいのか、表の横で読める形にしたいのかを、操作に入る前にそろえるとよいです。受け取った手順書に表示位置で出す説明がある場合も、今回の受け渡しの目的と合うかを確かめます。

4．紙の表と注釈の対応を確かめる

ここからは当社の整理です。

例として、備品の配布表に確認のやり取りが残っている場面を考えます。表本体の見た目だけで配布を決めず、確認の対象と末尾の内容を対応させて読みます。照合の観点は、次のように整理できます。

表の中の項目末尾の内容と照合する点
品目どの品物についての照会かを取り違えていないか
配布先担当への問いと返答が同じ対象を指しているか
備考保留の内容と、配布時に伝える補足が食い違っていないか

読む順番は、渡す表を確かめ、注釈が付いた箇所を拾い、末尾の内容を読み戻す流れにします。返信や解決済みの内容も渡す必要がある場合は、元のブックのやり取りと出力内容を照合し、必要な記録が載っているかを確かめます。紙だけを渡された人が対象を見つけられるかを基準にすると、印刷した本人には分かるが受取人には伝わらない箇所を探せます。

やり取りがあることと、担当者の判断が済んでいることは分けて扱います。問い合わせ中の内容が残っている場合は、保留のまま渡すのか、確認を終えてから配布するのかを担当者が判断します。紙に載ったことを、承認された印として扱わない運用にします。

社内向けの照会や配布先に不要な書き込みも、渡す内容に含めるかを点検します。省きたい文章を見つけた場合は、受取人と目的を整理してから、元のやり取りをどう扱うかを担当者に確認するとよいです。印刷の都合だけで記録の意味を変えないようにします。

5．引き継ぎには出力目的と確認結果を残す

印刷を引き継ぐときは、対象の表、受取人、注釈を渡す目的、照合を終えたかを短く残します。操作の入口だけを書いた説明より、どの状態を完成とみなすかが分かる記録のほうが、担当交代時の判断に使えます。

仕上がりが想定と違うときは、対象の表を取り違えていないか、注釈の種類は合っているか、出したい位置と選んだ設定は一致しているか、という順に戻ります。原因が分からない段階で文章を書き写すより、どの段階まで合っているかを分けて記録すると、引き継ぐ相手にも状況が伝わります。

配布する前には、紙の表と末尾の内容を続けて読み、必要な補足があるか、渡す相手に不要な内容がないかを見直します。表の見やすさと、確認のやり取りを共有する範囲は、別の観点として点検する形です。

この作業をAIで減らすことを考えるなら、印刷操作、注釈の内容確認、配布の判断を分けて、事務でAIを使う進め方を考えるとよいです。どの内容を紙に残すかを人が決める箇所として整理すると、検討する作業の範囲が見えてきます。
