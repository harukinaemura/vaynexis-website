代表者事項証明書の請求後に処理が進まないときの確認と照会先

要点

代表者事項証明書の請求後に処理が進まない場合、詳しい進捗の確認先は請求先の法務局です。審査のため、通常の登記事項証明書より処理に時間がかかる場合があります。受付を待っている状態か、表示の更新の問題かを分け、問い合わせる内容をそろえます。

公開：2026年11月16日／情報の確認日：2026年11月16日（出典はこの記事の最後）

代表者事項証明書の処理表示が進まず、受取予定を決められないときは、審査の進捗と画面の更新を分けて確認します。請求先の法務局と操作サポートデスクへの問い合わせ内容を整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月16日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

照会前後の引継ぎ表は、画面の表示・窓口の回答・社内の対応を分けて残すために当社がまとめたもので、法務局の様式ではありません。

  1. 審査があることと、画面の表示名を分けて見る
  2. 「到達・受付待ち」は、送信した日時と合わせて確かめる
  3. 更新できないときは、送信時の利用者情報と照会方法を確認する
  4. 進捗を尋ねる窓口と、操作を尋ねる窓口を分ける
  5. 当社が提案する、照会前後の引継ぎの残し方
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．審査があることと、画面の表示名を分けて見る

確認日：2026年11月16日

法務省の FAQ では、代表者事項証明書の交付請求は審査を行うため、通常の登記事項証明書の交付請求に比べて時間がかかる場合があると案内されています。前回の別の書類と同じ速さで進むことを前提にせず、今回の請求の控えと表示を見比べるところから始めます。

操作ガイドは、証明書請求の「処理中」と、証明書請求以外の「審査中」を区別しています。社内のメモでも、画面の文言は見えたとおりに写すとよいです。自分で言い換えた状態名だけを伝えると、相手がどの段階の話かを読み取りにくくなります。

照会の準備では、「表示が変わらない」という観察と、「処理が止まっているのではないか」という推測を分けておきます。見た時点の表示、送信した控え、前回見たときとの違いを並べると、確認したいことが明確になります。

2．「到達・受付待ち」は、送信した日時と合わせて確かめる

平日午後５時１５分を過ぎて、又は休日に申請・請求した場合は受付時間外となり、処理状況は「到達・受付待ち」から更新されません。その場合は、登記所の翌営業日の8:30以降に受け付けられます。送信の控えを見て、待っている間に受付時間が含まれていたかを整理するとよいです。

印鑑証明書・登記事項証明書の交付請求等、申請先で手数料計算等を行う手続は、申請先での受付後に手数料等を納付できるようになります。画面の状態と支払いに関する案内を別々に眺めず、同じ請求の情報として照合します。

問い合わせのメモには、送信した時刻だけでなく、最後に画面を確認した時刻も残しておきます。担当者が交代しても、どこまで確認済みで、どの時点から表示が変わっていないのかを追える形にします。受け取りたい日についても、社内の希望と窓口から得た回答を分けて記録すると、希望だけが確定した予定として伝わることを避けやすくなります。

3．更新できないときは、送信時の利用者情報と照会方法を確認する

かんたん登記・供託申請では、表示が更新されない場合に「最新の処理状況に更新」ボタンを押す手順が案内されています。送信時と違う ID でログインして更新しても、その申請の処理状況は更新されません。申請用総合ソフトを使っている場合は、申請者IDが送信時と一致しているのに状況が変わらなければ、データフォルダの構成を手作業等で編集していないことを確認した上で、サポートデスクへ問い合わせます。

送信した方法を、後から取り違えない

かんたん登記・供託申請から送信した申請・請求の処理状況は、申請用総合ソフトでは照会できません。同僚に確認を引き継ぐ際は、送信に使った方法も控えに含めます。単に「オンラインで送った」と伝えるだけでは、同じ案件を確認するための入口がそろいません。

かんたん登記・供託申請で、申請用総合ソフト等から送った案件や、利用中とは別の申請者IDから送った案件を検索する場合は、申請番号と処理状況確認番号の両方が必要です。その検索で使えるのは、手続の状況の表示と内容確認アイコンのみです。申請番号と処理状況確認番号は申請者に確認するもので、法務省・法務局では調べることができません。

社内で共有する控えは、誰が送信したかまで追えるようにし、見つからない情報を確認する相手を決めておきます。照会できる担当者が不在のまま、別の担当者が同じ操作を繰り返す状態を避けるための準備です。

4．進捗を尋ねる窓口と、操作を尋ねる窓口を分ける

公式の問い合わせ案内では、システムの操作に関する質問と、法務局の業務内容に関する質問で問い合わせ先が異なります。代表者事項証明書の作成は請求先の法務局が行うため、詳細な処理状況を確認する場合は、その請求先に照会します。問い合わせでは、表示された文言に加え、何を確認したいのかを短くまとめて伝えるとよいです。

登記・供託オンライン申請システム操作サポートデスクは、メールフォーム又は電話で問い合わせを受け付けています。メールフォームで問い合わせる内容は、利用環境等を含めて、できるだけ具体的に記載するよう案内されています。操作のどこで困るのか、表示された内容は何かを、推測と混ぜずにまとめます。

証明書の交付請求が「中止/却下」になった場合、その理由は「処理状況表示」画面などの「お知らせ」に掲載されます。待ち時間だけで対応を決めず、届いている案内も読んでから確認事項を整理するとよいです。書類の使い方などに法的な判断が伴う点は、公式資料と手元の書類を示して専門家に確認します。

5．当社が提案する、照会前後の引継ぎの残し方

照会の引継ぎについて当社が提案するのは、画面で見た事実、窓口の回答、社内で決めた対応を分けて残す方法です。次の表は担当分けの整理で、公式の様式ではありません。

誰がいつ用意するもの・残す内容
送信担当照会の前送信の控え、現在の表示、表示を見た日時
照会担当問い合わせの前尋ねたい内容、連絡する相手、社内の希望日
照会担当回答を受けた後回答内容、回答日時、次に確かめる事項
引継ぎ先再確認するとき前回の回答、自分が行う作業、結果を戻す相手

回答のメモでは、窓口から言われた内容と、担当者がそう受け取ったという解釈を分けます。追加で尋ねたい点が残った場合は、回答済みの事項を消して書き直すより、残った問いを追記する形が扱いやすくなります。

また、照会をした担当者と、その後の受け取りを進める担当者が違う場合は、回答を渡す相手まで決めておきます。連絡済みという記録だけで終えず、回答を受けて次に動く人が内容を読める場所にまとめる段取りです。希望した日に間に合うかを社内で相談する際も、窓口の回答と自社の予定を分けた記録を使うとよいです。

当社では、事務の手間を洗い出す際、照会そのものに加え、控え探しや回答の引継ぎも事務作業の棚卸しの対象として整理します。
