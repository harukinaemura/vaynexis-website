Excelで画面にあるセルの枠線を紙にも印刷する設定と確認順

要点

画面にあるセルの枠線を紙にも出すには、［ページ レイアウト］の［シートのオプション］で、［枠線］の［印刷］をオンにします。設定後は紙面の見え方を確かめ、記入用の空欄まで区切りが続いているかを見ます。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、画面では見えるExcelの枠線が紙に出ないことに困っている小さな会社の担当者が、印刷の設定、空欄まで線を出す条件、塗りつぶしで線が消える場合を、印刷プレビューで確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 画面の薄い線と、セルに付けた罫線を区別する
  2. 印刷するシートを選び、枠線の印刷をオンにする
  3. 紙で記入する空欄まで線を出すには
  4. 一部の線だけ消えるときは、塗りつぶしを見る
  5. 設定できない場合と、設定後も出ない場合を分ける
  6. 紙の記入欄と、引き継ぐ確認事項をそろえる
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．画面の薄い線と、セルに付けた罫線を区別する

確認日：2026年11月13日

この記事は公式ヘルプの Windows 向け手順を扱い、その適用先は Excel for Microsoft 365、Excel 2024、Excel 2021 です。適用先に Mac 版は挙がっていないため、Mac の画面はこの記事では扱いません。

セル間に表示される薄い線が枠線で、表示についての公式ヘルプでは「目盛線」とも呼ばれています。枠線は既定では印刷されないため、画面で見えていても、紙に出す設定を別に行います。

一方、セルに適用した罫線は、印刷したページに表示されます。全体の区切りが消えたのか、特定の欄の線だけを整えたいのかを先に見分けると、直す場所を絞れます。

なお、Excel for the web では枠線の印刷がサポートされていませんが、罫線を適用することで枠線を模倣できる、とヘルプは説明しています。使っている画面の種類を確認してから、対象の操作へ進む流れです。

2．印刷するシートを選び、枠線の印刷をオンにする

最初に、印刷するワークシートを選択します。似た表が並ぶファイルでは、内容と用途を見て対象を決めます。見えている表だけでなく、印刷したい表を選べているかが出発点です。

チェックを入れる場所

選んだシートで［ページ レイアウト］タブを開き、［シートのオプション］内の［枠線］の下にある［印刷］にチェックを入れます。「線が見えるか」という記憶だけで済ませず、紙へ出す指定の状態を見ます。

チェック後に紙面の見え方を開く

続いて［ファイル］タブから［印刷］を選びます。枠線がどのように出るかは、［印刷プレビュー］で確認できます。確認するのは、項目名と明細の間、明細どうしの間、表の末尾です。文字が読めるかに加えて、どの内容がどの欄に属するかを追えるかも見ます。

3．紙で記入する空欄まで線を出すには

枠線は、ワークシート内の実際のデータの周囲にだけ印刷されます。入力済みの部分に線が出ても、後で手書きする欄まで出るかは別に確認することになります。紙面の終わりを、文字の終わりだけで判断しないのが要点です。

空のセルの周囲にも枠線を出す場合は、そのセルを含む印刷範囲を設定する必要があります。対象を選んだ後、［ページ レイアウト］の［ページ設定］グループで［印刷範囲］、［印刷範囲の設定］の順に選びます。

選ぶ対象には、記入欄の右端や下端まで含める考え方です。文字がある位置と、用紙として使いたい位置を見比べると、記入する余地を残せているか判断できます。

空欄の区切りには、セルの周囲に罫線を適用する方法もあります。空欄に何を書くか、周囲と同じ区切りでよいかを決めてから、表の仕上がりを確認します。

4．一部の線だけ消えるときは、塗りつぶしを見る

塗りつぶしの色を適用したセルでは、枠線が表示も印刷もされなくなります。色を白に変更しても、枠線は非表示のままです。白く見える欄についても、見た目の色だけでは判断を終えないようにします。

塗りつぶしの色を残したまま区切りの線を表示するには、目盛線の代わりに罫線を使います。色に意味を持たせた表では、線を出すために色を取り除いてよいかも考えます。読み手が色を目印にしているなら、その役割も含めて仕上がりを判断するためです。

特定のセルやセル範囲の周囲を区切る場合は、定義済みの罫線のスタイルを使って罫線を追加できます。

5．設定できない場合と、設定後も出ない場合を分ける

チェック欄が淡色になっている場合

［シートのオプション］のチェック欄が淡色の場合は、グラフ、イメージ、その他のオブジェクトを選択している可能性があり、選択を取り消すと使用できるようになります。

印刷前の表示にも線が出ない場合

印刷した紙や［印刷プレビュー］に枠線が出ないときは、［下書き品質］が選択されていないかを確認します。［ファイル］から［印刷］、［ページ設定］へ進み、［シート］タブの［下書き品質］がオンなら解除します。

それでも正常に印刷されない場合は、プリンタードライバーに問題がある可能性があります。紙面のどの部分で線が消えるか、印刷前の表示にも同じ症状があるかを分けて記録すると、問い合わせる際の説明が具体的になります。

紙面の区切りを確認し終えたら、［印刷］ボタンを選んで出力します。

6．紙の記入欄と、引き継ぐ確認事項をそろえる

ここからは当社の整理です。

備品の点検用紙なら、印字する内容と、その場で記入する欄を分けて考えます。次の表の「点検結果」は空欄で配り、紙に書き込む想定です。

品名置き場所点検結果
書類ケース受付棚
延長コード会議室

見比べる場所は、文字が入った欄と記入用の空欄の境目です。品名と置き場所に区切りがあっても、結果を書く場所が隣の行とつながって見えないかを確かめます。下端まで視線を移し、末尾の記入欄にも書く場所があるかを見るとよいです。

引き継ぎでは、印刷する表の名前、手書きで残す欄、線が出なかった位置を短く残します。全体で線が消える状態と、色を付けた欄だけで線が消える状態を区別しておくと、次の担当者が確認する場所を把握しやすくなります。

この作業を AI で減らすなら、繰り返している印刷前の点検と、人が紙面で判断する箇所を分け、事務での AI 活用の進め方につなげて整理するとよいです。
