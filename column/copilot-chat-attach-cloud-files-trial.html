Copilot Chatの「クラウド ファイルの添付」で試す資料を指定するには

要点

OneDrive などのクラウドにあるファイルを Copilot Chat の依頼文に添えるには、［クラウド ファイルの添付］を選びます。ファイルだけでなく、フォルダー全体を添付することもできます。 入力欄に「/」と打ってファイル名を入れ、出てきた候補から選ぶ方法もあります。 AI の使い方を社内で試す段階では、Copilot に資料を探させるのではなく、試す資料をこちらで1〜2点に絞って渡すと、答えのどこが資料に基づくのかを確かめやすくなります。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Copilot Chat を社内で試してみたものの、答えがどの資料をもとにしているのか分からず、良し悪しを判断しにくい。試す資料を自分で選んで添付する方法と、ライセンスの有無で変わる範囲、渡す前に見るファイルの形と権限を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

試す資料の選び方の表や依頼文の例は、中小企業の試行を想定して当社が作った架空のもので、Microsoft の案内そのものとは分けてお読みください。

  1. 誰が、どの画面で使うか
  2. 資料を渡す3つの方法
  3. 渡す前に、ファイルの形と権限を見る
  4. 試す資料をどう選ぶか（当社の見方）
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．誰が、どの画面で使うか

確認日：2026年11月17日。

対象は、職場または学校のアカウントでサインインして使う Microsoft Copilot Chat です。職場または学校のアカウントでは、Copilot Chat は Web だけでなく、チャット、メール、ファイルなど組織のデータを使います。 Copilot の新しいホームは展開中のため、表示がヘルプの説明と違う場合がある、と注記されています。

参照できる範囲は、Microsoft Copilot のライセンスの有無で変わります。

使っている人ヘルプの説明（要約）
Microsoft Copilot のライセンスがある人Work IQ がオンのとき、ファイルへのリンクのほか、人、予定表の会議、メールなども参照できる
ライセンスがない人（Copilot Chat の利用者）参照できるのはファイルだけ

ライセンスがない人でも、IT 管理者が許可していれば、Copilot は Web で公開されている情報を参照できます。 自分の画面で何が使えるかは、ライセンスと会社の設定によって違うため、画面に出ない項目は社内の管理者に確かめます。社内資料の参照そのものを止める切り替え（Work IQ）は、ここでは扱いません。

2．資料を渡す3つの方法

方法操作向いている場面（架空の例）
クラウド ファイルの添付［OneDrive］のアイコンの［クラウド ファイルの添付］を選ぶ試す資料をまとめたフォルダーごと渡す
「/」で指定「/」と打ってファイル名を入力し、候補から選ぶ名前の分かっている1つのファイルを渡す
手元のファイルのアップロード作成ボックスのプラスのアイコンから画像やファイルをアップロードするまだクラウドに置いていない資料を渡す

ヘルプには、「/」を打つ以外に、コピー アンド ペーストやドラッグ アンド ドロップでファイルを参照できるとも書かれています。 手元のファイルをアップロードした場合は、選んだファイルのコピーが OneDrive に保存されます。 社外秘の資料を試しに上げると、自分の OneDrive に写しが残ることになるので、後で消すかどうかも決めておきます。

候補に出てくるファイルは、OneDrive for Business で最近アップロードしたり、開いたり、変更したり、共有したりしたものなどの動きをもとに選ばれます。ヘルプでは、こうした操作の数分後に使えるようになる、と説明されています。 保存したばかりのファイルが候補に出ないときは、少し待ってから探し直します。

3．渡す前に、ファイルの形と権限を見る

職場および学校の Copilot（ライセンスあり）で使えるファイル形式は、ヘルプに一覧があります。文書は .docx、.doc、.pdf、.txt など、表計算は .xlsx、.xls、.csv などです。 形式が合わないときは、Word の .doc を .docx として保存し直すなど、使える形式に変えるよう勧めています。

ファイルへのアクセス許可がない場合や、アクセスが制限されている場合は、Copilot がアップロードを止めることがあります。 渡せないからといって、ファイルの共有の設定を広げて回避するのは避けます。試すために権限を変えるかどうかは、資料の持ち主と相談して決めることです。

長い文書や大きな PDF、数式の多い表は、小さく分けて別々に渡すことも勧められています。 SharePoint のサイトを選んだ場合は、サイトの中で参照できるのは最大 10 個のファイルまたはページです。

4．試す資料をどう選ぶか（当社の見方）

業務の棚卸しを終えた中小企業が、AI を試す場面を考えます。ライセンスがあり、特定のファイルを指定しない場合、Copilot は応答に最適なデータ ソースを自分で選びます。 便利な反面、試した結果を見比べるときに「どの資料を見て答えたのか」が分かりにくくなります。試す段階では、資料を明示して渡すほうが、答えを確かめる手間が少なくて済みます。

試すこと（架空の例）渡す資料答えを確かめる人
受注の手順書の抜けを洗い出す受注の手順書（Word）1点受注の担当者
よくある問い合わせへの答え方の案を作る過去の問い合わせの一覧（Excel）と回答の決まり（Word）窓口の担当者
棚卸しの聞き取りメモを表にまとめる聞き取りメモのフォルダー聞き取りをした人

依頼文も、資料と同じくらい大切です。ヘルプでは、必要なものを明確、簡潔、具体的に示すよう勧めています。 また、よい依頼文にはふつう、目標、対象、詳細、データの要素が含まれる、と表で示されています。 添付した資料は、このうちの「データ」にあたります。たとえば「添付した受注の手順書を読み、新しく入った人がつまずきそうな所を、手順の番号つきで挙げてください。手順書に書かれていないことは推測せず、分からないと書いてください」のように、目標と答え方の条件を添えます。

渡した資料の名前と、依頼した文、確かめた人を短く記録しておくと、次に同じことを試すときに条件をそろえられます。資料をそろえて小さく試し、続けるかどうかを決めていく進め方は、AI 導入の相談のページでも紹介しています。

ヘルプには、Copilot で問題が起きる場合があるため、生成された内容を確かめることが大切だと書かれています。 資料に書かれていないことを答えていないか、資料の古い版を見ていないかを、担当者が原本と照らして確かめます。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□自分のアカウントにライセンスがあるか、参照できるのがファイルだけかを確かめたか
□試す資料を1〜2点（または1つのフォルダー）に絞ったか
□［クラウド ファイルの添付］か「/」で、資料を明示して渡したか
□手元のファイルを上げた場合、OneDrive に残る写しの扱いを決めたか
□ファイル形式が使えるものかを見たか（.doc は .docx に保存し直すなど）
□渡せない資料の共有の設定を、自分の判断で広げていないか
□渡した資料・依頼した文・確かめた人を記録したか
