Windowsで毎日使う業務フォルダーを固定してすぐ開くには

要点

毎日使う業務フォルダーは、クイック アクセスにピン留めして、そこから選べるようにできます。固定する前に正しい保存場所を確かめ、固定後は入口から開いた中身を照合します。担当者へ渡す情報には、表示名だけでなく保存場所と用途も残すとよいです。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、毎日使う業務フォルダーをすぐ開けるようにしたい小さな会社の担当者が、Windows のクイック アクセスへの固定と解除、開いた先の確かめ方、引き継ぎに残す内容を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 固定する前に、対象のフォルダーを確かめる
  2. 右クリックで固定し、入口から開き直す
  3. 業務に合わせて、入口を置く深さを決める
  4. 一覧が見えないときと、別の場所が開くとき
  5. 不要になった入口を外し、引き継ぎに残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．固定する前に、対象のフォルダーを確かめる

確認日：2026年11月10日。

キー操作の公式ヘルプの適用先は Windows 11 と Windows 10 です。画面操作は前者の説明に沿って紹介します。今回は保存場所を変えずに、既存のフォルダーへの入口を整える手順として進めます。

最初に、日頃の経路から目的のフォルダーを開きます。対象を選ぶときは、名前だけを見て済ませず、中にある書類と、その書類を置く業務上の目的を照らし合わせます。担当者の手元にある控えと、日々更新する保管先を取り違えていないかが確認の中心です。

保存場所を確かめる際は、エクスプローラーで Alt + D を押すと、アドレス バーを選択できます。表示された場所を、社内の手順書や管理担当者が案内している場所と比べます。場所が合っているか判断できない段階では、そのまま固定を進めず、現在の保管先を担当者に確かめるとよいです。

同名のフォルダーがあるときは、どちらを日々の作業に使うのかを先に整理します。入口を増やす前に利用先を決めておけば、後で表示された名前だけを頼りに選ぶ状態を避けやすくなります。

2．右クリックで固定し、入口から開き直す

エクスプローラーは、Windows ロゴ キーと E キーを同時に押して開けます。操作の対象は、毎日使う書類が入っているフォルダーです。固定したい場所の中へ入るだけでなく、右クリックする対象がそのフォルダーであるかを見ます。

対象のフォルダーを右クリックし、［クイック アクセスにピン留めする］を選択します。名称の似た別の項目を選ばないよう、操作前に選択中の名前を読み直すとよいです。

左側にあるナビゲーション ウィンドウは、フォルダーやドライブなどへアクセスする領域です。固定後は、用意した入口から目的の場所を開き直し、中の書類と保存場所を、固定前に確認したものと照合します。

一覧へ名前が加わったところだけで確認を終えると、似た名前の別の保管先を登録していても気づきにくくなります。書類を編集する前に、目的の場所へ着いたかまでを見て、操作の終わりとします。

3．業務に合わせて、入口を置く深さを決める

ここからは当社の整理です。

固定の対象は、普段どこまでたどってから仕事を始めるかで考えます。広い分類を入口にすると、その先で目的の場所を選びます。一方、細かな保管先を入口にすると、その用途が終わったときの見直しも必要です。使う場面と、保管先が入れ替わる頻度を合わせて考えるとよいです。

日々の使い方入口の候補選ぶ前に確かめること
共通の書式を取り出す書式の保管先配布用の正本か、個人の控えか
進行中の案件を更新する対象案件の保管先作業中の場所か、完了後の控えか
月ごとに資料を扱う月別の保管先をまとめた親の場所月が替わった後も同じ入口を使うか

たとえば、月替わりのたびに下の保管先が替わる業務では、月別の場所をまとめた親の場所を入口にする考え方があります。今扱う月へ直接入る形を選ぶ場合は、切り替え時に入口も見直す担当を決めておきます。どちらを選ぶかは、毎日の利用と切り替え時の確認を合わせた判断です。

社内で呼んでいる業務名と、画面に出るフォルダー名が違う場合は、その対応もメモに残します。表示名を変えるために元の保管先まで変更するのではなく、まず呼び方と場所の対応を共有する整理です。ほかの担当者が同じ場所を利用している業務では、保管先の変更は入口の整理と分けて扱います。

4．一覧が見えないときと、別の場所が開くとき

Microsoft のエクスプローラーのヘルプでは、Windows 11 で左側の一覧（ナビゲーション ウィンドウ）を非表示にしている場合、コマンド バーの［表示］を選び、［表示］、［ナビゲーション ウィンドウ］の順に選択するともう一度表示できると案内しています。

画面の左側に一覧そのものがない状態と、一覧はあるのに対象が見つからない状態を分けて見ます。前者では表示の状態を、後者では固定した対象と、探している名前を確認します。見当たらないからといって、すぐに元のフォルダーを移したり、同じ内容の場所を作ったりする流れにはしません。

入口から開いた中身が想定と違うときは、その場で書類を更新せず、普段の経路から開いた場所と照合します。同名でも、親に当たる場所や業務上の用途が違っていれば、目的の保管先とは限りません。登録した対象が違うのか、利用する保管先自体の案内が古いのかを分けて確認するとよいです。

なお、社内で案内されている経路からも目的の場所を開けない場合は、表示名と、たどった経路、画面に出た内容を管理担当者へ伝えます。入口の追加を繰り返す前に、元の場所を利用できる状態かを確かめるためです。

5．不要になった入口を外し、引き継ぎに残す

同じヘルプでは、不要になった固定は、対象を右クリック（または長押し）して［クイック アクセスからピン留めを外す］を選ぶと解除できるとしています。ここで行う作業は、日常の入口の見直しです。元の書類の廃棄や保管期間の判断は、社内の別の手順として扱います。

終了した業務や担当を離れた業務の入口については、日々開く必要があるかを確かめます。過去の資料を保存しておくことと、毎日の入口に残すことを分けて考えると、利用中の場所を選びやすい状態に整えられます。

引き継ぎでは、用途、画面に出るフォルダー名、実際の保存場所、保管先を確認する担当者を残します。表示された並び順だけを伝えるより、目的の場所へ到達したかを後任者が判断しやすい内容になります。画面を一緒に見る場合も、入口から開くところと、中の書類が想定どおりかを見るところまでを区切りにするとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□固定する対象が、日々の業務に使う保管先であることを確かめたか
□同名の控えや、完了後の保管先を取り違えていないか確認したか
□用意した入口から開き直し、中の書類と保存場所を照合したか
□一覧が見えない状態と、対象だけが見つからない状態を分けて確認したか
□月替わりや担当替えで、入口を見直す担当を決めたか
□後任者に用途、表示名、保存場所、確認先を残したか
