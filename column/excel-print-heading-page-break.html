Excelの印刷で見出しと明細が分かれるときの改ページ調整

要点

見出しと明細を同じ紙面に載せるには、改ページ プレビューで区切り位置を調整し、見出しの前から次ページを始める形にします。まず一緒に読みたい範囲を決め、調整後は前後の紙面で見出しと明細のつながりを確かめる流れです。

公開：2026年11月5日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelの表を印刷すると見出しだけが紙面の末尾に残る小さな会社の事務担当者が、改ページの位置を調整して前後の紙面を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 区切り線と見出しの位置を見比べる
  2. 見出しの行から次ページを始める
  3. 区分見出しと明細を一緒に送る例
  4. 指定が効かないときは設定を切り分ける
  5. 印刷する前に前後の紙面と引き継ぎを確かめる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．区切り線と見出しの位置を見比べる

確認日：2026年11月4日／挿入・移動・削除の手順は、公式ヘルプの Windows の欄の説明です（Web の欄は別の節で扱います）。

［表示］から［改ページ プレビュー］を開きます。この表示では、破線が自動の改ページ、実線が手動で追加した区切りを表します。

まず、紙面の末尾に見出しだけが残っていないかを見ます。見出しと、その下に続く明細の間に区切り線がある箇所を探すと、直したい場所を絞れます。表の最後まで眺め、同じように読みづらい箇所がないかも合わせて見ておくとよいです。

区切りを置く目標は、見出しのすぐ上です。余白を埋めることより、紙を受け取る相手が見出しから内容を続けて読めることを判断の中心に置きます。

2．見出しの行から次ページを始める

位置を指定して挿入する

次ページの先頭にしたい見出しの行を選び、右クリックして［改ページの挿入］を選択します。見出しも一緒に送りたいので、選ぶ対象は、その下の明細ではなく見出しの行です。行全体を対象にしているかを意識すると、どこから紙面を分けたいのかが明確になります。

ある区切り線を移動する

すでに表示されている区切り線を調整する場合は、線を目的の位置までドラッグします。見出しの直前へ位置を合わせた後は、前の紙面の終わりと次の紙面の始まりを続けて見ます。

挿入と移動のどちらを使う場合も、まず分断されていた箇所を直し、それから周囲を見直す進め方です。まとめて変更するより、どの区切りを何のために動かしたかを追いやすくなります。

3．区分見出しと明細を一緒に送る例

ここからは当社の整理です。

用具の一覧に、区分を示す見出しが途中に入っている場面を考えます。次の表は、上から下への並びを示す短い例です。

行の役割表に書かれた内容
区分の見出し点検用具
明細保護めがね
明細作業手袋

紙面の末尾に点検用具の見出しだけが残り、続きの紙面が保護めがねの行から始まっていたら、読みたいまとまりは見出しから下です。点検用具の行の直前を区切りの候補にします。元の表の並びは保ったまま、紙面の始まりをどこに置きたいかを考える例です。

読みやすさの確認では、見出しを送り出した側の紙面にも目を向けます。直前の区分の明細や確認欄が離れていないかまで見て、区切りを動かす範囲を決めるとよいです。

4．指定が効かないときは設定を切り分ける

位置の変更が反映されない

公式ヘルプでは、拡大縮小の［自動調整 横］オプションを使う場合は、任意指定のページ区切りが無視されると説明されています。手動の改ページを使うには、拡大縮小印刷を［拡大/縮小］へ変更します。区切り線を何度も動かす前に、位置の指定と印刷の設定のどちらを見直す段階かを切り分けます。

線をつかんでも動かせない

区切り線をドラッグできない場合は、セルのドラッグ アンド ドロップ機能が有効かを確かめます。動かないという結果だけで、見出しを移す行が間違っていると判断しないようにします。

不要な区切りを消したい

手動の改ページは、区切り線をプレビュー領域の外へドラッグして削除できます。自動の改ページは削除できません。線を消すことを目的にせず、残したいまとまりに合う位置かどうかから考えます。

ブラウザーで操作している

公式ヘルプの Web の欄では、Excel for the web のブックには改ページを追加できないと説明されています。追加する場合は、デスクトップ版で表を開いて操作します。

5．印刷する前に前後の紙面と引き継ぎを確かめる

公式ヘルプでは、印刷されたページの見え方は、［ファイル］から［印刷］を開く印刷プレビューで確認できると案内されています。移動した見出しの下に、意図した明細が続いているかを見ます。前の紙面の末尾に別の見出しだけが残っていないかも、合わせて確かめるとよいです。

見出しの下に明細が続いていても、まとめたい範囲の途中で再び分かれていないかは別の確認です。区分全体を同じ紙面に載せたいのか、見出しと明細の冒頭を一緒に読めればよいのかを決めてから、印刷結果を評価します。入りきらないまとまりは、内容のどこで分けると読み手が続きを追えるかを考える段階です。

保存したファイルを別のプリンターで印刷すると、改ページや文字の間隔が変わることがあります。配布に使う出力先で試し刷りし、画面で見ていたまとまりと読みやすさを確かめる進め方もあります。

引き継ぎには、どの見出しから紙面を始めたいか、どこまでの明細を一緒に読みたいかを短く残します。単に印刷を調整済みとだけ残すより、後から明細が増えた際に、見直す対象を判断しやすくなります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□同じ紙面に残したい見出しと明細の範囲を決めたか
□区切りが見出しと明細の間に入っていないかを確認したか
□見出しの直前から紙面が始まる形に調整したか
□調整した箇所の前後で、別のまとまりが分断されていないか確認したか
□末尾まで必要な明細が残っているかを確認したか
□配布に使う出力先で紙面の見え方を確かめたか
□引き継ぐ相手に、区切り位置を決めた理由を伝えたか
