CopilotやGeminiに社内ファイルを使わせる前に｜共有の範囲を見直す順番

要点

Microsoft CopilotやGoogle WorkspaceのGeminiは、使う人が閲覧できる社内のファイルやメールを材料に答えます。権限のないファイルは使いませんが、裏を返すと、共有の範囲が広すぎるファイルは、その人が探したことがなくても答えの材料になり得ます。使い始める前に、人事・給与・取引条件などの資料を誰が開けるかを確かめ、広すぎる共有を直してから使い始めます。

公開：2026年11月11日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、Microsoft 365 や Google Workspace を使っている小さな会社が、Microsoft Copilot や Gemini を社員に使わせる前に、ファイルの共有の範囲をどの順番で見直すかをまとめたものです。

Microsoft と Google の公式の説明を2026年11月10日に確かめました。製品の名前・機能・管理画面は変わることがあり、契約しているプランで使える管理機能も違います。使う前に各社の最新の説明で確かめてください。

見直しの順番と表の目安は、説明のために当社がまとめたもので、MicrosoftやGoogleが示している手順ではありません。

  1. 使う人が開けるファイルは、AIの答えの材料になる
  2. Microsoft 365は、共有リンクの種類でAIの対象が変わる
  3. Googleドライブは「一般的なアクセス」と共有相手を見る
  4. 見直す順番：中身の重い資料の置き場所から
  5. 使い始めた後も、共有を作るたびに同じ点を見る
  6. 確認表
  7. 自社のフォルダの構成に合わせて見直したいとき

1．使う人が開けるファイルは、AIの答えの材料になる

Microsoftの説明によると、Microsoft Copilotは、Microsoft Graphを通じて、メール・チャット・アクセス権限のあるドキュメントなどの組織のデータを使って答えを作ります。そのうえで、個々のユーザーが少なくとも表示のアクセス許可を持っている組織データだけを表示すると書き、適切なユーザーやグループが適切なコンテンツにアクセスできるよう、アクセス許可の仕組みを使うことが重要だとしています。

Googleの生成AIのプライバシー ハブも、Geminiは、ユーザーにアクセス権限がないWorkspace内のコンテンツにはアクセスせず、アクセス権限がある関連コンテンツに、プロンプトに応じてアクセスすると説明しています。ユーザーがドキュメントやメールにアクセスできない場合、Geminiはその内容を取得しない、とも書かれています。

どちらも、AIが権限を越えて読むわけではありません。ただ、これまでは「場所を知らないので開いたことがない」ファイルでも、AIに質問すれば内容が答えに入ることがあります。当社では、AIを入れる準備を「AIの設定」より先に「今の共有の範囲が意図どおりかの確認」から始める形を提案します。

入力した内容やファイルが学習に使われるかは別の問いです。Microsoftは、Microsoft Graph経由でアクセスされるプロンプト・応答・データは基礎となる大規模言語モデルの学習に使わないと書き、Googleも、許可なくドメインの外で生成AIモデルの学習に使わないと書いています。学習と保存の設定の確かめ方は、関連する記事にまとめています。

2．Microsoft 365は、共有リンクの種類でAIの対象が変わる

Microsoft Learnの「共有可能なリンクのしくみ」は、OneDriveとSharePointの共有リンクを3種類に分けて、Copilotとの関係も説明しています。

リンクの種類開ける人Copilotとの関係（Microsoftの説明）
すべてのユーザーリンクを持つ人なら誰でも。サインインは不要で、アクセスの監査はできないリンクを作っただけでは、検索結果やCopilotの対象にならない。リンクを開いた（引き換えた）人が対象になる
組織内のユーザー組織のメンバーだけ（ゲストは不可）作っただけでは対象にならない。ただし、OneDrive・SharePointの画面、Outlookのメール、Teamsのチャットで個人あてに送ると、受け取った人について自動で引き換えられる（上限100人）
特定のユーザー共有するときに指定した人だけ指定した人とセキュリティ グループのメンバーにとって、検索結果に出て、Copilotからアクセスできるようになる

つまり、名前を指定して共有した相手と、リンクを一度でも開いた人にとっては、そのファイルは答えの材料になり得ます。「昔、全員に送った給与の資料のリンク」のように、送った側が忘れている共有ほど見直しの対象です。

Microsoftは、Copilotの展開ガイダンスで「オーバーシェアリング（過剰な共有）を修復する」を3つの柱の1つに置き、リスクの高いサイトとファイルを見つけ、必要に応じて暫定的にアクセスを制限し、アクセスの問題を直す管理者の作業を挙げています。どの管理機能が使えるかは契約によって違うので、管理者の画面と契約内容で確かめます。

3．Googleドライブは「一般的なアクセス」と共有相手を見る

Googleドライブのヘルプは、リンクで共有するときの「一般的なアクセス」を次のように説明しています。「制限付き」はアクセス権を付与されたユーザーだけが開けます。「リンクを知っている全員」はインターネット上でリンクを知っている全員が開け、Googleアカウントへのログインは要りません。仕事用のアカウントでは「組織」を選ぶと、管理者が許可した共有レベルに基づいて、組織内のすべてのユーザーがファイルにアクセスできます。

誰が開けるかは、アイテムを右クリックして［ファイル情報］→［詳細］を選び、右側の詳細パネルの［アクセスを管理］で確かめます。共有をやめるときは、共有メニューで相手の名前の横の下矢印から［アクセス権を削除］を選びます。仕事用アカウントでは、共有に有効期限を付けることもできます。

Googleのプライバシー ハブは、人事や財務のドキュメントなどへのGeminiのアクセスを制限したいときの方法として、ダウンロード・コピー・印刷を無効にするInformation Rights Management（IRM）やクライアントサイド暗号化などの制限を挙げています。IRMでダウンロード・印刷・コピーを許可されていないユーザーについては、Geminiがそのファイルや内容を取得しないと説明しています。使えるかどうかはエディションで違うので、管理コンソールで確かめます。

4．見直す順番：中身の重い資料の置き場所から

すべてのファイルを一度に見直すのは大変です。当社では、漏れたときの影響が大きい資料の置き場所から先に見る順番を提案します。

  1. 人事・給与・健康に関する情報・評価・取引条件・顧客名簿などの置き場所（フォルダ・サイト・共有ドライブ）を書き出す
  2. その置き場所を開ける人を、管理の画面で確かめる
  3. 「すべてのユーザー」「リンクを知っている全員」のリンクを止めるか、期限を付ける
  4. 退職した人・異動した人・社外の相手に残っている権限を外す
  5. 試しに使う人を数人決め、その人が開けてはいけない資料の名前や中身で質問し、答えに出てこないかを確かめる
資料の種類開けてよい人の目安見直しで見る所
給与・評価・人事の記録担当者と決裁者部署全体や組織全体のリンクが残っていないか
健康診断・休職などの記録担当者に限る共有フォルダの中に個人のファイルが混ざっていないか
取引条件・見積の内訳その取引の担当者と上長社外の相手との共有が取引の終了後も残っていないか
顧客名簿使う業務の担当者「リンクを知っている全員」の設定になっていないか

5番目の確かめ方は、AIの答えだけを見て安心するためではなく、2〜4番目の見直しに漏れがないかを探すためのものです。出てきてしまった資料があれば、その置き場所の共有に戻って直します。

5．使い始めた後も、共有を作るたびに同じ点を見る

一度見直しても、新しい共有は毎日作られます。Microsoft Learnは、共有オプションを管理する記事として、サイトの既定の共有リンクの種類を変える方法も案内しています。Googleドライブでも、仕事用のアカウントでは管理者が外部とのリンクの共有を制限している場合がある、と書かれています。会社の既定の設定を狭いほうに寄せておくと、一人ひとりの判断に頼る部分が減ります。

当社では、次の3つを社内の決まりにしておく形を考えます。

  • 社内の資料を共有するときは、できるだけ相手の名前を指定し、「全員」のリンクを使うときは期限を付ける
  • 退職・異動の手続の中に、その人が作った共有と、その人に付いている権限の確認を入れる
  • 人事・給与などの置き場所の共有相手を、決まった時期に見直す

AIを使ってよい業務や入力してよい情報は、社内ルールで決めておきます。社員に何を伝えるかは、研修の記事にまとめています。

6．確認表

CopilotやGeminiを社員に使わせる前に、この表で確かめます。

確認確かめること
□人事・給与・健康情報・取引条件・顧客名簿の置き場所を書き出したか
□その置き場所を開ける人を、管理の画面で確かめたか
□「すべてのユーザー」「リンクを知っている全員」のリンクを止めるか、期限を付けたか
□退職した人・異動した人・社外の相手に残っている権限を外したか
□試しに使う人が、開けてはいけない資料について質問し、答えに出てこないことを確かめたか
□契約しているプランで使える管理機能（アクセス制限・ラベル・IRMなど）を、各社の最新の説明で確かめたか
□共有を作るときと退職・異動のときの決まりを、社内ルールに書いたか

7．自社のフォルダの構成に合わせて見直したいとき

見直す資料の一覧づくりや、確かめる順番、社内の決まりの文面まで、今のフォルダの構成に合わせて形にしたい場合は、当社のように、手順と確認の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

CopilotやGeminiを入れるかどうかから相談したい場合は、初回無料相談をご利用ください。情報が漏れないことの約束や、法律の判断は行いません。
