Chromeの「この種類のファイルは常に開く」を解除するには

要点

ダウンロード後に自動で開く動きを止めるには、Chromeの最近ダウンロードしたファイルを右クリックし、［この種類のファイルは常に開く］がオンならオフにします。解除後は対象と同じ形式のファイルで、保存の完了と、自分で開く操作を分けて確かめるとよいです。

公開：2026年11月16日／情報の確認日：2026年11月16日（出典はこの記事の最後）

ダウンロード完了のたびに書類が開くなら、Chromeの「この種類のファイルは常に開く」のチェック状態から確認します。

公式ページ・公式ヘルプなどの一次資料を2026年11月16日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 保存が終わった直後に開く動きを対象にする
  2. 最近ダウンロードしたファイルからチェックを外す
  3. 手動で開く操作や履歴の削除と混同しない
  4. 事務では「保存してから中身を確認する」順をそろえる
  5. 解除後の確認結果を、次の担当者が読める形で残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．保存が終わった直後に開く動きを対象にする

確認日：2026年11月16日。対象：Windows版Chrome（パソコン向け）。

資料を保存しただけなのに画面が切り替わると、保存先を確かめる前に別の作業が始まってしまいます。止めたい動きを整理するには、書類が表示される直前に、自分がファイルを選んだかを振り返るところから始めます。

Googleのパソコン向けヘルプでは、特定のファイル形式が自動的に開く場合の対処として、最近ダウンロードしたファイルから自動表示をオフにする手順を案内しています。

当社では、困っている場面を、保存の完了を待っている間と、保存した書類を自分で開いた後に分けて記録すると、引き継ぐ相手にも目的が伝わりやすいと考えます。「書類が開くのを止めたい」だけでは、どの場面を変えるのかが曖昧です。操作前に、保存の完了後は書類を開かず、後から必要なときに開きたい、と目的を書き留めておきます。

2．最近ダウンロードしたファイルからチェックを外す

対象の書類を保存し、完了を待つ

Chromeを開いて、ファイルの配布元に移動します。ダウンロードが完了したら［最近のダウンロード履歴］を選び、最近ダウンロードしたファイルを右クリックします。

操作の前に、止めたい動きが起きた書類の名前を控えておくと、別の書類を選ぶ取り違えを避けやすくなります。仕事の資料が並んでいるときは、見覚えがある名前だけで判断せず、今保存した対象と照らし合わせるとよいです。

チェックが付いている場合にオフにする

右クリックして表示される［この種類のファイルは常に開く］のチェックボックスがオンになっていたら、オフにします。

ここでは、変更前の状態も記録の対象にします。チェックが付いていたかを確認せずに操作を続けると、後から同僚へ説明するときに、何を変えたのか分からなくなります。すでにチェックが外れていた場合は、その状態を残し、同じ項目を繰り返し切り替える前に、書類が開いた場面を見直すとよいです。

なお、最近ダウンロードしたファイルは、アドレスバーの右側に表示されます。書類の中身が開いたのか、保存したファイルの一覧が見えたのかも、観察するときの区別になります。

3．手動で開く操作や履歴の削除と混同しない

ファイル名をクリックした後の表示

ダウンロードのリストでファイル名をクリックすると、そのファイル形式に関連付けられた既定のアプリケーションで開きます。

解除の結果を確かめる際は、保存を終えて待つ場面と、自分でファイルを選ぶ場面を分けます。確認中に書類を開く操作まで続けてしまうと、「何もしていないのに開いた」という状態と区別しにくくなります。確認する人は手を止めて観察し、開いた場合には直前に何をしたかも残すとよいです。

履歴から消す操作

ダウンロードの履歴からファイルを削除しても、パソコン内のファイルは削除されません。履歴の整理と、自動で開く動きを変える作業は、目的を分けて扱います。画面を片付けるために履歴を消す前に、対象の名前や変更前の状態を記録しておくと、担当者が確認を引き継ぎやすくなります。

また、GoogleはPDFを端末にダウンロードするかChromeで開くかを選ぶ設定も、別の項目として案内しています。困っている場面がどこかを確認し、関係のない設定まで続けて変えない進め方にすると、変更の理由を説明しやすくなります。

4．事務では「保存してから中身を確認する」順をそろえる

受け取った資料を、内容の確認前に保存先や名前で整理したい場面を考えます。当社では、すぐに中身を読み始めるかどうかを担当者ごとに任せるより、どの段階で確認するかを共有することが大切だと考えます。設定の変更そのものと、仕事の手順を混ぜずに書き分けるとよいです。

確認する場面架空の確認例引き継ぎに残す内容
保存直後保存を終えて、書類が自動で開くかを見るファイルの形式と開いたタイミング
整理するとき保存した名前と置き場所を確かめる中身を読む前に済ませたい整理
内容を読むとき担当者が必要な書類を選んで開く自分で開く操作をしたこと

この例で確かめたいのは、画面の見た目だけではなく、担当者の意図した順番で作業できるかです。保存したことを確認する担当と、内容を読む担当が違う場合は、どこまで済ませたかも引き継ぎに含めます。

5．解除後の確認結果を、次の担当者が読める形で残す

確認には、仕事で扱ってよい内容の書類を用い、対象と同じ形式で保存直後の様子を見ます。自動で開かなかったことと、ファイル自体を見つけられることは分けて記録するとよいです。書類を開く操作まで済ませた場合には、その前後が分かるように残します。

思った動きにならなかったときは、「直らなかった」だけで終えず、どの書類で、どの操作の後に、何が表示されたかを書き留めます。チェックの状態、対象の書類、表示された場面を合わせて残すと、次の担当者が同じ操作をむやみに繰り返さずに済みます。設定項目が見当たらない場合も、別の場所を推測して変更する前に、見えている項目を記録して担当者へ引き継ぐとよいです。

引き継ぎ用の説明には、変更前の困りごと、変えた項目、変更後に確かめた動き、確認に使った書類の種類を含めます。画面の画像を添えるなら、業務上共有してよい範囲に整えることも必要です。結果をまだ確かめていない場合は、操作を終えたことと、確認が残っていることを分けて伝えます。

事務の手間を洗い出すなら、自動で開く設定の調整と、保存後に人が行う整理を分けて考えるとよいです。AIで扱う作業を検討する際も、資料を受け取ってから確認を終えるまでの流れを先に書き出しておきます。
