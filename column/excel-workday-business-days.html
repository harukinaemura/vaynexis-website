Excelで休日を除いて何営業日後の作業予定日を計算するには

要点

Excelで休日を除いた作業予定日を出すには、開始日・営業日数・休日表を指定するWORKDAY関数を使います。土日と、休日として指定した日付が計算から除かれます。社内で使う休日表と数え方を決めてから、計算結果をカレンダーと照合するとよいです。

公開：2026年11月5日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelの社内予定表で休日を除いた作業予定日を出したい小さな会社の担当者が、WORKDAY関数の引数・休日表・日付の表示を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 先に、土日を休みとしてよいか確かめる
  2. 開始日・営業日数・休日表を別々に用意する
  3. 小さな予定表に式を入れる
  4. 数字やエラーが出たときに見る場所
  5. 引き継ぎには計算の前提も残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．先に、土日を休みとしてよいか確かめる

Microsoft サポートの WORKDAY 関数のページの適用先は、Excel for Microsoft 365、Excel for Microsoft 365 for Mac、Excel 2024、Excel 2024 for Mac、Excel 2021、Excel 2021 for Mac、Excel 2019、Excel 2016 です。この記事の画面の名前は Microsoft サポートの日本語のページの記載によるもので、Mac 版や Web 版の画面とは照らし合わせていません。

WORKDAY関数が返すのは、開始日から指定した稼働日数だけ前後に進んだ日付に対応する値です。通常のWORKDAY関数では、土曜日と日曜日が稼働日から除かれます。社内作業の予定表では、普段使っている休業日の決め方と合うかを先に確かめます。

土日以外を定休日として指定したい場合は、週末の曜日を指定できるWORKDAY.INTL関数を使えます。この記事では、社内で指定済みの休日表を使い、土日が休みの作業予定を組む流れを扱います。

2．開始日・営業日数・休日表を別々に用意する

開始日、そこから先へ進める営業日数、計算から除外する休日を、入力する前に整理します。引き継ぎで迷いやすいのは、開始日が「依頼を受けた日」なのか「作業を始める日」なのかという点です。社内で意味をそろえ、予定表にも分かる言葉で残します。

WORKDAY関数の日数に正の数を指定すると、起算日より後の日付を求められます。休日には、祝日や夏期休暇などの除外する日付を、セル範囲で指定できます。社内の休日表から対象の休業日を用意し、日付の列を計算に使う形に整えます。休日の名称と日付は分けておくと、確認もしやすくなります。

開始日や休日の日付を文字列として渡すと、エラーになることがあります。外部から貼り付けた日付は、文字列として保存されている場合もあります。見た目の日付だけで判断せず、入力済みの日付が計算に使える状態かを確認することが大切です。

3．小さな予定表に式を入れる

下表は入力欄の配置例です。実際の開始日や休業日は、社内で指定されたものを入力します。

作業名（A列）開始日（B列）営業日数（C列）作業予定日（D列）除外する休日（F列）
資料の確認社内で決めた日付社内で決めた日数数式で求める日付指定済みの休業日

結果を表示するセルに入力する

基本の書式は、WORKDAY(開始日, 日数, [祝日])です。下の式は、上表の配置に合わせて組み立てたものです。休日を入力する範囲は、用意した休日表に合わせます。

=WORKDAY(B2,C2,$F$2:$F$4)

入力先は作業予定日の欄です。式の参照先は、配置した開始日、日数、休日表に合わせます。休日の欄は見出しの下から縦に入力する想定です。参照範囲に、使う休日の日付が収まっているかも見ます。

数式を入力した後、Enterキーを押すと計算結果を表示できます。休日表の範囲をコピー時にも固定するため、列と行の前にドル記号を付ける絶対参照を使っています。入力する欄と計算する欄を分けておくと、予定を変えるときに確認する場所が分かりやすくなります。

公式ヘルプの使用例と照らす

公式ヘルプの使用例には、開始日の2008/10/1から、祝日として指定した3つの日付を除いて稼働日数151日後の日付を計算し、2009/5/5を返す例があります。これは過去の日付を使った関数の説明用データです。現在の休日表として転用せず、操作を確かめる際の比較材料として読みます。

4．数字やエラーが出たときに見る場所

日付に見えない数字が表示される

Excelは日付を連続したシリアル値として扱っています。結果を日付で表示するときは、［セルの書式設定］ダイアログ ボックス（Ctrl+1 キーでも開けます）の［カテゴリ］ボックスの一覧で［日付］をクリックし、［種類］ボックスの一覧で形式をクリックする、と案内されています。表示を整えた後、意図した作業日になっているかを改めて確認します。

エラーや予想と違う日付になる

無効な日付を引数に指定すると、WORKDAY関数は#VALUE!を返します。日数に小数を指定した場合、小数点以下は切り捨てられます。結果が合わないときは、式を直す前に、開始日、入力した日数、参照している休日表を順に見直すとよいです。

数式を別の行へコピーすると、相対参照の位置は自動で調整されます。コピー先の開始日・日数がその行の入力を参照しているかと、休日表の範囲が意図せず動いていないかは、分けて確かめます。

5．引き継ぎには計算の前提も残す

ここからは当社の整理です。

予定日を引き継ぐときは、結果の日付だけでなく、開始日の意味、使った休日表、休日を更新する担当も一緒に残すとよいです。休日表を変更した後は、変更前に共有した予定との食い違いがないかを確認します。

検算では、カレンダー上で対象の稼働日を拾い、入力した日数と結果の位置を照合します。関数の出力をそのまま採用する前に、社内で合意した数え方と一致するかを見るためです。

ここで作るのは、社内作業の予定日です。法定期限や契約上の期限の判断は扱わず、別途確認する事項として分けておきます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□開始日が何を表す日付なのかを、社内でそろえたか
□定休日の扱いと、使う計算方法が合っているかを確認したか
□社内で指定済みの休日表を使い、対象の休業日を含めたか
□開始日と休日が、計算に使える日付になっているかを確認したか
□コピー後の参照先と、休日表の参照範囲を確認したか
□計算結果を日付で表示し、カレンダーと照合したか
□予定表と一緒に、休日表の更新担当と計算の前提を記録したか
