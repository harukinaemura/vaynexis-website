ChatGPTのメモリ｜停止・会話削除・ファイル削除の違い

要点

メモリをオフにしても過去のチャットは消えません。覚えた情報、会話、別に保存したファイルを、それぞれの保存先で確認することが大切です。会社の情報を入れる前は、参照元、削除する範囲、社内の管理者が扱う設定を順に整理します。

公開：2026年11月2日／情報の確認日：2026年11月2日（出典はこの記事の最後）

この記事は、ChatGPTを仕事で使い始めた事務の担当者・経営者が、会社の情報を入れる前に、覚えさせない方法と消える範囲の違いを公式の説明で確かめるための整理です。

公式ページ・公式ヘルプなどの一次資料を2026年11月2日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．メモリは、会話などの情報を回答に生かす機能

機能・設定の確認日：2026-11-02（以下の各節に共通）

ChatGPTのメモリは、有効なときに会話などから関連する好みや詳細を覚え、回答を個人に合わせるために使う機能です。 プランや地域により、LibraryやSpaceの関連する保存ファイルや、接続したアプリの内容が参照される場合があります。

Memory summaryは、回答を個人に合わせるために使う情報の概要であり、参照できるすべての詳細や情報源を示すとは限りません。

見るべき点は、表示された要約の内容だけではありません。どの保存先や情報源を確認するかまで整理すると、消したい情報を探す範囲がはっきりします。

2．オフにする操作と、消す操作を分ける

「今後の回答で使わせたくない」と「保存した内容を削除したい」では、確認する操作が変わります。次の表では、設定の変更と保存先の削除を分けています。

操作変わること・残るもの
メモリをオフにするメモリを後からオンに戻すと、履歴に残る会話から新たに記憶される場合があります。
保存されたメモリを削除する削除したメモリは以後の個人向けの回答に使われなくなりますが、過去の会話に含まれる同じ情報は削除されません。
元の会話を削除する元のチャットを削除しても、別に保存されたメモリは自動では削除されません。
会話とは別に保存したファイルを削除する別に保存されたファイルを消すには、会話の削除とは別にLibraryやSpaceからそのファイルを削除します。

保存されたメモリの情報を取り除くには、そのメモリと最初に情報を共有したチャットを削除し、同じ情報があるほかの参照元からも取り除く必要があります。

消したい情報の保存先を先に書き出しておくと、設定の変更だけで対応を終えていないかを確かめやすくなります。

3．一時チャットは、開始時の選択と保存後を確認する

一時チャットでは、最初のメッセージを送る前にPersonalizedかUnpersonalizedを選びます。 Unpersonalizedでは、メモリ、カスタム指示、プラグインを使いません。 どちらの選択でも、一時チャットの間はメモリを作成・更新せず、会話開始後に個人向けの応答設定を変更することはできません。

一時チャットを保存すると、個人向けの応答を使わずに始めた会話も通常のチャットに変わります。 保存後は、メモリがオンであれば、その会話が以後の回答を個人に合わせるために使われる場合があります。

一時チャットのコピーは、安全のため最大30日間保持される場合があります。 また、メモリや個人向けの応答をオフにしても、まれな高リスクの状況で限定的な安全関連の文脈を使う安全機能は無効になりません。

後から読み返したくなった際は、「保存するか」だけでなく、「保存後に参照されてもよいか」も確認するのがよいです。

4．チャット・保存ファイル・プロジェクトでは削除の単位が違う

チャットのアーカイブは、保持期間を変えません。 保存済みチャットの削除後は原則として30日以内にシステムから完全に削除される予定となりますが、すでに匿名化されアカウントとの関連がなくなった場合や、安全・法的義務のため長期保持が必要な場合は例外です。

カスタムGPTの知識としてアップロードしたファイルは、そのGPTが削除されるまで保持されます。 共有を含むプロジェクトのファイルは、プロジェクトかファイルを削除するか、適用される組織の保持方針によって取り除かれるまで保持されます。

会話一覧から見えなくすること、保存先から削除すること、保持の処理が終わることを分けて確認するとよいです。法律上の判断が必要な場合は、公式資料と会社の文書管理規程をそろえ、専門家に確認します。

5．会社の情報を入れる前は、参照元から順に整理する

この節は当社の整理です。

まず、どの情報源を使う想定なのかを確認します。回答に役立てたい内容と、参照対象にしたくない内容を分け、使う予定の保存先も書き出すとよいです。ここで扱うのは、入力を許可する社内ルールの決め方ではなく、覚えさせる範囲と残る場所の確認です。

次に、削除したくなったときに確認する場所を整理します。会話を消す担当と、別の保存先を確認する担当が違う場合は、対応を引き継ぐ相手も決めておきます。削除済みと判断した根拠を担当者どうしで共有できる形にすると、対応の行き違いを避けやすくなります。

最後に、個人で操作する範囲と、社内の管理者が扱う範囲を確認します。使い始める前に、保存先、変更の担当者、削除時の連絡先をまとめておくと、担当が変わった場合にも確認を引き継げます。

6．設定名が違うときは、使う組織の管理者と確認する

メモリの機能や操作項目は、プラン、地域、利用する環境、組織の設定によって異なります。 使える項目には、Memory、Reference saved memories、Reference chat history、Memory summary、Manage、Saved memoriesなどがあります。

組織の所有者や管理者は、対応しているメモリ設定や役割ごとの権限を管理でき、設定が使えない場合は組織の管理者への確認が案内されています。

管理者には、使うアカウントと画面に出ている項目を伝え、変更できる範囲と削除を依頼する先を確認するとよいです。公式資料を読み直す日も決め、画面上の表示と照らし合わせながら運用します。
