PowerPointの資料をリンク先ファイルごと持ち出す手順

要点

Windows版のPowerPointでは、パッケージ化を使ってリンクされたファイルなどの外部要素も持ち出せます。作成時は同梱対象と保存先を指定し、持ち出し前にはコピー先から資料を開いて、参照する内容まで点検するとよいです。

公開：2026年11月11日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、リンクしたExcelの表やビデオを使うPowerPointの資料を別の端末へ持ち出したい小さな会社の事務担当者が、Windows版のパッケージ化の手順・リンク切れの直し方・Mac版とWeb版の違い・通信が必要なビデオを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 持ち出す前に、使う版と参照先を確かめる
  2. 保存先の指定までをひと続きで進める
  3. 元のファイルが見つからないときの対処を分ける
  4. Mac版と通信が必要な動画は別に確認する
  5. 引き継ぎではコピー先から開いて確かめる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．持ち出す前に、使う版と参照先を確かめる

確認日：2026年11月10日

公式ヘルプの適用先は、Windows版のPowerPoint for Microsoft 365・2024・2021・2019・2016と、Mac版のPowerPoint for Microsoft 365・2024・2021です。 まず、使う端末の版を確かめ、作成側で何を持ち出すのかを整理します。資料の表紙が表示されることと、参照する中身までそろっていることを分けて考えるのが出発点です。

スライドからリンクされた外部ファイルが移動・削除されると、データの編集時にエラーが表示されることがあります。 ビデオについては、ビデオのヘルプの Windows 用の欄に、［ファイル］＞［情報］の［メディアの互換性の最適化］の下で、メディアがリンクか埋め込みかを確かめられ、リンクされたビデオがあれば［リンクの表示］から保存場所を開ける、とあります。同じ欄では、リンクが壊れないように、プレゼンテーションと同じフォルダーにビデオをコピーしてからリンクするよう案内されています。 出発前の点検では、参照元を把握している担当者が、渡す必要のある資料と、渡してはいけない資料を分けます。受け渡す範囲が決まってから同梱の操作へ進むと、後で内容を選び直す手間を抑えられます。

2．保存先の指定までをひと続きで進める

パッケージの画面を開く

USBフラッシュドライブを端末に挿し、［ファイル］→［エクスポート］→［CD 用パッケージ プレゼンテーション］→［CD 用パッケージ］の順に開きます。 開いた画面では［CD の名前］に名前を入力し、ほかのプレゼンテーションもまとめる場合は［追加］で対象を選びます。

同梱するファイルを選ぶ

リンクファイルなどの補助ファイルを含める設定は［オプション］にあり、［これらのファイルを含める］で該当するチェックボックスを選びます。 同梱する対象を選ぶ場面では、持ち出し先で必要な内容と照らし合わせます。

保存先を選び、コピーを終える

［OK］で設定画面を閉じ、［CD 用パッケージ］で［フォルダーにコピー］を選び、続く画面で［参照］を開きます。 ［場所の選択］でUSBフラッシュドライブ、またはその中のサブフォルダーを選んで［選択］を押すと、保存先のパスが［場所］に入ります。 ここで目的の保存先になっているかを読み返します。

リンクされたファイルを含める確認には、必要なファイルをパッケージに含めるため［はい］と答える方法が公式に案内され、コピー完了後は保存されたパッケージのウィンドウが開きます。

3．元のファイルが見つからないときの対処を分ける

Windows版で外部ファイルへのリンクを調べる入口は、［ファイル］の［情報］にある［関連ドキュメント］の［リンクの編集］です。 ［関連ドキュメント］が表示されない場合、公式ヘルプではプレゼンテーションを保存しているか確認するよう案内しています。 このリンク修復の説明で対象にするWindows版は、PowerPoint for Microsoft 365・2024・2021・2019・2016です。 リンク元の新しい場所が分かる場合は、［ソースの変更］で対象を開き、リンク先のワークシートの正しいパスを選んで［今すぐ更新］を使います。

元のファイルの行方が分からない場合は［リンク解除］を選ぶ方法があり、内容はスライドに残ったまま、リンクではなくプレゼンテーションに埋め込まれます。Excelグラフのリンクを解除すると、スライドに表示されるデータは静的になり、元のワークシートを更新してもグラフには反映されません。 参照元を探し直すのか、更新しない状態で渡すのかは、受け手の用途に合わせて担当者が決める点です。画面に内容が残ったことだけで対処を終えず、渡した後も更新する予定があるかまで確認するとよいです。

4．Mac版と通信が必要な動画は別に確認する

Mac版には［CD 用パッケージ プレゼンテーション］機能がありません。 Mac版では、挿入したサウンド・画像・ビデオのコピーが既定でプレゼンテーション内に含まれると説明されています。 一方、Mac版でローカルのビデオを扱うヘルプには、［ファイルにリンク］を使って外部へのリンクを追加する操作もあります。リンクしたビデオとプレゼンテーションは同じフォルダーに保存するよう案内されています。 挿入済みの内容と外部への参照を分けて点検し、受け渡すファイルを整理する必要があります。

Mac版でリンク先のファイルを開くと、セキュリティ上の理由から追加のアクセス許可を求める画面が出る場合があります。 このアクセス許可のヘルプの適用先は、PowerPoint for Microsoft 365 for Mac、PowerPoint 2024 for Mac、PowerPoint 2021 for Macです。 Web版のPowerPointはパッケージ化をサポートしていません。

オンラインビデオはプレゼンテーション内ではなくウェブサイト上に保存されるため、正常に再生するにはインターネット接続が必要です。 同梱の確認と通信環境の確認は、受け渡しの記録でも分けておくとよいです。会場で通信が使えるか、当日どの内容を表示するかを事前に打ち合わせます。

5．引き継ぎではコピー先から開いて確かめる

ここからは当社の整理です。

例では、説明資料・参照表・説明動画を引き継ぐ場面を考えます。作成側で見えていた内容を受け手側でも使えるか、保存先から開いて確認する工程を設けます。元の作業用資料を開いたまま点検すると、どちらを見ているかが曖昧になりやすいため、持ち出す側の資料を選び直してから確認するとよいです。表示した画面だけでなく、参照する資料を開く動きや動画の再生まで、当日行う操作に沿って点検します。

点検するもの確認のしかた引き継ぎに残す内容
説明用の資料持ち出す保存先から開く使用するファイル名と保存先
参照する別資料当日使う箇所から開く同梱した対象と未解決の箇所
動画や音声当日使う端末で再生する再生の可否と通信の要否
受け渡す範囲内容を読める状態で確認する持ち出す対象と渡さない対象

点検で見つかった問題は、「開けない」だけで済ませず、どの資料のどの箇所で止まったかを残します。受け手が使うファイル名と保存場所まで伝えると、資料を選び直す際の手がかりになります。更新を続ける資料は、渡した後に誰が内容を直すかも決めておくと、引き継ぎの範囲が明確です。

公開・共有の前に、この表で確かめます。

出典（確認日：2026年11月10日）

  • CD または USB フラッシュ ドライブのプレゼンテーションをパッケージ化する：パッケージ化の適用先、外部ファイルの同梱、保存先の選択、Mac版とWeb版の違い
  • 外部ファイルへの壊れたリンクを更新または削除する：適用先、リンク切れの原因、リンクの編集、保存の前提、参照元の変更、リンク解除で埋め込みになることとその影響
  • コンピューターからビデオ ファイルを挿入して再生する：Windows版でのリンクされたビデオの場所の確かめ方、Mac版でのビデオへのリンク、リンクしたビデオの保存先
  • リンクされたファイルには、追加のアクセス許可が必要です：Mac版でリンク先を開く際の追加のアクセス許可と適用先
  • 他のサイトのビデオを挿入する（PowerPoint のトレーニング）：オンラインビデオの保存場所と通信の必要性
