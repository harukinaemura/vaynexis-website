Edgeの「拡張機能の管理」で勝手にオフになった機能を見るには

要点

Edge は、許可なく既定の設定を変えようとする拡張機能を自動的に無効にします。 オフになった拡張機能は、［設定など］から［拡張機能］、［拡張機能の管理］と進んで確かめ、必要ならトグルでオンに戻せます。 ただ、オフにされたのには理由があるので、戻す前に、その拡張機能が何を変えるものかを確かめます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

入れたはずの拡張機能が、Microsoft Edge でいつの間にかオフになっていたときの見方です。Edge が拡張機能を自動でオフにする理由、［拡張機能の管理］で確かめる道順、オンに戻す前に考えることを、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．なぜ勝手にオフになるのか

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Microsoft Edge です。

ヘルプによると、Edge の一部の拡張機能は、既定の検索エンジン、新しいタブ ページ、サイトの基本設定などの重要なブラウザー設定を変更できます。 ブラウザーの設定やセキュリティ、プライバシーを守るため、Edge はそうした変更を許可なく行おうとする拡張機能を自動的に無効にする、という説明です。

ある日、検索の結果がいつもと違うサイトで出るようになった、新しいタブの画面が変わった、といった出来事のあとに拡張機能がオフになっていたなら、この仕組みが働いた可能性があります。

2．拡張機能の管理を開く道順

ブラウザーの右上隅の［設定など］を選び、［拡張機能］を選んでから、［拡張機能の管理］を選びます。 一覧で、オフになっている拡張機能の名前を書き留めます。

拡張機能の追加・オフ・削除のヘルプには、アドレス バーの右側にある［拡張機能］を選び、［拡張機能の管理］を選ぶ道順も書かれています。 アドレス バーの右側に［拡張機能］が表示されない場合は、［設定など］から［拡張機能］を選ぶよう案内されています。 どちらの道順でも、同じ管理の画面にたどり着きます。

入れた経路を思い出すときは、Chrome 用の拡張機能も候補に入れます。ヘルプには、Google Chrome 用に設計された拡張機能は、Microsoft Edge でも使用できると書かれています。 Chrome ウェブストアから入れたものがないか、Edge のストア以外から入れた覚えがないかも思い出します。

3．オンに戻す前に考えること

オンに戻すときは、オンにする拡張機能を探して、トグルを選びます。 操作はそれだけですが、オフにされた理由を考えずに戻すと、また検索先や新しいタブが変わってしまうかもしれません。

確かめること（架空の例）戻してよさそうな場合戻すのを待つ場合
誰が入れたか自分や社内の担当者が業務のために入れた入れた覚えがない
何に使っているか毎日の業務で使っている何に使うものか分からない
オフになる前に変化があったか特に気づいた変化はない検索先や新しいタブが勝手に変わっていた

入れた覚えがない、何に使うか分からない、という拡張機能は、戻さずに社内のパソコンの担当者に相談します。

入れ直すことになった場合、ヘルプは、拡張機能に必要なアクセス許可を示すプロンプトで、アクセス許可を慎重に確認するよう案内しています。 管理者向けの Microsoft の文書では、拡張機能のアクセス許可には、拡張機能が表示または変更できる Web ページに関わるホスト アクセス許可と、拡張機能が実行されているデバイスで必要なデバイスのアクセス許可がある、と説明されています。 この2つの区分があることを頭に置いて、プロンプトの文面を読みます。業務で必要なものだと分かっていても、戻した後に検索先や新しいタブが変わっていないかを見ておきます。

パソコンに入っている拡張機能は、担当者ごとに違っていて、全体を誰も把握していないことがよくあります。どのパソコンに何が入っているかを一覧にしておくと、今回のような場面で判断しやすくなります。端末と道具を並べて見直すときは、業務棚卸しチェックシート（エクセル・CSV）の考え方も参考になります。

4．使わないと決めたら、オンに戻さず削除する

社内で確かめて、業務に使っていないと分かった拡張機能は、オフのまま置いておくより、削除したほうが一覧が見やすくなります。ヘルプには、削除する拡張機能のアイコンを長押し（または右クリック）し、［Microsoft Edge から削除］、［削除］と選ぶ方法が書かれています。 アドレス バーの右側の［拡張機能］から、削除する拡張機能の横にある［その他のアクション］を選ぶ方法もあります。 削除した後に業務で必要だと分かったときは、入れ直しになります。消す前に、名前と使っていた人を記録に残しておきます。

5．会社が管理しているパソコンの場合

管理者向けの Microsoft の文書では、組織はデータ保護ポリシーに基づいてユーザーのコンピューターの拡張機能をブロックまたは許可したり、拡張機能を強制的にインストールしたりできると説明されています。 職場のパソコンで、拡張機能のオンとオフが思うように切り替えられないときは、こうした会社の設定が関わっていることがあります。自分で何度も切り替えようとせず、パソコンを管理している人に、拡張機能の名前と、オフになっていた日を伝えて相談します。
