Wordの変更履歴をロックし、回覧中の記録停止を防ぐには

要点

Wordでは、［レビュー］タブの［追跡］＞［変更履歴］＞［ロック］から変更履歴をパスワードでロックすると、他のユーザーが記録をオフにするのを防げます（ヘルプの Windows 用の欄）。ロック中は、文書を開いた人は変更を表示できても、記録をオフにすることも、変更を承諾または拒否することもできません。回覧前には、記録を続ける文書と、解除を担当する人を決めておくとよいです。

公開：2026年11月11日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、Word文書を社内で回覧するあいだ変更の記録を止めさせたくない小さな会社の事務担当者が、Windows用の欄の［ロック］の入口・キーボードでの設定と解除・ロック中にできないこと・表示の切り替えとの違いを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象の版と、記録する相手をそろえる
  2. リボンから、停止を防ぐ設定へ進む
  3. キーボードと読み上げで設定を完了する
  4. 履歴の見え方だけで、停止したと判断しない
  5. 解除は、記録を止める操作と分けて扱う
  6. 回覧前に、担当と引き継ぐ情報を決める
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．対象の版と、記録する相手をそろえる

確認日：2026年11月10日

公式ヘルプの適用先のうち、この記事はWord for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016のWindowsデスクトップ版を対象にします。同じヘルプには Web・macOS・Office for iOS の欄もあり、たとえば macOS の欄ではロックを［校閲］タブの［ドキュメントの保護］＞［保護］から設定するなど、入口の書き方が異なります。この記事は Windows 用の欄だけを使います。別の環境へ引き継ぐ際には、使用する版と操作する端末を引き継ぎ先とそろえてから進めるとよいです。

他の担当者の変更も記録する場合、Windows欄の案内では［レビュー］タブから［追跡］、［変更履歴］、［すべてのユーザー］を選びます。回覧の準備では、誰が修正する文書なのかを先に整理します。自分の下書きを直す段階と、ほかの担当者へ確認を依頼する段階を区別しておけば、引き継ぎの目的を伝えやすくなります。

この記事で扱うのは、回覧中に記録を止めさせないための準備と確認です。返却後に修正内容を採用するかどうかの判断や、その操作手順は扱いません。

2．リボンから、停止を防ぐ設定へ進む

Windows 用の欄では、パスワードを使って停止を防ぐ入口は、［レビュー］タブの［追跡］から［変更履歴］、［ロック］へ進む順序です。入口を開く前には、回覧用として渡す文書を取り違えていないかを見ます。似た名前の下書きが並んでいるときは、保存場所と文書の内容を照らし合わせて対象を決めるとよいです。

変更の追跡がオンのときは該当する部分が強調表示され、削除には取り消し線、追加には下線が付きます。これは記録がオンかどうかを見る手がかりです。回覧の準備を終える際には、記録の状態を見る作業に加え、停止を防ぐ設定まで進めたかを区別して確認します。

画面を使う手順を引き継ぐときは、メニューの入口と設定の目的を対にして残すとよいです。「色が付いていた」という見た目だけの報告では、どの設定まで終えたのかが伝わりにくいためです。

3．キーボードと読み上げで設定を完了する

キーボード操作の公式手順は、Windowsのスクリーンリーダーを使用する人向けの案内です。ここでは、その前提のまま設定と解除の流れを整理します。読み上げを使う担当者への引き継ぎでは、画面の位置だけに頼らず、入力する順番も伝えるとよいです。

設定時はAlt＋R、G、Lの順にキーを押すと、「ロック追跡」と読み上げられます。続いてパスワードを入力してTabキーを押し、確認の読み上げの後に同じパスワードを再入力し、Enterキーを押します。

入力の途中で担当を交代するより、設定を始めた人が完了まで受け持つ流れにしておくと確認しやすくなります。引き継ぎメモには、操作を終えたか、これから操作するのかが分かる状態を残します。入力した秘密の文字列そのものと、作業が済んだという連絡は分けて管理するとよいです。

4．履歴の見え方だけで、停止したと判断しない

［変更履歴なし］は、変更履歴とコメントを非表示にして、変更を組み込んだ文書を表示する選択肢です。［すべての変更履歴］では、校閲者ごとに異なる色のテキストと線で変更履歴を表示します。色や線が見えなくなったときは、まず表示の選び方を見ます。見た目についての問い合わせと、記録を止められるかについての問い合わせを分けると、確認先を絞りやすくなります。

一方、変更の追跡をオフにすると、新たな変更の記録は止まりますが、すでに付いた色付きの下線や取り消し線は残ります。返却された文書に線が残っていることだけをもって、回覧中ずっと記録が続いていたと判断しないようにします。確認では、表示の状態と、これからの変更を記録する状態を別々に扱うことが大切です。

5．解除は、記録を止める操作と分けて扱う

スクリーンリーダー向けの解除手順でもAlt＋R、G、Lの順に押し、パスワードを入力してEnterキーを押します。解除を受け持つ人は、回覧先から戻ったという理由だけで処理を進めず、確認担当からの指示と対象の文書を照らし合わせます。

ロックされている間は、文書を開いたユーザーが変更を表示できても、記録をオフにすることも、変更を承諾または拒否することもできません。このため、返却後に変更を承諾・拒否する段階では、先にロックを解除します。閲覧できることと、設定を変更できることは分けて考えます。記録をオフにできない理由はロックだけとは限らず、ヘルプには、文書が校閲のために共有されている場合も［変更の追跡］をオフにできない可能性があると注記されています。担当者から「文書は読めるが操作が進まない」と連絡が来た場合は、すぐに別の文書を作り直す前に、回覧の管理担当へ現在の状態を伝えるとよいです。

6．回覧前に、担当と引き継ぐ情報を決める

ここからは当社の整理です。

社内案内文を回覧する場面では、修正する人と、回覧の準備・終了処理を受け持つ人を分けて整理できます。担当者名だけでなく、その人がどこまで受け持つかも短く残すと、途中で確認が止まった際の連絡先が明確になります。

役割引き継ぐ内容回覧前にそろえること
準備担当回覧用の文書と準備の完了状況渡す文書の名前と保存場所
修正担当直す範囲と返却先どこまで修正を頼まれているか
管理担当返却後の処理を始める合図依頼者からの終了連絡を受ける窓口

完了連絡には、回覧に使う文書を特定できる情報と、準備を終えたことを残します。解除を依頼する窓口も同じ連絡に添えておけば、修正担当が困ったときに、誰へ尋ねればよいかが分かります。

引き継ぎ先との確認では、操作名の暗記を求めるより、修正を続けてよい範囲、設定を変えたいときの連絡先、返却後に処理を始める合図をそろえます。
