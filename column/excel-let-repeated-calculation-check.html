Excelの長い式で同じ途中計算を繰り返さないには？LET関数の使い方

要点

Windows版のExcel for Microsoft 365では、LET関数で途中式に名前を付け、最後の計算からその名前を呼び出せます。同じ途中式だけを名前に置き換え、元の参照範囲や条件を維持します。差し替える前に、普段の結果に加え、判定の境界、参照先の空欄やエラーで結果が一致するかを確かめます。

公開：2026年11月9日／情報の確認日：2026年11月7日（出典はこの記事の最後）

Excelの既存式で繰り返す途中計算をLETの名前に置き換え、参照先・境界・空欄で変更前後の結果を比べます。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 1．名前を付けるのは、一つの式の中で繰り返す途中計算
  2. 2．重なっている途中式を一つ取り出し、名前を決める
  3. 3．条件と参照先をそのままにして、変更した箇所を追う
  4. 4．通常の結果と、判定が変わる境界を並べて確かめる

1．1．名前を付けるのは、一つの式の中で繰り返す途中計算

確認日：2026年11月7日

Microsoftの日本語ヘルプでは、LET関数の適用先にExcel for Microsoft 365、Excel 2024、Excel 2021と、それぞれのMac版が挙げられています。ここではWindows版のExcel for Microsoft 365で使う数式を扱います。

LET関数では、途中計算の結果に名前を付けられ、中間計算のほか、値や定義名なども数式内に格納できます。付けた名前は、そのLET関数の範囲内でのみ使えます。

同じ途中式を複数回書いている場合、LETでその式に名前を付けると、一つの数式の中でその式を一度計算して参照できます。

LETの引数は名前と値の組を先に置き、最後に結果を返す計算を置く構造です。

名前には文字で始まるものを使い、セル参照の形式と衝突する名前を避けます。

ここからは当社の整理です。

書き換える前に、元の式を確認用のコピーに残します。数式を見ながら、同じ途中計算がどこに現れるかを調べます。同じ合計でも範囲の端や固定するセルが違えば、まとめる候補から外します。条件判定より前に丸めているか、最終結果を丸めているかも控えておきます。

2．2．重なっている途中式を一つ取り出し、名前を決める

最初は、式を見たときに役割が分かる一つの計算から扱います。合計なら、どの範囲の合計を指すかが読み取れる名前にします。次の式は書き換えの構造を示しています。セル番地は手元の表で使う参照先に合わせます。

式の段階数式の骨組み
書き換え前`=IF(SUM($D$2:$D$100)>$F$2,SUM($D$2:$D$100)-$F$2,0)`
書き換え後`=LET(periodTotal,SUM($D$2:$D$100),IF(periodTotal>$F$2,periodTotal-$F$2,0))`

この骨組みでは、合計を上限と比べる箇所と、上限を引く箇所で、同じ範囲を集計しています。書き換え後は`periodTotal`を名前として置き、その値に元の`SUM($D$2:$D$100)`を入れます。最後の引数に置くIFでは、その合計が上限を超えたときに超えた分を返し、上限以下ではゼロを返す元の条件を保ちます。

3．3．条件と参照先をそのままにして、変更した箇所を追う

元の式から移すときは、名前に割り当てた式の参照先と、最後の計算で残した参照先をそれぞれ読みます。上の骨組みでは合計範囲と上限を参照する位置が別です。固定する参照に付いているドル記号を保ったか、範囲の先頭と末尾が元の式と一致するかも確認します。

最後の計算で、同じ途中式があった箇所を名前に置き換えます。条件式の比較記号や、条件に合わないときの戻り値は、元の式と照合しておきます。元の式に空欄の判定や丸めがある場合も、どの計算より前に処理していたかを追い、結果を確認するまでは位置を保ちます。

元の式で特定の条件のときだけ実行していた途中式を、先頭の名前の定義へ移す場合は、入力が空欄の行やエラーを含む行も確認に加えます。書き換えた後に結果が変わる場合は元の式を残し、名前を付ける範囲を見直します。

4．4．通常の結果と、判定が変わる境界を並べて確かめる

確認用のコピーで、元の式と変更後の式を同じ入力で計算します。列を追加して比較する場合、式を置いた位置がずれたことで参照先まで動いていないかを先に確認します。数値が一致するかに加え、空欄やエラーが元の式ではどの条件で出るかも見ます。

比べる箇所照合する内容
普段の結果元の式と新しい式が同じ参照範囲から同じ結果を返すか
判定の境界上限の直前・上限と同じ・直後で、同じ側の条件に入るか
空欄やエラー入力不足や参照先のエラーがあるとき、元の表示と一致するか
式をコピーした範囲行や列に応じて動く参照と、固定する参照がそろっているか

結果が合わなければ、名前に割り当てた式の参照先を確認し、その後で最後の計算の条件を照合します。合うことを確認してから、置き換える対象を広げます。引き継ぐ際には、変えた数式の位置、名前に付けた意味、比較した条件を伝え、利用する担当のExcelがLETの適用先に含まれるかも確かめます。

5．5．LETの引数と名前の決まり、ヘルプの書き換え例

Microsoftのヘルプでは、LET関数では少なくとも 1 つの名前/値のペア（変数）を定義する必要があり、最大 126 組までサポートされます。2つ目の名前を指定した場合は、その値と、次の計算または名前も必須です。最後の引数は、結果を返す計算である必要があります。

同じヘルプでは、変数の名前は名前マネージャーで使用できる有効な名前と一致し、たとえば "a" は有効ですが、"c" は R1C1 形式の参照と競合するため有効ではないと説明しています。また、名前を付けることで、自分と式を使う人にとって分かりやすい文脈を割り当てられる点も挙げています。1文字の短い名前を使う場合は、この例のように参照の形式と重ならないかを確かめます。

ヘルプの使用例 2 では、IF の中で同じ FILTER の式を2回書いた元の数式を、LET で書き換えています。条件の値に filterCriteria、FILTER の結果に filteredRange という名前を付け、2つ目の名前の値の中で1つ目の名前を使い、最後の IF で filteredRange を呼び出しています。この記事の骨組みと同じく、繰り返していた式を一度だけ名前に割り当て、判定と戻り値の形は元の数式のまま残している点が、書き換えを照合するときの見どころです。
