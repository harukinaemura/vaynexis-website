Edgeの「新しい InPrivate ウィンドウ」はどこで開く？

要点

InPrivate ウィンドウは、Edge の［設定など］アイコンから［新しい InPrivate ウィンドウ］を選んで開きます。 キーボードなら Ctrl＋Shift＋N です。 すべての InPrivate ウィンドウを閉じると、閲覧履歴、Cookie、サイト データに加えて、パスワード、アドレス、フォーム データが削除されます。 一方で、お気に入りやダウンロードしたファイルは残り、学校や職場、インターネット サービス プロバイダーから閲覧を隠す機能でもありません。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

共用のパソコンで閲覧の跡を残さずに調べものをしたいとき、Windows 版 Microsoft Edge で InPrivate ウィンドウを開く場所と、すべて閉じたときに消える物・残る物、職場や回線の側からは見えることを、Microsoft の日本語の公式ページに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．［設定など］の中にある

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Microsoft Edge です。スマートフォン版の Edge や、ほかのブラウザーにある似た機能は扱いません。

開き方は、Microsoft のヘルプでは1行で書かれています。Edge で［設定など］アイコンを選び、［新しい InPrivate ウィンドウ］を選びます。

同じヘルプの概要では、InPrivate ウィンドウを使うと、閲覧履歴、Cookie、サイト データ、フォーム エントリをデバイスに保存せずに Web を閲覧できると説明されています。 閲覧が終了したときに、履歴、インターネット一時ファイル、Cookie などの閲覧データは PC に保存されない、とも書かれています。

事務の場面で出番があるのは、受付や会議室に置いた共用のパソコンで来客の前に少しだけ調べものをするときや、自分の席ではない端末で一度だけ何かを確かめるときです。使う前に、何が消えて何が残るのかを知っておくと、使い終えた後の片付けを間違えません。

2．キーボードとお気に入りバーからも開ける

メニューをたどるのが手間なら、キーボードで開けます。Edge のキーボード ショートカットの一覧では、Ctrl＋Shift＋N が「新しい InPrivate ウィンドウを表示する」操作です。

お気に入りバーに並べたサイトを、まとめて InPrivate で開く道もあります。［設定など］から［お気に入り］を選び、［お気に入り］ウィンドウで［お気に入り］バーを右クリックして、［新しい InPrivate ウィンドウですべて開く］を選びます。 共用の端末で、毎朝確かめる業務サイトをいくつか順に開きたいときに使えます。

3．すべて閉じたときに消える物

InPrivate の閲覧データが消えるのは、InPrivate のウィンドウを1つ閉じたときではなく、すべての InPrivate ウィンドウを閉じたときです。Microsoft の閲覧データとプライバシーのページには、すべての InPrivate ウィンドウを閉じたときに、閲覧履歴、Cookie、サイト データだけでなく、パスワード、アドレス、フォーム データを削除すると書かれています。

裏を返すと、閉じるまでは残っています。Edge の紹介ページのよくある質問では、すべての InPrivate ウィンドウを閉じるまで Cookie やその他のサイトのアクセス許可は削除されないため、サイトはセッション中にコンテンツをカスタマイズできると説明されています。

InPrivate のウィンドウを2つ開いて片方だけ閉じた状態では、まだサイトのデータが残っている、ということです。共用のパソコンで使い終えたら、InPrivate のウィンドウが画面の後ろに残っていないかを見てから席を離れます。

4．閉じても残る物

InPrivate は、何も残らない機能ではありません。ヘルプの概要には、InPrivate ブラウズはローカル追跡を制限しつつ、ダウンロードやお気に入りを保存できると書かれています。 紹介ページのよくある質問でも、作成したコレクション、お気に入り、ブックマーク、ダウンロードしたファイルはすべて保存され、ダウンロード履歴は保存されないと説明されています。

事務で気を付けたいのはダウンロードです。共用のパソコンで、InPrivate のウィンドウから見積書の PDF などを保存すると、ウィンドウを閉じた後もファイルは残ります。ダウンロード履歴が残らない分、保存したことを本人が忘れやすくなります。保存した場所を確かめ、要らなくなったファイルは自分で消す、という手順を決めておきます。

お気に入りも残ります。紹介ページには、コレクションとお気に入りは保存され、コレクションへの変更はサインインしているデバイス間で同期され続けるとも書かれています。 共用のパソコンでは、みんなが使うお気に入りの一覧に個人の調べものが混ざらないようにします。

5．職場や回線の側からは見えている

InPrivate は、パソコンに閲覧の跡を残しにくくする機能で、ネットワークの上で匿名になる機能ではありません。紹介ページのよくある質問では、InPrivate は学校、雇用主、またはインターネット サービス プロバイダーからブラウジングを隠すことはないと書かれ、学校、職場、インターネット サービス プロバイダは見ることができると説明されています。

安全のための機能でもありません。同じよくある質問には、InPrivate は悪意のあるサイトからユーザーを保護したり、追加の広告ブロックを提供したりすることはないと書かれています。 怪しいリンクを開くときの身を守る手段として InPrivate を使う、という考え方は当たりません。

Microsoft 側の扱いについては、閲覧データとプライバシーのページに、InPrivate ブラウズでは自動候補はオフになり、アクセスした Web サイトに関する情報は収集されないと書かれています。 Edge が閲覧履歴を Windows と共有してスタート メニューやタスク バーなどで使えるようにする仕組みでも、InPrivate モードでアクセスした Web サイトは共有されないと説明されています。

6．会社のパソコンで思いどおりにならないとき

会社が管理しているパソコンでは、InPrivate の扱いが決められていることがあります。Microsoft の管理者向けの資料には、InPrivate モードが利用できるかどうかを構成するポリシーがあり、「無効」に設定すると、ユーザーが InPrivate モードを使用できなくなると書かれています。 「強制」に設定すると、常に InPrivate モードでの使用になります。

InPrivate で開こうとしても開けない、いつ開いても InPrivate になる、というときは、自分で設定を探し回るより、社内でパソコンを管理している人に確かめます。ルールを決める側は、InPrivate を使ってよい場面と使わない場面を先に決めておくと、現場が迷いません。
