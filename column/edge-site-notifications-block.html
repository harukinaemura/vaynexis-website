Edgeの「通知」で閉じた後も出るサイト通知を止めるには

要点

Edge を閉じた後にも出てくる通知は、以前にそのサイトの通知を許可したことによるものと考えられます。Microsoft のヘルプには、Web サイトの通知をオンにすると、Microsoft Edge が閉じていても表示されると書かれています。 止めるには、そのサイトの［通知］の設定をドロップダウン メニューから［ブロック］に変えます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Microsoft Edge を閉じているのに、以前に許可したサイトの通知が画面の隅に出続けるときの止め方です。通知を出しているサイトを特定し、そのサイトの［通知］を［ブロック］に変える2つの道順と、必要になったときに戻す方法を、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  2. 画面の中に出る広告は、通知ではなくポップアップ
  3. 道順1：そのサイトを開いて、アドレス バーから止める
  4. 道順2：設定の一覧から、サイトを選んで止める

1．まず、どのサイトの通知かを書き留める

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Microsoft Edge です。

業務中に、ニュースサイトや通販サイトのお知らせが急に出ると、集中が途切れるうえ、取引先との画面共有の最中に映り込むこともあります。止める前に、通知に表示されているサイトの名前やアドレスをメモしておきます。複数のサイトから届いている場合は、1つずつ止めていくので、一覧にしておくと抜けに気づきやすくなります。

ヘルプには、Web サイトの通知は画面の右下隅に表示され、通知センターにも表示されると書かれています。 出た瞬間にサイト名を読み取れなかったときは、通知センターに残っている通知を開いて、どのサイトから来たものかを確かめます。

Edge を閉じていても届くため、「ブラウザーを閉じたのに出る＝ブラウザーとは関係ない」と考えて、パソコン全体の通知を切ってしまう人がいます。そうすると、予定のお知らせなど要る通知まで止まりかねません。止めたいのが特定のサイトのお知らせなら、まず Edge の側でそのサイトだけを止めます。

2．画面の中に出る広告は、通知ではなくポップアップ

止める前に、困っているものが本当に「通知」かを見分けます。ヘルプの注には、Web サイトの通知と同じではない不要なポップアップを受信している場合は、ポップアップをブロックするページを見るよう書かれています。 ポップアップは、現在のブラウザー ウィンドウ、新しいウィンドウ、または別のタブで開く、広告、通知、オファー、およびアラートと説明されています。

見分けの目安は、出てくる場所です。Edge を閉じていても画面の右下に出て、通知センターにも残るなら、サイトごとの［通知］の設定で止める対象です。サイトを見ている最中に、ブラウザーの中や新しいタブに広告が開くなら、ポップアップの設定の側を見直します。どちらか分からないときは、出てきた画面を写真に撮っておくと、社内で相談するときに話が早く進みます。

3．道順1：そのサイトを開いて、アドレス バーから止める

通知を出しているサイトを Edge で開ける場合は、アドレス バーの左側から、このサイトのアクセス許可を開き、通知の項目でドロップダウン メニューから［ブロック］を選ぶ方法があります。 ヘルプの手順では、アドレス バーの左側にある［サイト情報の表示］を選び、［このサイトのアクセス許可］の中の通知の項目（ヘルプの表記は Notifications）で［ブロック］を選びます。 この道順は、既にサブスクライブしている Web サイトにアクセスしているときに使う方法として書かれています。 いま見ているサイトに対してだけ変えるので、ほかのサイトの設定に触れずに済みます。

4．道順2：設定の一覧から、サイトを選んで止める

ヘルプの見出しは「Edge 設定で通知を削除またはブロックする」で、個々の Web サイトの通知を削除またはブロックできると書かれています。 サイトごとに切り替える設定なので、業務で使うサイトの通知は残したまま、困っているサイトだけを止められます。

サイトのアドレスが分からないときや、いくつかのサイトをまとめて見直したいときは、Edge の［設定］からサイトの一覧を開き、通知をブロックする Web サイトを選んで、［通知］の設定をドロップダウン メニューから［ブロック］にします。 一覧で知らないサイトが通知を許可されていたら、その場で止めておきます。

ヘルプの手順では、ブラウザー ウィンドウの右上隅にある［設定など］から［設定］に進み、［すべてのサイト］［サイトのアクセス許可］［Privacy、検索、およびサービス］という項目名が並んでいます。 英語の混じった表記で、画面の並びと一致しないこともあるため、迷ったら［設定］の中の検索欄に「通知」と入れて探すと近道です。

場面（架空の例）使う道順選ぶもの
通販サイトのお知らせが毎朝出る。サイトは分かる道順1（アドレス バー）［通知］→［ブロック］
見覚えのない名前の通知が出る道順2（設定の一覧）該当のサイトを選び、［通知］→［ブロック］
業務で使う予約サイトの通知は残したいどちらでも残すサイトは変えない

5．止めた後で、また必要になったら

業務で使うサイトを誤って止めてしまった場合も、元に戻せます。ヘルプには、このメニューに戻って［許可］を選ぶと、今後 Web サイトの通知を再サブスクライブできると書かれています。 どのサイトを止め、どれを残したかを短く書いておくと、戻すときに迷いません。

社内で「通知が止まらない」という相談が続くなら、パソコンごとの設定のばらつきを一度洗い出しておくと、次の相談のときに同じ順番で確かめられます。端末と設定の困りごとを並べて見るときは、業務棚卸しチェックシート（エクセル・CSV）の考え方も参考になります。
