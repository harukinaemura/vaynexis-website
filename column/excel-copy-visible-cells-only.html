Excelで非表示の行を含めず見える部分だけコピーするには

要点

Windows版のExcelで非表示の行を含めずにコピーするには、対象範囲を先に選び、表示されているセルだけに選択を絞ってからコピーし、貼り付け先の左上のセルを指定する順で進めます。

公開：2026年11月4日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelで非表示にした行を含めずに見えている部分だけを渡したい小さな会社の担当者が、範囲の選び方とWeb版の制約を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 最初に範囲を決め、表示されているセルに絞る
  2. 事務用の一覧では、渡す列と行を先に決める
  3. Web版では通常の範囲とテーブルを分けて考える
  4. 対象が違うと感じたら、選び方を見直す
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．最初に範囲を決め、表示されているセルに絞る

Excelの公式ヘルプでは、既定のコピーには非表示またはフィルターで隠れたセルも含まれると案内されています。そのため、見えている行だけを渡したいときは、範囲の選択と、表示されているセルへの絞り込みを分けて考えるとよいです。

このヘルプの適用先は Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 で、手順は Windows と Web に分けて書かれています。次の手順は Windows 版の手順です。

コピーする範囲を先に選ぶ

最初にコピーしたいセル範囲を選びます。決めた領域の中だけで条件に合うセルを探す場合は、目的の範囲・行・列を先に選ぶと案内されています。

選択を絞ってからコピーする

  • Ctrl+Gで［ジャンプ］を開きます。
  • ［ジャンプ］の［セル選択］から、条件に合うセルを選ぶ画面へ進みます。
  • ［表示されているセルのみ］を選び、［OK］で確定します。
  • ［コピー］を選ぶか、Ctrl+Cでコピーします。

日本語のヘルプでも、ページによって名前の書き方が違います。特定の条件を満たすセルを検索して選択するヘルプでは、Ctrl+Gの後に［特殊］を選び、［選択オプション］ダイアログボックスで選ぶと書かれていて、項目の名前は［可視セルのみ］です。自分の画面に出ている名前と照合して進めます。

画面の言葉だけを覚えるより、範囲を選ぶ段階と、対象を絞る段階の順番を押さえると、引き継ぎのメモも書きやすくなります。

貼り付けを始める位置を選ぶ

貼り付け先の左上のセルを選びます。その後、［貼り付け］を選ぶか、Ctrl+Vで貼り付けます。ここまでで、コピー元の対象を選ぶ流れがそろいます。

2．事務用の一覧では、渡す列と行を先に決める

ここからは当社の整理です。

備品の一覧から、確認を頼む項目だけを別の担当者へ渡す場面を考えます。操作を始める前に、「何のために渡すか」「どの項目を含めるか」を短く整理しておくとよいです。

品名保管場所コピー前の表示として想定する状態渡す対象
封筒書庫表示含める
クリップ事務室非表示含めない
付箋受付表示含める

相手に渡したいのは、封筒と付箋の品名・保管場所です。内部メモの列が別にあれば、今回の目的に必要かを考えて対象を決めます。

行の扱いと列の扱いを同じメモに混ぜず、「渡す項目」と「渡す対象」に分けて残します。見出しを含めるかどうかも、相手の使い方に合わせて先に決めるとよいです。

引き継ぎでは、「表のここからここまで」とだけ伝えるより、含めたい項目名と、含めない対象の理由を添える方が意図を伝えやすくなります。対象外にする理由が分かれば、別の担当者も同じ目的に沿って範囲を選べます。

3．Web版では通常の範囲とテーブルを分けて考える

Microsoft の日本語のヘルプでは、Excel for the web でセル範囲をコピーして貼り付けると、表示されているセルと一緒に非表示のセルも貼り付けられ、表示されているセルのみを貼り付けるオプションがないため、これを変えることはできないと案内されています。ただし、データの表示形式が、フィルターを適用したテーブルとして設定されている場合は、表示されているセルのみをコピーして貼り付けることができるとされています。

データをテーブルとして設定しない場合は、Excel デスクトップ アプリケーションを使っていれば、［Excel で開く］からブックを開き、表示されているセルをコピーして貼り付ける方法が案内されています。表の作り方を変えてよいか、利用する環境を変えられるかを、作業前に整理しておくとよいです。

4．対象が違うと感じたら、選び方を見直す

特定の条件を満たすセルを検索して選択するヘルプでは、［可視セルのみ］で選ばれるのは、非表示の行または列と交差する範囲に表示されているセルのみと説明されています。行だけを意識していた場合も、渡したい列が表示されているかを含めて、コピー元の範囲を見直すとよいです。

可視セルのみをコピーするヘルプでは、セルの選択を取り消すには、ワークシート内の任意のセルをクリックすると案内されています。範囲を決め直すときは、渡す項目や対象を先に見返し、それから選び直すと整理しやすくなります。

迷ったときは、操作を繰り返す前に、対象を選び直す必要があるのか、作業に使う環境を見直す必要があるのかを分けて考えます。引き継ぎ用のメモにも、対象を選ぶ段階と操作する段階を分けて残すとよいです。
