Excelで注文番号と枝番を区切り記号で別列に分けるには

要点

「A1023-01」のように注文番号と枝番が「-」でつながった列は、Power Query の、テキストの列を複数の列に分ける機能で2つに分けられます。 手順は、［ホーム］の［列の分割］から［区切り記号で］を選び、［カスタム］で「-」を指定します。 番号の中に「-」が2つ以上あるときは、［右端の区切り記号］を選ぶと、最後の「-」の右側だけを枝番として分けられます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

受注の一覧に「A1023-01」の形の番号が並び、注文ごとに数えられない。区切り記号が2つある番号や枝番の無い注文も含めて、Power Query で2つの列に分けるときの選び方を整理しました。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 受注の一覧で、注文番号ごとに数えたいとき
  2. 分ける前に、番号の決まりを確かめる
  3. ［区切り記号で列を分割］の選び方
  4. 分けた後の列名と型を見直す
  5. 分けた結果を、誰がどう確かめるか
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．受注の一覧で、注文番号ごとに数えたいとき

確認日：2026年11月17日。

対象は Windows 版の Excel（Microsoft 365・2024・2021・2019・2016）です。

1つの注文を分納したり、明細を枝番で分けたりしている会社では、受注の一覧に「注文番号-枝番」の形の番号が並びます。この形のままだと、注文番号だけで並べ替えたり、注文ごとに件数を数えたりする前に、毎回、目で番号を読み分けることになります。注文番号と枝番を別の列にしておけば、注文番号の列で絞り込み、枝番の列で何回目の分納かを見る、という使い分けができます。

社名や住所の書き方をそろえる作業とは別の話で、ここで扱うのは、番号の付け方の決まりがはっきりしている複合の番号を、決まりどおりに2つに分ける操作です。

2．分ける前に、番号の決まりを確かめる

最初に、受注の一覧の番号を上から見て、区切り記号がいつも同じ文字か、何個入っているかを確かめます。

番号（架空の例）区切り記号の数分けたい形
A1023-011つA1023 と 01
A1023-021つA1023 と 02
2026-B0045-012つ2026-B0045 と 01
A10500枝番の無い注文

1つ目と2つ目は、「-」が1つだけなので、どの選び方でも同じ所で分かれます。3つ目のように、注文番号の中にも年を表す「-」がある番号が混ざっていると、選び方によって分かれる所が変わります。4つ目のような枝番の無い注文がある場合は、分けた後に枝番の列がどうなっているかを、その行だけ取り出して確かめます。区切り記号が全角の「－」になっている行が混ざっていないかも、この段階で見ておきます。

3．［区切り記号で列を分割］の選び方

受注の一覧を Excel のテーブルにし、テーブルの中にカーソルを置いて［データ］の［データの取得 & 変換］から［テーブル/範囲から］を選ぶと、Power Query エディターが開きます。

分ける列を選び、テキストのデータ型であることを確かめます。 ［ホーム］の［列の分割］から［区切り記号で］を選ぶと、［区切り記号で列を分割する］ダイアログ ボックスが出ます。 ［列の分割］は、［変換］タブの［テキスト列］グループや、列の右クリックからも選べます。

区切り記号の一覧には、コロン・カンマ・等号・セミコロン・スペース・タブなどがあり、［カスタム］を選ぶと任意の文字を区切り記号に指定できます。 「-」で分けるなら［カスタム］を選んで「-」を入れます。

［分割］の選び方は3つあります。［左端の区切り記号］は、いちばん左の区切り記号で分け、右側の残りを2つ目の列にします。［右端の区切り記号］は、いちばん右の区切り記号で分け、左側の残りを1つ目の列にします。［区切り記号の出現箇所］は、区切り記号ごとに分けるので、区切り記号が3つなら4つの列になります。

枝番がいつも最後に付く決まりなら、［右端の区切り記号］を選ぶと、「2026-B0045-01」も「2026-B0045」と「01」に分かれ、注文番号の側に年の「-」が残ります。

分けた結果を、列ではなく行に広げる選び方もあります。Learn の説明では、列に分けるか行に分けるかの選択は［詳細設定］の下にあり、既定は［列］になっています。 行に分けると、元の列の値がそれぞれのセルに入る分だけ行が増えるので、注文番号と枝番を横に並べたい今回は［列］のままにします。

4．分けた後の列名と型を見直す

分けた列の名前は、既定では元の列の名前に、ピリオドと番号が付いた形になり、後から名前を変えられます。 「受注番号.1」「受注番号.2」のままでは、受け取った人が中身を読み違えやすいので、「注文番号」「枝番」のように分かる名前に変えておきます。

データ型にも気を配ります。Power Query はデータ型を解釈し、後で調整できると説明されています。 枝番が「01」のように頭に0の付く形なら、分けた後の枝番の列が数値の型になっていないか、表示が「1」に変わっていないかを確かめ、番号として扱う列はテキストの型にそろえます。

最後に［ホーム］の［閉じる & 読み込み］で Excel に戻します。読み込んで変換しても元のワークシートは変わらないので、元の受注の一覧はそのまま残ります。

5．分けた結果を、誰がどう確かめるか

分ける操作をした担当者は、読み込んだ結果の行の数が元の一覧と同じかを見ます。行の数が増えていれば、列ではなく行に分けている可能性があります。次に、区切り記号が2つある番号と、枝番の無い番号を、それぞれ数件ずつ取り出し、分かれ方が決まりどおりかを確かめます。

受注の一覧を使う営業や経理の担当者には、どの列が元の番号で、どの列が分けた後の番号かを伝えておきます。番号の付け方を変える話が出たときは、区切り記号の文字や数が変わらないかを先に聞き、変わるならクエリの選び方も見直します。

番号の決まりや、それを誰が使っているかを書き出しておくと、事務の業務改善の進め方を考えるときの材料にもなります。

公開・共有の前に、この表で確かめます。

確認確かめること
□番号の区切り記号がいつも同じ文字か、全角と半角が混ざっていないか
