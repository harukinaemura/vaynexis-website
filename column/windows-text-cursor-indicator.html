Windowsのテキストカーソルを見やすくする目印と太さの設定

要点

入力位置を見つけやすくするには、テキスト カーソル インジケーターをオンにし、カーソルの上下に色付きの目印を付けます。調整後は、普段の入力欄で続きを書く位置を見つけられるか、周囲の文字も読み取れるかを確かめるとよいです。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、文字の入力位置を見つけやすくしたい小さな会社の担当者が、テキストカーソルの目印と太さの設定を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 探したいのは矢印か、文章の入力位置か
  2. 目印をオンにし、プレビューでサイズと色を選ぶ
  3. 目印の大きさと、入力位置の線の太さを分ける
  4. 普段の入力欄では、書き始めと書き直しを確かめる
  5. 表示が合わない場面を切り分け、引き継ぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．探したいのは矢印か、文章の入力位置か

確認日：2026年11月15日

ここでは、Microsoft の日本語ヘルプで Windows 11 向けに示されている手順を扱います。画面の表示は更新によって変わることがあります。探したいのが、画面上で動かしている矢印の場所なのか、文章のどこに文字を足すかを示す場所なのかを、操作前に分けておきます。今回の対象は、文章を入力するときの位置です。

調整する前に、困っている動作を具体的にすると、結果を判断しやすくなります。たとえば、文章の途中を直そうとして挿入する場所を探し直すのか、別の欄を見たあとで続きを書く場所が分からなくなるのかを整理します。文字そのものを読みにくいという困りごととは分けて記録するとよいです。

2．目印をオンにし、プレビューでサイズと色を選ぶ

［設定］→［アクセシビリティ］→［テキスト カーソル］の順に開きます。開いた先で［テキスト カーソル インジケーター］のスイッチをオンにします。次に、［サイズ］スライダーを動かし、プレビューで希望の大きさになるように調整します。

ここでは、まず目印の存在を見つけられるかに注目します。設定を変える前に感じていた「場所を探し直す」という困りごとを思い出し、目に留まる大きさを探す考え方です。大きさだけで判断を終えず、周囲の文章を読むときにも邪魔に感じないかを見ます。

色は表示された候補から選ぶ方法と、［別の色を選択］からカスタム カラーを選ぶ方法があります。好みの色を選んだあとも、いつもの入力欄の背景と並べて見比べるとよいです。色と大きさを続けて変えすぎず、何を変えたあとに見つけやすく感じたかを確かめます。

3．目印の大きさと、入力位置の線の太さを分ける

［テキスト カーソルの太さ］では、点滅するカーソル自体の幅を広げられます。目印でおおよその位置を探すことと、文字の間の位置を線で読み取ることを分けて考えると、次に何を調整したいかが明確になります。

位置が分かっても、隣り合う文字のどちら側へ追加するかを判断しにくい場合は、線と文字の境目に注目して見比べます。反対に、線を見つけるまでに視線が迷うなら、探し始める場面を確認の中心にします。「見やすくなった」という感想を、位置を探せたか、挿入する場所まで読み取れたかに分ける方法です。

文章の末尾だけで終えず、語の途中や改行に近い場所でも、文字との境目を確かめるとよいです。太くすること自体を目的にせず、どこへ書き足そうとしているかを読み取れる状態を目指します。比較には本番の送信前の文章を使わず、書き換えて差し支えない練習用の文章を用意します。

4．普段の入力欄では、書き始めと書き直しを確かめる

ここからは当社の整理です。

事務で使う場面に戻り、入力を始める場面と、いったん目を離して戻る場面を試します。確認用の欄と文章を用意してから、次のように見る箇所を絞ると整理しやすくなります。

試す場面見るところ残す判断
連絡文を書き始める最初に文字を入れる位置書き始める場所を見つけられたか
備考の言葉を書き直す語の途中の文字と文字の間書き足す側を読み取れたか
別の欄を見てから戻る続きを書く位置と周囲の文戻ったあとに位置を探し直したか

試す際は、目印が見えるという確認と、意図した場所へ文字を足せるという確認を分けます。短い言葉を追加したあと、前後の文を読み返し、狙った位置に入っているかまで見る流れです。これにより、表示の感想だけで終わらず、困っていた操作に戻って判断できます。

入力欄が並ぶ画面では、どの欄で試したかも残すとよいです。同じ画面という説明だけにせず、本文欄、件名欄、備考欄といった呼び方で対象を示します。欄を移ったあとに確かめた結果も分けておくと、別の担当者が同じ場所で見直せます。

5．表示が合わない場面を切り分け、引き継ぐ

期待した表示にならないときは、設定を開いたままの見え方と、入力作業に戻ったあとの見え方を分けて書き留めます。プレビューでは分かったのに入力欄では分からないのか、位置は分かるが文章との境目が読みにくいのかで、相談する内容が変わります。原因を断定せず、観察できた状態をそのまま残す考え方です。

担当者へ渡す記録には、使ったアプリの名前、問題の入力欄、変更した項目、試した操作と見え方を含めます。入力を始めたとき、文章の途中へ戻ったとき、別の欄から戻ったときのどこで困ったかも添えると、再確認する動作を共有できます。見える欄と見えない欄があれば、結果を混ぜずに並べます。

引き継ぐ人が代わる場合も、前の人と同じ見え方を良しとせず、実際に入力する人の判断を残します。変更後の表示をそのまま使いたいのか、調整を続けたいのか、元の状態と比較したいのかを記録しておくと、次の操作の目的が伝わります。

事務の手間を洗い出すなら、入力位置を探す負担と、文章を考えたり転記したりする負担を分けて記録するとよいです。AIを業務に取り入れる進め方 を検討する際も、どの作業で手が止まるかを具体的にしておくと、検討する範囲を整理できます。
