Copilot ページの［ページで編集］は追加の契約なしで使える？

要点

職場または学校（Entra ID）のアカウントでは、Copilot ページは SharePoint または OneDrive のストレージを持つユーザーが使え、Microsoft 365 Copilot のライセンスが無いユーザーも含まれるとされています。 個人用の Microsoft アカウントでは、Microsoft 365 Personal、Family、Premium、Pro のサブスクライバーが対象です。 ページそのものは追加のライセンスが無くても試せますが、Copilot が社内のデータをどこまで材料にできるかは、ライセンスの有無で変わります。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

追加のライセンスを買っていない社員が［ページで編集］を押しても使えるのか。職場のアカウントと個人用で条件が違い、Copilot が社内のデータを材料にできる範囲も変わります。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．［ページで編集］はどこにあるか

確認日：2026年11月17日。

Copilot Chat の回答の下の省略記号を選ぶと、［ページで編集］のボタンがあり、回答を既存のページに足すか、新しいページにするかを選べます。 新しいチャットから始めるときは、プロンプトの入力欄の左のプラスのボタンから［その他］にカーソルを合わせ、［下書きページまたはコード］を選びます。

ページは Copilot Chat と並べて開かれ、ページの中身を自分で直接直すことも、Copilot に頼んで足したり直したりすることもできます。 使い方の例としては、プロジェクトの概要、ベンダーの比較、会議のメモ、連絡の下書きなど、時間とともに育ち、チームで共有する内容が挙がっています。

ヘルプには、Chat と Cowork が一緒になる新しい［ホーム］が展開中のため、アプリの表示が記事の説明と違う場合があると注記されています。 ボタンの場所が見当たらないときは、画面の写しを残して、展開の状況を管理者に確かめます。

2．追加の契約の要否は、アカウントの種類で分かれる

会社の事務で使うのは、多くの場合、職場のアカウントです。この場合の条件は「SharePoint または OneDrive のストレージを持つこと」で、Microsoft 365 Copilot のライセンスは条件に入っていません。 まず試す人のアカウントに OneDrive があるかを、管理者が確かめます。

一方、Copilot Chat を使うには、Microsoft 365 のアカウントでサインインし、対象となるビジネスまたはエンタープライズのサブスクリプションを持っている必要があり、使える機能は、管理者が Copilot のアドオン ライセンスを割り当てているかで変わるとされています。 ヘルプの表では、ライセンスが無い場合の作業データの推論はアップロードしたファイルに限られ、ある場合は会議、メール、チャット、ファイルなどに広がります。

つまり、ライセンスの無い人が［ページで編集］で作るページは、Web の情報や自分でアップロードしたファイルをもとにした回答を育てる場になります。社内のメールや会議の内容まで材料にしたい、という目的なら、ページの可否とは別にライセンスの検討が要ります。自分に何が割り当てられているかは、copilot.cloud.microsoft にサインインして、名前の下のラベルで確かめるよう案内されています。

料金はこれらのヘルプには書かれていません。ライセンスやプランの条件は変わりうるため、検討するときは、その時点の Microsoft の公式のプランの案内と、契約している販売店の見積もりで確かめます。

3．保存先と共有を、試す前に決める

Copilot ページは、ユーザーが所有する新しい SharePoint 埋め込みコンテナーに .page ファイルとして保存されます。 ページは削除するまで使い続けられます。 作った人が異動や退職をしたときに、そのページをどう引き継ぐかは、ヘルプの範囲では分かりません。試す段階では、残す必要のある内容は社内の決まった保存場所へ移す、と決めておきます。

共有は、ページの右上の［共有］から選びます。［リンクのコピー］なら、同僚は Loop で開くそのページだけにアクセスでき、［コンポーネントのコピー］なら、Teams や Outlook などに貼ったコンポーネントでの変更がリアルタイムでページに反映されます。 取引先とのやり取りのメールにコンポーネントを貼る使い方は、試す段階では避け、社内の人どうしのリンクの共有に限る、という線引きが分かりやすくなります。

組織が IT で Copilot を管理している場合は、ページで使える AI ツールとデータ ソースを管理者が制御できるとされています。
