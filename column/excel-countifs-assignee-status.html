Excelで担当者と対応状況が一致する明細を数えるには？

要点

ExcelではCOUNTIFSに担当者列と担当者の条件、対応状況列と状況の条件を順に渡します。2つの範囲は同じ明細の開始行と終了行にそろえます。両方の条件に当たる行を数えるため、集計後は元の一覧でも対象行を確かめます。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、Excelの対応記録から担当者と対応状況がそろう件数を数えたい小さな会社の担当者が、COUNTIFSの範囲と条件の対応を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月9日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 集計前に、どの明細を1件とするか決める
  2. 担当者列と状況列を同じ行にそろえる
  3. 条件の書き方と、部分一致の注意
  4. 条件の空欄と、明細の未記入を分ける
  5. 元の一覧を絞り込み、集計と照合する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．集計前に、どの明細を1件とするか決める

確認日：2026年11月9日。

Microsoftの案内では、COUNTIFSは複数の範囲に条件を適用し、すべての条件に当たる位置を数える関数です。ここではWindows版Excel for Microsoft 365の一覧で、1行に1件の対応記録がある場合を扱います。

書式は COUNTIFS(条件範囲 1, 検索条件 1, [条件範囲 2, 検索条件 2],…) で、追加の範囲と条件の組は最大127組まで指定できます。関数のページの適用先には、Excel for Microsoft 365（Mac版を含む）、Excel 2016〜2024、Excel Web App が挙がっています。

ここからは当社の整理です。

集計したい期間と一覧を先に決め、見出し行や小計行が明細に混じっていないか見ます。同じ案件に複数の行がある一覧では、行数を集計するのか、案件の数を知りたいのかを依頼元へ確かめます。

2．担当者列と状況列を同じ行にそろえる

Microsoftは、追加する条件範囲を最初の範囲と同じ行数・列数にするよう案内しています。範囲同士が隣接する必要はありません。Microsoftの解説では、それぞれの範囲の条件は一度に1つのセルに適用され、各範囲の最初のセルがすべての条件を満たすと数が1増え、続けて2つ目のセルも同じように評価されます。担当者の範囲と状況の範囲は、同じ行の明細を表すように選びます。行数が同じでも開始行がずれると、別の明細の条件を照合することになります。

COUNTIFSに入れる順番指定するもの照合する内容
1番目の範囲明細の担当者欄見出しを除いた明細の最初と最後
1番目の条件数えたい担当者を指定する欄一覧の担当者表記と一致するか
2番目の範囲明細の対応状況欄担当者欄と同じ行にそろうか
2番目の条件数えたい対応状況を指定する欄一覧で使っている区分と一致するか

担当者や対応状況を選び直して使う集計表では、どのセルを条件にするかを明示します。入力表と集計表が別のシートにある場合は、式の参照先を確認してから、次の集計欄へ写します。

3．条件の書き方と、部分一致の注意

Microsoftの案内では、検索条件は数値、式、セル参照、文字列のいずれかで指定します。使用例には、同じ範囲に2つの条件を付けて1より大きく6より小さい数を数える式や、条件で定数の代わりにセル参照を使う式もあります。

同じ案内では、条件には半角の疑問符（?）とアスタリスク（*）をワイルドカードとして使え、疑問符は任意の1文字、アスタリスクは1文字以上の任意の文字列を表します。疑問符やアスタリスクそのものを探すときは、その文字の前にチルダ（~）を付けます。

担当者名や状況名を式に直接書くと、選び直すたびに式を書き換えることになるため、条件は別のセルに入れ、式ではそのセルを指定します。期間でも絞る場合は、日付の列を条件範囲に加え、開始日と終了日をそれぞれ条件のセルに入れて、同じ日付の列に2つの条件を付けます。ワイルドカードを使って状況名の一部だけで数えると、同じ語を含む別の区分も数えるため、区分を数えるときは一覧で使っている区分名をそのまま条件にします。区分名に「*」や「?」が入っている場合は、チルダを付けたかを確かめます。

4．条件の空欄と、明細の未記入を分ける

Microsoftによると、検索条件に空のセルへの参照を指定した場合、そのセルは0として扱われます。担当者を選ぶ欄や状況を選ぶ欄が空いているときは、集計結果の数字だけを見ず、条件の指定を先に確かめます。

一覧の状況名がそろっていない場合は、入力時の区分を管理する担当に確認します。未入力を数えたい場合と、特定の状況に該当する明細を数えたい場合では、集計の目的が違います。未入力にどんな値を入れるかを決める前に、その欄が誰の確認を待っているかを調べます。

5．元の一覧を絞り込み、集計と照合する

同じ期間と範囲を使って元の一覧を開き、対象の担当者と対応状況の両方に該当する明細を確認します。集計が少ないと感じた場合は、式の条件と元の表記がそろうか、明細が途中までしか含まれていないかを確かめます。

明細が追加された後も使う表では、担当者と状況の参照範囲を一緒に見直します。集計結果を渡すときは、対象にした期間、担当者、状況、どの一覧の版を使ったかを添えます。
