Excelで予算に対する使用率を計算し百分率で表示する手順

要点

予算に対する使用率は、使用額を予算額で割り、求めた割合を百分率の表示に切り替えて示します。事務の表では、分母にする予算額の範囲と、使用額の集計範囲をそろえることが出発点です。計算する欄と金額を入力する欄を分けると、引き継ぐ人も式の意味を追いやすくなります。

公開：2026年11月3日／情報の確認日：2026年11月3日（出典はこの記事の最後）

この記事は、Excelで予算の使用状況を管理する小さな会社の事務担当者が、使用額を予算額で割って百分率で表示し、結果が合っているかを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月3日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 使用額を予算額で割り、表示を切り替える
  2. 予算表では、計算の前に範囲と単位をそろえる
  3. 金額の欄と、割合を計算する欄を分ける

1．使用額を予算額で割り、表示を切り替える

Microsoft サポートのページ「Excel で数値をパーセンテージとして書式設定する」と「パーセンテージを計算する」は、Excel for Microsoft 365、Excel 2024、Excel 2021（どれも Mac 版を含む）と、Excel 2019、Excel 2016 を適用先に挙げています。（確認日：2026-11-03）

「書式設定」のページは、パーセンテージを「値 / 合計 = パーセンテージ」という等式で計算すると説明しています。たとえば、セルに「=10/100」という数式があれば計算結果は 0.1 になり、その 0.1 の表示形式をパーセンテージに設定すると 10% と表示されます。（確認日：2026-11-03）

数式には、金額を直接書く代わりに、その金額が入っているセルを選び、選んだセルの間に演算子を入力できます。入力した数式は Enter キーで確定します。（確認日：2026-11-03）

「書式設定」のページの例では、50 点満点のテストで 42 点を取った学生の正解率を求めるために、B2 に正解した得点、C2 に満点の数値が入っている場合、D2 に「=B2/C2」と入力します。（確認日：2026-11-03）

選択したセルにパーセンテージの表示形式をすばやく適用するには、[ホーム] タブの [数値] グループにあるパーセンテージ スタイルをクリックするか、Ctrl+Shift+% を押します。表示する小数点以下の桁数を決めるときは、[セルの書式設定] ウィンドウの [カテゴリ] リストで [パーセンテージ] を選び、[小数点以下の桁数] ボックスに桁数を入力します（このウィンドウの開き方は Windows と Mac で異なります）。（確認日：2026-11-03）

「パーセンテージを計算する」のページの例では、全 50 問のテストで 42 問正解したとき、空白のセルに「=42/50」と入力すると結果は 0.84 になり、その結果のセルを選んで [ホーム] タブでパーセント スタイルを選ぶと 84.00% となります。表示される小数点以下の桁数は、変更できるとも書かれています。（確認日：2026-11-03）

「書式設定」のページは、すでに数値が入っているセルにパーセンテージの表示形式を適用すると、Excel はその数値に 100 を掛けて表示するとしています。たとえば、セルに数値 10 が含まれていると、1000.00% と表示されます。正確に表示するには、表示形式をパーセンテージにする前に、その数値がパーセンテージ値として計算されていて、小数点付きで表示されていることを確認する、とされています。（確認日：2026-11-03）

「エラー値 #DIV/0! を修正する方法」のページは、0 や空白のセルを数式で参照したときなどに、Excel で #DIV/0! エラーが表示されると説明しています。（確認日：2026-11-03） 解決の方法として、数式の除数がゼロまたは空白セルでないことを確認することが挙げられています。（確認日：2026-11-03） また、IFERROR 関数と IF(ISERROR()) の方法は、どちらも #DIV/0! だけでなくすべてのエラーを抑制するため、エラー処理を適用する前に数式が適切に動作することを確認する必要がある、と注意しています。（確認日：2026-11-03）

Mac 版の Excel（Excel for Microsoft 365 for Mac、Excel 2024 for Mac、Excel 2021 for Mac）を適用先とするページ「日付、時刻、通貨、小数、またはパーセンテージを表示する」には、表示形式を設定しても、計算の実行時に使用されるセルの値には影響せず、実際の値は数式バーに表示されると書かれています。（確認日：2026-11-03） Windows 版の Excel について同じことを説明するページは、この記事では確認していません。

ここからは当社の整理です。

2．予算表では、計算の前に範囲と単位をそろえる

まず、何の予算に対する割合なのかを表の見出しに残します。費目別の予算を見るのか、まとめた予算を見るのかを決め、その範囲に対応する使用額を並べる形です。予算と使用額の集計期間が食い違っていないかも、入力前に確認するとよいです。

分母は、割る側に置く基準の金額を指します。ここでは予算額を基準とし、使用額がどの程度を占めるかを求める方針です。「予算額」と「使用額」の列名を省かずに書いておくと、後から式を見直す手がかりになります。

金額の単位は、予算額と使用額でそろえます。元の資料と表の単位が異なる場合は、そろえた後の金額を入力する運用にします。入力した人だけが単位を覚えている状態を避け、見出しにも単位を添えるとよいです。

3．金額の欄と、割合を計算する欄を分ける

下表の配置では、使用額をB2、予算額をC2に入れ、使用率を表示するD2に「=B2/C2」と入力します。公式ヘルプの例（得点をB2、満点をC2に入れる並び）に合わせた配置です。先に列の意味を決めてから、使用率を求める欄へ式を入れる流れです。金額が入っている欄に上書きすることを避け、入力欄と計算欄を区別しておきます。引き継ぎ用の説明では、「使用額を予算額で割る」という式の意味も添えるとよいです。

表示を百分率に切り替える対象は、割合を計算した結果の欄です。金額を入力した欄までまとめて選ばず、どの列の表示を変えているかを確かめながら進めます。

下表は、公式ヘルプの計算例の数字（42と50）を借りて、予算表の形に当てはめた配置です。金額の欄は、同じ単位で入力する形にしています。

A列：費目B列：使用額（円）C列：予算額（円）D列：使用率
説明用の費目425084.00%

表の数値と計算結果は、説明用の例です。D列の84.00%は、小数点以下を2桁表示した場合の見え方で、桁数は設定で変わります。

この配置は、使用額と予算額の関係を見るための最小限の形です。日々の表へ移すときは、費目の名称を対象の資料と合わせておきます。表の見た目だけを移すのではなく、基準にした金額がどの資料のどの範囲なのかも残すと、確認を引き継ぎやすくなります。

5．表示が合わないときは、式と元の金額を分けて見る

まず数式を見直し、その後に金額の入力状況を確かめる順序です。

表示が大きすぎる場合

上で挙げたとおり、数値 10 が入っているセルにパーセンテージの表示形式を適用すると、1000.00% と表示されます。当社の確認手順では、表示を変更する前に割合の計算が済んでいるか、式に不要な掛け算を足していないかを先に見ます。予算額と使用額の入力欄まで、表示を変更していないかも確認対象です。

予算額が未入力の場合

予算額のセルがゼロまたは空白だと、割り算で「#DIV/0!」が出る原因になります。当社の整理では、エラーを見えなくする設定を加える前に、予算額の入力状況を調べます。金額が未入力なのか、参照する欄を取り違えたのかを区別し、元の表へ戻って確認する方が、修正の理由を残しやすくなります。

見える桁と計算に使う値を混同しない

上で挙げた Mac 版のページでは、表示形式を変えても、計算に使われるセルの値自体には影響しないとされています。当社の整理では、見た目を整える作業と、入力した金額を直す作業を分けます。表示だけを直して作業を終えず、元の金額と式の向きも併せて確かめる運用です。

6．引き継ぎには、式の意味と入力元を残す

使用率だけを切り出して渡すより、予算額と使用額を並べ、どの金額から計算したかをたどれる形にするとよいです。

計算の欄を変更したときは、列名との対応も見直します。入力元の資料、集計の範囲、金額の単位を表の近くへ残しておくと、次の担当者も同じ基準で確認できます。表示された割合から予算の配分や支出の是非を判断する手順は、この記事では扱いません。
