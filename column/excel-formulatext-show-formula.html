Excelで計算結果の隣に使っている数式を表示するには？

要点

計算結果が入っているセルの隣に表示用のセルを用意し、FORMULATEXTの引数に結果のセルを指定します。隣に出た式が参照元の数式バーと一致するか確かめます。エラー値の#N/Aが出た場合は、参照元に式があるか、別のブックが開いているか、式が保護されていないかを調べます。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、Excelの計算結果を残したまま使っている式を別のセルで見せたい小さな会社の担当者が、FORMULATEXTの指定とエラー値の原因を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月9日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 表示用の列を決める
  2. FORMULATEXTで確認したいセルを指定する
  3. 数式バーと別セルの表示を照合する
  4. エラー値が出たときは参照元の状態を調べる
  5. シート全体の式を見る表示との使い分け
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．表示用の列を決める

確認日：2026年11月9日。

Microsoftの日本語ヘルプでは、FORMULATEXTは引数に指定したセルの数式を文字列として返す関数と説明されています。関数のページの適用先には、Excel for Microsoft 365（Mac版を含む）と Excel 2016〜2024 が挙がっています。使用例では、セル A2 に =TODAY() が入っているとき、C2 に =FORMULATEXT(A2) を入れると、C2 には =TODAY() がテキストとして表示されます。

ここからは当社の整理です。

計算結果の列を残し、その隣や確認用のシートに式を表示する場所を設けます。確認する結果の項目名や行番号を控え、どの結果の式がどこに出るか分かるようにします。

2．FORMULATEXTで確認したいセルを指定する

公式ヘルプでは、FORMULATEXTの引数にセルやセル範囲の参照を指定できると案内しています。

同じヘルプでは、対象は別のワークシートやブックでも指定できます。ただし、対象が行全体や列全体、複数のセルを含む範囲や定義名のときは、その左上隅のセルの値が返されます。また、FORMULATEXTを入れたセル自身への参照を入力しても、循環参照に関する警告は出ないと説明されています。

表示用のセルを選び、「=FORMULATEXT(」と入力します。式を調べたい計算結果のセルを選び、閉じ括弧を入れて確定します。確認したい計算結果ごとに1セルを指定すると、どの結果とどの式が対応するか追いやすくなります。範囲を指定しても左上のセルの式しか出ないため、1行ずつ隣のセルを指定し、式を下へコピーしたときに参照先が1行ずつずれているかを確かめます。引数を自分のセルにしてしまっても警告では気づけないため、引数のセル番地を目で確かめます。

3．数式バーと別セルの表示を照合する

公式ヘルプによると、関数から返るのは、参照元のセルを選んだときに数式バーに出る内容です。

元のセルを選び、数式バーの表示と確認用のセルを見比べます。同じ式を入力したつもりでも、参照列や固定する位置に違いがあれば、対象の行を特定して元の式を確認します。表示欄だけを別の担当へ送る場合は、式を取り出した元の表と対象のセルが分かるようにします。

4．エラー値が出たときは参照元の状態を調べる

Microsoftは、参照先に式がない場合、別のブックが開いていない場合、保護などで式が表示されない場合、または式が8,192文字を超える場合に、#N/Aが返ると案内しています。入力として無効なデータ型を使った場合は、エラー値 #VALUE! が返されます。

「保護などで式が表示されない場合」に当たる設定として、Microsoftの別のページは、セルの書式設定の［保護］タブで［非表示］をオンにしてからシートを保護する手順を示しています。この手順を行うと、数式が入力されているセル自体も編集できなくなります。保護を解除して数式を再表示するときは、［校閲］タブの［シートの保護を解除］を選びます。

まず参照が目的のセルかを確認し、そのセルの内容を数式バーで見ます。参照先が別のブックにあれば、そのブックが開いているかを確かめます。保護された式の確認が必要な場合は、保護を外す操作をする前に、表の管理担当へ対象のセルと確認したい点を伝えます。参照先に式があるはずなのに#N/Aになるときは、そのセルに数式ではなく値が貼り付けられていないかも数式バーで確かめます。

5．シート全体の式を見る表示との使い分け

Microsoftの案内では、［数式］、［数式の表示］の順に選ぶか、Ctrl キーを押しながら `（アクサン グラーブ）キーを押すと、数式と結果の表示を切り替えられます。このページの適用先は Excel for Microsoft 365 と Excel 2016〜2024 で、Windows と Web の欄があります。

この切り替えでは、セルに結果の代わりに数式が出ます。結果と式を同じ画面で並べて見比べたいときや、式を文字として別の担当へ渡したいときは FORMULATEXT を使い、シート全体の式をひととおり見たいときは表示の切り替えを使います。切り替えた表示のまま共有しないよう、渡す前に結果の表示へ戻したかを確かめます。
