Windowsで届いたZIP資料を展開し作業を始める手順と確認

要点

届いたZIP資料をまとめて展開するには、［すべて抽出］を使います。先に作業用の置き場を決め、受け取った状態を残す場所と修正する場所を分けるとよいです。取り出した資料がそろっているか、開く対象が作業用の場所にあるかを確認してから編集を始めます。

公開：2026年11月8日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、WindowsでZIP資料を受け取る小さな会社の担当者が、資料全体・個別の展開と作業用の置き場を分け、内容と保存先を照合する手順をまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 資料全体を取り出す操作から始める
  2. 必要なファイルだけを取り出す方法もある
  3. 受信したままの資料と作業用の置き場を分ける
  4. 編集前に内容の不足と保存場所を照合する
  5. 開けない資料は拡張子だけを変えない
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．資料全体を取り出す操作から始める

確認日：2026年11月6日

展開手順を説明する公式ヘルプの適用先は、Windows 11とWindows 10です。資料全体を取り出すには、対象のZIPフォルダーを右クリックまたは長押しし、［すべて抽出］を選んで画面の指示に従います。

操作前に、受信した資料の保存場所と、これから作業する場所を決めておきます。相手からの案内と対象のファイル名を照らし、今回届いたものを選んでいるかを見るとよいです。以前の受信分が近くにある場合も、見た目の似た名前だけで選ばず、今回の連絡に対応する資料かを確かめます。

画面の案内に沿って進める際は、取り出した資料の置き場を意識します。操作が終わったら、決めた場所を開き直し、取り出された内容を確認してから編集へ進む流れです。受信した資料を探す段階と、取り出した内容を扱う段階で、見ている場所を切り替えます。

2．必要なファイルだけを取り出す方法もある

必要なファイルやフォルダーだけを展開するには、ZIPフォルダーを開き、対象を中から新しい場所へドラッグします。

どこまで取り出すかは、今回の作業で使う資料を基に決めるとよいです。資料一式を確認する仕事では全体を対象とし、指定された書類だけを見る仕事では対象を絞る、という分け方ができます。ただし、必要な範囲が分からないときは、送付元の案内を読み直してから選びます。

個別に取り出した後は、選んだ資料と残した資料を混同しないようにします。手元に取り出した分を「届いた資料のすべて」と扱わず、確認の対象を区別する考え方です。ほかの担当者へ渡す際も、全体を取り出したのか、作業に必要な部分だけなのかを伝えておきます。

3．受信したままの資料と作業用の置き場を分ける

ここからは当社の整理です。

同じような名前のものが並ぶときは、名前に加えて保存場所と用途を照合します。受信したまま残すもの、取り出した内容、編集しているものを見分けられるようにすると、作業を再開する場所も伝えやすくなります。

次の表は、受信した資料と作業する資料の置き場を分けるための項目案です。

対象置き場の役割作業前の確かめ
受信したままの圧縮資料届いた状態を残す今回の送付案内に対応するものか
取り出した資料内容を確認し、作業を始める場所必要な本文や添付資料がそろっているか
修正中の資料担当者が編集を続ける場所編集対象と保存する場所を共有できているか

表のように役割を決めた後は、実際に使うフォルダーの場所を担当者間でそろえます。「届いた資料を開く」という説明だけでは、どの段階のものを指すかが曖昧です。引き継ぎでは、作業を始める場所と、受信した状態を残す場所を分けて伝えるとよいです。

取り出し直す場合も、すでに編集している資料の置き場を先に確かめます。途中の作業をどこに残したかが分からないまま、似た名前の候補を増やさないための確認です。社内の保管ルールがある場合は、その扱いに合わせます。

4．編集前に内容の不足と保存場所を照合する

作業開始の確認は、内容と置き場に分けると進めやすくなります。まず、送付元の案内にある資料名を、取り出した内容と照合します。名前の一致だけで終えず、今回の案件や用途に合う内容か、参照する付属資料が不足していないかも見るとよいです。

次に、使う資料を作業用の場所から開き、編集後の保存先を確かめます。受信したままの資料を見直しているのか、取り出した資料で作業しているのかを、開く前に区別しておく流れです。作業用として決めた場所に戻って対象を選ぶと、途中で迷ったときの確認先になります。

不足や内容の違いが見つかった場合は、展開を繰り返す前に、何が合わないのかを整理します。送付案内にはあるが見当たらない資料、名前は一致するが内容が違う資料など、気づいた点を分けておくとよいです。送付元に確かめる内容と、社内で作業場所を確かめる内容を切り分けて扱います。

引き継ぎ時は、確認した範囲と未着手の範囲も添えます。取り出す操作が終わったことと、資料の内容を確かめ終えたことを分けて伝えれば、次の担当者がどこから確認を始めるかを判断する材料になります。

5．開けない資料は拡張子だけを変えない

ファイル名の拡張子を変更しても、ファイルが別の形式に変換されるわけではありません。

開けない資料があるときは、名前を直して試す前に、どの操作で止まったかを控えるとよいです。取り出す段階で止まったのか、取り出した資料を開く段階で止まったのかを分け、対象の名前、保存場所、画面に出た文面を社内の担当者へ伝えます。

不足している資料と、存在するが開けない資料も分けて扱います。相談する際は、受信した状態を確認できる場所と、作業用に取り出した場所を示すとよいです。表示された文面を基に対応を確かめ、続きを行う対象が決まってから作業を再開します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□今回の送付案内と、受け取った資料の名前を照合したか
□資料全体を扱うのか、必要な部分だけを扱うのかを整理したか
□受信したまま残すものと、作業用に取り出したものの置き場を区別したか
□案内された資料と、取り出した内容に不足や違いがないか確認したか
□編集する対象と、編集後に保存する場所を確認したか
□止まった操作や表示された文面を、確認先へ伝えられるようにしたか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
