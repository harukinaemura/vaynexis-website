Excelブックを以前の版で使う相手に渡す前に、何を確認する？

要点

相手が使うExcelの版と、受け取ったブックで必要な作業を確かめます。配布用のコピーで互換性チェックを実行し、指摘された機能とセルを確認します。機能を直した後は、可能なら相手が使う版で開き、必要な操作を確かめます。

公開：2026年11月10日／情報の確認日：2026年11月9日（出典はこの記事の最後）

この記事は、以前の版のExcelを使う相手にブックを渡したい小さな会社の担当者が、互換性チェックの対象の版と指摘の扱いを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月9日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 受け手のExcelと必要な作業を聞く
  2. 配布用のコピーで互換性を確認する
  3. 指摘された場所と業務への影響を対応させる
  4. 相手が使う版で確認したことを残す
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．受け手のExcelと必要な作業を聞く

確認日：2026年11月9日。

Microsoftは、互換性チェックで以前の版に対応しない可能性がある機能や情報を特定できると案内しています。

ここからは当社の整理です。

相手が使うExcelの版、見るだけか入力・再計算も必要か、渡すファイル形式の指定を先に聞きます。複数の相手に渡す場合は、必要な版と作業を相手ごとに控えます。

2．配布用のコピーで互換性を確認する

Microsoftの案内では、WindowsのExcelで互換性を調べるときは、［ファイル］、［情報］、［問題のチェック］から［互換性の確認］を選びます。このページの適用先は Excel for Microsoft 365、Excel 2024、Excel 2021 です。チェックに含める版を選べます。既定ではすべての版がオンになっているため、含めたくない版のチェックを外します。また、［このブックの保存時に互換性を確認する］チェック ボックスをオンにすると、以後は保存のたびに互換性チェックが自動的に実行されます。相手から .xls 形式で渡すよう求められた場合は、［ファイル］＞［エクスポート］＞［ファイルの種類の変更］を選び、［ブックのファイルの種類］で形式を選んで保存する手順が案内されています。

元のブックを保存し、配布用のコピーを開いてから調べます。相手が使う版を対象にして、対象の版が結果の記録に残るようにします。複数の版の結果を比べるときは、どの版について調べたものかを分けます。

3．指摘された場所と業務への影響を対応させる

公式の案内では、［検索］リンクで問題の場所へ移動でき、［ヘルプ］リンクで説明を確認できます。

数式の互換性の説明では、機能の大幅な損失と、表示や動作の再現性の低下を分けています。

同じ説明では、機能の大幅な損失に挙がった問題は、データが永久に失われたり正しい機能が損なわれたりするのを防ぐため、ファイルを保存する前に解決できるとしています。再現性の低下の問題は、解決が必要な場合も必要でない場合もあり、データや機能は失われないものの、以前の版で開いたときに表示や動作が異なる場合があるとしています。調べる問題が多い場合は［新しいシートにコピー］を選び、作られた互換性チェック シートで1件ずつ解決できます。

Excel 97-2003 の形式で保存する場合の例として、同じページは次のような指摘を挙げています。

指摘の内容以前の版での結果
以前の版で使えない関数がある再計算すると #NAME? エラー。数式に _xlfn が付くことがある
テーブルへの構造化参照があるセル参照に変換される
入れ子のレベル数や関数の引数の個数が上限を超える数式が保存されず、#VALUE! エラーに変換される
閉じている別のブックのテーブルを構造化参照で指している#REF エラーに変換される

新しい関数は、以前の版で使える関数に置き換えるか、数式の結果に置き換えて数式を削除することもできると案内されています。

指摘ごとに、対象のシート、場所、機能の名前、相手がその機能を使うかを控えます。配布用のコピーで修正する場合は、直した箇所と元のブックで保持する内容を確認します。新しい関数を値に置き換えたコピーは再計算されない値になるため、元のブックと取り違えないよう別名にします。相手の版が .xlsx を開ける版でも、Microsoft 365 の Excel で作った式に相手の版に無い関数が入っていないかを、その関数のページの適用先で確かめます。

4．相手が使う版で確認したことを残す

修正したコピーは別名で保存し、相手が使う版で開ける場合は、見る・入力する・再計算するなど必要な作業を試します。実際の版で確認できなかった作業は未確認として渡します。

配布時には、対象版、変更した箇所、確認できた作業、残っている確認を短く添えます。次に同じブックを更新するときも、再確認する箇所が分かります。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□相手が使う版と必要な作業を聞いたか
□元のブックと配布用コピーを分けたか
□互換性チェックの対象版を確認したか
□機能の大幅な損失と再現性の低下を分け、保存前に直すものを決めたか
□新しい関数・構造化参照・閉じた別ブックへの参照の指摘を確かめたか
□指摘箇所と業務上の影響を対応させたか
□相手の版で確かめた結果と未確認の作業を区別したか

6．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月9日）

  • Microsoft Excel での数式の互換性の問題：機能の損失と再現性の違いと扱い、新しいシートにコピー、97-2003 形式の指摘の例、新しい関数の置き換え
