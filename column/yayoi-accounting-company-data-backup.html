弥生会計で事業所データのバックアップを取るには？

要点

弥生会計のバックアップは、クイックナビゲータの［事業所データ］カテゴリから［バックアップ］をクリックして始めます。 バックアップは事業所データごとに行い、現在開いている事業所データのすべての年度が保存されます。 保存先は、パソコンのハードディスクだけでなく、外付けのハードディスクや USB メモリなどにも分けておくことが勧められています。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

経理のパソコンが急に動かなくなったら、弥生会計の帳簿はどこまで戻せるのか。事業所データのバックアップファイルを作る画面の手順と、上書きや保存先で失敗しないための決めごとを確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．バックアップファイルとは何か

確認日：2026年11月17日。

対象は、パソコンにインストールして使う弥生会計です。弥生のサポートでは、データファイルは事業所データのことで、弥生会計ではこのデータファイルを開いて日常作業を行うと説明されています。 これに対してバックアップファイルは、事業所データのコピーを圧縮して保存したファイルで、そのままでは開くことができず、使うには事業所データに復元する必要があります。

弥生のサポートは、事業所データを誤って消してしまった場合、コンピューターの故障やウイルスによるデータの損失、火災・震災・停電、元に戻せない操作をする場合などに備えてバックアップをするよう勧めています。 バックアップファイルがあれば、バックアップを行った時点の事業所データを復元することができます。

2．取る前に確かめる3つのこと

1つ目は、どの事業所データを取るかです。複数の事業所データがある場合は、バックアップする事業所データに切り替えて、それぞれ行う必要があります。 グループ会社の分や、個人の分を同じパソコンで管理している場合は、開いている事業所名を画面で確かめてから始めます。

2つ目は、年度の範囲です。バックアップは事業所データ単位で行われ、会計年度単位で作成することはできません。 「今期の分だけ」を取ることはできないので、過去の年度も含めたファイルになると考えておきます。

3つ目は、入力途中の作業です。バックアップファイルを作成する際には、開いているすべての画面が自動的に閉じられるため、入力途中のデータがある場合は、作業が終わってから行うよう案内されています。 複数の人が同じデータを使っている場合は、ほかの人の入力が終わっているかも声をかけて確かめます。

3．画面の手順

  1. クイックナビゲータの［事業所データ］カテゴリから［バックアップ］をクリックする。
  2. ［保存場所］に表示された前回の保存先を確かめる。変える場合は［参照］をクリックして保存したい場所を開く。
  3. ［ファイル名］が表示されていない、または変更が必要な場合は［ファイル名］を入力して［保存］をクリックする。
  4. ［事業所データのバックアップ］画面に戻ったら、［保存場所］の表示を確かめて［OK］をクリックする。
  5. バックアップの終了メッセージが表示されたら、［OK］をクリックする。

マルチユーザーでユーザー管理している場合は、排他モードで起動すると案内されています。

4．同じ名前のファイルを上書きしない

指定した保存場所に同名のバックアップファイルがある場合は、上書きを警告するメッセージが表示されます。［はい］をクリックすると既存のデータが新しく保存するデータに置き換えられ、上書きしない場合は［いいえ］をクリックしてファイル名を変更します。 毎回同じ名前で上書きしていると、手元に残るのは直近の1つだけになります。誤った操作に後から気づいたときに戻れるよう、ファイル名に日付を入れるなど、社内で名前の付け方を決めておきます。

5．保存場所は2か所に分ける

バックアップファイルの保存場所の初期値は、ドキュメント（Documents）の中の弥生会計のデータフォルダにある Backup フォルダーです。 初期設定では、マルチユーザー以外の場合、弥生会計の終了時には自動バックアップが行われますが、コンピューターに問題が発生した場合は自動バックアップファイルが復元できないことがあるため、USB メモリなどにも必ずバックアップするよう案内されています。 USB メモリなどのメディアは品質劣化などで正常にバックアップできないことがあるとも書かれているので、1つの媒体に頼りきらないようにします。

CD や DVD に残したい場合は、いったん弥生会計でハードディスクにバックアップをした後、そのファイルをコピーして保存する手順です。容量を超えた場合に複数に分割して保存することはできないとされています。

保存場所がわからなくなったときは、Windows の検索機能で「弥生会計バックアップファイル」（ファイルの種類）または「.KB**」（拡張子）を指定して探せます。

6．社内で決めておくこと（架空の例）

弥生のサポートは、作業終了のたびにバックアップすることを勧めています。 経理の担当が1人の会社では、その人が休んだときに誰が取るのか、USB メモリをどこに保管するのかまで決めておかないと、続きません。

決めること架空の記入例
取る人経理の担当。休みの日は総務の担当
取る時毎日の入力の終わり、月次の締めの前後
ファイル名事業所名＋日付
保存先パソコンの Backup フォルダーと、鍵のかかる引き出しの USB メモリ
記録取った日と保存先を一覧に書く

経理の道具やデータの置き場所が担当者の頭の中にしかない場合は、まず一覧に書き出す事務の棚卸しから始めると、バックアップの抜けも見つけやすくなります。
