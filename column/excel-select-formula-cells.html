Excelで計算欄だけをまとめて選ぶ手順と色分け後の確認ポイント

要点

計算欄は、「ジャンプ」から「セル選択」を開き、数式を含むセルをまとめて選びます。 選択したセルは「塗りつぶしの色」で背景を変えられます。 対象範囲と選ばれた欄を照合し、色の意味を残すと引き継ぎにも使えます。

公開：2026年11月3日／情報の確認日：2026年11月3日（出典はこの記事の最後）

この記事は、Excelの表で手入力する欄と計算する欄を見分けたい小さな会社の事務担当者が、数式のセルをまとめて選び、色の意味を引き継ぐまでの流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月3日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．公式ヘルプにある、数式のセルの選択と背景色の手順（Windows 版）

Microsoft サポートの各ページは、適用先を次のように示しています。「Excel で特定の条件を満たすセルを検索して選択する」は Excel for Microsoft 365・Excel 2024・Excel 2021、「数式を含むセルを検索」は Excel 2024・Excel 2021・Excel 2019・Excel 2016、「Excel で特定のセルまたは範囲を選択する」「Excel でセルの背景色を追加または変更する」「数式の表示や印刷を行う」「Excel の数式の概要」は Excel for Microsoft 365・Excel 2024・Excel 2021・Excel 2019・Excel 2016 です。（確認日：2026-11-03）

「Excel で特定の条件を満たすセルを検索して選択する」のページは、Excel for Windows では、[ジャンプ] コマンド（Ctrl+G）を使うと、数式などの特定の種類のデータを含むすべてのセルをすばやく検索して選択できると説明しています。（確認日：2026-11-03）

「数式を含むセルを検索」のページは、1 つのセルを選択するとワークシート全体が検索され、範囲を選択するとその範囲のみが検索されると説明しています。（確認日：2026-11-03）

公式ヘルプにある、数式を含むセルをまとめて選ぶ操作は、次のとおりです。

  • Ctrl+G（または F5）キーを押して、「ジャンプ」の画面を開きます。（確認日：2026-11-03）
  • 「ジャンプ」の画面で「セル選択」をクリックし、目的のオプションをクリックします。（確認日：2026-11-03）
  • 「数式」を選びます。「数式」の下のチェックボックスは、数式の種類を定義します。（確認日：2026-11-03）
  • 「OK」をクリックします。（確認日：2026-11-03）

ただし、この画面の呼び方は、ページによって異なります。「Excel で特定のセルまたは範囲を選択する」のページは「ジャンプ」の画面の [セル選択] をクリックするとしていますが、「Excel で特定の条件を満たすセルを検索して選択する」のページは [特殊] を選択するとしています。（確認日：2026-11-03）

同じ「特定の条件を満たすセルを検索して選択する」のページは、選択条件の [数式] を「数式を含むセル」と説明し、[数式] の下のチェックボックスは数式の種類を定義すると書いています。（確認日：2026-11-03）

背景色については、「Excel でセルの背景色を追加または変更する」のページの Windows 向けの手順で、強調表示するセルを選び、[ホーム] の [塗りつぶしの色] の横にある矢印を選ぶか Alt+H、H キーを押して、[テーマの色] または [標準の色] のパレットから目的の色を選ぶとされています。（確認日：2026-11-03）

「数式の表示や印刷を行う」のページは、ワークシートのセルには数式の結果が表示され、数式バーには数式が表示されると説明しています。（確認日：2026-11-03） 「Excel の数式の概要」のページは、数式バーに数式を表示するにはセルを選択する、としています。（確認日：2026-11-03）

ここからは当社の整理です。

この記事は、Windows 版の手順だけを扱います。Mac 版と Excel for the web で同じ手順が使えるかは確認していません。公式ヘルプの説明をもとにまとめたもので、実際の画面で操作を試した記録ではありません。

2．確認範囲と使っている版をそろえる

作業前には元のファイルを残し、複製した見本で、どの欄を目印の対象にするかを確かめるとよいです。すでに色に意味がある表は、その意味を担当者に確認してから変更の範囲を決めます。

検索の範囲は、セルをひとつだけ選ぶとワークシート全体、範囲を選ぶとその範囲だけです。まずは確認したい表の内側に絞ると、意図した欄と選ばれた欄を比べやすくなります。離れた場所の集計欄も対象にしたいか、明細欄だけでよいかを先に整理します。

3．数式だけを選ぶ前後の進め方

操作は、確認したい表を選んだ状態から始めます。どの範囲を選んだかを控えておくと、やり直す際の基準になります。

すべての計算欄を目印にする作業では、種類を絞る意図がないのにチェックを外していないかを確認します。何を選ぶかを決める操作と、選ばれた場所が想定どおりかを確かめる作業を分けると、途中で判断が混ざりにくくなります。

操作メモは、画面の位置だけでなく、使った項目の名前も残す形がよいです。ページによって「セル選択」と「特殊」のように呼び方が違うため、引き継ぐ相手の画面と表示が合わないときは、いったん止めて、利用している版と公式ヘルプの適用先を照合します。

4．選んだ計算欄に背景色を付ける

選んだセルには、目印の背景色を付けます。目印にする色は、既存の注意表示や承認済みの表示と区別できるものを担当者同士で決めます。色の種類を増やす前に、何を表す目印なのかを短い言葉にすると整理しやすくなります。

備品の購入明細を例にすると、色分けの方針は次のように置けます。これは表示の決め方の例です。

欄見本での役割表示の方針
品名担当者が入力する欄今の背景を残す
数量担当者が入力する欄今の背景を残す
単価担当者が入力する欄今の背景を残す
明細金額数量と単価から求める欄計算欄の目印を付ける
合計金額明細を集計する欄計算欄の目印を付ける

表全体を同じ色にする方針では、入力する欄との区別が付きません。選ばれた場所が意図した計算欄に当たるかを見てから、背景を変える流れにします。色付け後も、文字の読みやすさと元からあった目印の意味を確認します。

5．選び漏れは範囲・条件・中身の順に調べる

想定より少ない欄しか選ばれなかったときは、まず対象にした表の端まで含めたかを見直します。次に、選択する種類を意図せず狭めていないかを確認し、それでも合わない欄は中身を調べます。見た目だけを頼りに、選ばれなかった場所まで同じ色を付け足すことは避けるとよいです。

上で挙げたとおり、選択条件の「数式」が対象にするのは、数式を含むセルです。計算欄として使う予定の場所でも、今入っている内容が予定どおりかを確かめる必要があります。選ばれなかった欄を、そのまま入力用と判断しないことが確認の要所です。

セルには計算結果、数式バーには数式が表示されるため、気になるセルを選択すると、数式バーでその数式を確認できます。金額の見た目が同じでも、欄の役割と中身が合っているかを見比べる姿勢が大切です。内容を直すかどうかは、表の管理者に確認してから判断します。

また、計算欄を見つける作業と、計算の意味や答えが合っているかを確認する作業は分けて記録します。今回は、対象にした範囲で計算欄の位置を見分けられるところまでを区切りにします。

6．引き継ぎには色の意味と対象範囲を残す

操作のあとに残すのは、色を付けたという報告だけでは足りません。どの表を対象にしたか、何の意味で色を選んだか、判断を保留した欄はどこかを合わせて記録します。確認した範囲が分かれば、次の担当者も続きの作業を決めやすくなります。

引き継ぎメモは、次のように短くまとめられます。

対象：今回確認した明細表の内側
目印の意味：計算に使う欄として位置を確認した箇所
入力する欄：元の背景を残す方針
保留：欄の役割と中身が合わない箇所は管理者へ確認

目印を付けたという記録と、内容まで確認済みという記録を混同しないことが大切です。見本での確認が済んだら、保留箇所を引き継いだうえで、元の表に同じ方針を適用してよいかを管理者と決めます。
