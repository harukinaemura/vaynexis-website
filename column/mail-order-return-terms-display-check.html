確定した通販の返品特約は広告と申込画面のどこで確認する？

要点

インターネット通販で返品特約がある場合、消費者庁の特定商取引法ガイドは、広告に加えて最終確認画面においても表示することが定められていると案内しています（特定商取引法第15条の3第1項ただし書、同法施行規則第44条）。利用ガイドへ詳細をまとめる場合も、広告・利用ガイド・最終確認画面に出ている内容を、確定文言と照合します。

公開：2026年11月6日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、責任者が確定した通販の返品特約を公開前に照合したい小さな会社の事務担当者が、商品広告・利用ガイド・最終確認画面の表示と確定文を並べて確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 確認の対象をそろえてから表示を見ます
  2. 商品広告は説明箇所と利用ガイドを対で確認します
  3. 最終確認画面は広告とは別の照合欄を持ちます
  4. 確定文と掲載箇所を並べて差を残します
  5. 文言の意味が変わる差は責任者へ戻します
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．確認の対象をそろえてから表示を見ます

この記事では、責任者・専門家が確定した文言を、事務担当者が公開前に照合する場面を扱います。対象はインターネットで販売する商品の表示です。受付方針を新たに作る作業から分け、掲載に使う確定文を受け取ったところから始めます。

消費者庁の「通信販売における返品特約の表示についてのガイドライン」が扱うのは、引き渡された商品が種類又は品質に関して契約の内容に適合している状態で設ける返品特約の表示方法です。返品の可否、返品の条件、返品に係る送料負担の有無は重要事項であり、他の事項より明瞭に表示する必要があります。

特定商取引法第11条第5号は、通信販売の広告に表示する事項として、申込みの撤回又は解除に関する事項を挙げ、第15条の3第1項ただし書に規定する特約（返品特約）がある場合はその内容を含むとしています。同法第12条の6第1項は、特定申込みを受ける場合に、その書面又は手続が表示される映像面（インターネット通販のいわゆる最終確認画面）に、商品の分量と、第11条第1号から第5号までに掲げる事項を表示しなければならないと定めています。

契約の内容に適合している商品の返品特約と、適合していない場合の販売業者の責任についての特約は、どちらを表示しているのか明確にする必要があります。販売業者に契約違反がなく、引き渡された商品が種類又は品質に関して契約の内容に適合している場合に返品を認めないときも、その旨を広告に明示する必要があります。返品に応じる場合が不明確な表示では、返品特約がある場合の内容を明確に表示する必要があります。

担当者は、異なる場面の文章をまとめて短くする前に、受け取った文言の区分を維持して並べるとよいです。

2．商品広告は説明箇所と利用ガイドを対で確認します

商品説明の近くに出ている内容

共通の利用ガイドなどを使わない場合は、広告と最終確認画面の各商品の説明箇所に、返品特約の全てを明瞭に、他の事項に埋もれないよう表示する方法が示されています。

共通表示部分を使う広告では、各商品の説明箇所で、主に返品の可否・条件・送料負担に関する文字やマークを明瞭に表示する方法が示されています。その上で、詳細への案内を表示し、クリックすると共通表示部分が開く方法を示しています。

共通表示部分への案内と掲載内容

広告から申込みまでの全ての段階で、利用ガイドなどの案内をクリックすると共通表示部分が開く方法も、広告の表示例の要件です。共通表示部分には、返品特約の記載箇所が一見して分かる表題などを設ける方法が示されています。そこでも、返品の可否・条件・送料負担は、その他の詳細より明瞭に表示する必要があります。

商品によって異なる返品特約が適用される場合は、どの商品にどの特約が適用されるかを分かりやすく表示し、共通表示部分との対応関係を明確にする方法が示されています。

照合では、商品ごとの表示と共通の文章を並べて見ます。案内先に文章が存在するかに加え、その商品に関する記載を見つけられるかが確認の軸になります。

3．最終確認画面は広告とは別の照合欄を持ちます

共通表示部分を使う最終確認画面の例では、各商品の名称や価格等の表示に加えて、返品特約を示す文字やマークを明瞭に、他の事項に埋もれないよう表示します。特約を分類している場合は、対応する分類の文字やマークを、各商品の名称や価格等とあわせて表示する方法も示されています。

その上で詳細への案内を表示し、クリックすると共通表示部分が開く方法です。最終確認画面についても、共通表示部分への案内、その中の表示、商品との対応をあわせて照合します。広告で確認した結果を転記するだけにせず、各商品の表示を別に記録しておくとよいです。

表示の照合は、申込みを実行する操作試験と分けて進めます。確認する文章と掲載箇所を担当者間で共有し、画面の見た目と文言の内容を取り違えないようにします。

4．確定文と掲載箇所を並べて差を残します

ここからは当社の整理です。

照合の前に、責任者から確定文、対象商品の範囲、更新予定、確認を戻す相手を受け取ります。古い案と確定文が混ざらないよう、ファイル名や承認の記録から、今回掲載する文章を識別できる状態にします。

担当確認する時点用意するもの・記録すること
責任者掲載作業を渡す前確定文、対象商品、承認の記録
事務担当者表示を照合するとき商品名、広告の掲載箇所、案内先、申込み前の画面の表示文
更新担当者修正を反映するとき差がある箇所、反映する確定文、修正後の表示
責任者と事務担当者修正後に見直すとき残った差、回答、確認した画面の記録

比較は、同じ商品について、確定文・広告・案内先・申込み前の画面を横に並べて行います。確認結果には「違いあり」だけでなく、抜けている文や異なる表現をそのまま残します。文章の差と、文字が小さい・掲載箇所が見つけにくいといった見え方の差を別の欄にすると、修正を頼む相手が作業を把握しやすくなります。

共通の文章を使う商品と、別の文章を使う商品は、照合する組を分けて管理します。担当者が見比べるときは、商品を識別できる表示と対象の文章を同じ記録に残すと、別の商品で確認した結果を取り違えにくくなります。

記録には、画面名、所在、確認日時、使用した端末、確認者を添えるとよいです。修正後は指摘箇所を見直し、確定文との一致を確認した記録と、回答待ちの記録を分けて残します。

5．文言の意味が変わる差は責任者へ戻します

表現を短くすることで対象範囲や費用の負担が変わるように見えるときは、確定文と掲載文を並べた状態で責任者・専門家に確認します。修正依頼には、問題に気づいた商品の表示と、その案内先の文章を添えると、確認する範囲を共有できます。

確定文の受け渡しで不足が見つかった場合も、担当者が都合のよい解釈を補わず、回答を受けてから照合を進めます。表示の照合を終えた記録と、判断が必要で保留した箇所を分けて引き継ぎ、法的な有効性や個別の返品対応の可否は、公式資料を示して専門家に確認します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□掲載に使う確定文と、その対象商品を確認したか
□商品広告と案内先の文章を、確定文と照合したか
□可否・条件・送料負担について、抜けや意味の変化がないか確認したか
□申込み前の画面を広告とは別に確認し、商品との対応を記録したか
□共通の文章への案内と、案内先での見つけやすさを確認したか
□修正後の表示を見直し、残る差を責任者・専門家に確認したか
□確認した画面、日時、端末、確認者、保留した箇所を記録したか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
