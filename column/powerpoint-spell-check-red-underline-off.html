1．赤い波線が出る理由と、Windows・Mac・Web の消し方の早見表

確認日：2026年11月28日

PowerPoint の赤い波線は、スペル ミスの可能性がある箇所に付く印です。Microsoft サポートの「Office でスペル チェックと文章校正を行う」によると、ほとんどの Office プログラムでは、入力したときに自動でスペル チェックと文章校正のエラーのチェックが行われ、スペル ミスの可能性がある箇所は赤色の波線で、文章校正のエラーの可能性がある箇所は青色の波線でマークされます。Windows 版のヘルプでは、自動文章校正を使えるのは Outlook・Word・PowerPoint だけとされています。型番、英字の略称、取引先の社名のように辞書に無い言葉が多い資料では、正しく書いていても波線が並ぶことがあります。Web 版のヘルプも、つづりが正しくても、ブランド名や略語は辞書で認識されないことがある、と断っています。

消し方は、使っている PowerPoint（Windows のデスクトップ版・Mac 版・ブラウザーで開く PowerPoint for the web）と、資料全体の波線を止めたいのか、品番などの一部の文字だけ外したいのかで変わります。ヘルプの表記で並べると次のとおりです。

PowerPoint資料全体で止める（ヘルプの表記）一部の文字だけ外す止めた後にまとめて確かめる
Windows（デスクトップ版）［ファイル］→［オプション］→［校正］→［入力時にスペル チェックを行う］をオフ文字を選んで［校閲］タブの［言語］→［校正言語の設定］→［スペルや文法をチェックしない］F7 キー
MacPowerPoint メニューの［環境設定］→［校正］→ 入力時の［スペル チェック］をオフ［校閲］タブの［言語］で選んだ文字の言語を選べる（「チェックしない」の項目はヘルプの Mac のタブに記載なし）［校閲］タブの［スペル チェック］
PowerPoint for the web［レビュー］タブの［ABC 校正］→［校正エラーを非表示にする］（職場や学校の OneDrive・Microsoft 365 の SharePoint のファイル）右クリック →［校正言語の設定］→［スペル チェックと文章校正を行わない］［レビュー］タブの［ABC 校正］→［エディター設定］

「このファイルだけ止めたい」という場合の書き方は、ヘルプで版ごとに違います。Windows 版のヘルプで、現在作業中の文書だけ、またはすべての新しい文書についてスペル チェックを切り替えられると書かれているのは Word で、［例外］ボックスの一覧と［この文書のみ、結果を表す波線を表示しない］のチェック ボックスを使う形です。PowerPoint の［校正］の画面に、この資料だけに効かせる項目があるかどうかは、このヘルプには書かれていません。PowerPoint for the web の［校正エラーを非表示にする］は、ヘルプの見出しが「ファイル全体で文章校正マーカーをオフにする」で、このプレゼンテーションでマーカーをもう一度出すときは同じコマンドを使う、と書かれています。

2．Windows：［ファイル］→［オプション］→［校正］でスペル チェックをオフにする

順番操作
1［ファイル］メニューの［オプション］を選ぶ
2［校正］を選ぶ
3［入力時にスペル チェックを行う］のチェック ボックスをオフにする

ヘルプの「多色の下線をオンまたはオフにする」の項は、Office で作業中にエラーの可能性を波線でマークしない場合は、自動的なスペル チェックと文章校正をオフにできる、と案内しています。PowerPoint では、［ファイル］メニューの［オプション］を選び、［校正］を選んで、［入力時にスペル チェックを行う］のチェック ボックスをオフにします。自動文章校正を行うプログラムでは、［自動文章校正］のチェック ボックスもオンとオフを切り替えられます。赤だけでなく青の波線も出したくないなら、こちらも見ます。

文章校正そのものを、スペル チェックの実行時にも入力時にも行わないなら、同じ画面で［自動文章校正］と［文章校正とスペル チェックを一緒に行う］の両方をオフにします。ただし、一部の Office のプログラムにはこれらのオプションがない、と注意書きがあります。手元の［校正］の画面にどの項目が並んでいるかを見てから外します。

ヘルプはこの設定を、作業中にエラーの可能性を波線でマークしない場合の操作として案内しています。波線の付いた語を直したいときは、別に、下線付きの単語や語句を右クリックして直し方を選ぶか、後の節のまとめてのチェックで［変更］を選びます。元に戻すときは、同じ場所で［入力時にスペル チェックを行う］をオンにします。

3．Mac：PowerPoint メニューの［環境設定］→［校正］で赤い波線を消す

Mac 版の手順は、同じヘルプ「Office でスペル チェックと文章校正を行う」の macOS のタブにあります。Office for Mac のアプリケーションでは、文字の入力時にスペル ミスや文法エラーが疑われる箇所が自動でチェックされ、入力が終わるまでチェックを待ちたいときは、自動チェックを無効にするか、一度にまとめてチェックできる、とされています。PowerPoint の項には、PowerPoint ではスペル チェックはできるが文章校正はできないこと、スペル ミスが疑われる箇所が自動的に指摘されて赤色の波線マークが付くことが書かれています。

順番操作
1PowerPoint メニューの［環境設定］を選ぶ
2［校正］を選ぶ
3［校正］ダイアログ ボックスで、入力時の［スペル チェック］をオフにする

メニューの名前はヘルプの表記です。Windows のように［ファイル］→［オプション］から開くのではなく、PowerPoint メニューから開く点が違います。スペル エラーがマークされなくなったときは、この手順で自動スペル チェックをオンにする必要がある場合がある、とヘルプは書いています。共用の Mac で波線が急に出なくなったときは、この画面でオフにしたままになっていないかを見ます。

波線を出したまま一語ずつ直すときは、Mac では単語や語句を Control キーを押しながらクリックし、提案されたオプションから選びます。品番や英字の社名など一部の文字の言語は、ヘルプ「校正言語を設定して別の言語に切り替える」の Microsoft 365 for Mac のタブによると、文字を選んで［校閲］タブの［言語］を選び、使う言語を選んで［OK］を選びます。Windows や Web 版のように「チェックしない」を選ぶ項目が Mac の［言語］にあるかどうかは、このタブには書かれていません。

4．PowerPoint for the web：［校正エラーを非表示にする］はファイル全体、［校正言語の設定］は語ごと

ブラウザーで開く PowerPoint for the web では、入力時にスペル、文法、スタイルの間違いが見つかると、単語に下線を付けて知らせます。ヘルプの表では、スペルの下線は OneDrive・職場または学校の OneDrive・Microsoft 365 の SharePoint に保存されたファイルで、文章校正の下線は職場または学校の OneDrive と Microsoft 365 の SharePoint に保存されたファイルで機能するとされています。

順番操作
1［レビュー］タブで［ABC 校正］のドロップダウンを選ぶ
2［校正エラーを非表示にする］を選ぶ
3もう一度マーカーを出すときは、同じコマンドをもう一度使う

ファイル全体のマーカーを隠せるのは、ファイルが職場や学校の OneDrive、または Microsoft 365 の SharePoint に保存されている場合です。［レビュー］タブで［ABC 校正］のドロップダウンを選び、［校正エラーを非表示にする］を選びます。このコマンドはマーカーのオンとオフを切り替えるもので、このプレゼンテーションで校正マーカーを再び表示したいときは、このコマンドを再び使います。ヘルプがこの操作で挙げる保存場所は職場や学校の OneDrive と Microsoft 365 の SharePoint で、個人用の OneDrive は挙がっていません。

品番の入った語や文字枠だけを外したいときは、外したい単語を選び（文字枠全体なら単語は選ばずに）、選んだ単語か文字枠そのものを右クリックして［校正言語の設定］を選び、［スペル チェックと文章校正を行わない］を選んで［OK］を選びます。ヘルプによると、ファイル全体の校正言語は変更できず、変更できるのは選んだ単語か文字枠だけです。資料全体の波線は残したまま決まった語だけを外せるので、ほかの誤字に気づく手がかりは残ります。

5．品番や社名だけ校正しない：Windows の［校正言語の設定］

資料全体の波線を止めると、本当の打ち間違いにも気づきにくくなります。品番や英字の社名など、決まった語や文字枠だけを外したいときは、選んだ文字の校正言語の設定を使います。Microsoft サポートの「スペルと文法のチェックに使用する言語を設定または変更する」は、［Review>Language>Set Proofing Language］（校正言語の設定）に移動し、Word、PowerPoint、または Outlook で選択したテキストのエラーをマークしたくない場合は［スペルや文法をチェックしない］を選ぶ、と案内しています。

順番操作
1外したい語や文字枠を選ぶ
2［校閲］タブで［言語］→［校正言語の設定］を選ぶ
3［スペルや文法をチェックしない］を選ぶ
4［OK］を選ぶ

ヘルプ「校正言語を設定して別の言語に切り替える」の Microsoft 365 のタブでは、別の言語としてマークするテキストを選び、［校閲］タブで［言語>校正言語の設定］を選んで、使う言語を選び、［OK］を選ぶ、と書かれています。日本語の資料に入れた英文を英語の辞書でチェックしたいときは、「チェックしない」ではなく、その文を選んで英語を選ぶ使い方もできます。

同じく「スペルと文法のチェックに使用する言語を設定または変更する」の［自動的に言語を認識する］の手順には、このオプションは PowerPoint では使用できない、と注記があります。PowerPoint で英文や品番の扱いを変えたいときは、その文字を選んでから校正言語を設定します。ヘルプは、この画面で文書に使われている言語が上部に表示され、校正ツールをダウンロードした言語にはチェックマークが付く、とも書いています。

6．オフにした後の確かめ方：送る前に F7 キーか［スペル チェック］

波線が出なくなると、本当の打ち間違いにも気づきにくくなります。ヘルプによると、Windows では F7 キーを押すだけで、文書のスペル チェックと文章校正のチェックが始まります。PowerPoint のトレーニングのページ「プレゼンテーションのスペル チェック」では、［Review>Spelling］（ヘルプの表記）を選ぶと［スペル チェックと文章校正］ウィンドウが開き、修正候補の一覧から正しいスペルを選んで［変更］を選ぶか、同じ誤りが文書内に複数回あるときは［すべて変更］を選ぶ、と案内されています。

Mac では、［校閲］タブの［スペル チェック］を選びます。エラーが疑われる箇所が見つかると［スペル チェック］ウィンドウに表示され、スライドで直すか、推奨される単語を選んで［変更］を選びます。PowerPoint でプレゼンテーションの校正が終わると、スペル チェックが完了したというメッセージが表示され、［OK］でプレゼンテーションに戻ります。

資料を送る前や印刷する前に、このまとめてのチェックを流す段取りを入れておきます。スペルや文法の間違いがマークされない場合は、自動チェックがオフになっている可能性がある、とヘルプは書いています。共用のパソコンで急に波線が出なくなったときは、誰かが止めたままになっていないかを、Windows は［ファイル］→［オプション］→［校正］、Mac は PowerPoint メニューの［環境設定］→［校正］で確かめます。

7．一語だけ消す・覚えさせる：［すべて無視］［辞書に追加］と再チェック

波線を出したまま、気になる語だけを片づける方法もあります。トレーニングのページでは、赤い波線が下に表示されている単語を右クリックし、修正候補の一覧から正しいスペルを選ぶか、［すべて無視］（エラーを無視し、赤い波線を削除する）か［辞書に追加］（今後そのスペルがエラーとして表示されないように辞書に追加する）を選べる、と案内されています。Office のヘルプも、そのスペルで入力する必要がある語は［辞書に追加］を選ぶと、今後その単語にスペル ミスとしてフラグが設定されない、としています。何度も使う社名や品番は、辞書に追加しておくと、資料ごとに波線を消す手間が減ります。Mac では、［スペル チェック］ウィンドウの［追加］で、スペル ミスと指摘された単語をすべてのドキュメントでスキップし、辞書に追加できます。

チェックの途中で「無視」を選んだ語が多いと、本当の誤りまで見逃したままになることがあります。Windows 版のヘルプによると、Word・Outlook・PowerPoint では、以前に無視するように選んだ単語をあらためてチェックさせることができます。［ファイル］メニューの［オプション］から［校正］を選び、［ドキュメントの再チェック］を選びます。リセットについての警告が出たら［はい］を選び、ダイアログ ボックスで［OK］を選んで資料に戻り、もう一度スペル チェックを流します。他の人から引き継いだ資料を社外に出す前に、一度この再チェックをしておくと、見落としに気づきやすくなります。

8．社内で使い方をそろえる（架空の例）

そろえること架空の記入例
波線を止めてよい場面品番や英字の略称が多い製品紹介の資料を作るとき
送る前のチェックF7 キーでスペル チェックを流し、社名と金額は目でも見る
品番や社名よく使う社名は辞書に追加し、品番の文字枠だけ「チェックしない」にする
Windows と Mac手順書に［ファイル］→［オプション］→［校正］と PowerPoint メニューの［環境設定］→［校正］の両方を書く
共用のパソコン作業が終わったら設定を元に戻すかを決めておく
