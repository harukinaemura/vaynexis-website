PowerPointのスペル チェックで赤い波線を表示しないには

要点

赤い波線を出さないようにするには、［ファイル］メニューの［オプション］から［校正］を開き、［入力時にスペル チェックを行う］のチェック ボックスをオフにします。 自動のチェックを止めても、F7 キーを押せばスペル チェックをその場で始められます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

品番や英字の社名に赤い波線が並び、画面を共有して見せるときに気になる。Windows 版 PowerPoint で入力時のスペル チェックを止める場所と、止めたあとに F7 キーや再チェックで誤字を確かめる方法、Web 版で語ごとに外す方法を見ます。

1．赤い波線が出る理由

確認日：2026年11月17日。

対象は、Windows のパソコンで使う PowerPoint（Microsoft 365 などのデスクトップ版）です。Mac 版は設定の場所が違うので、後ろの節で分けて書きます。

ヘルプによると、Office ではスペル ミスの可能性がある箇所に赤色の波線が付きます。 ほとんどの Office のプログラムは、入力したときに自動でチェックをしています。 型番、英字の略称、取引先の社名のように辞書に無い言葉が多い資料では、正しく書いていても波線が並ぶことがあります。

波線の色にも意味があります。同じヘルプでは、スペル ミスの可能性がある箇所は赤色、文章校正のエラーの可能性がある箇所は青色の波線で示される、と書かれています。 Windows 版のヘルプでは、入力中の自動の文章校正は Outlook・Word・PowerPoint でだけ使える、とされています。 赤だけでなく青の波線も気になるなら、次の節の［自動文章校正］も見ます。

2．波線を止める手順

順番操作
1［ファイル］メニューの［オプション］を選ぶ
2［校正］を選ぶ
3［入力時にスペル チェックを行う］のチェック ボックスをオフにする

同じ画面には［自動文章校正］のチェック ボックスもあり、自動の文章校正を行うプログラムでは、こちらもオンとオフを切り替えられます。 文章校正そのものを行わないなら、［自動文章校正］と［文章校正とスペル チェックを一緒に行う］の両方をオフにします。 ただし、一部の Office のプログラムにはこれらのオプションがない、と注意書きがあります。 手元の［校正］の画面にどの項目が並んでいるかを見てから外します。

ヘルプは、この手順を「エラーの可能性を波線でマークしない場合」の操作として、PowerPoint を含むプログラムに共通の形で案内しています。

3．止めたあとは、送る前に F7 キー

波線が出なくなると、本当の打ち間違いにも気づきにくくなります。資料を送る前や、印刷する前に、F7 キーでまとめてチェックする手順を入れておきます。

あとで自動のチェックに戻したいときは、同じ場所で［入力時にスペル チェックを行う］をオンにします。波線が急に出なくなった、という場合も、ヘルプは自動チェックがオフになっている可能性を挙げています。 共用のパソコンでは、誰かが止めたままになっていないかを確かめます。

4．一語だけ直すときと、無視した語をもう一度見るとき

波線を出したまま、その場で直す使い方もあります。ヘルプでは、下線の付いた単語や語句を右クリックし、出てきた選択肢から直し方を選ぶ、と案内されています。

チェックの途中で「無視」を選んだ語が多いと、本当の誤りまで見逃したままになることがあります。Windows 版のヘルプによると、Word・Outlook・PowerPoint では、以前に無視するように選んだ単語をあらためてチェックさせることができます。 ［ファイル］メニューの［オプション］から［校正］を選び、［ドキュメントの再チェック］を選びます。 リセットについての警告が出たら［はい］を選び、資料に戻ってからもう一度スペル チェックを流します。 他の人から引き継いだ資料を社外に出す前に、一度この再チェックをしておくと安心です。

5．Web 版はファイルごと・語ごとに外せる

ブラウザーで開く PowerPoint for the web には、別のやり方があります。ヘルプでは、正しいつづりでもブランド名や略語は辞書で認識されないことがある、と断ったうえで、ファイルが職場や学校の OneDrive、または Microsoft 365 の SharePoint に保存されている場合の操作を案内しています。 ファイル全体のマーカーを隠すなら、［レビュー］タブの［ABC 校正］のドロップダウンで［校正エラーを非表示にする］を選びます。このコマンドは、マーカーのオンとオフを切り替えるものです。

品番の入った文字枠だけを外したいなら、その単語や文字枠を右クリックして［校正言語の設定］を選び、［スペル チェックと文章校正を行わない］を選んで［OK］を押します。 資料全体の波線は残したまま、決まった語だけを対象から外せるので、誤字に気づく手がかりを失わずに済みます。

6．Mac 版は［環境設定］から

Mac 版のヘルプでは、PowerPoint はスペル チェックはできるが文章校正はできない、と書かれています。 自動のスペル チェックは、PowerPoint メニューの［環境設定］から［校正］を開き、入力時の［スペル チェック］をオンまたはオフにします。 まとめてチェックするときに見つかった箇所は、［スペル チェック］ウィンドウに表示されます。 Windows と Mac で同じ資料を直す職場では、設定の場所が違うことを手順書に書いておきます。
