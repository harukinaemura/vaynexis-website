補助事業が予定どおり進まないとき、事故報告に集める情報と記録

要点

事故報告に向けては、まず原因と内容を説明できる資料を集めます。あわせて経費の内訳、取った対応、作業の進捗、完了見込みを整理し、元の記録と結び付けます。確認済みの事実と今後の見込みを分けておくと、事務局への説明をそろえやすくなります。

公開：2026年11月5日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、小規模事業者持続化補助金＜創業型＞の補助事業が予定どおり進まないときに、事故報告に向けて集める情報と記録を整理したい事務担当者のためのものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。制度や規約の内容は出典の公式ページで確かめ、個別の判断は専門家に確認してください。

  1. 遅れを把握したら、まず報告対象と連絡の時期を確かめる
  2. 入力欄から逆に、必要な説明と金額をそろえる
  3. 社内の記録は、理由・進捗・見込みを分けて集める
  4. 事務局への連絡から、提出した内容の控えまで残す
  5. 延長や別の申請が必要かは、資料を示して相談する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．遅れを把握したら、まず報告対象と連絡の時期を確かめる

確認日：2026年11月4日（日本時間）。

ここでは、小規模事業者持続化補助金＜創業型＞の事故報告の入力手引きを、準備する情報の確認に使います。通常の報告対象と時期は、補助事業の手引きの第3回受付締切分で確認します。この手引きの表紙は第3版、2026年7月29日付です。

この手引きでは、事業者の責任によらない事由で期限までに完了できないと見込まれる場合、または事業実施が困難になった場合、その状況となった時点で速やかに事故報告書を事務局に提出する扱いです。一方、「取引先の都合」「自身の都合」「申請時に周知の事実によるもの」などの理由による提出では、事業実施期限の延長は認められないと記載されています。

担当者の準備では、「何が起きたか」と「どの作業が止まったか」を分けると、事情を説明しやすくなります。資料を集め終えてから相談する流れにせず、把握できている内容を伝え、確認を続ける項目を残す進め方が考えられます。

2．入力欄から逆に、必要な説明と金額をそろえる

事故報告の入力手引きでは、報告日に申請する日付を入力するよう指定されています。出来事が起きた日、社内で把握した日、入力する日の記録は分けておくと、経緯を追いやすくなります。

「事故に係る金額」の入力対象は、事故によって影響を受ける補助事業の補助対象経費金額です。被害の説明に使う金額をそのまま転記せず、対象となる経費と元の内訳を照合する整理が必要です。

事故に対して取った措置と、補助事業が完了する予定日も、入力手引きにある記載項目です。既に行った対応と今後の見込みを分け、予定を支える回答や工程の確認が取れているか、誰の見込みなのかも手元のメモに残すとよいです。文章を整える前に、連絡の履歴と作業の状況を集めることが出発点になります。

添付する資料が2つ以上ある場合、入力手引きではzip形式にまとめて添付する扱いです。ファイルをまとめる前に、どの説明を裏付ける資料なのか分かる名前を付けておくと、社内での照合にも使えます。

3．社内の記録は、理由・進捗・見込みを分けて集める

次の表は、相談や入力の準備に使う社内資料の集め方です。表の資料をすべて提出するという意味ではなく、説明の根拠を手元でたどれるようにするための案です。

整理する内容集める人の例着手する時点手元で照合する資料の例
起きたことと原因現場の担当者遅れを把握したとき発生時の連絡、相手から届いた説明、状況の記録
終えた作業と止まっている作業進行を管理する担当者現在の状況を聞き取るとき当初の工程表、完了を確認した記録、残っている作業の一覧
影響を受ける経費と内訳経理の担当者影響する取引を特定するとき見積書、注文内容、費用の内訳
既に取った対応取引先との連絡担当者対応内容を説明するとき問い合わせや再調整の履歴、相手からの回答
完了の見込みとその前提進行を管理する担当者残る作業を組み直すとき更新した工程表、納期の回答、作業を再開できる条件
業務への影響社内の責任者報告内容を確認するとき止まっている業務、代替対応の状況、影響範囲のメモ

原因を説明する資料と、進捗を示す資料は役割が異なります。相手から届いた連絡だけでは、社内のどの作業が残っているかまで分からないことがあります。反対に、工程表だけでは、なぜ予定が変わったのかが伝わりにくいため、両方を対応させて整理するとよいです。

状況をまとめる担当者は、各記録の作成日、確認した相手、保存場所を説明文の脇に残します。原因が分かった部分と調査を続けている部分、回答を得た予定と社内で置いた仮の予定が混ざらない形にします。

完了の見込みは、終えた作業から順に並べ直すと説明しやすくなります。残る作業、それを始められる条件、相手の回答を待っている部分を分け、責任者が同じ資料を見ながら確認できる状態に整えます。

4．事務局への連絡から、提出した内容の控えまで残す

入力手引きでは、事故報告を申請する際、事務局がマイページに申請ボタンを表示する手続きを行うため、電話で問い合わせるよう案内しています。連絡の際は、該当する事業を特定できる情報と経緯のメモを手元に置くと、説明をそろえやすくなります。回答を受けた内容、追加で用意するもの、社内で対応する担当者も記録します。

入力途中の情報を再編集する際は、「作成済みの申請」内に保存された「下書き中」のデータを編集する案内です。社内で引き継ぐ際も、どの下書きを使っているかを共有しておくとよいです。

提出後は、申請状況が「申請済み」になっていれば申請が完了しており、差戻しされるまでは編集できません。提出した文章、添付した資料、確認した状態を控えとしてそろえ、問い合わせが来た際に同じ内容を参照できるようにします。

5．延長や別の申請が必要かは、資料を示して相談する

公式の「各種変更等」では、変更承認、登録事項変更届、辞退、中止・廃止、事故報告に所定の手続きがあると案内しています。相談時には、遅れの説明に加え、内容や経費も変える予定があるかを伝え、必要な手続きを事務局に確認するとよいです。

第1回公募に関する中東情勢への対応案内では、延長期間は事由の影響度合いや事業の進捗状況などを踏まえ、個別に審査・決定するとされています。相談に向けては、希望する期間だけでなく、影響の程度と現在の進捗を説明できる資料も用意するとよいです。自身の型、公募回、事由に合う扱いは、手元の資料を示して事務局へ確認する進め方になります。

電話窓口の受付時間は9:00～12:00、13:00～17:00で、土日祝日と年末年始の休業日を除きます。法的な責任や契約上の対応の判断が必要な点は、公式手引きと取引の記録をそろえて専門家に確認します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□利用している補助金の型と公募回に合う資料を確認したか
□起きたことと、止まっている作業を分けて説明できるようにしたか
□影響を受ける経費の額を、元の内訳と照合したか
□既に行った対応と、これから行う予定を分けたか
□完了の見込みについて、根拠と確認待ちの事項を整理したか
□事務局に確認した提出時期、必要資料、回答の内容を記録したか
□提出した文章と添付資料、提出後に確認した状態を控えに残したか
