共有フォルダを点検する｜分類表の項目と実際の保存先を照合する方法

要点

共有フォルダの点検は、分類表から保存先へたどり、現物のフォルダ側からも分類表へ戻って確認します。表にあるのに見つからない場所と、現物にあるのに表にない場所を分け、文書を移す前に担当と利用者を確認します。内閣府が行政機関向けに示すマニュアルでは、記録用フォルダの階層と名称を保存期間表の分類と一致させ、フォルダ構成が正しく保たれているかを定期的に確認するとされており、会社の点検ではこの考え方を参考に使えます。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、共有フォルダの保存先を見直したい小さな会社の担当者が、社内の分類表と実際のフォルダを両方向から照らし、置き間違いや古いフォルダを見つけて直す流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 分類表と点検範囲を先に決める
  2. 分類表から現物へ順にたどる
  3. 現物から分類表へ逆に照合する
  4. 違いを直す場所と担当を分ける
  5. 変更後に資料へたどり着けるか確かめる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．分類表と点検範囲を先に決める

確認日：2026年11月10日。

内閣府は、行政文書の管理に関する通知の一覧に「共有フォルダにおける行政文書の電子的管理に関するマニュアル」（令和7年2月14日、内閣府大臣官房公文書管理課長）を掲載しています。同マニュアルは、各行政機関が共有フォルダで行政文書の電子的管理を行うに当たっての具体策を示したもので、対象は行政機関です。記録用フォルダは保存期間表に作成された大中小分類に沿って作り、フォルダの階層構造と名称を、保存期間表の大中小分類とその名称に一致させるとされています。

同じマニュアルでは、フォルダ名の先頭に保存期間表の順序と整合的に並ぶよう通し番号を付け、名称の前に【大分類】【中分類】【小分類】など区分が分かる記述を付けるとされています。フォルダ名とファイル名を合わせたパスの長さにも留意が必要とされ、どの分類に対応するかが分かる形であれば、フォルダ名を省略して書いても差し支えないとされています。

ここからは当社の整理です。

会社で点検するときは、自社で使う分類表の版、対象部署、点検する最上位のフォルダを決めます。フォルダのアクセス権を持つ担当と一緒に確認し、許可を得ていない場所は確認待ちとして記録します。内閣府のマニュアルは行政機関に向けたものなので、会社では自社の分類表を基準にし、番号や区分の付け方は自社の決まりに合わせて読み替えます。

2．分類表から現物へ順にたどる

分類表の行ごとに、想定している保存先を開きます。名称が似ていても、上の階層と利用する部署が合うかを見ます。年や案件によって階層が分かれる場合は、想定している期間が一致するかも確認します。

開けない場所は、フォルダが存在しないのか、確認する担当の権限では開けないのかを分けて記録します。保存先がある場合でも、その場所にある文書の種類が分類表の説明と異なれば、該当する行を控えます。

内閣府のマニュアルでは、小分類より下のフォルダは業務上の必要に応じて作ってよいとしつつ、不要に深い階層のフォルダは作らない（目安として2段階などの上限を定める）、意思決定の各段階の最終版がどれか判断がつくフォルダ体系にする、といった点に留意するとされています。

分類表の行から開いた先で、小分類の下が何段にも深くなっている場所や、どれが最終版か分からない場所も、点検の控えに挙げます。

3．現物から分類表へ逆に照合する

内閣府のマニュアルでは、行政機関の共有フォルダを、組織的な検討を経た文書の「記録用フォルダ」、組織的な検討を終える前の文書の「検討中フォルダ」、案の下書きや参考資料収集などの「個人用」のフォルダに分け、混同が生じないよう領域を分離して管理するとされています。検討中フォルダには「検討中」という名称を表示し、他者が見た場合に誤解を生じないようにすることとされています。

同じマニュアルでは、法令集や定型的な業務連絡のように課室で共通に使う資料は、これらとは分けて「組織参考資料」といったフォルダを作ることも考えられるとされています。

現物から照合するときは、部署が実際に使っているフォルダを順に見て、分類表で対応する項目があるかを確かめます。作業途中の資料と確定した記録が混ざっている場所や、担当者個人の場所にしか確定版がない状態を区別します。

分類がない場所は、使用している担当と、そこに置かれる文書の用途を確認します。新しく分類表に追加するのか、既存の分類に整理するのかは、用途を確認したうえで決めます。

4．違いを直す場所と担当を分ける

内閣府のマニュアルでは、過去の文書の整理は一律・即時ではなく、新しいフォルダ体系を作って今後の文書を先に格納し、過去の文書は順次移す「新築・順次引っ越し方式」などが合理的とされています。古いフォルダには、新しい体系と混同しないよう【整理中】などの名称を付けておくことが望ましいとされています。分類とフォルダの階層・名称をすぐに一致させられない場合の当面の措置として、ショートカットの付与などで分類から既存のフォルダへ紐づける方法も挙がっていますが、リンク先のフォルダ名の変更などでショートカットが正しく機能しなくなることに留意が必要とされています。

違いを見つけたら、分類表の記載を直すもの、保存先を変えるもの、権限を確認するものに分けます。移動や名称変更が必要なときは、利用者、保存する必要がある記録、その場所を指しているリンクやショートカットの有無を先に確認します。古い場所を一度に片付けられないときは、移し終えるまで古いフォルダの名前に整理中と分かる語を付け、新しい場所と取り違えないようにします。

点検時に見つけた重複資料は、どれが正式な記録かを担当に聞きます。名前や更新日だけで判断せず、正式な版を指定する記録や、保存先を決めた経緯も確認します。

5．変更後に資料へたどり着けるか確かめる

内閣府のマニュアルでは、個々の職員が自由にフォルダを追加できることから、文書管理者が構築のルールを周知し、大中小分類フォルダが正しく保たれているか、小分類の下に無秩序にフォルダが作られていないか、組織的な検討を経た文書が記録用フォルダに正しく格納されているかなどを定期的に確認するとされています。検討中フォルダの文書についても、漫然と放置されていないか確認するとされています。年度の途中で新しい分類を作るときは、文書管理者の承認を得た上で作るとされています。

変更後は、対象業務を担当する利用者が、分類表の記載から実際の資料にたどり着けるかを確かめます。点検結果には、分類名、変更前後の保存先、確認日、対応担当、残っている確認を記録します。会社では、点検する時期と点検する人、新しいフォルダを作るときに誰に断るかを決めておくと、次の点検で同じ違いを見つけやすくなります。

新しい業務を始めたり、資料を管理する部署が変わったりした場合は、分類表だけを更新して終わらず、今回と同じ方法で保存先を確かめます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□分類表の版と点検範囲を確認したか
□分類表から実際のフォルダをたどったか
□実際のフォルダから分類表に戻って確認したか
□作業途中の資料と確定した記録の置き場を区別したか
□変更前に利用者とリンクを確認したか
□変更後に必要な資料を開けるか確かめたか
□小分類の下に深すぎる階層や無秩序なフォルダがないか
□検討中の資料が放置されていないか
□古いフォルダに整理中と分かる名前を付けたか
□ショートカットのリンク切れがないか
