Excelの数式表示を戻すには｜計算結果の代わりに式が出るとき

要点

数式表示を戻すには、［数式］タブの［数式の表示］を選び、計算結果の表示へ切り替えます。表示を戻した後は、目的の欄に結果が出たかを確かめます。式そのものを書き直す前に、どの場所で式が見えているかを分けて見るとよいです。

公開：2026年11月16日／情報の確認日：2026年11月16日（出典はこの記事の最後）

この記事は、計算結果の代わりに式が出る表示を戻したい小さな会社の担当者が、Excelの環境別の操作と切替後の表示を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月16日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．セルに式が出ているのか、上の欄に出ているのか

確認日：2026-11-16

Microsoftの説明では、通常はワークシートのセルに数式の結果が表示され、数式バーには数式が表示されます。上に見える式だけで戻っていないと判断せず、表の中の欄に何が出ているかを見ます。確認したいのは、式を隠したかどうかより、普段の集計や閲覧に使う表示へ戻ったかです。

操作に入る前に、対象のファイルとシートの名前、式が見えている欄を控えるとよいです。ほかの担当者に状況を伝える際も、「表がおかしい」だけでなく、どの欄で何が見えているかを伝えられます。入力内容を変える作業と表示を戻す作業は、記録の上でも分けておきます。

この記事で扱うのは、結果と式の表示を切り替える場面です。式を別の欄へ書き出す方法や、入力内容そのものの修正には進みません。

2．リボンから戻す方法と、キー操作の注意点

Windows版の表示切替を案内するヘルプの適用先は、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016です。戻したい表を開いた状態で、画面上部の操作に進みます。

リボンでは［数式］タブから［数式の表示］を選択し、式を表示している状態から標準の表示へ戻す場合も同じボタンを使います。操作後に同じ欄へ目を戻し、目的の表示になったところで止めます。変化を確かめずに何度も押すと、戻った状態を見落としてしまいます。

Windows版のキーボード操作としては、Ctrlキーとアクサン グラーブ記号のキーによる、セルの値と数式の表示の切替が案内されています。ただし、公式のショートカット一覧は米国のキーボード配列を基準にしており、ほかの配列ではキーが正確に対応しない可能性があります。手元でキーを特定しにくいときは、名前を確認できる画面のボタンを使うとよいです。

3．詳細設定では、変更するシートを選ぶ

詳細オプションのヘルプでは、Windows版の適用先としてExcel for Microsoft 365、Excel 2024、Excel 2021が掲載されています。Windows版では、［ファイル］から［オプション］、［詳細設定］の順に進むと詳細オプションを開けます。リボンの切替とは別に、設定項目を直接確かめたいときの入口です。

［次のシートで作業するときの表示設定］では、設定の対象となるシートをリストボックスで選びます。ここでは、戻したい表の名前と、選択されている名前を照合します。別の表を見ている状態で作業を続けないよう、対象を確かめてから項目を読みます。

［計算結果の代わりに数式をセルに表示する］は、計算した値の代わりに式を表示する項目なので、計算結果を見たい場合はこの項目のチェックを外します。設定画面の名前だけを控えるより、対象のシートと変更した項目を併記すると、後でどこを戻したか確認しやすくなります。

4．Mac版とWeb版は、対応する手順で切り替える

Mac版の専用ヘルプの適用先は、Excel for Microsoft 365 for Mac、Excel 2024 for Mac、Excel 2021 for Macです。利用環境が違う担当者へ引き継ぐときは、同じ操作経路をそのまま渡す前に、対応する手順を分けておくとよいです。

Mac版でも［数式］タブの［数式の表示］で切り替えられ、標準の表示へ戻すには同じボタンをもう一度選択します。また、Mac版のヘルプでは、この表示切替は選択したセルだけに使う操作ではなく、シート全体に適用されると説明されています。

Web版は、公式ヘルプのWeb向けの案内にある［数式］、［数式の表示］の順で、数式と結果の表示を切り替えます。ブラウザーで開いた画面の操作と、デスクトップの設定画面の操作は、引き継ぎメモでも分けて記載します。

5．見本の表で、戻す前と後の見え方を分ける

ここからは当社の整理です。

短い集計表の合計欄を確認する場面を考えます。合計欄が式から結果へ戻ったかを見た後、同じ欄を選択したときに上部に何が見えるかを確かめる、という順で整理します。

確認する場所式を表示しているとき結果へ戻した後に見るもの
表の合計欄合計を求める式計算した合計
上部の数式バー選択した欄の式選択した欄の式

Microsoftの説明では、結果の表示へ戻した後も、数式バーに式が表示されることと、セルに計算結果が表示されることは両立します。この見分けが付けば、上の欄から式を消そうとして別の操作を始めずに済みます。

MicrosoftのWindows版向けの案内では、数式を表示した状態のワークシートを、その状態で通常どおり印刷する手順が示されています。配布用の表を整えるときは、確認のために式を見ていたのか、結果を読んでもらうための表なのかを区別し、渡す目的に合う見え方かを確認するとよいです。

6．戻らない欄は、場所と状態を残して引き継ぐ

切り替えた後に見たい表示にならない欄が残った場合は、その場所を控え、今回の操作で変わった範囲と分けます。原因を推測して欄を書き換えるより、戻った場所と残った場所を相手が見比べられる状態にしておくと、次の確認につながります。

引き継ぐ内容は、対象の表、操作した場所、操作前に見えていたもの、操作後に見えたものです。「直した」という結果だけでなく、表示を切り替えた段階なのか、残る問題を調べている段階なのかまで記録します。集計内容の正しさを確かめる作業は、表示が戻ったかの確認と分けて扱うとよいです。

この作業をAIで減らすなら、まず表示の切替と、元の内容を確かめる判断を分け、事務でのAI活用を考える際の作業整理につなげるとよいです。
