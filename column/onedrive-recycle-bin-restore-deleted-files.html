OneDriveのごみ箱から、誤って消した資料を元の場所へ戻すには

要点

消した資料は、OneDrive の Web サイトにサインインし、［ごみ箱］を選び、戻すファイルやフォルダーの丸いチェック ボックスをオンにして［復元］を選ぶと戻せます。 ただし期限があります。個人用アカウントは過去 30 日以内、職場または学校アカウントは、管理者が保持設定を変更しない限り過去 93 日以内に削除したものが対象です。 ごみ箱から完全に削除したものは戻せません。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

片付けのつもりで消したフォルダーに、まだ使う資料が入っていた。OneDrive の Web とパソコンのどちらのごみ箱を見るか、アカウントの種類で変わる戻せる日数、見当たらないときの相談先を順に確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

片付けの場面は作った例であり、確認表の項目は公式の手順に当社の注意を足して並べたものです。

  1. 消したと気づいたら、まず日付を見る
  2. Web のごみ箱から戻す手順
  3. パソコンのエクスプローラーで消したときは
  4. ごみ箱に無いときに考えられること
  5. たくさん消してしまったときの、もう一つの戻し方
  6. 消すときに出る確認を読み飛ばさない
  7. 架空の例：片付けの後に請求書のフォルダーが無い
  8. 確認表
  9. 自社の事務の手順まで形にしたいとき

1．消したと気づいたら、まず日付を見る

確認日：2026年11月17日。

対象は、OneDrive の Web サイト（onedrive.com）のごみ箱と、Windows のパソコンのごみ箱です。スマートフォンのアプリからも戻せますが、ここでは扱いません。

「先月の見積書のフォルダーを片付けたつもりが、今月分まで消していた」。こうした誤りは、消してすぐではなく、何日もたってから気づくことが少なくありません。そこで、戻す作業の前に、いつ消したかと、どの種類のアカウントの OneDrive かを確かめます。

アカウントの種類戻せる範囲（ヘルプの記載）
個人用アカウント過去 30 日以内に削除されたファイルまたはフォルダー
職場または学校アカウント管理者が保持設定を変更しない限り、過去 93 日以内に削除されたファイルまたはフォルダー

職場や学校のアカウントは、管理者の設定でこの日数が変わることがあります。会社の OneDrive で消してから日がたっているなら、早めに社内の担当者に確かめておくと安心です。

2．Web のごみ箱から戻す手順

OneDrive の Web サイトでの戻し方は次の順です。

順番操作（OneDrive の Web サイト）
1onedrive.com に移動し、Microsoft アカウント、または職場または学校アカウントでサインインする
2［ナビゲーション］ウィンドウで［ごみ箱］を選ぶ
3戻すファイルやフォルダーをポイントし、丸いチェック ボックスをオンにする
4［復元］を選ぶ

ごみ箱には、ほかの日に消したものも並んでいます。ファイル名が似ている場合は、消した日やフォルダーの名前を見て、戻すものを選び分けます。個人用 Vault に入れていたファイルを消した場合は、ごみ箱の［個人用 Vault アイテムの表示］で表示します。

3．パソコンのエクスプローラーで消したときは

OneDrive をパソコンと同期していて、エクスプローラーの OneDrive フォルダーから消した場合は、Windows のごみ箱も見ます。ヘルプでは、OneDrive フォルダーからファイルやフォルダーを削除した場合、またはオンラインで見つからない場合は、Windows のごみ箱または Mac のゴミ箱をチェックするよう案内しています。 Windows のごみ箱では、戻すファイルやフォルダーを選んで右クリックし、［復元］を選ぶと、元のフォルダーに戻ります。

反対に、パソコンのごみ箱に見当たらないこともあります。ヘルプには、クラウドから削除されたファイルはパソコンのごみ箱に表示されず、OneDrive または SharePoint の Web のごみ箱から戻せる場合がある、という注があります。 片方で見つからなければ、もう片方も見る、と覚えておくと迷いません。

4．ごみ箱に無いときに考えられること

Web のごみ箱にもパソコンのごみ箱にも無いときは、次のどれに当たるかを考えます。

考えられることヘルプの記載
ごみ箱からも消したOneDrive のごみ箱から完全に削除されたファイルやフォルダーは復元できない
ほかの人から共有された資料だった復元できるのは自分の OneDrive に保存されていたものだけで、他のユーザーが共有していたファイルは復元できない
別のアカウントで保存していた正しい Microsoft アカウントにログインしているかをチェックする

ほかの人から共有されていた資料は、自分のごみ箱には戻ってきません。共有していたファイルやフォルダーが他のユーザーによって削除されると、そのファイルやフォルダーは利用できなくなります。 この場合は、資料の持ち主に連絡して、持ち主の側で戻してもらうよう頼みます。

職場または学校のアカウントでは、ごみ箱から削除したアイテムを管理者が復元できる場合があります。 管理者に頼むときは、探しているファイルやフォルダーの名前、最後にファイルにアクセスしたおおよその日時と使ったデバイスを伝えられるようにしておきます。

5．たくさん消してしまったときの、もう一つの戻し方

1つ2つの資料ではなく、フォルダーをいくつもまたいで消したり動かしたりしてしまった場合は、ごみ箱から1件ずつ選ぶのが大変です。ヘルプでは、Microsoft 365 サブスクライバーは［OneDrive 全体を復元する］機能で、ファイルとフォルダーに起きた変更を過去 30 日間の任意の時点に戻せると案内しています。 職場または学校のアカウントでは、組織が対応していれば、OneDrive Web サイトの右上から［オプション］を選び、［OneDrive を復元する］を選ぶ流れです。

ただし、これは OneDrive 全体を巻き戻す操作です。個人用アカウントの説明には、復元ポイントの日付以降に作成されたファイルまたはフォルダーは OneDrive のごみ箱に送られる、という注意があります。 消した後にほかの資料を新しく作っていた場合、それらもいったんごみ箱へ移ることになります。消したものが少ないなら、まずはごみ箱から必要なものだけを戻す方が、ほかの作業への影響を小さくできます。

6．消すときに出る確認を読み飛ばさない

誤って消す場面を減らすには、消すときに出る確認のメッセージが役に立ちます。Windows のパソコンで消す手順のヘルプによると、共有されているアイテムを削除すると、すべてのユーザーに対してアイテムが削除され、OneDrive が意図的かどうかを確認するように求めることがあります。 一度に大量のファイルを削除したときにも、意図的かどうかを確認するメッセージが出る場合があります。 この確認が出たら、一度手を止めて、消す範囲が合っているかを見直します。

なお、消したのではなく、上書き保存して内容が変わってしまった場合は、ごみ箱ではなくファイルの以前のバージョンを戻す操作になります。ヘルプでも、以前のバージョンの復元は別の項目として案内されています。

7．架空の例：片付けの後に請求書のフォルダーが無い

月末に OneDrive のフォルダーを片付けた事務担当者が、翌週になって請求書のフォルダーごと消していたことに気づいた場面です（架空の例）。

確かめたこと架空の記入例
消した日6日前（会社のアカウントなので、ヘルプの日数の内）
見た場所OneDrive の Web サイトの［ごみ箱］
戻したもの「請求書」フォルダー（同じ日に消したほかのフォルダーは戻さない）
戻した後の確認元の場所に、中のファイルがそろって戻ったことを担当者2人で見た

こうした「消したときの戻し方」は、困ったその日に探すと時間がかかります。ごみ箱の場所と日数を社内の手順書に1行足しておくと、次に同じことが起きたときに慌てずに済みます。手順書の作り方は、業務マニュアルの作り方でも紹介しています。
