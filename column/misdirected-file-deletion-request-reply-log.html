誤送信した資料の削除依頼と受信者の回答を結んで残すには

要点

削除依頼と受信者の回答は、同じ案件の中で、受信者と対象資料ごとに対応を追える形で残します。依頼済み、回答待ち、回答で確認できた範囲を別々に記入し、元の依頼文と回答へ戻れるようにします。担当者が引き継ぐときは、残る質問と次の確認担当も併せて渡します。

公開：2026年11月11日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、資料を誤って送ってしまい受信者に削除を頼んだ小さな会社の担当者が、送信記録・依頼文・受信者の回答を受信者と資料ごとに結び、確認できた範囲と回答待ちを分けて引き継ぎ、個人データが含まれるときの報告の確認へつなぐ流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 削除を頼む対象を送信記録から特定する
  2. 依頼と回答を照合できる欄を用意する
  3. 回答の言葉から確認できた範囲を切り分ける
  4. 回答待ちの仕事を次の担当者へ渡す
  5. AIで整える下書きと人の照合を分ける
  6. 初動の記録を制度上の対応の確認へつなぐ
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．削除を頼む対象を送信記録から特定する

確認日：2026-11-10

IPAの「情報漏えい発生時の対応ポイント集」は、誤送信・Webでの誤公開の場合の初動対応として、何の情報がどの程度含まれていたのか、暗号化やアクセス制限の有無を確認するとしています。誤送信で送信先が明らかな場合は、受信者にミスについてお詫びし、受信した情報について削除を依頼するとしています。同じ箇所の応急処置の例には、メール・FAX・郵便の誤送信について受信者への連絡と情報の廃棄が挙がり、留意点として受信者に連絡が取れない場合の対応が挙がっています。この資料の表紙の記載は2012年9月3日・第3版です。令和4年4月からの漏えい等の報告の義務より前の資料のため、報告の要否は最後の節の個人情報保護委員会の案内で確かめます。

たとえば、案内資料に社内用の別紙を添付して送った場面を考えます。削除依頼の対象には、誤送信メールの件名や送信時刻、添付名など、相手が該当する資料を区別できる情報を記入します。同じ名前の資料が複数あるときのため、送信した版をたどれる手掛かりも社内の記録に残すとよいです。削除依頼の文面に資料の中身を再掲する範囲は、社内の対応責任者と調整します。

2．依頼と回答を照合できる欄を用意する

ここからは当社の整理です。

記録は、案件全体の概要と、受信者ごとのやり取りを結び付ける形にします。概要には発覚の経緯や誤送信した資料の識別情報を置き、やり取りには依頼と回答の対応関係を残します。担当者の交代後も、どの依頼に何が返ってきたかを追えることが目的です。

残す欄記入する内容照合する点
案件の識別情報社内で使う案件名と記録の置き場所誤送信の概要とやり取りがつながるか
受信者・対象資料送信先、件名、送信時刻、添付名、版の手掛かり誰のどの資料への依頼か
削除依頼依頼日時、連絡方法、依頼文の保存先、回答を求めた事項何を依頼し、何への回答を待っているか
回答回答日時、回答者、原文の保存先、回答の要旨依頼した相手・対象と一致するか
確認できた範囲回答で言及された削除対象、確認者、照合した内容相手の申告と社内の確認を区別できるか
残る確認回答のない事項、追加質問、次の連絡担当、確認予定対応待ちの仕事を引き継げるか

一覧の要旨は短くし、詳しい文面は保存先から読めるようにします。電話の回答は、受けた担当者が発言の要旨と受けた時刻を記録し、文章で受け取った回答と区別して扱います。聞き取った内容に補足が必要な箇所も残すと、次の担当者が質問を組み立てやすくなります。

受信者が複数いる案件では、回答の状況を受信者ごとに持たせます。同じ相手に資料を複数送った案件では、回答がどの添付に言及しているかも分けて記入します。担当者が概要だけを見て対応済みと判断することを避けるため、概要には回答待ちの相手や対象を表示する欄を設けるとよいです。

3．回答の言葉から確認できた範囲を切り分ける

回答を照合する順番は、回答者、対象資料、実施した内容、実施時点、残る質問とします。受信者が依頼文を引用せずに返信しているときも、保存した依頼の内容と突き合わせます。相手の「承知しました」という返事は、依頼を受け付けた回答として記録し、削除したという回答の有無は別の欄で追います。

「メールを削除した」という回答には、その文言を保った要旨を付けます。添付資料を別の場所に保存したか、印刷や転送をしたかについては、回答に触れられた範囲を記入します。触れられていない事項は、残る確認の欄に移します。相手から受け取っていない内容を要旨へ足すことは避けます。

社内の記録では、「受信者が削除したと回答」「担当者が回答と依頼対象を照合」「残る質問あり」と、確認の対象が読める表現を使います。回答を受けた事実、相手が実施したと述べた内容、社内で確かめた内容が、それぞれ読み取れる書き方に整えます。

追加回答を受けたときは、前の回答も読める形で追記します。要旨を直した担当者と理由も残すと、回答の内容が変わったのか、社内で読み違いを修正したのかをたどれます。回答の原文と要旨が食い違う箇所は、原文へ戻って整理し、担当者間の推測で埋めることを避けます。

4．回答待ちの仕事を次の担当者へ渡す

依頼を出した後の記録には、送った時点の情報に加え、回答を待つ担当者と次に見直す予定を入れます。連絡がつかない相手については、試した連絡方法、連絡した日時、得られた反応をまとめ、対応責任者へ渡します。次の連絡方法や扱いを決めた担当者も残すとよいです。

状況欄の表現をそろえる際は、その言葉で何が分かるかを社内で共有します。「依頼済み」は送った依頼へ戻れる状態、「回答待ち」は待っている事項と担当者が分かる状態、「確認済み」は確認した対象と根拠が分かる状態として運用します。確認済みの欄にも、確認できた範囲を添えます。

引き継ぎでは、未回答の相手と質問、追加連絡の予定、対応責任者への相談事項を取り出します。対応が進んだ相手の長い経緯を読み直さなくても、次に扱う仕事を見つけられる形が適しています。相手の返事を待っている間にも、社内へ共有した時点と共有先を追記しておきます。

5．AIで整える下書きと人の照合を分ける

AIを使う作業範囲は、社内で利用を認めた環境で、識別情報を置き換えた記録から、要旨や確認事項の下書きを作るところまでとします。渡す文章は必要なやり取りに絞り、誤送信した資料の内容を入力する範囲は社内の取扱方針に沿って決めます。

下書きの確認では、受信者の発言を断定へ変えていないかを見ます。「対応する予定」という回答が「対応済み」に変わっていないか、添付への言及をメール全体の削除へ広げていないかが着眼点です。要旨に使った原文の場所も併記させ、人が依頼と回答を照合します。

相手への追加連絡の文面や、記録上の対応状況を確定する役割も人が担います。照合を終えた要旨に確認者を付け、追記の根拠となった回答が読める状態で引き継ぎます。

6．初動の記録を制度上の対応の確認へつなぐ

IPAの資料の情報漏えい情報共有シート（例）には、初報なので不明な項目は不明として迅速に報告するよう書かれています。回答がそろうまで概要の共有を待つ運用を避け、分かった範囲と回答待ちの範囲を併記して、対応責任者へ渡すとよいです。

誤送信した資料に個人データが含まれる場合は、その後の法改正にも注意します。個人情報保護委員会の案内では、令和4年4月1日から、個人データの漏えい等が発生し、個人の権利利益を害するおそれがあるときは、個人情報保護委員会への報告及び本人への通知が必要となっています。同じ案内は、個人の権利利益を害するおそれがあるときに該当する事態として、要配慮個人情報が含まれる事態、財産的被害が生じるおそれがある事態、不正の目的をもって行われた漏えい等が発生した事態、1,000人を超える漏えい等が発生した事態の4つを挙げ、速やか（概ね3〜5日以内）に報告を行うよう案内しています。

同委員会のガイドライン（通則編）は、個人データを含むメールを第三者に誤送信した場合を漏えいに該当する事例に挙げ、個人データを第三者に閲覧されないうちに全てを回収した場合は漏えいに該当しないとしています。速報の内容については、報告をしようとする時点において把握している内容を報告すれば足りるとしています。受信者の回答に開封や閲覧の有無が書かれているか、書かれていないかも、確認できた範囲の欄に原文の言葉のまま残します。また、同委員会の案内では、権限委任先省庁等は毎年更新しているため、報告前には最新の報告先を確認するよう案内しています。

個別の報告・通知の要否や契約上の対応は、これらの公式案内を踏まえて専門家に確認します。相談へ渡す記録には、誤送信の対象、依頼した内容、受信者から得た回答、確認した範囲、残っている質問をまとめます。回答の到着後も、対応責任者が残件の扱いを確認できる形で保管します。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□受信者と対象資料を、元の送信記録に結び付けたか
□削除依頼の文面と送った日時を残したか
□回答者と回答対象を、依頼内容に照らして確かめたか
□回答の原文と要旨を対応させたか
□確認できた範囲と、回答のない事項を分けて記入したか
□回答待ちの担当者、次の確認予定、責任者への共有状況を残したか
□記録の下書きを元の依頼と回答に照合したか
