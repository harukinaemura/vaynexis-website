Windowsのエクスプローラーで最近使ったファイルを出さないには

要点

最近使ったファイルを出さないには、最近開いた項目の表示をオフにし、ほかの場所の履歴への影響も確認します。操作後は、一覧の見え方と元の資料を開けることを別々に確かめるとよいです。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、エクスプローラーに最近使ったファイルを出さないようにしたい小さな会社の担当者が、Windows の表示設定とスタートなどへの影響を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 最初に、名前が出ている場所を確かめる
  2. 最近開いた項目の表示を設定からオフにする
  3. 別の表示やクラウドの項目が残ったとき
  4. 表示の確認と、資料の保管を分ける
  5. 事務で使う場面と、引き継ぎに残すこと
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．最初に、名前が出ている場所を確かめる

確認日：2026年11月15日

この記事の操作は Windows 11 を対象とし、Microsoft の日本語ヘルプの適用先は Windows 11 と Windows 10 です。画面の表記は Windows の版や更新状況によって異なることがあります。まず、困っているのが保存先の一覧なのか、最近開いた資料を呼び出す一覧なのかを整理します。画面の名前と、表示を控えたい項目をメモしておくと、変更後に同じ場所で比べられます。

エクスプローラーでは、Windows 11 バージョン 22H2で、従来のクイック アクセスという開始画面の名前がエクスプローラー ホームに変わっています。手順書と目の前の呼び方が違うときは、呼び方だけで別の機能だと判断せず、どの領域の一覧を指しているかを合わせます。

スタート メニューの推奨事項には、最近追加したアプリ、頻繁に使用するアプリ、最近開いたファイルが含まれます。資料名が見える場所をまとめて「履歴」と呼ぶより、表示された場所と内容を分けておく方が、変更する範囲を説明しやすくなります。

2．最近開いた項目の表示を設定からオフにする

設定の場所まで進む

［スタート］→［設定］→［個人用設定］→［スタート］の順に開きます。今回探すのは、最近開いた資料の表示を切り替える項目です。画面全体をすっきりさせようとして、周辺の設定もまとめて変更する進め方は避け、目的の項目と変更前の状態を対応させます。

対象と範囲を読んで切り替える

［スタート］、［ジャンプ リスト］、［エクスプローラー］で最近開いたアイテムを表示するトグルをオフにします。項目名を読む際は、「最近追加した」「よく使用する」など、似た表現との違いに注意します。操作を終えたら、切り替えた設定名と、オフになっている状態を控えます。

この表示切り替えは、エクスプローラーに加え、スタートとジャンプ リストの最近開いた項目も対象としています。日頃の資料の呼び出し方に合わせて、変更後に困る入口がないかも確かめます。対象外の欄まで変わったと判断しないよう、確認する場所を変更前のメモとそろえるとよいです。

3．別の表示やクラウドの項目が残ったとき

Windows 11のエクスプローラーには、クイック アクセスへフォルダーをピン留めして表示する機能があります。残った名前が資料なのか保管先なのか、自分で置いた入口なのかを確認します。名前が残っているという理由だけで、履歴の設定が反映されなかったと結論づけないことが大切です。

エクスプローラー ホームからは、Microsoft365.comのファイルを検索することもできます。手元で開いた資料の一覧と、アカウントに関係する表示を混ぜず、どの欄にどの項目が残るかを記録します。

クラウドのファイル検索には、アカウントに基づく情報や最近のファイルなどを含める設定もあります。対象に含まれる情報の範囲を読み、履歴だけを扱うつもりで周辺の表示まで変更してよいかを考えます。意図した範囲と合わないときは、追加の変更を重ねず、管理担当者へ残った欄の名前を伝えるとよいです。

4．表示の確認と、資料の保管を分ける

表示設定を変えた後は、最初に名前が出ていた画面へ戻り、控えていた対象と見比べます。続いて、元の保存先から必要な資料を開き、仕事を続けられるかを確認します。「名前が見えない」と「資料を利用できない」を混同せず、表示を変える目的が満たされたかを見る流れです。

エクスプローラーで選択した項目を削除してごみ箱に移動する操作には、Ctrl+D（または Del）があります。表示を控えるための作業では、元の資料を削除する操作に進まず、設定を切り替えた結果を確認します。資料を処分するかどうかは、今回の表示変更とは別に扱います。

必要な資料を探し直す際は、エクスプローラーで保存先のフォルダーから検索できます。表示を変える前に保管先を控えておくと、履歴を使わない開き方を引き継ぐ際にも役立ちます。たどり着いた資料が、同名の控えではなく普段更新しているものかも照合します。

5．事務で使う場面と、引き継ぎに残すこと

ここからは当社の整理です。

画面をほかの人に見せる作業では、見せる資料を先に選び、関係のない名前が見える場所を整理しておくとよいです。表示の変更と合わせて、必要な資料へ戻る経路を用意しておけば、説明の途中で探し直す場面にも対応できます。

想定する場面表示を控えたいもの操作後に確かめること
画面を使って書類の説明をする説明と関係のない資料名説明する資料を保存先から開けるか
担当を引き継ぐ前任者が開いた資料への依存保管先と日常の開き方が伝わるか
端末の使い方をそろえる利用者ごとに異なる履歴の見え方変更した範囲と残った表示を説明できるか

引き継ぎには、変更した設定名、変更前後の状態、確認した画面、資料の保管先を残します。うまく合わなかった場合も、「消えなかった」だけで済ませず、残った欄と項目の種類が分かる記録にすると、次の担当者が調べる対象を絞れます。

事務の手間を洗い出すなら、資料を探す、開く、画面で説明する流れを分け、繰り返している箇所を整理します。AIで減らす作業を考える入口としても、まず人が扱う資料と判断する場面を明らかにするとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□表示を控えたい名前が出る画面と欄を記録したか
□変更する設定名と変更前の状態を控えたか
□表示が変わる対象の範囲を確認したか
□切り替え後に元の画面へ戻って見比べたか
□残った項目が資料か保管先かを見分けたか
□元の保存先から必要な資料を開けるか確認したか
□設定の変更内容と確認結果を引き継げる形にしたか
