Chromeの「ショートカットを作成...」で仕事のサイトを開くには

要点

ショートカットを作りたいサイトを開き、右上のその他アイコンから［キャスト、保存、共有］、［ショートカットを作成...］の順に選びます。表示されるダイアログで名前をそのまま使うか変更し、［作成］を選びます。 同じメニューの［ページをアプリとしてインストール］は、ウェブサイトをアプリとして使えるようにする別の機能です。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

勤怠や受発注のシステムなど、毎朝同じサイトを開くなら、パソコン版 Chrome の［キャスト、保存、共有］にある［ショートカットを作成...］でショートカットを作っておくと、Chrome を開いてから探す手間が減ります。作る手順と名前の付け方、同じメニューにある［ページをアプリとしてインストール］との違いを、Google の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 毎朝の「探して開く」を短くする
  2. ショートカットを作る
  3. 名前は「何を開くか」が分かるように
  4. 同じメニューの［ページをアプリとしてインストール］とは別物
  5. 作った後に確かめること
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．毎朝の「探して開く」を短くする

確認日：2026年11月16日。

対象は、Windows のパソコンで使う Google Chrome です。Chrome そのものをタスクバーに固定する方法と、ブックマーク バーの使い方は扱いません。

朝いちばんに勤怠のシステムを開き、次に受発注のシステム、昼前には銀行の取引の画面。毎日開くサイトが決まっている人は少なくありません。そのたびに Chrome を開き、ブックマークを探すか、アドレスを途中まで打って候補から選ぶ。一回は数秒でも、毎日、何人もが繰り返すと積み重なります。

Chrome には、お気に入りのウェブサイトへのショートカットを作る機能があります。 毎日開くサイトのショートカットを作っておけば、そのサイトを開くまでの操作を短くできます。

2．ショートカットを作る

  1. パソコンで Chrome を開きます。
  2. ショートカットを作成するウェブサイトにアクセスします。
  3. 右上のその他アイコンから［キャスト、保存、共有］、［ショートカットを作成...］の順に選びます。
  4. 表示されるダイアログで、名前をデフォルトのまま使うか、変更します。
  5. ［作成］を選びます。

手順2で開くページが行き先になると考えられます（ヘルプに明記はありません）。作る前に、どのページで作るかを決めておきます。ログインした後の画面ではなく、ログインの入口のページで作っておくと、翌朝にログインが切れていても同じ入口から入りやすいかもしれません。

3．名前は「何を開くか」が分かるように

ダイアログに最初に出るデフォルトの名前は、長かったり、どのシステムか分かりにくかったりすることもあります。ヘルプにもあるとおり、名前はここで変えられます。

開くサイト（架空）付けた名前の例決め方
勤怠のシステムのログインページ勤怠（打刻）何をするかを括弧で添える
取引先 A 社の受発注のサイト受発注 A社取引先の名前を後ろに付ける
社内の規程のページ規程集短く、ほかと重ならない名前

同じ会社のシステムでも、勤怠と経費精算で入口が違うことがあります。名前を「〇〇クラウド」のように会社名だけにすると、どちらか分からなくなりがちです。共用のパソコンなら、使う人が替わっても迷わない名前にしておくことが、とくに大切です。

4．同じメニューの［ページをアプリとしてインストール］とは別物

［キャスト、保存、共有］のメニューには、［ショートカットを作成...］のほかに、［ページをアプリとしてインストール］もあります。 名前が似ているので、取り違えないようにします。

ヘルプによると、ウェブアプリを使うと、ウェブサイトがアプリとして機能し、パソコンやモバイルデバイスのランチャーやホーム画面からアクセスできるようになります。一部のウェブアプリには、オフラインで見るための追加のストレージ、通知、ファイルシステムへのアクセス、アイコンバッジなどの追加機能が含まれています。

比べる点［ショートカットを作成...］［ページをアプリとしてインストール］
ヘルプでの説明お気に入りのウェブサイトへのショートカットを作るウェブサイトがアプリとして機能する
追加の機能ヘルプに記述なし一部のアプリには通知などの追加機能がある
やめるときヘルプに記述なしアプリを開き、その他アイコンの［[アプリ名] をアンインストール］

「サイトをすぐ開きたい」だけなら、まずはショートカットで足ります。通知などアプリとしての機能を使うかどうかは、職場で使い方を決めてからでも遅くありません。アプリとして入れた場合は、chrome://apps で管理することもできます。

アプリとして入れたものには、ショートカットに関わる機能がほかにもあります。chrome://apps でアプリを右クリックして［ショートカットを作成］を選ぶと、パソコン上のどこにショートカットを表示するかを選べます。 同じく右クリックで［起動時に開く］を選ぶと、Windows にログインしたときにアプリが自動で開くようにもできます。 毎朝かならず開くシステムなら便利ですが、全員のパソコンで勝手に開くようになると戸惑う人も出ます。使うかどうかは、職場で決めてからにします。

5．作った後に確かめること

作ったら、まずそのショートカットからサイトを開いてみて、思ったページが開くかを確かめます。ショートカットがパソコンのどこにできたか（デスクトップか、スタート メニューか）も、その場で見ておきます。後から「どこに作ったか分からない」と探し回ることがなくなります。

パソコンを入れ替えたり、新しい人が入ったりしたときにも、同じショートカットを作れるように、どのサイトにどの名前で作ったかを一覧にしておくと便利です。毎日の決まった作業を、手順や時間と一緒に書き出しておくなら、業務棚卸しチェックシート（エクセル・CSV）が使えます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□ショートカットにしたいページ（ログインの入口など）を開いてから作ったか
□［キャスト、保存、共有］の［ショートカットを作成...］を選んだか（［ページをアプリとしてインストール］と取り違えていないか）
□名前を、何を開くかが分かる名前に変えたか
□［作成］の後、ショートカットから開いて、思ったページが開くかを確かめたか
□ショートカットができた場所を確かめたか
□作ったサイトと名前を一覧に残したか
