Excelのピボットの行見出しを列ごとに分けて見せるには

要点

行見出しを項目ごとに別の列へ分けるには、ピボットテーブルを表形式に切り替えます。 列を分けた後は、見出しを各行に表示したいかも考えるとよいです。見る人が項目の境目を追えるか、途中の行から読んでも意味が伝わるかを基準に、仕上がりを確かめます。

公開：2026年11月5日／情報の確認日：2026年11月5日（出典はこの記事の最後）

この記事は、Excelのピボットテーブルで同じ列にまとまった行見出しを列ごとに分けて見せたい小さな会社の事務担当者が、表形式への切り替えとラベルの繰り返しを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月5日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 利用する版を確かめ、表示を切り替える
  2. 各行にも見出しを置きたいときの追加操作
  3. 備品の貸出表なら、見たい形を短く決める
  4. 変更前後を比べ、引き継ぎに残す
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．利用する版を確かめ、表示を切り替える

確認日：2026年11月4日。

この記事の操作対象は、ラベルの繰り返しの公式ヘルプが適用先として挙げるExcel for Microsoft 365、Excel 2024、Excel 2021です。 表示を切り替える手順は、レイアウトの公式ヘルプの［Windows］の欄の説明に沿って記載します。 同じヘルプには［Web］と［macOS］の欄もあり、利用環境ごとに説明が分かれています。

表全体の表示を変える手順

  1. 対象のピボットテーブルの内側をクリックします。
  2. ［デザイン］タブの［レイアウト］グループから、［レポートのレイアウト］を開きます。
  3. メニューで［表形式で表示］を選びます。

操作後は、分けたい見出しの名前がそれぞれの列に並んでいるかを見ます。見出しだけで意味が伝わるか、隣の項目との境目を読み違えないかも確認の観点です。

手元の画面と説明が合わない場合は、利用している版と、公式ヘルプで選んでいる環境を照合するとよいです。画面名の似た操作を続けるより、どの説明を読んでいるかを先に揃えます。

2．各行にも見出しを置きたいときの追加操作

列の境目が分かったら、次は同じ見出しが続く部分の読み方を考えます。途中の行だけを見た人にも所属する項目を伝えたいときは、見出しの繰り返しも確認する対象です。

繰り返しラベルが表示されるのは、ピボットテーブルが表形式の場合に限られます。 列を分ける操作を終えてから、次の設定を確かめます。

  1. 繰り返したいラベルを右クリックし、［フィールドの設定］を開きます。
  2. ［レイアウト］&［印刷］タブで、［アイテムのラベルを繰り返す］をオンにします。
  3. ［アイテムのラベルを表形式で表示する］が選択されていることも確かめます。

見出しが続く部分の表示まで揃ったら、途中の行から読み始めても内容を追えるかを見ます。受け取る人が表の上まで戻って意味を確かめる場面を思い浮かべると、必要な表示を考えやすくなります。

3．備品の貸出表なら、見たい形を短く決める

ここからは当社の整理です。

表示を直す前に、どの見出しを横に並べたいかを言葉にします。たとえば、保管場所と備品名を分けて見たい場合の、仕上がりの抜粋は次の形です。

保管場所備品名貸出件数
会議室延長コード集計した件数
会議室変換アダプター集計した件数
事務室ラベルライター集計した件数

表の「集計した件数」は表示位置を示すための言葉です。確認の中心は、保管場所と備品名を別々に追えることと、各行がどこに属するか読み取れることに置きます。

見本を作る段階で、受け取る人にも見出しの名前を読んでもらうとよいです。項目の意味が曖昧なら、並べ方だけを変えても読み方が揃わないためです。表示の変更と、項目の意味の確認を分けて進めます。

この記事で扱うのは、できあがっている集計表の見出しの見せ方です。元の台帳の列をどう設計するかは、別に整理する範囲とします。

4．変更前後を比べ、引き継ぎに残す

見た目を整えたら、変更前後の表を同じ範囲で見比べます。見出しの並びだけを見て終わらず、値や集計対象にも意図しない違いがないかを確かめるとよいです。違いが見つかったときは、表示以外に触れた操作がないかを振り返ります。

確認するときは、表の先頭だけでなく、同じ見出しが続く部分や、見出しの切り替わる部分も見ます。受け取る人の読み始める位置を変えてみると、意味を取り違えそうな箇所に気づきやすくなります。

引き継ぎには、利用する版、対象の表、選んだ表示、繰り返して表示する見出しを短く残します。「見やすくした」という説明だけでは、後任が同じ形を確かめにくいためです。変更した目的も添えると、表示を戻す場面の判断材料になります。
