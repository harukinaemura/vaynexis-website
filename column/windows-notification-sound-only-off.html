Windowsの通知の「サウンドの再生」だけを止めるには

要点

通知の音だけを止めたいときは、［設定］の［システム］から［通知］を開き、［アプリやその他の送信者からの通知］で音を止めたいアプリを選んで、［サウンドの再生］をオフにします。 同じ画面の［通知バナーの表示］や［通知センターに通知を表示する］はそのままにしておけば、通知そのものは届きます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Windows 11 で、チャットやメールのアプリの通知が来るたびに鳴る音だけを止めたいときの手順です。通知のバナーや通知センターの一覧は残したまま、アプリごとの［サウンドの再生］だけを切る道順と、バナーや通知そのものを止める設定との違いを、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．音だけが困る、という場面

確認日：2026年11月17日。

対象は Windows 11 のパソコンです。

電話の応対中や、静かな事務所で、通知の音が何度も鳴ると気になります。かといって通知を全部止めると、取引先からの連絡や会議の始まりに気づけなくなるおそれがあります。ヘルプには、Windows の通知は、画面にバナーとして表示でき、通知センターでもアクセスできると書かれています。 音はそれとは別の項目として切り替えられます。そこで、画面の右下に出るバナーや、あとから見返せる通知センターの一覧は残し、音だけを止める、という切り分けをします。

2．アプリごとに3つの項目がある

［通知］の画面でアプリを選ぶと、そのアプリの通知について、いくつかの項目を選べます。ヘルプに挙がっているのは次の3つです。

項目ヘルプの説明音だけ止めるとき
通知バナーの表示通知のポップアップ バナーを有効または無効にしますそのまま
通知センターに通知を表示する通知を通知センターに表示するかどうかを選択するそのまま
サウンドの再生受信通知のサウンドを切り替えるオフにする

アプリごとの設定なので、音を止めたいアプリを一つずつ選んで切り替えます。会議の予定を知らせるアプリの音は残し、チャットのアプリの音だけを止める、といった使い分けもできます。

3．鳴らなくなった分、見に行く場所を決めておく

音を止めると、通知が届いても耳では気づけなくなります。代わりの合図として、ヘルプには、新しい通知がある場合、タスク バーの通知ベル アイコンが点灯すると書かれています。 見逃した通知は、タスク バーの時計または通知ベル アイコンを選ぶか、Windows キー＋N キーを押して、通知センターで確かめられます。

音を止めたアプリについては、電話を終えたとき、来客を見送ったとき、といった区切りで通知センターを開く、と決めておくと取りこぼしが減ります。バナーと通知センターを残しておくのは、この「後から見る」ができるようにするためです。見終わった通知は、閉じるボタンでクリアするか、［すべてクリア］で通知センターから削除できます。 残っている通知が、まだ見ていない知らせだけになるので、次に開いたときに探しやすくなります。

4．大事なアプリは、音ではなく優先度で目立たせる

チャットの音は止めたいが、会議の予定の知らせは見落としたくない、という場合もあります。ヘルプでは、アプリごとの通知の優先度を［上位］、［高］、または［標準］に設定でき、トップに設定できるアプリは1つだけで、通知センターの通常の通知の上に優先度の高い通知が表示されると説明されています。 音を止めるアプリと、優先度を上げるアプリを分けて考えると、静かさと見落としにくさを両立しやすくなります。

5．通知センターの［その他］から切ってしまわない

通知センターで知らせを見ているとき、その場で止めたくなることがあります。ヘルプには、通知センターから特定のアプリのすべての通知をオフにする方法として、［その他］ボタンから［すべての通知をオフにする］を選ぶ手順が書かれています。 これは音だけでなく、そのアプリの通知そのものを止める操作です。音だけを止めたいときは、この近道を使わず、［設定］の［通知］の画面で［サウンドの再生］を切り替えます。

6．古い手順書の「通知にサウンドの再生を許可する」

社内の古い手順書に、通知の音をまとめて止めるチェック ボックスの説明が残っていることがあります。同じヘルプの Windows 10 の欄には、［システム］の［通知 & アクション］で［通知にサウンドの再生を許可する］を選べると書かれています。 Windows 11 の欄では、音の設定はアプリごとの［サウンドの再生］として挙がっています。 手順書を Windows 11 に合わせて直すときは、この違いを書き添えておきます。

7．バナーを止める設定と取り違えない

バナーがじゃまで止めたい、という相談とは別の話です。［通知バナーの表示］をオフにすると、画面の右下に出る知らせそのものが出なくなります。音だけを止めたいのに、こちらを切ってしまうと、届いたことに気づきにくくなります。設定を変える前に、困っているのが「音」なのか「画面に出る知らせ」なのかを確かめます。

社内で「通知がうるさい」という相談があったとき、音・バナー・通知そのものの、どれを止めたいのかを最初に聞くだけで、やり直しが減ります。パソコンの困りごとと対応を並べて記録しておくときは、業務棚卸しチェックシート（エクセル・CSV）の考え方も参考になります。

□［アプリやその他の送信者からの通知］で、音を止めたいアプリを選んだか
