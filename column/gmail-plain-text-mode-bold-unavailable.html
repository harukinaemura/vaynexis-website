Gmailのプレーン テキスト モードで太字が使えないときは

要点

太字や文字の色などの書式が使えないときは、作成画面のメッセージの下部にあるその他アイコンから［プレーン テキスト モード］を選び、オンかオフかを確かめます。 署名の書式を設定できず、署名ボックスの上に［書式なし］と表示されるときは、署名を編集する前にプレーン テキスト モードをオフにするよう、ヘルプで案内されています。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

太字のボタンを押しても文字が変わらない、署名の上に［書式なし］と出る。そんなときに見るのは、設定画面の歯車ではなく作成画面の中の切り替えです。オフにする場所と、書式をクリアとの使い分けを確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．太字が効かない原因を、モードから疑う

確認日：2026年11月17日。

対象は、パソコンのブラウザで使う Gmail です。Android や iPhone の Gmail アプリは、ヘルプの手順が別のタブに分かれているため扱いません。

Gmail のメールの見た目は、作成画面の書式設定オプションで変えます。ヘルプでは、メッセージの下部にある書式設定オプション アイコンをクリックする手順が示されています。 ところが、作成画面がプレーン テキスト モードになっていると、文字の飾りを付ける前提が変わります。

ヘルプの署名のトラブルシューティングには、署名のテキストの書式を設定できず、署名ボックスの上に［書式なし］と表示される場合は、プレーン テキスト モードをオフにする、と書かれています。 書式が使えない原因の一つとして、このモードが公式に挙げられているということです。太字のボタンを何度押しても変わらないときは、文字の選び方や操作の順番を疑う前に、まずモードを見ます。

なお、Outlook にもメッセージの形式を切り替える設定がありますが、画面も手順も別物です。ここで扱うのは、Gmail の作成画面の［プレーン テキスト モード］だけです。

2．切り替える場所は作成画面の「その他」

順番操作
1パソコンで Gmail を開く
2左上にある［作成］をクリックする
3メッセージの下部にあるその他アイコンをクリックする
4［プレーン テキスト モード］をクリックし、チェックが外れた状態にする

署名のトラブルシューティングのページでも、［作成］をクリックし、右下にあるその他のオプション アイコンから［プレーン テキスト モード］のチェックボックスをオフにする手順が書かれています。 設定画面の歯車の中ではなく、メールを書く画面の中にある切り替えだという点が、見つけにくさの原因になりがちです。

オフにした後は、太字にしたい語を選び直して、書式設定オプションから太字を当て直します。モードを切り替える前に入力していた文章の書式がどう扱われるかは、ヘルプのページからは読み取れなかったため、大事なメールでは、切り替えた後に本文全体を見直してから送ります。

3．署名の上に［書式なし］と出ていたら

署名は、設定の［署名］のボックスに入力し、必要に応じて画像の追加や書式の変更で体裁を整えられます。 署名の会社名を太字にしたいのに書式が付けられないときは、先に作成画面でプレーン テキスト モードをオフにしてから、署名の編集に戻ります。

ヘルプには、Gmail の一部のバージョンは太字や斜体などの書式設定に対応しておらず、それらのバージョンで書式設定されたテキストを使うと、署名に余分な文字が追加されることがある、とも書かれています。 署名に見覚えのない記号が混ざって見えるときは、署名から書式設定を削除する方法が案内されています。手順は、右上の設定アイコンから［すべての設定を表示］を開き、［署名］セクションで署名をハイライト表示して、「書式をクリア」アイコンをクリックする流れです。 太字の会社名にこだわりすぎず、書式がなくても読める署名にしておくと、こうした崩れに強くなります。

4．書式設定オプションと、キーボードで当てる方法

キーボード ショートカットを使うと、テキストの書式設定なども行えます。 ヘルプの書式設定の一覧では、太字は「⌘ または Ctrl+b」、書式をクリアは「⌘ または Ctrl+\」です。 ショートカットで太字にならないときも、まずプレーン テキスト モードを疑うのは同じです。

反対に、「ほかの文書から貼り付けた文字の色や大きさだけを消したい」という場合に、プレーン テキスト モードをオンにする必要はありません。プレーン テキスト モードは作成画面のメールの書き方そのものを切り替えるもので、一部の文字の飾りを外すだけなら、その文字を選んで書式をクリアするほうが、ほかの太字や箇条書きを残せます。モードは「書式を使わない」と決めたときの切り替え、書式をクリアは「この部分だけ元に戻す」ときの操作、と分けて覚えておくと迷いません。

毎回同じ文字の大きさや字体で書きたいときは、［すべての設定を表示］の［既定の書式スタイル］で、作成するすべての新規メールに適用するテキスト スタイルを選べます。設定を変えたら、ページの下部にある［変更を保存］をクリックします。 既定の書式とプレーン テキスト モードが同時にどう働くかは、ヘルプのページには書かれていません。

5．書式が使えないときの書き方（架空の例）

プレーン テキスト モードを使い続ける理由がある場合や、書式に頼らずに伝えたい場合は、文字の並べ方で目立たせる方法もあります。

場面（架空の例）太字にしたかった所書式なしでの書き方の例
支払期日の連絡期日の日付行を分け、【お支払期日】の見出しを付ける
社内への設備点検のお知らせ停止する時間帯先頭の一文に時間帯を書く
見積の再送差し替えた金額「変更点」として箇条書きにする

太字は便利ですが、相手の環境で同じように見えるとは限りません。大事な語ほど、書式がなくても伝わる位置に置いておきます。社内でよく送るメールの書き方をそろえたいときは、決まりを短い手順にまとめておくと迷いが減ります。手順のまとめ方は、業務マニュアルの作り方のページで紹介しています。
