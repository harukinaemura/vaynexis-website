クラシックOutlookの作業時間で勤務日の開始時刻を直すには

要点

クラシック Outlook では、［ファイル］タブ、［オプション］、［予定表］の順に開き、［作業時間］の［開始時刻］と［終了時刻］の一覧で勤務日の時刻を選びます。 この時刻は主に、ほかの人から会議出席依頼を受けるときの空き時間に使われます。 ただし、新しい Outlook や Web 版で「作業時間と場所」をすでに設定している場合は、クラシック Outlook での変更が反映されないことがあります。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

時短勤務で始業を10時に変えたのに、9時からの会議の依頼がまだ届く。クラシック Outlook の作業時間で開始時刻と勤務する曜日を直す場所と、新しい Outlook で設定した時間が優先される場合の見分け方を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

勤務の形ごとの決め方の表は架空の例です。作業時間を勤怠と分けて使う考え方や確認表は当社の整理で、Microsoft のヘルプに沿った手順そのものではありません。

  2. 開始時刻を直す手順
  3. 曜日ごとに時刻が違う人は、クラシックだけでは表せない
  4. 新しい Outlook で設定したことがあるなら、そちらを直す
  5. 週の最初の日と、年の最初の週も同じ画面にある

1．作業時間は、会議を入れる人のための設定

確認日：2026年11月17日。

対象は、Windows のパソコンで使うクラシック Outlook（［ファイル］タブがある Outlook for Microsoft 365、Outlook 2024、Outlook 2021）です。根拠にしたヘルプの適用先もこの3つです。

ヘルプによると、作業時間では、勤務週に含める曜日、勤務日の開始と終了の時刻、週の始まりの曜日を選べます。 既定では、勤務週は月曜日から金曜日の午前 9 時から午後 5 時とされ、週の最初の日は日曜日です。 一度も触っていなければ、始業が何時の人でも「9 時から 5 時」として扱われていることになります。

この設定は、自分の予定表の見た目を整えるためというより、会議を入れる側に自分の空き時間を伝えるためのものです。時短勤務やシフト勤務で始業が遅い人、午後だけ出社する人が既定のままにしていると、会議を入れる人の画面では朝から空いているように見えてしまいます。反対に、作業時間は勤怠の記録ではありません。出勤した時刻を残す仕組みとは分けて考え、Outlook の作業時間は「会議を入れてよい時間帯の目安」として使います。

2．開始時刻を直す手順

順番操作
1［ファイル］タブをクリックする
2［オプション］をクリックする
3［予定表］をクリックする
4［作業時間］の［開始時刻］と［終了時刻］の一覧で、勤務日の時刻をクリックする
5勤務する曜日のチェック ボックスをオンにし、含めない曜日をオフにする

手順5は、週の中で出勤する曜日が決まっている人のための設定です。ヘルプでは、勤務時間の一部である日のチェック ボックスを選び、含まれていない日のチェック ボックスをオフにする、と説明しています。 例えば水曜日が定休の人は、水曜日のチェックを外しておきます。

3．曜日ごとに時刻が違う人は、クラシックだけでは表せない

月曜日は8時から、水曜日は10時から、というように曜日で時刻が違う人は、クラシック Outlook の作業時間だけでは表せません。「作業時間と場所」のヘルプでは、従来のやり方では、勤務週の全体に対して1つの開始時刻と終了時刻しか使えない、と説明しています。

曜日ごとの時刻は、新しい Outlook や Outlook on the web の［設定］>［Calendar］>［作業時間と場所］で、曜日のチェック ボックスをオンにし、ドロップダウンで毎日の作業時間と場所を選んで設定します。 ただしこの設定は、資格のある Microsoft 365 サブスクリプションを持ち、Outlook で職場または学校アカウントを使っている人だけが使えます。

ヘルプには、曜日ごとに違う時刻を設定した場合、従来の作業時間は、その中のいちばん早い開始時刻といちばん遅い終了時刻を使った概算になる、という例が載っています。 月・火・木は8時から17時、水・金は10時から19時なら、クラシック Outlook からは「8時から19時」に見える、ということです。

4．新しい Outlook で設定したことがあるなら、そちらを直す

もう1つ気をつけたいのが、どちらの設定が生きているかです。ヘルプによると、新しいやり方の作業時間をまだ設定していないうちは、従来の作業時間を変えると、新しいほうの時間も更新されます。 ところが、新しいやり方の作業時間を一度設定（または更新）すると、その後の従来の作業時間への変更は反映されず、新しいほうの作業時間で上書きされます。

つまり、前に新しい Outlook や Web 版で作業時間を設定したことがある人は、クラシック Outlook で開始時刻を直しても、ほかの人から見える時刻が変わらないかもしれません。その場合は、新しい Outlook か Outlook on the web の［作業時間と場所］で直します。例外はタイム ゾーンで、従来の作業時間のタイム ゾーンを変えると、新しいほうのタイム ゾーンも毎回更新されると書かれています。

5．週の最初の日と、年の最初の週も同じ画面にある

同じ［作業時間］の欄には、週の最初の日と、年の最初の週の一覧もあります。週の最初の日は［週の最初の日］の一覧で曜日をクリックして選び、年の最初の週は［年の最初の週］の一覧で選びます。 既定は日曜日始まりなので、社内の勤務表や行事予定が月曜日始まりなら、ここで月曜日にそろえておくと、週の表示を見比べやすくなります。

6．会議を入れる側の画面で確かめる

直した後は、会議を入れる側からどう見えるかを確かめます。クラシック Outlook のヘルプでは、Microsoft 365 または Exchange のアカウントを使っている場合、スケジュール アシスタントで出席者のスケジュールを表示できると案内しています。 同僚に頼んで、自分を出席者に入れた会議の画面を開いてもらい、始業前の時間帯がどう見えるかを一度見てもらうと、直した結果を確かめやすくなります。

7．勤務の形ごとの決め方（架空の例）

勤務の形（架空の例）作業時間の設定補うこと
毎日10時から16時の時短勤務開始10:00、終了16:00、月〜金変更を部署に一言伝える
月・水・金だけ出勤するパート開始9:00、終了15:00、月・水・金だけオン出勤しない曜日は予定表にも書いておく
曜日で始業が違う営業クラシックでは1つの時刻しか持てない新しい Outlook の［作業時間と場所］で曜日ごとに設定

勤務の形が人ごとに違う職場ほど、会議を入れる人の手間が増えます。作業時間の設定を全員でそろえるのは、会議の日程調整の手戻りを減らす小さな工夫の1つです。日程調整の流れを見直すときは、業務改善の進め方の考え方も参考になります。
