Windowsのテキストサイズで画面の文字だけ大きくする手順

要点

画面の文字だけを大きくするには、［設定］の［アクセシビリティ］から［テキスト サイズ］を開き、スライダーで調整します。サンプルを見てから適用し、普段使う画面でも読みやすさを確かめる流れです。全体が小さいのか、文字を読み取りにくいのかを先に分けると、変更する場所を選びやすくなります。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、画面の文字だけを大きくしたい小さな会社の担当者が、Windows のテキストサイズの調整と適用後の見え方を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象を確かめ、文字の設定画面を開く
  2. サンプルを見てから［適用］を選ぶ
  3. 文字だけの調整と画面全体の拡大を分ける
  4. 変わった場所と変わらない場所を見比べる
  5. 事務の確認結果を引き継ぎに残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．対象を確かめ、文字の設定画面を開く

確認日：2026年11月15日

ここでは、Microsoft が日本語で案内している Windows 11 の手順を扱います。画面の表記は Windows の版や更新状況によって異なることがあります。開く場所は、次の順序です。

［設定］→［アクセシビリティ］→［テキスト サイズ］の順に進みます。文字の大きさを変えたいときは、この画面にいることを確かめてから操作に移ります。

Microsoft の案内では、テキストの調整が影響する場所の例として、タイトル バー、メニュー、アイコン テキストが挙げられています。そのため、仕事で困っている場所を「画面が小さい」とだけ伝えるより、「操作を選ぶメニューの文字が読みにくい」と表す方が、見直したい対象を共有しやすくなります。

2．サンプルを見てから［適用］を選ぶ

画面上のサンプルの文字を大きくするには、この画面のスライダーを右へ動かします。スライダーを動かすと、上部のプレビューがその場で更新されます。まずはサンプルを読み、見やすさの変化を確かめます。大きくすること自体を終点にせず、いつもの姿勢で文字を追えるかを見ます。

文字の大きさを確認したら、［適用］を選びます。サンプルを動かして見え方を選ぶ段階と、選んだ大きさを反映する段階を分けて考えると、操作の途中で終わることを避けやすくなります。

適用後は、最初に読み取りにくいと感じた画面へ戻って確かめるとよいです。文字が読めるかに加え、操作する項目の名前を最後まで追えるか、普段の仕事を進めるうえで困る場所がないかも見ます。設定画面のサンプルだけで判断を終えず、実際に使う場所の見え方を判断材料にします。

3．文字だけの調整と画面全体の拡大を分ける

Microsoft の案内では、文字だけを大きくする操作はテキストのスライダーで行い、画像やアプリを含む全体の拡大は［スケール］で選ぶため、操作する項目が異なります。今回は文字だけを読みやすくする手順なので、全体の拡大を同時に進めず、文字の見え方を先に比べます。

「文字が小さい」という相談でも、画像や操作部分も含めて見にくいのか、文字の読み取りだけが負担なのかで、整理する対象は変わります。文字の調整を試したあとは、最初の困りごとが残っている場所を見直すとよいです。別の項目まで続けて変更すると、どの操作によって見え方が変わったのかを確かめにくくなります。

画面の一部を拡大・縮小するための機能は、拡大鏡です。一部分を拡大して読むことと、普段の画面の文字の大きさを調整することも、目的を分けて考えます。引き継ぐときも、「拡大した」という言い方だけで済ませず、どこを変えたのかを残すと伝わりやすくなります。

4．変わった場所と変わらない場所を見比べる

テキスト サイズについて、Microsoft はレイアウトやアイコンのサイズを変更せず、Windows とほとんどのアプリの文字を拡大する機能として案内しています。すべてのアプリで同じように変わると考えず、使っている画面ごとに結果を確かめることが大切です。

たとえば、操作を選ぶ場所は読みやすくなったものの、作業中に読む場所には困りごとが残ることも考えて、確認する箇所を分けます。変化が分かりにくいときは、「大きくならなかった」とだけ記録せず、画面のどの部分を見たか、適用する操作まで終えたかを残すとよいです。

個々のアプリには、そのウィンドウだけを拡大できる場合もあります。ある画面だけ読み取りにくさが残る場合は、その画面で使える表示方法を別に確かめます。文字の調整を繰り返す前に、困っている範囲を絞るためです。

5．事務の確認結果を引き継ぎに残す

ここからは当社の整理です。

普段読む文字を、次のように場所ごとに見比べます。

困っている場面変更後に見るところ引き継ぎに残すこと
操作の項目名が読み取りにくい普段使うメニューの文字読みにくかった場所と変更後の見え方
画面の上部の文字を追いにくい同じ画面の同じ位置文字を追えるか、困る場所が残るか
作業画面の一部だけ読みにくい変わった部分と変わらない部分未解決の箇所と、別に確認する対象

確認は、普段の仕事を進める順番に沿って行うと整理しやすくなります。画面を開く、操作を選ぶ、内容を読む、という流れで、どこに負担が残るかを見ます。表の項目をすべて埋めることより、自分が困っていた場所について判断を残すことが目的です。

結果を共有するときは、見え方を確かめた人の判断も添えるとよいです。別の人が読めたことだけで終えず、日常的に操作する人が確認したかを区別します。引き継ぎの記録も、操作の経路、変更前の困りごと、変更後に確認した場所、残った困りごとの順にすると読み返しやすくなります。

事務の手間を洗い出すなら、表示の調整で対応する困りごとと、作業の進め方を見直す困りごとを分けて整理するとよいです。その先で AIを業務に取り入れる進め方 を考える際も、読む・写す・確かめるといった作業の内容を具体的に残しておくと、検討する対象が明確になります。
