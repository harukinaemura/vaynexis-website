Edgeの「Internet Explorer モード」で古い社内画面を開くには

要点

Internet Explorer で動作するように作られたサイトを見る必要があるときは、Microsoft Edge で Internet Explorer モードを使えます。 会社が管理していない PC で Edge 141 以上なら、［設定など］＞［設定］＞［既定のブラウザー］の［Internet エクスプローラー モードのページ］で［ページの追加］を選び、サイトを足してから再読み込みします。 会社が管理している PC では、サイトを開いて［設定など］から［Internet Explorer モードの再読み込み］を選びます。設定が灰色で変えられない場合もあります。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Internet Explorer 向けに作られた古い社内の画面が Microsoft Edge で正しく動かないとき、Edge の Internet Explorer モード（IE モード）で開く手順です。会社が管理していない PC で Edge 141 以上を使う場合と、会社が管理している PC の場合とで手順が分かれる点、30日の期限、戻り方を、Microsoft の日本語の公式ページに沿って整理します。

1．IE モードが要る画面か

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Microsoft Edge です。特定の業務システムの設定や動作は扱いません。

Microsoft のヘルプには、一部のサイトは Internet Explorer で動作するように作られていて、Edge のような最新のブラウザーでサポートされていない機能がある、と書かれています。 Internet Explorer のサポートは、2022年6月15日に終了しています。

管理者向けの資料によると、IE モードは、最新のサイトには Edge に組み込まれた Chromium エンジンを、従来のサイトには Internet Explorer 11 の Trident MSHTML エンジンを使う仕組みです。 何年も前に作った勤怠や受発注の社内画面で、ボタンを押しても反応しない、表示が崩れる、といった症状が出たときに、試す価値があります。反対に、普通に動いている画面まで IE モードに切り替える必要はありません。

2．自分の PC がどちらの手順かを先に確かめる

ヘルプの手順は、PC が会社に管理されているかと、Edge の版によって分かれています。先に二つを確かめます。

Edge の版は、ウィンドウの上部にある［設定など］から［設定］を選び、下にスクロールして［Microsoft Edge について］を選ぶと確かめられます。 会社が管理しているかどうかは、パソコンを配った人やパソコンを管理している人に聞くのが確実です。

3．共通の最初の手順：IE モードを許可する

ヘルプでは、IE モードを有効にする手順が最初に書かれています。

  1. Edge のアドレス バーに「edge://settings/defaultBrowser」と入力して Enter キーを押します。
  2. ［Internet エクスプローラーの互換性］で、［Internet エクスプローラー モード (IE モード) でのサイトの再読み込みを許可する］のドロップダウンから［許可］を選びます。
  3. Edge を再起動します。

4．会社が管理していない PC（Edge 141 以上）

ヘルプには「Enterprise 以外のデバイスで Edge バージョン 141 以上を使用している場合」として、次の手順が書かれています。

  1. ［設定など］（...）＞［設定］＞［既定のブラウザー］に進みます。
  2. ［Internet エクスプローラー モードのページ］のところで［ページの追加］を選び、IE 互換が必要なサイトを追加します。
  3. サイトの詳細を入力して［追加］を選びます。
  4. サイトを再読み込みします。

追加するのは、困っている画面のアドレスだけにします。社内のどの画面を足したかを控えておくと、別の人の PC で同じ設定をするときにも迷いません。

5．会社が管理している PC

「エンタープライズ デバイスを使用している場合、またはグループ ポリシーを使用して」IE モードを有効にしている場合の手順は、次のとおりです。

  1. IE モードで表示したいサイトに移動します。
  2. ブラウザー ウィンドウの右上隅にある［設定など］を選びます。
  3. ［Internet Explorer モードの再読み込み］を選びます。

Edge のバージョン92 以前なら、［その他のツール］＞［インターネット エクスプローラー モードで再読み込み］を選びます。

会社が管理している PC では、最初の手順の［再読み込みを許可する］の項目が表示されても、設定が灰色で変えられない場合があります。 ヘルプには、組織はエンタープライズ サイト一覧を使ってユーザーの IE モードを構成できるとも書かれています。 管理者向けの資料も、組織の従来のサイトはエンタープライズ モード サイト一覧で構成することを勧めています。 灰色で選べないときは、自分で回り道を探すより、困っている画面のアドレスを添えて、管理している人に一覧への追加を頼むのが早道です。

6．開いた後の見分け方と戻り方

IE モードで読み込まれると、ナビゲーション バーの左側に IE のロゴが表示されます。 画面の中のリンクやフォームで進む操作は IE モードのままですが、アドレス バーや戻るボタン、お気に入りのリンクで移動すると、Edge は IE モードから自動的に抜けます。

自分で戻るときは、画面の上部にある情報バーで［退出］を選ぶか、今のタブを閉じて新しいタブを開きます。 社内の古い画面を見終えたら、ほかの作業は普通のタブに戻ってから続けます。

7．30日たつと IE モードで開かなくなることがある

管理者向けの資料（Edge 92 以降の仕組みの説明）では、利用者が IE モードで開くように足したページは、既定の期間である30日間、ローカル サイト一覧に残ると書かれています。 31日目にそのサイトを開くと、IE モードで読み込まれなくなることを知らせるバナーが出て、希望すればもう一度一覧に追加できます。 日数は管理者がポリシーで変えられ、既定は30日、決めるときの値は0日から90日までです。

また、ローカル サイト一覧は、今のところデバイス間で同期されません。 月に一度しか開かない締めの画面なら、前回の追加から30日を過ぎて、また普通の表示に戻っていることもありえます。PC を入れ替えたときも、足し直しが要ると考えておきます。
