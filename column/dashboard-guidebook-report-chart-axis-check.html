ダッシュボードデザインの実践ガイドブックで報告図の軸をそろえるには

要点

配る前に開くのは、4章「情報表現のポイント」の4.4「グラフ設計の原則」と4.5「Do's Dont's」、それに5章の5.4「チェックリスト」です。4.4では、誤解を生まないための原則として、グラフ軸の値範囲を恣意的に設定しない、値の範囲を省略しない、と書かれています。 4.5では、グラフの原点、特に棒グラフの原点は0にするよう示されています。 これを並べた図の1枚ずつに当て、目盛りの範囲・単位・期間がそろっているかを確かめます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

会議資料にグラフを何枚か並べたら、同じ高さの棒なのに金額が違っていた、という行き違いは月次の報告で起きがちです。デジタル庁の「ダッシュボードデザインの実践ガイドブック」のグラフ設計の原則とチェックリストで、数量軸・原点・単位・期間を配る前に確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

軸を見る3点の表と配る前の確認表は当社の整理で、デジタル庁が示したチェックリストそのものではありません。

  1. 開く版と、節の探し方
  2. 軸より先に、何と比べる図かを決める
  3. 数量軸で見る3点
  4. 比較範囲は、題と注記で見せる
  5. 配る前は、チェックリストで締める
  6. 確認表
  7. 月次の報告資料の作り方をそろえたいとき

1．開く版と、節の探し方

確認日：2026年11月17日。

対象は、会議や取引先への報告に、表計算ソフトなどで作ったグラフを何枚か並べて出す会社の事務の担当者です。特定のソフトの設定の手順は扱いません。

デジタル庁のページ「ダッシュボードデザインの実践ガイドブックとデザインテンプレート」は、最終更新日が2026年7月17日です。 更新情報には、2026年3月31日にガイドブックとデザインテンプレートの正式版をリリースしたとあります。 いまダウンロードできるのは「ダッシュボードデザインの実践ガイドブック（2026年3月31日更新）」の本体（PDF）と代替テキストです。 対象は行政職員に限らず、民間事業者や個人も含め、データの活用方法に迷っている全ての方とされています。

以下で示すページ番号は、表紙に「2024年9月3日更新」とある1つ前の版のPDFのものです。 いまの公式ページからはリンクされていない古い版です。2026年3月31日更新版の代替テキストでも、「4.4 グラフ設計の原則」「4.5 Do's Don'ts」「5.4 チェックリスト」の節の番号と名前、軸や原点についての文は同じでした（2.2の見出しだけは後で述べるとおり言葉が違います）。 新しい版のPDFではページの位置がずれていることがあるため、ページ番号ではなく節の番号で探すのが確実です。

2．軸より先に、何と比べる図かを決める

目盛りを直す前に、その図が何と比べるためのものかを決めます。3.3「プロトタイプを作る」の中の「ダッシュボード設計の原則」（2024年版22ページ）では、数量単体では意思決定が難しいデータには、目標値や平均値、前年の値を併記したり、前年比で表したりして、比較できる対象を提供するとされています。 比べる相手が目標値なのか前年なのかで、横軸の期間も、並べる系列も変わります。

グラフの種類の選び方も、比べ方で決まります。4.2「グラフの種類と選び方」（2024年版30ページ）では、時間変化と傾向を伝える場合には折れ線グラフ、数量を比較して伝える場合には棒グラフが適しているとされています。 折れ線グラフについては、横軸は時間である必要があると書かれています。 部門別の比較を折れ線でつないでいたら、棒グラフに替える合図です。

元のデータがそもそも比べられる形かも見ておきます。2.2の節（2024年版11ページ）では、データの制約の確認項目に「指標同士を比較できない」が挙がっています。 なお、この節の見出しは2024年版では「2.2 制約条件を理解する」、2026年版の目次では「2.2 制約条件を整理する」です。 架空の例で、営業部の資料は4月からの累計、工事部の資料は月ごとの件数だったとします。この2枚は、目盛りをそろえても比べられません。元をそろえられないときは、横に並べずに別の図にして、違いを注記に書きます。

3．数量軸で見る3点

見る点ガイドブックの箇所（2024年9月3日更新版）報告図で確かめること
軸の値範囲4.4「表現を歪曲しない」（40ページ）図ごとに上限・下限を勝手に変えていないか、途中を省いていないか
原点4.5「グラフの原点は原則として0にする」（46ページ）棒グラフの縦軸が0から始まっているか
単位4.4「わかりやすく表記する」（40ページ）円・千円・件・％の別が、題か軸に書いてあるか

4.4の「表現を歪曲しない」には、グラフ軸の値範囲を恣意的に設定しない、値の範囲を省略しない、数量の差が実際よりも誇張や矮小化されて見えるような表現をしない、と並んでいます。 2枚の棒グラフを並べ、片方の上限が1,000万円、もう片方が500万円なら、同じ高さの棒でも金額は倍違います。並べて見せる図は、上限と目盛りの刻みを同じ値に決めてから作るのが安全です。

4.5の46ページには、悪い例として「原点が０になっていない」棒グラフが載っています。 縦軸が途中から始まると、小さな差が大きく見えます。ガイドブックの書き方は「原則として」で、特に棒グラフを名指ししています。折れ線グラフで0から始めない場合は、範囲を省いていることが読み手に分かるよう、図の近くに一言添えておきます。

単位については、4.4の「わかりやすく表記する」で、タイトルや系列名、数値の単位を丁寧かつ簡潔に表記するとされています。 1枚は円、もう1枚は千円という並びは、会議資料でよく起きる取り違えです。

4．比較範囲は、題と注記で見せる

目盛りがそろっても、期間や数え方が違えば比べられません。4.5の「タイトルにグラフの内容とデータ種別を表記する」（2024年版44ページ）では、月次推移や累計などのデータ種別を正確に記載し、見る人がデータを誤認しないようにするとされています。 「売上」だけの題を「部門別売上（4〜9月の月次推移・税抜）」のように直すと、隣の図との違いが一目で分かります。

4.4の「データを定義する」（40ページ）では、何を対象として収集したデータで、数値の意味が何であり、いつ更新されたかを参照できるようにするとされています。 同じページの「メタ情報を記載する」では、データのソース、更新日、いつ時点の数値か、注釈、免責事項などの補足情報を提供するとされています。 締め日が違う2つの台帳から作った図なら、その違いを注記に書きます。

紙で配る資料なら、凡例と色にも気を配ります。4.5では、凡例をグラフと隣接させ、凡例の順序をグラフと対応づけるとされています。 色のみで分類を識別しない、の項には、白黒印刷しても伝わる情報となるように意識するよう書かれています。

5．配る前は、チェックリストで締める

5.4「チェックリスト」（2024年版52〜54ページ）は、完成したダッシュボードをレビューするためのチェックリストです。 項目には「棒グラフの原点は0になっていますか？」「データの更新日は記載されていますか？」があり、比較できる数値が掲載されているかを問う項目もあります。 公式ページでは、このチェックリストをExcelのファイルでも配っています。

画面で見るダッシュボード向けの項目もあり、たとえば読み込み速度を問う項目は、紙の報告書なら飛ばしてかまいません。 社内で使う分は、軸・原点・単位・期間・更新日の5つに絞った短い表にして、作った人とは別の人が配る前に見る形にすると続けやすくなります。

報告に載せる数を、出どころ（実測か換算か）と並べて示す形は、当社のレポートの見本の第5節「月次レポートに載せる数」でも使っています。図を作る前に、どの数を、何と比べて載せるかを表で決めておく手がかりになります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□その図が何と比べるための図か（目標値・前年・部門どうし）を決めたか
□時間の変化は折れ線グラフ、数量の比較は棒グラフにしたか
□並べた図どうしで、軸の上限・下限と目盛りの刻みを同じにしたか
□棒グラフの原点を0にしたか（折れ線で0から始めないなら注記したか）
□単位（円・千円・件・％）を題か軸に書いたか
□題に、月次推移か累計かなどのデータ種別と期間を書いたか
□データの出どころ・更新日・いつ時点の数値かを注記したか
□白黒で印刷しても系列を見分けられるか

7．月次の報告資料の作り方をそろえたいとき

報告の図は、作る人が替わるたびに目盛りや題の付け方が変わり、前の月と並べて読めなくなることがあります。載せる数と比べる相手、図の題と注記の決まりを手順に書き出す見直しは、当社でも一緒に進められます。

資料の作り方を相談したい場合は、初回無料相談をご利用ください。数値の正しさや経営上の判断についての意見は述べていません。
