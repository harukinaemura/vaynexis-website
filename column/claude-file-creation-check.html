Claudeのファイル作成を確認する｜設定・保存先と形式別の検品

要点

機能の利用可否と保存先を確かめ、受け取ったファイルを開いて内容・計算・体裁を点検してから業務に使います。修正は元のファイルを残した別名の版にまとめ、修正箇所とその周辺を見直します。保存できたことと、内容を確認し終えたことを分けて扱うのが基本です。 この記事の例は説明のための架空の例です。実在の会社の話ではありません。 製品の機能・設定の確認日：2026-11-02。

公開：2026年11月2日／情報の確認日：2026年11月2日（出典はこの記事の最後）

この記事は、Claudeにファイルを作ってもらう事務の担当者が、機能の設定と保存先を確かめ、できたファイルを形式ごとに検品するまでの流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月2日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 機能の対象と設定を確かめる
  2. 保存先と受け取り方を分ける
  3. 形式ごとに完成ファイルを開く
  4. ずれは場所と期待する状態を伝える
  5. 使う版を選び保存場所を記録する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．機能の対象と設定を確かめる

コード実行とファイル作成は、Free・Pro・Max・Ultra・Team・Enterpriseの全ユーザーが、ウェブ・デスクトップ・モバイルで利用できる機能です。Free・Pro・Max・Ultraの設定は「設定 > 機能」にあり、更新された設定画面では「ファイルを作成・編集」という名称です。アップロードとダウンロードの最大ファイルサイズは、いずれもファイルあたり30MBと記載されています。

ここからの進め方は当社の整理です。作成を始める前に、利用中の画面で設定の状態を見て、受け渡すファイルの大きさも確認します。使いたい設定が見当たらないときは、契約や組織の管理状況を担当者と確かめるとよいです。

容量だけを見て元の資料を不用意に削ると、照合に使う情報まで失われます。必要な範囲を分ける場合も、元の資料は残し、どの範囲から作ったファイルなのかを記録しておきます。

2．保存先と受け取り方を分ける

生成ファイルは、ダウンロードするか、Google Driveに直接保存できます。Googleのコネクタを使う前には、Googleアカウントで直接認証する必要があります。Team・Enterpriseでは、個別ユーザーの認証より先に、組織のオーナーまたはプライマリオーナーによるコネクタの有効化が必要です。

Google形式での作成は、Google Doc・Google Sheet・Google Slidesを名前で指定するか既存ファイルのリンクを渡す方法が案内されており、Googleへの言及なしに文書を頼む場合はダウンロード可能なファイルが作られます。

受け取り方を選ぶ手順は当社の整理です。手元に受け取る場合は保存するフォルダを、接続先へ保存する場合は利用するアカウントと目的のフォルダを先に決めます。保存先とファイル形式は分けて指定すると、受け取るものを確認しやすくなります。

作成後は、予定した場所を自分で開き、ファイル名と中身を照合します。会話に表示された完了の説明だけで判断せず、実際に使うファイルを開くところまでを受け取りの手順に含めます。

3．形式ごとに完成ファイルを開く

この節は当社の整理です。以下の表は、人が検品するための観点をまとめたものです。

対応する出力形式には、Excel（.xlsx）、PowerPoint（.pptx）、Word（.docx）、PDFがあります。

形式中身の確認表示・配布前の確認
Excel合計の対象範囲、参照先、単位、端数の扱いを元の資料と照合見出しと値の対応、列幅、印刷する範囲
PowerPoint本文と図表の対応、表題と説明の整合文字のはみ出し、図の重なり、投影したときの読みやすさ
Word見出しの順序、本文の抜け、表や注記の位置改ページ、余白、見出しだけがページ末尾に残っていないか
PDF元の内容との一致、ページの抜け、図表と注記文字の欠けや重なり、ページ端の切れ、配布先での開きやすさ

計算のある表では、表示された合計と元の資料を突き合わせ、計算に含める範囲も確認します。見た目が整っていても、計算の対象を取り違えていないかは別に見る必要があります。

資料の体裁は、実際に開いた画面を見ながら確かめるとよいです。編集用と配布用を別々に作る場合は、それぞれを開き、同じ内容が残っているかを比べます。印刷する用途では印刷前の表示も確認対象に含めます。

見つかったずれは「計算がおかしい」「体裁が悪い」だけで終わらせず、該当する見出しや表、期待する表示を書き留めます。修正後に同じ場所を探せる記録にしておくと、再確認の基準になります。

4．ずれは場所と期待する状態を伝える

この節は当社の整理です。修正依頼には、問題の場所、期待する状態、変更しない範囲を入れます。元のファイルを直接書き換えず、別名の修正版を作る依頼にすると、修正前後を比較できます。

たとえば、配布資料の表がページの端で切れている場合は、次のように伝えます。

対象は、今回作成した配布資料。
元のファイルはそのまま残す。
「連絡先」の表がページの右端で切れているため、表全体が収まるように幅と余白を調整する。
本文の内容と項目の順序は変更しない。
修正版は、元の名前の末尾に「_修正版」を付けた別名で出力する。
変更した箇所を本文とは別の短いメモにまとめる。
保存や上書きが必要な操作は、実行する前に確認を挟む。

修正後は、切れていた表に加えて、その前後のページと本文も見直します。修正対象の外に変化がないかも比べ、意図しない変更は次の依頼に分けるとよいです。変更の説明は照合の手がかりにし、完成ファイルそのものを確認します。

5．使う版を選び保存場所を記録する

この節は当社の整理です。検品が終わった版を業務用として選び、保存場所と確認した人を記録します。修正前の版と修正版が並ぶ場合も、配布する版が分かる状態にしておきます。

未修正の箇所があるファイルは、確認済みのものと区別します。内容を確かめた人と配布する人が異なる場合は、残っている確認事項も一緒に渡すとよいです。

同じ名前のファイルを別の場所へ保存したときは、実際に配布する方を開き直します。受け取った時点、直した時点、使う版を選んだ時点を区切ることで、確認途中のファイルを渡す取り違えを防ぐための手順になります。

公開・共有の前に、この表で確かめます。

確認確かめること
