Wordのテキスト ボックスの「リンクの作成」で長い案内文を次の枠へ続けるには

要点

1つの枠に収まらない文章は、枠を大きくする代わりに、もう1つ枠を用意して2つをつなぐと、あふれた分が次の枠へ流れます。Windows 版の Word では、いずれかのテキスト ボックスを選び、［図形の書式］タブの［テキスト］グループで［リンクの作成］を選びます。 ヘルプの Mac 版の節には、選んだテキスト ボックスに空のテキスト ボックスをつなぐ、と書かれています。 つなぐ先の枠は、文字を入れずに空のまま用意しておくのが基本です。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

写真の横や表の下に置いた文字枠に案内文を入れたら、収まりきらずに途中で切れてしまった。文章を書き直すたびに枠の間で切り貼りしないよう、2つの枠をつないであふれた分を次へ流す準備と手順、消すときの注意を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

回覧前に見る所の表は架空の社内案内を想定した例で、確認表と同じく当社が整理した目安です。

  1. 文章を書き直すたびに、枠の間で手で移していないか
  2. つなぐ前に用意しておくこと
  3. 枠を2つ用意する
  4. ［リンクの作成］でつなぐ
  5. 枠の線を消して、本文になじませる
  6. 消す・写すときは、ポインターの位置を見る
  7. 回覧の前に見ておく所（架空の例）

1．文章を書き直すたびに、枠の間で手で移していないか

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Word（Microsoft 365 などのデスクトップ版）です。ヘルプの手順は Windows／Web／Mac のタブに分かれており、ここでは Windows のタブの手順を中心に書きます。

テキスト ボックスは、文書の好きな場所に文字を置いて入力できる部品です。 社内報や回覧の案内で、写真の横や表の下など決まった場所に説明文を置きたいときに使えます。

困るのは、文章を足したときです。枠からはみ出した分を切り取り、別の枠に貼り直す。もう一度書き直したら、また切り取って貼り直す。これを繰り返すと、文の途中で切れたり、同じ文が二重に残ったりしがちです。枠どうしをつないでおけば、文章を足しても削っても、あふれた分は次の枠へ自動で送られます。ヘルプでも、複数のテキスト ボックスがあるときは、ボックスの間で文章が続くようにまとめられると説明されています。

なお、文章を左右の列に流したいだけなら、枠をつながずにページの段組みで済むこともあります。写真や表をはさんで、離れた場所の枠へ続けたいときが、リンクの出番です。

2．つなぐ前に用意しておくこと

用意すること理由
文章を入れる最初の枠案内文の書き出しを入れる
続きを受け止める空の枠文字が入っていると、つなぐ先にできない場合がある
枠を置く場所と大きさ先に配置を決めると、流れ方を見ながら調整しやすい

ヘルプの Windows の節には、つなぐ先が空でなければならないとは書かれていません。ただ、Microsoft の開発者向けの資料（VBA の説明）では、つなぐ先の枠にすでに文字が入っている場合や、すでにほかの枠とつながっている場合は、つなげない扱いになっています。 ［リンクの作成］がうまくいかないときは、まずつなぐ先の枠に空白や改行が残っていないかを見ます。

3．枠を2つ用意する

テキスト ボックスは、［挿入］→［テキスト ボックス］から、組み込みの書式つきの枠を選ぶか、［テキスト ボックスの描画］を選んで入れます。 ［テキスト ボックスの描画］を選んだ場合は、文書の中をクリックしてドラッグし、好きな大きさの枠を描きます。 マウスを使わないときは、Alt キー、N キーを押して離し、X キーを押す方法も示されています。

最初の枠には、ボックスの中を選んで文章を入力するか貼り付けます。 2つ目の枠は、描いたら何も入れずに置いておきます。枠を置く場所を変えるときは、枠をクリックしてポインターが4方向の矢印になったらドラッグします。

4．［リンクの作成］でつなぐ

文章の入った最初の枠を選び、［図形の書式］タブの［テキスト］グループで［リンクの作成］を選びます。 ヘルプの Windows の節に書かれている手順はここまでで、その後につなぐ先の枠をどう指定するかは書かれていません。画面の表示に従って、用意しておいた空の枠を指定します。

つないだら、最初の枠の文章の最後と、次の枠の文章の頭が、意図したとおりにつながっているかを読んで確かめます。最初の枠の大きさを少し変えたり、文章を1行書き足したりして、あふれた分が次の枠へ移るかも試しておくと、回覧の直前に日付や会場を直すときに慌てずに済みます。3つ以上の枠に続けたい場合も、つないだ後に上から順に読み、読む順番と流れる順番が合っているかを確かめます。

5．枠の線を消して、本文になじませる

つないだ枠に線が付いたままだと、案内文の中に箱が並んで見えます。線を消すには、枠を選び、［図形の書式設定］タブで［図形の輪郭］を選んで［輪郭なし］にします。ヘルプでは、罫線を［輪郭なし］にすると、罫線を完全に削除すると説明されています。

2つの枠の線をまとめて消したいときは、最初の枠をクリックし、Ctrl キーを押しながらほかの枠をクリックして、いっしょに選べます。 ただし Word では、複数のオブジェクトを選ぶ前に、それぞれの［文字列の折り返し］を［行内］以外にしておく必要がある、と注意書きがあります。

枠の中の文字の書式は、文字を選んで［ホーム］タブの［フォント］グループで設定します。 枠そのものの書式は、枠を選んで［図形の書式設定］タブで設定します。 2つの枠で字の大きさがそろっているかも見ておきます。

6．消す・写すときは、ポインターの位置を見る

枠を消すときは、消す枠の罫線を選んで Delete キーを押します。 ポインターが枠の中にあると、Delete キーで消えるのは枠ではなく中の文字です。 コピーも同じで、ポインターが枠の中にあると、Ctrl + C キーでコピーされるのは中の文字になります。

つないだ枠の片方を消したり写したりしたときに、流れていた文章がどこへ行くかは、ヘルプには書かれていません。配布する前の文書で試すときは、元のファイルを別名で残してから作業します。

見る所架空の場面での見方
切れ目1ページ目の枠の最後が、文の途中で切れていないか

案内文の置き場所やひな形を部署ごとに決めておくと、毎回の組み直しが減ります。社内向けの文書の作り方をそろえるときは、業務マニュアルの作り方の考え方も参考になります。
