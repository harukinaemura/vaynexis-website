Windowsで消えるメニューを撮るには｜遅延撮影の手順と確認点

要点

撮影開始までの待ち時間を設け、その間に目的のメニューを開いておきます。引き継ぎ用に残す画像では、項目名に加え、どこから開いたメニューなのかが分かることも大切です。撮れた画像を見て、操作の途中の状態が伝わるかを確かめます。

公開：2026年11月5日／情報の確認日：2026年11月5日（出典はこの記事の最後）

この記事は、操作中に消えるメニューを手順書や引き継ぎ資料の画像に残したい小さな会社の事務担当者が、Snipping Toolの遅延撮影の手順と版による違い、撮れた画像の見直しを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月5日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 撮る前に、開くメニューを決める
  2. 遅延を設定し、待ち時間にメニューを開く
  3. 引き継ぎ資料には、選ぶ前の状態を残す
  4. 欠けた画像は、準備と写す範囲を見直す
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．撮る前に、開くメニューを決める

ここでは、公式ヘルプのWindows 11向けの手順を中心に扱います。

撮影対象のメニューを、準備の段階で決めておきます。操作説明に使う画像なら、読み手が探す項目名と、その項目がある場所を先に整理するとよいです。メニューを開いた直後を見せたいのか、項目を選ぶ直前を見せたいのかで、残したい状態も変わります。

撮る目的が曖昧なままだと、画像ができても説明に必要な部分が足りないことがあります。先に説明文を短く考えておくと、どの状態を残すかを絞りやすくなります。

2．遅延を設定し、待ち時間にメニューを開く

Snipping Tool を開いた状態から、次の順で進めます。以下は、待ち時間に［5 秒］を選んだ場合の流れです。

  1. Snipping Toolの［遅延］で、待ち時間を［5 秒］などに設定します。
  2. 撮る範囲の種類を選び、［新規］を選択すると、5秒のカウントダウンが始まります（日本語版ヘルプの遅延の節では、このボタンを［New］と表記しています）。
  3. 5秒以内に、対象のメニューを開いて撮りたい状態に整えます。
  4. 5秒後に画面が灰色になったら、マウスで撮る領域を指定します。

Snipping Tool の公式ヘルプのキーボード ショートカットの表では、Alt + D キーで「キャプチャを 1 ～ 5 秒遅延する」とされています。

Windows 10 を使っている場合は、同じヘルプの Windows 10 の節の手順を見ます。Windows 10 の節には、遅延のほかに、Snipping Tool を開いた後でキャプチャが必要なメニューを開き、Ctrl + PrtSc キーを押す方法が載っています。キーを押すと、開いたメニューを含めて画面全体が灰色になり、その後に切り取りの種類と範囲を選ぶ流れです。使っている Windows の版を先に確かめ、その版の節の手順で進めるとよいです。

待っている間に何を開くかは、撮影を始める前に決めておくとよいです。メニューを探すところから始めるより、開く場所まで準備しておく方が、残したい状態を意識して操作できます。

3．引き継ぎ資料には、選ぶ前の状態を残す

ここからは当社の整理です。画像の役割は、説明文の中で読み手が迷う場所を示すことです。操作が終わった後の画面だけでは、途中で何を選んだのか伝わりにくい場合があります。開いたメニューの中から項目を選ぶ説明なら、選ぶ前の状態を残し、その画像の近くに次の操作を添える形が考えられます。

説明したい場面画像に残したい状態見返す点
一覧の表示方法を変える開いたメニューと選ぶ項目項目名を最後まで読めるか
対象を右クリックして操作する対象と、その近くに開いたメニュー何に対する操作か分かるか
さらに下の階層の項目を選ぶ入口のメニューと、その先の項目たどる順序が分かるか

表は画像の撮り方を整理するための例です。説明文には「この状態から、どの項目を選ぶか」を書き、画像にはその項目を探す手がかりを残します。画面にある文字をすべて文章でも繰り返すと、読む量が増えて操作の順序を見失いやすくなります。

反対に、短い説明だけでは開く場所が伝わらない場合もあります。画像と文章を並べて読み、画像が示す状態と文章が指す操作が合っているかを見るとよいです。引き継ぎ相手が画面を見ながら操作する場面を想定すると、何を残すかを判断しやすくなります。

4．欠けた画像は、準備と写す範囲を見直す

撮れた画像に目的のメニューがない場合は、説明したかった状態を残せているかから見直します。メニューを開いたつもりでも、別の場所を操作した後の画面では、読み手が探している項目を示せません。撮り直す前に、どこを開き、どの状態で操作を止めるかを整理するとよいです。

メニューは写っていても、端が切れていると項目名を読み違えるおそれがあります。選ぶ項目だけに範囲を寄せすぎず、入口や対象との位置関係まで伝わるかが確認点です。細かな文字が読める大きさで見返し、項目名の途中や下の行が欠けていないかを見ます。

共有する画像には、操作の説明と関係のない内容が含まれていないかも目を通します。隠す必要のある内容と説明に必要な範囲が重なるときは、説明用の内容に置き換えた画面で準備する方法もあります。読み手が必要な場所を探せることと、共有する範囲が適切であることを合わせて確かめます。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□使っている Windows の版（Windows 11／Windows 10）と、その版の手順を確かめたか
□撮りたいメニューと、説明する操作を決めたか
□撮影を始める前に、メニューを開く場所まで準備したか
□待ち時間の間に、残したい状態まで操作したか
□選ぶ項目の名前が、途中で切れずに写っているかを確認したか
□メニューの入口や対象との位置関係が伝わるかを確認したか
□画像の状態と、添えた説明文の操作が合っているかを確認したか
□共有に不要な内容が写っていないかを確認したか
