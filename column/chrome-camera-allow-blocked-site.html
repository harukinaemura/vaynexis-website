Chromeの「カメラ」で一度拒否した会議サイトを許可するには

要点

会議の画面でカメラの確認が出たときに［許可しない］を選ぶと、そのサイトはカメラを使えません。 戻すには、Chrome の［設定］から［プライバシーとセキュリティ］、［サイトの設定］と進み、［権限］の［カメラ］を開きます。［カメラまたはマイクの使用を許可しないサイト］でサイト名を選び、権限を［許可］に変更します。 職場のパソコンでは、管理者の設定によって利用者が変えられないこともあります。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Web 会議に入ったのに自分の映像が出ないとき、以前そのサイトでカメラを［許可しない］にしていないかを、パソコン版 Chrome の［サイトの設定］で確かめて許可に戻す手順です。設定の一覧から直す道と、会議のページを開いたまま直す道、許可しても映らないときの見直しを、Google の公式ヘルプに沿って整理します。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．映らない理由が「許可しない」かを先に見分ける

確認日：2026年11月16日。

対象は、パソコンで使う Google Chrome です。会議サービスそれぞれの画面の設定（カメラのオン・オフのボタンなど）は扱いません。

会議のサイトを初めて開くと、カメラを使ってよいかを尋ねるメッセージが出ます。選べるのは［サイトへのアクセス時のみ許可する］、［今回のみ許可］、［許可しない］の3つです。

3つの違いは、次に同じサイトを開いたときに表れます。［今回のみ許可］は今回のアクセス時だけで、次のアクセス時には改めて尋ねられます。［サイトへのアクセス時のみ許可する］は、今後のアクセス時にも使えます。 毎回メッセージが出るのに映らないなら、別の所に原因がありそうです。反対に、メッセージが出ないまま映らないなら、前に［許可しない］を選んでいないかを疑います。ヘルプにも、許可しなかったサイトは、ビデオ会議に参加できなくなるなど、利用できなくなる場合があると書かれています。

急いでいる会議の直前ほど、確認のメッセージを読まずに閉じてしまいがちです。月に一度しか使わない取引先の会議サイトだと、前回どれを押したかを誰も覚えていない、ということも起きます。

2．設定の［カメラ］から許可に戻す

許可しないサイトの一覧は、Chrome の設定の中にあります。

  1. パソコンで Chrome を開きます。
  2. 右上のその他アイコンから［設定］を選びます。
  3. ［プライバシーとセキュリティ］、［サイトの設定］の順に選びます。
  4. ［権限］で［カメラ］を選びます。
  5. ［カメラまたはマイクの使用を許可しないサイト］で会議のサイト名を選び、カメラの権限を［許可］に変更します。

この画面では、許可しているサイトと許可していないサイトを見比べられます。一覧に知らないサイトが並んでいたら、どこで何を押したかを思い出すきっかけにもなります。前に設定した例外そのものを取り消したいときは、そのサイトの右側にある削除を選びます。

3．会議のページを開いたまま直す

設定の画面まで戻るのが手間なら、会議のページから直す道もあります。

  1. 会議のサイトを開きます。
  2. ウェブアドレスの左側で、サイト情報を表示するアイコンを選びます。
  3. ［サイトの設定］を選びます。
  4. カメラの許可の設定を変更します。

このやり方で変えた設定は、デフォルトの設定ではなく、そのサイトだけに使われます。ほかのサイトの扱いは変わりません。 ヘルプには、変更は自動的に保存されること、［権限をリセット］ボタンを使える場合は変更した設定をリセットできることも書かれています。

4．許可しても映らないとき

サイトの権限を許可に戻しても映らないときは、パソコン側の設定と、使うカメラの選び方を見ます。

  • パソコンの設定：Chrome がカメラの使用許可を求めるダイアログを出したときは、［設定を開く］を選び、［カメラ］をオンにします。設定名はデバイスによって異なる場合があります。
  • カメラの選び方：ノートパソコンの内蔵カメラと外付けのカメラがある場合は、同じ［カメラ］の画面で下矢印を選び、デフォルトのカメラを選ぶか、別のカメラに切り替えます。
  • 入り直す：ヘルプのトラブルシューティングでは、ビデオ通話を終了して再参加し、それでもだめなら Chrome とパソコンを再起動する順が示されています。

許可したからといって、いつでも撮られるわけではありません。ヘルプでは、許可したサイトでも、別の Chrome タブや別のアプリを使っている間は録音・録画を始められないと説明されています。 社内で「カメラを許可するのが不安」という声があるときは、この説明を添えて、使う会議のサイトだけを許可する形にすると話が進めやすくなります。

5．職場のパソコンで変えられないとき

職場や学校で Chrome を使っている場合、ネットワーク管理者がカメラとマイクの設定を行っていて、利用者がカメラとマイクの設定を変更できない場合があります。 項目が選べない、変えても元に戻る、というときは、自分で何度も試すより、社内でパソコンを管理している人に、会議のサイトの名前を添えて相談します。

もう一つ覚えておきたいのが、しばらく使っていないサイトの権限です。ヘルプには、ユーザーデータを保護するため、Chrome では最近使用していないサイトから権限を削除すると書かれています。 数か月ぶりの会議でまた確認のメッセージが出ても、慌てずに今回の使い方に合うものを選びます。
