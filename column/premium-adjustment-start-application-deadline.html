保険料調整開始申出書はいつどこへ出す？期限と記入欄の確かめ方

要点

保険料調整開始申出書は、制度の利用が可能となった日から2年が経過した日が属する月の前月までが提出期限です。日本年金機構への提出は、郵送なら事務センターまたは管轄の年金事務所、持参なら管轄の年金事務所です。利用は受付日の属する月からで、過去の月にはさかのぼれません。

公開：2026年11月14日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、保険料調整制度の開始申出を準備したい小さな会社の担当者が、対象該当を確認した後の申出期限、提出先、用紙の選択欄と転記元を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 期限を数える基準日と、利用を始める受付月
  2. 共通様式では「開始」を選び、通知書から転記する
  3. 郵送先と持参先、相談する窓口を分ける
  4. 提出前に、開始後の負担と関連届書も確認する
  5. 社内では、準備・承認・提出後の記録をつなぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．期限を数える基準日と、利用を始める受付月

確認日：2026年11月13日。

この記事は、対象に該当することを確認した後の提出準備を扱います。 対象になるかの判定や保険料の計算は扱いません。

日本年金機構の開始申出の案内では、対象事業所が保険料調整制度の利用を始める際に、事業主が期限内に申出書を提出する扱いです。

担当者が準備を進める際は、社内で利用を決めた日と、公式の通知に記された該当日を分けて記録するとよいです。

申出書の説明では、利用が可能となった日を「基準日」とし、その日から2年を経過した日が属する月の前月までを申出期限としています。日本年金機構の期限の例では、2026年10月中に任意特定適用事業所となった場合、提出期間は2026年10月から2028年9月末までです。対象事業所の条件に複数該当するときは、最初に該当した条件が申出期限の基準になります。

期限の控えには、締切だけでなく、そこへ至る起算の根拠も残します。 後任が同じ資料から確かめられる状態にすると、社内の決定日を起算日に置き換える誤りを見つけやすくなります。 利用を始めたい時期も別欄に置き、提出準備を始める社内の予定と区別します。

2．共通様式では「開始」を選び、通知書から転記する

日本年金機構の届出ページには、開始申出用として「保険料調整（開始／停止解除）申出書」と、開始申出書の記入例が掲載されています。記入例では、保険料調整開始申出書を提出する場合、開始・停止解除の別で「1」を丸で囲みます。

同じ用紙に別の手続きの欄があっても、担当する申出の内容に合わせて確認を進めます。

記入例の主な記入事項は、届書提出日、事業所整理記号・事業所番号、所在地などの事業所情報で、全体は同じ記入例で確認できます。申出書の記入方法では、事業所整理記号・事業所番号は、新規適用時または名称・所在地変更時に付されたものを記入します。

任意特定適用事業所に該当した場合の基準日は、「特定適用事業所該当通知書（任意）」で通知された該当年月日を⑦に記入する説明です。④の開始年月と⑤の事業所区分は職員記入欄で、申出者の記入は不要です。

希望する月を自分で書き込む前に、誰が記入する欄かを見ることが大切です。

開始申出の案内では添付書類は「なし」です。

通知書など、転記のために手元で確認する資料と、提出物として同封する資料を別に管理すると、不要な書類をまとめる手間を避けられます。

エクセルの様式は端末の設定で印刷位置がずれる場合があるため、印刷前に余白設定やレイアウトを確認するよう案内されています。

3．郵送先と持参先、相談する窓口を分ける

日本年金機構の届出ページでは、郵送先は事務センターまたは管轄の年金事務所で、窓口へ持参する場合は管轄の年金事務所です。日本年金機構の郵送の案内では、事務センターへの封筒に送付先の名称と郵便番号（大口事業所個別番号）を記載し、住所の記載は不要としています。

事務センターは窓口相談・電話相談を受けておらず、郵送した書類の問い合わせ先は管轄の年金事務所です。事業所の健康保険・厚生年金保険の手続きの相談は、事業所所在地を管轄する年金事務所が案内先です。

厚生労働省の通知では、健康保険の保険料調整制度の申出は、日本年金機構または健康保険組合へ提出するものとされています。加入先による書類の扱いで迷う点は、今回の提出先に照会し、労務上の判断は専門家に確認するとよいです。

4．提出前に、開始後の負担と関連届書も確認する

日本年金機構の制度概要では、制度の利用を事業主の申出によって途中でやめることはできません。申出書の重点確認項目では、調整終了月分まで事業主があらかじめ追加負担し、対象となる被保険者全員の保険料負担を軽減することが必要です。希望した一部の対象被保険者だけを選んで利用することもできません。

開始申出の案内は、対象者の確認や軽減額の計算に影響するため、資格取得・資格喪失・報酬月額変更などの各種届書を迅速・適正に提出するよう求めています。

申出の作成担当と日常の届出担当が別であれば、未処理の書類や照会中の事項を引き継ぐ準備も必要になります。

5．社内では、準備・承認・提出後の記録をつなぐ

ここからは当社の整理です。

提出準備は、転記を担当する人、内容を確かめる人、発送や持参を担当する人に分けて整理できます。 兼務していても、今どの段階まで済んでいるかが分かるようにするとよいです。 次の表は担当を割り振るためのひな形です。

段階担当の役割手元で用意するもの残す記録
着手総務・労務の担当該当日を確認した通知、提出先の案内起算の根拠、締切、社内の予定
作成書類を作る担当使用する用紙、転記元の情報記入済みの控え、未記入の理由
承認事業主・内容確認の担当申出の内容、負担についての確認事項確認した事項、判断を保留した点
提出発送・持参の担当提出物、宛先、問い合わせ先提出方法、提出した日、送付の控え
引継ぎ日常の事務を扱う担当提出済みの控え、窓口とのやり取り回答内容、担当者、次に処理する事項

発送した控えと、受け付けられたことの確認は、記録の欄を分けます。 担当者の記憶だけで処理状況を埋めず、窓口から回答があれば、その内容を保存するとよいです。 照会の際は、質問した内容、回答の対象になった書類、社内で対応する人をまとめて残します。 返事を受け取った担当者が不在でも、後任が同じ疑問を最初から調べ直さずに済む形を目指します。

書類づくりに手間がかかっている箇所は、転記元を探す作業、内容を確認する作業、提出後の記録に分けて見直せます。 事務の手間を洗い出すなら、事務作業の棚卸しで、担当と手元の資料を整理するとよいです。

公開・共有の前に、この表で確かめます。

確認確かめること
□対象に該当すると確認した内容と、その根拠の通知を整理したか
□起算に用いる日、締切、社内で提出を進める予定を区別したか
□用紙の選択欄、転記した情報、記入不要の欄を照合したか
□手元で確認する資料と、提出する書類を分けたか
□送付・持参する先と、相談する先を確認したか
□負担について事業主と確認し、判断が必要な点は専門家に確認したか
□提出物の控え、受付についての回答、次の担当者への引継ぎを記録したか
