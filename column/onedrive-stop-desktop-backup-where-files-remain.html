OneDriveでデスクトップのバックアップを停止したら、ファイルはどこに残る？

要点

Windows 版の OneDrive では、［同期とバックアップ］タブの［バックアップの管理］で、止めたいフォルダーのトグルをオフにするとバックアップが止まります。 そのとき、ファイルを OneDrive にだけ残してコンピューターからは消すか、自分の PC にだけ残して OneDrive からは消すかを選びます。 「止めたらデスクトップのファイルはどこへ行ったのか」の答えは、この選択で決まります。OneDrive 側を選んだならエクスプローラーの OneDrive か OneDrive の Web サイトを、PC 側を選んだならパソコンのデスクトップを見ます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

デスクトップに置いていた資料が、OneDrive の設定を変えた次の日から見当たらない。バックアップを止めるときに選ぶ残し先と、止めた後にファイルを探す場所を、Windows と Mac に分けて確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

パソコンを入れ替える場面と記入例は架空のもので、確認表も Microsoft の手順そのものではなく当社がまとめた目安です。

  1. デスクトップが急に空いたように見えるとき
  2. 止める操作と、出てくる2つの選択肢
  3. 「OneDrive にのみ」を選んだ後に探す場所
  4. 「自分の PC にのみ」を選んだ後に気をつけること
  5. 止めようとして「移動できない」と出たら

1．デスクトップが急に空いたように見えるとき

確認日：2026年11月17日。

対象は、Windows のパソコンで使う OneDrive 同期アプリです。Mac で止めた場合は、後の節で分けて書きます。

デスクトップに置いていた見積書のひな形や作りかけの資料が、朝パソコンを開いたら見当たらない。前の日に OneDrive の設定を触った覚えがある。こうした相談でまず思い出したいのは、バックアップを止めたときにどちらを選んだかです。

そもそもヘルプでは、デスクトップやドキュメントなどの標準フォルダーを OneDrive にバックアップすると、保護され、すべてのデバイスで利用できると説明されています。 デスクトップ フォルダーをバックアップしていると、デスクトップ上のアイテムは、OneDrive を実行しているほかのパソコンのデスクトップでも利用できます。 バックアップを止めると、この「どのパソコンでも同じデスクトップ」という状態が終わり、ファイルはどちらか一方にだけ残ります。

2．止める操作と、出てくる2つの選択肢

Windows 版での止め方は次の順です。

順番操作（Windows 版）
1通知領域で［OneDrive クラウド］アイコンを選び、［OneDrive のヘルプと設定］アイコン、［設定］の順に選ぶ
2［同期とバックアップ］タブに移動する
3［バックアップの管理］を選ぶ
4止めるフォルダー（デスクトップなど）のトグルを選んでオフにする
5ファイルを残す先を選ぶ

手順5で選ぶものを、ヘルプの説明をもとに並べると次のとおりです。

選ぶもの（ヘルプの説明）ファイルが残る所ファイルが消える所
ファイルを OneDrive にのみ保存し、コンピューターからは削除するOneDriveパソコンのデスクトップ
ファイルを自分の PC にのみ保存し、OneDrive から削除するパソコンのデスクトップOneDrive

どちらを選んでも、片方からはファイルが消えます。「止めるだけで、何も動かない」選択肢は、ヘルプの Windows の説明には出てきません。止める前に、どちらに残したいかを決めておくのが一番の備えです。

3．「OneDrive にのみ」を選んだ後に探す場所

パソコンのデスクトップからは消えていても、ファイルは OneDrive の側にあります。コンピューターで OneDrive 同期アプリにサインインしている場合は、エクスプローラーを使用して OneDrive にアクセスできます。

エクスプローラーで見つからないときは、OneDrive の Web サイトで探します。紛失したファイルの探し方のヘルプでは、ページ上部の［すべて検索］を使用してファイルを検索する、とされています。 検索で出てこなければ、Web サイトの左側にある［ごみ箱］も見ます。

会社のアカウントと個人のアカウントの両方を使っている人は、サインインしているアカウントも確かめます。ヘルプにも、削除したファイルが見つからない場合は、正しい Microsoft アカウントにログインしているかどうかをチェックする、と書かれています。

4．「自分の PC にのみ」を選んだ後に気をつけること

こちらを選ぶと、ファイルはパソコンのデスクトップに残り、OneDrive からは消えます。 ほかのパソコンや Web で同じデスクトップを見ていた人にとっては、見えていたファイルが無くなる形になります。そのパソコンが故障したときの備えも、OneDrive とは別に考える必要が出てきます。家と会社の2台で同じデスクトップを使っていた場合は、止める前にどちらのパソコンで作業を続けるかを決めておきます。

5．止めようとして「移動できない」と出たら

バックアップを止める操作は、ファイルをどちらかへ動かす操作でもあります。そのため、動かせないファイルがあるとエラーが表示されます。

出てくる場面ヘルプにある対処
クラウドのみのファイルが入っている状態を［このデバイス上で常に保持する］に変更してダウンロードしてから止める
開いているファイルがあるファイルを保存して閉じ、もう一度やり直す
OneNote のノートブックが入っているノートブックはクラウドベースのファイルで、コンピューターに移動できない

止める直前に、デスクトップで開いている資料をすべて閉じておくと、やり直しが減ります。

6．Mac で止めた場合は案内が違う

Mac 版のヘルプでは、［バックアップの停止］を選び、要求を確認する手順になっています。 止めると、OneDrive によって既にバックアップされているファイルは OneDrive フォルダーに残り、デバイス フォルダーには表示されなくなります。 止めたフォルダーには「個人用ファイルはどこにありますか」という名前のアイコンが出て、OneDrive 内のフォルダーへのショートカットになります。 また、止めた後にそのフォルダーへ追加した新しいファイルは、OneDrive にバックアップされません。

7．架空の例：パソコンを入れ替える前の確かめ

事務担当者のパソコンを新しくする前に、デスクトップのバックアップを止める場面を考えます（架空の例）。

確かめること架空の記入例
止めるフォルダーデスクトップだけ（ドキュメントは続ける）
選んだ残し先OneDrive にのみ保存
止める前に閉じたファイル請求書のひな形、作業中の名簿
止めた後の確認エクスプローラーの OneDrive で、請求書のひな形が開けた

パソコンの入れ替えや担当の交代のたびに、どの資料がどのパソコンとどのクラウドにあるかを一覧にしておくと、事務の道具と作業の棚卸しを進めるときの材料にもなります。

8．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□止めたいのはバックアップか（同期を少し止めたいだけなら、別の操作を探す）
□止める前に、デスクトップで開いている資料を保存して閉じたか
□クラウドのみのファイルがあれば、［このデバイス上で常に保持する］にしてダウンロードしたか
□残し先を「OneDrive にのみ」「自分の PC にのみ」のどちらにしたか、メモに残したか
□OneDrive 側を選んだ場合：エクスプローラーの OneDrive か Web サイトで開けることを確かめたか
□PC 側を選んだ場合：ほかのパソコンや Web で見ていた人に伝えたか
□Mac の場合：「個人用ファイルはどこにありますか」のアイコンから開けるか確かめたか
