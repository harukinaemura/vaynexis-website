消費税申告の付表はどこで探す？申告方式と対象期間に合う版の確認

要点

消費税申告の付表は、国税庁の「消費税及び地方消費税の申告書・添付書類等」から取得できます。専門家が指定した申告方式を起点に、対象期間の区分と必要な書類を照合し、取得元を記録して一式をそろえます。

公開：2026年11月8日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、専門家から申告方式と必要書類の指定を受けた小さな会社の事務担当者が、課税期間の開始日・終了日と付表の番号を照合して取得する順序をまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 付表の説明から様式の配布先へ進む
  2. 対象期間は終了日と開始日を分けて見る
  3. 付表は番号と正式名称を組にして照合する
  4. 取得から受渡しまでを同じ一覧で管理する
  5. 判断が要る組合せは取得前に確認する
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．付表の説明から様式の配布先へ進む

確認日：2026年11月6日。

消費税の確定申告書には、課税期間中の資産の譲渡等の対価の額や課税仕入れ等の税額等に関する明細である付表等を添付する必要があります。国税庁のタックスアンサー番号6615は、「確定申告書等に添付することとなる書類」を案内しています。

配布ページには、申告書や添付書類の様式のほか、申告書の作成に便利な各種計算表の様式も掲載されています。必要な書類の指定を受けてから取得すると、名称が似たファイルとの取り違えを防ぎやすくなります。

この記事は、通常の申告に使う書類の取得と受渡しを扱います。申告方式の選択、適用の可否、税額の判断は専門家に確認し、担当者は指定された書類をそろえる役割に絞ります。過去に保存したファイルをそのまま使う前に、配布先の区分と今回の指示を照合するとよいです。

2．対象期間は終了日と開始日を分けて見る

配布ページは、令和５年10月1日以後に終了する課税期間分の様式等を掲載し、それより前に終了する課税期間分は別のリンク先へ案内しています。

一般用・簡易課税用の申告書第一表と第二表には、「令和８年９月30日以前に開始した課税期間用」の掲載欄があります。別に「令和８年10月１日以後に開始する課税期間用」の掲載欄もあります。このように、入口の案内と個々の掲載欄では、日付の見方が異なります。提出する日や保存した日だけで選ばず、対象期間の始まりと終わりを手元に置いて照合します。

専門家への依頼には、対象期間を省略せずに書きます。ファイル名に年だけが付いている場合も、それだけで使用する版を決めず、どの区分から取得したかを記録するとよいです。申告書と付表を別々に受け取ったときは、同じ対象期間の組合せとして確認されたものかを合わせます。

3．付表は番号と正式名称を組にして照合する

タックスアンサー番号6615の提出書類等の一覧は、標準税率7．8％または軽減税率6．24％が適用された取引のみの場合を対象としています。以下は、その一覧にある主な付表です。必要書類の全体はリンク先の「提出書類等」の一覧で確認し、用意する範囲を専門家と合わせます。

一般用の主な付表には、「税率別消費税額計算表 兼 地方消費税の課税標準となる消費税額計算表」（付表1－3）があります。「課税売上割合・控除対象仕入税額等の計算表」は付表2－3です。

簡易課税用の主な付表では、「税率別消費税額計算表 兼 地方消費税の課税標準となる消費税額計算表」は付表4－3です。「控除対象仕入税額等の計算表」は付表5－3です。

名称が似ていても、番号まで照合します。依頼文に略称しか書かれていなければ、取得前に正式名称と組合せを確認すると、準備を進めやすくなります。

一般用・簡易課税用の配布欄では、申告書第一表と併せて第二表の提出が必要とされています。付表だけを取得して準備を終えず、専門家が指定した書類全体と照合します。

4．取得から受渡しまでを同じ一覧で管理する

ここからは当社の整理です。

取得作業は、指示を受ける人、保存する人、照合する人の役割をそろえて進めます。兼務する場合も、取得した段階と内容の確認が済んだ段階を分けて記録すると、未確認のファイルが完成分に混ざりにくくなります。

担当する人着手するタイミング用意するもの記録に残すこと
依頼を受ける担当者取得前専門家からの書類の指定と対象期間指示者、受渡し期限、不明点
取得する担当者指定を受けた後配布先と指定された書類の一覧取得元、取得日、保存場所
照合する担当者ファイルを開いた後指定内容と取得したファイル名称の一致、期間の表示、確認を待つ箇所
取りまとめる担当者専門家へ渡す前確認済みの一式と不足分の一覧渡した相手、渡した範囲、回答待ちの内容

保存時は配布されたファイルを残し、社内で使う名前との対応を一覧に持たせます。説明書が別にあるときも、どの書類に対応するものかを同じ行から追える状態にします。古い控えと今回の取得分は保存場所を分けると、照合の途中で取り違えにくくなります。

表示されている対象期間や書類名が指示と合わないときは、担当者が内容を書き換えて合わせず、相違箇所を専門家へ伝えます。差し替えを受けた場合は、受け取った相手と変更理由を残し、渡す一式に旧版が混ざっていないかを見直します。

5．判断が要る組合せは取得前に確認する

配布ページでは、旧税率（3％、4％又は6.3％）が適用された取引がある場合、一般用の付表1－3に代えて付表1－1及び付表1－2を使用するよう案内されています。こうした分岐への該当性や、ほかに必要な組合せは専門家に確認します。担当者は、指定と異なる表示を見つけた箇所を伝え、回答を受けてから一式を整えます。

国税に関する相談は、各国税局に設置する「電話相談センター」で国税局の職員等が対応しています。相談時には、探している書類の名称、対象期間、配布先の表示、専門家からの指定をまとめておくと、どこで迷っているかを説明しやすくなります。

書類を取得できたことと、提出する内容の確認が済んだことは分けて扱います。専門家へ渡す際は、そろった書類だけでなく、不足しているものと回答を待っている点も添えるとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□専門家が指定した申告方式と必要な書類を記録したか
□対象期間の開始日と終了日を確認したか
□配布先の対象期間の区分と指定内容を照合したか
□各書類の番号と正式名称を照合したか
□指定された一式の不足分と確認先を整理したか
□取得元、取得日、保存場所、受渡し先を記録したか
