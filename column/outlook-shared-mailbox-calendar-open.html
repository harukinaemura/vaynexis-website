Outlookで部署の共有メールボックスの予定表を開く手順

要点

新しいOutlookでは、予定表ビューで部署の共有メールボックスを選ぶと、その予定表を開けます。開く前に利用者の登録を管理者に確認し、予定を入力するときは部署用の登録先を見直すとよいです。開けたことと、意図した場所へ登録できたことを分けて確かめます。

公開：2026年11月5日／情報の確認日：2026年11月5日（出典はこの記事の最後）

この記事は、部署の共有メールボックスの予定表を新しいOutlookで開きたい小さな会社の事務担当者が、版の見分け方と利用者の登録、予定表の開き方、登録先の見直しと引き継ぎを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月5日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 操作の前に画面の種類と利用者の登録を確認する
  2. 再起動後に部署用の予定表を開く
  3. 共有メールボックスが表示されないときは追加の操作を分ける
  4. 登録先は入力前と入力後に見直す
  5. 引き継ぎには開き方と確認結果を残す
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．操作の前に画面の種類と利用者の登録を確認する

確認日：2026年11月5日

この手順は、Windows版の新しいOutlookを対象にしています。Windows版で右上隅に［設定］ボタンがある場合は、新しいOutlookです。共有メールボックスのヘルプは、使っている Outlook のバージョンに応じて［新しい Outlook］［クラシック Outlook］［Outlook on the web］のタブを選ぶ形です。新しい Outlook のタブの手順が機能しない場合は、新しい Outlook for Windows をまだ使っていない可能性があるため、従来の Outlook のタブの手順に従うよう案内されています。この記事は、新しい Outlook のタブの手順だけを扱います。画面の種類を先にそろえておくと、引き継ぎ相手が異なる操作説明をたどるのを避けやすくなります。

共有メールボックスを使い始めるには、IT管理者によるメンバーへの追加が必要です。名前が分からないときは、部署で使っている表示名と、利用者として登録されているかを管理者に尋ねるとよいです。似た名前が並ぶ職場では、引き継ぎ用の記録にも正式な名前を残しておきます。

2．再起動後に部署用の予定表を開く

管理者によるメンバーへの追加後、新しいOutlookを閉じて再起動すると、共有メールボックスに関連付けられた予定表が［予定表］一覧に自動的に追加されます。予定表ビューに移動し、部署の共有メールボックスを選択します。操作の区切りは、アプリを開き直すところと、表示する対象を選ぶところです。メールを読める状態になっただけで作業を終えず、予定を表示する画面まで進めます。

共有メールボックスの予定表に入力した予定は、メンバー全員が表示できます。登録する内容は、関係者と共有する目的に合う範囲に整えるとよいです。自分だけが見るつもりの覚え書きと、部署で共有する予定を、入力前に整理しておきます。

3．共有メールボックスが表示されないときは追加の操作を分ける

公式ヘルプでは、メンバーに追加された後に新しいOutlookを再起動すると、共有メールボックスはフォルダーウィンドウに自動的に表示されるはずだと説明されています。表示されないときは、管理者が追加してから表示されるまでに数分かかることがあるため、しばらく待ってから新しいOutlookを閉じて再起動するか、共有メールボックスを手動で追加するよう案内されています。

手動で追加するときは、ナビゲーションウィンドウで［メール］を選び、フォルダーウィンドウでアカウント名を右クリックして［共有フォルダーまたはメールボックスの追加］を選びます。続いて、開いたウィンドウにアクセスする共有メールボックスの名前を入力します。

ここで行っているのは、利用する対象の追加です。追加する名前が曖昧なまま似た候補を選ばず、管理者から案内された名前と突き合わせるとよいです。手動で追加した後に予定表の一覧へ表示されるかどうかは、公式ヘルプのこの手順には書かれていません。操作後は予定表ビューで表示を確かめ、見当たらなければ管理者に相談します。

引き継ぎの記録では、通常の開き方と、表示されないときの対応を分けておきます。手動追加から毎回始める説明にすると、すでに表示されている人にも準備の操作を繰り返させることになります。どこまで進んだかを残すと、管理者にも状況を伝えやすくなります。

4．登録先は入力前と入力後に見直す

ここからは当社の整理です。

部署で使う予定は、内容が正しくても、保存先を取り違えると関係者が見つけにくくなります。入力前に選んだ場所と、登録後に予定が残った場所を見比べるとよいです。件名だけで判断せず、所属する予定の一覧も確かめます。

場面見るところ確認の目安
部署内の書類整理の予定を入力する前選択している登録先の名前個人用と部署用を取り違えていない
入力を終えた後部署用の登録先に残った予定件名と時間が意図した内容になっている
引き継ぎ相手と確認するとき相手が開いている登録先の名前同じ対象を見ていることを確認できる

表の内容は、操作を点検するための例です。入力後に見当たらないときは、すぐ同じ内容を追加せず、選択した登録先と、表示している日付を確かめます。重複を避けるため、すでに登録した内容を見つけてから、修正の要否を判断するとよいです。

予定の内容を変える担当者も決めておくと、引き継ぎ後の連絡先が明確になります。変更を依頼する相手と、画面の利用について相談する相手を区別し、操作の相談だけで予定そのものを変更しないようにします。

5．引き継ぎには開き方と確認結果を残す

記録に残すのは、画面の種類、部署用の登録先の名前、通常の開き方、表示されないときの相談先です。画面の画像だけに頼らず、何を選ぶのかを短い言葉でも補っておくと、表示が少し違う場面でも対象を探しやすくなります。

確認結果は、開けたことだけで終えず、部署用の登録先に予定があるところまで見たと分かる形で残します。次の担当者が、準備の途中なのか、登録後の点検まで終わっているのかを読み取れることが大切です。

利用者の登録は管理者へ、予定の内容は業務の担当者へ、というように確認先を記録しておくとよいです。解決していない点は、誰に何を尋ねているかまで添えます。これにより、後任者が同じ確認を最初から繰り返す場面を減らしやすくなります。
