Wordの社内配布資料にページ全体を囲む罫線を付ける手順と確認

要点

Word でページ全体を囲む罫線は、［デザイン］＞［ページの境界線］に移動し、罫線の外観を選んで付けます。ページ罫線は個々のページではなくセクションごとに付くので、途中のページだけを囲むときは、そのページを独自のセクションに分けます。印刷で線が欠けるときは、プリンターの最小余白と、罫線の位置を測る基準の設定を見ます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Word の社内配布資料の紙面を罫線で囲みたい小さな会社の担当者が、罫線の付け方と、セクションごとの適用範囲、印刷で線が欠けるときの見方を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 使う版と罫線を付ける範囲を決める
  2. 線の外観とページ端からの距離を整える
  3. 途中のページを囲むときは区切りを確認する
  4. 社内配布の見本と引き継ぎ事項をそろえる
  5. 印刷前に全体を見て、欠ける線の位置を調べる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．使う版と罫線を付ける範囲を決める

確認日：2026年11月11日

Microsoft サポートの「ページに罫線を追加する」は、適用先に Word for Microsoft 365、Word for Microsoft 365 for Mac、Word 2024、Word 2024 for Mac、Word 2021、Word 2021 for Mac、Word 2019、Word 2016 を挙げ、手順を Windows・macOS・Web に分けています。また「セクション区切りを挿入する」は、Web の Word ではセクション区切りはまだ追加できないとし、Word デスクトップ アプリで［Word で開く］から文書を開いて追加する方法を案内しています。

ページ罫線の適用単位はセクションです。線を付けたい場所を、資料の全体、表紙、途中の案内部分など、内容のまとまりで決めておくと操作を追いやすくなります。配布対象に含まれる本文や添付資料まで読み、囲む範囲の始まりと終わりを確認します。

作業用の複製を用意し、変更前の見本も手元に置きます。引き継がれた書式を使う場合は、既存の線の有無を見てから編集に入ります。線を追加する目的を「配布する案内の範囲を示す」のように短く決めておけば、後から直す担当者も仕上がりを判断しやすくなります。

2．線の外観とページ端からの距離を整える

Windows 向けの手順では、［デザイン］＞［ページの境界線］に移動し、罫線の外観を選択します。macOS 向けの手順では、［線種とページ罫線と網かけの設定］ボックスで、左側の［設定］から罫線のスタイルを選び、［スタイル］［色］［幅］を選択します。同じ手順は、プレビュー ボックスで罫線のスタイルを確認し、一方の辺から罫線を削除するには［プレビュー］ボックスでその行を選択するとしています。紙面全体を囲む用途では、上下左右の線がそろった状態を目標にします。設定した後は、線が付いたかに加え、本文が枠の内側で読みやすいか、見出しや末尾の注意書きとの間隔にも目を向けます。

Windows 向けの手順では、罫線とページ端との距離は［オプション］で調整し、変更後に［OK］で確定します。紙面の端に近い所で線が窮屈に見えるときは、周囲の空き方を見ながら整えます。文字に接する所だけを眺めず、上端から下端まで通して確認します。

設定画面を閉じた後は、本文が長い所や末尾の注意書きまで見直します。線と文字が近すぎる箇所を見つけたら、その位置を作業用の見本に残します。

3．途中のページを囲むときは区切りを確認する

Microsoft サポートは、罫線を追加するページが文書の中央にある場合は、最初にセクション区切りを追加する必要があるとしています。対象の前後で線の有無を変えたいときは、どこからどこまでを囲むかを書き出してから作業に入ります。

書式を変更する範囲の先頭にはセクション区切りを挿入し、書式を再び変更する位置には別のセクション区切りを入れます。Windows版では、新しいセクションの開始位置を選び、［レイアウト］から区切りの種類を選択します。次のページで始める種類のセクション区切りは、新しいページからセクションを開始します。

区切りを入れた後は、囲む部分に加えて、その直前と直後も見比べます。想定より広く線が付いていたら、対象範囲の始まりと終わりに立ち返って確認します。線の形を何度も変える前に、付けたい場所と実際に付いた場所の違いを整理しておきます。書式を受け継いだ資料では、変更した箇所が分かるよう、作業用の見本に確認結果を残します。

Mac版で表紙だけに付ける設定

macOS 向けの手順では、［適用先］の右側にある矢印を選択して［このセクション - 最初のページのみ］を選択し、この設定は文書の最初のページに罫線を追加する場合にも機能するとしています。表紙だけを囲む目的では、本文の始まりにも目を通し、意図した区別が付いているかを確認します。

4．社内配布の見本と引き継ぎ事項をそろえる

ここからは当社の整理です。

配布資料の仕上げでは、囲む対象、周囲との間隔、紙で見た結果を同じ担当者が続けて確認すると判断をそろえやすくなります。途中で担当が変わる場合は、どの部分を確認済みとしたかを記録して渡します。

配布するものの例囲む範囲として決めておくこと見本で確かめる点
社内の掲示案内案内本文を載せた紙面全体周囲の線のつながりと本文の読みやすさ
説明会の配布資料表紙として使う部分本文側に意図しない線が付いていないか
手続き案内を挟んだ資料手続き案内の始まりから終わりまで前後の説明部分との境目

引き継ぎには、完成ファイルの場所、囲む対象、確認に使った出力先、残っている調整箇所をまとめます。「見た目を整えた」とだけ記すと、受け取った側がどこまで確かめたのかを読み取れません。確認済みの紙面と、調整が必要な箇所を対応させて残します。

校正で本文を追加した後も、配布直前の見本を確認対象にします。前の版の紙と取り違えないよう、配布するファイルと見比べる紙をそろえておきます。確認を依頼する際は、線の有無、囲む対象、紙での欠けのどこを見てほしいかを伝えると、確認する人も作業の範囲を把握できます。

5．印刷前に全体を見て、欠ける線の位置を調べる

Microsoft サポートの「印刷と印刷プレビュー」では、プリンターに送信する前に印刷ジョブがどのように表示されるかを確認するには、［ファイル］＞［印刷］に移動するとしています。Word の節では、各ページを表示するには、プレビューの下部にある矢印をクリックするとしています。囲む対象の始まりから終わりまで順に送り、前後の紙面も含めて線の有無を見比べます。全体を見た後は、本文が枠に近い所や、線の端が欠けて見える所を重点的に確かめます。

Microsoft サポートの「ページ罫線が印刷されないのはなぜですか?」は、罫線が印刷されない通常の理由はプリンターの最小余白設定としています。このページの適用先は Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016 で、Mac は挙げられていません。同じページでは、罫線の位置を調べるときは、［デザイン］から罫線設定の［オプション］を開き、［測定元］で［ページのエッジ］が選ばれているかを確認します。実際に配布に使う出力先で見本を取り、上側、下側、左右のどこが欠けているのかを記録します。調整する前に欠けた位置を押さえると、変更後の紙と同じ場所を見比べられます。

同じページは、印刷時に罫線がまだ表示されない場合は、余白を調整して、罫線と文書のページの端との間にスペースを広げるとし、［レイアウト］の余白から［カスタム余白］を選択する手順を挙げています。最小余白の情報は、使用するプリンターの製造元のサポートサイトで確認する案内です。間隔を変えた後は、線の欠けに加えて本文の読みやすさも見直します。配布用として残す見本には、最終的に使用する出力先で確認した紙をそろえておきます。

公開・共有の前に、この表で確かめます。

確認確かめること
□線を付けたい範囲の始まりと終わりを確認したか

□本文や見出しと線との間隔を確認したか
