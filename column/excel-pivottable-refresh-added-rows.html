Excelで明細を追加してもピボットテーブルの数字が変わらないときは

要点

ピボットテーブルは、キャッシュと呼ばれるデータのスナップショットで動いています。明細に行を足したら、そのデータ ソースで作ったピボットテーブルは更新が必要です。 更新しても変わらないときは、追加した行が元の範囲の外にないかを［データ ソースの変更］で確かめます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

明細シートに今月分を書き足したのに、ピボットテーブルの総計が先月のまま。［更新］で直るときと、元の範囲を広げないと直らないときの見分け方をまとめました。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 「合計が合わない」と言われたら
  2. 1つだけ更新する・全部まとめて更新する
  3. 追加した行が、元の範囲の外にあるとき
  4. 次の月から範囲の外に出ないようにする
  5. 開いたときの更新と、自動更新の扱い
  6. 月次の締めでの確かめ方（架空の例）
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．「合計が合わない」と言われたら

確認日：2026年11月17日。

対象は Windows 版の Excel です。Web 版・Mac 版はメニューの名前や場所が違う所があります。

月末に明細シートへ数行を書き足し、別シートのピボットテーブルを報告に貼る流れでは、「明細の合計とピボットの総計が合わない」という声が出やすくなります。原因はおおむね2つに分かれます。

状態起きていること打つ手
更新していない前のスナップショットのまま［更新］を選ぶ
更新しても変わらない追加した行が元の範囲に入っていない［データ ソースの変更］で範囲を確かめる

1つ目は、明細を書き足しただけで、ピボットテーブルの側では何もしていない状態です。ピボットテーブルは前に読み込んだ時点の写しで集計しているので、明細を足しても自動では追いつきません。2つ目は、更新はしたのに、ピボットテーブルが見に行く範囲の外に新しい行がある状態です。先に1つ目を試し、それでも総計が変わらなければ2つ目を疑う、という順にすると、確かめる所が少なくて済みます。

2．1つだけ更新する・全部まとめて更新する

ピボットテーブルを選ぶと［ピボットテーブルの分析］タブが出ます。［データ］グループの［更新］を選ぶか、Alt＋F5 キーを押します。右クリックして［更新］を選ぶこともできます。部門別・月別など複数のピボットテーブルがあるときは、［更新］の矢印から［すべて更新］を選ぶと、ブックの中を一度に更新できます。時間がかかるときは［更新状態］で様子を見て、［更新のキャンセル］で止められます。

1つだけ直して報告に貼り、ほかのシートは古いまま、ということを防ぐため、月次の締めでは［すべて更新］を決まりにしておくと迷いません。

明細が同じブックのシートではなく、Power Query で取り込んだデータベースなどのデータでも、ピボットテーブルのデータは同じように更新できます。 取り込み元のデータがいつ時点のものかは、取り込みを作った担当者に確かめておきます。

3．追加した行が、元の範囲の外にあるとき

明細をただのセル範囲のまま使い、ピボットテーブルを作ったときに「A1 から F200 まで」と範囲を決めていると、201行目より下に足した明細は、更新しても集計に入りません。

ピボットテーブルは、作った後でもソース データの範囲を変えられ、範囲を広げて対象のデータを増やせます。手順は、ピボットテーブルを選び、［分析］タブの［データ］グループで［データ ソースの変更］を選ぶと、［ピボットテーブルのデータ ソースの変更］ダイアログ ボックスが出ます。［テーブルまたは範囲の選択］を選び、［テーブル/範囲］のボックスで範囲を確かめます。列が増えたり減ったりするなど、ソース データが大きく変わる場合は、新しいピボットテーブルを作ることを考えるよう書かれています。

タブの名前は、更新のヘルプでは［ピボットテーブルの分析］と書かれています。

なお、ピボットテーブルがブックのデータ モデルに基づく場合は、データ ソースを変えられないと書かれています。 範囲を広げたら、もう一度［更新］を選び、明細の金額の合計とピボットテーブルの総計が合うかを確かめてから報告に使います。

4．次の月から範囲の外に出ないようにする

毎月、範囲を広げ直すのは手間で、忘れる人も出ます。ヘルプでは、Excel の表（テーブル）はピボットテーブルのよいデータ ソースで、データの更新時に、テーブルに追加された行は自動的にピボットテーブルに含まれると説明されています。データは1つのヘッダー行がある列にまとめ、空の行や列がないようにし、同じ列に日付とテキストを混ぜないことも求められています。

途中に空の行を入れて月の区切りにしている明細は、テーブルにする前に直しておきます。

5．開いたときの更新と、自動更新の扱い

［オプション］の［データ］タブで［ファイルを開くときにデータを更新する］をオンにすると、ブックを開いたときに更新されます。

新しいバージョンの Excel では、ローカルのブックのデータにつながったピボットテーブルが自動的に更新されます。ただし、この自動更新は現在、Microsoft 365 Insider プログラムの参加者が使える機能と書かれています。また、自動更新はデータ ソースごとに設定され、切り替えると、そのデータ ソースにつながるすべてのピボットテーブルに影響します。

また、ブックに自動更新がオフの既存のピボットテーブルがあると、同じソース データを使う新しいピボットテーブルでも自動更新はオフになります。 社内のパソコンで同じ動きになるとは限らないので、手順書には［更新］を押す手順を残しておきます。

更新のたびに列幅や書式が変わって困るときは、［オプション］の［レイアウトと書式］タブにある［更新時に列幅を自動調整する］と［更新時にセル書式を保持する］の欄を確かめます。

6．月次の締めでの確かめ方（架空の例）

集計を作る人と報告を受け取る人が別のときは、次のように役割を分けておくと、どこで数字がずれたかを後から追えます。

いつ誰が何と照らすか
明細を足した直後入力した担当者明細の行数と、追加した件数
更新した後集計を作る担当者明細の金額の合計と、ピボットテーブルの総計
報告に貼る前確認者前の月の総計からの増え方が、追加分と合うか

入力した担当者は、何件足したかを集計の担当者に伝えます。集計の担当者は［すべて更新］の後、明細の金額の合計とピボットテーブルの総計を並べて見ます。確認者は、前の月からの増え方が、足した明細の金額と合うかだけを見ます。3人が同じ数字を別の方向から見ることで、更新の漏れと範囲の外の行のどちらも見つけやすくなります。

月次の報告をどんな形で残すかを考えるときは、棚卸しレポートの見本の並べ方も手がかりになります。

公開・共有の前に、この表で確かめます。

確認確かめること
□明細に行を足した後、［更新］または［すべて更新］を選んだか
□変わらないとき、［データ ソースの変更］で［テーブル/範囲］を確かめたか
□明細をテーブルにして、足した行が自動で含まれるようにしたか
□空の行・空の列や、日付と文字の混ざった列がないか
□自動更新の切り替えが、同じデータ ソースのほかの集計にも及ぶと知っているか
□明細の合計とピボットテーブルの総計を照らしてから報告に貼ったか
