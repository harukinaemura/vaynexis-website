新しいOutlookで会議の間に移動時間を取る｜予定の短縮をアカウントごとに設定

要点

新しいOutlookでは、予定を数分早く終えるか遅く始める設定ができます。予定を作るメールアカウントを選び、1時間未満と1時間以上の分数を分けて保存します。設定後は、招待を送る前に予定の開始時刻と終了時刻を確かめます。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、Outlookで会議と会議の間に移動や準備の時間を取りたい小さな会社の担当者が、予定を自動で短くする設定の場所、アカウントごとの設定、長さ別の分数と招待前の時刻を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 新規予定の前後に余裕を取る方法を選ぶ
  2. 使うOutlookとメールアカウントを確認する

1．新規予定の前後に余裕を取る方法を選ぶ

確認日：2026年11月10日。

Microsoftの案内「すべてのイベントを自動的に短くする」では、Outlookでイベントを数分早く終了させたり、数分遅れて開始したりできます。イベント間の移動時間を作ったり、ほかのイベントが少し長引いたときの余裕を加えたりするための機能と説明されています。

この案内の適用先は、Outlook for Microsoft 365、Outlook 2024、Outlook 2021、Outlook 2019、新しい Outlook for Windows、Outlook on the web for Exchange Server 2019 です。ページは［新しい Outlook］［クラシック Outlook］［Outlook on Web］の欄に分かれ、設定への入り方が欄ごとに違います。Outlook for Mac の手順は別のページで案内されています。この機能はメール アカウントごとに設定され、アカウントが複数ある場合は、それぞれで開始時刻と終了時刻の設定をするよう書かれています。

「新しい Outlook と従来の Outlook の機能の比較」（最終更新日 2026年9月23日）の表では、［短縮された会議 (Outlook の設定とサービス設定)］が、クラシック Outlook と新しい Outlook の両方で［使用可能］と示されています。

ここからは当社の整理です。

会議後に別の部屋へ移る時間を取りたいのか、会議前に参加の準備時間を取りたいのかを決めます。前者なら終わりを早める方向、後者なら始まりを遅らせる方向を検討します。予定そのものの開始・終了を変える設定なので、必要な会議時間が確保できるかも確認します。

2．使うOutlookとメールアカウントを確認する

会社用と別用途のアカウントが同じOutlookにある場合は、予定を作るアカウントを確認します。普段の予定表を開いているだけでは、設定したアカウントと新しい会議の開催者が一致するとは限りません。設定を保存する前に、対象のアカウントが画面で確認できることを確かめます。

Microsoftの案内の新しい Outlook の欄では、［設定］から予定表の設定（ページの表記は［Calendar］）を開き、［イベントと招待］を選びます。その中の［すべてのイベントの期間を短縮する］チェック ボックスをオンにします。Outlook on Web の欄も同じ順で、どちらの欄にも、イベントを早期終了または遅延開始に設定できると書かれています。

3．1時間未満と1時間以上の設定を分ける

Microsoftの案内では、ドロップダウンで1時間未満と1時間以上のイベントの分数を選び、［保存］をクリックします。新しい Outlook の欄の手順には、早期終了と遅延開始を選ぶ欄の名前までは書かれていないため、画面で選択肢を確かめます。区分の表記は「1 時間未満」と「1 時間以上」で、1時間ちょうどの予定がどちらの分数になるかは、確認用の予定で確かめます。

Microsoftの案内のクラシック Outlook の欄では、［ファイル］＞［オプション］＞［Calendar］＞［Calendar オプション］を選び（ページの表記のまま）、［予定と会議の短縮］チェック ボックスをオンにして、ドロップダウン ボックスで［早期終了］か［遅刻開始］を選びます。続けて1時間未満と1時間以上の分数を選び、［OK］をクリックします。同じページの注記では、Outlook Desktop の最新の月次エンタープライズ チャネル ビルドを実行している必要があるとされています。

同じページのクラシック Outlook と Outlook on Web の欄には、設定すると、この設定が Outlook for Windows、Outlook for Mac、Outlook on the web、Outlook for iOS、Outlook for Android で適用されると書かれています。

分数を決めるときは、移動や準備に必要な時間と、会議に使える時間の両方を確認します。短い打合せと長い会議で必要な余裕が違う場合は、両方を同じ分数にする前に、よく使う予定の長さを確認します。

4．招待を出す前に表示される時刻を確かめる

設定したメールアカウントの予定表で、参加者を追加しない確認用の予定を開きます。1時間未満と1時間以上の両方で、選んだ方向と分数が予定の開始・終了に表れるかを見ます。特に1時間ちょうどの予定は、どちらの分数が反映されるかを確かめます。

想定した時刻にならなければ、予定を作成したメールアカウント、設定を保存したか、使用しているOutlookの版（クラシック Outlook ではビルド）の順に確認します。実際の会議では、招待前に時刻と必要な会議時間を読み直します。定期会議の変更を担当する人は、既に送った招待への連絡を別に管理します。

5．予定担当へ設定と確認方法を引き継ぐ

引き継ぐときは、設定したアカウント、早く終えるか遅く始めるか、長さ別の分数、試した予定で表示された時刻を残します。アカウントやアプリが変わった場合は、新しく作る予定で確かめ直します。

個別の会議で指定時間を優先するときは、予定の画面で実際の開始・終了を確かめます。変更により次の会議と重なりそうなら、招待を送る前に開催者側で調整します。
