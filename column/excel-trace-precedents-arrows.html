Excelの集計式が使う入力セルを矢印でたどる確認手順

要点

集計式が使う入力セルは、結果のセルを選び、［数式］タブの［数式監査］グループにある［参照元のトレース］をクリックし、トレース矢印でたどります。矢印でつながりを確かめた後は、計算の材料になった欄と、集計したかった欄の意味を見比べます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Excelの集計結果がどの入力セルを使っているかを確かめたい小さな会社の担当者が、［参照元のトレース］の矢印の表示・別のシートへの移動・たどれない参照・矢印の削除を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 最初に、結果から調べるか入力から調べるかを分ける
  2. 結果セルを選び、直接の参照元からたどる
  3. 小さな表で、欄の役割と確認する向きを合わせる
  4. 別のシートへ進むときと、矢印でたどれないとき
  5. 確認内容を残してから、矢印を片づける
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．最初に、結果から調べるか入力から調べるかを分ける

確認日：2026年11月11日

Microsoft の「数式とセルの関係を表示する」の適用先は、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 です。Mac 版と Web 版はこの一覧にありません。

同じページの説明では、参照元は別のセルの数式により参照されているセル、参照先は他のセルを参照する数式が含まれているセルです。たとえばセル D10 に数式「=B5」があれば、B5 は D10 の参照元セル、D10 は B5 の参照先セルになります。結果の材料を探したいのか、入力を変更したときに関係する結果欄を整理したいのかで、調べる出発点を分けます。

合計が想定と違って見える場面では、最初に何を含める集計なのかを言葉にします。対象の部署や項目、集計に含めない欄など、表を作った目的と照らして確認します。つながりを見つける作業と、そのつながりが業務の目的に合うかを判断する作業は分けて考えます。

調べ始める前に、対象のファイルとシート、確認したい結果欄を控えておきます。

2．結果セルを選び、直接の参照元からたどる

操作は、参照元を調べたいセルを選ぶところから始めます。結果欄の見出しや近くの空欄ではなく、調べたい式が入った場所を出発点にする、という考え方です。

矢印を表示する前の準備として、同じページは、［ファイル］の［オプション］から［詳細設定］を開き、［このブックの表示オプション］でブックを選んで、［オブジェクトの場合、表示］で［すべて］が選択されていることを確かめる手順を挙げています。そのうえで、［数式］タブの［数式監査］グループで［参照元のトレース］をクリックすると、選んだセルに直接データを提供する各セルにトレース矢印が表示されます。同じページの中でも、このグループは［数式監査］と［ワークシート分析］の2つの名前で書かれています。

矢印が出たら、画面全体の矢印を一度に読み切ろうとせず、まず出発点と結び付いた欄の見出しを見比べます。数量を使うつもりだったのに備考欄を含めていないかなど、表の担当者が説明できる意味に置き換えます。

さらに前段の計算にさかのぼるときは、［参照元のトレース］を再度クリックすると、次のレベルのセルを特定できます。矢印で示されたセルを選ぶには、その矢印をダブルクリックします。数式の引数に使っている参照元セルを色分けで見たいときは、セルを選んで F2 キーを押す方法も案内されています。

直接つながる欄を確かめたあと、途中の集計欄を見て終えるのか、入力担当者が値を置く欄まで戻るのかを決めます。見つかった場所は、結果欄との関係が分かる短い言葉で残します。

3．小さな表で、欄の役割と確認する向きを合わせる

ここからは当社の整理です。

たとえば、事務用の集計表を次のように整理します。値の大小よりも、入力と結果の関係を説明するための表です。

欄の役割セル・式の例確認する内容
入力欄B2、C2集計の材料にする項目か
結果欄D2、式は =B2+C2入力欄と式の対象が合っているか
引き継ぎメモ対象シート名と欄の見出しどの目的でその欄を集計するか

結果の根拠を説明したいときは、結果欄から材料へ戻る向きで整理します。一方、入力欄の担当を引き継ぐときは、その値がどの結果の材料になるかを説明すると、入力する意味が伝わります。同じ表でも、確認する問いが違えばメモの書き方も変わります。

引き継ぎでは、場所だけを並べるより、何を集計する欄か、どの入力を含めるか、対象外にするものは何かを添えます。式の対象に入っていることと、業務上含めたいことが一致しているかを、表の管理者と確かめるためです。不明な欄は勝手に対象外とせず、確認する相手と疑問を控えます。

4．別のシートへ進むときと、矢印でたどれないとき

Microsoft のヘルプは、別のブックで参照セルを指定するには、そのブックが開かれている必要があり、開いていないブック内のセルにはアクセスできないとしています。集計表のあるファイルだけを見て判断せず、関係するファイルの所在と管理者も整理しておきます。

同じページの手順では、参照元のセルがその他のワークシートやブックにある場合は、黒い矢印をダブルクリックして［ジャンプ］ダイアログ ボックスを表示し、［移動先］ボックスの一覧で目的のセルをダブルクリックします。

移動先では、シート名と欄の見出しを合わせて読みます。開けないファイルの中身を推測して式を直すのではなく、所在や開ける担当者を確かめるところで区切ります。

同じページは、青い矢印はエラーのないセル、赤い矢印はエラーの原因となっているセルを示すとしています。ただし、業務上含めたい欄を選べているかは、色とは別に照合します。

［参照元のトレース］をクリックして警告音が鳴る場合について、同じページは、Excel が数式のすべてのレベルをトレースしたか、追跡不可能なアイテムをトレースしようとしているとしています。監査ツールで追跡できないものとして挙げられているのは、ワークシートのテキスト ボックス・埋め込みグラフ・画像への参照、ピボットテーブル レポート、名前付き定数への参照、それに別のブック内にある数式で、他のブックが閉じているときにアクティブ セルを指しているものです。矢印が出ない欄は、こうした参照が式に含まれていないかを確かめます。

5．確認内容を残してから、矢印を片づける

同じページの手順では、ワークシートのすべてのトレース矢印を削除するには、［数式］タブの［ワークシート分析］グループで［矢印の削除］をクリックします。

また、矢印が指す数式の変更、列や行の挿入・削除、セルの削除・移動を行うと、すべてのトレース矢印が消えるとされています。変更後のつながりを見るには、トレース矢印を表示し直します。変更前のトレース矢印を記録しておく必要がある場合は、ワークシートを変更する前に、トレース矢印を表示してワークシートを印刷する方法が案内されています。

確認を終える前に、調べた出発点、材料になっていた欄、業務の目的と合っていた点、担当者へ確認が残る点をまとめます。確認済みとだけ書くより、何と何を照合したかを残すほうが、次の担当者が確認の範囲を判断しやすくなります。

修正が必要なときも、確認した内容と変更する内容を分けて記録します。集計対象を広げるのか、参照する場所を置き換えるのかで、表の管理者に相談する内容が変わるためです。自分だけで判断しにくい欄は、疑問が残っていることを明らかにして引き継ぎます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□調べたい結果欄と、集計の目的を対応させたか
□結果から材料へ戻る確認と、入力の利用先を見る確認を分けたか
□直接つながる欄と、その前段の入力欄を区別したか
□移動した先のシート名と、欄の見出しを見比べたか
□集計したい項目と、式が使っている項目を照合したか
□確認できた範囲と、担当者への質問を分けて残したか
□確認後に表を変更した場合、つながりを改めて確認したか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。
