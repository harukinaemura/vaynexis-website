Wordの両面資料で左右ページの見出しを別々に設定するには

要点

Microsoft サポートは、既定では Word のヘッダーおよびフッターはどのページでも同じとしています。左右のページで見出しを変えるには、ヘッダーの領域をダブルクリックして［奇数/偶数ページ別指定］を選択し、奇数ページと偶数ページのヘッダーをそれぞれ入力します。Web 用 Word では［オプション］の［異なる偶数ページ & 奇数ページ］を使います。表示したい文言と、紙で見たときの左右の位置を分けて確かめると、入力箇所の取り違えを見つけやすくなります。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Word の両面資料で左右のページに別々の見出しを出したい小さな会社の担当者が、奇数・偶数ページ別指定の手順と、先頭ページやセクションの引き継ぎ、印刷前の並びを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．デスクトップ版は奇数側と偶数側を分けて編集する

確認日：2026年11月11日。

Microsoft サポートの「奇数ページと偶数ページに異なるヘッダーまたはフッターを作成する」は、適用先に Word for Microsoft 365、Word for Microsoft 365 for Mac、Word 2024、Word 2024 for Mac、Word 2021、Word 2021 for Mac を挙げ、手順を Windows・Mac・Web に分けて書いています。利用している環境を先に確認し、該当する手順から進めます。

Windowsでの入力順

Windows 向けの手順では、まずヘッダーまたはフッターの領域をダブルクリックし、次に［奇数/偶数ページ別指定］を選択します。

奇数ページのいずれかで変更するヘッダー領域を選択して入力し、続いて偶数ページを選択して入力します。ヘルプの例では、奇数ページはタイトルを入力して Tab キーを 2 回押してから［ページ番号＞現在の位置］でスタイルを選び、偶数ページは先にページ番号を入れてからタイトルを入力する順です。入力を終えたら［ヘッダーとフッターを閉じる］を選択するか、Esc キーを押します。

編集前に、資料全体に共通させたい文言と、左右で変えたい文言を手元に書き出しておくと、入力中に内容を考え直す負担が少なくなります。文字を入れる作業と、余白を含む見た目の確認は区切って進めます。

2．MacとWebでは入口を取り違えない

Mac 向けの手順でも、ヘッダーまたはフッターの領域をダブルクリックして［奇数/偶数ページ別指定］を選択し、奇数ページと偶数ページで順に入力します。Mac の例では、ページ番号の代わりに［ヘッダー］または［フッター］を選択してスタイルを選ぶ手順です。すでに入っている見出しを Mac で直すときは、ヘッダーまたはフッター領域内をダブルクリックし、変更するテキストを選び、その場所に新しいヘッダーまたはフッターを入力します。

Webはオプションから切り替える

Web 用 Word の手順では、［挿入］からヘッダーとフッターを開き、文書領域上部の白い領域の右側で［オプション］＞［異なる偶数ページ & 奇数ページ］を選択します。偶数ページに表示するテキストを入力し、［奇数ページ］を選択して奇数ページに表示するテキストを入力します。編集が終了したら［プレビューを閉じる］を選択します。Web 用 Word では偶数ページから先に入力する順なので、Windows・Mac の手順と取り違えないようにします。

同じ資料を別の環境で開く担当者には、押した場所だけを口頭で伝えるより、どちら側に何を表示させるかも添えると確認しやすくなります。画面の呼び方が違っていても、完成形の文言を照合する基準が残るためです。

3．事務資料では見出しの役割を先に決める

ここからは当社の整理です。

上部に載せる文言は、読者が資料の途中を開いたとき、何を知りたいかから考えます。資料の名前を示すのか、対象となる業務を示すのかを曖昧にすると、左右を分けても似た情報が並びます。正式な名称と短い補足を組み合わせる程度なら、担当者が変わった後も意味を追いやすくなります。

表示する側上部の見出しの例読者に伝える役割
奇数ページ側備品の貸出案内何の資料かを示す
偶数ページ側社内配布用資料の用途を示す

表の文言は配置を考えるための案です。紙で見たときに、どちらの文言をどちら側に置きたいかは、実際の綴じ方に合わせて決めます。

長い正式名称をそのまま繰り返すより、略したときに意味が通るか、本文の見出しと紛らわしくないかを確認します。略称を採用した場合は、正式名称との対応も引き継ぎに残します。配布先に伝わらない社内だけの呼び方を使っていないかも確認の対象です。

4．先頭だけ違う場合と途中から変わる場合を切り分ける

表紙など先頭ページだけ別の内容にする設定は［先頭ページのみ別指定］です。Microsoft サポートの Windows 向けの手順では、最初のページのヘッダーまたはフッター領域をダブルクリックして［先頭ページのみ別指定］を選択すると、先頭ページのヘッダーまたはフッターのコンテンツが削除され、新しいコンテンツを追加する流れです。同じ手順の注は、［先頭ページのみ別指定］はトグルなので、有効になっていることを確認するとしています。先頭ページの表示だけが想定と違うときは、この設定のオン・オフを見て、先頭にも共通の見出しを出したいのか、先頭には出さない予定なのかを完成形に戻って確かめます。

前の範囲の内容が続いているとき

Microsoft サポートの「前にリンクする」では、既定ではセクションはリンクされているため、セクション区切りを作成すると、1 つのセクションで作成されたヘッダーが引き継がれるとしています。先頭ページや奇数・偶数を別にするオプションを使う場合も、各ヘッダーまたはフッターの種類は、前のセクションの同じ種類に個別にリンクされるとしています。途中から見出しを変えたいときは、その位置にセクション区切りを入れ、新しい各セクションの最初のヘッダーで［前へリンク］の選択を解除する手順です。

このページの適用先は Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016 で、Mac は挙げられていません。途中で意図しない変化があるときは、その前後の文言を見比べ、どこまで同じ内容を使う予定だったかを整理します。左右全体の問題なのか、特定の範囲だけの問題なのかを記録してから直すと、変更する範囲を絞れます。

5．配布前は印刷のプレビューで並びを確かめる

Microsoft サポートの「印刷と印刷プレビュー」では、Word では印刷とプレビューが同じウィンドウ内にまとめられ、［ファイル］＞［印刷］をクリックするとしています。プレビューの下部にある矢印で各ページを表示し、テキストが小さすぎて読めない場合はズーム スライダーで調整します。複数のページを左右に並べてプレビューしたい場合は、ズーム スライダーで縮小します。両面印刷などの印刷オプションは、同じ画面の［設定］で選びます。

見出しの文言が合っているかを見るときは文字を読める大きさにし、左右の並びを見るときは全体を見渡す、というように確認の目的を分けます。縮小した状態で整って見えても、正式名称の抜けや似た文字の誤りは読み比べる必要があります。紙で配布する資料は、試しに出したものも予定する向きにめくり、見出しが読み手の期待する側にあるかを確かめます。

6．引き継ぎには入力位置と完成形を残す

担当者向けの記録には、表示したい文言、どちら側へ入力したか、先頭をどう扱うかを残します。操作の途中の画面だけでは、なぜ文言を分けたのかが伝わりません。完成した状態を確認できる見本と、変更してよい文言の範囲があると、次回の改訂でも判断しやすくなります。

直しを依頼するときは、「左右がおかしい」だけでなく、期待する文言と実際の文言、最初から違うのか途中から違うのかを伝えます。内容の誤りと配置の誤りを分けて記録すれば、修正後に同じ観点で見直せます。

確認が済んだ後は、配布する版と編集途中の版を取り違えないよう、保存先と担当者の共有方法をそろえます。確認した見本が古い版だった場合には、本文が正しくても配布物との対応が崩れます。文言を更新した際は、完成形の見本も同じ内容に更新しておきます。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□左右に表示したい文言を、入力前に整理したか
□編集する側と、表示したい文言の対応を確認したか
□先頭を別扱いにする予定と、実際の表示が一致したか
□途中で意図せず文言が変わる箇所がないか、セクションごとの［前へリンク］を確認したか
□紙をめくる向きに合わせて、見出しの位置と読みやすさを確認したか
□次の担当者に、完成形と変更してよい文言を共有したか
