PowerPointの一つの文字枠を左右の二段組みにする手順と確認点

要点

文字枠の中で説明文を左右に並べるには、［列］で列数と間隔を指定します。続き物の説明を読みやすく配置したいときに使い、左右の文章を別々の内容として固定したいときは、内容の分け方から考えます。

公開：2026年11月13日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、PowerPointの一つの文字枠に入れた説明文を左右の二段に並べたい小さな会社の担当者が、列を設定する入口と、列区切りの制約、余白や行間の見直し、追記後の読み順を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 外枠を選び、列の設定まで進む
  2. 列の境目を固定できるかを先に考える
  3. 列間の空きと、文字まわりの空きを分けて直す
  4. 説明資料の例で、読み順と追記後の崩れを確かめる
  5. 引き継ぎには、設定した理由と残したい内容も添える
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．外枠を選び、列の設定まで進む

確認日：2026年11月13日。

ここで扱う段組みの公式ヘルプは Excel と PowerPoint に共通のページで、適用先として、PowerPoint for Microsoft 365・2024・2021・2019・2016、および Mac 向けの Microsoft 365・2024・2021 を挙げています（Excel の各版も並んでいます）。PowerPoint for the web は適用先に挙がっていないため、この記事では扱いません。

使っている環境に合わせて入口を選ぶ

出典のページは「新しい Windows バージョン」と「新しい Mac バージョン」の二つの欄に分かれています。Windows の欄では、対象のテキスト ボックス、プレースホルダー、または図形の外枠（出典では「罫線」）を右クリックし、［図形の書式設定］を開きます。右側のウィンドウで［テキスト オプション］から［テキスト ボックス］へ進み、下部の［列］を選びます。

Mac の欄では、対象の外枠（出典では「罫線」）を Control キーを押しながらクリックして［図形の書式設定］を開き、［テキスト オプション］、［テキスト ボックス］、［列］の順に進みます。 同僚へ操作を伝える際は、使った環境も添えると、入口の違いを見分けやすくなります。

列数と間隔を指定する

左右の二段にする場合は、［数値］に「2」を入れ、［間隔］で列と列の間を指定します。公式ヘルプの［間隔］はインチ単位の説明です。対象にすでに文章が入っていれば、その文章が列に表示されます。 列数を決めた後で、文章の読みやすさを見ながら列間の空きを調整するとよいです。

2．列の境目を固定できるかを先に考える

［列］が淡色表示になって操作できない場合は、テーブルを選んでいる可能性があります。テーブルの列を作る機能は、文字枠内の列を作る機能とは異なります。 設定を探す前に、今選んでいるのが文章の枠なのか、表の中なのかを見直すと、操作の行き違いを避けやすくなります。

列内の文章のバランスは改行の追加・削除で調整でき、列を含むボックスのサイズ変更でも列をより均等にできます。ただし、複数列のテキスト ボックスに列区切りを挿入することはできません。 したがって、特定の見出しをいつも右側の先頭に置きたい場面では、その位置を調整し続ける使い方が合うか、先に考えるとよいです。

見た目が整った時点で終えるのではなく、説明を読み進め、左右の境目で文意が切れていないかを確認します。続きの文章として読む内容と、左右それぞれで完結させる内容を分けて考えることが、配置を選ぶ手がかりになります。

3．列間の空きと、文字まわりの空きを分けて直す

枠の内側の余白は、文章と、囲んでいる図形やテキスト ボックスの外側の境界線との距離です。 左右の説明が近すぎるのか、文章が枠の端に寄りすぎているのかを分けて見ると、直す箇所を絞れます。

余白の調整では、左右・上下の値をインチまたはミリメートルの単位で指定できます。 端との距離を直すつもりで列間だけを広げたり、列間を直すつもりで端の余白だけを変えたりしないよう、困っている場所を言葉にしてから調整します。

行間や段落の空きも見比べる

Windows で行間を変える場合は、［ホーム］の［段落］グループにある［行間］を使います。段落の前後の空きは、［段落］ダイアログ ボックスの［前］や［後］で調整できます。 文章の途中が窮屈なのか、説明のまとまり同士が離れすぎているのかを見比べ、関係する設定から見直すとよいです。

プレースホルダーに行を追加して領域がいっぱいになると、自動調整によって行間やフォント サイズが変わる場合があります。Windows では、その際に表示される［自動調整オプション］から［このプレースホルダーにテキストをフィットさせない］を選ぶと、自動調整をオフにできます。 文字が小さくなって全体が収まっていても、読者にとって読みやすいとは限りません。全体の収まりと、本文の読みやすさを別々に確かめます。

4．説明資料の例で、読み順と追記後の崩れを確かめる

ここからは当社の整理です。

たとえば、社内の説明資料で「共用スペースの利用について」という短い案内を載せる場面を考えます。次の表は配置そのものではなく、文章を並べる前に決めておく内容の分け方です。

文章の扱い内容の例配置後に見るところ
続けて読む説明利用前の準備から利用後の片付けまで説明の続きが迷わず追えるか
独立した説明利用の決まりと問い合わせ先各項目の見出しと内容がまとまっているか

設定後は、最初から最後まで声に出さずに追い、次に読む位置で迷わないかを見ます。列の下端だけを合わせようとして、見出しとその説明が離れていないかにも目を向けます。

修正が入りやすい資料なら、いったん文章を追記した状態も想定して見直すとよいです。追記前には自然だった配置でも、見出しの置き場所や説明の区切りを直したくなることがあります。配置を完成形として渡す前に、どの内容が今後変わりやすいかも共有します。

体裁を整えるために言葉を削る際は、注意事項や連絡先など、読む人の行動に必要な内容が落ちていないかを確認します。短くすることと、意味を省くことを混同しないようにします。

5．引き継ぎには、設定した理由と残したい内容も添える

引き継ぎ用のメモは、操作の順番だけでなく、なぜその配置にしたかを添えると役立ちます。続けて読む説明を収めたかったのか、別の項目を並べたかったのかを残しておくと、次に直す人が文章の扱いを考えやすくなります。

また、配置を調整した人と文章を書き換える人が違う場合は、見出しの位置を優先するのか、説明のまとまりを優先するのかも合わせます。見た目だけを引き継ぐと、追記のたびに元の形へ戻すことが目的になりがちです。残すべき意味と、変更してよい体裁を言葉で分けておきます。

この作業を AI で減らすなら、まず説明文を短くする工程と、配置を確かめる工程を洗い出します。事務作業への AI 活用を考える際も、内容の確認を誰が担うかまで整理するとよいです。

公開・共有の前に、この表で確かめます。

確認確かめること
□使っている環境と、操作を始める外枠を確認したか
□段組みにしたい文章と、別々に扱いたい文章を分けて考えたか
□列の間隔と、枠の内側の余白を取り違えていないか確認したか

□追記後の読みやすさと、残すべき内容を確かめたか
□引き継ぎ先に、使った環境と配置の意図を共有したか
