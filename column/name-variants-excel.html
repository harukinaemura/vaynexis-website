エクセルで会社名・住所の表記ゆれを統一する。関数でそろえる部分と、AIに候補を出させる部分

要点

表記ゆれは、元のデータを書き換えずに照合用の列を作ってそろえます。見えない文字は CLEAN、半角スペースは TRIM、全角スペースと改行しないスペースは SUBSTITUTE で半角スペースに替えてから TRIM、全角と半角は ASC で、「（株）」「㈱」などの法人格は対応表と VLOOKUP でそろえます。同じ会社かどうか迷う違いは、AIに「同じと考えた理由つきの候補」を出させ、人が決めます。決めた対応表を式に反映し、直す前と後の件数を比べて確かめます。

公開：2026年11月2日／情報の確認日：2026年11月2日（出典はこの記事の最後）

この記事は、取引先の名簿や売上の一覧で、同じ会社が別の書き方で入っていて、数えたり突き合わせたりできないときの整え方をまとめたものです。会社名と住所を例にします。

Excel の関数の説明は、Microsoft サポートの公式ページで2026年11月2日に確かめました。式の結果は、Excel（日本語版）で実際に計算して確かめています。

表の会社名・住所は説明のための架空の例です。AIへの指示文も当社の作例で、AIが実際にそう答えることを示すものではありません。

  1. 表記ゆれは、6つの型に分けると直し方が決まる
  2. 元の列は書き換えず、「照合用の列」を作る
  3. 法人格の書き方は、対応表でそろえる
  4. 住所は、先にルールを決める。国税庁のサイトの置き換えも参考になる
  5. AIに頼んでよいのは「候補と理由」まで。置き換えは式で行う
  6. 最後の確認は、国税庁の法人番号公表サイトで
  7. 直したあと、件数で確かめる
  8. 表記ゆれをそろえるときの確認表
  9. 名簿・台帳のそろえ方を、仕組みにしたいとき

1．表記ゆれは、6つの型に分けると直し方が決まる

同じ会社でも、入力した人や元の資料によって書き方が変わります。エクセルは文字を1文字ずつ比べるため、見た目が同じでも、文字が違えば別のものとして数えます。たとえば =COUNTIF(A:A,"山田商事") は、「山田商事」と同じ文字のセルだけを数え、スペースや全角・半角が違うセルは数えません。

ゆれの型架空の例直す手段
①余分なスペース・見えない文字「 山田商事」「山田商事　」（先頭・末尾の空白、全角スペース）関数（CLEAN・TRIM・SUBSTITUTE）
②全角・半角「ＡＢＣ商事」と「ABC商事」、「ヤマダ」と「ﾔﾏﾀﾞ」関数（ASC・JIS）
③法人格の書き方「（株）山田商事」「㈱山田商事」「株式会社山田商事」対応表＋VLOOKUP（または SUBSTITUTE）
④ハイフン・長音の種類「3-1-1」「3－1－1」「3−1−1」SUBSTITUTE（または ASC で全角を半角に）
⑤住所の数え方「三丁目」と「3丁目」、「1番1号」と「1-1」ルールを決めて対応表。迷う分はAIの候補→人が決める
⑥呼び名の違い略称・旧社名・「山田商事」と「山田商会」関数では直せない。法人番号などで人が確かめる

①〜④は、決まった手順で機械的に直せます。⑤は、ルールを先に決めれば直せます。⑥は、別の会社かもしれないため、文字を機械的にそろえてはいけません。この3段階に分けて、手順を変えます。

2．元の列は書き換えず、「照合用の列」を作る

いきなり元のデータを上書きすると、直しすぎたときに戻せません。元の会社名の列（A列）はそのまま残し、となりに照合用の列（B列）を作って、そこでそろえます。名簿の突き合わせや重複の確認は B 列で行い、宛名の印刷など見た目が大事な用途には A 列を使います。

B 列の式は、次の順に重ねます（A2 が元のセルの場合）。

順そろえること使う式Microsoft サポートに書かれていること
1見えない文字を除くCLEAN(A2)印刷できない文字（値0〜31）を除く。値127などの追加分は、CLEAN だけでは除かれない
2全角スペースと改行しないスペースを、半角スペースにするSUBSTITUTE(SUBSTITUTE(…,"　"," "),CHAR(160)," ")TRIM は値32の半角スペース用。値160の改行しないスペース（Webページからの貼り付けに多い）は TRIM だけでは除かれない
3先頭・末尾の空白を除き、語の間は1つにするTRIM(…)各単語間のスペースは1つ残し、不要なスペースをすべて削除する
4全角を半角にそろえるASC(…)全角（2バイト）文字を半角（1バイト）文字に変える。全角文字を含まない文字列は変わらない

4つを1つの式にすると、次のようになります。

=ASC(TRIM(SUBSTITUTE(SUBSTITUTE(CLEAN(A2),"　"," "),CHAR(160)," ")))

この式で、「 ＡＢＣ　商事 」（先頭と末尾に半角スペース、間に全角スペース、英字は全角）は「ABC 商事」になりました。「 山田商事　株式会社 」（先頭と末尾の半角スペース、間の全角スペース）は、TRIM だけだと「山田商事　株式会社」で全角スペースが残り、SUBSTITUTE を挟んだ式では「山田商事 株式会社」になりました（Excel で計算）。

注意が2つあります。1つ目は、ASC はカタカナも半角カナにする点です（「ヤマダ商事」は「ﾔﾏﾀﾞ商事」になり、文字数は5から6になります）。B 列は突き合わせ専用と割り切り、見た目を直す用途には使いません。逆に、半角を全角にそろえたいときは JIS 関数を使います。2つ目は、=A2=B2 のような比較は、英字の大文字と小文字を区別しない点です（「ABC」と「abc」は等しいと判定されます）。区別したいときは EXACT 関数を使います。

3．法人格の書き方は、対応表でそろえる

「（株）」「(株)」「㈱」「株式会社」は、機械にとっては別の文字列です。ASC を通すと、全角の「（株）」は半角の「(株)」になりますが、「㈱」はそのまま残ります（Excel で確認）。そこで、そろえ方を書いた対応表を別の場所（たとえば別シートの G 列と H 列）に作ります。

元の書き方（G 列）そろえる書き方（H 列）
(株)株式会社
㈱株式会社
(有)有限会社
㈲有限会社

表を引く式は VLOOKUP です。Microsoft サポートによると、検索の型を FALSE（または0）にすると、左端の列から検索値と完全に一致する値が検索されます。省略すると近似一致になるため、必ず FALSE を付けます。

=IFERROR(VLOOKUP(C2,$G$2:$H$5,2,FALSE),"要確認")

C2 に法人格の部分だけを取り出した文字を入れた場合、「㈱」は「株式会社」に、表にない「合資」は「要確認」と表示されます。表にない書き方は、勝手に直さず「要確認」として人が見る、という動きにするためです。

会社名の中の法人格をまとめて置き換えるだけなら、SUBSTITUTE でも直せます。たとえば =SUBSTITUTE(SUBSTITUTE(A2,"(株)","株式会社"),"㈱","株式会社") です。ただし、「株式会社」が名前の前につくか後ろにつくか（前株・後株）は、別の会社かもしれないため、式では直しません。位置の違いは、⑥の型として人が確かめます。

4．住所は、先にルールを決める。国税庁のサイトの置き換えも参考になる

住所の表記は、「3丁目1番1号」「3-1-1」「三丁目一番一号」など、正解が1つではありません。どれにそろえるかを先に決め、ルールを1行で書いておきます。たとえば「数字は半角の算用数字、番地の区切りはハイフン、丁目の漢数字は算用数字にする」のように決めます。

ASC を使うと、全角の数字とハイフンは半角になります（「３丁目１－１」が「3丁目1-1」に）。ただし漢数字は変わらないため、「三丁目」は「三丁目」のままです。漢数字を算用数字にする置き換えは、SUBSTITUTE で「三丁目」→「3丁目」のように1つずつ書くか、次の節のとおりAIの候補を使います。

参考になる公的な例があります。国税庁の法人番号公表サイトの検索画面には、丁目番地等を入力するときの注意として、「三丁目」は「三」を算用数字の「３」に、「１番１号」は「１－１」に置き換えて入力するよう書かれています（2026年11月2日確認）。サイトが検索のために決めた入力の約束ごとで、住所の書き方の標準を示すものではありませんが、置き換えの考え方の参考になります。

5．AIに頼んでよいのは「候補と理由」まで。置き換えは式で行う

⑤⑥のように、関数では決められない違いは、AIに候補を出させると速く進みます。ただし、AIに「直した一覧」を作らせて、そのまま上書きするのは避けます。どこがどう変わったかが見えず、別の会社を同じ会社にまとめてしまっても気づけないためです。

次の会社名の一覧から、同じ会社と思われる表記のグループを作ってください。
・直した一覧は出さないでください。
・出力は表にしてください。列は「グループ番号」「元の表記」「同じ会社と考えた理由」「確からしさ（高・中・低）」です。
・文字の違い（全角・半角、株式会社の書き方など）だけで同じと言えるものは、確からしさを「高」にしてください。
・社名そのものが違うもの（山田商事と山田商会など）は、同じグループにしないで「要確認」と書いてください。
・一覧にない情報を推測で足さないでください。

【一覧】
（会社名を1行に1件で貼る）

返ってきた表は、人が見て、同じと決めた分だけを対応表（元の書き方→そろえる書き方）に写します。置き換えは、その対応表を引く式で行います。こうすると、AIが示した理由と、実際に直した内容が、表の形で残ります。

名簿に個人事業主の氏名や住所が含まれる場合は、個人情報にあたることがあります。個人情報保護委員会は、個人情報取扱事業者が個人情報を含むプロンプトを生成AIサービスに入力する場合には、利用目的の達成に必要な範囲内であることを十分に確認するよう注意喚起しています。入力するサービスの学習の扱いと、入力してよい情報の範囲は、生成AIの社内ルールの作り方で決めておきます。

6．最後の確認は、国税庁の法人番号公表サイトで

⑥のような「本当に同じ会社か」の確認には、国税庁の法人番号公表サイトが使えます。このサイトでは、法人番号の指定を受けた法人等の基本3情報（商号または名称、本店または主たる事務所の所在地、法人番号）を検索でき、ダウンロードやWeb-APIでデータを取得することもできます（2026年11月2日確認）。

名簿に法人番号の列を足しておくと、会社名の書き方が違っても、法人番号が同じかどうかで同じ会社かを確かめられます。確認のしかたは、次のようにします。

  • 公表サイトで、名称・所在地、または法人番号から検索し、基本3情報を名簿と見比べる
  • 公表サイトの検索には「公表以後の変更履歴を検索対象に含める」などの条件があるため、商号や所在地を変えた会社は、変更履歴を含めて探す
  • 個人事業者は、法人番号の指定を受けた法人等ではないため、このサイトでは探せない。名刺や請求書の記載など、別の方法で確かめる

7．直したあと、件数で確かめる

そろえたあとは、「同じものが同じとして数えられるようになったか」と「別のものをまとめすぎていないか」の両方を、件数で確かめます。次の表は、架空の名簿80件での確認の例です。

確認方法例（架空）
行数が変わっていない=COUNTA(A2:A81) と =COUNTA(B2:B81)どちらも80
重複が減った（同じ会社が1つにまとまった）A 列と B 列で、それぞれ重複を除いた件数を数える（重複の削除は別の場所にコピーして試す）A 列 73件 → B 列 66件（減った7件は、中身を見て同じ会社と確かめる）
まとめすぎていない減った分の組を1組ずつ見て、同じ会社か確かめる「山田商事」と「山田商会」は別の会社として残す
「要確認」が残っていない=COUNTIF(B2:B81,"要確認")0（残っていれば人が決める）

件数・合計・重複を元の資料と数えて比べる考え方は、転記ミスの原因と防止策にまとめています。

8．表記ゆれをそろえるときの確認表

整える前と、整えたあとに、この表で確かめます。

確認確かめること
□元の列は書き換えず、照合用の列を別に作った
□ゆれを6つの型（スペース・全角半角・法人格・ハイフン・住所・呼び名）に分けて、直す手段を決めた
□全角スペースと改行しないスペースを、TRIM の前に半角スペースにした
□法人格の対応表を作り、VLOOKUP の検索の型に FALSE を付けた
□表にない書き方は「要確認」にして、勝手に直していない
□住所のルール（数字・ハイフン・丁目）を1行で書いて決めた
□AIには「直した一覧」でなく「同じと考えた理由つきの候補」を出させた
□名簿に個人情報が含まれる場合、入力してよい範囲を社内のルールで決めてからAIに渡した
□前株・後株や、似た社名は、人が法人番号などで確かめた
□行数が変わっていないこと、重複が減った組が同じ会社であることを確かめた

9．名簿・台帳のそろえ方を、仕組みにしたいとき

表記ゆれは、一度そろえても、新しい入力でまた生まれます。入力の欄を選択式にする、受け取る資料の形を決める、そろえる式と対応表を台帳に付けておく、といった決めごとがあると、毎回の手直しが減ります。重複と件数を確かめる手順の実演は転記・集計の実演ページにあります。

  • Microsoft サポート「CLEAN 関数」：印刷できない文字を除く・値0〜31の範囲
  • Microsoft サポート「TRIM 関数」：値32の半角スペースを除く・値160の改行しないスペースは単独では除かれない
  • Microsoft サポート「SUBSTITUTE 関数」：文字列の中の指定した文字を置き換える
  • Microsoft サポート「ASC 関数」：全角（2バイト）文字を半角（1バイト）文字に変える
  • Microsoft サポート「JIS 関数」：半角の英数カナ文字を全角に変える
  • Microsoft サポート「VLOOKUP 関数」：検索の型 FALSE（0）は完全一致、省略すると近似一致
  • Microsoft サポート「COUNTIF 関数」：条件に合うセルの数を数える（件数の確認で使用）
  • Microsoft サポート「COUNTA 関数」：空でないセルの数を数える（行数の確認で使用）
  • 国税庁法人番号公表サイト：基本3情報の検索・ダウンロード・Web-API・丁目番地等の入力の注意
