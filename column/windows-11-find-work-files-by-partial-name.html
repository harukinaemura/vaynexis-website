Windows 11で名前の一部しか分からない業務資料を探す手順

要点

Windows 11のエクスプローラーで、心当たりのあるフォルダーを開き、右上の検索ボックスに覚えている名前の一部を入力します。候補が出なければ、同じ言葉で別のフォルダーや［この PC］を検索します。見つかった候補は、内容と保存先を照合してから使います。

公開：2026年11月8日／情報の確認日：2026年11月7日（出典はこの記事の最後）

Windows 11で業務資料の正確な名前が分からないときに、エクスプローラーで検索範囲を選ぶ流れです。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 保存先の見当から、検索する場所を選ぶ
  2. 覚えている名前の一部を検索ボックスに入れる
  3. 覚えている名前と検索した場所を別々に控える
  4. 候補がない場合と、見つかった後の確認を分ける
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．保存先の見当から、検索する場所を選ぶ

確認日：2026年11月7日

検索ヘルプの適用先は Windows 11 と Windows 10 で、この記事では Windows 11 を対象にします。エクスプローラーは、PC とクラウド上のファイルやフォルダーの検索、開く操作、整理、管理を支える道具です。

Windows キー＋E を押すと、エクスプローラーが開きます。

保存したフォルダーに心当たりがあるとき

保存先に見当がつく資料は、エクスプローラーで対象のフォルダーを選び、その中から検索できます。資料を置いた覚えのあるフォルダーから始めます。受け取った直後の置き場と、その後に整理した置き場を混同していないか、手元の案内や自分の記憶を確かめるとよいです。

保存先の見当がつかないとき

保存先が分からないときは、心当たりのあるドライブから探します。Microsoftの日本語ヘルプは、より詳しく探す場合に［この PC］を選ぶと、［ホーム］から検索する場合より時間がかかると案内しています。狭い範囲で候補が出なかったときに、探す場所を広げる選択肢として考えます。会社の共有先などに置いた可能性がある場合は、その保存場所にアクセスできるかも確かめます。

2．覚えている名前の一部を検索ボックスに入れる

エクスプローラーでは、画面右上の検索ボックスへの入力によって、既定で現在のフォルダーと子フォルダーからファイルやフォルダーを検索します。検索ボックスをキーボードで選ぶには、エクスプローラー内で Ctrl＋F を使えます。

入力する言葉は、覚えている名前の一部を使います。確かでない語を付け足す前に、入力した語で出た候補を確かめます。

  1. エクスプローラーで、探すフォルダーを開きます。
  2. 右上の検索ボックスに覚えている名前の一部を入力します。
  3. 候補の名前を読み、目的の書類か確かめます。

3．覚えている名前と検索した場所を別々に控える

ここからは当社の整理です。

一度の検索で入力する言葉と場所の両方を変えると、次にどの条件を試すか決めにくくなります。入力した言葉、検索した場所、候補から確かめられたことを分けて控えます。

検索して分かったこと次に確かめることメモに残すこと
候補がないが、入力した名前の一部に覚えがある同じ言葉で、保存した可能性がある上の階層や別の場所を探す同じ言葉で確認したフォルダーやドライブ
場所に心当たりがあるが、名前の記憶が曖昧同じ場所で、別に覚えている名前の一部を使うその場所で試した言葉
似た名前の候補が複数見つかった候補の内容と保存先を、今回必要な資料と照合する資料を特定できた場所や、未照合の候補

候補が多いときは、資料の用途を思い出して、より特徴のある言葉がないか考えます。「何となく見覚えがある名前」を選ぶ前に、その資料で行いたい仕事を言葉にしておくと、内容を照合する際の基準になります。探した結果を残すメモにも、書類の用途を短く添えるとよいです。

4．候補がない場合と、見つかった後の確認を分ける

候補が出なかった場合

見つからなかった結果は、その言葉と場所で目的の資料を特定できなかった、というところまでで受け止めます。資料が消えたと判断する前に、入力した言葉と探した場所を振り返ります。名前の覚え違いに気づいたのか、別の保存先を思い出したのかを分けて考えると、次に試すことが明確になります。

担当者に所在を尋ねる際も、書類の用途、覚えている名前、探した場所をそろえるとよいです。「資料がない」という連絡だけで終えず、どこまで探して候補を絞れなかったかを伝えます。所在について新しい手がかりを得たら、それまでの探し方と混ぜずに追記します。

候補が見つかった場合

候補の名前を見て終わりにせず、内容が今回必要な書類かを確かめます。下書きか提出用か、対象の相手や案件が合っているか、手元の依頼や連絡と照らし合わせるとよいです。似た名前の資料が並んだときは、どれを使うかを名前だけで決めず、違いを読み取ってから選びます。

保存先も併せて確認します。目的の資料を特定できたら、次回は名前を思い出すところから始めずに済むよう、見つかった場所を控えておきます。候補の所在を探す段階と、使う資料を決める段階を分けることで、名前の一部が一致しただけで別の書類を使うことを避けやすくなります。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□覚えている名前の一部と、曖昧な記憶を分けて整理したか
□保存先の見当を付けて、探し始める場所を選んだか
□入力した言葉に覚え違いや入力の誤りがないか確かめたか
□探す場所と言葉を変えた経過を区別したか
□見つかった資料の内容が、今回の用途に合うか照合したか
□目的の資料の保存先を控え、次に探す手がかりを残したか

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

  • Windows のエクスプローラー：ファイルやフォルダーを検索・管理する道具としての役割
  • Windows のキーボード ショートカット：エクスプローラーを開く操作と、その中で検索ボックスを選択する操作
