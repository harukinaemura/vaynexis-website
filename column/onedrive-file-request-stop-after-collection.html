OneDriveで書類回収を終えたら提出用リンクを閉じるには

要点

OneDrive for Businessの書類回収は、回収先のフォルダーでファイル要求リンクを削除すると停止でき、そのリンクから追加のアップロードができなくなります。再開には同じフォルダーで新しいファイル要求を作り、相手に新しいリンクかメール招待を送ります。

公開：2026年11月8日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、OneDrive for Businessで書類を集める小さな会社の担当者が、回収後にファイル要求リンクを閉じて終了記録を残す手順をまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 対象をそろえ、回収漏れを確認する
  2. 回収先の要求リンクを削除する
  3. 削除後の確認と、再受付の進め方
  4. 回収終了の記録を引き継ぐ
  5. 確認表
  6. 自社の事務の手順まで形にしたいとき

1．対象をそろえ、回収漏れを確認する

確認日：2026年11月6日。

操作のヘルプの適用先はOneDrive for Businessです。ファイル要求を利用する前提には、職場または学校でOneDriveを使っていることが含まれます。すでに書類を集めている担当者が、受付を閉じるところから扱います。

操作前の社内確認として、回収先の名前と、提出を依頼した案内を照合します。似た名前の保存先が並んでいるときは、名前だけで選ばず、今回の書類が入っている場所かを見るとよいです。提出済みの連絡だけで完了とせず、受け取った書類を開いて、依頼したものがそろっているかまで確かめます。

差し替えを待っている書類や、提出の見込みが分かっている相手は、終了前に担当者同士で共有しておきます。「回収を終えた」と考えている人と、追加提出を待っている人の認識をそろえてから閉じる進め方です。

2．回収先の要求リンクを削除する

停止の操作は、提出を受けたフォルダーから始めます。

  1. OneDriveで、ファイル要求に使ったフォルダーを選びます。
  2. 省略記号（...）を選びます。
  3. ［アクセスの管理］を選びます。
  4. ［アクセスを与えるリンク］で、要求リンクの横にある省略記号（...）を選びます。
  5. 対象のリンクの横にある［x］を選びます。
  6. ［リンクの削除］を選びます。

削除を確定する前には、提出依頼の控えと対象をもう一度照合するとよいです。別の業務でも似た案内を送っているときは、担当している回収の名前だけでなく、相手に送った案内との対応を確認します。

画面に書かれた項目が見当たらないときは、似た言葉の項目を推測で選び進めず、開いている対象と表示を控えます。社内の確認先に伝える内容は、止めたい回収、開いた場所、どの操作まで進めたかです。表示に迷った箇所を残しておけば、引き継ぐ人も確認の出発点をそろえられます。

3．削除後の確認と、再受付の進め方

削除した要求リンクを持つ相手は、そのフォルダーへファイルをアップロードできなくなります。また、リンクの削除は取り消せません。

社内での終了確認には、提出者に送った案内の控えを使い、閉じる対象に取り違えがなかったかを確かめる進め方があります。操作を担当した人の判断だけで終えず、確認した対象と結果を記録しておくとよいです。提出者へ終了を伝える担当も決めておきます。

追加提出が必要になった場合は、同じフォルダーで新しいファイル要求を作成し、受信者へ新しいリンクまたはメール招待を送ります。

再受付の社内連絡では、誰から何を待つのかを先に整理します。対象を限定した追加提出なのか、回収全体をやり直すのかを担当者間でそろえ、今回の案内を送る相手を確認する流れです。提出者に渡す説明と、社内に残す記録の内容も合わせます。

4．回収終了の記録を引き継ぐ

ここからは当社の整理です。

終了の記録には、回収した書類、閉じる対象、終了後の確認、残っている連絡を短く残します。書類の内容確認と、提出受付を閉じた操作の記録を分けると、後任者が終わった範囲を読み取りやすくなります。

終了時には、次の項目を実際の確認結果に合わせて記録する案です。

残す項目残す情報
書類の確認依頼した書類と受領した書類、内容の照合結果
操作の対象提出依頼の案内と要求リンク・フォルダーの対応
終了後の確認操作した担当者、対象と結果を確かめた内容
残っている連絡未提出・差し替え・終了連絡の残件と担当者

記録の「確認済み」は、実際に終えたことだけに使います。未提出の書類や、まだ開いていない書類があるときは、残件として相手と担当者を書き添えるとよいです。終了の連絡が済んでいなければ、その点も分けて残します。

後から追加提出の相談を受けた担当者は、終了時の記録を読み、回収の責任者に再受付の要否を確認します。操作の記録だけでなく、誰が次の対応を決めるかまで分かる形にしておくと、引き継ぎ先が判断に迷いにくくなります。

5．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□回収した書類を開き、依頼したものがそろっているか確認したか
□差し替え待ちや未提出の連絡を担当者間で共有したか
□停止する対象を、提出依頼の案内と照合したか
□削除する対象を確かめ、停止の操作を最後まで終えたか
□操作の対象と終了後の確認結果を記録したか
□追加提出の要否を決める人と、残っている連絡の担当者を明確にしたか
