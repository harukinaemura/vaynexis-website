画像が多いPowerPointの容量を小さくする手順と確認点

要点

画像が多い資料は、画像の圧縮で容量を小さくできます。まず原本を残し、共有用のコピーで対象範囲を決めて作業します。仕上げは容量だけで判断せず、写真の細部や画像内の文字を読み取れるかまで確かめる進め方がよいです。

公開：2026年11月3日／情報の確認日：2026年11月3日（出典はこの記事の最後）

この記事は、画像が多いPowerPointの資料を共有用に軽くしたい小さな会社の事務担当者が、原本を残したうえでの圧縮の範囲と、保存後に確かめる点を整理するためのものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月3日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 原本と共有用を分け、読む場面を決める
  2. 画像を選び、圧縮する範囲を設定する
  3. 解像度を下げるときは読みやすさを比べる
  4. 切り取った部分と編集用データの削除を分ける
  5. 保存後は容量と読める内容を確かめる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．原本と共有用を分け、読む場面を決める

作業前に元の資料を複製し、原本と共有用の名前を分けます。原本には手を加えず、容量を小さくする操作は共有用で試す流れにします。あとで写真の範囲や見せ方を変える可能性があれば、資料に使った元の画像も残しておくとよいです。

次に、相手が画面で読むのか、紙に印刷するのかを決めます。写真の雰囲気が伝わればよい資料と、細かな表示を読む資料では、残したい情報が違います。どこまで読めれば共有できるのかを先に決めると、仕上がりを比べる観点が定まります。

作業前の容量と、読みにくくしたくないページを控えておきます。見た目に問題がないか確かめる対象は、写真が大きく載ったページだけではありません。画像の中に文字や細線があるページも選んでおきます。

2．画像を選び、圧縮する範囲を設定する

この記事は Windows のデスクトップ版を対象とし、ウェブ版では画像圧縮を利用できません。ここでは公式ヘルプの操作手順をもとに整理します。

資料内の画像を選ぶと［図の書式］タブが現れ、［調整］にある［画像の圧縮］から設定を開けます。資料全体の画像に適用する場合は、［この画像にのみ適用する］の選択を外します。

選んだ画像だけを圧縮する場合は、［この画像だけに適用する］をオンにします。

実務では、資料全体を軽くしたいのか、特定の写真だけを調整したいのかを、設定を開く前に決めておきます。まとめて変更したあとも、読みにくくしたくない画像は個別に見直すとよいです。

操作の名称は、画面上の表記と照らし合わせます。ここに記した機能の確認日は、出典の一覧にまとめています。

3．解像度を下げるときは読みやすさを比べる

画像の既定の解像度を下げることでも、資料全体の容量を小さくできます。設定場所は［ファイル］→［オプション］→［詳細設定］です。［イメージのサイズと画質］の設定は、開いている資料だけに適用されます。［イメージのサイズと画質］内の［既定の解像度］では、公式ヘルプは容量を減らす設定として150ppi以下を案内しています。

画像を圧縮すると細部が失われ、見た目が変わる場合があります。

容量を減らすための設定と、仕上がりを採用する判断は分けて考えます。共有用で設定を変えたら、原本の同じページと並べて比較します。細い線が途切れて見えないか、画像内の小さな文字を読み違えないかが確認の中心です。

表示を大きくして見比べるだけでなく、相手が読むときの大きさでも確認します。紙で配る資料なら、文字や図が細かなページを試しに印刷し、手元で読めるかを見るとよいです。容量が小さくなっても、説明に必要な情報が読み取れない仕上がりは採用を見送ります。

4．切り取った部分と編集用データの削除を分ける

画像はトリミングしただけでは、切り取った領域が非表示のままファイル内に残ります。切り取った部分を削除する操作では、［圧縮オプション］の［図のトリミング部分を削除する］をオンにします。切り取った部分の削除は、保存するまでなら元に戻せます。

［編集データを破棄する］は、画像の変更を元に戻すためのデータを削除する設定です。編集用データを削除したあとに画像の編集を戻す場合は、画像の再挿入が必要になります。

実務では、まだ写真の見せ方を調整する段階か、配布する内容が固まった段階かで、削除するかを考えます。あとで周囲まで見せ直す可能性がある写真は、原本を残してから共有用で処理します。軽くする操作をまとめて進める前に、どのデータを残したいかを決めておくとよいです。

5．保存後は容量と読める内容を確かめる

たとえば、写真と操作画面を含む説明資料なら、画像の種類ごとに確認する箇所を変えます。

画像の種類保存後に見るところ採用を見送る目安
全体の様子を伝える写真説明したい箇所を見分けられるか対象の境目が分からない
操作画面の画像ボタンの文字が読めるか文字を推測しないと読めない
細かな図を画像にしたもの線や注記を追えるか線の区別や注記が読み取れない

作業後は保存した共有用を開き直し、容量の変化と表の観点を確かめます。編集途中の画面だけで終えず、実際に渡すファイルを見る流れにします。送る直前には、添付する資料が共有用であるかも照合するとよいです。

容量があまり変わらなければ、変更した対象範囲を見直します。その場でさらに画質を下げ続けるより、どの操作を試したかを整理してから次を判断します。引き継ぎには、原本の場所、変更した設定、確認したページを短く残します。次の担当者も、同じ観点で仕上がりを確かめやすくなります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□原本と共有用を分け、元の画像の保管場所も確認したか
□画面で読む資料か、印刷して読む資料かを整理したか
□変更する画像の範囲を、作業前の意図と照合したか
□保存後の容量を、作業前の容量と比較したか
□画像内の小さな文字や細い線を、読む場面に合わせて確認したか
□元に戻すために残すデータを、保存前に確認したか
□相手に渡す資料と、引き継ぎのメモを照合したか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。
