e-Taxの利用者識別番号等の通知書を紛失したときは？

要点

通知書が無くても、まずほかの控えで番号を探します。e-Taxの案内では、利用者識別番号を確認する方法は5つあるとされています。 どれでも確認できない場合は、変更等届出書を所轄の税務署へ提出（送信）します。 届出のあと、利用者識別番号が所轄の税務署から郵送で届きます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

会社のe-Taxの利用者識別番号が書かれた通知書が見つからないときは、届出を出す前に社内で探せる場所があります。それでも分からないときの変更等届出書と、届くまでの流れを、国税庁の案内で順に確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

社内で探す場所の一覧と確認表は当社の整理で、国税庁が示すものではありません。

  1. 届出の前に、社内で探す場所
  2. 「開始届出書」をもう一度出さない
  3. 番号は分かったが、パスワードだけ分からないとき
  4. 見つからなければ「変更等届出（法人用）」
  5. 届くのは郵便、仮の暗証番号と一緒に
  6. 番号の置き場所も、事務の一覧に入れておく
  7. 確認表
  8. 番号やIDの置き場所を決めておきたいとき

1．届出の前に、社内で探す場所

確認日：2026年11月17日。

対象は、法人がe-Taxで使っている利用者識別番号の確認です。

担当者が替わったときや、数年ぶりに電子申告をするときに、通知書の行方が分からなくなることがあります。案内にある5つの確認方法を、会社の書類の置き場所に当てはめると次のようになります。

案内にある確認方法会社で探す場所の例
利用者識別番号等の通知（書）や印刷した受信通知税務署からの郵便物、申告書の控えのつづり
e-Taxソフトの「受付システムログイン用暗証番号入力」画面e-Taxソフトを入れているパソコン
確定申告書等作成コーナーの保存データ（.data）作成コーナーで作ったデータの保存先
税理士等が管理しているか顧問の税理士事務所
マイナンバーカード方式を利用している場合の確認方法個人の利用者向けの方法

印刷した受信通知が手元にあるなら、そこから番号を確かめられます。 税理士等に委任している場合は、税理士等が利用者識別番号を管理しているか確認するよう案内されています。 法人の申告を顧問の税理士事務所が代理送信しているなら、事務所に聞くのがいちばん早いことが多いでしょう。

2．「開始届出書」をもう一度出さない

番号が分からないと、最初の手続きからやり直したくなります。ところが、e-Taxの届出書の作成・提出コーナーでは、すでに利用者識別番号を取得している人が再度開始届出書を提出すると、これまでe-Taxで提出した申告等の内容を確認できなくなると注意しています。 開始届出書は、e-Taxを初めて利用する人が利用者識別番号を取得するための手続で、番号や暗証番号を忘れた場合は変更等届出の手順で進めるよう案内されています。

顧問の税理士がいる会社は、関与税理士から開始届出書が提出されていないことも確かめるよう書かれています。 前の担当者か税理士事務所が以前に番号を取っていたかもしれない、という段階なら、新しく取り直すより先に、5つの方法で探すほうが安全です。

3．番号は分かったが、パスワードだけ分からないとき

控えから番号は見つかったのに、ログインのパスワードが分からないこともあります。「秘密の質問」と「メールアドレス」を登録していれば、「秘密の質問と答えの入力」画面からパスワードを再設定できます。 入力するのは、利用者識別番号、秘密の質問、質問の答え、登録済みメールアドレス、生年月日（または設立年月日）です。 前の担当者が秘密の質問を登録していたかどうか分からなければ、この方法は使えないものとして、次の変更等届出に進みます。

4．見つからなければ「変更等届出（法人用）」

5つの方法で確認できなかったときは、変更等届出書を出します。案内のPDFでは、次の順に進めます。

  1. e-Taxホームページの「e-Taxの開始（変更等）届出書作成・提出コーナー」から「変更等届出書」を押す
  2. 『変更等届出（法人用）　利用者識別番号・パスワードをお忘れになった方』を押す（案内の PDF では「暗証番号をお忘れになった方」の表記）
  3. 入力画面の案内に沿って必要事項を入力し、送信する
  4. 「送信結果」画面を確かめる

送信結果に表示される受付番号は、問い合わせの際に必要となるため、印刷等をしておくよう勧められています。 届くまでのあいだに税務署へ問い合わせることになっても、この番号があれば話が早く進みます。

入力の途中では、ブラウザの「戻る」ボタンや「更新」ボタンを押さないよう注意書きがあります。 入力した内容は送信後に印刷・保存できないため、送信前に印刷か保存をしておくよう勧められています。 税理士事務所に手続きを頼む場合も、代理で変更等届出書を送信したときの送付先は関与先、つまり会社になります。 郵便を受け取る総務の担当者にも、税務署から通知書が届く予定だと伝えておくと、ほかの郵便に紛れずに済みます。

5．届くのは郵便、仮の暗証番号と一緒に

送信のあと、後日、利用者識別番号と仮の暗証番号が記載された「利用者識別番号等の通知書」が書面で郵送されます。 画面ですぐに番号が分かるわけではないため、申告の期限が近いときは、届くまでの日数も考えて早めに手続きします。

郵便が届いたら、次の担当者が同じことで困らないよう、置き場所を決めて残します。通知書の原本は社外秘の書類と同じ扱いにし、社内の誰が番号を知っているか、税理士事務所が控えを持っているかも一緒に書いておくと安心です。

6．番号の置き場所も、事務の一覧に入れておく

利用者識別番号のように、年に数回しか使わないのに、無いと手続きが止まる情報はほかにもあります。e-Gov・eLTAX・GビズIDなどのIDと、その控えの置き場所を、業務の一覧と並べて書き出しておくと、担当替えのときの引き継ぎが楽になります。書き出し方は、業務棚卸表のテンプレートと記入例も参考にしてください。

7．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□税務署からの郵便物や、印刷した受信通知の控えを探したか
□e-Taxソフトや作成コーナーの保存データを確かめたか
□顧問の税理士事務所が番号を管理していないかを聞いたか
□開始届出書を出し直していないか（顧問の税理士にも確かめたか）
□パスワードだけなら、秘密の質問で再設定できるかを見たか
□それでも分からなければ『変更等届出（法人用）　利用者識別番号・パスワードをお忘れになった方』から送信したか
□送信結果の受付番号を印刷して残したか
□郵送で届いた通知書の置き場所と、知っている人を書き残したか

8．番号やIDの置き場所を決めておきたいとき

利用者識別番号のように、たまにしか使わない番号は、置き場所が決まっていないと担当の交代で行方が分からなくなります。電子申請で使う番号やIDを一覧にしておく作業は、当社の業務の棚卸しでも扱います。

どこまで一覧にするかを相談したい場合は、初回無料相談をご利用ください。税務の判断や届出の代行は行いません。
