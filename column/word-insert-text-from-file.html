Wordで別ファイルの説明文を今の文書へ取り込む手順と確認点

要点

別ファイルの説明文は、取り込み先で挿入位置を決め、［挿入］の［オブジェクト］の横から［ファイルからテキスト］を選んで、ファイルの内容を追加します。本文に加えてページ上部・下部の表示（ヘッダーとフッター）も含める場合は、ファイルからのテキストを新しいセクションに挿入するよう案内されています。作業を始める前に、移したい内容と、取り込み先で維持したい範囲を決めておくとよいです。

公開：2026年11月11日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、別のWord文書に保管した説明文を今の資料へまとめたい小さな会社の事務担当者が、［ファイルからテキスト］で取り込む手順・ヘッダーとフッターも含めるときのセクション区切り・前後のリンクと区切りを直す前の確認を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 取り込み先と元の文書を先に決める
  2. 挿入位置を選び、ファイルの内容を追加する
  3. ページ上部・下部も含めるときは区切りを用意する
  4. 前後で異なる表示にするならリンクも確かめる
  5. 事務の資料では、残す説明とつながりを整理する
  6. 内容の境目と、区切りを直す前の確認
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．取り込み先と元の文書を先に決める

確認日：2026年11月10日。

「Word で文書を挿入する」の適用先は、Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016です。 適用先に Mac 用・Web 用の Word は挙がっていないため、この記事の取り込みの手順は、上に挙げた版の Word を前提にします。事務で使う説明資料に別途保管した文章を加える場面では、取り込み先の文書と、内容を取り出す元の文書を先に区別しておきます。

作業用の控えを用意し、完成させる資料のどの見出しの下へ入れるかを決めます。選ぶ前には元の内容を読み、残す注意書きと、今回の資料には不要な案内を整理するとよいです。同じ題名の控えが並んでいる場合は、保存場所だけで判断せず、本文の内容も照合します。引き継ぎ用には、採用した元の資料が分かるように名前と保管先を記録しておきます。

2．挿入位置を選び、ファイルの内容を追加する

まず、今の文書で説明文を入れたい場所をクリックまたはタップします。 先頭に追加するのか、既存の説明の後へ続けるのかを見ながら位置を選びます。長い文書では、目的の見出しの近くまで移動したうえで、その直前と直後の文章を読むと判断しやすくなります。

次に、［挿入］から［オブジェクト］の横の矢印を開きます。 ［ファイルからテキスト］を選び、取り込むファイルを見つけてダブルクリックします。 操作後は追加された文章の最初と最後を見て、選んだ内容が入ったかを確かめます。

別の文書の内容も続けて加える場合は、同じ取り込み手順を繰り返します。 追加のたびに次の挿入位置を決めておくと、説明の順番を確認しながら進められます。まとめた資料を読み手の順路に沿って並べるため、元のファイルの保管順とは別に、完成後の説明の順番を考えます。

3．ページ上部・下部も含めるときは区切りを用意する

ヘッダーとフッターも挿入する場合は、ファイルからのテキストを新しいセクションに挿入するよう案内されています。そうすることで、ヘッダーとフッターが対象のページだけに適用されます。 本文の内容を選ぶ段階で、ページ上部の文書名や下部の注記も取り込みたいかを決めます。

セクション区切りは、新しいセクションを始める場所を選び、［レイアウト］＞［Breaks］に移動して、必要な区切りの種類を選んで追加します（ヘルプの Windows 用の欄の表記のまま）。 主な選択肢として、次のページで始める区切りと、同じページで始める連続の区切りがあります。 このほかに、次の偶数ページで新しいセクションを始める区切りと、次の奇数ページで始める区切りも挙がっています。

WebのWordでは、改ページは追加できてもセクション区切りはまだ追加できません。デスクトップ アプリを使っている場合は、［Word で開く］で文書を開いてから区切りを追加するよう案内されています。 この準備を伴うときは、取り込みを始める前に使う画面を決めておきます。

4．前後で異なる表示にするならリンクも確かめる

セクションは既定でリンクされており、区切りを作成すると、作成済みのヘッダーが引き継がれます。 区切りを作った後は、前後のページで表示を共有したいか、それぞれ別の内容にしたいかを確認します。

前のセクションとのリンクを解除する操作は、新しいセクションの最初のページでヘッダーまたはフッターをダブルクリックし、［前へリンク］をオフにする順です。 ヘッダーとフッターは個別にリンクされるため、セクションごとに両方を変える場合は、両方のリンクをオフにします。 作業後は、意図したページとその後に続くページを見比べます。上部だけを確認して終えず、下部に残す案内にも目を向けるとよいです。

5．事務の資料では、残す説明とつながりを整理する

ここからは当社の整理です。

別保管の説明を追加するときは、元の資料をそのまま採用できる部分と、今回の文脈に合わせて読み直す部分を分けます。小さな整理表を作ると、取り込み前に決めることと、取り込み後に見ることが対応します。

加える内容先に決めること追加後の照合箇所
申し込みの補足説明本文のどの案内に続けるか前の文章から自然につながるか
備品返却の注意書き旧い案内のうち残す範囲返却先や注意事項の重複がないか
社内研修の別紙説明今回の資料に含める範囲別紙を参照する文と実際の内容が合うか

例えば補足説明を加えた後は、「別紙の案内を参照」などの表現を残すかも検討します。内容が同じ資料の中へ入ったことで、読み手が参照先に迷わないかを確かめるためです。取り込む範囲の冒頭に題名があり、取り込み先にも似た見出しがある場合は、内容のまとまりが伝わる構成に整えます。

引き継ぎには、完成した資料と元の資料の対応を残しておきます。何を採用したかに加え、取り込み後にどの文章を調整したかが分かると、次に内容を見直す担当者が照合しやすくなります。

6．内容の境目と、区切りを直す前の確認

取り込み後は、追加した説明の最初と最後、その前後の既存の文章を読みます。見出しが重複していないか、必要な注意事項がそろっているか、文章の順番が適切かを照合します。見た目の調整は、内容の過不足を確認してから進めるとよいです。

区切りの位置を見るには、［ホーム］の［表示/非表示］（¶）で編集記号を表示するよう、Word のヘルプで案内されています。 ヘルプの Windows 用の欄では、区切りを消すときは、区切りの直前にカーソルを置いて Delete キーを押します。 同じヘルプでは、セクション区切りを削除すると前後が同じセクションにまとまり、区切りの後のセクションの書式設定が使われる、と説明されています。 区切りの前のセクションの書式設定やヘッダー、フッターを使いたい場合は、区切りを削除するのではなく［前へリンク］を使うよう案内されています。 空白や配置が気になる場合も、境目の前後で残したい表示を整理してから直します。

最後は元の資料を横に置き、取り込むと決めた範囲と完成した文書を照合します。説明が抜けている場合と、余計な内容が残っている場合は分けて扱います。

公開・共有の前に、この表で確かめます。

□取り込んだ資料と、追加後に調整した内容を記録したか

  • Word で文書を挿入する：適用先、挿入位置、ファイル選択、繰り返し追加、ヘッダーとフッターも含める条件
  • セクション区切りを挿入する：区切りを追加する手順、開始位置の違い（次のページ・連続・偶数ページ・奇数ページ）、Web版での制約

  • セクション区切りを削除する：区切りを消す手順、削除した場合に使われる書式設定、前の書式を使いたいときの［前へリンク］
