OneDriveの［フォルダーの選択］で、このPCにだけ同期しないフォルダーを決めるには

要点

OneDrive の設定の［アカウント］タブで［フォルダーの選択］を選び、このパソコンと同期しないフォルダーのチェックを外して［OK］を選びます。 外したフォルダーはこのパソコンからは消えますが、フォルダーとその中身はオンラインで引き続き使えます。 この選び方はパソコンごと、アカウントごとに別々に決まるため、ほかの社員のパソコンには影響しません。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

受付の共用パソコンには、経理や給与のフォルダーまで置いておきたくない。［フォルダーの選択］で外すと何が残り何が消えるのか、削除との違い、外せないフォルダーと外した後に出るエラーを確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

受付の共用パソコンの設定例は架空の場面で、確認表には Microsoft の手順に無い当社の注意も入れています。

1．「このパソコンだけ」を決める設定

確認日：2026年11月17日。

対象は、Windows のパソコンで使う OneDrive 同期アプリです。Mac も同じ名前の画面で操作できますが、手順は後で短く触れるだけにします。

受付に置いた共用のパソコンでは、来客の予定表のフォルダーは使っても、給与や経理のフォルダーまで表示させておく理由はありません。容量の小さいノートパソコンなら、写真や動画の大きなフォルダーを置かずに済ませたいこともあります。ヘルプでは、同期するフォルダーを選ぶことで、重要なファイルのみをオフラインで使えるようにできると説明されています。

ここで押さえておきたいのは、外すのは「このパソコンの見え方」だけだということです。Web ブラウザーやモバイル アプリで OneDrive を開くと、常にすべてのフォルダーが表示されます。 共用のパソコンから見えなくしても、そのフォルダーに社内の誰がアクセスできるかは変わりません。見せる相手を変えたいなら、共有の設定を見直す別の作業になります。

2．Windows で外す手順

順番操作（Windows 版）
1通知領域で OneDrive クラウド アイコンを選び、［OneDrive のヘルプと設定］アイコン、［設定］の順に選ぶ
2［アカウント］タブに移動する
3［フォルダーの選択］を選ぶ
4［フォルダーの選択］ダイアログ ボックスで、このパソコンと同期しないフォルダーのチェックを外し、［OK］を選ぶ

Mac の場合も、OneDrive クラウド アイコンから［設定］を開き、［アカウント］タブの［フォルダーの選択］で同じようにチェックを外します。

3．一覧に出ないもの、外せないもの

［フォルダーの選択］で扱えるのは、OneDrive にすでに入っているフォルダーだけです。 外付けの USB ドライブのように OneDrive の外にあるフォルダーは、同期に含められません。

反対に、一覧にあってもチェックを外せないフォルダーがあります。ドキュメント、デスクトップ、画像、Personal Vault フォルダーなど、PC にとって重要な特定のフォルダーはオフにできません。 デスクトップやドキュメントを OneDrive にバックアップしている場合、そこに置いた資料をこの画面で外すことはできないので、外したい資料は別のフォルダーに分けておく必要があります。

4．会社と個人の2つのアカウントが入っているパソコンでは

1台のパソコンに、会社のアカウントと個人の Microsoft アカウントの両方で OneDrive を入れていることがあります。ヘルプによると、複数の OneDrive アカウントを使っている場合、エクスプローラーでは個人用のファイルと職場または学校のファイルが別々のフォルダーの下に表示されます。 Windows 10 では、それぞれ「OneDrive – 個人用」「OneDrive – 組織の名前」の形のフォルダーになると説明されています。

［フォルダーの選択］の設定は、パソコンごとだけでなく、アカウントごとにも別々です。会社のアカウントで経理のフォルダーを外しても、個人のアカウント側の設定はそのままです。どちらのアカウントのフォルダーを外したいのかを先に決め、そのアカウントの設定画面で操作します。外した後は、エクスプローラーの左側で、どちらのアカウントのフォルダーから消えたのかも見ておきます。

5．エクスプローラーで消すのとは、結果がまったく違う

「このパソコンから見えなくしたい」と思ったとき、エクスプローラーでフォルダーを選んで Delete キーを押すのは避けます。ヘルプでは、同期されたオンラインのみのファイルをデバイスから削除すると、そのファイルはすべてのデバイスとクラウドから削除されると説明されています。 共用のパソコンで消した操作が、経理担当者のパソコンや Web の OneDrive にまで及ぶことになります。

したいこと使う操作クラウドの資料
このパソコンでだけ見えなくする［フォルダーの選択］でチェックを外す残る
資料そのものを要らなくするエクスプローラーや Web で削除するごみ箱へ移る

同じヘルプには、同期を解除すると、ファイルはエクスプローラーから削除されるが、クラウドではまだ利用できる、とも書かれています。 また、目的がパソコンの空き容量だけなら、外さなくてもよい場合があります。既定では、同期されたファイルはインターネットに接続しているときに使えるものの、デバイスの記憶領域を占有しないと説明されています。

6．外した後に「既に存在します」と出たら

フォルダーの選択を外した後、「OneDrive にファイルまたはフォルダーが既に存在します。」というエラーが出ることがあります。 ヘルプが示す回避策は2つで、どちらを選ぶかで資料の残り方が変わります。

回避策ヘルプの説明
オプション 1：フォルダーを PC から削除するフォルダーは引き続き OneDrive に保存されているため、削除しても大丈夫
オプション 2：OneDrive からファイルまたはフォルダーを削除するフォルダーを OneDrive フォルダー以外の場所に移すと、OneDrive.com から削除され、PC 上でのみ利用できるようになる

共用のパソコンから見えなくしたいだけなら、クラウドに資料が残るオプション 1 の考え方に沿います。オプション 2 は、資料を OneDrive から外してパソコンだけに置く選び方なので、ほかの社員が Web やほかのパソコンで見られなくなります。

7．架空の例：受付の共用パソコンから経理のフォルダーを外す

来客対応用の共用パソコンを、総務の担当者が設定し直す場面です（架空の例）。

決めること架空の記入例
このパソコンに残すフォルダー来客予定、会議室の予約表
外すフォルダー経理、給与、取引先との契約書
外せないフォルダーデスクトップ（バックアップ中のため。資料は置かない決まりにする）
外した後の確認エクスプローラーに経理のフォルダーが出ないこと、Web の OneDrive では経理の担当者が開けること

どのパソコンにどのフォルダーを置くかは、パソコンが増えるほど分からなくなります。パソコンごとの置き場所を一覧にしておくと、事務の道具と作業の棚卸しを進めるときの材料にもなります。

公開・共有の前に、この表で確かめます。

確認確かめること
□目的は「このパソコンで見えなくする」か、「資料そのものを消す」か
