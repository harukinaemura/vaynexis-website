Edgeの「スタートアップ ブースト」で閉じても動くのはなぜ？

要点

Edge を閉じても処理が残って見えるのは、スタートアップ ブーストが有効になっている場合があるからです。Microsoft のヘルプでは、起動時のブーストは、ブラウザーが閉じられたときに最小限のプロセスでバックグラウンドで実行され続けると説明されています。 オンとオフは、Edge のアドレス バーに edge://settings/system/manageSystem と入れて開く設定で切り替えられます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Microsoft Edge のウィンドウを全部閉じたのに、Edge の処理がパソコンの中で動き続けているように見えるときの理由と、スタートアップ ブーストの切り替え方です。何のための機能か、どこでオンとオフを変えるか、会社のパソコンで変えられないときの考え方を、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．閉じたのに動いている、の正体

確認日：2026年11月17日。

対象は、Windows のパソコンで使う Microsoft Edge です。

Windows のタスク マネージャを開いたとき、Edge のウィンドウはどこにも無いのに Edge の項目が残っていて、驚く人がいます。スタートアップ ブーストは、バックグラウンドで Edge プロセスを実行することで、ブラウザーの起動を高速化する機能です。 次に Edge を開くときにすぐ使えるよう、少しだけ準備を残しておく仕組みなので、閉じた後に処理が見えるのは、この機能が働いている姿と考えられます。

ヘルプには、ブラウザー ウィンドウが既に開いている場合、スタートアップ ブーストはリソースを追加しないとも書かれています。 影響が出るのは、Edge を閉じている間の話です。

ヘルプによると、この機能で速くなるのは、デバイスの起動後やブラウザーを閉じた後に、タスク バー、デスクトップ、またはほかのアプリに埋め込まれたリンクから Edge を開く場面です。 メールや業務のアプリの中のリンクを押したとき、Edge がすぐ開きやすくなる、ということです。

2．最初からオンのパソコンと、そうでないパソコン

ヘルプには、既定で有効にする条件として、競合する拡張機能がインストールされずに Edge が数日おきに使われる場合、4 GB を超える RAM を搭載した Windows デバイスで使用できる、といった基準が書かれています。 そのため、同じ社内でも、パソコンによって最初からオンのものと、そうでないものがあります。有効になっていない場合は、edge://settings/system/manageSystem の設定で手動で有効にすることもできるとされています。

ほかの人の画面には項目があるのに、自分の画面には見当たらない、という声もあります。ヘルプは、この機能を順に提供している途中のため、それぞれのチャネルで表示されるまでに少し時間がかかる場合があると説明しています。 隣の席のパソコンと見比べて違っていても、すぐに故障と決めつけないようにします。

3．切り替える場所と、決める前に考えること

切り替えは、edge://settings/system/manageSystem を開いた画面で行います。

オンのままにするか、オフにするかは、使い方で決めます。

使い方（架空の例）向いている選び方理由
朝から晩まで Edge で業務のサイトを開くオンのまま閉じている時間が短く、開くのが速いほうが助かる
Edge はたまにしか使わず、閉じたら何も残したくないオフを検討閉じている間に処理が残るのを避けたい
パソコンが古く、起動直後が重いオフにして様子を見る起動直後に動くものを減らして比べられる

オフにすると、Edge を開くときに少し待つことがあるかもしれません。変えた日付と、変えた後の様子を短く書いておくと、元に戻すかどうかを判断しやすくなります。

4．自動でオフになる場合と、会社のパソコンの場合

ヘルプには、スタートアップ ブーストと競合する拡張機能がインストールされると、スタートアップ ブーストが自動的にオフになると書かれています。 Edge は、ブラウザーが存在しない場合にブラウザー ウィンドウを開く拡張機能を、競合する拡張機能として扱うと説明されています。 自分ではオンにしたはずなのにオフになっているときは、最近入れた拡張機能に、そうした動きをするものがないかを見ます。

会社のパソコンでは、管理者とユーザーがスタートアップ ブーストを有効または無効にできるグループ ポリシーがあります。 グループ ポリシーは必須と推奨の両方を指定でき、推奨の場合は、ユーザーが後で変更できる既定の動作を IT 管理者が設定できるとされています。 設定を変えられない、または変えても戻るときは、会社の決まりで固定されている場合があるので、社内のパソコンの担当者に確かめます。

動きがおかしいと感じたときは、Microsoft に知らせる方法も案内されています。Windows のパソコンで Alt キーと Shift キーを押しながら I キーを押すか、［設定など］の［ヘルプとフィードバック］から［フィードバックを送信］を選びます。

パソコンの「なぜか動いている」は、担当者ごとに調べ方がばらばらになりがちです。調べた結果と判断を残しておくと、社内で同じ質問が出たときの答えになります。業務の道具の困りごとをまとめて見直すときは、AIコンサルティング：できること64項目も参考にしてください。
