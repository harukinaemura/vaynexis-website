Windows 11で同じ名前に見えるWord文書とPDFを見分けるには？

要点

Windows 11のエクスプローラーで［表示］→［表示］→［ファイル名拡張子］を選ぶと、名前の末尾でWord文書の「.docx」とPDFの「.pdf」を区別できます。編集や提出に使うファイルを選ぶときは、拡張子で形式を確認した後、担当者の指定や文書の版を照合します。

公開：2026年11月9日／情報の確認日：2026年11月7日（出典はこの記事の最後）

Windows 11で同じ名前に見えるWord文書とPDFの拡張子を表示し、提出指示や文書の版と照合します。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．1．エクスプローラーでファイル名の末尾まで表示する

確認日：2026年11月7日

Windows 11のエクスプローラーでは、上部の［表示］から、メニュー内の［表示］、続いて［ファイル名拡張子］を選ぶと拡張子が表示されます。

ファイル名拡張子の一覧で、docxはMicrosoft Word文書の形式です。

同じ一覧のpdfは、Portable Document Formatのファイルです。

拡張子を書き換える操作では、ファイルの形式は変換されず、ファイル名以外は何も変わりません。

ここからは当社の整理です。

まず、依頼で指定されたフォルダーをエクスプローラーで開き、候補の名前を末尾まで読みます。拡張子の前までが同じなら、Word文書の「.docx」とPDFの「.pdf」を含めて完全な名前を控えます。同じ資料が共有フォルダーと手元の作業フォルダーにある場合は、保存先も一緒に残します。

2．2．形式を見分けたら、依頼の用途に当てはめる

文面の修正を頼まれたときは、作業の対象として指定されたWord文書を探します。提出を頼まれたときは、提出指示に書かれた形式を読みます。PDF指定なら「.pdf」の候補に絞れますが、そのPDFが今回の提出版かどうかは、提出担当が指定した名前や保存先で確認します。受け手がWord形式を指定している場合も、同じ順序で候補を絞ります。

「編集用」「提出用」は今回の作業での役割です。完全なファイル名を控える際は、形式とは別の欄に今回の用途を記します。名前に「最終」とあっても、担当者が依頼で挙げたファイルと対応しているかを見ます。保存先が複数ある場合は、どのフォルダーのファイルを指すかまで確かめます。

3．3．内容を開き、確認したファイルと選んだファイルを結び付ける

拡張子と提出指示が一致したら、実際の候補を開きます。表紙や冒頭の文書名、対象の案件・期間、版番号や改訂日が記載されていれば、その情報を提出指示や確定の連絡と見比べます。差し替えがあった場合は、修正を指示された箇所まで見ておくと、元のWord文書と出力済みのPDFの内容が同じ時点のものかを確認できます。

資料を選ぶ担当と添付する担当が異なる場合は、形式を確認しただけの候補と、内容まで照合したファイルを区別します。次の項目を残すと、引き継いだ人が添付する直前に対象を選び直せます。

記録欄確かめる内容判断に使う資料
完全なファイル名拡張子を含む名前と保存先エクスプローラーの表示、指定フォルダー
ファイルの形式Word文書かPDFか名前の末尾、開いたファイル
今回の用途編集、確認、提出のどれに使うか作業依頼、提出先の指定
内容の版案件・対象期間・版や改訂日開いた文書、確定または差し替えの連絡
受渡し実際に添付する名前と確認者照合したファイル、送付の準備画面

添付の直前は、選択中のファイルの完全な名前と、照合時に控えた名前を照らします。いったん選択し直した場合や、別のフォルダーから添付する場合は、保存先と内容の版も見直します。

4．4．使うファイルを決めきれないときは、候補を示して照会する

提出する形式が分かっても、同じ案件のPDFが複数ある場合は、提出担当に対象のファイルを確認します。照会には、依頼の名称、候補の完全な名前、保存先、確認できた版の違いを添えます。どちらが新しいかという質問より、どれを今回使うかを指定してもらうと、返答を添付の判断に使えます。

Word文書しか見つからず提出指示がPDFのときは、既存のPDFの保存先か、誰が提出用PDFを用意するかを担当者に確認します。名前の末尾を「.pdf」に書き換えても、第1節のとおりファイルの形式は変わりません。返答後に照合表の選択結果を更新し、今回の提出で使う一つのファイルを渡します。

5．Word文書の拡張子は「.docx」だけとは限らない

Microsoftの一般的なファイル名拡張子の一覧では、Windowsのファイル名はピリオドで区切られた2つの部分からなり、前半はファイルの名前、後半はファイルの種類を定義するための3～4文字の拡張子だと説明されています。

同じ一覧には、docxのほかに、docが「Word 2007 より前の Microsoft Word 文書」、docmが「Microsoft Word マクロ有効文書」、dotxが「Microsoft Word テンプレート」として別に載っています。

同じ一覧では、拡張子によって、どのアプリケーションでファイルを開けるかと、どのアイコンを表示するかが判断されるとされています。例として、docx拡張子は、Microsoft Wordでファイルを開けることと、エクスプローラーでWordのアイコンを表示することをコンピューターに知らせると説明されています。ほとんどのファイル名拡張子には、インストールされている複数のプログラムとの互換性があるとも書かれています。

拡張子の前が同じ名前でも、末尾が「.docx」のほかに「.doc」「.docm」「.dotx」の候補が並ぶことがあります。提出指示が「Word形式」とだけ書いていて、どの拡張子でよいかが分からない場合は、提出先の指定を確かめます。「.dotx」はテンプレートの形式なので、記入を終えた文書と取り違えていないかを開いて見ます。アイコンは拡張子から判断して表示されるものなので、形式は名前の末尾の文字で読み、アイコンは補助として見ます。
