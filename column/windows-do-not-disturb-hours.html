Windowsの応答不可を勤務時間帯に合わせ自動で切り替えるには

要点

勤務時間に合わせるには、［応答不可を自動的にオンにする］の［次の時間帯］をオンにし、自動で切り替わる時刻と頻度を設定します。通知を抑える時間と、すぐに受け取りたい連絡を分けて考えることが、勤務中の運用を決める出発点になります。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、勤務時間帯の通知を抑えたい小さな会社の担当者が、自動切り替えの時刻・頻度と優先通知の例外を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 時間帯の自動切り替えを設定する
  2. 通知を許可する例外も一緒に決める
  3. 事務の流れに当てはめる短い例
  4. 想定と違うときは時刻・例外・表示を切り分ける

  6. 確認表

1．時間帯の自動切り替えを設定する

確認日：2026年11月15日（日本時間）

ここでは、Microsoft の日本語ヘルプにある Windows 11 の手順を扱います。

時刻と頻度まで設定する

［スタート］から［設定］、［システム］、［通知］の順に開きます。［応答不可を自動的にオンにする］を開き、［次の時間帯］をオンにします。続いて、応答不可が自動でオン・オフになる時刻と、その頻度を設定します。

勤務の始まりから終わりまでを対象にするのか、照合や資料作成に集中する間だけを対象にするのかを、設定前に整理しておくとよいです。勤務中ずっと連絡を受ける担当と、途中で連絡をまとめて確認できる担当では、静かにしたい範囲が異なります。所属先の就業時刻だけをそのまま当てはめず、自分が連絡を確認する役割も含めて考えます。

入力した時刻だけで確認を終えず、頻度も読み直します。引き継ぎ用には、画面に表示された選択内容をそのまま残すと、次の担当者が意図をたどりやすくなります。「勤務中は静かにする」という説明だけでは、どの時間を対象にしたのかが伝わりません。

抑えた通知の行き先を知る

ミュートされた通知は通知センターへ移動し、後から表示できます。作業に戻れる状態を作ることと、後で連絡を確認することを組み合わせて運用します。静かにする範囲を決める段階で、連絡を確認する場面も一緒に決めておくと、引き継ぎの説明に含められます。

2．通知を許可する例外も一緒に決める

［優先通知の設定］では、応答不可がオンの間も、通話、リマインダー、特定のアプリの通知を許可するかどうかを設定できます。アプリを例外に加える操作は、［アプリ］の［アプリの追加］から、通知を許可するアプリを選ぶ流れです。

仕事で使うものをすべて例外に含めると、静かにしたい時間と、連絡を受けたい場面の区別が曖昧になります。先に、途中でも気づく必要がある連絡の種類を整理し、その連絡がどこから届くかを担当者と確認します。名前が見慣れているという理由だけで、例外に含める判断をしない方が運用を説明しやすくなります。

例外を決める際は、「今すぐ対応する連絡」と「作業を区切って読む連絡」を書き分けます。連絡を受け取る人だけで判断せず、連絡する側とも確認のタイミングを共有しておくとよいです。設定の担当者と業務の担当者が異なる場合も、この区別を残しておけば変更理由を引き継げます。

3．事務の流れに当てはめる短い例

ここからは当社の整理です。

午前の照合作業に集中し、その後に連絡をまとめて読む場合を考えます。設定値の入力前に、抑制を始める場面と終える場面、途中でも受けたい連絡を、次のように分けます。

決める項目整理の例
抑制を始める場面照合対象をそろえて作業に入るとき
抑制を終える場面照合を区切り、連絡を確認するとき
途中でも受けたい連絡担当者間で合意した緊急の連絡
まとめて確認する連絡急ぎの対応を伴わない通常の案内
見直すきっかけ担当業務や連絡の受け方が変わったとき

これは時刻を代わりに決める表ではなく、入力内容を決める前の整理です。連絡対応を兼ねる日は、照合だけを行う日と同じ扱いでよいかも確認します。担当の交代で連絡を受ける役割が変わるなら、前任者の設定を引き継ぐ理由も見直しの対象になります。

確認時には、希望する状態と実際の結果を別々に記録するとよいです。「静かにしたい時間を決めた」と「その時間に意図した状態になった」を分けておくと、設定の記入漏れと、運用上の行き違いを混同せずに済みます。

4．想定と違うときは時刻・例外・表示を切り分ける

対象の時間外も静かなままの場合

Microsoft の案内では、時間帯以外にも、ディスプレイの複製、ゲームのプレイ、アプリの全画面表示、Windows の機能更新プログラムが適用されてから最初の1時間が自動条件として挙げられています。同じ案内では、応答不可を手動でオンにした場合は、手動でオフにするまで通知がミュートになります。許可した優先通知の例外も併せて確認します。

確認の順は、入力した時刻と頻度、時刻以外の自動条件、手動で切り替えたかどうかです。関係のありそうな項目をまとめて変更するより、変更前の状態と変更した理由を残しながら確かめる方が、引き継ぎの説明を作りやすくなります。

対象の時間に通知が出る場合

許可した例外に当たる連絡かどうかを、先に照合します。予定どおりに受け取るものまで不具合として扱うと、必要な連絡の受け方も変えてしまうおそれがあります。確認する相手には、どの連絡が、どの場面で表示されたかを伝えるとよいです。

終了後も通知が見当たらない場合

Microsoft の案内では、通知センターはタスクバーの時計または通知ベルのアイコンを選んで開けます。同じ案内のアプリごとの通知設定には、ポップアップの表示を有効・無効にする［通知バナーの表示］があります。

「画面に出なかった」「後から確認できた」「連絡元にも届いていない」は、別の結果としてメモを分けます。表示されなかったという事実だけから原因を決めず、どこまで確認できたかを残すことが、次の確認につながります。試すときは業務上の急ぎの連絡を使わず、関係者と相談した確認用の連絡で結果を記録します。

5．引き継ぎには設定の意図と確認結果を残す

引き継ぎには、静かにしたい時間、繰り返す頻度、途中でも受けたい連絡、後で確認する場面を残します。さらに、誰が内容を決めたのか、担当が変わったときに誰へ相談するかも添えると、設定を維持する理由が分かります。画面の操作だけを説明するより、連絡対応の役割を含めた記録が役立ちます。

確認結果は、開始前、対象の時間中、終了後という場面ごとに整理するとよいです。未確認の場面を確認済みとして記録せず、試した範囲が読み取れる書き方にします。希望に合わなかった場合は、変更した箇所とその後の結果を残し、次の担当者が同じ箇所を繰り返し変更しないようにします。

事務の手間を洗い出すなら、通知を受けた後の分類や確認メモの作成も、AIを業務に取り入れる進め方を考える題材になります。人が決める連絡の扱いと、整理を補助させたい作業を分けておくとよいです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□通知を抑えたい時間と、連絡を確認する場面を整理したか
□開始・終了の時刻だけでなく、繰り返す頻度も読み直したか
□途中でも受けたい連絡と、まとめて確認する連絡を分けたか
□時刻以外の自動条件と、手動で切り替えた状態を確認したか
□対象の時間中と終了後で、意図した受け方になったか確認したか
□設定の意図、確認した範囲、見直す担当を引き継ぎに残したか
