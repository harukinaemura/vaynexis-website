Excelの条件付き書式が予定した色にならないときの確認順序

要点

複数の条件付き書式のルールが当てはまる場合は、［条件付き書式ルールの管理］ダイアログ ボックスの一覧の順序（上から下へ）の優先順位で各ルールが評価されるため、予定した色にならないときはルールの並びを確認します。特定のルールでルールの評価を停止する［条件を満たす場合は停止］チェック ボックスもあるため、並びとは別に確認します。色の指定をやり直す前に、どの範囲で、何を優先して見せたいかをそろえるとよいです。

公開：2026年11月5日／情報の確認日：2026年11月4日（出典はこの記事の最後）

この記事は、Excelの条件付き書式が予定した色にならない小さな会社の担当者が、ルールの適用範囲・並び順・［条件を満たす場合は停止］を分けて確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月4日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 色が違うセルから、適用する範囲をたどる
  2. 同じ書式が重なる部分の優先順位を直す
  3. 下のルールに進まないときは停止条件を調べる
  4. 確認用の表に「残したい表示」を書く
  5. 修正後は、変えたくない箇所も見比べる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．色が違うセルから、適用する範囲をたどる

Microsoft サポートの「条件付き書式を使用して Excel 内の情報を強調表示する」の適用先は、Excel for Microsoft 365、Excel 2024、Excel 2021、Excel 2019、Excel 2016 です。ページには Windows と Web の手順の切り替えがあり、ここでは Windows の手順の記載に沿って、［ホーム］タブの［スタイル］グループで［条件付き書式］の横にある矢印をクリックし、［ルールの管理］をクリックします。探しているルールが見当たらない場合は、［書式ルールの表示］で対象のワークシートやセル範囲が選ばれているかを確かめます。

［条件付き書式ルールの管理］ダイアログ ボックスには、現在の選択に対する条件付き書式ルールが、ルールの種類、書式、ルールが適用されているセル範囲、［条件を満たす場合は停止］の設定などとともに表示されます。同じ見た目の表でも、色が合う箇所と合わない箇所を比べ、調べたいセルが対象に含まれているかを見るのが確認の出発点です。

変更前には、期待する表示と現在の表示を短く控えておくとよいです。「色が違う」だけでなく、「確認が必要な項目を目立たせたいのに、別の色になっている」と、困っている点を具体的にします。比較するセルも控えると、変更後に同じ場所を見直せます。

2．同じ書式が重なる部分の優先順位を直す

競合する書式がともに条件を満たすと、一覧で位置が上のルールが優先されます。順序を直すときは、対象のルールを選び、［上へ移動］または［下へ移動］の矢印で位置を変えます。

新しいルールは既定で一覧の先頭に追加され、優先順位が高くなります。追加の直後に色が変わった表では、以前からある指定と追加した指定の関係も照合するとよいです。

見たい色を先に決めておくと、順番を変える理由が明確になります。例外として目立たせたい表示と、通常の分類を示す表示を分け、重なった場面でどちらを残すかを整理するとよいです。

競合しない書式は、条件を満たすルールの両方が適用されます。そのため、色だけを見るのではなく、文字の強調や背景など、何を変える指定なのかも見比べます。見た目が組み合わさっていること自体を、不具合と考えない確認が必要です。

Microsoft サポートの案内では、条件付き書式が設定されたセルの値のコピーや貼り付け、セル範囲のフィル、書式のコピー/貼り付けを行うと、コピー元のセルに基づいてコピー先のセルに新しいルールが作成され、ルールの優先順位に変化が生じる可能性があるとされています。表をコピーして作り直した後に色が変わった場合は、一覧の並びも読み直し、意図した並びになっているかを確認するとよいです。

3．下のルールに進まないときは停止条件を調べる

Microsoft サポートの案内では、特定のルールでルールの評価を停止するには、［条件を満たす場合は停止］チェック ボックスをオンにします。たとえば、最初のルールのみを評価する場合は最初のルールの、最初のルールと2番目のルールのみを評価する場合は2番目のルールの［条件を満たす場合は停止］チェック ボックスをオンにする、と説明されています。このチェック ボックスは、下位互換性のために、3つ以上の条件付き書式ルールや同じ範囲に適用される複数のルールをサポートしていない以前のバージョンの Excel での表示をシミュレートするもの、とも説明されています。

ここで確かめたいのは、強調を追加したいのか、その場面ではほかの強調を出さないのか、という表示の方針です。両方を残したいのに後続を止める設定になっていないか、業務上の意図と照らし合わせます。順番だけを変え続ける前に、この点を切り分けると調べる対象を絞れます。

ルールの書式にデータ バー、カラー スケール、またはアイコン セットが使われている場合は、［条件を満たす場合は停止］チェック ボックスをオンまたはオフにできません。該当する種類を扱っている表では、背景色や文字の書式を扱うルールと分けて確認するとよいです。

条件を満たすルールの書式は、競合する手動の書式よりも優先されます。表示だけを手で塗り直して済ませる前に、どのルールを残したいかを整理するとよいです。

4．確認用の表に「残したい表示」を書く

ここからは当社の整理です。

次は、設定を変更する前に担当者の意図を整理するための、小さな確認用の表です。入力は「区分」と「確認欄」に分け、色を見たい対象を「件名」にそろえる想定にします。表に書くのは期待する表示であり、操作を試した結果ではありません。

区分確認欄件名に残したい表示
優先未確認黄色の背景
通常済太字
優先済黄色の背景と太字
通常未確認通常の表示

特に比べたいのは、優先で確認済みの項目です。目立たせたい背景と確認済みの目印を両方残す方針なら、その意図を共有してから設定を見直します。背景の色だけを見て完了とせず、文字の強調も照合する形です。

逆に、優先の項目では確認済みの目印を出さない運用なら、表の期待する表示を先に直します。設定の正しさを判断する前に、表を読む人どうしで意味をそろえるためです。色を付ける理由があいまいなまま修正すると、別の担当者が引き継いだときに、元へ戻してしまうおそれがあります。

5．修正後は、変えたくない箇所も見比べる

確認では、色がおかしかったセルだけでなく、これまで正しく見えていた箇所も比較対象にします。期待する表示が重なる場面、片方だけを残したい場面、何も強調しない場面を分け、表の読み方が変わっていないかを見ます。

調べるときは、適用する範囲、並び順、後続を止める指定をまとめて変えず、変更内容と結果を対応させて記録するとよいです。表示が意図と合った後も、どの修正が必要だったかを説明しやすくなります。

引き継ぎには、変更理由、優先して残す表示、確認した箇所を添えます。画面の見た目だけを残すより、「この表示が重なったら、こちらを見せたい」という判断の理由があると、後の変更でも方針を追えます。色の意味が分かる状態まで確かめることが、今回の修正の区切りです。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□期待する表示と現在の表示を具体的に控えたか
□対象のセルが、適用する範囲に含まれるか確認したか
□重なったときに優先して残す表示を決めたか
□並び順と後続を止める指定を分けて確認したか
□背景と文字の強調を併用したい場面も確認したか
