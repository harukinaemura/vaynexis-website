OneDriveの共有設定が灰色で選べないときの確認と連絡の進め方

要点

共有設定が灰色で選べないときは、組織の管理者による共有制限の可能性を確認します。まず、どの画面のどの項目が選べないのかを記録します。原因を断定して設定を変える前に、表示と目的をそろえ、社内の確認先へつなぐ進め方です。

公開：2026年11月6日／情報の確認日：2026年11月6日（出典はこの記事の最後）

この記事は、OneDriveで資料を共有しようとして共有の設定が灰色で選べなかった小さな会社の事務担当者が、止まった画面とアカウントを記録し、原因を決め付けずに社内の確認先へつなぐ流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月6日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 最初に、止まった画面とアカウントをそろえる
  2. Webでは対象資料と灰色の項目名を見る
  3. Windowsのデスクトップではアプリの状態と制限を分ける
  4. 管理者には現象と目的を渡す
  5. 短い受付例で、対応済みと返答待ちを分ける
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．最初に、止まった画面とアカウントをそろえる

確認日：2026年11月6日。

Microsoft サポートの「Microsoft OneDrive でファイルやフォルダーを共有する」のページの適用先には、OneDrive for Business が含まれます。会社の端末を使っているという情報だけで判断せず、会社用と個人用のどちらで作業しているか、どの資料を選んでいるかをそろえます。

職場または学校のアカウントでサインインした場合、組織が OneDrive Web の共有表示や［リンクを知っているすべてのユーザー］を無効にしている可能性があります。ブラウザー内の選択肢なのか、端末で右クリックした際の項目なのかを分けると、次に確認する箇所を伝えやすくなります。

共有できないとだけ記録するより、項目自体がないのか、見えているのに選べないのかを書き分けます。同じ言葉で連絡していても、止まった場所が違えば確認の出発点も変わるためです。

2．Webでは対象資料と灰色の項目名を見る

Web の共有手順では、丸いアイコンを選択して、共有するファイルまたはフォルダーを選びます。対象の取り違えがないことを確認してから、選べない項目の表示を控えます。

職場または学校の OneDrive アカウントでは、複数のアイテムを同時に共有する機能は使用できません。対象をまとめて選んでいた場合は、確認したい資料だけを選ぶところから見直します。

例えば［すべてのユーザー］は、リンクが組織外へ転送されるのを防ぐために、管理者が無効にしている場合があります。選べない項目を別のものに置き換えて送信する前に、本来の共有相手と、許可されている共有範囲を社内で確認するとよいです。

項目が選べることと、その相手への送信が社内で認められていることは分けて扱います。急ぎの依頼でも、共有したい資料と相手を明確にして相談する流れにします。

3．Windowsのデスクトップではアプリの状態と制限を分ける

OneDrive が実行されていない、またはデスクトップアプリがインストールされていない場合は、エクスプローラーや検索から共有できません。タスクバーや通知領域に OneDrive アイコンが表示されない場合は、OneDrive を起動する手順が案内されています。起動後は、同じ対象で表示が変わったかを確認します。

エクスプローラーの［共有］が灰色、または右クリックのメニューに表示されない場合は、管理者が機能を制限している可能性があります。表示の有無だけで、故障や設定ミスと断定しないことが大切です。

Windows エクスプローラーで OneDrive のメニュー項目が表示されない原因には、組織による設定制限のほか、サポートされない「昇格された特権」での実行の可能性も挙げられています。利用者側では表示と起動状態を記録し、端末の設定変更が必要かどうかは管理者へ確認する扱いにします。

4．管理者には現象と目的を渡す

職場・学校での技術的な問い合わせ先は、組織の IT ヘルプデスク、サービス デスク、または管理者です。連絡時は、対象資料、共有したい相手が社内か社外か、必要な作業、止まった画面、選べない項目名をまとめます。

見せるだけで足りるのか、相手による修正も必要なのかを添えると、管理者が目的に合う扱いを検討しやすくなります。業務上の必要性と現在の表示を組にして、連絡する内容を整えます。

画面の記録を添える場合も、問い合わせに必要な部分を選ぶ運用が考えられます。返答を受けた後は、許可された方法と対象範囲を社内の担当者間でそろえてから、作業を再開します。

5．短い受付例で、対応済みと返答待ちを分ける

ここからは当社の整理です。

確認用の資料を別の担当者へ渡そうとして、共有の設定で止まった場面を考えます。受付では原因を先に決めず、画面に出た事実と、自分が確認した結果を並べます。

受付で分かったこと記録する内容次に確認すること
ブラウザー内の選択肢が選べない対象資料、選べない項目名、共有したい相手社内で認められた共有範囲
端末の右クリックに項目がない対象資料、起動状態、表示の有無端末側の確認を任せる担当者
確認先からの返答を待っている問い合わせ先、依頼した内容、現在の状態返答後に再確認する作業

後任には、確認済みの内容と返答待ちの内容を分けて渡します。対応中とだけ書いて終えず、誰が何を確認する段階かを残すとよいです。作業を再開できた際も、目的の相手に必要な範囲で渡せたかを確かめて、対応を閉じます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□利用中のアカウントと対象資料を特定したか
□ブラウザー内の選択肢と端末の右クリックの表示を分けて確認したか
□対象資料の選択状態と、選べない項目名を確認したか
□端末側で作業している場合は、アプリの起動状態を確認したか
□共有したい相手と必要な作業を社内の確認先へ伝えたか
□許可された方法、未解決の内容、次の担当者を記録したか

7．自社の事務の手順まで形にしたいとき

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

自社の事務のどこから確認を入れるかを相談したい場合は、初回無料相談をご利用ください。法律・税務・労務の判断や、効果の約束は行いません。

出典（確認日：2026年11月6日）

  • Microsoft OneDrive でファイルやフォルダーを共有する：適用先、共有対象の選択、複数アイテムの制約、共有オプションの灰色表示
  • OneDrive のファイルを共有できない：職場・学校アカウントの共有制限、デスクトップの起動状態・灰色表示、組織の問い合わせ先
