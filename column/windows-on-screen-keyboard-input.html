Windowsのスクリーンキーボードで文字を入力する手順と確認点

要点

画面上のキーをクリックして文字を入力するには、スクリーン キーボードの入力方法で［キーをクリック］を使います。開いた後は、入力先の欄と実際に入った文字を見比べます。文字キーが見えないときの表示の切り替えと、文字の入り方が想定と違うときの入力方法の確認を、別々に進めるとよいです。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、画面上のキーで文字を入力したい小さな会社の担当者が、スクリーンキーボードの開き方・入力方法・表示の切り替えを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 物理キーを使わずに開く準備をする
  2. クリックで入力する方式を選ぶ
  3. 文字キーが見当たらなければ表示を切り替える
  4. 数字を入力するときと、入力を終えるとき
  5. 短い事務入力で確かめ、手順を引き継ぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．物理キーを使わずに開く準備をする

確認日：2026年11月15日

Microsoft の日本語ヘルプをもとに、ここでは Windows 11 のスクリーン キーボードをオンにする手順を扱います。画面の表示は更新によって変わることがあります。スクリーン キーボードは、タッチスクリーンのないパソコンでも使えます。画面上のキーは、マウスなどのポインティング デバイスで選択できます。画面に触れて操作できる機種かどうかより、普段使っているマウスで目的の場所を選べるかを、準備の中心にするとよいです。

設定画面から開く

［スタート］から［設定］、［アクセシビリティ］、［キーボード］の順に進み、［スクリーン キーボード］をオンにします。手順を引き継ぐ際は、入口の場所と最後に選ぶ項目を続けて記すと、途中で違う設定へ進んでいないかを照合しやすくなります。

キー操作が使えるときに開く

Windows ロゴ キー + Ctrl キー + O は、スクリーン キーボードをオンにするショートカットです。物理キーを使うこと自体が難しい場面では、先に挙げた設定画面からの経路を手元の手順に残すとよいです。引き継ぎ資料でも、画面をたどる方法とキー操作による方法を別の行に分けると、使える操作から選べます。

2．クリックで入力する方式を選ぶ

スクリーン キーボードを開いた状態で［オプション］キーを選ぶと、入力方法などを選択できます。［キーをクリック］は、画面上のキーをクリックまたはタップして文字を入力するモードです。最初は長い文章を仕上げようとせず、手元で照合できる短い文字列から始めると、押したつもりの文字と表示された文字の違いに気づきやすくなります。

ポイントによる入力では、文字を指定した時間ポイントし続けると、その文字が自動的に入力されます。クリックするつもりで操作しているのに、待っている間に文字が入ると感じたときは、表示そのものより先に入力方法の選択を見直すとよいです。見た目のキーが並んでいることと、どの操作で文字を入れるかは、分けて確かめる必要があります。

また、文字を選んだ回数だけを手がかりにせず、入力先に現れた内容を読み直すことが大切です。画面上の操作に気を取られやすい場面では、入力する前の状態と、入力後の状態を区切って見る流れにしておきます。

3．文字キーが見当たらなければ表示を切り替える

［全般］レイアウトには、標準キーがすべて含まれます。ナビゲーション レイアウトから文字入力用の表示に戻すには、スクリーン キーボードの［全般］キーを選択します。文字を選ぶ場所が見当たらないときは、入力する文章を変える前に、表示されているキーの構成を見直すとよいです。

スクリーン キーボードは、閉じて開き直してもレイアウトがリセットされません。開き直す操作を繰り返すより、現在の表示と切り替え先の名前を確認する方が、次の操作を選びやすくなります。引き継ぎでは、画面を開く経路だけで終えず、文字を選べる状態になっているかも確認項目に含めます。

表示で困っているのか、キーを選んだ後の文字の入り方で困っているのかを、短い言葉で記録しておくとよいです。困った状態を単に「入力できない」とまとめるより、どの段階まで進めたかが伝わります。

4．数字を入力するときと、入力を終えるとき

［テンキーを有効にする］では、スクリーン キーボードを拡張してテンキーを表示できます。数量などの入力に使う際は、数字を選ぶ操作に加え、元の記載と入力後の値を照合する流れを用意します。数量の欄へ入れるつもりだった内容を、隣の欄へ入れていないかも確認の対象です。

スクリーン キーボードは、手動で閉じるまで画面に表示されたままになります。入力が終わったところで、入力先の内容を確認する区切りを設けるとよいです。操作する画面を閉じたことだけを、作業内容の確認が済んだ印にしないよう、引き継ぎの手順にも照合の工程を残します。

5．短い事務入力で確かめ、手順を引き継ぐ

ここからは当社の整理です。

備品の記録へ短い内容を入れる場面なら、入力先の欄を選び、画面上の文字キーを選択した後、表示された内容を見比べる流れが考えられます。下の例は、操作と結果の確認を分けて考えるためのものです。

入れる内容の例入力前に見る点入力後に見比べる点
備品名の短い略称名称を入れる欄が選ばれているか略称が途中で欠けていないか
数量数量の欄が選ばれているか元の記載と値が一致するか
短い備考備考の欄が選ばれているか別の欄へ入っていないか

見直す順番は、入力先、文字の並び、入力漏れとすると、どこを読み直すかを決めやすくなります。誤りが見つかった際も、いきなり残りの文章を続けず、どの欄のどの部分を直すかを先に決めるとよいです。

手順を残すときは、開いた経路、入力に使った方法、期待した表示、実際の表示を分けて記します。うまく進まない場面についても、画面が開かなかったのか、文字キーが見えなかったのか、入力先に期待した文字が入らなかったのかを区別すると、続きを担当する人が状態を追いやすくなります。

毎回同じ内容を手で入れている作業については、入力操作を覚えることに加え、元の情報をどこから受け取り、何を確かめて転記しているかを洗い出すとよいです。その整理から事務の手間を減らす方法を考える際は、AIを業務に取り入れる進め方も検討の入口になります。

公開・共有の前に、この表で確かめます。
