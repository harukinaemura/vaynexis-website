Excelの申請表で入力欄だけ編集できるようにする設定と確認

要点

入力欄だけを書き換えられる申請表は、入力欄の［ロック］を外してから［シートの保護］を有効にして作ります。 配布前は、記入したい欄に入力できることと、見出しや計算欄を書き換えられないことを、それぞれ確かめます。

公開：2026年11月3日／情報の確認日：2026年11月3日（出典はこの記事の最後）

この記事は、Excelの申請表を配る前に、入力欄だけを編集できるようにしたい小さな会社の事務担当者が、ロックとシートの保護の設定順と、配布前の確認を整理するためのものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月3日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や作例は、当社の考えをまとめたもので、公式の機関が示しているものではありません。

  1. 設定前に、申請者が書く欄を決める
  2. 固定欄を確認してから、入力欄のロックを外す
  3. 許可する操作を選び、シートの保護を有効にする
  4. 入力できる場所と、変更できない場所を試す
  5. 編集範囲の管理と、情報の取り扱いを分ける
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．設定前に、申請者が書く欄を決める

まず、元の申請表を残し、設定を試すためのコピーを用意します。申請者が記入する欄と、担当者が管理する欄を、実際の記入の流れに沿って分けるとよいです。項目の追加や配置の変更まで同時に進めず、今回は既存の欄のうち、どこを編集可能にするかを決めます。

たとえば、備品の申請表なら、記入の役割を次のように整理できます。

欄誰が扱うか配布時に目指す状態
申請者名・使用目的申請者記入できる
品名・数量申請者記入できる
項目の見出し・注意書き様式の管理担当者書き換えられない
合計の計算欄様式の管理担当者式を書き換えられない

色が付いている欄を眺めるだけで終えず、記入を受け付ける場所を欄名で説明できる状態にします。承認担当者の記入欄がある場合も、申請者に編集させるかどうかを先に決めておくと、設定中の迷いを減らせます。

2．固定欄を確認してから、入力欄のロックを外す

ここで扱う操作は、公式ヘルプの Windows 版の手順に沿ったものです。 確認日：2026-11-03。

すでに保護されている表を変更するときは、［校閲］から［シートの保護を解除］を選びます。解除時に求められた場合は、パスワードを入力します。

既存の設定を整理するときは、［すべて選択］でシート全体を選択します。選択したセルは、［セルの書式設定］の［保護］で［ロック］をオンにして確定します。

次に入力を許可するセルを選択して右クリックし、［セルの書式設定］を開き、［保護］タブの［ロック］をオフにします。

選択する範囲に見出しや計算欄を巻き込んでいないか、確定前に見直します。離れた欄をまとめて扱おうとして選択範囲が分かりにくくなったときは、欄ごとに設定を進める方法もあります。

3．許可する操作を選び、シートの保護を有効にする

入力欄の設定後は、［校閲］タブで［シートの保護］を選択します。表示された［このシートのすべてのユーザーに許可する操作］では、利用者に許可する項目をオンにします。

申請者が普段行う操作を書き出し、必要な範囲を基準に選ぶとよいです。記入を受け付けたいだけなのか、受け付けた後に様式も直してもらうのかで、管理上の方針は変わります。操作できる範囲を広げる前に、誰がどこまで担当するのかを確認します。

保護解除用のパスワードは省略できますが、設定しない場合は、すべての利用者が保護を解除して保護対象を変更できます。 配布後に様式を直す担当者を決め、設定内容と管理方法を引き継げるようにします。

保護を確定する際は、必要に応じてパスワードを入力して［OK］を選び、設定した場合は確認の入力も行います。

パスワードを忘れたり紛失したりしても、Microsoft は取り戻せません。

4．入力できる場所と、変更できない場所を試す

保護が有効になると、［校閲］にある［シートの保護］の表示が［シート保護の解除］に変わります。 表示を確認した後は、配布相手になったつもりで記入を試すとよいです。

最初に、用意した入力欄へ文字や値を入れ、修正と消去も試します。次に、見出しや計算欄の書き換えを試し、先に決めた範囲と結果を照合します。画面上の見た目が整っていることと、意図した欄だけ編集できることを分けて確認する流れです。

ロックされたセルも既定では選択できるため、選択できることだけでは、編集できるとは判断できません。 固定欄をクリックできても、実際の書き換えを試した結果で判断します。

入力できない欄や、意図せず変更できた欄は、場所と行った操作をメモに残します。修正対象をあいまいにしたまま設定を広く変えず、最初に決めた欄の区分と照らし合わせると、直す箇所を絞りやすくなります。試し入力は配布前に片付け、受け取った人が記入を始められる状態で渡します。

結果が違うときは、欄の区分に戻る

入力したい欄に記入できない場合は、最初に決めた入力範囲と、実際に選択した範囲を照合します。固定欄を書き換えられる場合も、表全体を設定し直す前に、どの場所で意図と違ったのかを整理するとよいです。

担当者が直す欄と、申請者が記入する欄を同じ扱いにしていたなら、配布前に区分を見直します。都合に合わせてその場で編集範囲を広げるより、修正を受け付ける担当者を通して見直す流れを決めると、引き継いだ後も設定の目的を追いやすくなります。

5．編集範囲の管理と、情報の取り扱いを分ける

シート保護は、ロックしたセルの変更を制限するもので、セキュリティ機能を目的としたものではありません。

申請表を誰に渡すか、記入された情報を誰が扱うかは、編集範囲とは別に整理します。欄を書き換えられない状態になったことだけを理由に、配布先を広げない運用が大切です。引き継ぎでは、入力を受け付ける欄、固定する欄、様式を修正する担当者をそろえて伝えると、後から設定を見直す際の判断材料になります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□申請者が記入する欄と、管理担当者が直す欄を区別したか
□作業前の申請表を残し、コピーで設定を進めたか
□見出しや計算欄を、入力を許可する範囲に含めていないか確認したか
□入力を受け付ける欄で、記入・修正・消去を試したか
□固定したい欄で書き換えを試し、意図した結果か確認したか
□試し入力を片付け、様式の修正担当者と管理方法を共有したか
