新しいOutlookの通知で新着メールのポップアップを止めるには

要点

新しい Outlook では、［表示］で［表示の設定］を選び、［全般］、［通知］の順に開いて、［自分について通知する］の［メール］の切り替えをオフにします。 同じ場所に［Calendar］と［ドキュメント］の切り替えも並んでいるので、メールだけを止めて、会議の通知は残すこともできます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

画面を映して説明している最中に、届いたメールの差出人と件名が右下に出てしまう。新しい Outlook でメールの通知だけを切り、予定表の通知は残す設定と、戻したのに出ないときの確認先を見ていきます。

1．画面の隅に出ているのは何か

確認日：2026年11月17日。

対象は、Windows のパソコンで使う新しい Outlook for Windows です。クラシック Outlook は［ファイル］の［オプション］、［メール］から設定する別の手順で、ここでは扱いません。

Microsoft のヘルプでは、新しいメールや会議出席依頼、タスクの依頼を受け取ったときにデスクトップに表示されるものを「デスクトップ通知」と呼び、既定では有効だと説明しています。 メールの場合は、送信者の名前、件名、メッセージの最初の 2 行が表示されます。

本文の書き出しまで出るので、画面を共有している場面では、社外秘の連絡や個人の名前が参加者の目に入るおそれがあります。なお、暗号化またはデジタル署名されたメッセージの内容は、デスクトップ通知には表示されないと書かれています。 普段のメールはそうではないので、通知そのものを止めるかどうかを、使う場面で決めます。

一覧に並ぶメールの本文の書き出しを隠したいのであれば、それは通知ではなく、メッセージ一覧の表示の設定です。公開済みの別の記事で扱っているため、ここでは画面の隅に出るポップアップに絞ります。

2．メールの通知だけを切る手順

順番操作
1新しい Outlook を開く
2［表示］で［表示の設定］を選ぶ
3［全般］、［通知］の順に選ぶ
4［自分について通知する］で、［メール］の切り替えをオフにする

ヘルプの新しい Outlook のタブには、この手順が機能していない場合は、まだ新しい Outlook for Windows を使っていない可能性がある、という注意があります。 メニューに［表示の設定］が見当たらないときは、使っている Outlook がクラシック Outlook でないかを先に確かめます。

3．メールと予定表を分けて考える

［自分について通知する］には、［メール］、［Calendar］、［ドキュメント］の3つの切り替えがあります。 来客の対応や電話の取り次ぎで席を離れがちな人は、メールの通知を切っても、会議の開始を知らせる予定表の通知まで切ると、次の打ち合わせに遅れかねません。困っているのが新着メールのポップアップだけなら、［メール］だけをオフにして、［Calendar］は残す、という分け方が無理のない選び方です。

反対に、音だけが気になる場合は、通知を止めずに音を変える方法もあります。新しい Outlook では通知のカスタム サウンドを設定できるようになったと書かれていて、［メール］の［New Email and Reactions］の［Play Sound］から音を選びます。 静かな事務所で着信音が響くのが気になる、という悩みなら、通知を切る前にこちらを試す手もあります。

4．Outlook の中で止めるか、Windows の側で止めるか

通知は、Outlook の設定と Windows の設定の両方を通って表示されます。ヘルプは、Outlook で通知を有効にしているのに新しいメッセージの通知が出ない場合は、Windows の設定で Outlook の通知も有効になっているかを確かめるよう案内しています。 Windows の側では、［システム>通知］の［アプリやその他の送信者からの通知］で［Outlook］を選んで確かめます。

Windows の側で Outlook の通知を切ると、メールだけでなく、Outlook から出る通知がまとめて止まると考えておくのが安全です。メールのポップアップだけを止めたいなら、まず Outlook の中の［メール］の切り替えを使い、Windows の側は触らない、という順番にしておくと、予定表の通知まで消える思わぬ事態を避けられます。Windows の通知の設定そのものは、公開済みの Windows の記事で扱っています。

5．あとで通知を戻したのに出ないとき

会議が終わって［メール］の切り替えをオンに戻したのに、通知が出ない場合もあります。新しい Outlook の通知のトラブルのヘルプでは、システムの設定が通知の配信を妨げることがあるとして、いくつかの確認先を挙げています。

1つは Teams の状態で、応答不可に設定されていないことを確かめます。 Windows の［応答不可］がオフになっているかも確かめます。 ノート パソコンでは、バッテリー節約モードのときに通知が一時的に無効になることがあると書かれています。 会社のパソコンなら、システム管理者が通知をオフにしている場合もあるため、切り替えが選べないときは社内の担当者に聞きます。

6．場面ごとの決め方（架空の例）

場面（架空の例）困ること決めた設定
経理が月末に画面を映して説明する取引先からのメールの件名と書き出しが映る［メール］だけオフ、［Calendar］は残す
受付の机で来客と画面を見る社員あての連絡が表示される［メール］をオフにし、受信トレイは決めた時刻に開く
静かな事務所で一人で作業する着信の音が気になる通知は残し、［Play Sound］で音を変える

メールの通知を切ると、急ぎのメールに気づくのが遅れます。切るなら「10時と14時に受信トレイを見る」のように見る時刻を決め、急ぎの連絡は電話かチャットでもらう、と周りに伝えておきます。こうした小さな設定の違いは、担当者ごとにばらばらになりやすいものです。パソコンの設定や事務の道具の使い方をそろえるときは、事務の道具と作業の棚卸しの考え方も使えます。
