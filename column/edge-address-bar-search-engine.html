Edgeの「アドレス バーと検索」で検索先を変えるには

要点

既定にしたい検索エンジンでアドレス バーから一度検索してから、［設定など］の［設定］を開き、［プライバシー、検索、サービス］、［検索と接続済みサービス］、［アドレス バーと検索］と進みます。［アドレス バーで使用する検索エンジン］のメニューから、使いたい検索エンジンを選びます。 既定の検索エンジンは、OpenSearch テクノロジを使う任意のサイトに変えられます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

Microsoft Edge のアドレス バーに言葉を入れて検索すると、いつも同じ検索エンジンの結果が出ます。これをほかの検索エンジンに変えるには、［アドレス バーと検索］の［アドレス バーで使用する検索エンジン］を選び直します。一覧に目当ての検索エンジンが出ないときの足し方も含めて、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 変えたい理由を先に確かめる
  2. 手順：一度検索してから、設定で選ぶ
  3. 一覧に出ないときは、先にそのサイトで検索する
  4. 変えた後に確かめること
  5. 新しいタブ ページの検索の欄は別に確かめる

1．変えたい理由を先に確かめる

確認日：2026年11月16日。

対象は、Windows のパソコンで使う Microsoft Edge です。新しいタブ ページの中にある検索の欄の設定は扱いません（このヘルプのページには書かれていないためです）。

検索エンジンを変えたい理由は、職場によってさまざまです。社内で使い方の説明を統一したい、前のパソコンで使っていた検索エンジンに合わせたい、業界の調べものに強いサイトの検索を使いたい。理由を先に書き出しておくと、変えた後に「なぜこれにしたのか」と聞かれても答えられます。反対に、はっきりした理由がないなら、無理に変えないのも一つの判断です。

一方で、Microsoft のヘルプには、Bing を既定のまま使い続けた場合の利点も書かれています。Windows アプリへの直接リンク、職場または学校のアカウントでサインインしている場合の組織からの関連性の高い提案、Windows に関する質問への回答をすぐに得られる、といった点です。 職場のアカウントで Edge を使っているなら、この利点を手放してよいかも合わせて考えます。

2．手順：一度検索してから、設定で選ぶ

ヘルプの手順は、設定の画面を開く前に、まず検索をするところから始まります。

  1. 既定にしたい検索エンジンを使って、アドレス バーで検索します。
  2. Edge で［設定など］から［設定］を選びます。
  3. ［プライバシー、検索、サービス］を選びます。
  4. ［検索と接続済みサービス］を選び、［アドレス バーと検索］を選びます。
  5. ［アドレス バーで使用する検索エンジン］のメニューから、使いたい検索エンジンを選びます。

手順1を飛ばして設定の画面を開くと、メニューに目当ての検索エンジンが見当たらないことがあります。その場合は、次の「一覧に出ないとき」の手順に進みます。

3．一覧に出ないときは、先にそのサイトで検索する

メニューの一覧に使いたい検索エンジンがないときは、その検索エンジンで一度検索すると、一覧に足されます。ヘルプでは、別の検索エンジン（または Wiki サイトなど、検索をサポートする Web サイト）を使ってアドレス バーで検索を実行し、［アドレス バーと検索］に移動すると、検索に使ったエンジンや Web サイトが、選べるオプションの一覧に表示されると説明されています。

ここで大事なのは、「検索をサポートする Web サイト」も一覧に入りうる、という点です。業界の用語集や、社内でよく使う資料のサイトで検索したことがあると、それが一覧に並ぶことがあります。選ぶときは、一覧の名前をよく見て、ふだんの調べものに使う検索エンジンを選びます。誤って特定のサイトの検索を既定にすると、アドレス バーで調べた言葉がそのサイトの検索として扱われ、戸惑う原因になるかもしれません（ヘルプにこの場合の説明はありません）。

4．変えた後に確かめること

設定を変えたら、アドレス バーに何か言葉を入れて検索し、選んだ検索エンジンの結果が出るかを確かめます。確かめるときは、社内の情報や取引先の名前ではなく、天気や時刻のような当たり障りのない言葉を使うと安心です。

共用のパソコンや、複数の人が同じ使い方をする職場では、どの検索エンジンにしたかを書き残しておきます。

残す内容架空の記入例
変えた設定［アドレス バーで使用する検索エンジン］
選んだもの社内で使い方の説明をそろえている検索エンジン
理由新人向けの手順書の画面と合わせるため

5．新しいタブ ページの検索の欄は別に確かめる

Edge で新しいタブを開くと、ページの中にも検索の欄が出ることがあります。今回のヘルプの設定の名前は［アドレス バーで使用する検索エンジン］で、アドレス バーで検索したときの検索先を決めるものです。 新しいタブ ページの中の検索の欄がどの検索エンジンを使うかは、このページには書かれていません。設定を変えた後に、アドレス バーと新しいタブ ページの欄の両方で検索してみて、結果の出方を確かめておくと、「変えたはずなのに変わっていない」という問い合わせを減らせます。

パソコンの設定の小さな違いは、社内の手順書と画面が食い違う原因になりがちです。社内の作業と手順を一度書き出してみるときは、業務棚卸しチェックシート（エクセル・CSV）が使えます。
