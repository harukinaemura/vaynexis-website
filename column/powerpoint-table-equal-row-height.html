PowerPointの比較表で行の高さを均等にそろえる手順と確認点

要点

PowerPoint の表で行の高さをそろえるには、Windows 向けのヘルプでは、表をクリックして［テーブル レイアウト］タブの［セル サイズ］グループの［高さ］ボックスに目的のサイズを入力します。Mac 向けのヘルプでは、そろえたい行を選んで［行の分散］を選択すると、複数の行を同じサイズにできます。見出しの行を含めるかは操作前に決め、そろえた後は長い説明が入る欄も読み、罫線の並びと文字の収まりを別々に確かめます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、PowerPoint の比較表で行の高さをそろえたい小さな会社の担当者が、Windows と Mac の操作の違いと、そろえた後の文字の収まりを確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

1．見出しを含めるか、本文の行だけにするか

確認日：2026年11月11日。

Microsoft サポートの「PowerPointのテーブル、列、または行のサイズを変更する」は、適用先に PowerPoint for Microsoft 365、PowerPoint for Microsoft 365 for Mac、PowerPoint 2024、PowerPoint 2024 for Mac、PowerPoint 2021、PowerPoint 2021 for Mac、PowerPoint 2019、PowerPoint 2016 を挙げ、手順を Windows・macOS・Web に分けています。Mac の［行の分散］が載っている「WordまたはPowerPoint for Macのテーブルのサイズを変更する」の適用先は、PowerPoint for Microsoft 365 for Mac、PowerPoint 2024 for Mac、PowerPoint 2021 for Mac と Word for Mac です。

調整前に、表のどこからどこまでを同じ高さにしたいのかを決めます。見出しは内容の区切りとして残し、比較する項目の行だけをそろえるのか、見出しを含めた全体の見た目を統一するのか、完成形を先に言葉にしておきます。

表の上から順に直し始めるより、そろえる範囲の先頭と末尾を確認してから作業すると、対象外の行まで変更する行き違いを避けやすくなります。

2．高さを指定する欄で、そろえる寸法を統一する

Windows 向けの手順では、サイズを変更する行を含む表をクリックし、［テーブル レイアウト］タブの［セル サイズ］グループにある［高さ］ボックスに目的のサイズを入力します。同じ手順は、行の境界線の上にポインターを置いて上下にドラッグする方法も挙げています。同じ高さにそろえるときは、目で合わせるドラッグより、値を入れて行ごとに比べられる［高さ］ボックスを使います。

そろえたい行を順に調整し、同じ高さの値を指定します。行の高さを合わせる目的なので、隣にある幅の値まで変える作業には広げません。入力前には、今扱っているのがどの行か、目的の範囲から外れていないかを見直します。

基準にする高さは、余白が少ない行だけを見て決めません。文字が多い欄も読める大きさを候補にし、対象の行をそろえた後に、窮屈な欄が残っていないかを確認します。高さの値を統一したことと、読みやすく仕上がったことは、別の確認項目です。

3．Mac版は、選んだ行を同じサイズにする操作も使う

Mac版では、表を選ぶと［テーブルデザイン］と［レイアウト］のタブが表示されます。 同じ高さにしたい行を選び、［行の分散］を選択すると、複数の行を同じサイズにそろえられます。

この方法では、先に決めた範囲と選んだ範囲が一致しているかを、操作の直前に確認します。見出しを別の高さで残す計画なら、本文の範囲を対象にして仕上がりを見ます。表の上下端だけで判断せず、途中の境界も追って確かめます。

特定の行だけの寸法を指定する場合は、その行をクリックし、［高さ］を変更します。

対象の行をまとめてそろえる作業と、例外として残す行を個別に直す作業を分けておくと、後から修正する場所が明確になります。担当者へ渡すメモにも、そろえた範囲と、別の高さにした行を区別して残します。

4．小さくそろえられないときは、文字の大きさを確認する

「PowerPointのテーブル、列、または行のサイズを変更する」は、セルの最小高さは、テーブル セル内のテキストのフォント サイズによって異なるとしています。［高さ］に小さい値を入れても行が思ったほど低くならないときは、セル内の文字の大きさが下限を決めていないかを見ます。

希望の高さに近づけるために文字だけを縮め続けず、まず文字の大きさと読みやすさを見直します。行の上下に余白が残っているように見えても、罫線の位置だけを基準に判断しません。

確認の順番は、文字を最後まで読めるか、改行した箇所で意味が途切れていないか、比較する項目を横へ追えるか、という流れにします。高さが同じでも、説明の長い欄だけが詰まって見える状態は、仕上げの確認で拾う対象です。内容を省く判断が必要になった箇所は、寸法の調整とは分け、資料を作った担当者と相談します。

Microsoft サポートのアクセシビリティの案内では、テーブルを使用する必要がある場合は、データ専用の単純なテーブル構造を作成し、列ヘッダー情報を指定するとしています。

見た目を整えるために、比較項目と列の見出しの関係が曖昧になっていないかも確認します。高さを統一した後も、各欄がどの項目に対応するかをたどれることを、仕上がりの条件にします。

5．調整後の確認は、範囲・境界・文字の順に進める

ここからは当社の整理です。

既存の比較表を引き継いだ場面を想定し、内容には手を加えず、高さを直す範囲だけを整理した例です。次の表は、比較結果を作るものではなく、担当者どうしで調整方針を共有するためのメモです。

表の中の場所調整方針仕上がりで見る点
見出しの行本文とは別の高さで残す項目名が読めるか
比較項目の行対象の範囲で高さを統一する行の境界にばらつきがないか
長い説明のある欄読みやすさを確認する文末まで読めるか

調整後は、まず変更した範囲の先頭と末尾を見て、意図した行を扱ったか確かめます。次に、その間の境界を順に追い、未調整の行が混ざっていないかを見ます。最後に、説明が長い欄から文字を読み、途中で欠けた内容や、見出しとの対応を確認します。

周囲の余白も含めて眺め、表の下にある注記などと近づきすぎていないかも確かめます。行の寸法をそろえる作業が終わった段階で、資料全体の読みやすさへ視点を戻します。引き継ぎでは、対象外にした行と、文字量のために再確認が必要な欄を伝えると、次の担当者が修正を再開する場所を判断しやすくなります。
