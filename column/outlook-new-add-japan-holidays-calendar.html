Outlookで来年の祝日を予定表に追加するには？2027年の祝日が出ないときの対処

要点

新しい Outlook では、予定表ビューで予定表グリッドの下のウィンドウにある［Calendar追加］（予定表の追加）を選び、［休日］から日本を選ぶと、Outlook が祝日を予定表にコピーします（Outlook on the web・Outlook.com は［予定表の追加］→［休日］、クラシック Outlook は［ファイル＞オプション＞Calendar］→［予定表オプション］の［祝日の追加］）。ただし Microsoft は、祝日カレンダーに 2026 年後半や 2027 年の祝日が含まれていない問題を既知の問題として公表しており、報告例に「2026 年の残りの期間から 2027 年を通して日本の祝日は外れます」が挙がっています（2026年11月27日時点で状態は「回避策」）。追加した後は予定表を 2027 年まで進めて内閣府の表と見比べ、足りなければ会社で管理する予定表などの代わりの休日データで補います。

公開：2026年11月18日／更新：2026年11月27日／情報の確認日：2026年11月27日（出典はこの記事の最後）

Outlook の予定表に来年（2027年）の祝日を出したい、祝日を追加したのに 2027 年の分が出ない、というときに、新しい Outlook・Outlook on the web・クラシック Outlook で日本の祝日を追加する手順と、Microsoft が公表している既知の問題、内閣府の 2027 年の祝日の表、重複したときの削除のしかたを、Microsoft サポートと内閣府のページで確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月27日に確かめました。機能や画面は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．来年（2027年）の祝日が Outlook に出ないとき：Microsoft が公表している既知の問題

確認日：2026年11月27日

Outlook の予定表に 2027 年の祝日が出ないときは、まず Microsoft サポートの既知の問題のページ「Outlook で 2026 年 6 月以降の祝日カレンダーが表示されない」を見ます。このページは、Outlook の祝日カレンダーに、2026 年後半および/または 2027 年の予定のすべての祝日エントリが含まれていないことに気付くお客様もいるかもしれない、と説明しています。影響は、Outlook on the web、新しい Outlook for Windows、従来の Outlook for Windows、Microsoft の休日カレンダー データを使用するその他の Outlook クライアントを通じて追加された休日カレンダーに及ぶ可能性があるとされています。

現象として挙がっているのは、2026 年の特定の日付以降の祝日が表示されなくなる、2026 年までの祝日は含まれるが 2027 年の祝日は含まれない、特定の個々の祝日が見つからないか日付が正しくない、の3つです。報告を受けた国と地域の一覧には日本が入っていて、お客様から報告された例として「2026 年の残りの期間から 2027 年を通して日本の祝日は外れます」と書かれています。Microsoft はこの問題を認識しており、複数の地域からの報告を調査しているとしています。2026年11月27日に取り直した時点で、ページの最終更新日は 2026 年 9 月 4 日、状態は「回避策」のままでした。

手順どおりに日本の休日を追加しても 2027 年の祝日が予定表に出ないときは、操作の誤りではなく、この休日カレンダーのデータの側の問題である可能性があります。回避策としてページが挙げるのは、組織が管理する休日カレンダー、サードパーティの祝日カレンダー サブスクリプション（ICS）、政府または地域の公式祝日カレンダーといった代わりの休日データです。これらは Microsoft が管理する休日カレンダーではないため、別の管理と検証が必要になる場合があるとも注意しています。サポート ケースでは、予定表データの手動削除と再インポートは個々のユーザーには機能する可能性があるものの、大規模な組織には実用的ではない可能性があることが示されている、とも書かれています。

出ないときに確かめる順番

（1）休日カレンダーがそもそも入っているか。ヘルプは、Outlook を初めて使用する場合、予定表に休日はなく、1 つ以上の国の祝日を追加できるとしています。新しい Outlook に切り替えたばかりなら、まだ追加していないこともあります（手順は下の節）。（2）予定表を 2027 年まで進め、次の節の内閣府の表と見比べる。（3）2026 年の分は出ていて 2027 年の分が無い、または一部だけ抜けているなら、既知の問題のページの今の状態を見たうえで、休日カレンダーを削除して追加し直すか、会社で管理する予定表などで補います。

2．2027年（令和9年）の日本の祝日・休日：内閣府の表

内閣府の「「国民の祝日」について」のページには、令和8年（2026年）及び令和9年（2027年）の国民の祝日が載っています。国民の祝日に関する法律では、年間に計16の日が「国民の祝日」とされ、「国民の祝日」は休日とされています。2027 年の表は次のとおりで、16 の国民の祝日に加えて、3月22日が祝日法第3条第2項による休日です。

祝日法第3条第2項は、「国民の祝日」が日曜日に当たるときは、その日後においてその日に最も近い「国民の祝日」でない日を休日とすると定めていて、内閣府はこれをいわゆる「振替休日」と呼ばれる休日だと説明しています。2027 年は 3月21日の春分の日が日曜日に当たるため、翌日の3月22日が休日です。内閣府のページには、昭和30年（1955年）から令和9年（2027年）までの国民の祝日の CSV 形式のファイルもあり、2027 年の分は上の表と同じ日付です。

3．どの Outlook を使っているかを先に見分ける

祝日の追加の画面は、新しい Outlook for Windows、クラシック Outlook、Web 版（Outlook on the web・Outlook.com）で違います。Microsoft のヘルプ「Outlook で予定表に休日を追加する」も、使用している Outlook のバージョンに応じてタブを選ぶ形になっていて、タブは「新しい Outlook」「クラシック Outlook」「Web」の3つです。

ヘルプ「所有している Outlook のバージョンが不明な場合」によると、Outlook for Windows には新しい Outlook for Windows と従来の Outlook for Windows の 2 つのバージョンがあり、右上隅に［設定］ボタンがあれば新しい Outlook、なければ従来の Outlook です。新しい Outlook を開くと、リボンに［ホーム］［表示］［ヘルプ］のタブが表示されます。Web 版は、サインインした後の URL が outlook.live.com で始まれば Outlook.com（個人用 Microsoft アカウント）、ドメインに outlook.office.com または outlook.office365.com が含まれていれば Outlook on the web（職場または学校のアカウント）です。

年末が近づくと、来年の営業日や、連休の前後の当番、取引先との定例会議の日程を決める場面が増えます。そのときに予定表に祝日が入っていないと、祝日に会議を入れてしまったり、連休明けの締め切りを読み違えたりしがちなので、来年の予定を組む前に入れておきます。

6．追加した後に、2027 年の祝日まで出ているかを見比べる

追加した後は、予定表を 2027 年の祝日がある月まで進め、内閣府の表と1日ずつ見比べます。日付の決まった祝日だけでなく、月曜日に移る祝日（祝日法では、成人の日は1月の第2月曜日、海の日は7月の第3月曜日、敬老の日は9月の第3月曜日、スポーツの日は10月の第2月曜日）と、祝日法第3条第2項による休日（2027 年は 3月22日）まで入っているかを見ると、抜けや日付のずれに気づきやすくなります。既知の問題のページは、特定の個々の祝日が見つからないか、日付が正しくないという現象も挙げています。

見比べて 2027 年の分が欠けていたら、既知の問題のページの状態が「回避策」のままかを確かめ、次の節の方法で補います。見比べた結果は、下の「照らし合わせのメモ」のように、内閣府の表の日付ごとに残しておくと、翌年に見直すときにも使えます。

7．足りないときの補い方：会社で管理する予定表・ICS・公式の祝日

既知の問題のページが、Outlook の休日カレンダーで現在利用可能な情報以外の休日情報が必要な場合の代わりとして挙げるのは、組織が管理する休日カレンダー、サードパーティの祝日カレンダー サブスクリプション（ICS）、政府または地域の公式祝日カレンダーです。どれも Microsoft が管理する休日カレンダーではないため、別の管理と検証が必要になる場合があります。

Outlook on the web では、.ics ファイルから既存の予定表にイベントをインポートしたり、オンラインで予定表を購読して自動更新を受け取ったりできます（ICS 購読または iCal 購読と呼ばれます）。ヘルプによると、.ics ファイルをインポートした場合は、元のカレンダーの所有者が更新しても、インポートしたイベントは自動的に更新されません。購読した場合は所有者の変更に合わせて更新されますが、更新には 24 時間以上かかることがあります。Microsoft は、サードパーティの予定表の正確性や内容について責任を負わないとし、インポートや購読の前に使用条件を確認するよう勧めています。クラシック Outlook では、［ファイル＞開く & エクスポート＞Import/Export］のインポートとエクスポート ウィザードで、iCalendar（.ics）または vCalendar ファイル（.vcs）をインポートできます。

小さな会社なら、総務の担当者が内閣府の表をもとに、来年の祝日と会社の休業日をまとめた予定表を1つ作り、全員に共有する、という形が現実的です。Outlook on the web では［予定表の追加］から空白の予定表を作成できます。内閣府のページにある祝日のファイルは CSV 形式で、上の Microsoft のヘルプが取り込むファイルとして挙げているのは .ics（クラシック Outlook では .ics と .vcs）です。作った予定表の中身は会社が自分で確かめて直す必要があり、翌年の分を入れ忘れない段取りも要ります。

8．同じ祝日が2つずつ並ぶとき：クラシック Outlook と Web の重複

クラシック Outlook のタブによると、国または地域の祝日が既に追加されている場合、［予定表に祝日を追加］ダイアログ ボックスでその国のボックスがオンになっていて、そのまま［OK］を選択すると、休日が追加され、重複が作成されます。同じタブには、Outlook for Windows と Outlook on the web の両方を使用して休日カレンダーを追加すると、重複したイベントが表示されることがある、とも書かれています。

クラシック Outlook のタブには、休日情報の年の範囲について、Outlook for Microsoft 365、Outlook 2019、Outlook 2016 で提供される休日情報はグレゴリオ暦年 2016 年から 2026 年を含む、という注記があり、2027 年については書かれていません。2026 年までの休日の日付が表示されない場合は、既存の休日情報を削除し、Outlook の最新の更新プログラムをインストールし、予定表に休日を再追加する必要がある場合がある、とされています。新しい Outlook のタブには年の範囲の記載はありません。前のパソコンやクラシック Outlook で祝日を入れていた人は、新しい Outlook や Web で追加し直す前に、同じ祝日が2つずつ並んでいないかを見ておき、要らない方を次の節の手順で外します。

9．要らなくなった休日カレンダーを削除する

新しい Outlook と Outlook on the web・Outlook.com では、ナビゲーション ウィンドウで休日カレンダーを右クリックし、［削除］を選び、もう一度［削除］を選んで確定します。

クラシック Outlook では、予定表から［表示＞変更ビュー＞List］（ヘルプの表記）を選び、［配置］グループで［カテゴリ］を選んで、すべてのイベントを分類別に並べ替えます。［休日］カテゴリが表示されるまで一覧をスクロールし、削除する祝日を選んで［ホーム＞削除］を選びます。祝日は場所で並べ替えられ、国ごとに並んでいるので、外したい国の分だけを選べます。通常の予定表の表示に戻すには、［表示＞変更ビュー＞Calendar］を選びます。

試しに入れた国の休日が要らなくなったときや、会社で作った予定表に切り替えるときも、この手順で外します。

11．確認表
