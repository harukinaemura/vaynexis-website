宿泊者名簿は何を記録する？本人確認と旅券の写し、保存の管理

要点

旅館業の営業者は、宿泊者名簿を備え、宿泊者の氏名、住所、連絡先その他の厚生労働省令で定める事項を記載し、都道府県知事の要求があれば提出しなければなりません。 名簿は、正確な記載を確保するための措置を講じたうえで作成し、作成の日から3年間保存します。 日本国内に住所を有しない外国人の宿泊者については、国籍と旅券番号の記載、旅券の呈示、旅券の写しの保存が求められています。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

フロントで宿泊者名簿の欄をどこまで埋めればよいか、外国人のお客様の旅券のコピーはどう残すか。旅館業法と管理要領に沿って、記載・本人確認・3年の保存を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 何を書くかは、法令と都道府県の両方で決まる
  2. 本人確認は、対面か、それと同等の方法で
  3. 外国人の宿泊者の旅券
  4. 保存と備え付けの場所
  5. 宿泊の回ごとに残す（架空の例）
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．何を書くかは、法令と都道府県の両方で決まる

確認日：2026年11月17日。

施行規則は、名簿に書く事項を、宿泊者の氏名、住所及び連絡先のほか、日本国内に住所を有しない外国人であるときはその国籍及び旅券番号、その他都道府県知事が必要と認める事項、と定めています。 最後の「都道府県知事が必要と認める事項」は地域ごとに違いうるため、施設のある都道府県等の条例や細則で、追加の欄があるかを確かめてから名簿の様式を決めます。管理要領を改正した令和8年1月20日の通知は、旅館業における生活環境への悪影響の防止に関する考え方を整理したもので、各地域の実情を踏まえ、必要な場合には条例の改正等を行うよう都道府県等に求める技術的な助言とされています。

宿泊者の側も、営業者から請求があったときは、名簿の事項を告げなければならないとされています。 受付で記入を断られたときに、この規定があることを落ち着いて伝えられるよう、フロントの手順書に書いておきます。

団体の宿泊には例外があります。代表者又は引率責任者が構成員の氏名、住所、連絡先等を確実に把握している場合は、代表者等の必要事項のほか、団体の名称、男女別の人数などの構成が分かる事項を記載すれば足りるとされています。 この例外を使うときは、代表者が構成員の情報を把握していることを、予約の時点で確かめておきます。

2．本人確認は、対面か、それと同等の方法で

管理要領は、名簿の正確な記載を確保する措置として本人確認を行い、対面又は対面と同等の手段として、決められた要件に当たる ICT を使う方法等で行うとしています。 要件は2つの型で示されています。

  • 宿泊しようとする者の顔と旅券が鮮明な画像で確認でき、その画像が施設の近くから発信されていると確認できること
  • 本人確認情報と、営業者が発行する二次元コードや暗証番号等の事前共有情報を事前に共有し、施設の自動チェックイン機器等で照合できること。その際は本人確認の状況を、顔を判別できる角度で、防犯のために自ら設けたビデオカメラ等で録画し、必要時に確かめられること

1つ目の型の「施設の近くから発信されている」ことの確かめ方の例として、施設等に備え付けたテレビ電話やタブレット端末等による方法が挙げられています。 客室や玄関の端末で本人と旅券を映す運用なら、どの端末を使うかを決めておきます。

自動チェックイン機器を使う場合は、宿泊しようとする者が機器の操作について問い合わせできる設備や体制も確保するとされています。 夜間に無人で受け付ける施設なら、問い合わせを受ける担当と連絡の手段を、シフト表と一緒に決めておきます。

3．外国人の宿泊者の旅券

日本国内に住所を有しない外国人の宿泊者については、名簿の国籍と旅券番号の欄への記載を徹底し、旅券の呈示を求め、旅券の写しを名簿とともに保存します。写しの保存には、自動チェックイン機器等による電子的な保存も含まれ、写しを保存すれば、名簿の氏名、国籍、旅券番号の欄への記載を代えても差し支えないとされています。

呈示を拒まれたときは、国の指導による措置であることを説明して呈示を求め、更に拒否する場合は、旅券不携帯の可能性があるものとして最寄りの警察署に連絡するなど、適切に対応するとされています。 厚生労働省は、宿泊者に呈示とコピーへの協力を求める案内文を、日本語、英語、韓国語、中国語で載せています。 受付の台に置いておくと、説明の言葉がそろいます。

4．保存と備え付けの場所

名簿は、旅館業の施設か、営業者の事務所のいずれかに備えます。 保存の期間は作成の日から3年間なので、名簿の1件ごとに作成した日が分かるようにしておかないと、いつ消してよいかが決められません。

警察官から職務上、名簿の閲覧請求があった場合は、捜査関係事項照会書の交付の有無にかかわらず、職務の目的に必要な範囲で協力するとされ、交付がないときも本人の同意を得る必要はないとされています。 請求を受けたときは、誰が応じ、何を見せたかを記録に残す手順を決めておきます。

5．宿泊の回ごとに残す（架空の例）

名簿と旅券の写しは、宿泊の回ごとに、作成の日と保存の期限を並べて管理すると、消す時期を見落としません。

管理の欄（架空）書くこと
宿泊の回の番号予約ごとの番号
名簿の作成日チェックインで名簿を作った日
本人確認の方法対面／ICT のどちらか
旅券の写し該当なし／紙／電子
保存の期限作成日から3年
保管の場所施設／事務所

この表は実際の氏名や旅券番号を書く表ではなく、名簿の束やファイルの管理のための表です。名簿そのものと分けて管理します。連泊や同じ人の再来館の扱いを含め、名簿の作り方を個別に決めるときは、施設を所管する保健所に確かめます。フロントの書類と保管先を業務ごとに一覧にするなら、業務棚卸表のテンプレートと記入例の形も使えます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□名簿の欄に、氏名・住所・連絡先と、外国人の宿泊者の国籍・旅券番号があるか
□都道府県知事が必要と認める事項を、条例や細則で確かめたか
□本人確認を、対面か ICT の要件に当たる方法で行っているか
□旅券の写しを名簿とともに保存し、呈示を拒まれたときの手順があるか
□名簿ごとに作成の日が分かり、3年の保存の期限を管理しているか
□備え付けの場所を、施設か事務所に決めたか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。
