SharePointのチェックインで、編集を終えた資料をほかの人が使える状態に戻すには

要点

チェックアウトした資料と、その資料に加えた変更は、ライブラリにチェックインするまで同僚は使えません。 編集が終わったら、資料を保存（ダウンロードして直したならアップロード）してから、ライブラリで資料を選び、［その他］メニューの［チェックイン］を選びます。 何も変えなかった、または変更を残したくない場合は、チェックインではなく［チェックアウトの破棄］を選びます。

公開：2026年11月18日／情報の確認日：2026年11月17日（出典はこの記事の最後）

直したはずのひな形が同僚の画面では古いまま、しかも編集もできないと言われた。原因になりやすいチェックインの戻し忘れについて、保存との順番、コメントの書き方、変更を残さないときの破棄を確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

見積書のひな形を改定する場面は架空の例で、代わりにチェックインする前に本人へ確かめる進め方は当社の考えです。

  1. チェックアウトしている間に起きていること
  2. 戻すまでの順番
  3. コメントは「後で戻すときの手がかり」
  4. Excel のブックを直していた場合
  5. 変更を残さないなら「チェックアウトの破棄」
  6. 戻し忘れの資料を見つけたとき
  7. 架空の例：見積書のひな形の改定
  8. 確認表
  9. 自社の事務の手順まで形にしたいとき

1．チェックアウトしている間に起きていること

確認日：2026年11月17日。

対象は、Microsoft 365 の SharePoint のドキュメント ライブラリを Web ブラウザーで使う場合です（Excel のデスクトップ版からの戻し方も後で触れます）。

チェックアウトは、自分が直している間、ほかの人に資料を編集させないための仕組みです。ヘルプでは、チェックアウトしたファイルはオンラインでもオフラインでも編集でき、何度でも保存できると説明されています。 そして、編集を終えてライブラリにチェックインすると、変更がほかのユーザーに表示され、適切なアクセス許可を持つユーザーがファイルを編集できるようになります。

裏を返すと、チェックインを忘れると、直した内容は同僚に見えず、同僚はその資料を直せないままです。「最新の見積書のひな形が反映されていない」「資料が編集できない」と言われたら、まず自分のチェックアウトが残っていないかを疑います。チェックアウト中のファイルには、ファイル名の右側に小さなアイコンが表示され、チェックアウトされていることをすべてのユーザーに示します。

2．戻すまでの順番

ヘルプでは、チェックアウトして編集する場合、オンラインでもダウンロードでも、次の順で進めるよう書かれています。

  1. ドキュメントをチェックアウトする
  2. サポートされているアプリでドキュメントを開くか、ダウンロードする
  3. ドキュメントを編集する
  4. 文書を保存またはアップロードする
  5. ドキュメントをチェックインする

詰まりやすいのは4と5の順番です。パソコンにダウンロードして作業した場合は、チェックインする前にアップロードするよう勧められています。 先にチェックインしてしまうと、手元のパソコンにある直した資料がライブラリに入らないまま、ほかの人が編集できる状態に戻ってしまいます。

3．コメントは「後で戻すときの手がかり」

コメントは省略できますが、ヘルプは省略しないよう勧めています。版が組織で追跡されていれば、コメントはバージョン履歴の一部になり、以前の版に戻すときに重要になる可能性があるためです。 バージョン管理が有効なライブラリでは、チェックアウトした後のチェックインごとに新しいバージョンが作られます。 「4月の単価に改定」「宛名の誤字を修正」のように、何を変えたかが分かる短い言葉を残します。

4．Excel のブックを直していた場合

Excel for Windows のデスクトップ版で直していたなら、アプリの中から［ファイル］>［情報］>［チェックイン］を選び、変更の説明を書いて［OK］を選べます。 一方、Excel for the web で直していた場合は、ブラウザーのタブを閉じ、ドキュメント ライブラリに戻ってから、ライブラリの手順でチェックインします。

5．変更を残さないなら「チェックアウトの破棄」

チェックアウトしたものの何も変えなかった場合や、直した内容を残したくない場合は、保存せずにチェックアウトを破棄できます。ライブラリで資料を選び、［その他］メニューから［チェックアウトの破棄］を選び、［はい］で完了します。 組織が版を管理している場合、チェックインのたびに新しい版ができますが、破棄すれば、変えていないのに新しい版ができることを避けられます。 破棄してもバージョン番号は変わりません。

6．戻し忘れの資料を見つけたとき

ほかの人がチェックアウトしたままで編集できない資料は、ライブラリでファイル名にマウスを合わせると、チェックアウトしたユーザーの名前などの詳細が表示されます。 まずはその人に連絡して、チェックインしてもらうのが順番です。

本人が休んでいて連絡がつかない場合、権限があれば、ほかのユーザーがチェックアウトしたファイルを代わりにチェックインできます。その際は、別のユーザーにチェックアウトされていることを示す警告が表示され、［OK］を選ぶと上書きになります。 本人の手元でまだアップロードしていない変更があれば、それは反映されないと考えられます。上書きする前に、本人か上司に一言確かめておきます。

7．架空の例：見積書のひな形の改定

営業事務の担当者が、共有ライブラリの見積書のひな形を改定した場面です（架空の例）。

手順架空の記入例
チェックアウト見積書のひな形を選び、［その他］から［チェックアウト］
編集と保存パソコンにダウンロードして直し、ライブラリへアップロード
チェックイン［その他］から［チェックイン］、コメントに「4月の単価に改定」
確認チェックアウトのアイコンが消え、同僚が新しいひな形を開けた

チェックアウトを使うかどうか、使うなら戻すまでの順番をどうするかは、共有の資料を扱う社内の決まりとして決めておくと、戻し忘れが減ります。共有の決まりの整え方は、業務改善の進め方でも扱っています。
