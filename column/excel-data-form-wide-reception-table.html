Excelデータフォームで横に長い受付表を一件ずつ入力するには

要点

Excel のデータフォームを使うと、横に長い表の各列を入力欄として表示し、一件ずつ記入できます。元の受付表の見出しと記録のまとまりを整理してから、入力する内容と計算で表示する内容を分けて進めるとよいです。

公開：2026年11月14日／情報の確認日：2026年11月13日（出典はこの記事の最後）

この記事は、横に長い受付表を一件ずつ入力したい小さな会社の担当者が、Excelデータフォームの準備と追加・訂正の手順を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月13日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 横長の表を入力画面にする前に、対象と上限を押さえる
  2. 見出しを整え、［フォーム］ボタンを追加する
  3. 新しい受付は、記入してから確定する
  4. 訂正・削除と、追加できないときの扱いを分ける
  5. 記入する欄の意味を、受付の運用とそろえる
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．横長の表を入力画面にする前に、対象と上限を押さえる

確認日：2026年11月13日。

Windowsデスクトップ版を対象に、日本語の公式ヘルプの手順を整理しています。実画面での操作確認は行っていません。Mac版とWeb版は対象に含めていません。

Microsoft の案内に合わせ、この記事では Excel for Microsoft 365、Excel 2024、Excel 2021 を対象とします。

組み込みのデータフォームは、セル範囲またはテーブルから自動生成できます。各列見出しが入力欄のラベルになり、入力できる列数は最大32列です。項目が多い受付表では、画面を開く前に列の総数を確かめておくと、途中で構成を考え直す手間を避けられます。

データフォームは、見出しとテキストボックスを並べた単純な入力で足り、高度な部品や独自の画面を必要としない場合に使います。受付表に何を記録するかが決まっているなら、入力欄の見た目を作り込む前に、既存の項目で記入できるかを考える順序になります。

2．見出しを整え、［フォーム］ボタンを追加する

対象の範囲やテーブルには各列の見出しを付け、データ範囲に空白行がない状態にします。「備考」のように広く使える名前だけでは、何を記入する欄か引き継ぎ相手に伝わりにくいことがあります。受付時点の連絡事項なのか、対応後の記録なのかまで、見出しで区別するとよいです。

入力対象のセル範囲またはテーブルをクリックします。続いて、クイックアクセスツールバーの横の矢印から［その他のコマンド］を開きます。［コマンドの選択］の一覧で［すべてのコマンド］を選びます。リストの［フォーム］を選択した後、［追加］、［OK］の順にクリックします。

クイックアクセスツールバー自体が見えない場合は、リボンの上にあるウィンドウ右上を右クリックし、［クイック アクセス ツール バーを表示］を選びます。これは、ボタンを探す前にツールバーを表示するための操作です。

追加したツールバーの［フォーム］ボタンをクリックして入力画面を開きます。現れた項目名を元の表と照らすと、別の受付表を選んでいないか、記入する内容に合う欄がそろっているかを確認できます。

3．新しい受付は、記入してから確定する

新しい記録を追加するときは、データフォームの［新規作成］をクリックし、表示された欄へ内容を入力します。次の欄へは Tab キー、前の欄へは Shift キーを押しながら Tab キーで移動します。連絡内容を読み返す段階と、記入を終える段階を分けておくと、確認の途中で確定する混乱を防ぎやすくなります。

入力を終えて Enter キーを押すと変更が保存され、その行は範囲またはテーブルの一番下に追加されます。Enter キーを押す前なら［復元］で変更を元に戻せますが、入力したデータは破棄されます。書きかけの内容を残しておきたい場面では、戻す操作の前に手元の記録と照らすとよいです。

データフォームの［閉じる］をクリックすると、ワークシートへ戻れます。戻った後は、受付内容が同じ記録としてまとまっているかを見ます。表示されたことだけで入力完了とせず、連絡方法や対応状況が手元の記録と合っているかまで確かめる流れです。

4．訂正・削除と、追加できないときの扱いを分ける

既存の行は、［次を検索］または［前を検索］で移動できます。受付内容が似ている記録でも、受付番号や連絡内容を手元の記録と照らしてから変更する扱いにするとよいです。

内容を変更した後、Enter キーで行を更新すると、次の行へ自動的に移ります。数式のあるセルは結果が表示されますが、データフォームから数式を変更することはできません。結果の表示が期待と違うときは、受付内容の訂正と計算方法の見直しを分けて扱います。

行の［削除］では確認のメッセージが表示され、確認後は削除を元に戻せません。連絡事項の書き間違いを直す場面で、記録そのものを消さないように、引き継ぎ時にも訂正と削除を別の操作として伝えるとよいです。

「リストまたはデータベースを拡張することはできません」と表示された場合は、表の下への拡張によって既存データが上書きされる可能性があります。周辺に置いた集計や別の記録を見て、追加先の空間を確認する場面です。

5．記入する欄の意味を、受付の運用とそろえる

ここからは当社の整理です。

入力欄を開けた後は、実際に記入する人が迷う箇所を整理します。次のように欄の意味を決めておけば、見た目だけを整えて、記録の基準が人によって異なる状態を避けやすくなります。

項目記入する内容の例確かめる点
受付番号仮受付あ手元の受付記録と対応しているか
問い合わせ内容資料の送付希望要望と対応結果を混ぜていないか
連絡方法電子メール相手の希望と合っているか
対応状況担当確認待ち受付しただけか、対応が済んだか

欄の意味を決める際は、入力担当者が判断できる内容と、担当者の確認を待つ内容を分けます。まだ決まっていない事項を、記入欄を埋めるためだけに推測して書くと、後から見た人が確定した情報として扱うおそれがあります。空欄の理由や確認待ちの表記をそろえるほうが、連絡の経過を追いやすくなります。

運用を始める前には、見本の表で追加と訂正の流れを試し、元の受付表と照らす役割も決めておくとよいです。入力を終えた人と後から対応する人では必要な情報が異なるため、内容を受け渡す段階まで見て、欄の不足や重複を判断します。

事務の手間を洗い出すなら、記入欄へ転記する作業と、内容を判断する作業を分けることが、AIを業務に取り入れる進め方を考える入口になります。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□対象にする表と、利用する版の適用範囲を確認したか
□項目の見出しと、データ範囲に空白行がないことを確認したか
□列数が入力できる範囲に収まっていることを確認したか
□新規追加と既存記録の訂正を区別したか
□記入内容を確定する前に、手元の受付記録と照合したか
□削除する必要がある場合は、対象の記録と判断理由を確認したか
□元の表に戻り、追記先と周辺の記録を確認したか
