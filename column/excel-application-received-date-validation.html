Excelの受付日を申請期間内に限るには？開始日と終了日の設定

要点

Windows版のExcel for Microsoft 365で受付日欄を選び、［データの入力規則］で入力値の種類を［日付］にし、開始日と終了日の間に限る条件を設定します。エラーメッセージのスタイルは［停止］です。配布前には開始日と終了日、その前後を手入力で確かめ、貼り付けた値やすでに入っている日付は別に点検します。

公開：2026年11月9日／情報の確認日：2026年11月7日（出典はこの記事の最後）

Excelの受付欄に開始日と終了日を設定し、期間内外の手入力と次回の更新を確認します。

公式ページ・公式ヘルプなどの一次資料を2026年11月7日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 1．受付案内にある開始日と終了日を設定する
  2. 2．配布する表のうち、どの欄に条件がかかったかを見る
  3. 3．期間の両端と、そのすぐ外側を確認する
  4. 4．次回の期間は、前回の申請表を残して切り替える
  5. 5．条件をかけたセルを探し、次回の期間をまとめて直す
  6. 6．すでに入っている期間外の日付に印を付けて探す
  7. 確認表
  8. 自社の事務の手順まで形にしたいとき

1．1．受付案内にある開始日と終了日を設定する

確認日：2026年11月7日

この記事ではWindows版のExcel for Microsoft 365で、日付だけを記入する受付欄を設定します。対象の受付日セルを選び、［データ］＞［データの入力規則］を選びます。

［設定］タブの［入力値の種類］で［日付］を選び、［データ］で条件を選んで、選んだ内容に応じた値を設定します。

同じヘルプの後半にある表「その他の種類のデータ入力規則の追加」では、日付の期間を設定する例として、［データ］ボックスで［次の値の間］を選び、［開始日］と［終了日］のボックスに入力しています。このヘルプのWindows向けの手順には条件と欄の名前までは書かれていないため、受付期間に限るときは、画面でこの名前の条件と欄を確かめてから受付案内の日付を入力します。

［エラー メッセージ］タブでエラーメッセージをカスタマイズし、［スタイル］を選んで［OK］を選びます。

「データの入力規則に関する詳細」のヘルプでは、［停止］は無効な値の入力を止める種類で、［注意］は警告、［情報］は通知をしたうえで、無効な値の入力を許可します。期間外の手入力を止めるときは［停止］を選びます。

コピーやオートフィルで値を入れた場合は、期間外の値でもメッセージが表示されません。

設定時点ですでに入力されている無効な値にも、自動の通知はありません。

ここからは当社の整理です。

設定に使うのは、今回の受付案内で確定した二つの日付です。案内に申請書の作成日や審査予定日もある場合は、何の日付を受付欄に記入するかを担当者とそろえてから転記します。開始日と終了日を控えるときは、月日だけでなく年も記録します。年度をまたいで使うひな形では、前年の年だけが残っていないかも確認できます。

2．2．配布する表のうち、どの欄に条件がかかったかを見る

設定する前に、申請者が実際に日付を記入する範囲を控えます。受付日が複数行に並ぶ表では、列全体を対象にする前に、見出し、備考欄、日付以外の入力欄が混ざっていないかを見ます。申請を集約する側だけが使う日付欄と、配布する申請表の受付日欄が両方あるなら、どちらに条件を設けたかを記録します。

設定の後は、対象範囲の先頭と末尾を別々に選び、［開始日］と［終了日］を読み直します。元の表に条件が異なる行が含まれていた場合は、その行の扱いを担当者に確認してから適用します。日付の表示形式がそろっていても、入力規則の適用範囲は設定画面で確認する方が、見落とした行を見付けやすくなります。

エラーメッセージに日付を載せる運用では、入力できる期間を受付案内と同じ表記で示します。期間を変更する際には、設定の二つの日付とエラーメッセージを一緒に見直すと、説明だけが前回の期間のまま残る事態を見つけられます。

3．3．期間の両端と、そのすぐ外側を確認する

確認は配布前のコピーで行います。受付案内から実際の開始日と終了日を取り、四つの日付を順に手入力します。期間の中央の日だけでは、開始日や終了日を一日ずらして設定していても見つかりにくいため、境界で確かめます。

手入力する日受付案内との関係確かめる動作
開始日の前日期間の直前入力が止まり、受付日欄に期間外の日付が残らないか
開始日期間の初日入力でき、案内にある開始日として表示されるか
終了日期間の最終日入力でき、案内にある終了日として表示されるか
終了日の翌日期間の直後入力が止まり、受付日欄に期間外の日付が残らないか

期間内の日付が止まったら、年を含む設定値と、入力したセルに適用されている条件を確認します。期間外の日付が入った場合は、まず手入力で試したかを確認し、そのセルのスタイルが［停止］かを見直します。設定日を直す前に、照合で見つけた原因を区別しておくと、別の欄の規則を誤って変更しにくくなります。

既存の行や貼り付けで集約した行は、受け付けた日付を受付案内の範囲と別に照合します。受付日が空欄の行や、別のシステムから時刻付きで取り込んだ値を扱う場合は、そのまま配布用の手入力欄と同じ点検に含めず、管理担当に扱いを確かめます。

4．4．次回の期間は、前回の申請表を残して切り替える

次の受付期間に切り替えるときは、前回の配布版を残した状態で次回用の表を用意します。新しい受付案内を基に、開始日と終了日を両方見直します。古い日付が残りやすい箇所は、表の見出し、記入案内、エラーメッセージです。入力欄を追加したときは、追加した範囲にも設定を適用したかを確認します。

新しい期間でも四つの日付で境界を確かめ、配布先が参照するファイルを決めてから共有します。引継ぎには、受付案内の所在、対象のシートと欄、設定した両端の日付、確認者を残します。問い合わせを受けたときに、申請者が開いている表の期間と担当者の控えの期間を照らし合わせられるようにしておきます。

5．5．条件をかけたセルを探し、次回の期間をまとめて直す

Microsoftの「データの入力規則に関する詳細」のヘルプ（適用先はExcel for Microsoft 365、Excel 2024などで、Mac版とWeb版は挙げていません）では、データの入力規則が設定されているセルを探すには、［ホーム］タブの［編集］グループで［検索と選択］をクリックし、［データの入力規則］をクリックします。

見つかったセルを、第2節で控えた受付日の範囲と見比べます。控えにない欄が選ばれたときは、前の版で別の欄に付けた規則が残っている可能性があるため、消す前に担当者に扱いを確かめます。

同じヘルプでは、あるセルの入力規則を変えたときに、同じ入力規則が設定されたすべてのセルへ同じ変更を自動で適用するには、［設定］タブで［同じ入力規則が設定された他のすべてのセルに変更を適用する］チェック ボックスをオンにします。次回の期間に切り替えるときは、受付日の欄の1つで［開始日］と［終了日］を直し、このチェック ボックスをオンにしてから［OK］を選びます。直した後は、範囲の先頭と末尾の行で第3節の四つの日付を確かめます。

同じヘルプでは、ブックが共有または保護されている場合はデータの入力規則の設定を変更できず、先に共有または保護を解除する必要があるとしています。ワークシートやブックを保護するときは、入力規則を設定してから行うとしています。配布用にシートを保護している表では、保護を解除してから期間を直し、境界を確かめた後に保護し直します。

6．6．すでに入っている期間外の日付に印を付けて探す

Microsoftの「データの入力規則に関する詳細」のヘルプでは、既にデータが入力されているセルにもデータの入力規則を適用できます。第1節のとおり既存の無効なデータには自動の通知がありませんが、このヘルプでは、その場合にワークシート上の無効なデータを円で囲んで強調表示するようにExcelを設定できるとしています。円を付けるには、評価するセルを選択し、［データ］＞［データ ツール］＞［データの入力規則］＞［無効なデータを円］に進みます。無効な入力を修正すると、円は自動的に消えます。

前回の受付分の行を残したまま新しい期間の規則を同じ列にかけると、前回の日付は新しい期間の外にあるため、円の対象になります。円は今の規則の期間外であることを示すだけなので、今回の受付分の行に絞って選んでから確かめ、円が付いた行は受付案内と申請の控えで日付を照らし合わせます。円が消えたかどうかだけで、受付の可否を決めないようにします。
