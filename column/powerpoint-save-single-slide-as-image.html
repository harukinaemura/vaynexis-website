PowerPointで案内スライド1枚だけを画像にして渡す方法

要点

Windows版PowerPointで、左側のサムネイルから対象のスライドを選びます。［名前を付けて保存］でPNGなどの画像形式を選び、保存時のダイアログで［この 1 つだけ］を選択します。できた画像を開き、渡したいページと合っているか確認します。

公開：2026年11月10日／情報の確認日：2026年11月10日（出典はこの記事の最後）

この記事は、PowerPointの案内スライドを1枚だけ画像にして渡したい小さな会社の担当者が、スライドの選び方、画像の形式、［この 1 つだけ］の選択と保存後の見え方を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月10日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 選んだページをタイトルと番号で確かめる
  2. 保存形式を画像に切り替える
  3. ダイアログで一枚だけを選ぶ
  4. 画像を開いて配布時の見え方を点検する

1．選んだページをタイトルと番号で確かめる

確認日：2026年11月10日。

Microsoftは、スライドのサムネイルで保存する一枚を選ぶ方法を案内しています。この案内の適用先は、PowerPoint for Microsoft 365、PowerPoint 2024・2021・2019・2016 と、PowerPoint for Microsoft 365 for Mac・PowerPoint 2024 for Mac・PowerPoint 2021 for Mac で、ページは［Windows］と［macOS］の欄に分かれています。

Windows の欄では、PowerPoint ウィンドウの左側のスライド サムネイル ペインで、保存するスライドを選びます。［スライド］タブが表示されない場合は、［表示］＞［正規化］を選ぶよう注記されています（ページの表記のまま）。

同じページでは、特定のスライドを別のプレゼンテーションで使う場合に残りの部分とは別に保存する方法と、他のアプリケーションで使える画像として保存する方法が並べて案内されています。新しいプレゼンテーションにする場合は、スライドを［コピー］し、空のプレゼンテーションに［ソースの書式設定を保持］で貼り付けます。貼り付けたスライドは2番目のスライドになるため、空白のスライドを選んで Del キーで消してから保存します。

ここからは当社の整理です。

受け取る人がスライドの文字や図を直す必要があるなら、画像ではなく新しいプレゼンテーションとして渡すほうが合うかを先に確かめます。画像にすると決めたら、配布する版を開き、スライドの順番だけで選ばず、見出しと内容も読みます。似たスライドが複数ある資料では、更新した案内の日時、問い合わせ先、図の範囲を見比べます。

2．保存形式を画像に切り替える

Microsoftの案内の Windows の欄では、［ファイル］＞［名前を付けて保存］を選びます。プレゼンテーションが OneDrive または SharePoint に保存されている場合は［コピーを保存］を選びます。保存するフォルダーに移動し、［ファイル名］にスライド イメージの名前を入力して、［種類として保存］のドロップダウン メニューから画像の形式を選びます。macOS の欄は、［ファイル］メニューの［エクスポート］から保存する手順で、選べる形式も違います。

macOSJPEG、TIFF、PNG、BMP［エクスポート］の画面で［現在のスライドのみ保存］

3．ダイアログで一枚だけを選ぶ

Microsoftの説明では、保存時に［この 1 つだけ］を選ぶと、選択したスライドを画像として保存します。注記では、［すべてのスライド］を選ぶと、プレゼンテーションのすべてのスライドが画像として保存され、各スライドは別のファイルになると説明されています。

Microsoftの案内の macOS の欄では、［標準］ビューで保存するスライドを開き、［ファイル］メニューの［エクスポート］を選びます。［ファイル形式］で画像の形式を選び、［現在のスライドのみ保存］を選んでから［エクスポート］を選びます。［幅］と［高さ］のボックスにスライド イメージのサイズを入力することもでき、保存の後に、イメージ ファイルが保存されている場所を示すメッセージ ボックスが表示されます。

選択を確定する前に対象が一枚かを見ます。［すべてのスライド］を押してしまった場合は、保存先に全ページ分の画像ができるため、今回渡す1枚以外を取り違えないようにします。出力先のフォルダを開き、古い画像と今回保存した画像が混ざっていないかを確認します。

4．画像を開いて配布時の見え方を点検する

生成した画像で端の文字、表の細かい文字、連絡先を確認します。画像ではクリックできないリンクの案内が必要なら、送付文にもURLを示します。配布前に、相手が実際に開く画面で見られる大きさかを確かめます。
