エクスプローラーの「ナビゲーション ウィンドウ」が消えたときは

要点

エクスプローラーの左側の一覧は「ナビゲーション ウィンドウ」と呼ばれ、フォルダー、ドライブ、ライブラリ、ピン留めされたファイルまたはフォルダー、OneDrive などの場所にここからアクセスします。 非表示になっているときは、エクスプローラーを開き、コマンド バーの［表示］を選んでから、［表示］、［ナビゲーション ウィンドウ］の順に選ぶと、もう一度表示されます。

公開：2026年11月17日／情報の確認日：2026年11月17日（出典はこの記事の最後）

エクスプローラーを開いたら、左側にあったフォルダーやドライブの一覧が見当たらない。そんなときに、Windows 11 のエクスプローラーで［ナビゲーション ウィンドウ］をもう一度表示する手順と、戻った後にどこに何があるかを、Microsoft の公式ヘルプに沿って整理します。

公式ページ・公式ヘルプなどの一次資料を2026年11月17日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．左側の欄の名前と役目

確認日：2026年11月16日。

対象は、Windows 11 のエクスプローラーです。クイック アクセスにフォルダーをピン留めしたり外したりする操作は扱いません。

「左のところが消えた」と言われても、どこのことか伝わりにくいものです。Microsoft のヘルプでは、エクスプローラーの画面をいくつかの領域に分けて説明しています。

領域場所ヘルプの説明（要約）
タブウィンドウの上部開いているタブが並び、新しいタブを足せる
ナビゲーション ウィンドウウィンドウの左側フォルダー、ドライブ、ライブラリにアクセスする
コンテンツ ウィンドウ中央ファイルやフォルダーが表示される
詳細ウィンドウ表示されている場合だけ選んだ項目の追加の情報。既定ではオフ
ステータス バー右下表示やレイアウトを変えるボタンがある

今回消えたのは、この表の2行目です。ナビゲーション ウィンドウがないと、ほかのフォルダーやドライブに移るたびに、アドレス バーや［戻る］のボタンを頼りにすることになり、いつもの移動に手間がかかります。共有のフォルダーや OneDrive のように、ふだん左の一覧から開いている場所ほど、どこから入ればよいか分からなくなります。

2．もう一度表示する手順

ヘルプには、左側のナビゲーション ウィンドウを非表示にしていた場合に、もう一度表示する手順が載っています。

  1. ［スタート］からエクスプローラーを選ぶか、タスク バーのエクスプローラーのアイコンを選びます。
  2. コマンド バーから［表示］を選びます。
  3. ［表示］を選んでから、［ナビゲーション ウィンドウ］を選びます。

これで、エクスプローラーのウィンドウにナビゲーション ウィンドウが表示されます。 ヘルプの手順では［表示］が2回出てきます。最初の［表示］はコマンド バーのメニューで、その中にもう一段［表示］の項目があり、そこに［ナビゲーション ウィンドウ］が入る形と思われます。1回目の［表示］だけで見つからないときは、2段目まで開いてみます。戻した後は、いったんエクスプローラーを閉じて開き直し、左側の一覧が出たままになっているかも確かめておくと安心です。

同じ［表示］の中には、ファイル名拡張子や隠しアイテム、項目のチェック ボックスといった、表示の切り替えが並んでいます。 近くの項目を触ったときに、ナビゲーション ウィンドウまで一緒に切り替えてしまったのかもしれません。

3．戻ったら、どこに何があるか

ナビゲーション ウィンドウが戻っても、「前と並びが違う」と感じることがあります。とくに、デスクトップやドキュメントのフォルダーの場所です。

ヘルプによると、Windows 11 バージョン 22H2 以降では、デスクトップ、ドキュメント、ダウンロード、写真、ミュージック、ビデオの既知の Windows フォルダーは、エクスプローラーのホームと左側のナビゲーション ウィンドウの両方のクイック アクセスに、ピン留めされたフォルダーとして既定で表示されます。 これらの既定のフォルダーは、［この PC］の下には表示されなくなります。

つまり、「この PC の下にドキュメントがない」のは、ナビゲーション ウィンドウが壊れたのではなく、置き場所がクイック アクセスに移ったためと考えられます。古い手順書に「この PC → ドキュメント」と書いてある職場では、手順書の書き方を見直しておくと、新しい人が迷いません。ヘルプではこの扱いがバージョン 22H2 以降の話として書かれているため、手順書には使っている Windows 11 のバージョンも添えておくと、画面と見比べやすくなります。

4．マウスを使わずに左の欄へ移る

ナビゲーション ウィンドウが表示されていれば、キーボードでも移れます。エクスプローラーそのものは、Windows ロゴ キー＋E キーで開けます。ヘルプでは、F6 キーで前へ、Shift+F6 キーで後ろへ、エクスプローラーの主要な要素の間を移動すると説明されています。 ナビゲーション ウィンドウに移ったら、↑キーと↓キーでフォルダーとドライブを選び、Enter キーを押すと、選んだフォルダーやドライブがコンテンツ ウィンドウに開きます。

5．共用のパソコンで起きたとき

共用のパソコンでは、前に使った人が表示を変えたまま、ということが起きます。直した人が、何をどう戻したかを一言残しておくと、同じことが起きたときに次の人がすぐ直せます。

残す内容架空の記入例
起きたことエクスプローラーの左側の一覧が消えていた
戻し方［表示］→［表示］→［ナビゲーション ウィンドウ］
気付いたことドキュメントは［この PC］ではなくクイック アクセスにある

こうしたパソコンの小さな直しは、誰がどれだけ時間を使っているかが見えにくい作業です。社内の作業を一度書き出してみるときは、業務棚卸しチェックシート（エクセル・CSV）を使うと、1行ずつ整理できます。
