Wordの案内文に現れた選べない横線を罫線設定から消す手順

要点

クリックしても選べない横線は、境界線の一種である水平線の可能性があります。その場合は、線の真上にカーソルを置き、［ホーム］タブの［罫線と網かけ］ボタンの横にある矢印から［罫線なし］を選んで消します。入力のたびに横線ができるときは、［入力時にオートフォーマット］の［罫線］をオフにします。文章や必要な区切りを保てているかは、変更後の文書で確かめます。

公開：2026年11月12日／情報の確認日：2026年11月11日（出典はこの記事の最後）

この記事は、Word の案内文に出た選べない横線を消したい小さな会社の担当者が、線の正体と罫線の外し方、入力で横線が入る設定を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月11日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 選べない線の正体と、手順を使う版を確かめる
  2. 線の直上から罫線のメニューを開く
  3. 線が残るときは、位置と対象を見直す
  4. 消した後の文書と、次の入力を確かめる
  5. 案内文の確認結果を短く引き継ぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．選べない線の正体と、手順を使う版を確かめる

確認日：2026年11月11日

Microsoft サポートの「Word で行を削除する」は、削除する行を選択できない場合は、実際には境界線の一種である水平線である可能性があるとしています。「Word で水平線を挿入する」は、Word では文書やメッセージに全角の横罫線を挿入する 3 文字のショートカットが使われるとし、1 行だけに決まった文字を 3 つ入力して Enter キーを押す手順を挙げています。同じページは、3 文字のショートカットは下部の境界線を持つ空白の段落を作成するとしています。線の見た目だけで原因を決めず、選択できるかと、どの文章の下にあるかを確かめます。

同じページのヒントでは、横方向の行をキャンセルして 3 文字を保持するには、横線を作成した直後に BackSpace キーを押すとしています。入力した直後に線ができたと気付いたときは、この方法で戻せます。時間がたってから気付いたときは、次の節の手順で罫線を外します。

「Word で行を削除する」の適用先は Word for Microsoft 365、Word 2024、Word 2021、Word 2019、Word 2016 で、Mac は挙げられていません。「Word で水平線を挿入する」の注は、この内容は Word for Windows（Microsoft 365 サブスクリプションの Word を含む）に適用され、手順とオプションは Word for Mac と Word for the web では異なる場合があるとしています。この記事の手順は Windows 版の Word のものです。使っている版を先に控え、画面が合わないときは、その版に合った説明を探します。

2．線の直上から罫線のメニューを開く

作業前には元の文書を残し、変更前の文章と線の位置を見比べられる状態にしておきます。操作する箇所を案内文の中で特定し、直上の文末と直下の書き出しを目印にします。空いて見える部分でも、先に文字や改行を削らず、線だけを取り除く目的を保って進めます。

カーソルを置く位置

削除を始める位置は、消したい水平線の真上です。線の下にある文章を選んだまま進めていないかを見直します。複数の案内が続く書面では、似た区切りが別の場所にもあるため、見出しと本文の組み合わせで対象を確かめると追いやすくなります。

メニューから解除する

カーソルを置いたら、［ホーム］タブで［罫線と網かけ］ボタンの横にある矢印を選択し、［罫線なし］を選択します。操作後はいったん本文へ視線を戻し、対象の横線が消えたか、前後の文字が残っているかを読み直します。

消えたことだけを見て終了せず、残す予定だった別の区切りも確認します。意図した箇所以外の見た目も変わっていたら、変更前の状態と照らし合わせ、どこを対象にしたかを調べ直します。

3．線が残るときは、位置と対象を見直す

解除しても見た目が変わらない場合は、同じ操作を広い範囲へ繰り返す前に、カーソルの位置を確かめます。消したい箇所の上下の文章をもう一度読み、別の段落を対象にしていなかったかを見直します。途中から別の担当者が見るときも、どこにカーソルを置いて操作したかが分かる記録が役立ちます。

Microsoft サポートの「Wordのテキストに罫線を追加する」は、［罫線と網かけ］の設定で、［適用先］ボックスに正しい設定（テキスト または 段落）があることを確認するとしています。同じページの Mac の手順では、文字列を選んでいない場合は、適用先を［段落］にのみ設定できるとしています。文字の周りに付いた線を扱っているのか、段落の下に付いた線を扱っているのかを確かめます。設定画面をすでに開いている場合も、線の色や太さを変える前に、対象が合っているかを見ます。

同じページでは、スタイル、色、幅を選択し、ダイアログ ボックスの［プレビュー］セクションのボタンで選択を適用し、プレビューが目的の形なら［OK］を選択するとしています。確認を終えた後は、実際の本文でも前後の並びを見ます。

クリックして選べる線は、別の扱いです。「Word で行を削除する」は、Word 文書内の線、コネクタ、または図形を削除する必要がある場合は、それらを選択してから Delete キーを押すとしています。線がページの端に沿って付いているときは、ページ罫線の設定も見ます。「ページ罫線を削除する」では、Windows の新しいバージョンで［デザイン］タブの［ページ罫線］を選択し、［設定］で［罫線なし］を選択する手順です。横線のある位置だけで判断せず、選択の可否と設定の対象を照らし合わせると、調べる手順を絞れます。

4．消した後の文書と、次の入力を確かめる

既存の線を取り除いた後は、文書を整えた結果と、その後の入力の結果を見ます。横線を消す操作を終えても、同じ入力をしたときの動作まで確認したとは限らないためです。

「Word で水平線を挿入する」では、3 つのショートカット文字を入力したときに横線が挿入されないようにするには、［ファイル］タブで［オプション］を選択し、［校正］タブで［オートコレクトのオプション］を選択し、［入力時にオートフォーマット］を選択して［罫線］オプションをオフにし、［OK］を選択するとしています。入力時の設定も見直す場合は、作業用の文書で入力の結果を確かめ、変更した項目を短く控えます。

引き継ぎでは、現在の文書を直した箇所と、入力時の動作を確認した範囲を記録します。線が消えた状態を見せるだけでなく、どんな編集をした後に確認したかも残すと、再び線が現れた際に状況を比べられます。文書を受け取った担当者は、記録された箇所から確認を始められます。

5．案内文の確認結果を短く引き継ぐ

ここからは当社の整理です。

社内説明会の案内を直す例では、対象の位置、変更後に残す内容、確認結果を短い表にまとめます。

確認する場所残す内容記録する結果
開催案内の本文と申込案内の間それぞれの文章不要な横線が消え、文章が残ったか
注意書きの前後注意書きと読み順文字抜けや不要な空きがないか
末尾の連絡案内連絡先の記載行の欠けや他の区切りの変化がないか

引き継ぎには、文書名と修正した見出し、変更後に見た範囲を残します。「線を消した」だけでは場所を特定しにくいため、「申込案内の前」のように前後の内容で位置を示します。読み手がその箇所までたどり着けるかを基準にすると、記録を長くせずに済みます。

確認の終わりには、案内文を冒頭から末尾まで読みます。横線が消えた後も、本文のまとまりが伝わるか、注意書きを見落としにくいかを確かめ、仕上がった状態を共有します。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□使っている版と、参照した手順の対象が合っているかを確認したか
□消したい横線の位置を、前後の文章で特定したか
□線の直上に操作位置を合わせたか
□操作後に、不要な横線が消えたかを確認したか
□本文や注意書きが欠けず、残す区切りも保たれているかを確認したか
□入力時の設定（［入力時にオートフォーマット］の［罫線］）を見直した場合、その結果も確認したか
□変更箇所と確認結果を、引き継ぐ人がたどれる形で記録したか

ここまでの確認を、自社の事務の手順書や、AIの結果を確かめる検査まで形にしたい場合は、当社のように、手順と検査の設計まで行う相談先が選択肢になります。オンラインは全国から対応しています。

出典（確認日：2026年11月11日）

  • Word で行を削除する：選択できない水平線の可能性、線の直上からの削除、選択できる線の扱い、適用先（Mac なし）
  • Word で水平線を挿入する：3 文字のショートカット、段落の下側の境界線、直後の BackSpace、Windows 版が対象の注、自動挿入を止める
  • Wordのテキストに罫線を追加する：罫線の適用先（テキスト・段落）、文字列を選ばないときは段落だけ、プレビューのボタン
  • ページ罫線を削除する：ページ罫線を［罫線なし］にする手順（Windows の新しいバージョン）
