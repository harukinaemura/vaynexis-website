Chromeを開きっぱなしにするとどうなる？更新が保留になる理由と再起動の手順

要点

Chrome の更新は、通常はブラウザを閉じて次に開くまでの間にバックグラウンドで行われます。開きっぱなしにしていると更新が適用されず、保留中のアップデートがあることが示されます。右上のその他アイコンから［ヘルプ］→［Google Chrome について］を開き、［再起動］を選ぶと適用されます。開いていたタブやウィンドウは再起動のあとに自動で表示されますが、シークレット ウィンドウは表示されないので、入力中の内容は先に保存します。

公開：2026年11月4日／更新：2026年11月19日／情報の確認日：2026年11月18日（出典はこの記事の最後）

業務で Chrome（クローム）を何日も閉じずに使っていると、更新が当たらないまま古い版で動き続けることがあります。開きっぱなしにすると何が起きるか、保留中の更新の当て方、開いたままのタブの扱いを、Google Chrome ヘルプで確かめます。

公式ページ・公式ヘルプなどの一次資料を2026年11月18日に確かめました。機能や画面は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

1．開きっぱなしだと更新が保留のままになる

確認日：2026年11月18日

Google Chrome ヘルプでは、Chrome は新しいバージョンが利用可能になったときに自動更新できるようになっていて、アップデートは通常、パソコンでブラウザを閉じて次に開くまでの間にバックグラウンドで行われると説明されています。言い換えると、閉じずに使い続けている間は、新しい版が届いていても今の版のまま動いています。

同じヘルプでは、ブラウザをしばらく開いたままにしていると、保留中のアップデートがあることが示される可能性があるとも書かれています。朝にパソコンを開いて、夕方まで、あるいは何日も Chrome を閉じない使い方では、この「保留」の状態が続きやすくなります。更新には最新のセキュリティ アップデートが含まれるので、気づいたら区切りのよい所で当てておきます。

2．保留中の更新を［再起動］で適用する手順

保留中の更新は、次の順で適用します。

  1. パソコンで Chrome を開きます。
  2. 右上のその他アイコンから［ヘルプ］→［Google Chrome について］を選択します。この画面を開くと、アップデートがあるかどうかが確認されます。
  3. ［再起動］を選択します。

［再起動］が表示されない場合は、最新バージョンです。［Google Chrome］という見出しの下に表示される番号が、今のバージョン番号です。すぐに再起動できないときは［後で］を選べますが、その場合は Chrome を次回再起動したときに更新が適用されます。

Windows では、アップデートを適用するには、デスクトップ上に開いているすべての Chrome ウィンドウとタブを閉じてから Chrome を再起動するよう案内されています。ウィンドウを1つ閉じただけでは、別のウィンドウが残っていて更新が当たらないことがあります。

3．再起動で戻るタブと、先に保存しておくもの

ヘルプのヒントには、再起動のときに開いていたタブやウィンドウは、ブラウザを再起動したときに自動的に表示される（ただしシークレット ウィンドウは表示されない）とあります。タブが戻ることと、入力した内容が残ることは別です。再起動の前に、開いている仕事を見渡して保存を済ませます。

開いている仕事の例再起動の前に済ませること開き直したあとに見る所
問い合わせへの返信書きかけの文章を下書きとして保存する下書きと宛先
備品の申請入力を保存し、申請を確定したかを控える保存した内容と処理の状態
クラウドの表の編集編集を終え、再開する表を控える保存先と編集した箇所
シークレット ウィンドウでの確認見ていたページのアドレスを控える（自動では戻らない）

下書きとして残せる仕事は下書きにし、保存のしかたが分からない画面は社内の担当者に聞いてから再起動します。急いで送信や確定を済ませるより、どこまで終えてどこから再開するかを決めておく方が、開き直したあとに迷いません。更新を別の人に頼むときも、「閉じてよい」だけでなく、保存済みの仕事と再開のときに見る仕事を分けて伝えます。

4．開いたままのタブはメモリセーバーで抑えられる

「開きっぱなし」がタブの数の話なら、Chrome の［設定］→［パフォーマンス］にある［メモリセーバー］が関係します。ヘルプでは、使用していないタブを無効にしてパソコンのメモリを節約し、アクティブなタブがスムーズに動作するようにする機能と説明され、アクティブでないタブにアクセスすると自動的に再読み込みされます。非アクティブにするまでの時間は、［適度］［バランス重視（推奨）］［最大］から選びます。

入力の途中のタブが勝手に消えないかが気になるところですが、ヘルプには、パソコンの設定やアクティビティによってはタブを非アクティブにできない場合があるとして、アクティブな音声や動画、画面共有、ページ通知、アクティブなダウンロード、一部記入済みのフォーム、固定タブ、接続済みのデバイスが挙げられています。業務システムのように常に動かしておきたいサイトは、同じ［パフォーマンス］の画面で［常にアクティブにするサイト］に追加できます。

メモリセーバーは開いたままのタブの負担を減らす機能で、更新を適用する機能ではありません。タブを整理しても、保留中の更新は［再起動］まで当たらない点は変わりません。

5．更新できない・「組織によって管理されています」と出るとき

その他アイコンのメニューの下部に「組織によって管理されています」と表示されている場合、そのブラウザは管理対象です。アドレスバーに「chrome://management」と入力して確かめることもできます。管理対象の Chrome では、管理者が特定の機能の設定や制限を行っている可能性があります。

更新ができないときの対処として、ヘルプでは、Chrome をもう一度ダウンロードして再インストールする方法や、更新が完了しない場合にパソコンを再起動してからもう一度更新する方法が案内されています。そのうえで、パソコンでこれらの手順を行う権限がない場合は、パソコンの管理者に Chrome の更新を依頼するよう書かれています。会社のパソコンなら、自分で再インストールを試す前に、表示された文言と、どこで止まったかを控えて管理者に伝えます。

管理者から案内を受けたあとも、［Google Chrome について］でバージョンを見て［再起動］が出ていないことを確かめ、保存した仕事を開いて続きに戻れたところで区切ります。
