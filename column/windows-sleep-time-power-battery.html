Windows 11の電源設定でスリープまでの時間を変更するには

要点

Windows 11の電源設定では、使っていないときにデバイスがスリープ状態になるまでの待機時間を、電源接続時とバッテリー使用時について選びます。変更前の値を控え、普段使う状態ごとに選んだ内容と動作を照らし合わせる流れです。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、スリープまでの時間を変更したい小さな会社の担当者が、Windows 11 の電源状態ごとの待機時間と変更後の動作を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

例は説明のための架空の例です。確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 設定への入口から、待ち時間の項目へ進む
  2. 画面を消す時間と、端末が待機する時間を読み分ける
  3. 電源につないで使うときと、持ち出すときを分けて選ぶ
  4. 待ち時間の確認中は、別の操作を混ぜない
  5. 使う場面と変更後の結果を引き継ぐ
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．設定への入口から、待ち時間の項目へ進む

機能・画面の確認日：2026-11-15

Microsoft の日本語ヘルプが案内する対象は Windows 11 で、［スタート］→［設定］→［システム］から電源とバッテリーに関するページへ進み、画面・スリープ・休止状態のタイムアウトを扱う項目を開きます。画面の表記は Windows の版や更新状況によって異なることがあります。［設定］を開く入口には、［スタート］を右クリックして選ぶ方法もあります。

時間を選ぶ前に、画面に表示されている電源状態ごとの欄と、現在の値を控えておくとよいです。あとで仕事の進め方に合わないと分かったときも、変更前との比較ができます。引き継ぎ用の記録では、どの端末の、どの項目を変えたのかまで残します。

項目の場所を探しにくい場合、［設定］には検索バーでキーワードを入力して設定を探す方法があります。検索する語として「スリープ」を試し、開いた先で待ち時間を扱う箇所かどうかを読むとよいです。画面の位置だけを頼りにせず、何を変える項目かまで確かめてから選びます。

2．画面を消す時間と、端末が待機する時間を読み分ける

Microsoftの説明では、［次の後で画面をオフにする］は画面が消えるまでの待機時間、［次の後にデバイスをスリープ状態にする］はデバイスがスリープ状態になるまでの待機時間を選ぶ項目です。

変えたい対象を言葉にすると、選び間違いを減らしやすくなります。「資料を読む途中で画面が見えなくなる」のか、「操作していない間に端末が待機状態へ移る」のかを分けて考えます。相談を受けた担当者も、最初に起きた変化と、その後にした操作を聞き取ると、どちらを見直す話なのかを整理できます。

設定を選ぶときは、見出しだけでなく、その下の項目名を読みます。近くに時間を選ぶ欄が並んでいても、今回の対象を確かめてから変更する流れです。困っていることを解消しようとして周囲の欄までまとめて変えると、後でどの変更が必要だったのかを追いにくくなります。まず対象の欄に絞り、ほかの欄は変更前の記録と照らして扱います。

3．電源につないで使うときと、持ち出すときを分けて選ぶ

待ち時間を選ぶ対象には、電源に接続されているときと、バッテリー電源を使っているときの両方が含まれます。また、公式ヘルプでは画面オフとスリープの時間を短く設定することを、アイドル時の電力使用量を減らす方法として示しています。

時間を選ぶ際は、操作を止めている間も資料を参照する仕事と、席を離れて使わない場面を分けて考えるとよいです。単に長めの時間へ変えるのではなく、どの場面で困ったかを控え、その場面で必要な待ち方を管理担当者と相談します。日常の使い方に合うかどうかが、見直しの判断材料になります。

持ち出して使う人が、机で使ったときの確認だけで作業を終えないようにすることも大切です。確認した側と、まだ試していない側を分けて記録すれば、引き継いだ人が残りを判断できます。値をそろえること自体を目的にせず、使う場面と選択した内容の関係が伝わる記録にします。

4．待ち時間の確認中は、別の操作を混ぜない

Microsoftは、多くのPCではカバーを閉じたり電源ボタンを押したりすることでもスリープ状態になると案内しています。そのため、待ち時間を調べる際は、作業を保存して入力を止め、カバーやボタンには触れずに様子を見るとよいです。自分で状態を変える操作と、待った結果を分けて記録します。

画面が変化したときは、変化した時点と、そこから仕事へ戻るためにした操作を控えます。暗くなったという記録だけで終わらせず、選んだ項目と観察した変化が対応しているかを見ます。判断しにくければ、その状態を無理に「確認済み」にせず、見えたことを管理担当者に伝える形で十分です。

復帰方法を確かめる際は、端末に付属する資料か、製造元の案内を確認します。別の端末と戻り方が違うときも、すぐ待ち時間の選び方の誤りとはせず、対象の端末に対応した案内を確かめます。

5．使う場面と変更後の結果を引き継ぐ

ここからは当社の整理です。

紙の資料と画面を照合している間に端末が待機状態に入る場合は、操作を止めていた場面と、変更後に確かめた電源状態を分けて記録します。

記録すること架空の記入例
困っている場面紙の資料と照合する途中で端末が待機状態に入る
変更前の記録対象の端末と、変更する欄の元の値を控えた
確かめた使い方机で通常どおり使う状態で、入力を止めて待った
観察した内容表示が変わるまでの経過と、仕事へ戻る際の操作を記録した
残った確認持ち出して使う状態での確認は次の担当者へ引き継ぐ

記録では、設定した内容と試した結果を別々に書きます。選択を終えたことだけでは、普段の使い方で確かめた範囲までは伝わりません。期待と違う結果になった場合は、さらに変更を重ねる前に、変更前の値、選んだ値、待っていた間の操作を並べると相談しやすくなります。

社内の基準がある端末では、見直したい理由とともに管理担当者へ相談するとよいです。

設定の問い合わせや引き継ぎ文の作成を含め、事務の手間を洗い出すなら、AIで扱う作業を整理する考え方につなげて検討できます。その際も、変更内容を決める人と、端末で結果を確かめる人を明確にしておきます。

6．確認表

公開・共有の前に、この表で確かめます。

確認確かめること
□変更したい対象と、画面が消えるまでの待ち時間を読み分けて確認したか
□対象の端末と、変更前に表示されていた値を記録したか
□電源につないで使う場面と、持ち出して使う場面を分けて検討したか
□時間を選ぶときに、対象の欄の説明まで確認したか
□作業を保存し、待っている間の操作も含めて結果を記録したか
□確認を終えた範囲と、次の担当者へ引き継ぐ範囲を区別して記録したか
