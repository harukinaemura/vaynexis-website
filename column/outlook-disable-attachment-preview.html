Outlookの添付ファイルプレビューを無効にする手順と確認点

要点

従来の Outlook では、［ファイル］から［オプション］、［トラスト センター］、［トラスト センターの設定］、［添付ファイルの処理］へ進み、［添付ファイル プレビューを無効にする］を選びます。変更後は、選択した項目と添付を選んだときの表示を確かめ、引き継ぎに残すとよいです。

公開：2026年11月16日／情報の確認日：2026年11月15日（出典はこの記事の最後）

この記事は、添付ファイルのプレビューを無効にしたい小さな会社の担当者が、クラシック版の設定項目と変更後の表示を確かめる流れをまとめたものです。

公式ページ・公式ヘルプなどの一次資料を2026年11月15日に確かめました。機能や制度は変わることがあるので、使う前に各ページで最新の状態を確認してください。法律・税務・労務の判断や、効果を約束するものではありません。

確認表や記録項目は当社の整理です。公式機関が示す様式ではありません。

  1. 従来版の画面かを確かめます
  2. 全体を無効にする項目を選びます
  3. 「開く」と「プレビューする」を取り違えません
  4. 引き継ぎには目的と観察結果を分けて残します
  5. 表示が想定と違う場合の相談先を決めます
  6. 確認表
  7. 自社の事務の手順まで形にしたいとき

1．従来版の画面かを確かめます

確認日：2026年11月15日

Microsoft の添付ファイルに関するヘルプの適用先は、Outlook for Microsoft 365、Outlook 2024、Outlook 2021、新しい Outlook for Windows です。ここで扱う切り替えは、従来の Outlook のセキュリティ センターにある設定です。ここでは、この画面の操作に範囲を絞ります。

Microsoft の版の確認方法では、［設定］ボタンがあれば新しい Outlook、なければ従来の Outlook とされています。操作場所を探す前に使っている画面を確認すると、別の版の手順をたどる取り違えを避けやすくなります。

製品名や版を引き継ぎに残す場合は、［ファイル］から［Office アカウント］を開き、表示されない場合は［ヘルプ］を選ぶと製品のバージョンを確認できます。相談するときも、単に「項目がない」と伝えるより、どの画面を見ているかを添えると状況を共有しやすくなります。

2．全体を無効にする項目を選びます

設定への経路は、［ファイル］→［オプション］→［トラスト センター］→［トラスト センターの設定］→［添付ファイルの処理］で、選ぶ項目は［添付ファイル プレビューを無効にする］です。画面を開く操作と、最後に選択する項目を分けて読むとよいです。「無効にする」という項目を選ぶ目的なので、名前だけを見て選択を外す方向に読み違えないようにします。

別の日本語公式ヘルプでは、入口を［セキュリティ センター］、その先を［セキュリティ センターの設定］と表記しています。また、すべてのプレビューアーをオフにする項目は［添付ファイルのプレビューをオフにする］という表記です。引き継ぎでは、手元に表示された名称を控えると、案内文との照合に役立ちます。

特定の添付ファイルのプレビューアーだけを無効にする設定も、公式ヘルプでは別の操作として案内されています。今回の目的は全体を止めることです。種類ごとの設定を順番に変える手順と混ぜず、全体の項目を選んだかを確認します。

変更前の状態も控えておくと、後から別の担当者が意図を読み取れます。画面内の近い場所にある項目まで続けて変更せず、今回選んだ項目を明確にしてから結果の確認へ進むとよいです。

3．「開く」と「プレビューする」を取り違えません

添付ファイルのプレビューは、別のアプリケーションで開かずに、Outlook 内で内容を表示する機能です。一方、従来版では添付ファイルのアイコンをダブルクリックしてファイルを開きます。変更結果を確かめる際も、内容を表示した場所と、行った操作を分けて記録します。

添付を押したら開いたという報告だけでは、プレビューしたのか、別のアプリで開いたのかが曖昧です。変更前後の比較には、同じメールの同じ添付を使い、同じ操作を行う確認方法が考えられます。担当者が別の資料を開いていたり、異なる操作を行っていたりすると、設定と表示の関係を判断しにくくなります。

Microsoftの添付ファイルの案内では、閲覧ウィンドウで［件名］行の下にある添付ファイルを選択すると、ファイルやアイテムをプレビューできます。

公式ヘルプでは、メッセージ本文内の添付ファイルはプレビューできないとされています。もともと表示できない場所の添付を見て「止まった」と判断せず、変更前にどう見えていたかも確認するとよいです。設定欄の選択状態と実際の表示を照らし合わせれば、操作したつもりの状態で引き継ぐことを避けやすくなります。

4．引き継ぎには目的と観察結果を分けて残します

ここからは当社の整理です。

控える内容は、変更した理由、変更した項目、確認時に行った操作、見えた結果です。設定済みという結論だけでは、後任が同じ状態を確かめにくくなります。項目の名前は手元の表記を写し、確認した結果は自分の言葉で残すとよいです。

残す欄引き継ぎに書く内容の例
目的添付を確認する際の表示方法を担当者間でそろえる
変更した箇所選択した項目名と、変更前後の選択状態を記入する
確かめ方対象にしたメールと添付、行った操作を記入する
観察結果見えた内容と、想定どおりだったかを記入する
引き継ぐ事項画面が異なった箇所や、相談が必要な点を記入する

表は記入する内容の例です。まだ確かめていない欄を推測で埋めず、担当者が画面を確認した後に記録します。相手へ渡す控えに顧客の書類をそのまま添えるより、操作場所と結果が分かる記述にまとめるとよいです。

5．表示が想定と違う場合の相談先を決めます

選んだはずの項目が見つからない、変更後の状態が読み取れない、といった場合は、どの画面まで進めたかを整理します。画面名、選択状態、試した操作を社内の管理担当へ伝えるとよいです。原因を推測して周辺の項目を変える前に、今回の目的と対象を共有します。

後任に渡す段階では、設定の変更と添付内容の確認を別の作業として扱います。表示方法を変えたことだけで資料の内容を確認した扱いにせず、業務で必要な点検を誰が担当するかも決めておくとよいです。ブロックされた添付ファイルの解除は、この記事では扱いません。

事務の手間を洗い出すなら、添付を選ぶ前後の確認や転記も含めて、AI の活用を考える際の作業整理につなげるとよいです。人が判断する箇所と、同じ内容を繰り返し扱う箇所を分けて書き出します。
