AI Consulting

AIで日々の事務を減らし、
減らしたあとも回り続ける形にする。

毎日の事務を、AIで減らします。ただし、減らして終わりにはしません。AIは止まるより先に、動いているように見えたまま成果を出さなくなります。減らしたあとも回り続ける形にするところまでを、仕事の範囲としています。

Why

なぜ「確かめる」までを引き受けるのか

01 / 08

当社は自分の会社の事務をAIに任せて半年になります。いちばん困ったのは、AIが止まることではありませんでした。「できました」と報告されたのに、成果物が出ていなかったことです。

レシートの整理を任せて、2か月後に成果物が1枚もないことに気づきました。毎日公開していた記事は、書式が崩れたまま53日間公開されていました。どちらの場合も、AIは毎回「完了しました」と返していました。

AIを実務に入れた人が最初にぶつかる壁は、使い方ではなく「信用できるか分からない」ことです。この痛みを解く方法は、AIを賢くすることではなく、本当に終わったかを確かめる手順を、仕事の一部として持つことでした。

だから当社は、事務を減らす設計と、減らしたあとの検査を、1つの仕事として引き受けます。経緯は note の記録 に毎日書いています。

Triage

業務を3つに振り分ける

02 / 08

向き不向きは難易度ではなく「間違いに気づくまでの時間」で決まります。棚卸しでは現在の業務を全部並べ、この3つに振り分けます。AIに任せられる仕事を増やすのではなく、検査をつければ任せられる仕事を、検査つきで任せるのが当社の仕事です。

Class A

AIに任せられる

間違えてもすぐ分かる業務。議事録の下書き、問い合わせの一次返信、資料の要約。

気づくまで：数分
Class B

検査をつければ任せられる

気づくのが遅い業務。請求書の作成、経費の仕分け、在庫の突合。ここが仕事の中心です。

気づくまで：数日〜月末
Class C

人がやるべき

気づけない、または気づいたときには遅い業務。契約の判断、人事、取引先との交渉。

気づくまで：手遅れ

03 · Deliverables

手順書と検査

手順書は、お手元のAIに実装させるための文書です。投げる文面、順序、確認する点を、そのまま使える形で書きます。Claude を前提に書き、ChatGPT や Gemini をお使いの場合は読み替えの注記を付けます。

検査は、AIが返した結果について、何をどう確かめれば「本当に終わった」と言えるかの手順です。合否を記録し、人が最終確認する位置を決めます。検査を通った件数だけを、成果として数えます。

「今月、検査が3件の不整合を見つけました」は、「20時間削減しました」より説得力があります。前者は事実で、後者は推定だからです。

顧問料の算定に使う節約時間も、この考え方で出します。1件あたりの時間は貴社の記録から着手前に確定し、件数は検査を通った処理ログから数えます。推定は入りません。

FAQ

よくある質問

08 / 08
どんな業務が対象ですか。

定型の事務作業全般です。ただし向き不向きは難易度ではなく「間違いに気づくまでの時間」で決まります。

導入実績はありますか。

外部のお客様への提供は2026年9月に始めました。掲載できる事例はまだありません。自社での実績を数字でお示しします。

AIツールの導入から頼めますか。

設計と検査は行いますが、実装の代行は行いません。お手元のAIに実装させる手順をお渡しします。

どのAIに対応していますか。

手順書は Claude を前提に書きます。ChatGPT や Gemini をお使いの場合は読み替えの注記を付けます。ツールの選定は代行しません。

オンラインだけで完結しますか。

棚卸しとライトはオンラインのみです。スタンダードとプロは月1回の対面を含みます。対面は滋賀県内で、県外は交通費の実費をいただきます。

費用はいくらですか。

棚卸しは5万円（税別）で、全額返金保証つきです。顧問は節約時間×時給×50%を月額とし、最初の3か月は最低額なし、以後の最低額は月5万円からです。上限は年間売上の1%です。

節約時間はどう測るのですか。

1件あたりの時間を貴社の記録から算出して着手前に確定し、検査を通った処理件数を掛けます。推定はしません。月次レポートで件数と時間をお見せします。

小さな会社でも頼めますか。

はい。事務を1人で担っている会社こそ、主なお客様です。

途中でやめられますか。

棚卸しだけで終えて構いません。顧問は期間6か月・最低3か月で、そのあとは1か月前の通知で解約できます。

業務のデータはどう扱いますか。

相互の秘密保持契約のもとで、手順書と検査の設計に必要な範囲でだけ扱います。当社のAIに入力する必要がある場合は、事前にご確認いただきます。

契約書のチェックも頼めますか。

行いません。法律事務にあたるため、必要な場合は弁護士をご紹介します。
